Baixar o DIGITAR

Instale no Windows para treinar sem internet, ou use direto no navegador. É o mesmo curso, grátis nos dois jeitos.

Baixar para Windows Usar online

O download abre a página da versão mais recente no GitHub. Baixe o arquivo do instalador (.exe) da lista de arquivos.

Instalar

  1. Abra o instalador

    Dê dois cliques no arquivo baixado.

  2. Se o Windows avisar

    Pode aparecer a tela azul do SmartScreen. Clique em Mais informações e depois em Executar assim mesmo. O aviso aparece porque o instalador não tem uma assinatura digital paga, não porque seja inseguro.

  3. Pronto

    A instalação é rápida e termina com uma mensagem de confirmação. O atalho fica na Área de Trabalho e no Menu Iniciar.

Com o Microsoft Edge ou o Google Chrome instalado, o atalho abre o DIGITAR como um programa, numa janela própria, sem abas nem barra de endereço.

Requisitos

  • Windows 10 ou 11.
  • Microsoft Edge ou Google Chrome, atualizados. O Edge já vem no Windows.
  • Um teclado físico, de preferência no padrão ABNT2 (o que tem a tecla ç).
  • Internet só para baixar. Depois de instalado, o DIGITAR funciona sem conexão.

Para usar online, serve qualquer computador com um navegador atual, inclusive Linux e macOS.

Privacidade

O DIGITAR não tem servidor nem conta. Perfis, lições, estatísticas e prêmios ficam guardados no próprio navegador, no seu computador. Nada do que você digita é enviado para a internet.

Para levar o progresso para outro computador, use Exportar e Importar em Ajustes, dentro do app.

Como os dados ficam no navegador, limpar os dados de navegação do Edge ou do Chrome apaga o progresso. Exporte uma cópia de vez em quando.

Desinstalar

Abra o Menu Iniciar e clique em Desinstalar DIGITAR. Ele remove os atalhos e a pasta do programa.

O progresso fica no navegador e não é apagado pela desinstalação. Para apagá-lo, use Apagar dados em Ajustes, dentro do app, antes de desinstalar.
