Aula 30 · if de uma linha (operação ternária)

Nesta aula você vai aprender

  • Escrever a expressão condicional valor_a if condição else valor_b
  • Trocar um if/else simples por uma linha
  • Usar o ternário dentro de f-strings e de laços
  • Saber quando não usar o ternário

Escolher entre dois valores

Muitas vezes um if/else serve só para guardar um valor ou outro numa variável:

idade = 15
if idade >= 18:
    situacao = "maior de idade"
else:
    situacao = "menor de idade"
print(situacao)

menor de idade

São quatro linhas para uma escolha simples. O Python tem uma forma curta, a expressão condicional (também chamada de operação ternária, porque junta três partes):

idade = 15
situacao = "maior de idade" if idade >= 18 else "menor de idade"
print(situacao)

menor de idade

Leia da esquerda para a direita: "guarde "maior de idade" se a idade for maior ou igual a 18, senão guarde "menor de idade"".

As três partes

A forma é sempre: valor_se_verdadeiro if condição else valor_se_falso. O else é obrigatório: a expressão sempre precisa produzir um valor.

numero = 7
tipo = "par" if numero % 2 == 0 else "ímpar"
print(f"{numero} é {tipo}")
temperatura = 31
print("Bora pra praia!" if temperatura > 28 else "Melhor ficar em casa.")

7 é ímpar
Bora pra praia!

Atenção: Esquecer o else dá SyntaxError: x = "sim" if ok não é válido. Se você não tem um valor para o caso falso, use um if comum.

Dentro de f-strings e laços

Como o ternário é uma expressão (produz um valor), ele cabe em qualquer lugar onde caberia um valor: dentro de uma f-string, de um print, de uma conta. Um uso clássico é acertar o plural:

for quantidade in range(0, 4):
    palavra = "mensagem" if quantidade == 1 else "mensagens"
    print(f"Você tem {quantidade} {palavra}")

Você tem 0 mensagens
Você tem 1 mensagem
Você tem 2 mensagens
Você tem 3 mensagens

notas = [8.5, 4.0, 7.0, 6.9]
for nota in notas:
    print(f"{nota:4.1f} -> {'aprovado' if nota >= 7 else 'recuperação'}")

 8.5 -> aprovado
 4.0 -> recuperação
 7.0 -> aprovado
 6.9 -> recuperação

Repare nas aspas simples dentro da f-string de aspas duplas: assim o Python não confunde onde o texto termina.

Quando não usar

O ternário é ótimo para escolhas simples. Encadear vários deixa o código difícil de ler:

nota = 6.5
conceito = "A" if nota >= 9 else "B" if nota >= 7 else "C" if nota >= 5 else "D"
print(conceito)

C

Funciona, mas um if/elif/else (aula 18) é muito mais claro para quem lê. Também não use o ternário só para rodar ações diferentes (como dois print com lógicas complicadas): ele serve para escolher um valor.

Dica: Uma boa regra: se o ternário não couber confortavelmente numa linha, ou se você precisou ler duas vezes para entender, volte para o if/else de várias linhas.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
tipo = "par" if n % 2 == 0 else "ímpar"

Exercícios

1. Reescreva em uma linha, com o ternário: se saldo >= 15, mensagem recebe "Pode comprar o lanche"; senão, "Saldo insuficiente". Teste com saldo = 12.

Ver resposta 
saldo = 12
mensagem = "Pode comprar o lanche" if saldo >= 15 else "Saldo insuficiente"
print(mensagem)

Saldo insuficiente

2. Guarde em maior o maior entre a = 17 e b = 23, usando o ternário (sem usar max).

Ver resposta 
a = 17
b = 23
maior = a if a > b else b
print(maior)

23

3. Um cinema dá meia-entrada para quem tem menos de 18 anos ou 60 anos ou mais. O ingresso inteiro custa R$ 30. Com o ternário, calcule e mostre o preço para cada idade da lista [10, 30, 65].

Ver resposta 
for idade in [10, 30, 65]:
    preco = 15 if idade < 18 or idade >= 60 else 30
    print(f"{idade} anos: R$ {preco}")

10 anos: R$ 15
30 anos: R$ 30
65 anos: R$ 15

4. Mostre os números de 1 a 6, cada um seguido de "(par)" ou "(ímpar)", usando o ternário dentro de uma f-string.

Ver resposta 
for n in range(1, 7):
    print(f"{n} ({'par' if n % 2 == 0 else 'ímpar'})")

1 (ímpar)
2 (par)
3 (ímpar)
4 (par)
5 (ímpar)
6 (par)
