Uma imagem é uma grade de números

Toda foto digital é uma grade de quadradinhos chamados pixels. Uma foto de 4000 × 3000 tem 12 milhões deles. Cada pixel guarda uma cor, normalmente como três números de 0 a 255: quanto de vermelho, verde e azul (em inglês, RGB).

  • (255, 0, 0) é vermelho puro, (0, 0, 255) é azul puro;
  • (0, 0, 0) é preto e (255, 255, 255) é branco;
  • (128, 128, 128) é um cinza médio: quando os três são iguais, a cor é um tom de cinza.

Dá para brincar com isso só com listas, aqui no navegador. Esta "imagem" tem 3 × 2 pixels:

imagem = [
    [(255, 0, 0), (0, 255, 0), (0, 0, 255)],
    [(0, 0, 0), (255, 255, 255), (255, 200, 0)],
]

altura = len(imagem)
largura = len(imagem[0])
print("Tamanho:", largura, "x", altura)
print("Pixel do canto de cima, à esquerda:", imagem[0][0])
print("Pixel de baixo, no meio:", imagem[1][1])

Tamanho: 3 x 2
Pixel do canto de cima, à esquerda: (255, 0, 0)
Pixel de baixo, no meio: (255, 255, 255)

Repare que a ordem é imagem[linha][coluna], ou seja, primeiro o y (de cima para baixo) e depois o x. O Pillow, que você verá a seguir, usa (x, y) e diz o tamanho como (largura, altura).

Tons de cinza com as próprias mãos

Para transformar uma cor em cinza, o jeito mais usado pondera cada cor pelo quanto o olho humano a percebe (o verde parece mais claro que o azul). É a mesma conta que o Pillow faz no convert("L"):

def para_cinza(pixel):
    r, g, b = pixel
    return round(0.299 * r + 0.587 * g + 0.114 * b)

linha = [(255, 0, 0), (0, 255, 0), (0, 0, 255), (255, 255, 255)]
print([para_cinza(p) for p in linha])

[76, 150, 29, 255]

O vermelho virou 76, o verde 150 e o azul só 29: o verde parece mais claro mesmo. Uma imagem em tons de cinza guarda um número por pixel, em vez de três.

Instalando o Pillow

A biblioteca se chama Pillow, mas no código o nome é PIL (o nome do projeto antigo de onde ela veio). Com o ambiente virtual ativado (aula 60):

python -m pip install pillow

Coloque uma foto qualquer na pasta do projeto, por exemplo praia.jpg, e rode os exemplos a seguir no computador com python nome.py. Os tamanhos mostrados são de uma foto de exemplo; com a sua foto, os números mudam.

Abrindo e conhecendo a imagem

from PIL import Image

foto = Image.open("praia.jpg")
print("Tamanho:", foto.size)
print("Largura:", foto.width, "| Altura:", foto.height)
print("Formato:", foto.format, "| Modo:", foto.mode)
print("Pixel (0, 0):", foto.getpixel((0, 0)))

Tamanho: (4000, 3000)
Largura: 4000 | Altura: 3000
Formato: JPEG | Modo: RGB
Pixel (0, 0): (135, 190, 235)

  • size é (largura, altura) em pixels;
  • format é o tipo do arquivo (JPEG, PNG…); mode diz como as cores são guardadas: "RGB", "RGBA" (com transparência) ou "L" (tons de cinza);
  • getpixel((x, y)) devolve a cor de um pixel — aqui, um azul de céu.
Atenção: Se aparecer FileNotFoundError, o programa não achou a foto: ela precisa estar na pasta de onde você roda o python, ou use o caminho completo. E se aparecer ModuleNotFoundError: No module named 'PIL', o Pillow foi instalado em outro Python: ative o venv e instale de novo.

Redimensionar, recortar e girar

from PIL import Image

foto = Image.open("praia.jpg")

pequena = foto.resize((800, 600))
pequena.save("praia_800.jpg")
print("resize:", pequena.size)

recorte = foto.crop((1000, 500, 2000, 1500))    # (esquerda, topo, direita, base)
recorte.save("praia_recorte.png")
print("crop:", recorte.size)

girada = foto.rotate(90, expand=True)
girada.save("praia_girada.jpg")
print("rotate:", girada.size)

copia = foto.copy()
copia.thumbnail((800, 800))
print("thumbnail:", copia.size)

resize: (800, 600)
crop: (1000, 1000)
rotate: (3000, 4000)
thumbnail: (800, 600)

  • resize devolve uma imagem nova com exatamente o tamanho pedido;
  • crop recorta um retângulo; a caixa é (esquerda, topo, direita, base), contada a partir do canto de cima à esquerda;
  • rotate(90, expand=True) gira 90° no sentido anti-horário; o expand=True aumenta a tela para a imagem não ser cortada;
  • thumbnail encolhe a própria imagem, mantendo a proporção, até caber no tamanho pedido (por isso usamos uma cópia).
Atenção: resize((800, 800)) numa foto 4000 × 3000 deixa tudo achatado, porque a proporção muda. Para manter a proporção, use thumbnail. E lembre: thumbnail não devolve nada (None); escrever nova = foto.thumbnail(...) deixa nova vazia.

Convertendo cores e formatos

convert muda o modo das cores e save escolhe o formato pela extensão do nome:

from PIL import Image

foto = Image.open("praia.jpg")
cinza = foto.convert("L")
cinza.save("praia_cinza.jpg")
print(cinza.mode, cinza.getpixel((0, 0)))

logo = Image.open("logo.png")
print(logo.mode)
logo.convert("RGB").save("logo.jpg", quality=85)
print("logo.jpg salvo")

L 179
RGBA
logo.jpg salvo

O pixel (135, 190, 235) virou o número 179 — a mesma conta ponderada que você fez à mão lá em cima.

Dica: O JPEG não guarda transparência. Salvar uma imagem "RGBA" como .jpg dá OSError: cannot write mode RGBA as JPEG; converta para "RGB" antes. O quality (de 1 a 95) troca tamanho do arquivo por qualidade: 85 costuma ser um bom meio-termo.

Miniaturas de uma pasta inteira

Juntando com pathlib (aula 103), um programa processa centenas de fotos de uma vez:

from pathlib import Path
from PIL import Image

origem = Path("fotos")
destino = Path("miniaturas")
destino.mkdir(exist_ok=True)

for arquivo in sorted(origem.glob("*.jpg")):
    with Image.open(arquivo) as img:
        img.thumbnail((300, 300))
        img.save(destino / arquivo.name)
        print(arquivo.name, "->", img.size)

aniversario.jpg -> (300, 225)
escola.jpg -> (225, 300)
praia.jpg -> (300, 225)

Fotos deitadas ficam com 300 de largura e fotos em pé, com 300 de altura: o thumbnail respeita a proporção de cada uma.

Dica: Abrir com with (como em arquivos, aula 61) garante que cada imagem seja fechada logo depois de usada, o que importa quando são centenas de fotos.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
foto.thumbnail((300, 300))

Exercícios

1. Escreva um programa que converta logo.png em logo.jpg. Dica: JPEG não tem transparência, então converta para "RGB" antes de salvar.

Ver resposta 
from PIL import Image

with Image.open("logo.png") as img:
    img.convert("RGB").save("logo.jpg")

2. Qual é a diferença entre resize((300, 300)) e thumbnail((300, 300))?

Ver resposta

resize força exatamente 300x300 pixels, mesmo que a imagem fique achatada,
e devolve uma imagem nova. thumbnail encolhe a própria imagem mantendo a
proporção até ela caber dentro de 300x300, e não devolve nada.

3. Uma foto tem 1200 × 800 pixels. Escreva a caixa do crop que recorta o quadrado de 800 × 800 bem do meio da foto, calculando os números com Python.

Ver resposta 
largura, altura = 1200, 800
lado = min(largura, altura)
esquerda = (largura - lado) // 2
topo = (altura - lado) // 2
caixa = (esquerda, topo, esquerda + lado, topo + lado)
print(caixa)

(200, 0, 1000, 800)

No computador, bastaria fazer foto.crop(caixa). Esse cálculo funciona para qualquer foto, deitada ou em pé.

4. Usando a lista de pixels abaixo, crie a versão em negativo da imagem: cada cor (r, g, b) vira (255 - r, 255 - g, 255 - b).

Ver resposta 
imagem = [
    [(255, 0, 0), (0, 0, 0)],
    [(255, 255, 255), (100, 150, 200)],
]

negativo = [[(255 - r, 255 - g, 255 - b) for r, g, b in linha] for linha in imagem]
for linha in negativo:
    print(linha)

[(0, 255, 255), (255, 255, 255)]
[(0, 0, 0), (155, 105, 55)]

5. Escreva um programa que gire 180° todas as fotos .png da pasta fotos e salve com o nome terminado em _girada.png na mesma pasta.

Ver resposta 
from pathlib import Path
from PIL import Image

for arquivo in sorted(Path("fotos").glob("*.png")):
    if arquivo.stem.endswith("_girada"):
        continue
    with Image.open(arquivo) as img:
        nova = arquivo.with_name(arquivo.stem + "_girada.png")
        img.rotate(180).save(nova)
        print("salvei", nova.name)

O if evita girar de novo uma foto que já foi girada, se você rodar o programa duas vezes.
