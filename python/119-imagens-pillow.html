Aula 119 · Imagens com Pillow

Nesta aula você vai aprender

  • Abrir uma imagem e ver tamanho e formato
  • Redimensionar, recortar, girar e converter
  • Processar uma pasta inteira de fotos
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Instalando

A biblioteca se chama Pillow, mas no código o nome é PIL:

pip install pillow

Coloque uma foto qualquer na pasta do projeto, por exemplo praia.jpg.

Primeiros passos

from PIL import Image

foto = Image.open("praia.jpg")
print(foto.size, foto.format, foto.mode)    # ex.: (4000, 3000) JPEG RGB

pequena = foto.resize((800, 600))
pequena.save("praia_800.jpg")

recorte = foto.crop((0, 0, 1000, 1000))     # (esquerda, topo, direita, base)
recorte.save("praia_recorte.png")

foto.rotate(90, expand=True).save("praia_girada.jpg")
foto.convert("L").save("praia_cinza.jpg")   # "L" = tons de cinza
  • size é (largura, altura) em pixels;
  • resize muda o tamanho; crop recorta um retângulo; rotate gira em graus;
  • save escolhe o formato pela extensão do nome (.jpg, .png...).
Atenção: resize((800, 600)) pode deixar a foto achatada se a proporção for diferente. Para manter a proporção, use foto.thumbnail((800, 800)), que encolhe a imagem até caber nesse tamanho.

Miniaturas de uma pasta inteira

from pathlib import Path
from PIL import Image

origem = Path("fotos")
destino = Path("miniaturas")
destino.mkdir(exist_ok=True)

for arquivo in sorted(origem.glob("*.jpg")):
    with Image.open(arquivo) as img:
        img.thumbnail((300, 300))
        img.save(destino / arquivo.name)
        print(arquivo.name, "->", img.size)
Dica: Abrir com with (como em arquivos, aula 61) garante que a imagem seja fechada logo, o que importa quando são centenas de fotos.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
foto.thumbnail((300, 300))

Exercícios

1. Escreva um programa que converta logo.png em logo.jpg. Dica: JPEG não tem transparência, então converta para "RGB" antes de salvar.

Ver resposta 
from PIL import Image

with Image.open("logo.png") as img:
    img.convert("RGB").save("logo.jpg")

2. Qual é a diferença entre resize((300, 300)) e thumbnail((300, 300))?

Ver resposta

resize força exatamente 300x300 pixels, mesmo que a imagem fique achatada,
e devolve uma imagem nova. thumbnail encolhe a própria imagem mantendo a
proporção até ela caber dentro de 300x300.
