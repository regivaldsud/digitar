Módulo 4 · Programação orientada a objetos

Aula 75 · Associação, agregação e composição

Nesta aula você vai aprender

  • O que é associação: um objeto usa outro
  • O que é agregação: um objeto reúne outros que existem sozinhos
  • O que é composição: um objeto é feito de partes que ele mesmo cria
  • Escolher entre herança ("é um") e relação entre objetos ("tem um")

Objetos que conversam

Programas de verdade têm vários objetos trabalhando juntos: um aluno tem uma mochila, um carrinho tem produtos, uma casa tem cômodos. Existem três jeitos principais de um objeto se ligar a outro, do mais solto ao mais forte: associação, agregação e composição.

Associação: um objeto usa outro

Na associação, um objeto conhece outro e o usa, mas cada um vive a sua vida. O escritor usa uma caneta; trocar de caneta não muda o escritor.

class Caneta:
    def __init__(self, cor):
        self.cor = cor

    def escrever(self, texto):
        return f"[{self.cor}] {texto}"

class Escritor:
    def __init__(self, nome):
        self.nome = nome
        self.ferramenta = None

    def escrever(self, texto):
        if self.ferramenta is None:
            print(f"{self.nome} está sem caneta!")
            return
        print(self.ferramenta.escrever(texto))

autor = Escritor("Ruth Rocha")
autor.escrever("Era uma vez...")
autor.ferramenta = Caneta("azul")
autor.escrever("Era uma vez...")
autor.ferramenta = Caneta("vermelha")
autor.escrever("Fim.")

Ruth Rocha está sem caneta!
[azul] Era uma vez...
[vermelha] Fim.

Repare em self.ferramenta.escrever(texto): um objeto chamando o método de outro objeto guardado num atributo.

Agregação: reunir objetos que existem sozinhos

Na agregação, um objeto reúne outros, mas as partes existem por conta própria — foram criadas fora e continuam existindo se o "todo" sumir. Um carrinho de compras junta produtos que já estavam na prateleira.

class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

class Carrinho:
    def __init__(self):
        self.produtos = []

    def adicionar(self, produto):
        self.produtos.append(produto)

    def total(self):
        return sum(p.preco for p in self.produtos)

arroz = Produto("Arroz 5 kg", 27.90)
feijao = Produto("Feijão 1 kg", 8.49)
cafe = Produto("Café 500 g", 18.00)

meu = Carrinho()
meu.adicionar(arroz)
meu.adicionar(cafe)
do_vizinho = Carrinho()
do_vizinho.adicionar(arroz)
do_vizinho.adicionar(feijao)

print(f"Meu carrinho: R$ {meu.total():.2f}")
print(f"Do vizinho: R$ {do_vizinho.total():.2f}")

Meu carrinho: R$ 45.90
Do vizinho: R$ 36.39

O mesmo objeto arroz está nos dois carrinhos. Se você esvaziar um carrinho, o produto continua existindo.

Composição: o todo é feito das partes

Na composição, o objeto cria as próprias partes dentro dele, e elas só fazem sentido junto com ele. Uma casa é feita de cômodos; se a casa for demolida, os cômodos vão junto.

class Comodo:
    def __init__(self, nome, area):
        self.nome = nome
        self.area = area

class Casa:
    def __init__(self, endereco):
        self.endereco = endereco
        self.comodos = []

    def construir(self, nome, area):
        self.comodos.append(Comodo(nome, area))

    def area_total(self):
        return sum(c.area for c in self.comodos)

casa = Casa("Rua das Flores, 10")
casa.construir("sala", 18)
casa.construir("cozinha", 9.5)
casa.construir("quarto", 12)
for c in casa.comodos:
    print(f"{c.nome}: {c.area} m²")
print("Total:", casa.area_total(), "m²")

sala: 18 m²
cozinha: 9.5 m²
quarto: 12 m²
Total: 39.5 m²

Ninguém de fora cria os objetos Comodo: quem cria é a própria Casa, no método construir.

Dica: Para lembrar: associação = "usa um" (escritor e caneta); agregação = "tem vários, que existem sozinhos" (carrinho e produtos); composição = "é feito de" (casa e cômodos).

Herança ou relação?

Na aula 76 você vai ver herança, que é a relação "é um": um gato é um animal. Já associação, agregação e composição são relações "tem um": um carro tem um motor. Muitos programadores experientes preferem "tem um" sempre que der, porque deixa as classes mais independentes.

class Motor:
    def __init__(self, potencia):
        self.potencia = potencia

    def ligar(self):
        return f"motor de {self.potencia} cv ligado"

class Carro:
    def __init__(self, modelo, potencia):
        self.modelo = modelo
        self.motor = Motor(potencia)

    def ligar(self):
        print(f"{self.modelo}: {self.motor.ligar()}")

Carro("Gol", 84).ligar()

Gol: motor de 84 cv ligado

Atenção: Não faça class Carro(Motor): um carro não é um motor, ele tem um motor. Usar herança no lugar de composição deixa o código confuso.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
self.produtos.append(produto)

Exercícios

1. Crie as classes Professor(nome) e Turma(codigo) numa agregação: a turma guarda uma lista de professores criados fora dela, com o método adicionar(professor). Coloque a mesma professora em duas turmas e mostre os nomes.

Ver resposta 
class Professor:
    def __init__(self, nome):
        self.nome = nome

class Turma:
    def __init__(self, codigo):
        self.codigo = codigo
        self.professores = []

    def adicionar(self, professor):
        self.professores.append(professor)

ana = Professor("Profa. Ana")
leo = Professor("Prof. Léo")
t7 = Turma("7A")
t8 = Turma("8B")
t7.adicionar(ana)
t8.adicionar(ana)
t8.adicionar(leo)
for t in [t7, t8]:
    print(t.codigo, [p.nome for p in t.professores])

7A ['Profa. Ana']
8B ['Profa. Ana', 'Prof. Léo']

2. Crie a classe Pedido que, por composição, cria seus próprios Item(nome, qtd, preco) no método incluir(nome, qtd, preco), e um método total().

Ver resposta 
class Item:
    def __init__(self, nome, qtd, preco):
        self.nome = nome
        self.qtd = qtd
        self.preco = preco

class Pedido:
    def __init__(self):
        self.itens = []

    def incluir(self, nome, qtd, preco):
        self.itens.append(Item(nome, qtd, preco))

    def total(self):
        return sum(i.qtd * i.preco for i in self.itens)

p = Pedido()
p.incluir("Pastel", 2, 8.0)
p.incluir("Caldo de cana", 2, 6.5)
print(f"Total: R$ {p.total():.2f}")

Total: R$ 29.00

3. Crie uma associação entre Motorista(nome) e Onibus(linha): o ônibus tem um atributo motorista que pode ser trocado, e o método partir() mostra Linha 101 partindo com Sr. Zé.

Ver resposta 
class Motorista:
    def __init__(self, nome):
        self.nome = nome

class Onibus:
    def __init__(self, linha):
        self.linha = linha
        self.motorista = None

    def partir(self):
        if self.motorista is None:
            print(f"Linha {self.linha} sem motorista!")
        else:
            print(f"Linha {self.linha} partindo com {self.motorista.nome}")

bus = Onibus(101)
bus.partir()
bus.motorista = Motorista("Sr. Zé")
bus.partir()

Linha 101 sem motorista!
Linha 101 partindo com Sr. Zé

4. Classifique cada relação como associação, agregação, composição ou herança: (a) livro e capítulos; (b) biblioteca e livros; (c) leitor e óculos; (d) romance e livro.

Ver resposta

(a) composição: os capítulos fazem parte do livro e não existem sem ele.
(b) agregação: a biblioteca reúne livros que existem por conta própria.
(c) associação: o leitor usa os óculos, mas cada um vive separado.
(d) herança: um romance "é um" livro.
