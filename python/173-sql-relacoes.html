Dividir para não repetir

Se cada pedido guardasse o nome, o e-mail e o endereço do cliente, um cliente com 50 pedidos teria os dados repetidos 50 vezes, e mudar o e-mail seria um pesadelo. A solução é ter uma tabela clientes e, em pedidos, guardar só o id do cliente. Essa coluna que aponta para outra tabela é a chave estrangeira (FOREIGN KEY).

Juntando com JOIN

import sqlite3

con = sqlite3.connect(":memory:")
con.executescript("""
    CREATE TABLE clientes (id INTEGER PRIMARY KEY, nome TEXT);
    CREATE TABLE pedidos (
        id INTEGER PRIMARY KEY,
        cliente_id INTEGER REFERENCES clientes(id),
        produto TEXT,
        valor REAL
    );
    INSERT INTO clientes (nome) VALUES ('Lia'), ('Davi'), ('Rosa');
    INSERT INTO pedidos (cliente_id, produto, valor) VALUES
        (1, 'Fone', 89.9), (1, 'Capinha', 25.0), (2, 'Mouse', 59.0);
""")
sql = """
    SELECT clientes.nome, pedidos.produto, pedidos.valor
    FROM pedidos
    INNER JOIN clientes ON clientes.id = pedidos.cliente_id
    ORDER BY pedidos.id
"""
for linha in con.execute(sql):
    print(linha)
con.close()

('Lia', 'Fone', 89.9)
('Lia', 'Capinha', 25.0)
('Davi', 'Mouse', 59.0)

executescript roda vários comandos separados por ;. O INNER JOIN ... ON junta cada pedido com o cliente cujo id é igual ao cliente_id.

LEFT JOIN: incluindo quem não tem par

A Rosa não fez pedidos, por isso não apareceu acima. O LEFT JOIN mantém todas as linhas da tabela da esquerda, mesmo sem par:

import sqlite3

con = sqlite3.connect(":memory:")
con.executescript("""
    CREATE TABLE clientes (id INTEGER PRIMARY KEY, nome TEXT);
    CREATE TABLE pedidos (id INTEGER PRIMARY KEY, cliente_id INTEGER, valor REAL);
    INSERT INTO clientes (nome) VALUES ('Lia'), ('Davi'), ('Rosa');
    INSERT INTO pedidos (cliente_id, valor) VALUES (1, 89.9), (1, 25.0), (2, 59.0);
""")
sql = """
    SELECT c.nome, COUNT(p.id), COALESCE(SUM(p.valor), 0)
    FROM clientes AS c
    LEFT JOIN pedidos AS p ON p.cliente_id = c.id
    GROUP BY c.id
    ORDER BY c.nome
"""
for nome, qtd, total in con.execute(sql):
    print(f"{nome}: {qtd} pedido(s), R$ {total:.2f}")
con.close()

Davi: 1 pedido(s), R$ 59.00
Lia: 2 pedido(s), R$ 114.90
Rosa: 0 pedido(s), R$ 0.00

AS c dá um apelido curto à tabela. COALESCE(x, 0) troca o vazio (NULL) por 0.

Atenção: No SQLite, a checagem de chaves estrangeiras vem desligada. Para ligar, rode PRAGMA foreign_keys = ON logo depois de conectar.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
JOIN clientes ON clientes.id = pedidos.cliente_id

Exercícios

1. Crie as tabelas turmas (id, nome) e alunos (id, nome, turma_id) e mostre cada aluno com o nome da sua turma.

Ver resposta 
import sqlite3

con = sqlite3.connect(":memory:")
con.executescript("""
    CREATE TABLE turmas (id INTEGER PRIMARY KEY, nome TEXT);
    CREATE TABLE alunos (id INTEGER PRIMARY KEY, nome TEXT, turma_id INTEGER REFERENCES turmas(id));
    INSERT INTO turmas (nome) VALUES ('7º A'), ('8º B');
    INSERT INTO alunos (nome, turma_id) VALUES ('Ana', 1), ('Caio', 2), ('Duda', 1);
""")
sql = """
    SELECT alunos.nome, turmas.nome FROM alunos
    JOIN turmas ON turmas.id = alunos.turma_id
    ORDER BY alunos.nome
"""
for aluno, turma in con.execute(sql):
    print(aluno, "-", turma)
con.close()

Ana - 7º A
Caio - 8º B
Duda - 7º A

2. Com PRAGMA foreign_keys = ON, o que acontece ao inserir um pedido com cliente_id 99, que não existe? Teste.

Ver resposta 
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("PRAGMA foreign_keys = ON")
con.execute("CREATE TABLE clientes (id INTEGER PRIMARY KEY, nome TEXT)")
con.execute("CREATE TABLE pedidos (id INTEGER PRIMARY KEY, cliente_id INTEGER REFERENCES clientes(id))")
try:
    con.execute("INSERT INTO pedidos (cliente_id) VALUES (99)")
except sqlite3.IntegrityError as e:
    print("Erro:", e)
con.close()

Erro: FOREIGN KEY constraint failed
