Comentários com #

Tudo que vem depois de # numa linha é um comentário: o Python ignora. Comentários servem para explicar o código para pessoas — inclusive para você mesmo daqui a um mês.

# Programa que mostra o cardápio do dia
print("Prato do dia: strogonoff")  # comentário no fim da linha
print("Sobremesa: pudim")

Prato do dia: strogonoff
Sobremesa: pudim

O comentário pode ocupar uma linha inteira ou ficar no fim de uma linha de código. Para um comentário de várias linhas, comece cada linha com #:

# Cálculo do lanche da turma
# São 30 alunos e cada coxinha custa 5 reais.
# O resultado é o total em reais.
print(30 * 5)

150

"Desligando" linhas

Um uso muito comum dos comentários é desligar uma linha sem apagá-la, para testar o programa sem ela:

print("Bom dia")
# print("Esta linha não roda, porque virou comentário")
print("Boa noite")

Bom dia
Boa noite

Dica: No VS Code, selecione linhas e aperte Ctrl+; (ou Ctrl+/) para comentar ou descomentar tudo de uma vez.
Atenção: Comentário bom explica o porquê, não repete o óbvio. print("Oi") # mostra Oi não ajuda ninguém. Já # 1,60 m é a altura mínima do brinquedo ajuda muito.

Docstrings: textos entre três aspas

Uma docstring é um texto entre três aspas (""") colocado no começo de um arquivo, de uma função ou de uma classe para explicar o que ele faz. Diferente do comentário, a docstring é guardada pelo Python e pode ser consultada depois.

No começo de um arquivo, ela descreve o programa inteiro e pode ocupar várias linhas:

"""Calculadora de mesada.

Mostra quanto dinheiro sobra no fim do mês.
Autora: Júlia, 7º ano.
"""
print("Mesada:", 50)
print("Gastos:", 35)
print("Sobra:", 50 - 35)

Mesada: 50
Gastos: 35
Sobra: 15

O texto entre """ não aparece na tela: ele é documentação, não uma ordem para mostrar algo.

Lendo a documentação do Python

As funções do Python também têm docstrings. Você pode ler a de qualquer uma com __doc__ (dois sublinhados antes e dois depois):

print(len.__doc__)
print(abs.__doc__)

Return the number of items in a container.
Return the absolute value of the argument.

A documentação vem em inglês: len devolve o número de itens de algo (por exemplo, quantas letras tem um texto) e abs devolve o valor absoluto (o número sem sinal). A função help() mostra a mesma informação de um jeito mais completo:

help(abs)

Help on built-in function abs in module builtins:
 
abs(x, /)
    Return the absolute value of the argument.

Na aula 40 você vai criar suas próprias funções com def. Só para você já reconhecer: a docstring fica na primeira linha dentro da função.

def boas_vindas():
    """Mostra uma mensagem de boas-vindas ao curso."""
    print("Bem-vindo ao curso de Python do DIGITAR!")

boas_vindas()
print(boas_vindas.__doc__)

Bem-vindo ao curso de Python do DIGITAR!
Mostra uma mensagem de boas-vindas ao curso.

Atenção: As três aspas precisam ser iguais na abertura e no fechamento. Se você abrir com """ e esquecer de fechar, o Python acha que todo o resto do arquivo é texto e mostra um SyntaxError.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
# Este programa calcula a média da turma

Exercícios

1. Escreva um programa que mostre o horário da sua escola em duas linhas (entrada e saída) e tenha um comentário no topo explicando o que ele faz.

Ver resposta 
# Mostra o horário de entrada e de saída da escola
print("Entrada: 7h")
print("Saída: 12h20")

Entrada: 7h
Saída: 12h20

2. O programa abaixo deveria mostrar só "Bom dia" e "Boa noite". Coloque um comentário para "desligar" a linha do meio, sem apagá-la: print("Bom dia"), print("Boa tarde"), print("Boa noite").

Ver resposta 
print("Bom dia")
# print("Boa tarde")
print("Boa noite")

Bom dia
Boa noite

3. Coloque uma docstring de várias linhas no topo de um programa que calcula quantos dias tem um ano de 52 semanas (52 vezes 7).

Ver resposta 
"""Dias em 52 semanas.

Multiplica 52 semanas por 7 dias.
"""
print(52 * 7)

364

4. Use __doc__ para ler a documentação da função print. Qual parâmetro ela cita para trocar o separador entre os valores?

Ver resposta 
print(print.__doc__)

(trecho do começo da saída; o texto exato muda um pouco entre versões do Python)
Prints the values to a stream, or to sys.stdout by default.
 
  sep
    string inserted between values, default a space.
  end
    string appended after the last value, default a newline.

A documentação cita o parâmetro sep (o separador, que por padrão é um espaço). Você vai usá-lo na aula 10.

5. Qual a diferença entre um comentário com # e uma docstring?

Ver resposta

O comentário (#) é ignorado pelo Python: serve só para quem lê o código.
A docstring ("""...""") fica no começo de um arquivo, função ou classe e é
guardada pelo Python: dá para consultá-la com __doc__ ou help().
