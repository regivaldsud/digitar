Curso de Python

Do primeiro print aos seus próprios programas, em português e no seu ritmo. Os exemplos rodam aqui mesmo no navegador: não precisa instalar nada para começar.

Para quem é

  • Para quem nunca programou e quer começar do zero.
  • Para estudantes que já digitam com os dez dedos e querem usar isso para criar.
  • Para professores que procuram um material gratuito para a turma.

Você só precisa saber usar o computador e ter vontade de errar algumas vezes. Matemática além das quatro operações não é necessária.

Exemplo executável

Experimente agora: clique em Executar.

nome = input("Como você se chama? ")
for i in range(3):
    print(f"Olá, {nome}! Volta {i + 1}")
