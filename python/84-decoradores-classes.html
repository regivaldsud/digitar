Aula 84 · Decoradores com classes e __call__

Nesta aula você vai aprender

Objetos que viram funções: __call__

Você já sabe que funções são chamadas com parênteses: print("oi"). Com o método especial __call__, um objeto também pode ser chamado assim. A vantagem é que o objeto guarda atributos, então ele lembra coisas entre uma chamada e outra.

class Multiplicador:
    def __init__(self, fator):
        self.fator = fator

    def __call__(self, numero):
        return numero * self.fator

dobro = Multiplicador(2)
triplo = Multiplicador(3)
print(dobro(10))
print(triplo(10))
print(callable(dobro), callable(42))

20
30
True False

A função callable() diz se algo pode ser chamado com parênteses.

Um decorador feito com classe

Na aula 56 você criou decoradores com funções. Uma classe também serve: o __init__ recebe a função decorada, e o __call__ roda no lugar dela. Como é um objeto, fica fácil guardar estado, como o número de chamadas:

class ContarChamadas:
    def __init__(self, funcao):
        self.funcao = funcao
        self.chamadas = 0

    def __call__(self, *args, **kwargs):
        self.chamadas += 1
        print(f"Chamada nº {self.chamadas} de {self.funcao.__name__}")
        return self.funcao(*args, **kwargs)

@ContarChamadas
def saudar(nome):
    return f"Oi, {nome}!"

print(saudar("Ana"))
print(saudar("Léo"))
print("Total:", saudar.chamadas)

Chamada nº 1 de saudar
Oi, Ana!
Chamada nº 2 de saudar
Oi, Léo!
Total: 2

Lembre: @ContarChamadas em cima de def saudar é o mesmo que escrever saudar = ContarChamadas(saudar). Agora saudar é um objeto da classe, não mais a função original.

Dica: Para o objeto decorador "herdar" o nome e a docstring da função original, chame functools.update_wrapper(self, funcao) dentro do __init__. É a versão para classes do @wraps.

Decorador de classe com parâmetros

Quando o decorador recebe parâmetros, como @Repetir(3), o __init__ recebe os parâmetros e o __call__ recebe a função, devolvendo a função "embrulhada":

class Repetir:
    def __init__(self, vezes):
        self.vezes = vezes

    def __call__(self, funcao):
        def embrulho(*args, **kwargs):
            for _ in range(self.vezes):
                funcao(*args, **kwargs)
        return embrulho

@Repetir(3)
def gritar(texto):
    print(texto.upper() + "!")

gritar("gol")

GOL!
GOL!
GOL!

Decorando uma classe inteira

Um decorador também pode receber uma classe em vez de uma função. É útil para registrar classes ou acrescentar algo a todas elas. Aqui, cada classe decorada entra num cardápio:

cardapio = {}

def no_cardapio(classe):
    cardapio[classe.__name__.lower()] = classe
    return classe

@no_cardapio
class Coxinha:
    preco = 6.50

@no_cardapio
class Pastel:
    preco = 8.00

for nome, classe in cardapio.items():
    print(f"{nome}: R$ {classe.preco:.2f}")

coxinha: R$ 6.50
pastel: R$ 8.00

Atenção: O decorador de classe precisa devolver a classe com return classe. Se esquecer, o nome Coxinha passa a valer None.

Outro exemplo: um decorador que acrescenta um método __str__ pronto à classe.

def com_descricao(classe):
    def __str__(self):
        campos = ", ".join(f"{k}={v}" for k, v in vars(self).items())
        return f"{classe.__name__}({campos})"
    classe.__str__ = __str__
    return classe

@com_descricao
class Time:
    def __init__(self, nome, estado):
        self.nome = nome
        self.estado = estado

print(Time("Fortaleza", "CE"))

Time(nome=Fortaleza, estado=CE)

3. Escreva o decorador de classe Memoria, que guarda num dicionário os resultados já calculados de uma função de um argumento e mostra "(da memória)" quando reaproveita um resultado.

Ver resposta 
class Memoria:
    def __init__(self, funcao):
        self.funcao = funcao
        self.guardados = {}

    def __call__(self, n):
        if n in self.guardados:
            print("(da memória)")
            return self.guardados[n]
        resultado = self.funcao(n)
        self.guardados[n] = resultado
        return resultado

@Memoria
def quadrado(n):
    return n * n

print(quadrado(9))
print(quadrado(9))

81
(da memória)
81

4. Crie o decorador de classe com parâmetro Prefixo(texto), que coloca o texto antes do resultado de qualquer função que devolva uma string.

Ver resposta 
class Prefixo:
    def __init__(self, texto):
        self.texto = texto

    def __call__(self, funcao):
        def embrulho(*args, **kwargs):
            return self.texto + funcao(*args, **kwargs)
        return embrulho

@Prefixo("[AVISO] ")
def mensagem(conteudo):
    return conteudo

print(mensagem("A aula começa às 14h"))

[AVISO] A aula começa às 14h
