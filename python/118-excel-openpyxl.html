CSV ou Excel?

Um CSV (aula 106) é só texto: cada linha é uma linha da tabela e as colunas são separadas por vírgula ou ponto e vírgula. Ele não tem cores, fórmulas, negrito nem várias abas — mas qualquer programa abre.

Um arquivo .xlsx é a planilha "de verdade" do Excel (e também abre no LibreOffice e no Google Planilhas). Quando o resultado do seu programa vai ser lido por uma pessoa que quer fórmulas, títulos destacados e abas separadas, vale gerar um .xlsx com a biblioteca openpyxl.

Antes de instalar qualquer coisa, veja que a ideia de "tabela = lista de linhas" é a mesma nos dois. Este exemplo monta uma tabela e gera o CSV na memória com io.StringIO, sem criar arquivo:

import csv
import io

tabela = [
    ["Mês", "Recebi", "Gastei"],
    ["Janeiro", 100, 65],
    ["Fevereiro", 100, 80],
    ["Março", 120, 70],
]

arquivo = io.StringIO()
csv.writer(arquivo, delimiter=";", lineterminator="\n").writerows(tabela)
print(arquivo.getvalue())

Mês;Recebi;Gastei
Janeiro;100;65
Fevereiro;100;80
Março;120;70

io.StringIO finge ser um arquivo aberto: tudo o que seria gravado no disco fica guardado num texto. O delimiter=";" é o padrão que o Excel brasileiro entende, e lineterminator="\n" termina cada linha com uma quebra simples (o padrão do csv é \r\n, que aparece como linhas em branco ao imprimir).

Instalando

O openpyxl é um pacote de terceiros. Com o ambiente virtual ativado (aula 60):

python -m pip install openpyxl

Os exemplos com openpyxl devem ser salvos em arquivos .py e rodados no seu computador com python nome.py. A planilha gerada aparece na mesma pasta; abra no Excel para conferir.

Criando uma planilha

from openpyxl import Workbook

livro = Workbook()
aba = livro.active
aba.title = "Mesada"

aba.append(["Mês", "Recebi", "Gastei"])
aba.append(["Janeiro", 100, 65])
aba.append(["Fevereiro", 100, 80])
aba.append(["Março", 120, 70])

aba["D1"] = "Sobrou"
print("Célula A2:", aba["A2"].value)
print("Linhas usadas:", aba.max_row, "| Colunas usadas:", aba.max_column)

livro.save("mesada.xlsx")
print("Planilha salva!")

Célula A2: Janeiro
Linhas usadas: 4 | Colunas usadas: 4
Planilha salva!

  • Workbook() cria um arquivo novo; livro.active é a aba que já vem pronta;
  • append escreve uma linha inteira embaixo da última usada;
  • aba["D1"] acessa uma célula pelo endereço (coluna em letra, linha em número); .value é o conteúdo;
  • max_row e max_column dizem até onde a planilha está preenchida.
Atenção: Feche a planilha no Excel antes de rodar o programa. Com o arquivo aberto, o Windows bloqueia a gravação e aparece PermissionError: [Errno 13] Permission denied: 'mesada.xlsx'.

Fórmulas e estilos

Um texto que começa com = vira fórmula, calculada pelo Excel quando ele abre o arquivo. Os estilos ficam em openpyxl.styles:

from openpyxl import load_workbook
from openpyxl.styles import Font, PatternFill

livro = load_workbook("mesada.xlsx")
aba = livro["Mesada"]

for linha in range(2, aba.max_row + 1):
    aba[f"D{linha}"] = f"=B{linha}-C{linha}"

ultima = aba.max_row + 1
aba[f"A{ultima}"] = "Total"
aba[f"C{ultima}"] = f"=SUM(C2:C{ultima - 1})"

amarelo = PatternFill(fill_type="solid", start_color="FFE699")
for celula in aba[1]:                 # a linha 1 inteira
    celula.font = Font(bold=True)
    celula.fill = amarelo
aba.column_dimensions["A"].width = 14

livro.save("mesada.xlsx")
print(aba["D2"].value, "|", aba[f"C{ultima}"].value)

=B2-C2 | =SUM(C2:C4)

Repare que o Python mostra a fórmula como texto: quem calcula é o Excel. Use os nomes das funções em inglês (SUM, AVERAGE, MAX), mesmo que o seu Excel mostre SOMA e MÉDIA — o arquivo guarda sempre em inglês.

Atenção: Escrever =SOMA(C2:C4) pelo openpyxl gera #NOME? no Excel. E separe os argumentos com vírgula (=ROUND(B2,1)), não com ponto e vírgula.

Várias abas

Um livro pode ter várias abas (planilhas). create_sheet cria uma nova, e livro.sheetnames lista os nomes:

from openpyxl import Workbook

notas = {
    "Matemática": [("Ana", 8.5), ("Caio", 7.0)],
    "Português": [("Ana", 9.0), ("Caio", 6.5)],
}

livro = Workbook()
livro.remove(livro.active)           # tira a aba vazia que vem pronta
for materia, alunos in notas.items():
    aba = livro.create_sheet(materia)
    aba.append(["Aluno", "Nota"])
    for nome, nota in alunos:
        aba.append([nome, nota])

livro.save("notas.xlsx")
print(livro.sheetnames)
print(livro["Português"]["B3"].value)

['Matemática', 'Português']
6.5

Lendo uma planilha

load_workbook abre um arquivo que já existe. iter_rows percorre as linhas; com values_only=True, cada linha vem como uma tupla de valores:

from openpyxl import load_workbook

livro = load_workbook("notas.xlsx")
for nome_aba in livro.sheetnames:
    aba = livro[nome_aba]
    soma = 0
    for aluno, nota in aba.iter_rows(min_row=2, values_only=True):
        soma += nota
    media = soma / (aba.max_row - 1)
    print(f"{nome_aba}: média {media:.2f}")

Matemática: média 7.75
Português: média 7.75

min_row=2 pula a linha de títulos. Fórmulas vêm como texto ("=B2-C2"); se o arquivo já foi aberto e salvo pelo Excel, load_workbook(nome, data_only=True) entrega os resultados calculados em vez das fórmulas.

Dica: Para planilhas enormes (centenas de milhares de linhas), use load_workbook(nome, read_only=True): fica bem mais rápido e gasta menos memória.

Lendo CSV com cabeçalho

Quando a planilha vem como CSV, o csv.DictReader entrega cada linha como um dicionário, usando a primeira linha como nomes das colunas — o mesmo trabalho do iter_rows, sem instalar nada:

import csv
import io

texto = """Aluno;Matemática;Português
Ana;8,5;9,0
Caio;7,0;6,5
"""

for linha in csv.DictReader(io.StringIO(texto), delimiter=";"):
    mat = float(linha["Matemática"].replace(",", "."))
    por = float(linha["Português"].replace(",", "."))
    print(f"{linha['Aluno']}: média {(mat + por) / 2:.2f}")

Ana: média 8.75
Caio: média 6.75

No CSV brasileiro, os números vêm com vírgula (8,5), então troque por ponto antes do float. No .xlsx isso não é preciso: o openpyxl já entrega o número como float.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
aba.append(["Janeiro", 100, 65])

Exercícios

1. Crie uma planilha tabuada.xlsx com a tabuada do 7 (coluna A com o multiplicador, coluna B com o resultado), com o título em negrito.

Ver resposta 
from openpyxl import Workbook
from openpyxl.styles import Font

livro = Workbook()
aba = livro.active
aba.title = "Tabuada do 7"
aba.append(["Multiplicador", "Resultado"])
for i in range(1, 11):
    aba.append([i, 7 * i])
for celula in aba[1]:
    celula.font = Font(bold=True)
livro.save("tabuada.xlsx")
print(aba["B11"].value)

A última linha mostra 70, o resultado de 7 × 10, guardado na célula B11.

2. Na planilha da mesada, a linha 5 tem os valores de março nas colunas B e C. Que fórmula você escreveria na célula D5 para calcular quanto sobrou? E para a média dos gastos de C2 até C5?

Ver resposta

aba["D5"] = "=B5-C5"
aba["C6"] = "=AVERAGE(C2:C5)"
(Os nomes das funções vão em inglês: AVERAGE, e não MÉDIA.)

3. Escreva um programa que leia notas.xlsx (com as abas do exemplo) e mostre, de todas as abas, o aluno com a maior nota.

Ver resposta 
from openpyxl import load_workbook

livro = load_workbook("notas.xlsx")
melhor = ("", "", 0)
for aba in livro.worksheets:
    for aluno, nota in aba.iter_rows(min_row=2, values_only=True):
        if nota > melhor[2]:
            melhor = (aluno, aba.title, nota)
print(f"Maior nota: {melhor[0]} em {melhor[1]} ({melhor[2]})")

Com os dados do exemplo, aparece Maior nota: Ana em Português (9). O 9.0 volta como 9 porque o Excel guarda números inteiros sem casas decimais. livro.worksheets é a lista das abas.

4. Sem openpyxl: transforme a lista [["Produto", "Preço"], ["Caderno", 12.5], ["Lápis", 1.75]] num texto CSV com ponto e vírgula, usando csv e io.StringIO.
