Aula 118 · Planilhas do Excel com openpyxl

Nesta aula você vai aprender

  • Criar uma planilha .xlsx com openpyxl
  • Escrever valores e fórmulas nas células
  • Ler uma planilha existente linha por linha
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

CSV ou Excel?

Um CSV (aula 106) é só texto: não tem cores, fórmulas nem várias abas. Quando você precisa de uma planilha de verdade do Excel (.xlsx), use a biblioteca openpyxl:

pip install openpyxl

Criando uma planilha

from openpyxl import Workbook
from openpyxl.styles import Font

livro = Workbook()
aba = livro.active
aba.title = "Mesada"

aba.append(["Mês", "Recebi", "Gastei"])
aba.append(["Janeiro", 100, 65])
aba.append(["Fevereiro", 100, 80])
aba.append(["Março", 120, 70])

aba["D1"] = "Sobrou"
for linha in range(2, 5):
    aba[f"D{linha}"] = f"=B{linha}-C{linha}"    # fórmula do Excel

for celula in aba[1]:
    celula.font = Font(bold=True)

livro.save("mesada.xlsx")
print("Planilha salva!")
  • Workbook() cria o arquivo; active é a primeira aba;
  • append escreve uma linha inteira; aba["D1"] acessa uma célula pelo endereço;
  • um texto que começa com = vira fórmula, calculada quando o Excel abre o arquivo.
Atenção: Feche a planilha no Excel antes de rodar o programa. Com o arquivo aberto, o Windows bloqueia a gravação e aparece PermissionError.

Lendo uma planilha

from openpyxl import load_workbook

livro = load_workbook("mesada.xlsx")
aba = livro["Mesada"]

total_gasto = 0
for mes, recebi, gastei, sobrou in aba.iter_rows(min_row=2, values_only=True):
    print(mes, "gastou", gastei)
    total_gasto += gastei
print("Total gasto:", total_gasto)

values_only=True entrega só os valores. Fórmulas vêm como texto ("=B2-C2"), a não ser que você abra com load_workbook(..., data_only=True) um arquivo que já foi salvo pelo Excel.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
aba.append(["Janeiro", 100, 65])

Exercícios

1. Crie uma planilha tabuada.xlsx com a tabuada do 7 (coluna A com o multiplicador, coluna B com o resultado).

Ver resposta 
from openpyxl import Workbook

livro = Workbook()
aba = livro.active
aba.append(["Multiplicador", "Resultado"])
for i in range(1, 11):
    aba.append([i, 7 * i])
livro.save("tabuada.xlsx")

2. Que erro aparece se a planilha estiver aberta no Excel enquanto o programa tenta salvar, e como resolver?

Ver resposta

PermissionError: o Windows bloqueia o arquivo aberto. Feche a planilha no
Excel (ou salve com outro nome) e rode o programa de novo.
