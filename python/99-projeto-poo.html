Módulo 4 · Programação orientada a objetos

Aula 99 · Projeto: banco simples com contas, clientes e exceções

Nesta aula você vai aprender

  • Planejar um programa orientado a objetos dividindo as responsabilidades entre classes
  • Criar exceções próprias para os erros do negócio
  • Usar classe abstrata, herança e polimorfismo nas contas
  • Proteger o saldo com @property e ligar clientes e contas por composição
  • Juntar tudo num programa com menu

O que vamos construir

Um banco de mentirinha, o Banco Digitar, que roda no terminal. Antes de programar, vale pensar em quem faz o quê — esse é o coração da orientação a objetos:

  • Conta: guarda o saldo e sabe depositar e sacar. Existem dois tipos: Conta corrente (tem limite de cheque especial) e Conta poupança (não pode ficar negativa, mas rende juros).
  • Cliente: tem nome, CPF e as suas contas.
  • Banco: cadastra clientes, abre contas, encontra contas pelo número e faz transferências.
  • Exceções: SaldoInsuficiente e ValorInvalido avisam quando uma operação não pode acontecer.

Vamos usar quase tudo do Módulo 4: classes (aula 70), @property (aula 73), encapsulamento (aula 74), composição (aula 75), herança (aula 76), classe abstrata (aula 78), polimorfismo (aula 79), exceções próprias (aula 80) e __str__ (aula 81).

Passo 1: as exceções do banco

Erros de negócio merecem nomes próprios. Assim, quem usa as contas pode tratar exatamente o erro que interessa. Uma classe base ErroBancario agrupa todos:

class ErroBancario(Exception):
    """Base para todos os erros do banco."""


class ValorInvalido(ErroBancario):
    pass


class SaldoInsuficiente(ErroBancario):
    def __init__(self, disponivel, pedido):
        super().__init__(
            f"Saldo insuficiente: disponível R$ {disponivel:.2f}, pedido R$ {pedido:.2f}."
        )
        self.disponivel = disponivel
        self.pedido = pedido


try:
    raise SaldoInsuficiente(50, 80)
except ErroBancario as erro:
    print(type(erro).__name__, "->", erro)
    print("Faltaram R$", erro.pedido - erro.disponivel)

SaldoInsuficiente -> Saldo insuficiente: disponível R$ 50.00, pedido R$ 80.00.
Faltaram R$ 30

Como SaldoInsuficiente herda de ErroBancario, um except ErroBancario pega os dois tipos de erro de uma vez.

Passo 2: a conta abstrata

Toda conta deposita do mesmo jeito, mas cada tipo decide quanto dá para sacar. Por isso Conta é abstrata: ela tem o método abstrato disponivel_para_saque, que cada filha é obrigada a escrever. O saldo fica em _saldo e só pode ser lido pela @property — ninguém de fora muda o saldo sem passar por depositar ou sacar:

from abc import ABC, abstractmethod


class ErroBancario(Exception):
    pass


class ValorInvalido(ErroBancario):
    pass


class SaldoInsuficiente(ErroBancario):
    pass


class Conta(ABC):
    def __init__(self, numero):
        self.numero = numero
        self._saldo = 0.0
        self.extrato = []

    @property
    def saldo(self):
        return self._saldo

    @abstractmethod
    def disponivel_para_saque(self):
        ...

    def depositar(self, valor):
        if valor <= 0:
            raise ValorInvalido("O valor precisa ser positivo.")
        self._saldo += valor
        self.extrato.append(f"Depósito  +{valor:8.2f}")

    def sacar(self, valor):
        if valor <= 0:
            raise ValorInvalido("O valor precisa ser positivo.")
        if valor > self.disponivel_para_saque():
            raise SaldoInsuficiente(f"Disponível: R$ {self.disponivel_para_saque():.2f}")
        self._saldo -= valor
        self.extrato.append(f"Saque     -{valor:8.2f}")


try:
    Conta(1)
except TypeError as erro:
    print("Não dá para criar uma Conta genérica:")
    print(erro)

Não dá para criar uma Conta genérica:
Can't instantiate abstract class Conta without an implementation for abstract method 'disponivel_para_saque'

O TypeError mostra que a classe abstrata cumpre seu papel: ela é um molde, não uma conta de verdade.

Atenção: Não esqueça de levantar o erro antes de mexer no saldo. Se você descontar primeiro e conferir depois, a conta fica com o saldo errado quando o saque falha.

Passo 3: conta corrente e poupança

Agora as filhas. Cada uma responde à mesma pergunta — "quanto posso sacar?" — do seu jeito. Isso é polimorfismo: o método sacar da classe mãe funciona para as duas sem saber qual é qual.

from abc import ABC, abstractmethod


class SaldoInsuficiente(Exception):
    pass


class Conta(ABC):
    def __init__(self, numero):
        self.numero = numero
        self._saldo = 0.0

    @property
    def saldo(self):
        return self._saldo

    @abstractmethod
    def disponivel_para_saque(self):
        ...

    def depositar(self, valor):
        self._saldo += valor

    def sacar(self, valor):
        if valor > self.disponivel_para_saque():
            raise SaldoInsuficiente(f"Disponível: R$ {self.disponivel_para_saque():.2f}")
        self._saldo -= valor


class ContaCorrente(Conta):
    def __init__(self, numero, limite=200.0):
        super().__init__(numero)
        self.limite = limite

    def disponivel_para_saque(self):
        return self._saldo + self.limite


class ContaPoupanca(Conta):
    def __init__(self, numero, taxa_mensal=0.005):
        super().__init__(numero)
        self.taxa_mensal = taxa_mensal

    def disponivel_para_saque(self):
        return self._saldo

    def render(self):
        self._saldo += self._saldo * self.taxa_mensal


corrente = ContaCorrente(1)
poupanca = ContaPoupanca(2)
for conta in (corrente, poupanca):
    conta.depositar(100)
    try:
        conta.sacar(150)
        print(type(conta).__name__, "sacou 150. Saldo:", conta.saldo)
    except SaldoInsuficiente as erro:
        print(type(conta).__name__, "não sacou:", erro)

poupanca.render()
print(f"Poupança depois de render: R$ {poupanca.saldo:.2f}")

ContaPoupanca não sacou: Disponível: R$ 100.00

Passo 4: clientes e o banco

O Cliente tem contas (composição/agregação, aula 75), e o Banco tem clientes. O banco também numera as contas e faz a transferência, que é um saque numa conta seguido de um depósito em outra:

class SaldoInsuficiente(Exception):
    pass


class Conta:
    def __init__(self, numero, titular):
        self.numero = numero
        self.titular = titular
        self._saldo = 0.0

    @property
    def saldo(self):
        return self._saldo

    def depositar(self, valor):
        self._saldo += valor

    def sacar(self, valor):
        if valor > self._saldo:
            raise SaldoInsuficiente(f"Disponível: R$ {self._saldo:.2f}")
        self._saldo -= valor

    def __str__(self):
        return f"Conta {self.numero} de {self.titular.nome}: R$ {self.saldo:.2f}"


class Cliente:
    def __init__(self, nome, cpf):
        self.nome = nome
        self.cpf = cpf
        self.contas = []


class Banco:
    def __init__(self, nome):
        self.nome = nome
        self.clientes = {}
        self.contas = {}
        self._proximo_numero = 1

    def cadastrar(self, nome, cpf):
        cliente = Cliente(nome, cpf)
        self.clientes[cpf] = cliente
        return cliente

    def abrir_conta(self, cliente):
        conta = Conta(self._proximo_numero, cliente)
        self._proximo_numero += 1
        cliente.contas.append(conta)
        self.contas[conta.numero] = conta
        return conta

    def transferir(self, origem, destino, valor):
        self.contas[origem].sacar(valor)
        self.contas[destino].depositar(valor)

conta_caio = banco.abrir_conta(caio)
conta_bia.depositar(300)

Repare na ordem dentro de transferir: primeiro o saque, que pode falhar. Se ele levantar SaldoInsuficiente, o depósito nem acontece e o dinheiro não "aparece do nada" na outra conta.

Dica: Os CPFs aqui são de brincadeira ("111", "222"). Na aula 31 você aprendeu a validar um CPF de verdade — um ótimo desafio é usar aquela função no cadastrar.

Passo 5: o programa completo

Juntando tudo e colocando um menu. O try/except ErroBancario do menu mostra a mensagem de qualquer erro do banco sem fechar o programa, e o except ValueError cuida de quem digita letras no lugar de números:

from abc import ABC, abstractmethod


class ErroBancario(Exception):
    """Base para os erros do banco."""


class ValorInvalido(ErroBancario):
    pass


class SaldoInsuficiente(ErroBancario):
    pass


class ContaNaoEncontrada(ErroBancario):
    pass


class Conta(ABC):
    def __init__(self, numero, titular):
        self.numero = numero
        self.titular = titular
        self._saldo = 0.0
        self.extrato = []

    @property
    def saldo(self):
        return self._saldo

    @abstractmethod
    def disponivel_para_saque(self):
        ...

    def depositar(self, valor):
        if valor <= 0:
            raise ValorInvalido("O valor precisa ser maior que zero.")
        self._saldo += valor
        self.extrato.append(f"Depósito    +{valor:9.2f}")

    def sacar(self, valor):
        if valor <= 0:
            raise ValorInvalido("O valor precisa ser maior que zero.")
        if valor > self.disponivel_para_saque():
            raise SaldoInsuficiente(
                f"Saldo insuficiente. Disponível: R$ {self.disponivel_para_saque():.2f}"
            )
        self._saldo -= valor
        self.extrato.append(f"Saque       -{valor:9.2f}")

    def __str__(self):
        return f"{self.numero} | {self.TIPO:<9} | {self.titular.nome:<12} | R$ {self.saldo:9.2f}"


class ContaCorrente(Conta):
    TIPO = "Corrente"

    def __init__(self, numero, titular, limite=200.0):
        super().__init__(numero, titular)
        self.limite = limite

    def disponivel_para_saque(self):
        return self._saldo + self.limite


class ContaPoupanca(Conta):
    TIPO = "Poupança"

    def disponivel_para_saque(self):
        return self._saldo


class Cliente:
    def __init__(self, nome, cpf):
        self.nome = nome
        self.cpf = cpf
        self.contas = []


class Banco:
    def __init__(self, nome):
        self.nome = nome
        self.clientes = {}
        self.contas = {}
        self._proximo = 1

    def cadastrar(self, nome, cpf):
        nome = nome.strip()
        if not nome or not cpf.strip():
            raise ErroBancario("Nome e CPF são obrigatórios.")
        if cpf in self.clientes:
            raise ErroBancario("Já existe um cliente com esse CPF.")
        cliente = Cliente(nome, cpf)
        self.clientes[cpf] = cliente
        return cliente

    def abrir_conta(self, cpf, tipo):
        cliente = self.clientes.get(cpf)
        if cliente is None:
            raise ErroBancario("Cliente não encontrado.")
        classe = ContaCorrente if tipo == "c" else ContaPoupanca
        conta = classe(self._proximo, cliente)
        self._proximo += 1
        cliente.contas.append(conta)
        self.contas[conta.numero] = conta
        return conta

    def conta(self, numero):
        if numero not in self.contas:
            raise ContaNaoEncontrada(f"A conta {numero} não existe.")
        return self.contas[numero]

    def transferir(self, origem, destino, valor):
        conta_origem = self.conta(origem)
        conta_destino = self.conta(destino)
        conta_origem.sacar(valor)
        conta_destino.depositar(valor)


def ler_numero(mensagem):
    return int(input(mensagem))


def ler_valor(mensagem):
    return float(input(mensagem).replace(",", "."))


def main():
    banco = Banco("Banco Digitar")
    print(f"=== {banco.nome} ===")
    while True:
        print()
        print("1 Cliente  2 Abrir conta  3 Depositar  4 Sacar")
        print("5 Transferir  6 Extrato  7 Listar contas  0 Sair")
        opcao = input("Opção: ").strip()
        try:
            if opcao == "1":
                cliente = banco.cadastrar(input("Nome: "), input("CPF: "))
                print(f"Cliente {cliente.nome} cadastrado.")
            elif opcao == "2":
                cpf = input("CPF do cliente: ")
                tipo = input("Corrente (c) ou poupança (p)? ").strip().lower()
                conta = banco.abrir_conta(cpf, tipo)
                print(f"Conta {conta.numero} aberta.")
            elif opcao == "3":
                conta = banco.conta(ler_numero("Número da conta: "))
                conta.depositar(ler_valor("Valor: R$ "))
                print(f"Novo saldo: R$ {conta.saldo:.2f}")
            elif opcao == "4":
                conta = banco.conta(ler_numero("Número da conta: "))
                conta.sacar(ler_valor("Valor: R$ "))
                print(f"Novo saldo: R$ {conta.saldo:.2f}")
            elif opcao == "5":
                origem = ler_numero("Conta de origem: ")
                destino = ler_numero("Conta de destino: ")
                banco.transferir(origem, destino, ler_valor("Valor: R$ "))
                print("Transferência feita.")
            elif opcao == "6":
                conta = banco.conta(ler_numero("Número da conta: "))
                for linha in conta.extrato:
                    print(" ", linha)
                print(f"  Saldo:       R$ {conta.saldo:.2f}")
            elif opcao == "7":
                for conta in banco.contas.values():
                    print(conta)
            elif opcao == "0":
                print("Obrigado por usar o Banco Digitar!")
                break
            else:
                print("Opção inválida.")
        except ErroBancario as erro:
            print("Erro:", erro)
        except ValueError:
            print("Erro: digite um número válido.")


if __name__ == "__main__":
    main()

    if valor > saldo:
        erro = SaldoInsuficiente(f"Faltam R$ {valor - saldo:.2f}")
        erro.add_note("Dica: consulte o extrato ou faça um depósito antes.")
        raise erro
    return saldo - valor


try:
    sacar(80.0, 100.0)
except SaldoInsuficiente as erro:
    print("Erro:", erro)
    for nota in erro.__notes__:
        print(nota)

Erro: Faltam R$ 20.00
Dica: consulte o extrato ou faça um depósito antes.

As notas ficam na lista __notes__ da exceção e aparecem também no traceback quando o erro não é tratado.
