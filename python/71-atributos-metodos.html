Atributos de instância

Tudo o que você guarda em self dentro dos métodos é um atributo de instância: cada objeto tem o seu. Foi o que você fez na aula 70.

class Aluno:
    def __init__(self, nome, serie):
        self.nome = nome
        self.serie = serie

ana = Aluno("Ana", "7º ano")
beto = Aluno("Beto", "8º ano")
print(ana.nome, "-", ana.serie)
print(beto.nome, "-", beto.serie)

Ana - 7º ano
Beto - 8º ano

Atributos de classe

Um atributo escrito direto na classe, fora dos métodos, é um atributo de classe: ele é compartilhado por todos os objetos. Serve para informações que valem para todo mundo daquele tipo.

class Aluno:
    escola = "Escola Estadual Monteiro Lobato"

    def __init__(self, nome):
        self.nome = nome

    def apresentar(self):
        print(f"Sou {self.nome}, da {self.escola}.")

Aluno("Ana").apresentar()
Aluno("Beto").apresentar()
print(Aluno.escola)

Sou Ana, da Escola Estadual Monteiro Lobato.
Sou Beto, da Escola Estadual Monteiro Lobato.
Escola Estadual Monteiro Lobato

Quando o Python procura self.escola, ele olha primeiro no objeto; como não acha, olha na classe.

Um contador compartilhado

Um uso clássico do atributo de classe é contar quantos objetos foram criados. Para mudar o valor, use o nome da classe, não o self.

class Senha:
    proxima = 1

    def __init__(self, nome):
        self.nome = nome
        self.numero = Senha.proxima
        Senha.proxima += 1

for pessoa in ["Dona Rosa", "Seu Jorge", "Bia"]:
    s = Senha(pessoa)
    print(f"{s.nome}: senha {s.numero:03d}")
print("Próxima senha:", Senha.proxima)

Dona Rosa: senha 001
Seu Jorge: senha 002
Bia: senha 003
Próxima senha: 4

Atenção: Se você escrever self.proxima += 1, o Python cria um atributo novo no objeto com esse nome e o da classe fica igual. O contador não anda! Para mudar o atributo de classe, escreva NomeDaClasse.atributo.

A armadilha da lista na classe

Cuidado com listas e dicionários como atributo de classe: como são compartilhados, mexer na lista de um objeto mexe na de todos.

class Mochila:
    itens = []  # ERRADO: uma única lista para todas as mochilas

    def __init__(self, dono):
        self.dono = dono

    def guardar(self, coisa):
        self.itens.append(coisa)

m1 = Mochila("Caio")
m2 = Mochila("Duda")
m1.guardar("caderno")
print(m2.dono, "tem:", m2.itens)

Duda tem: ['caderno']

A Duda nunca guardou nada, mas a mochila dela "tem" o caderno do Caio. O certo é criar a lista dentro do __init__:

class Mochila:
    def __init__(self, dono):
        self.dono = dono
        self.itens = []  # uma lista nova para cada mochila

    def guardar(self, coisa):
        self.itens.append(coisa)

m1 = Mochila("Caio")
m2 = Mochila("Duda")
m1.guardar("caderno")
print(m1.dono, "tem:", m1.itens)
print(m2.dono, "tem:", m2.itens)

Caio tem: ['caderno']
Duda tem: []

Espiando o objeto: __dict__ e vars

Todo objeto guarda seus atributos de instância num dicionário chamado __dict__. A função vars(objeto) devolve esse mesmo dicionário. É ótimo para depurar.

class Filme:
    genero = "animação"

    def __init__(self, titulo, ano):
        self.titulo = titulo
        self.ano = ano

f = Filme("O Menino e o Mundo", 2013)
print(f.__dict__)
print(vars(f))
f.nota = 9.5
print(vars(f))
print("genero" in vars(f), f.genero)

{'titulo': 'O Menino e o Mundo', 'ano': 2013}
{'titulo': 'O Menino e o Mundo', 'ano': 2013}
{'titulo': 'O Menino e o Mundo', 'ano': 2013, 'nota': 9.5}
False animação

Repare que genero não aparece no vars(f): ele é da classe, não do objeto. Mas f.genero funciona, porque o Python procura na classe.

Dica: vars também ajuda a criar objetos a partir de dicionários e a salvar objetos em JSON (aula 62): json.dumps(vars(f)) vira texto rapidinho.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
print(vars(aluno))

Ver resposta

    rodas = 4

    def __init__(self, marca, cor):
        self.marca = marca
        self.cor = cor

for c in [Carro("Fiat", "vermelho"), Carro("VW", "prata")]:

Fiat vermelho 4
VW prata 4

2. Crie a classe Jogador que conta, num atributo de classe total, quantos jogadores foram criados. Crie três e mostre o total.

Ver resposta 
class Jogador:
    total = 0

    def __init__(self, nome):
        self.nome = nome
        Jogador.total += 1

for nome in ["Marta", "Formiga", "Cristiane"]:
    Jogador(nome)

Jogadores: 3

3. O código abaixo deveria guardar as notas de cada aluno separadamente, mas todos ficam com as mesmas notas. Corrija: class Boletim: com notas = [] na classe e def adicionar(self, n): self.notas.append(n).

Ver resposta 
class Boletim:
    def __init__(self):
        self.notas = []

    def adicionar(self, n):
        self.notas.append(n)

a = Boletim()
b = Boletim()
a.adicionar(8)
print(a.notas, b.notas)

[8] []

A lista precisa ser criada no __init__, para que cada boletim tenha a sua.

5. Sem rodar, diga o que aparece. A classe Placa tem pais = "Brasil". Fazemos p = Placa(), depois p.pais = "Argentina" e mostramos p.pais e Placa.pais. Depois rode para conferir.

Ver resposta 
class Placa:
    pais = "Brasil"

p = Placa()
p.pais = "Argentina"
print(p.pais)
print(Placa.pais)

Argentina
Brasil

p.pais = ... cria um atributo novo no objeto, que esconde o da classe só para ele. A classe continua com "Brasil".
