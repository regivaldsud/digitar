Documentação mora dentro do código

Na aula 04 você conheceu as docstrings: o texto entre três aspas logo na primeira linha de uma função. Elas também valem para classes e métodos. Assim, quem usa a sua classe descobre como ela funciona sem precisar ler o código inteiro.

class Cofrinho:
    """Guarda moedas e informa o total economizado."""

    def __init__(self):
        """Cria um cofrinho vazio."""
        self.total = 0.0

    def depositar(self, valor):
        """Soma o valor ao total e devolve o novo total."""
        self.total += valor
        return self.total

print(Cofrinho.__doc__)
print(Cofrinho.depositar.__doc__)

Guarda moedas e informa o total economizado.
Soma o valor ao total e devolve o novo total.

help(): o manual completo

A função help() junta todas as docstrings da classe num manual organizado, com os métodos e o que cada um faz:

class Termometro:
    """Converte temperaturas entre Celsius e Fahrenheit."""

    def para_fahrenheit(self, celsius):
        """Converte graus Celsius para Fahrenheit."""
        return celsius * 9 / 5 + 32

help(Termometro.para_fahrenheit)

Help on function para_fahrenheit in module __main__:
 
para_fahrenheit(self, celsius)
    Converte graus Celsius para Fahrenheit.

Experimente também help(Termometro) e help(str.upper): funciona com as suas classes e com as do Python.

Dica: No VS Code, passe o mouse sobre o nome de uma classe ou método para ver a docstring. Bem documentado, o seu código "conversa" com o editor.

Docstrings de várias linhas em classes

Para classes maiores, use a mesma convenção das funções: uma linha de resumo, uma linha em branco e os detalhes. Na classe, é comum listar os atributos:

class Aluno:
    """Representa um aluno de uma turma.

    Atributos:
        nome: o nome completo do aluno.
        notas: lista com as notas das provas (0 a 10).
    """

    def __init__(self, nome):
        self.nome = nome
        self.notas = []

    def media(self):
        """Devolve a média das notas, ou 0 se não houver notas."""
        if not self.notas:
            return 0
        return sum(self.notas) / len(self.notas)

resumo = Aluno.__doc__.splitlines()[0]
print(resumo)

Representa um aluno de uma turma.

O módulo inspect tem a função getdoc, que tira o recuo das linhas e deixa a docstring limpa para mostrar:

import inspect

class Pedido:
    """Pedido de uma lanchonete.

    Guarda os itens e calcula o total com a taxa de entrega.
    """

print(inspect.getdoc(Pedido))

Pedido de uma lanchonete.
 
Guarda os itens e calcula o total com a taxa de entrega.

dir(): o que tem dentro?

A função dir() lista os nomes de tudo o que um objeto tem: atributos e métodos. Ela mostra também muitos nomes especiais, que começam com dois sublinhados. Para ver só os "normais", filtre:

class Celular:
    def __init__(self):
        self.bateria = 100

    def ligar(self):
        pass

    def tirar_foto(self):
        pass

meu = Celular()
nomes = [n for n in dir(meu) if not n.startswith("_")]
print(nomes)

['bateria', 'ligar', 'tirar_foto']

dir é ótimo para explorar algo que você não conhece. Por exemplo, quais métodos de texto existem que começam com is?

print([n for n in dir(str) if n.startswith("is")])

['isalnum', 'isalpha', 'isascii', 'isdecimal', 'isdigit', 'isidentifier', 'islower', 'isnumeric', 'isprintable', 'isspace', 'istitle', 'isupper']

Atenção: A docstring precisa ser a primeira linha dentro da classe ou do método. Se vier depois de um atributo ou de outra linha, ela vira um texto solto e __doc__ fica None.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
"""Representa um aluno de uma turma."""

4. Escreva uma função resumo(objeto) que devolve só a primeira linha da docstring de qualquer objeto, ou "(sem documentação)" se ele não tiver docstring. Teste com uma classe documentada e outra sem docstring.

Ver resposta 
def resumo(objeto):
    doc = objeto.__doc__
    if not doc:
        return "(sem documentação)"
    return doc.strip().splitlines()[0]

class Bicicleta:
    """Bicicleta com marchas.

    Tem 21 marchas e freio a disco.
    """

class Patinete:
    pass

print(resumo(Bicicleta))
print(resumo(Patinete))

Bicicleta com marchas.
(sem documentação)
