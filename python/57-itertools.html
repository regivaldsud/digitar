Uma fábrica de iteradores

O módulo itertools traz ferramentas para criar e combinar sequências. Elas devolvem iteradores "preguiçosos" (como os geradores da aula 52): os valores são produzidos um de cada vez, só quando alguém pede. Por isso usamos list() para ver tudo de uma vez.

from itertools import chain

manha = ["matemática", "português"]
tarde = ["educação física", "digitação"]

print(list(chain(manha, tarde)))

['matemática', 'português', 'educação física', 'digitação']

O chain emenda várias sequências como se fossem uma só, sem criar listas novas no meio do caminho.

count: contando sem parar

count(inicio, passo) conta para sempre. Como ele nunca termina, use-o com um break ou com islice, que pega só um pedaço:

from itertools import count, islice

for senha in count(101):
    print("Senha", senha)
    if senha == 104:
        break

print(list(islice(count(0, 5), 6)))

Senha 101
Senha 102
Senha 103
Senha 104
[0, 5, 10, 15, 20, 25]

Atenção: Nunca faça list(count()): como a contagem não acaba, o programa fica preso para sempre tentando montar uma lista infinita.

combinations e permutations

combinations(itens, k) dá todos os grupos de k itens, sem se importar com a ordem. permutations(itens, k) dá todas as filas, em que a ordem importa.

from itertools import combinations, permutations

amigos = ["Ana", "Bia", "Caio"]

print("Duplas para o trabalho:")
for dupla in combinations(amigos, 2):
    print(dupla)

print("Pódio (1º e 2º lugar):")
for podio in permutations(amigos, 2):
    print(podio)

Duplas para o trabalho:
('Ana', 'Bia')
('Ana', 'Caio')
('Bia', 'Caio')
Pódio (1º e 2º lugar):
('Ana', 'Bia')
('Ana', 'Caio')
('Bia', 'Ana')
('Bia', 'Caio')
('Caio', 'Ana')
('Caio', 'Bia')

Repare: na dupla, ("Ana", "Bia") é o mesmo que ("Bia", "Ana"), então aparece uma vez só. No pódio, Ana em primeiro e Bia em segundo é diferente de Bia em primeiro e Ana em segundo.

Dica: Para saber só quantas combinações existem, sem gerar todas, use math.comb(n, k) e math.perm(n, k). Por exemplo, math.comb(60, 6) dá o número de jogos possíveis da Mega-Sena: 50.063.860.

product: todas as misturas

product combina cada item de uma lista com cada item de outra — como montar todas as opções de um cardápio:

from itertools import product

sabores = ["calabresa", "frango"]
bordas = ["catupiry", "cheddar", "sem borda"]

for sabor, borda in product(sabores, bordas):
    print(f"Pizza de {sabor}, borda {borda}")

Pizza de calabresa, borda catupiry
Pizza de calabresa, borda cheddar
Pizza de calabresa, borda sem borda
Pizza de frango, borda catupiry
Pizza de frango, borda cheddar
Pizza de frango, borda sem borda

Com repeat, a mesma lista é combinada com ela mesma. Todas as senhas de 2 dígitos com 0 e 1:

from itertools import product

for digitos in product("01", repeat=2):
    print("".join(digitos))

00
01
10
11

groupby: agrupando vizinhos

groupby(itens, key) junta itens seguidos que têm a mesma chave. Por isso, quase sempre ordenamos antes pela mesma chave:

from itertools import groupby

alunos = [
    ("Ana", "7º A"), ("Leo", "7º B"), ("Bia", "7º A"),
    ("Caio", "7º B"), ("Davi", "7º A"),
]

def turma(aluno):
    return aluno[1]

alunos.sort(key=turma)
for nome_turma, grupo in groupby(alunos, key=turma):
    nomes = [nome for nome, _ in grupo]
    print(nome_turma, nomes)

7º A ['Ana', 'Bia', 'Davi']
7º B ['Leo', 'Caio']

Atenção: Sem o sort antes, o groupby cria um grupo novo cada vez que a chave muda, e a mesma turma aparece repetida várias vezes.

E o accumulate vai somando (ou aplicando outra conta) passo a passo — ótimo para saldos e placares:

from itertools import accumulate

gols_por_rodada = [2, 0, 3, 1]
print(list(accumulate(gols_por_rodada)))

[2, 2, 5, 6]

Exercícios

1. Quatro times vão jogar um torneio em que todos se enfrentam uma vez: ["Bahia", "Vitória", "Sport", "Náutico"]. Mostre todos os jogos.

Ver resposta 
from itertools import combinations

times = ["Bahia", "Vitória", "Sport", "Náutico"]
for a, b in combinations(times, 2):
    print(f"{a} x {b}")

Bahia x Vitória
Bahia x Sport
Bahia x Náutico
Vitória x Sport
Vitória x Náutico
Sport x Náutico

2. Mostre todas as ordens possíveis para três pessoas na fila do caixa: ["mãe", "pai", "eu"]. Quantas são?

Ver resposta 
from itertools import permutations

filas = list(permutations(["mãe", "pai", "eu"]))
for fila in filas:
    print(" -> ".join(fila))
print(len(filas), "ordens")

mãe -> pai -> eu
mãe -> eu -> pai
pai -> mãe -> eu
pai -> eu -> mãe
eu -> mãe -> pai
eu -> pai -> mãe
6 ordens

3. Uma loja vende camisetas nas cores azul e branca e nos tamanhos P, M e G. Use product para listar todas as opções no formato azul-P.

Ver resposta 
from itertools import product

for cor, tamanho in product(["azul", "branca"], ["P", "M", "G"]):
    print(f"{cor}-{tamanho}")

azul-P
azul-M
azul-G
branca-P
branca-M
branca-G

4. Agrupe as palavras ["banana", "abacaxi", "caju", "amora", "cacau", "bacuri"] pela primeira letra, mostrando cada letra com a sua lista.

Ver resposta 
from itertools import groupby

frutas = sorted(["banana", "abacaxi", "caju", "amora", "cacau", "bacuri"])
for letra, grupo in groupby(frutas, key=lambda f: f[0]):
    print(letra, list(grupo))

a ['abacaxi', 'amora']
b ['bacuri', 'banana']
c ['cacau', 'caju']

5. Use count para mostrar os 5 primeiros múltiplos de 7 (começando em 7) e accumulate para mostrar o saldo após os depósitos [50, 20, -30, 10].

Ver resposta 
from itertools import accumulate, count, islice

print(list(islice(count(7, 7), 5)))
print(list(accumulate([50, 20, -30, 10])))

[7, 14, 21, 28, 35]
[50, 70, 40, 50]
