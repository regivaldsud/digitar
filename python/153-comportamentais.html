Strategy: trocar a estratégia

No Python, funções são valores (aula 45), então a Strategy fica bem simples: passe a função que faz o cálculo.

def sem_desconto(valor):
    return valor


def black_friday(valor):
    return valor * 0.7


def cupom_10(valor):
    return valor - 10


def fechar_compra(valor, estrategia):
    return round(estrategia(valor), 2)


for estrategia in [sem_desconto, black_friday, cupom_10]:
    print(estrategia.__name__, fechar_compra(200, estrategia))

sem_desconto 200
black_friday 140.0
cupom_10 190

Observer: avisar quem se inscreveu

Um canal de vídeos avisa todos os inscritos quando publica algo novo:

class Canal:
    def __init__(self, nome):
        self.nome = nome
        self.inscritos = []

    def inscrever(self, funcao):
        self.inscritos.append(funcao)

    def publicar(self, video):
        for avisar in self.inscritos:
            avisar(self.nome, video)


def avisar_bia(canal, video):
    print(f"Bia: novo vídeo em {canal}: {video}")


def avisar_leo(canal, video):
    print(f"Leo: {canal} postou {video}!")


canal = Canal("Ciência Fácil")
canal.inscrever(avisar_bia)
canal.inscrever(avisar_leo)
canal.publicar("Por que o céu é azul?")

Bia: novo vídeo em Ciência Fácil: Por que o céu é azul?
Leo: Ciência Fácil postou Por que o céu é azul?!

Command e Memento: desfazer

O Command transforma uma ação em objeto, que pode ser guardado numa lista e desfeito depois. O Memento guarda uma "foto" do estado para voltar a ela. Um editor bem simples com Ctrl+Z:

class Editor:
    def __init__(self):
        self.texto = ""
        self.historico = []

    def escrever(self, trecho):
        self.historico.append(self.texto)
        self.texto += trecho

    def desfazer(self):
        if self.historico:
            self.texto = self.historico.pop()


ed = Editor()
ed.escrever("Olá")
ed.escrever(", mundo")
ed.escrever("!!!")
print(ed.texto)
ed.desfazer()
print(ed.texto)
ed.desfazer()
print(ed.texto)

Olá, mundo!!!
Olá, mundo
Olá

Os outros, em uma frase

  • State: o objeto muda de comportamento conforme o estado (semáforo verde, amarelo, vermelho).
  • Template Method: a classe-mãe define os passos; as filhas preenchem alguns deles.
  • Iterator: percorre uma coleção sem mostrar como ela é guardada por dentro (aula 52 e aula 90).
  • Chain of Responsibility: um pedido passa por uma corrente de "atendentes" até alguém resolver.
  • Mediator: um objeto central coordena a conversa entre os outros, como a torre de controle de um aeroporto.
  • Visitor: acrescenta operações novas a uma estrutura de objetos sem mudar as classes deles.

Um exemplo de State com o semáforo:

proximo = {"verde": "amarelo", "amarelo": "vermelho", "vermelho": "verde"}
estado = "verde"
for _ in range(4):
    print(estado)
    estado = proximo[estado]

verde
amarelo
vermelho
verde

Atenção: No Observer, passe a função sem parênteses: inscrever(avisar_bia). Com parênteses, você chamaria a função na hora e guardaria o resultado (None).
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
print(fechar_compra(200, black_friday))

1. Crie uma estratégia frete_gratis_acima_100 que dá 15 reais de desconto quando o valor passa de 100 e use com fechar_compra(150, ...).

Ver resposta 
def frete_gratis_acima_100(valor):
    if valor > 100:
        return valor - 15
    return valor


def fechar_compra(valor, estrategia):
    return round(estrategia(valor), 2)


print(fechar_compra(150, frete_gratis_acima_100))
print(fechar_compra(80, frete_gratis_acima_100))
