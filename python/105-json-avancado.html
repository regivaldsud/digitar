Revisão rápida

Na aula 62 você salvou dados em arquivos com json.dump e json.load. Aqui vamos usar as versões com "s" no fim, dumps e loads, que trabalham com textos. É assim que programas trocam dados pela internet: a resposta de um site chega como texto JSON.

import json

pedido = {"cliente": "Bia", "itens": ["açaí", "granola"], "total": 22.5, "entregue": False}

texto = json.dumps(pedido, ensure_ascii=False)
print(texto)
print(type(texto))

de_volta = json.loads(texto)
print(de_volta["itens"][0])

{"cliente": "Bia", "itens": ["açaí", "granola"], "total": 22.5, "entregue": false}
<class 'str'>
açaí

Deixando o JSON do seu jeito

import json

placar = {"Vasco": 3, "Bahia": 1, "Athletico": 2}

print(json.dumps(placar, indent=2))
print(json.dumps(placar, sort_keys=True))
print(json.dumps(placar, separators=(",", ":")))

{
  "Vasco": 3,
  "Bahia": 1,
  "Athletico": 2
}
{"Athletico": 2, "Bahia": 1, "Vasco": 3}
{"Vasco":3,"Bahia":1,"Athletico":2}

  • indent=2 coloca um item por linha, com recuo — bom para pessoas lerem;
  • sort_keys=True ordena as chaves em ordem alfabética;
  • separators=(",", ":") tira os espaços e deixa o texto o menor possível — bom para enviar pela rede.

JSON quebrado: JSONDecodeError

Nem todo texto é JSON válido. Quando o texto está errado, loads dá json.JSONDecodeError, e a mensagem diz a linha e a coluna do problema:

import json

textos = ['{"nome": "Caio"}', "{'nome': 'Caio'}", '{"nome": "Caio",}']

for t in textos:
    try:
        print("OK:", json.loads(t))
    except json.JSONDecodeError as erro:
        print("Inválido:", erro)

OK: {'nome': 'Caio'}
Inválido: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)
Inválido: Expecting property name enclosed in double quotes: line 1 column 17 (char 16)

Atenção: Os dois erros mais comuns ao escrever JSON à mão: usar aspas simples (JSON só aceita aspas duplas) e deixar uma vírgula sobrando depois do último item.

Tipos que o JSON não conhece

O JSON só entende textos, números, true/false, null, listas e objetos. Uma data do Python dá erro:

import json
from datetime import date

print(json.dumps({"prova": date(2026, 11, 10)}))

TypeError: Object of type date is not JSON serializable

A solução é o parâmetro default: uma função que o dumps chama para cada valor que ele não sabe converter.

import json
from datetime import date

def converter(valor):
    if isinstance(valor, date):
        return valor.isoformat()
    raise TypeError(f"não sei converter {type(valor).__name__}")

agenda = {"prova": date(2026, 11, 10), "materias": {"história", "geografia"}}
agenda["materias"] = sorted(agenda["materias"])
print(json.dumps(agenda, default=converter, ensure_ascii=False))

{"prova": "2026-11-10", "materias": ["geografia", "história"]}

Ao carregar de volta, a data vem como texto. Use date.fromisoformat (aula 101) para transformá-la em data de novo.

TypedDict: descrevendo o formato

Quando um programa recebe muitos dicionários do mesmo formato, ajuda escrever esse formato em um só lugar. O TypedDict faz isso com type hints (que você estuda a fundo na aula 91):

import json
from typing import TypedDict

class Produto(TypedDict):
    nome: str
    preco: float
    estoque: int

def valor_em_estoque(p: Produto) -> float:
    return p["preco"] * p["estoque"]

texto = '[{"nome": "caderno", "preco": 18.9, "estoque": 10}, {"nome": "lápis", "preco": 1.5, "estoque": 40}]'
produtos: list[Produto] = json.loads(texto)

for p in produtos:
    print(f"{p['nome']}: R$ {valor_em_estoque(p):.2f}")

caderno: R$ 189.00
lápis: R$ 60.00

Na hora de rodar, um TypedDict é um dicionário comum: o Python não confere os tipos. Quem confere é o editor (o VS Code sublinha se você escrever p["prec"]) e ferramentas como o mypy. Mesmo assim, só de olhar a classe Produto qualquer pessoa entende o que o JSON deve ter.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
print(json.dumps(dados, indent=2, ensure_ascii=False))

Exercícios

1. Transforme {"cidade": "Belém", "temperatura": 31} em JSON com as chaves em ordem alfabética e sem trocar o acento.

Ver resposta 
import json

print(json.dumps({"cidade": "Belém", "temperatura": 31}, sort_keys=True, ensure_ascii=False))

{"cidade": "Belém", "temperatura": 31}

2. Escreva uma função ler_json(texto) que devolve os dados ou None se o texto for inválido. Teste com '[1, 2, 3]' e '[1, 2, 3'.

Ver resposta 
import json

def ler_json(texto):
    try:
        return json.loads(texto)
    except json.JSONDecodeError:
        return None

print(ler_json("[1, 2, 3]"))
print(ler_json("[1, 2, 3"))

[1, 2, 3]
None

3. Converta para JSON a lista de aniversários [{"nome": "Rui", "data": date(2013, 5, 2)}], transformando a data em texto no formato dd/mm/aaaa.

Ver resposta 
import json
from datetime import date

def converter(valor):
    if isinstance(valor, date):
        return valor.strftime("%d/%m/%Y")
    raise TypeError("tipo desconhecido")

aniversarios = [{"nome": "Rui", "data": date(2013, 5, 2)}]
print(json.dumps(aniversarios, default=converter))

[{"nome": "Rui", "data": "02/05/2013"}]

4. Crie um TypedDict chamado Aluno com nome (str) e notas (list[float]) e uma função que recebe um Aluno e devolve a média. Teste com dados lidos de um texto JSON.

Ver resposta 
import json
from typing import TypedDict

class Aluno(TypedDict):
    nome: str
    notas: list[float]

def media(aluno: Aluno) -> float:
    return sum(aluno["notas"]) / len(aluno["notas"])

aluno: Aluno = json.loads('{"nome": "Lia", "notas": [7.5, 9.0, 8.0]}')
print(aluno["nome"], round(media(aluno), 2))

Lia 8.17
