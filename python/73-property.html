Getters e setters, do jeito Python

Em muitas linguagens, para ler e mudar um dado do objeto você escreve métodos como get_preco() e set_preco(valor). Em Python isso é raro: usamos atributos simples e, quando precisamos de controle, trocamos por um property, sem que quem usa a classe perceba a diferença.

Atributos calculados

O @property transforma um método em algo que você usa como atributo, sem parênteses. É ótimo para valores que dependem de outros.

class Retangulo:
    def __init__(self, largura, altura):
        self.largura = largura
        self.altura = altura

    @property
    def area(self):
        return self.largura * self.altura

r = Retangulo(4, 3)
print(r.area)
r.largura = 10
print(r.area)

12
30

A área é recalculada toda vez que você lê r.area, então nunca fica desatualizada.

class Aluno:
    def __init__(self, nome, notas):
        self.nome = nome
        self.notas = notas

    @property
    def media(self):
        return sum(self.notas) / len(self.notas)

    @property
    def situacao(self):
        return "aprovado" if self.media >= 6 else "recuperação"

a = Aluno("Iago", [7, 5, 8.5])
print(f"{a.nome}: média {a.media:.1f}, {a.situacao}")
a.notas.append(3)
print(f"{a.nome}: média {a.media:.1f}, {a.situacao}")

Iago: média 6.8, aprovado
Iago: média 5.9, recuperação

Somente leitura

Um property sem setter não pode receber valor: é somente leitura.

class Circulo:
    def __init__(self, raio):
        self.raio = raio

    @property
    def diametro(self):
        return self.raio * 2

c = Circulo(5)
print(c.diametro)
c.diametro = 20

10
AttributeError: property 'diametro' of 'Circulo' object has no setter

Setter: validando antes de guardar

Para permitir objeto.atributo = valor com validação, crie um setter com @nome.setter. O valor de verdade fica guardado num atributo com sublinhado (_celsius).

class Termometro:
    def __init__(self, celsius):
        self.celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, valor):
        if valor < -273.15:
            raise ValueError("abaixo do zero absoluto")
        self._celsius = valor

    @property
    def fahrenheit(self):
        return self._celsius * 9 / 5 + 32

t = Termometro(25)
print(t.celsius, "°C =", t.fahrenheit, "°F")
t.celsius = 37
print(t.celsius, "°C =", t.fahrenheit, "°F")
try:
    t.celsius = -500
except ValueError as e:
    print("Recusado:", e)

25 °C = 77.0 °F
37 °C = 98.6 °F
Recusado: abaixo do zero absoluto

Por fora, quem usa a classe continua escrevendo t.celsius = 37. Por dentro, o valor passa pela validação — inclusive no __init__, porque self.celsius = celsius também chama o setter.

Atenção: Dentro do property, use o nome com sublinhado (self._celsius). Se você escrever return self.celsius dentro do próprio property celsius, ele chama a si mesmo sem parar e dá RecursionError.

Setter que ajusta em vez de recusar

Nem todo setter precisa dar erro. Ele pode corrigir o valor, como um volume que nunca passa de 0 a 10:

class Volume:
    def __init__(self):
        self.nivel = 5

    @property
    def nivel(self):
        return self._nivel

    @nivel.setter
    def nivel(self, valor):
        self._nivel = max(0, min(10, valor))

v = Volume()
for novo in [15, -3, 7]:
    v.nivel = novo
    print(f"pedido {novo} -> nível {v.nivel}")

pedido 15 -> nível 10
pedido -3 -> nível 0
pedido 7 -> nível 7

Dica: Comece sempre com atributos simples. Só troque por property quando precisar calcular ou validar — quem usa a classe não precisa mudar nada.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
def area(self): return self.largura * self.altura

Exercícios

1. Crie a classe Produto(nome, preco) em que preco é um property com setter que gera ValueError se o preço for negativo. Teste com um preço válido e outro inválido.

Ver resposta 
class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

    @property
    def preco(self):
        return self._preco

    @preco.setter
    def preco(self, valor):
        if valor < 0:
            raise ValueError("preço não pode ser negativo")
        self._preco = valor

p = Produto("Guaraná", 6.0)
print(p.nome, p.preco)
try:
    p.preco = -2
except ValueError as e:
    print("Erro:", e)

Guaraná 6.0
Erro: preço não pode ser negativo

2. Crie a classe Pessoa(nome, ano_nascimento) com um property idade (somente leitura) calculado para o ano de 2026.

Ver resposta 
class Pessoa:
    def __init__(self, nome, ano_nascimento):
        self.nome = nome
        self.ano_nascimento = ano_nascimento

    @property
    def idade(self):
        return 2026 - self.ano_nascimento

p = Pessoa("Kauã", 2013)
print(p.nome, "tem", p.idade, "anos")

Kauã tem 13 anos

3. Crie a classe Usuario com um property apelido cujo setter tira espaços das pontas, deixa tudo minúsculo e recusa apelido vazio com ValueError.

Ver resposta 
class Usuario:
    def __init__(self, apelido):
        self.apelido = apelido

    @property
    def apelido(self):
        return self._apelido

    @apelido.setter
    def apelido(self, valor):
        valor = valor.strip().lower()
        if not valor:
            raise ValueError("apelido vazio")
        self._apelido = valor

    u.apelido = "   "
except ValueError as e:
    print("Erro:", e)

4. Crie a classe Viagem(km, litros) com o property consumo (km por litro, arredondado com 1 casa). Mostre o consumo de 420 km com 35 litros.

Ver resposta 
class Viagem:
    def __init__(self, km, litros):
        self.km = km
        self.litros = litros

    @property
    def consumo(self):
        return round(self.km / self.litros, 1)

print(Viagem(420, 35).consumo, "km/l")

12.0 km/l

5. Por que o código abaixo dá RecursionError? @property def nome(self): return self.nome. Corrija.

Ver resposta 
class Cliente:
    def __init__(self, nome):
        self._nome = nome

    @property
    def nome(self):
        return self._nome

print(Cliente("Sueli").nome)

Sueli

self.nome dentro do property nome chama o próprio property de novo, para sempre. O valor deve ficar em outro nome, como self._nome.
