Aula 100 · if __name__ == "__main__"

Nesta aula você vai aprender

  • O que guarda a variável especial __name__
  • Por que código "solto" num módulo roda quando ele é importado
  • Como proteger o programa principal com if __name__ == "__main__":
  • Como organizar o arquivo com uma função main()

Todo módulo sabe o próprio nome

Na aula 54 você aprendeu a importar módulos e, na aula 55, a criar os seus. Agora vamos ver um detalhe que aparece em quase todo programa Python profissional.

Cada módulo carregado pelo Python tem uma variável chamada __name__ (dois sublinhados de cada lado) com o nome dele:

import math
import json
import random

print(math.__name__)
print(json.__name__)
print(random.__name__)

math
json
random

Até aqui, nada de mais: o módulo math se chama "math". A parte interessante é o que acontece com o arquivo que você manda rodar.

O arquivo que você roda se chama "__main__"

Quando você roda um arquivo diretamente (por exemplo, python frete.py), o Python não usa o nome do arquivo. Ele dá a esse arquivo o nome especial "__main__", que quer dizer "o programa principal".

print("Meu nome é:", __name__)

Meu nome é: __main__

Se outro arquivo fizer import quem_sou, a mesma linha mostraria Meu nome é: quem_sou. Ou seja: __name__ diz se o arquivo está sendo rodado ou importado.

O problema: código solto roda no import

Imagine um módulo de frete que também tem um teste rápido no final, solto no arquivo:

def frete(peso_kg):
    """Frete de uma loja: R$ 15 fixos mais R$ 2 por quilo."""
    return 15 + 2 * peso_kg

print("Teste: frete de 3 kg =", frete(3))

Agora outro programa só quer usar a função frete:

from frete import frete

print("Seu pedido de 5 kg paga R$", frete(5))

Teste: frete de 3 kg = 21
Seu pedido de 5 kg paga R$ 25

Repare que o "Teste" apareceu também! Ao importar, o Python executa o arquivo frete.py inteiro, de cima a baixo — inclusive o print solto.

A solução: if __name__ == "__main__"

Basta colocar o código de teste dentro de um if que só é verdadeiro quando o arquivo é o programa principal:

def frete(peso_kg):
    """Frete de uma loja: R$ 15 fixos mais R$ 2 por quilo."""
    return 15 + 2 * peso_kg

if __name__ == "__main__":
    print("Teste: frete de 3 kg =", frete(3))
from frete import frete

print("Seu pedido de 5 kg paga R$", frete(5))

Seu pedido de 5 kg paga R$ 25

Agora o import fica silencioso. E quem rodar python frete.py diretamente continua vendo o teste.

Atenção: São dois sublinhados de cada lado em __name__ e em "__main__", e "__main__" vai entre aspas porque é um texto. Escrever _name_ dá NameError; escrever "_main_" não dá erro nenhum — o if simplesmente nunca é verdadeiro e o programa "não faz nada".

O padrão com main()

O costume é juntar todo o programa principal numa função main() e chamá-la dentro do if. Assim o arquivo fica organizado: primeiro as ferramentas, no fim o "botão de ligar".

def converter_para_dolar(reais, cotacao):
    return reais / cotacao

def main():
    mesada = 80
    cotacao = 5.0
    print(f"R$ {mesada} valem US$ {converter_para_dolar(mesada, cotacao):.2f}")

main()

R$ 80 valem US$ 16.00

Aqui no navegador chamamos main() direto. No seu computador, a última linha fica assim:

if __name__ == "__main__":
    main()
Dica: No VS Code, digite main e escolha a sugestão "if __name__ == '__main__'" (com a extensão Python instalada) para o editor escrever o bloco para você.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
if __name__ == "__main__":

Exercícios

1. Mostre o valor de __name__ dos módulos datetime e string.

Ver resposta 
import datetime
import string

print(datetime.__name__)
print(string.__name__)

datetime
string

2. O arquivo piadas.py tem uma função piada() e, no fim, a linha solta print(piada()). Quando outro programa faz import piadas, a piada aparece sozinha. Como consertar?

Ver resposta 
def piada():
    return "Por que o livro de matemática ficou triste? Porque tinha muitos problemas."

if __name__ == "__main__":
    print(piada())

Coloque a linha print(piada()) dentro do if __name__ == "__main__":. Assim ela só roda com python piadas.py.

3. Escreva um programa com uma função area_retangulo(base, altura) e uma função main() que mostra a área de um quarto de 3 por 4 metros. Termine com o bloco if __name__ == "__main__":.

Ver resposta 
def area_retangulo(base, altura):
    return base * altura

def main():
    print("Área do quarto:", area_retangulo(3, 4), "m²")

if __name__ == "__main__":
    main()

Área do quarto: 12 m²

4. Um colega escreveu if __name__ == "_main_": e reclamou que o programa roda sem erro, mas não mostra nada. Explique o motivo.

Ver resposta

Com um sublinhado só, "_main_" é um texto diferente de "__main__".
A comparação dá False, o bloco do if nunca roda e, como não há erro
de sintaxe, o Python termina em silêncio. O certo é "__main__".
