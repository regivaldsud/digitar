Aula 46 · Dicionários: chaves, valores e métodos

Nesta aula você vai aprender

  • Criar dicionários com chaves e valores
  • Ler, adicionar, alterar e apagar itens

  • Usar update, pop e setdefault, e contar coisas com um dicionário

Chave e valor

Numa lista, você acha um item pela posição. Num dicionário, você acha pelo nome — a chave. É como uma agenda: você procura "Mãe" e encontra o telefone. Dicionários usam chaves {} e cada item é chave: valor:

aluno = {"nome": "Rafael", "idade": 14, "cidade": "Curitiba"}
print(aluno["nome"])
print(aluno["idade"])
print(aluno)

Rafael
14
{'nome': 'Rafael', 'idade': 14, 'cidade': 'Curitiba'}

As chaves geralmente são textos (também podem ser números ou tuplas), e os valores podem ser qualquer coisa: números, textos, listas e até outros dicionários.

Adicionar, alterar e apagar

Atribuir a uma chave nova adiciona; atribuir a uma chave que já existe altera. Para apagar, use del:

estoque = {"pão de queijo": 30, "coxinha": 12}
estoque["empada"] = 8
estoque["coxinha"] = 20
del estoque["pão de queijo"]
print(estoque)
print(len(estoque))

{'coxinha': 20, 'empada': 8}
2

Dica: Cada chave aparece uma vez só. Se você criar {"a": 1, "a": 2}, fica valendo o último valor: {"a": 2}.

Chaves que não existem: in e get

Ler uma chave que não existe dá KeyError. Para evitar, confira com in ou use get, que devolve None (ou o valor padrão que você escolher) em vez de dar erro:

precos = {"banana": 6.99, "maçã": 9.50}
print("uva" in precos)
print(precos.get("uva"))
print(precos.get("uva", 0))
print(precos.get("banana", 0))

False
None
0
6.99

Atenção: precos["uva"] com uma chave que não existe dá KeyError: 'uva'. Esse erro é muito comum — sempre que a chave puder faltar, prefira get ou teste com in.

Percorrendo um dicionário

keys() dá as chaves, values() dá os valores e items() dá os pares. Um for direto no dicionário percorre as chaves. Desde o Python 3.7, os dicionários mantêm a ordem em que os itens foram inseridos.

populacao = {"São Paulo": 11.4, "Rio de Janeiro": 6.2, "Brasília": 2.8}
for cidade in populacao:
    print(cidade)
print(round(sum(populacao.values()), 1))
for cidade, milhoes in populacao.items():
    print(f"{cidade}: {milhoes} milhões")

São Paulo
Rio de Janeiro
Brasília
20.4
São Paulo: 11.4 milhões
Rio de Janeiro: 6.2 milhões
Brasília: 2.8 milhões

Métodos úteis: update, pop e setdefault

  • update(outro) copia os itens de outro dicionário para este (alterando os que já existem);
  • pop(chave, padrao) tira a chave e devolve o valor dela;
  • setdefault(chave, valor) devolve o valor da chave e, se ela não existir, cria com o valor dado.
perfil = {"nome": "Duda", "nivel": 3}
perfil.update({"nivel": 4, "ppm": 38})
print(perfil)
ppm = perfil.pop("ppm")
print(ppm, perfil)
print(perfil.pop("medalhas", 0))

turmas = {}
turmas.setdefault("8A", []).append("Ana")
turmas.setdefault("8A", []).append("Caio")
turmas.setdefault("9B", []).append("Lia")
print(turmas)

{'nome': 'Duda', 'nivel': 4, 'ppm': 38}
38 {'nome': 'Duda', 'nivel': 4}
0
{'8A': ['Ana', 'Caio'], '9B': ['Lia']}

O setdefault é ótimo para montar um dicionário de listas, como as turmas acima.

Contando com dicionário

Um uso clássico: contar quantas vezes cada coisa aparece. Para cada item, somamos 1 ao valor atual, que começa em 0 graças ao get:

votos = ["pizza", "hambúrguer", "pizza", "açaí", "pizza", "açaí"]
contagem = {}
for voto in votos:
    contagem[voto] = contagem.get(voto, 0) + 1
print(contagem)

{'pizza': 3, 'hambúrguer': 1, 'açaí': 2}

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
contagem[voto] = contagem.get(voto, 0) + 1

Exercícios

1. Crie um dicionário com o nome, a série e a matéria favorita de um aluno e mostre a frase "Lívia está no 7º ano e gosta de Ciências".

Ver resposta 
aluno = {"nome": "Lívia", "serie": "7º ano", "materia": "Ciências"}
print(f"{aluno['nome']} está no {aluno['serie']} e gosta de {aluno['materia']}")

Lívia está no 7º ano e gosta de Ciências

Repare que, dentro da f-string com aspas duplas, usamos aspas simples na chave.

2. Num dicionário de preços {"café": 4.0, "pão": 0.75, "suco": 6.5}, aumente o café para 4.5, adicione "bolo" por 7.0 e mostre todos os itens no formato café: R$ 4.50.

Ver resposta 
precos = {"café": 4.0, "pão": 0.75, "suco": 6.5}
precos["café"] = 4.5
precos["bolo"] = 7.0
for item, preco in precos.items():
    print(f"{item}: R$ {preco:.2f}")

café: R$ 4.50
pão: R$ 0.75
suco: R$ 6.50
bolo: R$ 7.00

3. Use get para mostrar o DDD de uma cidade ou "desconhecido" se ela não estiver no dicionário {"São Paulo": 11, "Salvador": 71, "Manaus": 92}. Teste com "Salvador" e com "Natal".

Ver resposta 
ddd = {"São Paulo": 11, "Salvador": 71, "Manaus": 92}
print(ddd.get("Salvador", "desconhecido"))
print(ddd.get("Natal", "desconhecido"))

71
desconhecido

4. Conte quantas vezes cada letra aparece na palavra "paralelepipedo" usando um dicionário.

Ver resposta 
contagem = {}
for letra in "paralelepipedo":
    contagem[letra] = contagem.get(letra, 0) + 1
print(contagem)

{'p': 3, 'a': 2, 'r': 1, 'l': 2, 'e': 3, 'i': 1, 'd': 1, 'o': 1}

5. Agrupe as frutas ["abacaxi", "banana", "acerola", "caju", "bacuri"] pela letra inicial num dicionário de listas, usando setdefault.

Ver resposta 
frutas = ["abacaxi", "banana", "acerola", "caju", "bacuri"]
grupos = {}
for fruta in frutas:
    grupos.setdefault(fruta[0], []).append(fruta)
print(grupos)

{'a': ['abacaxi', 'acerola'], 'b': ['banana', 'bacuri'], 'c': ['caju']}
