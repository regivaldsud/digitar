Adapter: o "benjamim" do código

Sabe o adaptador de tomada de três pinos? O Adapter faz o mesmo com objetos: um termômetro antigo só fala em Fahrenheit, mas o seu programa espera Celsius.

class TermometroAmericano:
    def fahrenheit(self):
        return 86.0


class AdaptadorCelsius:
    def __init__(self, termometro):
        self.termometro = termometro

    def celsius(self):
        return (self.termometro.fahrenheit() - 32) * 5 / 9


t = AdaptadorCelsius(TermometroAmericano())
print(f"{t.celsius():.1f} °C")

30.0 °C

Composite: grupo que se comporta como item

Uma pasta pode ter arquivos e outras pastas. Com o Composite, pasta e arquivo têm o mesmo método tamanho, e a pasta soma os tamanhos dos filhos:

class Arquivo:
    def __init__(self, nome, kb):
        self.nome = nome
        self.kb = kb

    def tamanho(self):
        return self.kb


class Pasta:
    def __init__(self, nome):
        self.nome = nome
        self.itens = []

    def adicionar(self, item):
        self.itens.append(item)

    def tamanho(self):
        return sum(item.tamanho() for item in self.itens)


fotos = Pasta("fotos")
fotos.adicionar(Arquivo("praia.jpg", 300))
fotos.adicionar(Arquivo("festa.jpg", 450))
escola = Pasta("escola")
escola.adicionar(Arquivo("redacao.txt", 4))
escola.adicionar(fotos)
print(escola.tamanho(), "KB")

754 KB

Facade: um botão para tudo

A Facade (fachada) oferece um método simples que chama várias partes complicadas por trás:

class Estoque:
    def reservar(self, item):
        print(f"Estoque: {item} reservado")


class Pagamento:
    def cobrar(self, valor):
        print(f"Pagamento: R$ {valor:.2f} cobrado")


class Entrega:
    def agendar(self, cep):
        print(f"Entrega: agendada para o CEP {cep}")


class LojaFacade:
    def comprar(self, item, valor, cep):
        Estoque().reservar(item)
        Pagamento().cobrar(valor)
        Entrega().agendar(cep)


LojaFacade().comprar("tênis", 199.9, "01310-100")

Estoque: tênis reservado
Pagamento: R$ 199.90 cobrado
Entrega: agendada para o CEP 01310-100

Decorator, Proxy, Flyweight e Bridge

  • Decorator: embrulha um objeto para acrescentar comportamento sem mudar a classe. Os decoradores do Python (@, aula 56) seguem essa ideia com funções.
  • Proxy: um "representante" que fica no lugar do objeto real, por exemplo para só carregar uma imagem pesada quando ela for usada, ou para checar permissão.
  • Flyweight: compartilha partes iguais entre muitos objetos para economizar memória (as letras de um editor de texto, por exemplo).
  • Bridge: separa duas dimensões que variam, como "tipo de controle remoto" e "aparelho", para combinar qualquer um com qualquer outro.

Um Proxy simples que carrega o dado só na primeira vez:

class ImagemPesada:
    def __init__(self, nome):
        print("Carregando", nome, "...")
        self.nome = nome


class ProxyImagem:
    def __init__(self, nome):
        self.nome = nome
        self._real = None

    def mostrar(self):
        if self._real is None:
            self._real = ImagemPesada(self.nome)
        print("Mostrando", self.nome)


foto = ProxyImagem("mapa.png")
foto.mostrar()
foto.mostrar()

Carregando mapa.png ...
Mostrando mapa.png
Mostrando mapa.png

Dica: Não decore os nomes dos padrões. Entenda o problema que cada um resolve; o nome vem com o uso.

Exercícios

1. Crie um adaptador AdaptadorKm para um objeto GpsAmericano cujo método milhas() devolve 10. O adaptador deve ter o método km() (1 milha = 1,609 km).

Ver resposta 
class GpsAmericano:
    def milhas(self):
        return 10


class AdaptadorKm:
    def __init__(self, gps):
        self.gps = gps

    def km(self):
        return self.gps.milhas() * 1.609


print(f"{AdaptadorKm(GpsAmericano()).km():.2f} km")

16.09 km
