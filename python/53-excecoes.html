O que é uma exceção

Quando algo dá errado enquanto o programa roda — dividir por zero, converter "abc" em número, pedir uma chave que não existe —, o Python cria uma exceção. Se ninguém cuidar dela, o programa para e mostra a mensagem de erro (você aprendeu a ler essas mensagens na aula 06).

print("Começando a conta...")
print(10 / 0)
print("Esta linha nunca aparece.")

Começando a conta...
ZeroDivisionError: division by zero

As exceções que você mais vai encontrar:

  • ValueError: o tipo está certo, mas o valor não serve, como int("doze");
  • ZeroDivisionError: divisão por zero;
  • KeyError: chave que não existe num dicionário;
  • IndexError: posição que não existe numa lista;
  • TypeError: operação com tipos que não combinam, como "a" + 1;
  • FileNotFoundError: arquivo que não existe.
estoque = {"coxinha": 12, "pastel": 8}
print(estoque["coxinha"])
print(estoque["empada"])

12
KeyError: 'empada'

try e except

O try ("tente") roda um bloco de código. Se acontecer uma exceção lá dentro, o Python pula para o except em vez de parar o programa.

texto = "doze"

try:
    numero = int(texto)
    print("O dobro é", numero * 2)
except ValueError:
    print(f"'{texto}' não é um número inteiro.")

print("O programa continua normalmente.")

'doze' não é um número inteiro.
O programa continua normalmente.

Um mesmo try pode ter vários except, um para cada tipo de erro. Com as e, você guarda a exceção numa variável e pode mostrar a mensagem dela.

def dividir(a, b):
    try:
        resultado = int(a) / int(b)
        print(f"{a} / {b} = {resultado}")
    except ValueError:
        print("Digite apenas números.")
    except ZeroDivisionError as e:
        print("Não dá para dividir por zero:", e)

dividir("10", "4")
dividir("10", "0")
dividir("dez", "2")

10 / 4 = 2.5
Não dá para dividir por zero: division by zero
Digite apenas números.

Atenção: Evite except: sozinho ou except Exception: para tudo. Ele esconde erros que você precisava ver, como um nome de variável digitado errado. Pegue só os tipos de erro que você espera.
Atenção: Só o código dentro do try é protegido. Se o erro acontecer antes ou depois dele, o programa para do mesmo jeito.

else e finally

O try completo tem quatro partes, sempre nesta ordem:

  • try: o código que pode dar erro;
  • except: o que fazer se der erro;
  • else: o que fazer se não der erro;
  • finally: o que fazer sempre, no fim, com ou sem erro.
def sacar(saldo, valor):
    print(f"Tentando sacar R$ {valor}...")
    try:
        if valor > saldo:
            raise ValueError("saldo insuficiente")
        saldo -= valor
    except ValueError as e:
        print("Erro:", e)
    else:
        print("Saque feito! Novo saldo:", saldo)
    finally:
        print("Obrigado por usar o Banco do Bairro.")
    return saldo

sacar(100, 30)
sacar(100, 500)

Tentando sacar R$ 30...
Saque feito! Novo saldo: 70
Obrigado por usar o Banco do Bairro.
Tentando sacar R$ 500...
Erro: saldo insuficiente
Obrigado por usar o Banco do Bairro.

O else ajuda a deixar dentro do try só a linha arriscada. O finally serve para "arrumar a casa": mostrar uma mensagem final, fechar algo que foi aberto.

raise: gerando seus próprios erros

Às vezes é o seu código que precisa avisar que algo está errado. O raise cria uma exceção. Escolha o tipo que combina com o problema e escreva uma mensagem que ajude quem for corrigir.

def nota_valida(nota):
    if not 0 <= nota <= 10:
        raise ValueError(f"a nota deve estar entre 0 e 10, recebi {nota}")
    return nota

print(nota_valida(8.5))
try:
    nota_valida(12)
except ValueError as e:
    print("Problema:", e)

8.5
Problema: a nota deve estar entre 0 e 10, recebi 12

Sem o try, o programa pararia mostrando a sua mensagem:

def idade_valida(idade):
    if idade < 0:
        raise ValueError("a idade não pode ser negativa")
    return idade

idade_valida(-5)

ValueError: a idade não pode ser negativa

Atenção: Não use raise com um texto solto, como raise "erro". Isso causa TypeError. O certo é raise ValueError("erro"). Na aula 80 você aprende a criar tipos de exceção só seus.

Um input de números que não quebra

O uso mais comum de try é pedir um número até a pessoa digitar certo:

while True:
    try:
        idade = int(input("Qual é a sua idade? "))
    except ValueError:
        print("Ops! Digite a idade com algarismos, por exemplo 13.")
        continue
    if idade < 0:
        print("A idade não pode ser negativa.")
        continue
    break

print(f"Daqui a 5 anos você terá {idade + 5} anos.")

(exemplo digitando quinze, -3, 15)
Qual é a sua idade? quinze
Ops! Digite a idade com algarismos, por exemplo 13.
Qual é a sua idade? -3
A idade não pode ser negativa.
Qual é a sua idade? 15
Daqui a 5 anos você terá 20 anos.

Dica: O continue volta para o começo do while e pergunta de novo. O break só acontece quando a idade é válida.

2. Escreva uma função preco(produto) que procura o produto no dicionário {"açaí": 15.0, "tapioca": 9.5} e devolve o preço, ou None se o produto não existir (use try com KeyError).

Ver resposta 
cardapio = {"açaí": 15.0, "tapioca": 9.5}

def preco(produto):
    try:
        return cardapio[produto]
    except KeyError:
        return None

print(preco("açaí"))
print(preco("acarajé"))

15.0
None

Para dicionários, cardapio.get(produto) faz a mesma coisa sem try. Mas o try funciona para qualquer tipo de erro.

3. Sem rodar, diga o que aparece: um try mostra A, calcula 1 / 0 e mostra B; o except ZeroDivisionError mostra C, o else mostra D e o finally mostra E. Depois rode a resposta para conferir.

Ver resposta 
try:
    print("A")
    x = 1 / 0
    print("B")

    print("D")
finally:
    print("E")

Mostra A, C e E. O B não aparece porque o erro acontece antes dele, e o else não roda porque houve erro.

4. Faça a função cadastrar_senha(senha) que gera ValueError com a mensagem a senha precisa ter pelo menos 8 caracteres se a senha for curta, e devolve "Senha cadastrada" caso contrário. Teste com "abc" e "digitar2026".

Ver resposta 
def cadastrar_senha(senha):
    if len(senha) < 8:
        raise ValueError("a senha precisa ter pelo menos 8 caracteres")
    return "Senha cadastrada"

for s in ["abc", "digitar2026"]:
    try:
        print(cadastrar_senha(s))
    except ValueError as e:
        print("Erro:", e)

Senha cadastrada
