Módulo 7 · Expressões regulares

Aula 145 · Projeto: validar CPF, e-mail e telefone com regex

Nesta aula você vai aprender

  • Validar o formato de CPF, e-mail e telefone com re.fullmatch
  • Extrair os dígitos com grupos e re.sub
  • Combinar regex com o cálculo dos dígitos verificadores do CPF
  • Garantir que tudo funciona com testes do unittest

O plano

Num cadastro, o usuário digita do jeito que quer: 123.456.789-09, 12345678909, (81) 99876-5432, 81998765432... Vamos escrever três funções que aceitam essas variações e recusam o que está errado:

  • cpf_valido(texto): confere o formato e os dígitos verificadores.
  • email_valido(texto): confere o formato básico de um e-mail.
  • telefone_formatado(texto): valida um celular ou fixo e devolve no formato (81) 99876-5432, ou None se for inválido.

Os CPFs dos exemplos são números de teste que passam no cálculo; nunca use o CPF de uma pessoa real em exemplos.

Passo 1 — o formato do CPF

O CPF tem 11 dígitos, que podem vir com pontos e tracinho: ddd.ddd.ddd-dd. Os separadores são opcionais, por isso o ? depois de cada um:

import re

FORMATO_CPF = re.compile(r"\d{3}\.?\d{3}\.?\d{3}-?\d{2}")

for texto in ["123.456.789-09", "12345678909", "123.456.78909", "123.456.789-0", "abc.def.ghi-jk"]:
    print(f"{texto:>15}", bool(FORMATO_CPF.fullmatch(texto)))

 123.456.789-09 True
    12345678909 True
  123.456.78909 True
  123.456.789-0 False
 abc.def.ghi-jk False

Passo 2 — os dígitos verificadores

Os dois últimos dígitos do CPF são calculados a partir dos nove primeiros (você viu a conta na aula 31). Primeiro tiramos tudo o que não é dígito com re.sub(r"\D", "", texto), depois conferimos:

import re


def digito(numeros):
    peso = len(numeros) + 1
    soma = sum(int(n) * (peso - i) for i, n in enumerate(numeros))
    resto = soma * 10 % 11
    return "0" if resto == 10 else str(resto)


def cpf_valido(texto):
    if not re.fullmatch(r"\d{3}\.?\d{3}\.?\d{3}-?\d{2}", texto):
        return False
    numeros = re.sub(r"\D", "", texto)
    if numeros == numeros[0] * 11:
        return False
    d1 = digito(numeros[:9])
    d2 = digito(numeros[:9] + d1)
    return numeros[9:] == d1 + d2


print(cpf_valido("123.456.789-09"))
print(cpf_valido("123.456.789-10"))
print(cpf_valido("111.111.111-11"))
print(cpf_valido("12345678909"))

True
False
False
True

Atenção: 111.111.111-11 passa no cálculo, mas não é um CPF válido. Por isso a função recusa números com todos os dígitos iguais.

Passo 3 — e-mail

Validar e-mail com perfeição é complicadíssimo. Para um cadastro simples, basta conferir: algo antes do @, um domínio e pelo menos um ponto com algo depois:

import re

EMAIL = re.compile(r"[\w.+-]+@[\w-]+(\.[\w-]+)+")


def email_valido(texto):
    return EMAIL.fullmatch(texto) is not None


for email in ["bia@escola.com.br", "joao.p+jogos@mail.com", "sem-arroba.com", "ana@", "ana@site"]:
    print(f"{email:>22}", email_valido(email))

     bia@escola.com.br True
 joao.p+jogos@mail.com True
        sem-arroba.com False
                  ana@ False
              ana@site False

Dica: O jeito mais garantido de saber se um e-mail existe é mandar uma mensagem de confirmação. A regex só pega erros de digitação óbvios.

Passo 4 — telefone

O telefone brasileiro tem DDD de dois dígitos e o número com 8 dígitos (fixo) ou 9 (celular, começando com 9). Parênteses, espaço e tracinho são opcionais. Com grupos com nome, já devolvemos o número arrumado:

import re

TELEFONE = re.compile(r"""
    \(?(?P<ddd>\d{2})\)?   # DDD, com ou sem parênteses
    \s?                    # espaço opcional
    (?P<parte1>9?\d{4})    # 4 dígitos, ou 5 se começar com 9
    -?                     # tracinho opcional
    (?P<parte2>\d{4})      # últimos 4 dígitos
""", re.VERBOSE)


def telefone_formatado(texto):
    achado = TELEFONE.fullmatch(texto.strip())
    if not achado:
        return None
    return "({ddd}) {parte1}-{parte2}".format(**achado.groupdict())


for tel in ["(81) 99876-5432", "81998765432", "11 3456-7890", "998765432", "(81) 8876-54321"]:
    print(f"{tel:>16} -> {telefone_formatado(tel)}")

 (81) 99876-5432 -> (81) 99876-5432
     81998765432 -> (81) 99876-5432
    11 3456-7890 -> (11) 3456-7890
       998765432 -> None
 (81) 8876-54321 -> None

Passo 5 — testes para tudo

Agora juntamos as três funções e escrevemos testes com o unittest (aula 131). Se um dia alguém mexer numa regex, os testes avisam na hora:

import re
import unittest

FORMATO_CPF = re.compile(r"\d{3}\.?\d{3}\.?\d{3}-?\d{2}")
EMAIL = re.compile(r"[\w.+-]+@[\w-]+(\.[\w-]+)+")
TELEFONE = re.compile(r"\(?(?P<ddd>\d{2})\)?\s?(?P<parte1>9?\d{4})-?(?P<parte2>\d{4})")


def digito(numeros):
    peso = len(numeros) + 1
    soma = sum(int(n) * (peso - i) for i, n in enumerate(numeros))
    resto = soma * 10 % 11
    return "0" if resto == 10 else str(resto)


def cpf_valido(texto):
    if not FORMATO_CPF.fullmatch(texto):
        return False
    numeros = re.sub(r"\D", "", texto)
    if numeros == numeros[0] * 11:
        return False
    d1 = digito(numeros[:9])
    return numeros[9:] == d1 + digito(numeros[:9] + d1)


def email_valido(texto):
    return EMAIL.fullmatch(texto) is not None


def telefone_formatado(texto):
    achado = TELEFONE.fullmatch(texto.strip())
    if not achado:
        return None
    return "({ddd}) {parte1}-{parte2}".format(**achado.groupdict())


class TestValidadores(unittest.TestCase):
    def test_cpf(self):
        self.assertTrue(cpf_valido("123.456.789-09"))
        self.assertFalse(cpf_valido("123.456.789-00"))
        self.assertFalse(cpf_valido("000.000.000-00"))

    def test_email(self):
        self.assertTrue(email_valido("bia@escola.com.br"))
        self.assertFalse(email_valido("bia@escola"))

    def test_telefone(self):
        self.assertEqual(telefone_formatado("81998765432"), "(81) 99876-5432")
        self.assertIsNone(telefone_formatado("12345"))


unittest.main(argv=[""], exit=False)

Exercícios

1. Escreva cep_formatado(texto), que aceita "01310100" ou "01310-100" e devolve sempre "01310-100", ou None se não for um CEP.

Ver resposta 
import re


def cep_formatado(texto):
    achado = re.fullmatch(r"(\d{5})-?(\d{3})", texto.strip())
    if not achado:
        return None
    return f"{achado.group(1)}-{achado.group(2)}"


print(cep_formatado("01310100"))
print(cep_formatado("01310-100"))
print(cep_formatado("0131-0100"))

01310-100
01310-100
None

2. Use findall para listar todos os e-mails que aparecem no texto "Fale com ana@site.com ou com o suporte: ajuda@loja.com.br.".

Ver resposta 
import re

texto = "Fale com ana@site.com ou com o suporte: ajuda@loja.com.br."
print(re.findall(r"[\w.+-]+@[\w-]+(?:\.[\w-]+)+", texto))

['ana@site.com', 'ajuda@loja.com.br']

Repare no (?:...) da aula 142: com um grupo de captura comum, o findall devolveria só o final do domínio, e não o e-mail inteiro.

3. Escreva cpf_formatado(texto) que recebe 11 dígitos sem pontuação e devolve no formato 123.456.789-09, usando re.sub com grupos.

Ver resposta 
import re


def cpf_formatado(texto):
    return re.sub(r"(\d{3})(\d{3})(\d{3})(\d{2})", r"\1.\2.\3-\4", texto)


print(cpf_formatado("12345678909"))

123.456.789-09

4. A função telefone_formatado aceita "(81) 99876-5432". Ela aceita também um número com espaço no lugar do tracinho, como "81 99876 5432"? Teste e, se não aceitar, ajuste a regex.

Ver resposta 
import re

TELEFONE = re.compile(r"\(?(?P<ddd>\d{2})\)?\s?(?P<parte1>9?\d{4})[-\s]?(?P<parte2>\d{4})")


def telefone_formatado(texto):
    achado = TELEFONE.fullmatch(texto.strip())
    if not achado:
        return None
    return "({ddd}) {parte1}-{parte2}".format(**achado.groupdict())


print(telefone_formatado("81 99876 5432"))
print(telefone_formatado("(81) 99876-5432"))

(81) 99876-5432
(81) 99876-5432

A versão original não aceitava, porque entre as partes só podia haver -. Trocando -? por [-\s]?, o separador pode ser tracinho, espaço ou nada.
