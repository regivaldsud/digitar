Aula 01 · O que é Python e como este curso funciona

Programar é dar instruções

Um programa é uma lista de instruções que o computador segue à risca. Pense numa receita de bolo: "misture os ovos", "adicione a farinha", "asse por 40 minutos". Se a receita estiver clara, qualquer pessoa chega ao mesmo bolo.

O computador é esse cozinheiro: muito rápido, mas sem nenhuma imaginação. Ele faz exatamente o que está escrito, nem mais, nem menos.

Programar é escrever essas instruções numa linguagem que o computador entende. Você já sabe digitar; agora vai usar o teclado para conversar com a máquina.

O que é o Python

Python é uma linguagem de programação criada em 1991 pelo holandês Guido van Rossum. Ela é famosa por ser fácil de ler: muitas vezes o código parece quase uma frase em inglês. Por isso é uma das linguagens mais usadas no mundo para ensinar programação.

E não é só para iniciantes. Python é usado em:

  • sites e aplicativos (o Instagram usa Python no servidor);
  • ciência de dados e inteligência artificial;
  • automação de tarefas chatas, como renomear centenas de arquivos;
  • jogos, robótica e até no controle de telescópios.

Seu primeiro programa

Aperte o botão Executar no código abaixo. Ele está sendo rodado de verdade, aqui no seu navegador.

print("Olá, mundo!")

Olá, mundo!

print é uma função: um comando com nome que faz uma tarefa. A tarefa do print é mostrar na tela o que estiver entre os parênteses. O texto vai entre aspas para o Python saber que é um texto, e não um comando.

Uma instrução por linha, de cima para baixo

O Python lê o programa de cima para baixo e executa uma linha de cada vez. Veja:

print("Primeiro, acordo.")
print("Depois, tomo café com pão de queijo.")
print("Por fim, vou para a escola.")

Primeiro, acordo.
Depois, tomo café com pão de queijo.
Por fim, vou para a escola.

Troque a ordem das linhas e a ordem do que aparece na tela também muda. A ordem importa!

Sem aspas, o Python entende números e faz contas:

print(2 + 3)
print(10 * 4)
print("2 + 3")

5
40
2 + 3

Repare na diferença: 2 + 3 sem aspas é uma conta e dá 5; "2 + 3" com aspas é só um texto e aparece do jeito que foi escrito.

Atenção: O Python diferencia letras maiúsculas e minúsculas. print funciona, mas Print ou PRINT dão erro.

Como este curso funciona

Cada aula tem a mesma estrutura, para você saber sempre onde procurar:

  • Objetivos no topo: o que você vai aprender.
  • Exemplos de código com o botão Executar. Você pode mudar o código antes de executar — mexer é o melhor jeito de aprender.
  • Logo abaixo de cada exemplo, a saída esperada: o que deve aparecer na tela.
  • Caixas de Dica (atalhos e boas ideias) e de Atenção (erros comuns que vale evitar).
  • A caixa Pratique no DIGITAR: um trecho para digitar no modo *Programar* do app, treinando os símbolos que programadores mais usam.
  • Exercícios no final, com a resposta escondida em "Ver resposta". Tente sozinho antes de abrir!

Algumas aulas são marcadas como no computador: o assunto delas (instalar programas, usar o terminal, criar janelas) não roda no navegador, e a aula mostra o passo a passo para fazer no seu computador.

Estou pronto para aprender Python!

Exercícios

1. Faça um programa que mostre na tela o seu nome.

Ver resposta 
print("Ana Beatriz")

Ana Beatriz

Qualquer nome entre aspas serve. O importante é usar print com parênteses e aspas.

2. Faça um programa que mostre três linhas: o nome da sua cidade, o seu estado e o seu país.

Ver resposta 
print("Recife")
print("Pernambuco")
print("Brasil")

Recife
Pernambuco
Brasil

3. Use o Python para calcular quantas horas tem uma semana (7 dias de 24 horas).

Ver resposta 
print(7 * 24)

168

4. Qual é a diferença entre print(5 + 5) e print("5 + 5")? Rode os dois e explique.

Ver resposta 
print(5 + 5)
print("5 + 5")

10
5 + 5

Sem aspas o Python faz a conta e mostra 10. Com aspas, "5 + 5" é um texto e aparece exatamente como foi escrito.

5. Escreva um programa com três linhas que conte, na ordem certa, como você prepara um misto-quente.

Ver resposta 
print("Pego duas fatias de pão, queijo e presunto.")
print("Monto o sanduíche.")
print("Esquento na sanduicheira por 3 minutos.")

Pego duas fatias de pão, queijo e presunto.
Monto o sanduíche.
Esquento na sanduicheira por 3 minutos.

Se você trocar a ordem dos print, a receita fica fora de ordem: o computador obedece a ordem em que as linhas foram escritas.
