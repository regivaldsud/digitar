O que é HTML

Toda página da internet é um arquivo de texto escrito em HTML. Ele não é uma linguagem de programação: não tem if nem laços. É uma linguagem de marcação, que diz ao navegador o que é cada pedaço — isto é um título, isto é um parágrafo, isto é um link.

Cada pedaço fica entre tags: uma de abertura, como <p>, e uma de fechamento, como </p>. Tudo junto (abertura, conteúdo e fechamento) se chama elemento. Quem programa em Python precisa de HTML para fazer sites com Django (módulo 11), para raspar páginas (aula 112) e para gerar relatórios bonitos.

Algumas tags têm atributos, informações extras escritas na abertura: em <a href="https://python.org">, o atributo href diz para onde o link leva.

Uma página completa

Crie no VS Code um arquivo index.html com este conteúdo e abra-o com dois cliques (ele abre no navegador):

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Minha página</title>
</head>
<body>
  <h1>Olá, eu sou a Bia!</h1>
  <p>Estou aprendendo <strong>Python</strong> e <em>HTML</em>.</p>
  <h2>Minhas comidas favoritas</h2>
  <ul>
    <li>Coxinha</li>
    <li>Açaí</li>
    <li>Pão de queijo</li>
  </ul>
  <p>Treino digitação no <a href="https://example.com">DIGITAR</a>.</p>
  <img src="foto.jpg" alt="Minha foto na praia">
</body>
</html>
  • <!doctype html> avisa que é HTML5; <html lang="pt-BR"> diz o idioma (ajuda o tradutor e o leitor de tela).
  • <head> guarda informações sobre a página (como o título da aba); <body> guarda o que aparece na tela.
  • <h1> a <h6> são títulos, do maior ao menor; <p> é parágrafo; <strong> é destaque forte e <em>, ênfase (itálico).
  • <ul> é uma lista com marcadores e cada item é um <li>; <ol> faz uma lista numerada.
  • <a href="..."> é um link e <img src="..." alt="..."> é uma imagem. A <img> não tem tag de fechamento.
Atenção: Esquecer de fechar uma tag (escrever <p> e não pôr </p>) ou fechar na ordem errada bagunça a página. Feche sempre na ordem inversa da abertura: <p><strong>oi</strong></p>, e não <p><strong>oi</p></strong>.
Dica: <meta charset="utf-8"> faz os acentos e o ç aparecerem certos. Sem ele, "Açaí" pode virar letras estranhas.

Estrutura do HTML5 e tabelas

O HTML5 trouxe tags que dizem o papel de cada região: <header> (cabeçalho), <nav> (menu), <main> (conteúdo principal), <section> (uma seção), <footer> (rodapé). Visualmente elas não mudam nada, mas ajudam o Google e os leitores de tela a entender a página.

Tabelas usam <table>; cada linha é um <tr>, cada título de coluna um <th> e cada célula um <td>:

<main>
  <section>
    <h2>Notas do bimestre</h2>
    <table>
      <tr><th>Matéria</th><th>Nota</th></tr>
      <tr><td>Matemática</td><td>8,5</td></tr>
      <tr><td>Português</td><td>9,0</td></tr>
    </table>
  </section>
</main>
<footer>Feito pela Bia em 2026</footer>

Gerando HTML com Python

Como o HTML é só texto, o Python consegue escrever páginas sozinho. Basta montar o texto com f-strings e join:

comidas = ["Coxinha", "Açaí", "Pão de queijo"]
itens = "\n".join(f"  <li>{comida}</li>" for comida in comidas)

lista_html = f"<ul>\n{itens}\n</ul>"
print(lista_html)

<ul>
  <li>Coxinha</li>
  <li>Açaí</li>
  <li>Pão de queijo</li>
</ul>

Com uma lista de dicionários, dá para montar uma tabela inteira. Mude os dados, rode de novo, e a tabela muda junto:

notas = [
    {"materia": "Matemática", "nota": 8.5},
    {"materia": "Português", "nota": 9.0},
    {"materia": "Ciências", "nota": 7.0},
]

linhas = ["<table>", "  <tr><th>Matéria</th><th>Nota</th></tr>"]
for n in notas:
    nota = f"{n['nota']:.1f}".replace(".", ",")
    linhas.append(f"  <tr><td>{n['materia']}</td><td>{nota}</td></tr>")
linhas.append("</table>")

print("\n".join(linhas))

<table>
  <tr><th>Matéria</th><th>Nota</th></tr>
  <tr><td>Matemática</td><td>8,5</td></tr>
  <tr><td>Português</td><td>9,0</td></tr>
  <tr><td>Ciências</td><td>7,0</td></tr>
</table>

No seu computador, salve o resultado num arquivo com Path("notas.html").write_text(pagina, encoding="utf-8") e abra o arquivo no navegador.

Cuidado com o que vem de fora: html.escape

Os caracteres <, > e & têm significado especial no HTML. Se um texto digitado por alguém tiver <, o navegador acha que é uma tag. Isso pode só quebrar a página... ou deixar alguém colocar um programa malicioso nela (um ataque chamado XSS).

A solução é escapar o texto com html.escape, que troca esses caracteres por códigos seguros, como &lt;:

import html

comentario = 'Adorei! <script>alert("hackeado")</script> 5 < 10 & 2 > 1'

print("Perigoso:", f"<p>{comentario}</p>")
print("Seguro:  ", f"<p>{html.escape(comentario)}</p>")

Perigoso: <p>Adorei! <script>alert("hackeado")</script> 5 < 10 & 2 > 1</p>
Seguro:   <p>Adorei! &lt;script&gt;alert(&quot;hackeado&quot;)&lt;/script&gt; 5 &lt; 10 &amp; 2 &gt; 1</p>

O navegador mostra o texto seguro exatamente como a pessoa digitou, mas não executa nada.

Atenção: Escape sempre os dados que vêm do usuário, de arquivos ou da internet antes de colocá-los no HTML. O Django (aula 202) faz isso sozinho nos templates; quando você monta HTML com f-string, a responsabilidade é sua.

Conferindo a estrutura com html.parser

O Python tem um leitor de HTML na biblioteca padrão, o html.parser. Criando uma classe filha de HTMLParser, você é avisado de cada tag aberta e fechada — dá para contar tags, listar links ou achar tags esquecidas abertas:

from html.parser import HTMLParser


class Conferidor(HTMLParser):
    VAZIAS = {"img", "br", "meta", "link", "input", "hr"}

    def __init__(self):
        super().__init__()
        self.abertas = []
        self.links = []

    def handle_starttag(self, tag, attrs):
        if tag == "a":
            self.links.append(dict(attrs).get("href"))
        if tag not in self.VAZIAS:
            self.abertas.append(tag)

    def handle_endtag(self, tag):
        if self.abertas and self.abertas[-1] == tag:
            self.abertas.pop()
        else:
            print(f"Problema: fechou </{tag}> mas a última aberta era <{self.abertas[-1]}>")


pagina = '<p>Veja o <a href="https://python.org">site</a> <strong>agora</p></strong>'
c = Conferidor()
c.feed(pagina)
print("Links:", c.links)

Problema: fechou </p> mas a última aberta era <strong>
Links: ['https://python.org']

4. Use html.parser para contar quantas vezes cada tag aparece no HTML <ul><li>a</li><li>b</li></ul><p>fim</p>.

Ver resposta 
from collections import Counter
from html.parser import HTMLParser


class Contador(HTMLParser):
    def __init__(self):
        super().__init__()
        self.tags = Counter()

    def handle_starttag(self, tag, attrs):
        self.tags[tag] += 1


c = Contador()
c.feed("<ul><li>a</li><li>b</li></ul><p>fim</p>")
print(dict(c.tags))

{'ul': 1, 'li': 2, 'p': 1}
