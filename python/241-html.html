O que é HTML

Toda página da internet é um arquivo de texto escrito em HTML. Ele não é uma linguagem de programação: não tem if nem laços. É uma linguagem de marcação, que diz ao navegador o que é cada pedaço — isto é um título, isto é um parágrafo, isto é um link.

Cada pedaço fica entre tags: uma de abertura, como <p>, e uma de fechamento, como </p>. Quem programa em Python precisa de HTML para fazer sites com Django (módulo 11) e para gerar relatórios bonitos.

Uma página completa

Crie no VS Code um arquivo index.html com este conteúdo e abra-o com dois cliques (ele abre no navegador):

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Minha página</title>
</head>
<body>
  <h1>Olá, eu sou a Bia!</h1>
  <p>Estou aprendendo <strong>Python</strong> e HTML.</p>
  <h2>Minhas comidas favoritas</h2>
  <ul>
    <li>Coxinha</li>
    <li>Açaí</li>
    <li>Pão de queijo</li>
  </ul>
  <p>Treino digitação no <a href="https://example.com">DIGITAR</a>.</p>
  <img src="foto.jpg" alt="Minha foto na praia">
</body>
</html>
  • <head> guarda informações sobre a página (como o título da aba); <body> guarda o que aparece na tela.
  • <h1> a <h6> são títulos, do maior ao menor; <p> é parágrafo; <strong> é destaque.
  • <ul> é uma lista com marcadores e cada item é um <li>; <ol> faz uma lista numerada.
  • <a href="..."> é um link e <img src="..." alt="..."> é uma imagem. O alt descreve a imagem para quem não pode vê-la.
Atenção: Esquecer de fechar uma tag (escrever <p> e não pôr </p>) ou fechar na ordem errada bagunça a página. Feche sempre na ordem inversa da abertura: <p><strong>oi</strong></p>.
Dica: <meta charset="utf-8"> faz os acentos e o ç aparecerem certos. Sem ele, "Açaí" pode virar letras estranhas.

Gerando HTML com Python

Como o HTML é só texto, o Python consegue escrever páginas sozinho. Este programa monta uma lista a partir de uma lista do Python e salva o arquivo comidas.html:

from pathlib import Path

comidas = ["Coxinha", "Açaí", "Pão de queijo"]
itens = "\n".join(f"    <li>{comida}</li>" for comida in comidas)

pagina = f"""<!doctype html>
<html lang="pt-BR">
<head><meta charset="utf-8"><title>Comidas</title></head>
<body>
  <h1>Comidas favoritas</h1>
  <ul>
{itens}
  </ul>
</body>
</html>
"""
Path("comidas.html").write_text(pagina, encoding="utf-8")
print(itens)
print("Página salva em comidas.html")

    <li>Coxinha</li>
    <li>Açaí</li>
    <li>Pão de queijo</li>
Página salva em comidas.html

Abra comidas.html no navegador para ver o resultado. Mude a lista no Python, rode de novo e a página muda junto.

Exercícios

1. Escreva o HTML de uma lista numerada (<ol>) com os três primeiros passos para fazer um café.

Ver resposta 
<ol>
  <li>Ferver a água</li>
  <li>Colocar o pó no coador</li>
  <li>Despejar a água devagar</li>
</ol>

2. Faça um programa Python que receba um dicionário de contatos (nome e telefone) e gere as linhas de uma tabela HTML, uma <tr> por contato, mostrando o resultado com print.

Ver resposta 
contatos = {"Mãe": "(11) 99999-1234", "Pai": "(11) 98888-4321"}

for nome, telefone in contatos.items():
    print(f"<tr><td>{nome}</td><td>{telefone}</td></tr>")

<tr><td>Mãe</td><td>(11) 99999-1234</td></tr>
<tr><td>Pai</td><td>(11) 98888-4321</td></tr>

3. Para que serve o atributo alt em <img src="gato.jpg" alt="Gato dormindo no sofá">?

Ver resposta

O alt descreve a imagem em texto. Ele é lido por leitores de tela (usados por pessoas cegas)
e aparece no lugar da imagem quando ela não carrega.
