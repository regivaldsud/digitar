Nesta aula você vai aprender

  • Revisar o caminho que você percorreu no curso
  • Conhecer áreas onde o Python é usado e por onde começar em cada uma

Olha só até onde você chegou

Você começou com print("Olá, mundo!") e passou por variáveis, decisões, laços, listas, dicionários, funções, arquivos, exceções, classes, testes e muito mais. Isso é a base de qualquer programador Python — parabéns!

O próximo passo é o mais importante: praticar com projetos seus. Programação se aprende como digitação: um pouco todo dia vale mais do que muito de vez em quando.

Para onde ir agora

  • Sites e APIs: aprofunde o Django (módulo 11) ou experimente o Flask e o FastAPI.
  • Dados e ciência: aprenda pandas para planilhas e matplotlib para gráficos, usando o Jupyter (aula 115).
  • Automação: junte arquivos, planilhas e e-mail (módulo 5) para acabar com tarefas repetitivas.
  • Jogos: a biblioteca pygame é um ótimo jeito de treinar laços, classes e eventos.
  • Inteligência artificial: depois de dominar o básico e um pouco de matemática, conheça o scikit-learn.
Dica: Desafios curtos ajudam a manter o ritmo. Sites como o Beecrowd (feito no Brasil) e o Exercism têm milhares de exercícios, e você pode resolver em Python.

Monte seu plano de estudos

Que tal usar Python para organizar o próprio estudo? Este programa distribui os temas pelas semanas e mostra o plano:

temas = ["Revisar funções", "Projeto com pygame", "pandas básico",
         "Gráficos com matplotlib", "Publicar no GitHub"]

for semana, tema in enumerate(temas, start=1):
    print(f"Semana {semana}: {tema}")

print(f"Total: {len(temas)} semanas de estudo")

Semana 1: Revisar funções
Semana 2: Projeto com pygame
Semana 3: pandas básico
Semana 4: Gráficos com matplotlib
Semana 5: Publicar no GitHub
Total: 5 semanas de estudo

E este conta quantos minutos você pratica por semana, juntando o treino de digitação no DIGITAR e o de programação:

pratica = {"seg": 30, "ter": 20, "qua": 0, "qui": 45, "sex": 25}

total = sum(pratica.values())
dias_parados = [dia for dia, minutos in pratica.items() if minutos == 0]

print(f"Você praticou {total} minutos nesta semana.")
print("Dias sem prática:", ", ".join(dias_parados))

Você praticou 120 minutos nesta semana.
Dias sem prática: qua

Atenção: Não tente aprender tudo ao mesmo tempo. Escolha uma área, faça um projeto pequeno do começo ao fim e só então passe para a próxima.

Exercícios

1. Crie uma lista com três projetos que você quer fazer e mostre cada um numerado, no formato 1. Nome do projeto.

Ver resposta 
projetos = ["Jogo da forca", "Controle de mesada", "Quiz de geografia"]

for numero, projeto in enumerate(projetos, start=1):
    print(f"{numero}. {projeto}")

1. Jogo da forca
2. Controle de mesada
3. Quiz de geografia

2. Usando o dicionário pratica do exemplo, descubra o dia em que você mais praticou.

Ver resposta 
pratica = {"seg": 30, "ter": 20, "qua": 0, "qui": 45, "sex": 25}

melhor_dia = max(pratica, key=pratica.get)
print(f"O dia com mais prática foi {melhor_dia}: {pratica[melhor_dia]} minutos.")

O dia com mais prática foi qui: 45 minutos.

3. Faça uma função meta_atingida(minutos, meta=150) que devolva True se o total de minutos da semana chegou à meta, e teste com 140 e com 160.

Ver resposta 
def meta_atingida(minutos, meta=150):
    return minutos >= meta


print(meta_atingida(140))
print(meta_atingida(160))

False
True
