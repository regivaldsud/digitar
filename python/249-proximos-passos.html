Esqueleto 1: dados com statistics

Antes do pandas, dá para analisar dados com o módulo statistics, que já vem com o Python. Troque as notas pelas suas e acrescente gráficos de barras feitos com texto:

import statistics

notas = {"Matemática": [7.5, 8.0, 6.5, 9.0], "Português": [9.0, 8.5, 9.5, 8.0],
         "Ciências": [6.0, 7.0, 8.5, 7.5]}

for materia, valores in notas.items():
    media = statistics.mean(valores)
    barra = "#" * round(media * 2)
    print(f"{materia:11} {media:4.1f} {barra}")

todas = [n for valores in notas.values() for n in valores]
print(f"Mediana geral: {statistics.median(todas)}")
print(f"Desvio padrão: {statistics.stdev(todas):.2f}")

Matemática   7.8 ################
Português    8.8 ##################
Ciências     7.2 ##############
Mediana geral: 8.0
Desvio padrão: 1.06

Ideias para crescer: ler as notas de um CSV (aula 106), salvar o resultado em JSON (aula 62) e, depois, refazer tudo com pandas.

Esqueleto 2: automação com pathlib

Este organizador separa arquivos em pastas pela extensão — o tipo de tarefa chata que um programa faz em segundos. Aqui ele roda numa pasta temporária, com arquivos de mentira:

import shutil
import tempfile
from pathlib import Path

TIPOS = {".jpg": "imagens", ".png": "imagens", ".pdf": "documentos", ".txt": "textos"}

with tempfile.TemporaryDirectory() as raiz:
    downloads = Path(raiz)
    for nome in ["foto.jpg", "prova.pdf", "lista.txt", "meme.png", "musica.mp3"]:
        (downloads / nome).touch()

    for arquivo in list(downloads.iterdir()):
        pasta = TIPOS.get(arquivo.suffix, "outros")
        (downloads / pasta).mkdir(exist_ok=True)
        shutil.move(str(arquivo), str(downloads / pasta / arquivo.name))

    for pasta in sorted(downloads.iterdir()):
        print(pasta.name, "->", sorted(p.name for p in pasta.iterdir()))

documentos -> ['prova.pdf']
imagens -> ['foto.jpg', 'meme.png']
outros -> ['musica.mp3']
textos -> ['lista.txt']

Atenção: Quando for usar um programa que move ou apaga arquivos de verdade, teste antes numa pasta de treino, com cópias. E faça o programa só mostrar o que faria (um "modo ensaio") antes de deixá-lo mexer nos arquivos.

Esqueleto 3: um jogo de terminal

Jogos são ótimos para treinar classes e regras. Este é um jogo de dados entre dois jogadores; as jogadas são sorteadas, e o random.seed faz o resultado sair sempre igual para você conferir. No seu computador, troque o sorteio por input para jogar de verdade:

import random


class Jogador:
    def __init__(self, nome):
        self.nome = nome
        self.pontos = 0

    def jogar(self):
        dado = random.randint(1, 6)
        self.pontos += dado
        return dado


random.seed(7)
jogadores = [Jogador("Ana"), Jogador("Léo")]
for rodada in range(1, 4):
    jogadas = [f"{j.nome} tirou {j.jogar()}" for j in jogadores]
    print(f"Rodada {rodada}: " + ", ".join(jogadas))

vencedor = max(jogadores, key=lambda j: j.pontos)
print(f"Vencedor: {vencedor.nome} com {vencedor.pontos} pontos")

Rodada 1: Ana tirou 3, Léo tirou 2
Rodada 2: Ana tirou 4, Léo tirou 6
Rodada 3: Ana tirou 1, Léo tirou 1
Vencedor: Léo com 9 pontos

Ideias para crescer: empate, mais jogadores, um placar salvo em arquivo e, depois, uma versão com janela usando pygame ou PySide6 (módulo 10).

Esqueleto 4: a ideia da inteligência artificial

No fundo, muitos programas de IA aprendem com exemplos. O mais simples deles é o "vizinho mais próximo": para classificar algo novo, procure o exemplo conhecido mais parecido. Aqui, frutas descritas por peso (em gramas) e cor (0 = verde, 10 = vermelho):

import math

exemplos = [((150, 9), "maçã"), ((170, 8), "maçã"), ((120, 2), "limão"),
            ((110, 1), "limão"), ((300, 3), "manga")]


def classificar(peso, cor):
    def distancia(exemplo):
        (p, c), _ = exemplo
        return math.dist((peso / 10, cor), (p / 10, c))

    return min(exemplos, key=distancia)[1]


for fruta in [(160, 9), (115, 2), (280, 4)]:
    print(fruta, "->", classificar(*fruta))

(160, 9) -> maçã
(115, 2) -> limão
(280, 4) -> manga

O scikit-learn faz essa mesma ideia (e muitas outras) com milhares de exemplos e muito mais rapidez. Entender a versão pequena primeiro deixa a grande bem menos misteriosa.

Como estudar sozinho

  • Pouco todo dia: 20 a 30 minutos por dia rendem mais do que 4 horas no sábado.
  • Projetos pequenos e terminados: um programa simples que funciona ensina mais do que um gigante pela metade.
  • Digite, não copie e cole: digitar o código (como no modo Programar do DIGITAR) faz você reparar em cada detalhe.
  • Explique para alguém: se você consegue explicar uma ideia para um colega, aprendeu de verdade.
  • Revise: volte às aulas antigas de vez em quando e refaça os exercícios sem olhar a resposta.

Lendo documentação e pesquisando erros

A documentação oficial, em docs.python.org/pt-br/3, tem boa parte traduzida para o português. Quando quiser saber o que um módulo faz, comece por lá. Dentro do próprio Python também há ajuda: help() mostra a documentação e dir() lista o que um objeto tem (aula 86):

import statistics

funcoes = [nome for nome in statistics.__all__ if nome.islower()]
print("Algumas funções de statistics:", funcoes[:8])
print(statistics.mode.__doc__.strip().splitlines()[0])

Algumas funções de statistics: ['correlation', 'covariance', 'fmean', 'geometric_mean', 'harmonic_mean', 'linear_regression', 'mean', 'median']
Return the most common data point from discrete or nominal data.

Quando aparecer um erro, leia a última linha do traceback primeiro (aula 06). Se não entender, copie essa linha (sem os nomes dos seus arquivos) e pesquise. Quase sempre alguém já teve o mesmo problema.

Atenção: Nunca cole senhas, chaves ou dados pessoais em sites de pergunta ou em ferramentas de IA ao pedir ajuda (veja a aula 177). E quando uma IA ou um site sugerir um código, entenda o que ele faz antes de usar.

Um bom README tem sempre as mesmas partes. Este programa monta um modelo para você copiar:

def readme(nome, descricao, comando, aprendi):
    linhas = [f"# {nome}", "", descricao, "", "## Como rodar", "", "```", comando, "```",
              "", "## O que eu aprendi", ""]
    linhas += [f"- {item}" for item in aprendi]
    return "\n".join(linhas)


print(readme("Jogo da Forca", "Jogo da forca no terminal, com palavras sobre o Brasil.",
             "python forca.py", ["listas e laços", "ler palavras de um arquivo"]))
