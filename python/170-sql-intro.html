Por que um banco de dados

Na aula 62 você salvou dados em JSON. Isso funciona bem para poucos dados. Quando a escola tem milhares de alunos, notas e turmas, e várias pessoas mexem ao mesmo tempo, usamos um banco de dados: um programa especializado em guardar e buscar dados rapidamente e com segurança.

Um banco relacional guarda tudo em tabelas, parecidas com planilhas. Cada coluna é um tipo de informação (nome, idade) e cada linha é um registro (um aluno). A coluna que identifica cada linha sem repetir é a chave primária.

A linguagem SQL

Para conversar com o banco usamos o SQL (pronuncia-se "esse-quê-éle" ou "síquel"). Os comandos são quase frases em inglês: CREATE TABLE cria tabela, INSERT insere, SELECT busca.

O Python já vem com o SQLite, um banco pequeno que guarda tudo num arquivo, ou só na memória, com o nome especial ":memory:":

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE alunos (id INTEGER PRIMARY KEY, nome TEXT, idade INTEGER)")
con.execute("INSERT INTO alunos (nome, idade) VALUES ('Ana', 12)")
con.execute("INSERT INTO alunos (nome, idade) VALUES ('Caio', 13)")
for linha in con.execute("SELECT id, nome, idade FROM alunos"):
    print(linha)
con.close()

(1, 'Ana', 12)
(2, 'Caio', 13)

Cada linha volta como uma tupla. Repare que o id foi preenchido sozinho: INTEGER PRIMARY KEY numera automaticamente.

Dica: Na primeira vez que você roda um exemplo com sqlite3 aqui no site, o navegador baixa o módulo do SQLite. Pode levar alguns segundos; depois fica rápido.

Bancos diferentes, a mesma ideia

Existem vários bancos relacionais: SQLite, MySQL, PostgreSQL, SQL Server. O SQL básico é quase igual em todos. O que você aprender neste módulo com SQLite vale para os outros (a aula 176 mostra o MySQL).

import sqlite3

con = sqlite3.connect(":memory:")
versao = con.execute("SELECT sqlite_version()").fetchone()[0]
print("Versão do SQLite:", versao)
print(con.execute("SELECT 2 + 3, 'texto', 10 * 1.5").fetchone())
con.close()

(exemplo — a sua saída pode ser diferente)
Versão do SQLite: 3.49.1
(5, 'texto', 15.0)

Atenção: Em SQL, textos vão entre aspas simples: 'Ana'. Por isso, no Python, a string do comando costuma usar aspas duplas por fora.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
con = sqlite3.connect(":memory:")

Exercícios

1. Crie uma tabela cidades com as colunas id, nome e estado, insira Salvador (BA) e Manaus (AM) e mostre todas as linhas.

Ver resposta 
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE cidades (id INTEGER PRIMARY KEY, nome TEXT, estado TEXT)")
con.execute("INSERT INTO cidades (nome, estado) VALUES ('Salvador', 'BA')")
con.execute("INSERT INTO cidades (nome, estado) VALUES ('Manaus', 'AM')")
for linha in con.execute("SELECT * FROM cidades"):
    print(linha)
con.close()

(1, 'Salvador', 'BA')
(2, 'Manaus', 'AM')
