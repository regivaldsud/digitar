Aula 61 · Lendo e gravando arquivos com with open; modos e encoding

Nesta aula você vai aprender

  • Abrir arquivos com open e escolher o modo: "r", "w", "a" ou "x"
  • Usar o bloco with para o arquivo fechar sozinho
  • Ler o arquivo inteiro com read, em lista com readlines ou linha por linha com for
  • Escrever várias linhas de uma vez com writelines e com print(..., file=f)
  • Por que sempre usar encoding="utf-8" com textos em português

Por que usar arquivos

Tudo o que fica numa variável some quando o programa termina. Se você quer guardar a lista de compras, o placar de um jogo ou as notas da turma para usar amanhã, precisa salvar num arquivo.

Um arquivo de texto (.txt) é o tipo mais simples: só letras, números e quebras de linha, como os que você abre no Bloco de Notas.

Dica: Aqui no navegador, os arquivos são criados num sistema de arquivos virtual, que existe só enquanto a página está aberta. No seu computador, o arquivo aparece de verdade na pasta onde o terminal está. Por isso, todos os exemplos desta aula escrevem o arquivo e o leem de volta no mesmo bloco.

Escrevendo: o modo "w"

A função open abre um arquivo. O primeiro valor é o nome do arquivo; o segundo é o modo: "w" (de *write*, escrever) cria o arquivo — ou apaga o que já existia nele — e deixa escrever.

with open("compras.txt", "w", encoding="utf-8") as arquivo:
    arquivo.write("arroz\n")
    arquivo.write("feijão\n")
    arquivo.write("farinha de mandioca\n")

print("Arquivo salvo!")

Arquivo salvo!

O with abre o arquivo, guarda ele na variável arquivo e, quando o bloco indentado termina, fecha o arquivo sozinho — mesmo que aconteça um erro no meio. Sem fechar, parte do texto pode não ser gravada.

O write não pula linha por conta própria: é você quem coloca o \n (quebra de linha) no fim de cada linha.

Atenção: O modo "w" apaga tudo o que havia no arquivo antes de escrever. Se você quer acrescentar no final, use o modo "a", que você vai ver logo abaixo.

Lendo: o modo "r" e o read

O modo "r" (de *read*, ler) é o padrão. O método read devolve o arquivo inteiro como uma única string.

with open("recado.txt", "w", encoding="utf-8") as f:
    f.write("Mãe, fui para o treino de futsal.\n")
    f.write("Volto às 18h.\n")

with open("recado.txt", "r", encoding="utf-8") as f:
    conteudo = f.read()

print(conteudo, end="")
print("Caracteres:", len(conteudo))

Mãe, fui para o treino de futsal.
Volto às 18h.
Caracteres: 48

O end="" no print evita uma linha vazia extra: o texto já termina com \n.

Atenção: Sem encoding="utf-8", o Windows pode usar outra codificação, e palavras como feijão e às aparecem estragadas (por exemplo feijÃ£o). Use sempre encoding="utf-8" ao ler e ao escrever.

Linha por linha: for, readlines e strip

Um arquivo aberto pode ser percorrido com for, uma linha de cada vez. Cada linha vem com o \n no fim; o método strip() tira esses espaços e quebras das pontas.

with open("times.txt", "w", encoding="utf-8") as f:
    f.write("Flamengo\nPalmeiras\nGrêmio\nBahia\n")

with open("times.txt", encoding="utf-8") as f:
    for numero, linha in enumerate(f, start=1):
        print(numero, linha.strip())

1 Flamengo
2 Palmeiras
3 Grêmio
4 Bahia

Já o readlines() devolve uma lista com todas as linhas, cada uma ainda com seu \n:

with open("times.txt", "w", encoding="utf-8") as f:
    f.write("Flamengo\nPalmeiras\nGrêmio\n")

with open("times.txt", encoding="utf-8") as f:
    linhas = f.readlines()

print(linhas)
print([linha.strip() for linha in linhas])

['Flamengo\n', 'Palmeiras\n', 'Grêmio\n']
['Flamengo', 'Palmeiras', 'Grêmio']

Para escrever uma lista de uma vez, há o writelines (que também não põe \n sozinho) e o print com file=, que põe:

alunos = ["Ana", "Bruno", "Carla"]

with open("chamada.txt", "w", encoding="utf-8") as f:
    f.writelines(nome + "\n" for nome in alunos)
    print("Total:", len(alunos), file=f)

with open("chamada.txt", encoding="utf-8") as f:
    print(f.read(), end="")

Ana
Bruno
Carla
Total: 3

Acrescentando: os modos "a" e "x"

O modo "a" (de *append*, acrescentar) escreve no final do arquivo, sem apagar o que já estava lá. Ótimo para um diário ou um registro de pontuações.

with open("diario.txt", "w", encoding="utf-8") as f:
    f.write("Segunda: prova de matemática.\n")

with open("diario.txt", "a", encoding="utf-8") as f:
    f.write("Terça: aula de digitação, 35 PPM!\n")

with open("diario.txt", encoding="utf-8") as f:
    print(f.read(), end="")

Segunda: prova de matemática.
Terça: aula de digitação, 35 PPM!

O modo "x" cria um arquivo novo e dá erro se ele já existir — uma proteção para não apagar nada sem querer:

with open("unico.txt", "x", encoding="utf-8") as f:
    f.write("primeira vez\n")

try:
    with open("unico.txt", "x", encoding="utf-8") as f:
        f.write("segunda vez\n")
except FileExistsError:
    print("O arquivo já existe; nada foi apagado.")

O arquivo já existe; nada foi apagado.

Dica: Resumo dos modos: "r" lê (erro se não existir), "w" cria ou apaga e escreve, "a" cria ou acrescenta no fim, "x" só cria (erro se existir). Juntando "+", como "r+", dá para ler e escrever no mesmo arquivo, mas isso raramente é necessário.
Atenção: Abrir no modo "r" um arquivo que não existe causa FileNotFoundError. Confira o nome e se o terminal está na pasta certa — e trate o erro com try (aula 53).

Exercícios

1. Escreva um programa que crie o arquivo frutas.txt com três frutas (uma por linha) e depois leia e mostre o conteúdo.

Ver resposta 
with open("frutas.txt", "w", encoding="utf-8") as f:
    f.write("manga\n")
    f.write("caju\n")
    f.write("açaí\n")

with open("frutas.txt", encoding="utf-8") as f:
    print(f.read(), end="")

manga
caju
açaí

2. Grave os números de 1 a 5 no arquivo numeros.txt, um por linha, usando um for. Depois leia o arquivo e mostre a soma dos números.

Ver resposta 
with open("numeros.txt", "w", encoding="utf-8") as f:
    for n in range(1, 6):
        f.write(str(n) + "\n")

soma = 0
with open("numeros.txt", encoding="utf-8") as f:
    for linha in f:
        soma += int(linha)

print("Soma:", soma)

Soma: 15

O write só aceita texto, por isso o str(n). Na leitura, int(linha) funciona mesmo com o \n no fim, porque o int ignora espaços e quebras de linha nas pontas.

4. Grave um arquivo com as palavras bola, casa, banana e bicicleta, uma por linha. Leia o arquivo e mostre só as palavras que começam com a letra b.

Ver resposta 
with open("palavras.txt", "w", encoding="utf-8") as f:
    f.write("bola\ncasa\nbanana\nbicicleta\n")

with open("palavras.txt", encoding="utf-8") as f:
    for linha in f:
        palavra = linha.strip()
        if palavra.startswith("b"):
            print(palavra)

bola
banana
bicicleta

5. Faça uma função ler_ou_vazio(nome) que devolve a lista de linhas (sem \n) de um arquivo, ou uma lista vazia se o arquivo não existir. Teste com um arquivo que existe e outro que não.

Ver resposta 
def ler_ou_vazio(nome):
    try:
        with open(nome, encoding="utf-8") as f:
            return [linha.strip() for linha in f]
    except FileNotFoundError:
        return []

with open("lista.txt", "w", encoding="utf-8") as f:
    f.write("pão\nleite\n")

print(ler_ou_vazio("lista.txt"))
print(ler_ou_vazio("nao_existe.txt"))

['pão', 'leite']
[]
