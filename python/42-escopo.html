Aula 42 · Escopo: local, global, nonlocal

Nesta aula você vai aprender

  • O que é escopo de uma variável
  • A diferença entre variável local e variável global
  • Por que alterar uma global dentro da função dá UnboundLocalError
  • O que fazem global e nonlocal e por que é melhor usá-los pouco

Cada função tem a sua "sala"

Pense numa escola: o que é escrito no quadro de uma sala só existe naquela sala. As variáveis criadas dentro de uma função são locais: existem só enquanto a função está rodando, e só lá dentro. O "lugar onde a variável existe" se chama escopo.

def calcular():
    total = 10 + 5
    print("Dentro:", total)

calcular()
print("Fora:", total)

Dentro: 15
NameError: name 'total' is not defined

A função mostrou Dentro: 15, mas fora dela total não existe mais. Se você precisa do valor fora, use return.

Variáveis globais

Uma variável criada fora de qualquer função é global: ela pode ser lida de dentro das funções. Mas, se a função cria uma variável com o mesmo nome, são duas variáveis diferentes:

escola = "E.E. Monteiro Lobato"
cor = "azul"

def mostrar():
    cor = "vermelho"
    print("Estudo na", escola)
    print("Dentro da função:", cor)

mostrar()
print("Fora da função:", cor)

Estudo na E.E. Monteiro Lobato
Dentro da função: vermelho
Fora da função: azul

Tentando alterar uma global

E se a função tentar mudar uma global, como um contador de pontos?

pontos = 0

def marcar_ponto():
    pontos = pontos + 1

marcar_ponto()

UnboundLocalError: cannot access local variable 'pontos' where it is not associated with a value

Como existe uma atribuição (pontos = ...) dentro da função, o Python decide que pontos é local. Aí ele tenta ler pontos antes de ela ter valor, e dá UnboundLocalError. A palavra global avisa que você quer usar a variável de fora:

pontos = 0

def marcar_ponto():
    global pontos
    pontos = pontos + 1

marcar_ponto()
marcar_ponto()
print("Pontos:", pontos)

Pontos: 2

Prefira parâmetros e return

Funciona, mas global deixa o programa difícil de entender: qualquer função pode mudar a variável a qualquer momento, e achar o culpado de um bug vira caça ao tesouro. O jeito recomendado é receber o valor por parâmetro e devolver o novo valor:

def marcar_ponto(pontos):
    return pontos + 1

placar = 0
placar = marcar_ponto(placar)
placar = marcar_ponto(placar)
print("Pontos:", placar)

Pontos: 2

Dica: Uma boa função é como uma máquina de suco: entra fruta (parâmetros), sai suco (return). Ela não mexe em nada que está fora dela.

nonlocal: a variável da função de fora

Uma função pode ser criada dentro de outra. A de dentro consegue ler as variáveis da de fora; para alterá-las, use nonlocal (o global não serve aqui, porque a variável não é global):

def criar_contador():
    contagem = 0

    def contar():
        nonlocal contagem
        contagem += 1
        return contagem

    return contar

catraca = criar_contador()
print(catraca())
print(catraca())
print(catraca())

1
2
3

Cada chamada de catraca() lembra o valor anterior de contagem. Esse truque de "função que lembra" se chama closure e vai aparecer de novo na aula 45.

Atenção: O Python procura um nome nesta ordem: primeiro no escopo local, depois nas funções de fora, depois no global e por fim nas funções prontas (como print). Por isso, se você criar uma variável chamada print ou list, a função pronta fica escondida!
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
def marcar_ponto(pontos): return pontos + 1

Exercícios

1. O que este código mostra? x = 5, uma função muda() que faz x = 99 e mostra x, e depois muda() e print(x). Explique.

Ver resposta 
x = 5

def muda():
    x = 99
    print(x)

muda()
print(x)

99
5

Dentro da função, x = 99 cria uma variável local. A global continua valendo 5.

2. Reescreva sem global: um contador de moedas começa em 0 e a função pegar_moeda soma 10. Chame três vezes e mostre o total.

Ver resposta 
def pegar_moeda(moedas):
    return moedas + 10

moedas = 0
moedas = pegar_moeda(moedas)
moedas = pegar_moeda(moedas)
moedas = pegar_moeda(moedas)
print("Moedas:", moedas)

Moedas: 30

3. Por que este código dá erro e como corrigir com global? vidas = 3, e a função perder_vida() faz vidas = vidas - 1.

Ver resposta 
vidas = 3

def perder_vida():
    global vidas
    vidas = vidas - 1

perder_vida()
print("Vidas:", vidas)

Vidas: 2

Sem global, a atribuição faz o Python tratar vidas como local, e ela é lida antes de ter valor (UnboundLocalError). Com global vidas funciona, mas a versão com parâmetro e return é melhor.

4. Crie criar_cofrinho(), que devolve uma função depositar(valor). Cada depósito soma ao saldo guardado e devolve o saldo atual. Deposite 5, 10 e 2.

Ver resposta 
def criar_cofrinho():
    saldo = 0

    def depositar(valor):
        nonlocal saldo
        saldo += valor
        return saldo

    return depositar

cofrinho = criar_cofrinho()
print(cofrinho(5))
print(cofrinho(10))
print(cofrinho(2))

5
15
17
