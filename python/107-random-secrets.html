Aula 107 · Números aleatórios: random e secrets

Sorteando números

randint(a, b) sorteia um inteiro entre a e b, incluindo os dois. random() sorteia um decimal entre 0 e 1, e uniform(a, b) um decimal entre a e b.

import random

print("O dado deu:", random.randint(1, 6))
print("Entre 0 e 1:", random.random())
print("Temperatura sorteada:", round(random.uniform(18, 35), 1), "°C")

(exemplo — a sua saída pode ser diferente)
O dado deu: 4
Entre 0 e 1: 0.7364712141640124
Temperatura sorteada: 27.3 °C

Rode várias vezes: cada execução dá um resultado diferente.

Escolhendo e embaralhando

import random

times = ["Corinthians", "Vasco", "Cruzeiro", "Fortaleza", "Sport"]
print("Sorteado:", random.choice(times))
print("Dois diferentes:", random.sample(times, 2))
print("Três com repetição:", random.choices(times, k=3))

cartas = ["A", "2", "3", "4", "5"]
random.shuffle(cartas)
print("Embaralhadas:", cartas)

(exemplo — a sua saída pode ser diferente)
Sorteado: Fortaleza
Dois diferentes: ['Vasco', 'Sport']
Três com repetição: ['Cruzeiro', 'Cruzeiro', 'Corinthians']
Embaralhadas: ['3', 'A', '5', '2', '4']

  • choice(lista) escolhe um item;
  • sample(lista, k) escolhe k itens diferentes;
  • choices(lista, k=n) escolhe n itens e pode repetir;
  • shuffle(lista) embaralha a própria lista e não devolve nada.
Atenção: Não escreva cartas = random.shuffle(cartas). O shuffle devolve None, e você perde a lista! Apenas chame random.shuffle(cartas).

Sorteios com peso

choices aceita weights, os pesos de cada item. Um item com peso 3 tem três vezes mais chance que um com peso 1. É assim que jogos sorteiam itens raros:

import random

random.seed(7)
premios = ["moeda", "gema", "troféu"]
pesos = [80, 18, 2]
sorteios = random.choices(premios, weights=pesos, k=1000)
for p in premios:
    print(p, sorteios.count(p))

moeda 797
gema 185
troféu 18

Sorteios repetíveis com seed

Os números do random são pseudoaleatórios: vêm de uma conta que parte de uma semente. Fixando a semente com random.seed, a sequência fica sempre igual — ótimo para testar programas:

import random

random.seed(42)
print([random.randint(1, 100) for _ in range(5)])
random.seed(42)
print([random.randint(1, 100) for _ in range(5)])

[82, 15, 4, 95, 36]
[82, 15, 4, 95, 36]

secrets: quando o sorteio precisa ser seguro

Justamente por vir de uma conta, quem descobre a semente consegue prever os próximos números do random. Para senhas, códigos de verificação e tokens, use o módulo secrets, que usa a fonte de aleatoriedade segura do sistema:

import secrets
import string

print("Código de 6 dígitos:", secrets.randbelow(1_000_000))
print("Token:", secrets.token_hex(8))

caracteres = string.ascii_letters + string.digits
senha = "".join(secrets.choice(caracteres) for _ in range(12))
print("Senha:", senha)

(exemplo — a sua saída pode ser diferente)
Código de 6 dígitos: 482913
Token: 9f2c4e1a7b03d6e8
Senha: q7RtZk2LmW9a

Dica: Regra simples: jogo, sorteio de amigo secreto ou exercício → random. Senha, link de "esqueci minha senha" ou qualquer coisa de segurança → secrets.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
dado = random.randint(1, 6)

Exercícios

2. Faça um gerador de números da Mega-Sena: 6 números diferentes de 1 a 60, em ordem crescente.

Ver resposta 
import random

print(sorted(random.sample(range(1, 61), 6)))

(exemplo — a sua saída pode ser diferente)
[22, 23, 31, 37, 42, 50]

3. Com random.seed(1), sorteie a ordem de apresentação de ["Ana", "Bia", "Caio", "Davi"]. Rode duas vezes e confira que a ordem se repete.

Ver resposta 
import random

for _ in range(2):
    random.seed(1)
    grupo = ["Ana", "Bia", "Caio", "Davi"]
    random.shuffle(grupo)
    print(grupo)

['Davi', 'Ana', 'Caio', 'Bia']
['Davi', 'Ana', 'Caio', 'Bia']

4. Gere um código de verificação seguro com exatamente 6 dígitos (com zeros à esquerda quando precisar, como 004817).

Ver resposta 
import secrets

codigo = secrets.randbelow(1_000_000)
print(f"{codigo:06d}")

(exemplo — a sua saída pode ser diferente)
667333

O formato :06d completa com zeros até ter 6 dígitos.
