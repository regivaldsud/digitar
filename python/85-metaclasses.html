Classes também são objetos

Em Python, tudo é objeto: números, textos, funções... e as próprias classes. Uma classe pode ser guardada numa variável, colocada numa lista ou passada para uma função:

class Gato:
    pass

class Cachorro:
    pass

bichos = [Gato, Cachorro]
for classe in bichos:
    print(classe.__name__, type(classe))

Gato <class 'type'>
Cachorro <class 'type'>

Se Gato é um objeto, ele precisa ser de alguma classe. A resposta aparece acima: a classe de uma classe é type. Uma classe que cria classes se chama metaclasse, e type é a metaclasse padrão.

Criando uma classe com type()

Já que type cria classes, dá para criar uma sem usar a palavra class. Passamos o nome, uma tupla de classes mães e um dicionário com os atributos e métodos:

def apresentar(self):
    return f"Sou {self.nome}"

Pessoa = type("Pessoa", (), {"especie": "humana", "apresentar": apresentar})

p = Pessoa()
p.nome = "Rita"
print(p.apresentar())
print(Pessoa.especie, type(p).__name__)

Sou Rita
humana Pessoa

É exatamente isso que o Python faz por baixo dos panos quando lê um bloco class.

Sua primeira metaclasse

Uma metaclasse é uma classe filha de type. O método __new__ dela roda quando a classe é criada (não quando um objeto é criado). Aqui, a metaclasse registra todas as classes de jogo que forem criadas:

class Registro(type):
    classes = []

    def __new__(mcs, nome, bases, atributos):
        nova = super().__new__(mcs, nome, bases, atributos)
        Registro.classes.append(nome)
        print(f"Classe {nome} criada")
        return nova

class Jogo(metaclass=Registro):
    pass

class Xadrez(Jogo):
    pass

class Damas(Jogo):
    pass

print(Registro.classes)

Classe Jogo criada
Classe Xadrez criada
Classe Damas criada
['Jogo', 'Xadrez', 'Damas']

As mensagens aparecem só por definir as classes — nenhum objeto foi criado. E as classes filhas (Xadrez, Damas) herdam a metaclasse da mãe.

Uma metaclasse também pode exigir regras, como obrigar toda classe a ter certo método:

class ExigeDescricao(type):
    def __new__(mcs, nome, bases, atributos):
        if bases and "descricao" not in atributos:
            raise TypeError(f"{nome} precisa ter o método descricao")
        return super().__new__(mcs, nome, bases, atributos)

class Produto(metaclass=ExigeDescricao):
    pass

class Caderno(Produto):
    def descricao(self):
        return "Caderno de 10 matérias"

print(Caderno().descricao())

try:
    class Borracha(Produto):
        pass
except TypeError as erro:
    print("Erro:", erro)

Caderno de 10 matérias
Erro: Borracha precisa ter o método descricao

Atenção: Metaclasses são um assunto avançado e raramente necessário. Um programador experiente disse uma vez que, se você está em dúvida se precisa de uma, não precisa. Conheça para entender bibliotecas como o Django, que usam metaclasses nos models.

O jeito simples: __init_subclass__

Na maioria dos casos, o método especial __init_subclass__ resolve o mesmo problema sem metaclasse. Ele roda na classe mãe toda vez que alguém cria uma classe filha:

class Plugin:
    registrados = []

    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        Plugin.registrados.append(cls.__name__)

class Corretor(Plugin):
    pass

class Tradutor(Plugin):
    pass

print(Plugin.registrados)

['Corretor', 'Tradutor']

Dica: Prefira, nesta ordem: uma função comum, um decorador de classe (aula 84), __init_subclass__ e, só se nada disso servir, uma metaclasse.

Exercícios

1. Use type() para criar a classe Fruta com o atributo cor = "amarela" e mostre a cor de um objeto dessa classe.

Ver resposta 
Fruta = type("Fruta", (), {"cor": "amarela"})
banana = Fruta()
print(banana.cor)

amarela

2. Mostre o que type() devolve para: o número 5, a classe int e a classe type. O que o último resultado revela?

Ver resposta 
print(type(5))
print(type(int))
print(type(type))

<class 'int'>
<class 'type'>
<class 'type'>

A classe de type é o próprio type: ele é a metaclasse de todas as classes, inclusive de si mesmo.

3. Escreva a metaclasse NomeMaiusculo que dá TypeError se o nome da classe não começar com letra maiúscula. Teste com uma classe carro.

Ver resposta 
class NomeMaiusculo(type):
    def __new__(mcs, nome, bases, atributos):
        if not nome[0].isupper():
            raise TypeError(f"o nome {nome!r} deve começar com maiúscula")
        return super().__new__(mcs, nome, bases, atributos)

class Moto(metaclass=NomeMaiusculo):
    pass

try:
    class carro(metaclass=NomeMaiusculo):
        pass
except TypeError as erro:
    print("Erro:", erro)

Erro: o nome 'carro' deve começar com maiúscula

4. Com __init_subclass__, faça a classe Animal exigir que toda classe filha tenha o atributo som. Crie Vaca com som e tente criar Peixe sem som.

Ver resposta 
class Animal:
    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        if not hasattr(cls, "som"):
            raise TypeError(f"{cls.__name__} precisa de um som")

class Vaca(Animal):
    som = "muuu"

print(Vaca.som)
try:
    class Peixe(Animal):
        pass
except TypeError as erro:
    print("Erro:", erro)

muuu
Erro: Peixe precisa de um som
