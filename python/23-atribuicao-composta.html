Nesta aula você vai aprender

  • Entender o que significa atualizar uma variável usando o valor dela mesma

  • Evitar os erros mais comuns com atribuição composta

Atualizar uma variável

Em programação, é muito comum mudar uma variável a partir do valor que ela já tem: somar um ponto no placar, tirar um real do saldo, dobrar uma receita. Na aula 22 você escreveu muito contador = contador + 1. Leia assim: "pegue o valor atual de contador, some 1 e guarde de volta em contador".

pontos = 10
pontos = pontos + 5
print(pontos)

15

O sinal = não é "igual" da matemática: ele guarda o resultado da direita na variável da esquerda.

Os atalhos

Como isso aparece o tempo todo, o Python tem operadores de atribuição composta. Eles fazem a conta e guardam o resultado na mesma variável:

saldo = 100
saldo += 50   # saldo = saldo + 50
print(saldo)
saldo -= 30   # saldo = saldo - 30
print(saldo)
saldo *= 2    # saldo = saldo * 2
print(saldo)
saldo /= 4    # saldo = saldo / 4
print(saldo)

150
120
240
60.0

Repare que depois do /= o saldo virou 60.0: a divisão / sempre dá um float, como você viu na aula 15.

Os outros atalhos

Todo operador aritmético tem seu atalho. Os menos usados também são úteis:

balas = 17
balas //= 5    # divisão inteira: balas = balas // 5
print(balas)
minutos = 135
minutos %= 60  # resto: minutos = minutos % 60
print(minutos)
lado = 3
lado **= 2     # potência: lado = lado ** 2
print(lado)

3
15
9

Atalhos com textos

Com strings, += junta um texto no fim e *= repete o texto. Isso é ótimo para montar frases aos poucos dentro de um laço:

frase = "Bom"
frase += " dia"
frase += ", turma!"
print(frase)
linha = "-"
linha *= 20
print(linha)

Bom dia, turma!
--------------------

contagem = ""
n = 5
while n > 0:
    contagem += str(n) + "... "
    n -= 1
contagem += "Já!"
print(contagem)

5... 4... 3... 2... 1... Já!

Atenção: += só junta texto com texto. contagem += 5 dá TypeError: can only concatenate str (not "int") to str. Converta antes com str(5).

Erros comuns

A variável precisa existir antes do atalho. Se ela ainda não tem valor, o Python não sabe a que somar:

total += 10

NameError: name 'total' is not defined

O certo é começar a variável antes, por exemplo total = 0, e só depois usar total += 10.

Atenção: Não existe ++ em Python. contador++ dá SyntaxError. Use contador += 1.
Dica: Não confunda a ordem: x += 1 soma 1 em x. Já x =+ 1 é lido como x = +1 — guarda o número 1 positivo em x, sem dar erro. Um bug silencioso!
x = 10
x =+ 1
print(x)

1

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
saldo -= preco * quantidade

Exercícios

1. Você tem R$ 50,00 de mesada. Com -=, desconte um lanche de R$ 12,50 e uma recarga de R$ 15,00 e mostre o que sobrou.

Ver resposta 
mesada = 50.0
mesada -= 12.5
mesada -= 15.0
print("Sobrou:", mesada)

Sobrou: 22.5

2. Um investimento rende 10% ao mês. Começando com R$ 1000, use *= dentro de um while para mostrar o valor depois de cada um dos 3 meses (com duas casas decimais).

Ver resposta 
valor = 1000
mes = 1
while mes <= 3:
    valor *= 1.10
    print(f"Mês {mes}: R$ {valor:.2f}")
    mes += 1

Mês 1: R$ 1100.00
Mês 2: R$ 1210.00
Mês 3: R$ 1331.00

3. Monte com += o texto "1, 2, 3, 4, 5" usando um while (sem vírgula depois do 5).

Ver resposta 
texto = ""
n = 1
while n <= 5:
    texto += str(n)
    if n < 5:
        texto += ", "
    n += 1
print(texto)

1, 2, 3, 4, 5

4. Qual é o valor de x no fim deste programa? x = 7, depois x **= 2, depois x %= 10, depois x //= 3. Calcule de cabeça e confira rodando.

Ver resposta 
x = 7
x **= 2
print(x)
x %= 10
print(x)
x //= 3
print(x)

49
9
3

7 elevado a 2 é 49; o resto de 49 por 10 é 9; e a divisão inteira de 9 por 3 é 3.
