Sinal avisa, slot responde

No Qt, quando algo acontece (um clique, um texto digitado, uma opção marcada), o widget emite um sinal. Um slot é a função que roda em resposta. Você liga os dois com sinal.connect(funcao). É como a campainha da sua casa: o botão emite o sinal, e quem atende é o slot.

Um contador de cliques

import sys
from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout,
                               QLabel, QPushButton)


class Contador(QWidget):
    def __init__(self):
        super().__init__()
        self.cliques = 0
        self.rotulo = QLabel("Nenhum clique ainda")
        botao = QPushButton("Clique")
        botao.clicked.connect(self.contar)
        layout = QVBoxLayout(self)
        layout.addWidget(self.rotulo)
        layout.addWidget(botao)

    def contar(self):
        self.cliques += 1
        self.rotulo.setText(f"Cliques: {self.cliques}")


app = QApplication(sys.argv)
janela = Contador()
janela.show()
sys.exit(app.exec())

O slot aqui é o método self.contar. Como ele é um método, pode mexer nos atributos da janela, como self.rotulo.

Sinais que carregam valores

Alguns sinais enviam informação para o slot. O textChanged do QLineEdit manda o texto novo a cada tecla:

import sys
from PySide6.QtWidgets import QApplication, QWidget, QVBoxLayout, QLabel, QLineEdit


class Espelho(QWidget):
    def __init__(self):
        super().__init__()
        self.entrada = QLineEdit()
        self.rotulo = QLabel()
        self.entrada.textChanged.connect(self.atualizar)
        layout = QVBoxLayout(self)
        layout.addWidget(self.entrada)
        layout.addWidget(self.rotulo)

    def atualizar(self, texto):
        self.rotulo.setText(f"{len(texto)} caracteres: {texto.upper()}")


app = QApplication(sys.argv)
janela = Espelho()
janela.show()
sys.exit(app.exec())
Dica: Quer passar um valor extra para o slot? Use uma lambda (aula 49): botao.clicked.connect(lambda: self.digitar("7")).
Atenção: Escreva connect(self.contar), com self.. Sem ele, o Python procura uma função solta chamada contar e dá NameError.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
self.entrada.textChanged.connect(self.atualizar)
