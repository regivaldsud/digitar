Sinal avisa, slot responde

No Qt, quando algo acontece (um clique, um texto digitado, uma opção marcada), o widget emite um sinal. Um slot é a função que roda em resposta. Você liga os dois com sinal.connect(funcao).

É como a campainha da sua casa: o botão da campainha não sabe quem vai atender — ele só toca. Quem atende é quem estiver "ligado" a ela. Isso deixa as peças independentes: o QPushButton foi escrito pelos criadores do Qt anos atrás e não sabe nada do seu programa, mas consegue chamar a sua função.

Um mesmo sinal pode ter vários slots, e um mesmo slot pode responder a vários sinais.

Um sistema de sinais em Python puro

Para entender o que acontece por dentro, veja um sinal bem simples feito só com Python. Ele guarda uma lista de funções e, ao emitir, chama todas:

class Sinal:
    def __init__(self):
        self._slots = []

    def connect(self, funcao):
        self._slots.append(funcao)

    def emit(self, *valores):
        for funcao in self._slots:
            funcao(*valores)


def tocar_musica():
    print("Tocando a campainha: dim-dom!")


def avisar_cachorro():
    print("O cachorro latiu: au au!")


campainha = Sinal()
campainha.connect(tocar_musica)
campainha.connect(avisar_cachorro)

print("Alguém apertou a campainha...")
campainha.emit()

Alguém apertou a campainha...
Tocando a campainha: dim-dom!
O cachorro latiu: au au!

O clicked de um QPushButton funciona do mesmo jeito: o Qt guarda as funções que você passou para connect e chama cada uma quando o clique acontece. Por isso a função vai sem parênteses (aula 190).

Um contador de cliques

Numa janela escrita como classe, o slot costuma ser um método. Assim ele pode mexer nos outros widgets, que estão guardados em atributos (self.rotulo):

import sys
from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout,
                               QLabel, QPushButton)


class Contador(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Contador")
        self.cliques = 0
        self.rotulo = QLabel("Nenhum clique ainda")
        botao = QPushButton("Clique")
        botao.clicked.connect(self.contar)
        layout = QVBoxLayout(self)
        layout.addWidget(self.rotulo)
        layout.addWidget(botao)

    def contar(self):
        self.cliques += 1
        self.rotulo.setText(f"Cliques: {self.cliques}")


app = QApplication(sys.argv)
janela = Contador()
janela.show()
sys.exit(app.exec())

Abre a janela "Contador" com o texto "Nenhum clique ainda" e o botão "Clique".
Depois de três cliques, o texto mostra: Cliques: 3

Atenção: Escreva connect(self.contar), com self.. Sem ele, o Python procura uma função solta chamada contar e dá NameError: name 'contar' is not defined.

Sinais que carregam valores

Alguns sinais enviam informação para o slot. O textChanged do QLineEdit manda o texto novo a cada tecla; o valueChanged de um QSpinBox ou QSlider manda o número novo. O slot só precisa ter um parâmetro para receber:

import sys
from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout,
                               QLabel, QLineEdit, QSlider)
from PySide6.QtCore import Qt


class Espelho(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Espelho")
        self.entrada = QLineEdit()
        self.rotulo = QLabel("0 caracteres")
        self.barra = QSlider(Qt.Orientation.Horizontal)
        self.barra.setRange(8, 40)
        self.entrada.textChanged.connect(self.atualizar)
        self.barra.valueChanged.connect(self.mudar_letra)
        layout = QVBoxLayout(self)
        layout.addWidget(self.entrada)
        layout.addWidget(self.rotulo)
        layout.addWidget(self.barra)

    def atualizar(self, texto):
        self.rotulo.setText(f"{len(texto)} caracteres: {texto.upper()}")

    def mudar_letra(self, tamanho):
        self.rotulo.setStyleSheet(f"font-size: {tamanho}px")


app = QApplication(sys.argv)
janela = Espelho()
janela.show()
sys.exit(app.exec())

Abre a janela "Espelho". Ao digitar "oi", o rótulo mostra: 2 caracteres: OI
Ao arrastar a barra, as letras do rótulo crescem ou diminuem (de 8 a 40 pixels).

No nosso sinal de Python puro, isso é o emit com valores. Experimente:

class Sinal:
    def __init__(self):
        self._slots = []

    def connect(self, funcao):
        self._slots.append(funcao)

    def emit(self, *valores):
        for funcao in self._slots:
            funcao(*valores)


def atualizar(texto):
    print(f"{len(texto)} caracteres: {texto.upper()}")


text_changed = Sinal()
text_changed.connect(atualizar)

digitado = ""
for letra in "gato":
    digitado += letra
    text_changed.emit(digitado)   # como o QLineEdit faz a cada tecla

1 caracteres: G
2 caracteres: GA
3 caracteres: GAT
4 caracteres: GATO

Valor extra com lambda e a armadilha do laço

O clicked não diz qual botão foi apertado. Quando vários botões chamam o mesmo método, use uma lambda (aula 49) para mandar um valor junto: botao.clicked.connect(lambda: self.digitar("7")).

Mas cuidado ao criar botões num for. Uma lambda não guarda o valor da variável na hora em que foi criada: ela olha a variável na hora em que roda, e aí o laço já acabou. Veja em Python puro:

errado = []
for texto in ["7", "8", "9"]:
    errado.append(lambda: print("apertou", texto))

certo = []
for texto in ["7", "8", "9"]:
    certo.append(lambda t=texto: print("apertou", t))

print("Errado:")
for funcao in errado:
    funcao()
print("Certo:")
for funcao in certo:
    funcao()

Errado:
apertou 9
apertou 9
apertou 9
Certo:
apertou 7
apertou 8
apertou 9

O jeito certo é o t=texto: um valor padrão é calculado na hora em que a lambda é criada, então cada botão guarda o seu texto. No Qt, como o clicked às vezes manda um valor (checked), escreva assim:

# dentro do __init__ de uma janela com self.grade = QGridLayout(self)
for i, texto in enumerate(["7", "8", "9"]):
    botao = QPushButton(texto)
    botao.clicked.connect(lambda _=False, t=texto: self.digitar(t))
    self.grade.addWidget(botao, 0, i)
Dica: O _=False recebe o valor checked que o clicked envia e o ignora. Sem ele, o checked (False) entraria no lugar de t e o botão digitaria False.

Criando o seu próprio sinal

Suas classes também podem emitir sinais. Declare o sinal como atributo da classe com Signal(tipo) e emita com self.nome.emit(valor). A classe precisa herdar de QObject (todo QWidget já é um QObject):

from PySide6.QtCore import QObject, Signal


class Termometro(QObject):
    temperatura_mudou = Signal(float)

    def __init__(self):
        super().__init__()
        self._graus = 20.0

    def medir(self, graus):
        if graus != self._graus:
            self._graus = graus
            self.temperatura_mudou.emit(graus)


def mostrar(graus):
    print(f"Agora está {graus:.1f} °C")


termometro = Termometro()
termometro.temperatura_mudou.connect(mostrar)
termometro.medir(20.0)   # igual à anterior: não emite
termometro.medir(31.5)
termometro.medir(18.0)

Agora está 31.5 °C
Agora está 18.0 °C

Esse exemplo nem abre janela: sinais servem para qualquer objeto Qt avisar outros. Na aula 195 você vai usar um sinal próprio para uma tarefa em segundo plano avisar a janela que terminou.

Atenção: O Signal precisa ficar no corpo da classe, fora do __init__. Escrito como self.temperatura_mudou = Signal(float) dentro do __init__, ele não funciona: dá AttributeError ao chamar connect ou emit.

Para desligar um slot, use sinal.disconnect(funcao).

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
self.entrada.textChanged.connect(self.atualizar)

3. Use a classe Sinal de Python puro para criar um sinal nota_lancada que envia um número. Ligue dois slots: um que mostra "Aprovado" ou "Reprovado" (média 7) e outro que guarda a nota numa lista. Emita as notas 8, 5 e 9.5.

Ver resposta 
class Sinal:
    def __init__(self):
        self._slots = []

    def connect(self, funcao):
        self._slots.append(funcao)

    def emit(self, *valores):
        for funcao in self._slots:
            funcao(*valores)


notas = []


def situacao(nota):
    print(nota, "->", "Aprovado" if nota >= 7 else "Reprovado")


nota_lancada = Sinal()
nota_lancada.connect(situacao)
nota_lancada.connect(notas.append)

for nota in [8, 5, 9.5]:
    nota_lancada.emit(nota)
print("Guardadas:", notas)

8 -> Aprovado
5 -> Reprovado
9.5 -> Aprovado
Guardadas: [8, 5, 9.5]

Repare que notas.append também é uma função e pode ser um slot.

4. Dentro de um for texto in ["7", "8", "9"]:, alguém criou cada botão e ligou com botao.clicked.connect(lambda: self.digitar(texto)). Por que todos os botões digitam "9"? Corrija.

Ver resposta 
for texto in ["7", "8", "9"]:
    botao = QPushButton(texto)
    botao.clicked.connect(lambda _=False, t=texto: self.digitar(t))

A lambda olha a variável texto só quando o botão é clicado, e aí o laço já terminou com texto = "9". Com t=texto, cada lambda guarda o valor da sua volta do laço.

5. Faça uma janela com um QSpinBox (de 0 a 100) e um QLabel. Quando o número mudar, o rótulo deve mostrar "Volume: N%".

Ver resposta 
import sys
from PySide6.QtWidgets import QApplication, QWidget, QVBoxLayout, QSpinBox, QLabel


class Volume(QWidget):
    def __init__(self):
        super().__init__()
        self.caixa = QSpinBox()
        self.caixa.setRange(0, 100)
        self.rotulo = QLabel("Volume: 0%")
        self.caixa.valueChanged.connect(self.mostrar)
        layout = QVBoxLayout(self)
        layout.addWidget(self.caixa)
        layout.addWidget(self.rotulo)

    def mostrar(self, valor):
        self.rotulo.setText(f"Volume: {valor}%")


app = QApplication(sys.argv)
janela = Volume()
janela.show()
sys.exit(app.exec())
