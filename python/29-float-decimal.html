Aula 29 · Imprecisão do float, round e Decimal

Nesta aula você vai aprender

O mistério do 0.1 + 0.2

Faça uma conta simples e veja o resultado estranho:

print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(1.1 * 3)

0.30000000000000004
False
3.3000000000000003

Não é defeito do seu código nem do Python: quase toda linguagem faz igual. O computador guarda números em binário (zeros e uns). Assim como 1/3 vira 0,3333... para sempre no nosso sistema decimal, o número 0,1 vira uma "dízima" infinita em binário. O computador guarda só uma aproximação muito boa — mas não exata.

Dica: Para a maioria das contas (média de notas, distância, temperatura), essa diferença minúscula não importa. Ela importa quando você compara números com == ou quando lida com dinheiro.

Arredondando com round

round(valor, casas) arredonda para o número de casas pedido. Sem as casas, arredonda para um inteiro. Para só mostrar com duas casas, a f-string :.2f (aula 16) também resolve.

print(round(10 / 3, 2))
print(round(0.1 + 0.2, 2))
print(round(7.8))
media = (7 + 8 + 8) / 3
print(media)
print(f"{media:.2f}")

3.33
0.3
8
7.666666666666667
7.67

Mas atenção a uma surpresa: quando o número está exatamente no meio, o round vai para o par mais próximo. É o chamado "arredondamento do banqueiro", que evita puxar sempre para cima.

print(round(2.5))
print(round(3.5))
print(round(4.5))
print(round(2.675, 2))

2
4
4
2.67

O round(2.675, 2) dá 2.67, e não 2.68, por outro motivo: em binário, 2.675 é guardado como 2,67499999..., um pouquinho menos que o meio.

Comparando floats com segurança

Como 0.1 + 0.2 == 0.3 dá False, não compare float com ==. Teste se a diferença é bem pequena, ou use math.isclose, que faz isso para você:

import math

total = 0.1 + 0.2
print(abs(total - 0.3) < 0.000001)
print(math.isclose(total, 0.3))

True
True

abs devolve o valor sem sinal (a distância entre os números). A linha import math traz o módulo de matemática do Python; você vai estudar módulos na aula 54.

Decimal: contas exatas

Para dinheiro, onde cada centavo conta, o Python tem o tipo Decimal, que faz contas no sistema decimal, como a gente faz no papel:

from decimal import Decimal

print(Decimal("0.1") + Decimal("0.2"))
print(Decimal("0.1") + Decimal("0.2") == Decimal("0.3"))
preco = Decimal("19.90")
print(preco * 3)

0.3
True
59.70

Atenção: Crie o Decimal a partir de um texto: Decimal("0.1"). Se você escrever Decimal(0.1), ele copia a imprecisão do float e mostra 0.1000000000000000055511151231257827021181583404541015625.
from decimal import Decimal

print(Decimal(0.1))

0.1000000000000000055511151231257827021181583404541015625

Arredondando dinheiro

Para arredondar um Decimal do jeito da escola (meio para cima), use quantize com ROUND_HALF_UP. Decimal("0.01") quer dizer "duas casas decimais":

from decimal import Decimal, ROUND_HALF_UP

conta = Decimal("100.00")
por_pessoa = conta / 3
print(por_pessoa)
print(por_pessoa.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))
print(Decimal("2.675").quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))

33.33333333333333333333333333
33.33
2.68

Dica: Outro truque muito usado por sistemas de pagamento: guardar dinheiro em centavos, como número inteiro. R$ 19,90 vira 1990. Inteiros são sempre exatos; só na hora de mostrar você divide por 100.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
from decimal import Decimal

Exercícios

1. Mostre o resultado de 0.7 + 0.1 e depois compare-o com 0.8 de forma segura, usando math.isclose.

Ver resposta 
import math

soma = 0.7 + 0.1
print(soma)
print(math.isclose(soma, 0.8))

0.7999999999999999
True

2. Um lanche custa R$ 12,35. Usando Decimal, calcule quanto custam 7 lanches.

Ver resposta 
from decimal import Decimal

lanche = Decimal("12.35")
print(lanche * 7)

86.45

3. Quais são os resultados de round(0.5), round(1.5) e round(2.5)? Pense antes de rodar, lembrando do arredondamento do banqueiro.

Ver resposta 
print(round(0.5))
print(round(1.5))
print(round(2.5))

0
2
2

Nos três casos o número está exatamente no meio, então o round vai para o par mais próximo: 0, 2 e 2.

4. Uma conta de R$ 85,00 vai ser dividida entre 3 amigos. Use Decimal e ROUND_HALF_UP para mostrar o valor por pessoa com duas casas.

Ver resposta 
from decimal import Decimal, ROUND_HALF_UP

conta = Decimal("85.00")
parte = (conta / 3).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
print(f"Cada um paga R$ {parte}")

Cada um paga R$ 28.33

5. Some 10 vezes o valor 0.1 num laço, primeiro com float e depois com Decimal, e compare os dois totais.

Ver resposta 
from decimal import Decimal

total_float = 0.0
total_decimal = Decimal("0")
for i in range(10):
    total_float += 0.1
    total_decimal += Decimal("0.1")
print(total_float)
print(total_decimal)

0.9999999999999999
1.0
