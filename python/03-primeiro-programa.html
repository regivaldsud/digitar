O interpretador

O computador não entende Python diretamente. Quem entende é o interpretador: o programa python que você instalou na aula 02. Ele lê o seu arquivo e executa as instruções uma de cada vez, de cima para baixo.

Aqui no site, o interpretador roda dentro do navegador. Repare que cada linha só roda depois da anterior:

print("Linha 1: o interpretador começou a ler.")
print("Linha 2: 10 vezes 3 é", 10 * 3)
print("Linha 3: fim do programa.")

Linha 1: o interpretador começou a ler.
Linha 2: 10 vezes 3 é 30
Linha 3: fim do programa.

Se uma linha tem um problema, o interpretador para ali. As linhas de cima já rodaram; as de baixo não rodam mais:

print("Esta linha roda.")
print("Esta também.")
prinnt("Aqui tem um erro de digitação.")
print("Esta nunca vai aparecer.")

Esta linha roda.
Esta também.
NameError: name 'prinnt' is not defined. Did you mean: 'print'?

É por isso que digitar com atenção importa tanto em programação: uma letra trocada para o programa inteiro. Na aula 06 você aprende a ler essas mensagens de erro.

O que é o terminal

O terminal (no Windows: Prompt de Comando ou PowerShell) é uma janela onde você dá ordens ao computador digitando, em vez de clicar. Parece antigo, mas programadores usam o terminal todos os dias — e quem digita bem tem vantagem!

O terminal está sempre "dentro" de uma pasta. O caminho antes do > mostra onde você está, por exemplo C:\Users\Ana>.

dir                 :: lista o que existe na pasta atual (no PowerShell, no Linux e no macOS: ls)
mkdir projetos      :: cria a pasta "projetos"
cd projetos         :: entra na pasta "projetos"
cd ..               :: volta uma pasta para cima
cls                 :: limpa a tela (no Linux e no macOS: clear)

O texto depois de :: é só explicação; digite apenas o comando.

Dica: Aperte a tecla Tab para completar nomes de pastas e arquivos, e a seta para cima para repetir comandos anteriores. Economiza muita digitação.

Criando o projeto

Vamos criar uma pasta para os exercícios do curso e abrir no VS Code:

cd %USERPROFILE%\Documents
mkdir curso-python
cd curso-python
code .

O comando code . abre a pasta atual (o ponto significa "aqui") no VS Code. Se ele não funcionar, abra o VS Code e use Arquivo › Abrir Pasta. No Linux e no macOS, troque a primeira linha por cd ~/Documents.

Seu primeiro arquivo .py

No VS Code, clique em Novo Arquivo, dê o nome ola.py e escreva o código abaixo. Você também pode executá-lo aqui para ver o que vai acontecer:

print("Olá! Este é meu primeiro arquivo Python.")
print("Ele está salvo no meu computador.")

Olá! Este é meu primeiro arquivo Python.
Ele está salvo no meu computador.

Salve com Ctrl+S. A extensão .py avisa ao computador que o arquivo é um programa Python.

Um arquivo pode ter quantas linhas você quiser. Este aqui monta um pequeno cartão de apresentação:

print("==========================")
print("  Nome: Pedro Henrique")
print("  Cidade: Fortaleza - CE")
print("  Time: Ceará")
print("==========================")

==========================
  Nome: Pedro Henrique
  Cidade: Fortaleza - CE
  Time: Ceará
==========================

Rodando o programa

Há dois jeitos:

  • Clique no triângulo ▶ Run Python File no canto superior direito do VS Code.
  • Ou abra o terminal do próprio VS Code (Terminal › Novo Terminal, ou Ctrl+') e digite o comando abaixo.
python ola.py

Olá! Este é meu primeiro arquivo Python.
Ele está salvo no meu computador.

Atenção: Para rodar python ola.py, o terminal precisa estar na mesma pasta do arquivo. Se aparecer can't open file ... No such file or directory, use cd para entrar na pasta certa ou confira se o arquivo foi salvo.
Atenção: Não digite python ola.py dentro do modo interativo (>>>). Esse comando é do terminal. Se você estiver no >>>, saia com exit() primeiro.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
cd curso-python

Exercícios

1. Escreva os comandos de terminal para criar uma pasta chamada jogos, entrar nela e listar o conteúdo.

Ver resposta 
mkdir jogos
cd jogos
dir

2. Crie um arquivo apresentacao.py que mostre seu nome, sua idade e sua comida favorita, cada um em uma linha. Qual comando roda esse arquivo no terminal?

Ver resposta 
print("Meu nome é Lucas")
print("Tenho 13 anos")
print("Minha comida favorita é feijoada")

Meu nome é Lucas
Tenho 13 anos
Minha comida favorita é feijoada

No terminal, dentro da pasta do arquivo: python apresentacao.py.

3. Você está na pasta C:\Users\Ana\Documents\curso-python\jogos e quer voltar para curso-python. Qual comando usa?

Ver resposta 
cd ..

4. O programa abaixo tem quatro linhas, mas só duas aparecem na tela. Por quê? Corrija para todas aparecerem: print("Um"), print("Dois"), pritn("Três"), print("Quatro").

Ver resposta 
print("Um")
print("Dois")
print("Três")
print("Quatro")

Um
Dois
Três
Quatro

A terceira linha tinha pritn em vez de print. O interpretador parou nela com um erro, e por isso a quarta linha também não rodou.

5. O que significa o ponto em code .?

Ver resposta

O ponto significa "a pasta atual". code . abre no VS Code a pasta onde o terminal está.
