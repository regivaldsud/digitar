Bibliotecas de outras pessoas

O Python já vem com muita coisa pronta (a biblioteca padrão), mas a comunidade criou centenas de milhares de pacotes extras: para fazer jogos (pygame), acessar sites (requests), fazer gráficos (matplotlib) e muito mais. Eles ficam no PyPI (pypi.org), a "loja de aplicativos" gratuita do Python.

Esta aula é uma visão geral, para você saber que essas ferramentas existem. Não precisa decorar nada: na aula 60 você vai praticar com calma os ambientes virtuais e o pip.

Atenção: Esta aula é feita no terminal do seu computador. Abra o terminal do VS Code com Ctrl+', dentro da pasta do seu projeto.

pip: o instalador que vem com o Python

O pip vem junto com o Python. Os comandos principais são:

pip install pygame          :: baixa e instala o pacote
pip list                    :: mostra os pacotes instalados
pip show pygame             :: mostra detalhes de um pacote
pip uninstall pygame        :: remove o pacote

Depois de instalado, o pacote é usado com import. Este programa só funciona no seu computador, depois do pip install pygame:

import pygame

print("pygame versão", pygame.version.ver)
Dica: Se o comando pip não for encontrado no Windows, use py -m pip install pygame. No Linux e no macOS, use pip3 ou python3 -m pip.

uv: uma ferramenta moderna e rápida

O uv é uma ferramenta mais nova que faz o trabalho do pip e de outras ferramentas de uma vez: cria o projeto, cuida do ambiente virtual e instala pacotes muito rápido. Instale com o próprio pip (ou, no Windows, com winget install astral-sh.uv):

pip install uv
uv --version

Para começar um projeto novo:

uv init meu-jogo
cd meu-jogo
uv add pygame
uv run main.py
  • uv init meu-jogo cria a pasta do projeto com um main.py e um pyproject.toml;
  • uv add pygame instala o pacote e anota no pyproject.toml;
  • uv run main.py roda o programa usando o ambiente do projeto.

O arquivo pyproject.toml

O pyproject.toml é a "ficha de identidade" do projeto: nome, versão, versão mínima do Python e pacotes de que ele precisa. Depois do uv add pygame, ele fica parecido com isto:

[project]
name = "meu-jogo"
version = "0.1.0"
description = "Add your description here"
readme = "README.md"
requires-python = ">=3.12"
dependencies = [
    "pygame>=2.6.1",
]

O formato TOML é feito de pares chave = valor, agrupados em seções entre colchetes, como [project]. O Python sabe ler esse formato com o módulo tomllib. Rode no seu computador, na pasta do projeto:

import tomllib

texto = """
[project]
name = "meu-jogo"
version = "0.1.0"
requires-python = ">=3.12"
dependencies = ["pygame>=2.6.1"]
"""

dados = tomllib.loads(texto)
print("Projeto:", dados["project"]["name"])
print("Versão:", dados["project"]["version"])
print("Precisa de:", dados["project"]["dependencies"])

Projeto: meu-jogo
Versão: 0.1.0
Precisa de: ['pygame>=2.6.1']

Não se preocupe com os colchetes e as aspas desse código: você vai entender cada parte nas próximas aulas.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
uv add pygame

Exercícios

1. Qual comando instala o pacote requests com o pip? E qual mostra todos os pacotes instalados?

Ver resposta 
pip install requests
pip list

2. Escreva os comandos do uv para criar um projeto chamado calculadora, entrar na pasta e rodar o arquivo main.py.

Ver resposta 
uv init calculadora
cd calculadora
uv run main.py

3. Num pyproject.toml, em que linha você descobre a versão mínima do Python que o projeto exige?

Ver resposta

Na linha requires-python, por exemplo: requires-python = ">=3.12"
(o projeto precisa do Python 3.12 ou mais novo).

4. O que é o PyPI?

Ver resposta

É o repositório oficial de pacotes do Python (pypi.org). É de lá que o pip
e o uv baixam os pacotes quando você pede para instalar.
