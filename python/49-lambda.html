Aula 49 · Funções lambda e ordenação com key

Nesta aula você vai aprender

  • O que é uma função lambda e como escrevê-la

Uma função numa linha

lambda cria uma função pequena, sem nome, que cabe numa linha. Ela recebe parâmetros e devolve uma expressão — sem escrever return. A forma é lambda parâmetros: expressão:

dobro = lambda x: x * 2
soma = lambda a, b: a + b

print(dobro(8))
print(soma(3, 4))

16
7

Isso equivale a def dobro(x): return x * 2.

Atenção: Uma lambda só pode ter uma expressão: nada de laços ou vários comandos. Se precisa disso, use def. E dar nome a uma lambda (como fizemos acima, só para aprender) não é bom estilo: se a função vai ter nome, use def.

Onde a lambda brilha: ordenar

A lambda é mais útil quando uma função precisa receber outra função (aula 45). O sorted aceita uma key: uma função que diz por qual critério ordenar. O sorted chama a key para cada item e ordena pelos resultados:

frutas = ["melancia", "uva", "abacaxi", "kiwi"]
print(sorted(frutas))
print(sorted(frutas, key=lambda f: len(f)))
print(sorted(frutas, key=len, reverse=True))

['abacaxi', 'kiwi', 'melancia', 'uva']
['uva', 'kiwi', 'abacaxi', 'melancia']
['melancia', 'abacaxi', 'kiwi', 'uva']

Quando já existe uma função pronta (como len), passe-a direto, sem lambda.

Listas de tuplas e de dicionários

Com listas de tuplas ou dicionários, a lambda escolhe qual parte comparar. O método sort da lista aceita a mesma key, mas altera a própria lista:

alunos = [("Ana", 8.5), ("Bruno", 9.7), ("Carla", 7.0)]
ranking = sorted(alunos, key=lambda aluno: aluno[1], reverse=True)
for nome, nota in ranking:
    print(nome, nota)

produtos = [{"nome": "Caderno", "preco": 18.9}, {"nome": "Lápis", "preco": 1.5}]
produtos.sort(key=lambda p: p["preco"])
print([p["nome"] for p in produtos])

Bruno 9.7
Ana 8.5
Carla 7.0
['Lápis', 'Caderno']

min e max com key

min e max também aceitam key, e devolvem o item inteiro, não só o valor comparado:

produtos = [
    {"nome": "Caderno", "preco": 18.90},
    {"nome": "Lápis", "preco": 1.50},
    {"nome": "Mochila", "preco": 129.00},
]
mais_barato = min(produtos, key=lambda p: p["preco"])
mais_caro = max(produtos, key=lambda p: p["preco"])
print("Mais barato:", mais_barato["nome"])
print("Mais caro:", mais_caro["nome"])

Mais barato: Lápis
Mais caro: Mochila

Mais de um critério

Se a key devolve uma tupla, o Python compara o primeiro item; em caso de empate, o segundo, e assim por diante. Para inverter só um critério numérico, use o sinal de menos:

classificacao = [("Bahia", 20), ("Ceará", 23), ("Vitória", 20), ("Sport", 23)]
tabela = sorted(classificacao, key=lambda t: (-t[1], t[0]))
for time, pontos in tabela:
    print(f"{time:<8} {pontos}")

Ceará    23
Sport    23
Bahia    20
Vitória  20

Os times com mais pontos vêm primeiro e, no empate, ficam em ordem alfabética.

Dica: Para ordenar textos sem diferenciar maiúsculas de minúsculas, use key=str.lower. Sem ela, todas as palavras com maiúscula vêm antes das minúsculas.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
ranking = sorted(alunos, key=lambda a: a[1], reverse=True)

Exercícios

1. Crie uma lambda quadrado que devolve o número ao quadrado e mostre quadrado(12).

Ver resposta 
quadrado = lambda n: n ** 2
print(quadrado(12))

144

2. Ordene a lista de cidades ["São Paulo", "Rio", "Belo Horizonte", "Recife"] da maior para a menor quantidade de letras.

Ver resposta 
cidades = ["São Paulo", "Rio", "Belo Horizonte", "Recife"]
print(sorted(cidades, key=lambda c: len(c), reverse=True))

['Belo Horizonte', 'São Paulo', 'Recife', 'Rio']

3. Na lista de jogadores [("Duda", 120), ("Gabi", 340), ("Leo", 95)], cada tupla tem nome e pontos. Use max com key para mostrar o nome de quem fez mais pontos.

Ver resposta 
jogadores = [("Duda", 120), ("Gabi", 340), ("Leo", 95)]
campeao = max(jogadores, key=lambda j: j[1])
print(campeao[0])

Gabi

4. Ordene os nomes ["bia", "Ana", "carlos", "Bruno"] em ordem alfabética ignorando maiúsculas e minúsculas.

Ver resposta 
nomes = ["bia", "Ana", "carlos", "Bruno"]
print(sorted(nomes))
print(sorted(nomes, key=str.lower))

['Ana', 'Bruno', 'bia', 'carlos']
['Ana', 'bia', 'Bruno', 'carlos']

Sem a key, "Ana" e "Bruno" (maiúsculas) vêm antes de "bia". Com str.lower, a ordem fica alfabética de verdade.

5. Ordene os alunos [("Rui", 8), ("Ana", 9), ("Lia", 8), ("Gil", 9)] da maior para a menor nota e, no empate, por nome.

Ver resposta 
alunos = [("Rui", 8), ("Ana", 9), ("Lia", 8), ("Gil", 9)]
print(sorted(alunos, key=lambda a: (-a[1], a[0])))

[('Ana', 9), ('Gil', 9), ('Lia', 8), ('Rui', 8)]
