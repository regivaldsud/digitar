Mais de uma mãe

Em Python, uma classe pode herdar de várias classes de uma vez: basta separar os nomes por vírgula. A filha ganha os métodos de todas.

class Voador:
    def voar(self):
        print(f"{self.nome} está voando.")

class Nadador:
    def nadar(self):
        print(f"{self.nome} está nadando.")

class Pato(Voador, Nadador):
    def __init__(self, nome):
        self.nome = nome

donald = Pato("Donald")
donald.voar()
donald.nadar()
print(isinstance(donald, Voador), isinstance(donald, Nadador))

Donald está voando.
Donald está nadando.
True True

Mixins: habilidades de encaixar

Um mixin é uma classe pequena, que não serve sozinha, criada só para dar uma habilidade a outras classes. Por convenção, o nome termina em Mixin.

class DescricaoMixin:
    def descrever(self):
        partes = [f"{k}={v}" for k, v in vars(self).items()]
        return f"{type(self).__name__}(" + ", ".join(partes) + ")"

class Produto(DescricaoMixin):
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

class Cliente(DescricaoMixin):
    def __init__(self, nome, cidade):
        self.nome = nome
        self.cidade = cidade

print(Produto("Açaí", 15.0).descrever())
print(Cliente("Bia", "Belém").descrever())

Produto(nome=Açaí, preco=15.0)
Cliente(nome=Bia, cidade=Belém)

Classes que não têm nada a ver uma com a outra ganham o mesmo método descrever, sem copiar código.

E se as duas mães tiverem o mesmo método?

O Python segue uma ordem fixa para procurar métodos, chamada MRO (*Method Resolution Order*, ordem de resolução de métodos). Na regra simples: primeiro a própria classe, depois as mães da esquerda para a direita.

class Celular:
    def ligar(self):
        return "ligando para um contato"

class Camera:
    def ligar(self):
        return "ligando a câmera"

class Smartphone(Celular, Camera):
    pass

class CameraDeAcao(Camera, Celular):
    pass

print(Smartphone().ligar())
print(CameraDeAcao().ligar())
print([c.__name__ for c in Smartphone.__mro__])

ligando para um contato
ligando a câmera
['Smartphone', 'Celular', 'Camera', 'object']

O atributo __mro__ mostra a ordem exata da busca. Repare que no fim sempre aparece object: toda classe em Python herda dele.

O losango e o super()

Quando duas mães herdam da mesma avó, o desenho das classes forma um losango. O super() não chama simplesmente "a mãe": ele chama a próxima classe da MRO. Assim, cada método roda uma única vez.

class A:
    def ola(self):
        print("A")

class B(A):
    def ola(self):
        print("B")
        super().ola()

class C(A):
    def ola(self):
        print("C")
        super().ola()

class D(B, C):
    def ola(self):
        print("D")
        super().ola()

D().ola()
print([c.__name__ for c in D.__mro__])

D
B
C
A
['D', 'B', 'C', 'A', 'object']

O super() dentro de B chamou C, e não A, porque na MRO de D quem vem depois de B é C.

Atenção: Herança múltipla é poderosa, mas confunde rápido. Use principalmente com mixins pequenos. Se você precisar de um desenho complicado para entender suas classes, provavelmente composição (aula 75) resolve melhor.

Mixin com super()

Mixins bem escritos chamam super() para não "quebrar a corrente". Este mixin registra uma mensagem antes de salvar:

class Salvavel:
    def salvar(self):
        print(f"salvando {self.nome}")

class LogMixin:
    def salvar(self):
        print("[log] vai salvar...")
        super().salvar()

class Documento(LogMixin, Salvavel):
    def __init__(self, nome):
        self.nome = nome

Documento("redacao.txt").salvar()

[log] vai salvar...
salvando redacao.txt

Dica: Coloque os mixins à esquerda da classe principal (class Documento(LogMixin, Salvavel)), para que o método do mixin rode primeiro e depois passe a vez com super().

Exercícios

1. Crie os mixins CorreMixin (método correr) e PulaMixin (método pular) e a classe Atleta(nome) que usa os dois.

Ver resposta 
class CorreMixin:
    def correr(self):
        print(f"{self.nome} correu 100 m.")

class PulaMixin:
    def pular(self):
        print(f"{self.nome} saltou 7 m.")

class Atleta(CorreMixin, PulaMixin):
    def __init__(self, nome):
        self.nome = nome

a = Atleta("Rebeca")
a.correr()
a.pular()

Rebeca correu 100 m.
Rebeca saltou 7 m.

2. Sem rodar, diga o que aparece: class X e class Y têm o método quem() que devolve "X" e "Y"; class Z(Y, X): pass. O que mostra Z().quem()? Rode para conferir e mostre a MRO.

Ver resposta 
class X:
    def quem(self):
        return "X"

class Y:
    def quem(self):
        return "Y"

class Z(Y, X):
    pass

print(Z().quem())
print([c.__name__ for c in Z.__mro__])

Y
['Z', 'Y', 'X', 'object']

3. Crie o mixin JsonMixin com um método para_json() que devolve json.dumps(vars(self), ensure_ascii=False), e use-o numa classe Filme(titulo, ano).

Ver resposta 
import json

class JsonMixin:
    def para_json(self):
        return json.dumps(vars(self), ensure_ascii=False)

class Filme(JsonMixin):
    def __init__(self, titulo, ano):
        self.titulo = titulo
        self.ano = ano

print(Filme("Central do Brasil", 1998).para_json())

{"titulo": "Central do Brasil", "ano": 1998}

4. Na hierarquia em losango A, B(A), C(A), D(C, B), em que ordem aparecem as letras se cada ola() mostra a sua letra e chama super().ola() (menos A)?

Ver resposta 
class A:
    def ola(self):
        print("A")

class B(A):
    def ola(self):
        print("B")
        super().ola()

class C(A):
    def ola(self):
        print("C")
        super().ola()

class D(C, B):
    def ola(self):
        print("D")

D().ola()

D
C
B
A

Como D herda de (C, B), a MRO é D, C, B, A: a ordem das mães entre parênteses decide.
