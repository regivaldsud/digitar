Uma caixa de ferramentas

O Python vem com centenas de ferramentas prontas — a chamada biblioteca padrão —, mas elas não ficam todas carregadas o tempo todo. Seria como carregar a caixa de ferramentas inteira para apertar um parafuso. Elas ficam guardadas em módulos, e você pega só o que precisa com import.

Um módulo é simplesmente um arquivo .py cheio de funções e variáveis que você pode usar em outro programa.

import

import math

print(math.sqrt(81))
print(math.pi)

9.0
3.141592653589793

Depois do import math, usamos math. e o nome da ferramenta. O ponto quer dizer "a ferramenta sqrt que está dentro de math". Esse jeito é o mais claro: quem lê o código sabe exatamente de onde veio cada função.

from ... import e as

Se você vai usar poucas ferramentas muitas vezes, pode trazê-las diretamente, sem o prefixo:

from math import sqrt, pi

print(sqrt(16))
print(round(pi, 2))

4.0
3.14

Com as você dá um apelido, útil para nomes compridos:

import statistics as est
from random import randint as sortear

notas = [7.5, 8.0, 9.5, 6.0]
print(est.mean(notas))
print(est.median(notas))
print(sortear(5, 5))

7.75
7.75
5

Atenção: Evite from math import *. Ele traz tudo de uma vez, e você perde a noção de onde veio cada nome. Pior: um nome do módulo pode apagar uma variável sua com o mesmo nome sem aviso.

O módulo math

O math traz funções que vão além de + - * /:

import math

print(math.sqrt(49))        # raiz quadrada
print(math.pow(2, 10))      # potência (devolve float)
print(math.hypot(3, 4))     # hipotenusa de um triângulo retângulo
print(math.factorial(5))    # fatorial
print(math.floor(4.9))      # arredonda para baixo
print(math.ceil(4.1))       # arredonda para cima

7.0
1024.0
5.0
120
4
5

O ceil resolve problemas do dia a dia, como saber quantas vans levar numa excursão:

import math

alunos = 37
por_van = 15
print(f"Precisamos de {math.ceil(alunos / por_van)} vans")

Precisamos de 3 vans

O que tem dentro de um módulo?

A função dir lista os nomes de um módulo, e help mostra a documentação de cada um. Para não encher a tela, vamos filtrar só os nomes que começam com "s":

import math

print([nome for nome in dir(math) if nome.startswith("s")])
print(math.sqrt.__doc__)

['sin', 'sinh', 'sqrt', 'sumprod']
Return the square root of x.

Dica: A documentação completa da biblioteca padrão está em docs.python.org/pt-br/3/library. Vale a pena passear por lá: muita coisa que você pensaria em programar já está pronta.
Atenção: Nunca dê ao seu arquivo o nome de um módulo do Python, como random.py ou math.py. O import random vai achar o seu arquivo primeiro, e nada funciona. Se isso acontecer, renomeie o arquivo e apague a pasta __pycache__.

Se o nome do módulo estiver errado ou ele não estiver instalado, aparece ModuleNotFoundError:

import matematica

ModuleNotFoundError: No module named 'matematica'

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
from math import sqrt, pi

Exercícios

1. Importe o módulo math e mostre a raiz quadrada de 144 e o valor de pi com 4 casas decimais.

Ver resposta 
import math

print(math.sqrt(144))
print(round(math.pi, 4))

12.0
3.1416

2. Reescreva usando from ... import: import math e depois print(math.floor(7.8)).

Ver resposta 
from math import floor

print(floor(7.8))

7

3. Uma pizzaria corta cada pizza em 8 pedaços. Quantas pizzas pedir para 27 pessoas comerem 2 pedaços cada? Use math.ceil.

Ver resposta 
import math

pedacos = 27 * 2
print(math.ceil(pedacos / 8), "pizzas")

7 pizzas

4. Importe o módulo statistics com o apelido est e mostre a média e o maior valor mais comum (mode) das idades [12, 13, 13, 14, 12, 13].

Ver resposta 
import statistics as est

idades = [12, 13, 13, 14, 12, 13]
print(est.mean(idades))
print(est.mode(idades))

12.833333333333334
13

5. Por que um arquivo chamado random.py na sua pasta faz o import random parar de funcionar?

Ver resposta

Porque o Python procura os módulos primeiro na pasta do programa. Ele encontra o
seu random.py e importa ele no lugar do random de verdade. Renomeie o arquivo
(por exemplo, sorteio.py) e apague a pasta __pycache__.
