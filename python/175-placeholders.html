Aula 175 · Placeholders e como evitar SQL Injection

Nesta aula você vai aprender

  • O que é SQL Injection e por que é perigoso
  • Como usar placeholders ? e com nome (:nome)
  • Por que nunca montar SQL com f-string ou +

O perigo de montar SQL com texto

Imagine uma tela de login que monta o comando juntando textos. Se alguém digitar um "nome" esperto, ele muda o sentido do SQL. Isso se chama SQL Injection e é uma das falhas de segurança mais comuns do mundo:

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE usuarios (nome TEXT, senha TEXT)")
con.execute("INSERT INTO usuarios VALUES ('ana', 'segredo123')")

nome = "qualquer' OR '1'='1"
sql = f"SELECT * FROM usuarios WHERE nome = '{nome}'"
print(sql)
print("Linhas encontradas:", len(con.execute(sql).fetchall()))
con.close()

SELECT * FROM usuarios WHERE nome = 'qualquer' OR '1'='1'
Linhas encontradas: 1

O texto digitado fechou a aspa e acrescentou OR '1'='1', que é sempre verdadeiro. Resultado: o comando devolve usuários sem saber o nome certo.

Atenção: Nunca monte comandos SQL com f-string, + ou format usando dados que vieram do usuário, de um formulário ou de um arquivo.

A solução: placeholders

Com o placeholder ?, você manda o comando e os valores separados. O banco trata o valor sempre como dado, nunca como parte do comando:

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE usuarios (nome TEXT, senha TEXT)")
con.execute("INSERT INTO usuarios VALUES (?, ?)", ("ana", "segredo123"))

nome = "qualquer' OR '1'='1"
linhas = con.execute("SELECT * FROM usuarios WHERE nome = ?", (nome,)).fetchall()
print("Linhas encontradas:", len(linhas))
print(con.execute("SELECT nome FROM usuarios WHERE nome = ?", ("ana",)).fetchall())
con.close()

Linhas encontradas: 0
[('ana',)]

Placeholders com nome

Quando há muitos valores, use :nome e passe um dicionário. Fica mais fácil de ler:

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE contatos (nome TEXT, cidade TEXT, telefone TEXT)")
contato = {"nome": "Beto", "cidade": "Belém", "telefone": "(91) 90000-0000"}
con.execute("INSERT INTO contatos VALUES (:nome, :cidade, :telefone)", contato)
print(con.execute("SELECT * FROM contatos WHERE cidade = :c", {"c": "Belém"}).fetchone())
con.close()

('Beto', 'Belém', '(91) 90000-0000')

Dica: Placeholders servem só para valores. Nomes de tabela ou de coluna não podem ser ?. Se precisar escolher a coluna, confira o nome contra uma lista de nomes permitidos.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
con.execute("SELECT * FROM usuarios WHERE nome = ?", (nome,))

Exercícios

1. Reescreva este código de forma segura: con.execute(f"DELETE FROM alunos WHERE nome = '{nome}'"). Teste com uma tabela de dois alunos.

Ver resposta 
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE alunos (nome TEXT)")
con.executemany("INSERT INTO alunos VALUES (?)", [("Ana",), ("Caio",)])
nome = "Ana"
con.execute("DELETE FROM alunos WHERE nome = ?", (nome,))
print(con.execute("SELECT * FROM alunos").fetchall())
con.close()

[('Caio',)]

2. Insira três produtos com executemany e placeholders com nome, usando uma lista de dicionários.

Ver resposta 
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE produtos (nome TEXT, preco REAL)")
lista = [
    {"nome": "Açaí", "preco": 15.0},
    {"nome": "Tapioca", "preco": 8.0},
    {"nome": "Pastel", "preco": 7.5},
]
con.executemany("INSERT INTO produtos VALUES (:nome, :preco)", lista)
print(con.execute("SELECT COUNT(*), SUM(preco) FROM produtos").fetchone())
