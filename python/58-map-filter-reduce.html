Programação funcional em três palavras

Muitos problemas com listas são uma destas três tarefas: transformar cada item (map), escolher alguns itens (filter) ou juntar tudo num resultado só (reduce). O Python tem uma função para cada uma. Todas recebem outra função como argumento — muitas vezes uma lambda (aula 49).

map: transformar cada item

map(funcao, itens) aplica a função a cada item. Ele devolve um objeto "preguiçoso", por isso usamos list() para ver o resultado:

precos = [10.0, 25.0, 40.0]
com_aumento = list(map(lambda p: round(p * 1.1, 2), precos))
print(com_aumento)

idades_texto = ["12", "15", "13"]
idades = list(map(int, idades_texto))
print(idades, sum(idades))

[11.0, 27.5, 44.0]
[12, 15, 13] 40

Repare no segundo exemplo: dá para passar qualquer função, inclusive as prontas, como int, str ou len. Sem parênteses! Você passa a função, não o resultado dela.

filter: escolher itens

filter(funcao, itens) mantém só os itens para os quais a função devolve um valor verdadeiro:

idades = [9, 15, 12, 18, 21]
maiores = list(filter(lambda i: i >= 18, idades))
print(maiores)

nomes = ["Ana", "", "Bruno", "", "Carla"]
print(list(filter(None, nomes)))

[18, 21]
['Ana', 'Bruno', 'Carla']

Com None no lugar da função, o filter tira os valores "falsos", como textos vazios e zeros (você vê isso em detalhes na aula 51).

Atenção: O resultado de map e filter só pode ser percorrido uma vez. Se você fizer list(r) duas vezes, a segunda dá []. Guarde o resultado numa lista se for usar de novo.
pares = filter(lambda n: n % 2 == 0, [1, 2, 3, 4])
print(list(pares))
print(list(pares))

[2, 4]
[]

reduce: juntar tudo num valor

reduce (do módulo functools) pega os dois primeiros itens, aplica a função, depois junta o resultado com o terceiro, e assim por diante, até sobrar um valor só:

from functools import reduce

numeros = [3, 5, 2, 4]
produto = reduce(lambda acumulado, n: acumulado * n, numeros)
print(produto)

palavras = ["Python", "é", "muito", "legal"]
frase = reduce(lambda a, b: a + " " + b, palavras)
print(frase)

120
Python é muito legal

Passo a passo do produto: 3 × 5 = 15, 15 × 2 = 30, 30 × 4 = 120.

Dica: Para somar, achar o maior ou juntar textos já existem sum, max e " ".join(...), que são mais claros. Guarde o reduce para contas que não têm uma função pronta.

partial: funções pré-configuradas

partial cria uma nova função a partir de outra, com alguns argumentos já preenchidos:

from functools import partial

def preco_com_desconto(preco, desconto):
    return round(preco * (1 - desconto), 2)

black_friday = partial(preco_com_desconto, desconto=0.5)
cupom_dez = partial(preco_com_desconto, desconto=0.1)

print(black_friday(199.90))
print(cupom_dez(199.90))

print(list(map(black_friday, [40, 60, 100])))

99.95
179.91
[20.0, 30.0, 50.0]

Compreensão ou map/filter?

As compreensões da aula 50 fazem o mesmo trabalho e costumam ser mais fáceis de ler:

precos = [10, 25, 40, 5]

print(list(map(lambda p: p * 2, filter(lambda p: p > 8, precos))))
print([p * 2 for p in precos if p > 8])

[20, 50, 80]
[20, 50, 80]

Os dois dão o mesmo resultado. Use o que ficar mais claro: map(int, lista) é ótimo; já map com lambda comprida dentro de filter costuma ficar melhor como compreensão.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
total = reduce(lambda a, b: a + b, valores)

Exercícios

1. Use map para transformar ["ana", "bruno", "carla"] em nomes com a primeira letra maiúscula.

Ver resposta 
nomes = ["ana", "bruno", "carla"]
print(list(map(str.capitalize, nomes)))

['Ana', 'Bruno', 'Carla']

2. Use filter para pegar só as palavras com mais de 4 letras de ["sol", "praia", "mar", "coqueiro", "areia"].

Ver resposta 
palavras = ["sol", "praia", "mar", "coqueiro", "areia"]
print(list(filter(lambda p: len(p) > 4, palavras)))

['praia', 'coqueiro', 'areia']

3. Use reduce para achar o maior número de [17, 42, 8, 33] sem usar max.

Ver resposta 
from functools import reduce

numeros = [17, 42, 8, 33]
print(reduce(lambda a, b: a if a > b else b, numeros))

42

4. Converta as temperaturas em Celsius [0, 25, 37, 100] para Fahrenheit com map (F = C × 1,8 + 32).

Ver resposta 
celsius = [0, 25, 37, 100]
print(list(map(lambda c: c * 1.8 + 32, celsius)))

[32.0, 77.0, 98.60000000000001, 212.0]

5. Crie com partial a função potencia_de_dois(expoente), a partir de uma função potencia(base, expoente), e mostre 2 elevado a 0 até 8.

Ver resposta 
from functools import partial

def potencia(base, expoente):
    return base ** expoente

potencia_de_dois = partial(potencia, 2)
print([potencia_de_dois(e) for e in range(9)])

[1, 2, 4, 8, 16, 32, 64, 128, 256]
