Aula 50 · List, dict e set comprehension (mapear e filtrar)

Nesta aula você vai aprender

  • Criar listas com compreensão de lista
  • Transformar (mapear) e filtrar itens com if
  • Escolher entre dois valores com if/else dentro da compreensão
  • Criar dicionários e conjuntos com compreensão
  • Saber quando um for comum é mais claro

Do for à compreensão

Muitas vezes criamos uma lista vazia e enchemos com append num for. A compreensão de lista faz isso numa linha só:

quadrados = []
for n in range(1, 6):
    quadrados.append(n * n)
print(quadrados)

quadrados = [n * n for n in range(1, 6)]
print(quadrados)

[1, 4, 9, 16, 25]
[1, 4, 9, 16, 25]

Leia assim: "n * n para cada n em range(1, 6)". Primeiro vem o que você quer guardar, depois o for.

Mapear: transformar cada item

Aplicar a mesma transformação em todos os itens se chama mapear:

precos = [10.0, 25.5, 8.0]
print([round(p * 0.9, 2) for p in precos])
nomes = ["ana", "bruno", "carla"]
print([nome.capitalize() for nome in nomes])
print([len(nome) for nome in nomes])

[9.0, 22.95, 7.2]
['Ana', 'Bruno', 'Carla']
[3, 5, 5]

Filtrar com if

Coloque um if no fim para guardar só os itens que passam no teste:

numeros = [4, 7, 10, 13, 16, 19]
pares = [n for n in numeros if n % 2 == 0]
print(pares)
palavras = ["sol", "abacaxi", "mar", "computador"]
print([p.upper() for p in palavras if len(p) > 3])

[4, 10, 16]
['ABACAXI', 'COMPUTADOR']

Se em vez de filtrar você quer escolher entre dois valores, o if/else (o ternário da aula 30) vai no começo:

notas = [5.5, 8.0, 9.5, 6.0]
print(["aprovado" if n >= 7 else "recuperação" for n in notas])

['recuperação', 'aprovado', 'aprovado', 'recuperação']

Atenção: if sozinho vai depois do for (filtra). if ... else vai antes do for (escolhe o valor). Trocar os lugares dá SyntaxError.

Compreensão de dicionário e de conjunto

Com chaves {} e chave: valor, você cria um dicionário. Com chaves e só um valor, cria um conjunto:

frutas = ["uva", "caju", "melancia"]
print({fruta: len(fruta) for fruta in frutas})
precos = {"pão": 0.8, "leite": 5.5, "queijo": 32.0}
print({item: valor for item, valor in precos.items() if valor > 5})
iniciais = {nome[0] for nome in ["Ana", "Alice", "Bruno"]}
print(sorted(iniciais))

{'uva': 3, 'caju': 4, 'melancia': 8}
{'leite': 5.5, 'queijo': 32.0}
['A', 'B']

Dois for e quando não usar

Uma compreensão pode ter dois for, na mesma ordem em que você os escreveria aninhados. Isso serve, por exemplo, para "achatar" uma lista de listas:

turmas = [["Ana", "Caio"], ["Lia"], ["Rui", "Bia"]]
todos = [aluno for turma in turmas for aluno in turma]
print(todos)

['Ana', 'Caio', 'Lia', 'Rui', 'Bia']

Mas cuidado: compreensões deixam o código curto, não devem deixá-lo difícil. Se a linha ficar comprida, com vários for e if, um for comum é mais fácil de ler e de corrigir.

Dica: Compreensões servem para criar coleções. Se você precisa de print ou de várias ações para cada item, use um for comum.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
pares = [n for n in range(20) if n % 2 == 0]

Exercícios

1. Use uma compreensão de lista para criar a lista dos cubos de 1 a 5 ([1, 8, 27, 64, 125]).

Ver resposta 
cubos = [n ** 3 for n in range(1, 6)]
print(cubos)

[1, 8, 27, 64, 125]

2. Dada a lista de temperaturas em Celsius [0, 25, 30, 37], crie uma lista em Fahrenheit (F = C x 9 / 5 + 32).

Ver resposta 
celsius = [0, 25, 30, 37]
fahrenheit = [c * 9 / 5 + 32 for c in celsius]
print(fahrenheit)

[32.0, 77.0, 86.0, 98.6]

3. Da lista ["Ana", "Bernardo", "Léo", "Valentina", "Gabi"], crie uma lista só com os nomes de até 4 letras.

Ver resposta 
nomes = ["Ana", "Bernardo", "Léo", "Valentina", "Gabi"]
print([nome for nome in nomes if len(nome) <= 4])

['Ana', 'Léo', 'Gabi']

4. A partir de estoque = {"lápis": 40, "caneta": 0, "borracha": 15, "cola": 0}, crie uma lista com os produtos que acabaram e um dicionário só com os que ainda têm estoque.

Ver resposta 
estoque = {"lápis": 40, "caneta": 0, "borracha": 15, "cola": 0}
acabaram = [item for item, qtd in estoque.items() if qtd == 0]
tem = {item: qtd for item, qtd in estoque.items() if qtd > 0}
print(acabaram)
print(tem)

['caneta', 'cola']
{'lápis': 40, 'borracha': 15}

5. Para os números de 1 a 6, crie uma lista que diga "par" ou "ímpar" para cada um.

Ver resposta 
print(["par" if n % 2 == 0 else "ímpar" for n in range(1, 7)])

['ímpar', 'par', 'ímpar', 'par', 'ímpar', 'par']
