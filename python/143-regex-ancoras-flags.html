Aula 143 · Âncoras, flags e modo verboso

Nesta aula você vai aprender

  • Usar as âncoras ^, $ e \b

  • Mudar a busca com as flags re.IGNORECASE e re.MULTILINE
  • Escrever regex longas e comentadas com re.VERBOSE
  • Reaproveitar padrões com re.compile

Âncoras: onde o padrão está

Âncoras não pegam nenhum caractere; elas marcam uma posição:

  • ^: o começo do texto.
  • $: o fim do texto.
  • \b: uma borda de palavra (entre uma letra e um espaço, pontuação, começo ou fim).
import re

print(re.search(r"^Bom", "Bom dia!"))
print(re.search(r"^dia", "Bom dia!"))
print(re.findall(r"\bsol\b", "sol, solidão, girassol, o sol"))

<re.Match object; span=(0, 3), match='Bom'>
None
['sol', 'sol']

Sem o \b, o padrão sol também acharia o pedaço dentro de "solidão" e "girassol".

Validando o texto inteiro: fullmatch

Para validar (o texto todo tem que seguir o formato), use re.fullmatch. Ele só aceita se o padrão cobrir o texto do começo ao fim, como se tivesse ^ e $:

import re

for cep in ["01310-100", "1310-100", "01310-1000", "CEP 01310-100"]:
    valido = re.fullmatch(r"\d{5}-\d{3}", cep) is not None
    print(f"{cep:>15}: {valido}")

      01310-100: True
       1310-100: False
     01310-1000: False
  CEP 01310-100: False

Atenção: re.search(r"\d{5}-\d{3}", "01310-1000") acha um pedaço válido dentro do texto errado! Para validar, use fullmatch (ou ^...$), nunca só search.

Flags: mudando o jeito de procurar

Flags são opções passadas no fim da chamada:

  • re.IGNORECASE (ou re.I): ignora maiúsculas e minúsculas.
  • re.MULTILINE (ou re.M): ^ e $ passam a valer em cada linha, não só no texto inteiro.
import re

print(re.findall(r"python", "Python, PYTHON e python", re.IGNORECASE))

lista = """Arroz
- feijão (acabou)
Farinha
- óleo (acabou)"""
print(re.findall(r"^- (\w+)", lista, re.MULTILINE))

['Python', 'PYTHON', 'python']
['feijão', 'óleo']

Para usar duas flags, junte com |: re.I | re.M.

Modo verboso e re.compile

Regex longas viram uma sopa de símbolos. Com re.VERBOSE (ou re.X), você pode quebrar o padrão em linhas, com espaços e comentários #, que são ignorados. E re.compile guarda o padrão pronto para usar várias vezes:

import re

HORARIO = re.compile(r"""
    ([01]\d|2[0-3])   # horas: 00 a 23
    :                 # dois-pontos
    ([0-5]\d)         # minutos: 00 a 59
""", re.VERBOSE)

for texto in ["08:30", "23:59", "24:00", "7:5"]:
    print(texto, "válido" if HORARIO.fullmatch(texto) else "inválido")

08:30 válido
23:59 válido
24:00 inválido
7:5 inválido

Dica: No modo verboso os espaços são ignorados. Para procurar um espaço de verdade, use \s ou [ ].
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
padrao = re.compile(r"^\d{5}-\d{3}$")

3. Ache todas as linhas que começam com um número no texto abaixo, usando re.MULTILINE. O texto é "1 ovo\nfarinha\n2 xícaras de leite\nsal".

Ver resposta 
import re

receita = "1 ovo\nfarinha\n2 xícaras de leite\nsal"
print(re.findall(r"^\d+ .*$", receita, re.MULTILINE))

['1 ovo', '2 xícaras de leite']
