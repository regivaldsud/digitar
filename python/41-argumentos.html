Argumentos posicionais: a ordem importa

Quando você chama funcao(a, b), o primeiro argumento vai para o primeiro parâmetro, o segundo para o segundo, e assim por diante. Esses são os argumentos posicionais. Trocar a ordem não dá erro — mas pode dar resultado errado:

def dividir_conta(total, pessoas):
    return total / pessoas

print(dividir_conta(120, 4))
print(dividir_conta(4, 120))

30.0
0.03333333333333333

A segunda chamada calculou 4 dividido por 120. O Python não tem como saber que você trocou os valores.

Valores padrão

Às vezes um parâmetro quase sempre recebe o mesmo valor. Você pode deixá-lo como padrão usando = no def. Se quem chama não informar, o padrão é usado:

def pedir_pizza(sabor, tamanho="média"):
    print(f"Uma pizza {tamanho} de {sabor}, por favor!")

pedir_pizza("calabresa")
pedir_pizza("portuguesa", "grande")

Uma pizza média de calabresa, por favor!
Uma pizza grande de portuguesa, por favor!

Você já conhece uma função com valores padrão: o print (aula 10)! Ele tem sep=" " e end="\n" escondidos:

print("A", "B", "C")
print("A", "B", "C", sep="-")
print("Carregando", end="...")
print(" pronto!")

A B C
A-B-C
Carregando... pronto!

Argumentos nomeados

Na chamada, você pode dizer o nome do parâmetro: nome=valor. Assim a ordem não importa e o código se explica sozinho:

def cadastrar(nome, idade, cidade):
    print(f"{nome}, {idade} anos, mora em {cidade}")

cadastrar("Rafael", 14, "Manaus")
cadastrar(cidade="Curitiba", nome="Bia", idade=12)
cadastrar("Leo", cidade="Natal", idade=13)

Rafael, 14 anos, mora em Manaus
Bia, 12 anos, mora em Curitiba
Leo, 13 anos, mora em Natal

Dica: Argumentos nomeados ajudam muito quando a função recebe vários números ou True/False. Compare parcelar(1200, 10, True) com parcelar(1200, parcelas=10, com_juros=True): o segundo dá para entender sem abrir a função.

Regras de ordem

Duas regras evitam erros:

  • No def, os parâmetros com padrão vêm depois dos parâmetros sem padrão.
  • Na chamada, os argumentos posicionais vêm antes dos nomeados.
def errado(tamanho="média", sabor):   # SyntaxError: parâmetro sem padrão depois de um com padrão
    pass
def cadastrar(nome, idade):
    print(nome, idade)

cadastrar(nome="Leo", 13)

SyntaxError: positional argument follows keyword argument

Também não dá para passar o mesmo parâmetro duas vezes:

def cadastrar(nome, idade):
    print(nome, idade)

cadastrar("Leo", nome="Léo")

TypeError: cadastrar() got multiple values for argument 'nome'

Atenção: A mensagem got multiple values for argument 'nome' quer dizer que o parâmetro recebeu um valor pela posição e outro pelo nome. Confira a ordem dos seus argumentos.

def pedir(sabor, tamanho="média"):

Exercícios

1. Crie a função saudacao(nome, periodo="dia") que mostre Bom dia, Ana! por padrão, ou Boa noite, Ana! se periodo for "noite".

Ver resposta 
def saudacao(nome, periodo="dia"):
    if periodo == "noite":
        print(f"Boa noite, {nome}!")
    else:
        print(f"Bom {periodo}, {nome}!")

saudacao("Ana")
saudacao("Ana", periodo="noite")

Bom dia, Ana!
Boa noite, Ana!

2. Crie a função preco_final(preco, desconto=0) que devolve o preço com o desconto (em porcentagem). Teste um tênis de R$ 200 sem desconto e com 15% de desconto, usando argumento nomeado.

Ver resposta 
def preco_final(preco, desconto=0):
    return preco - preco * desconto / 100

print(preco_final(200))
print(preco_final(200, desconto=15))

200.0
170.0

3. Use o print com sep para mostrar a data 25/12/2025 a partir dos números 25, 12 e 2025.

Ver resposta 
print(25, 12, 2025, sep="/")

25/12/2025

4. Crie a função parcelar(valor, parcelas=1, juros=0) que devolve o valor de cada parcela, onde juros é a porcentagem somada ao total. Mostre uma bicicleta de R$ 1200 à vista, em 10 vezes sem juros e em 10 vezes com 5% de juros, usando argumentos nomeados.

Ver resposta 
def parcelar(valor, parcelas=1, juros=0):
    total = valor + valor * juros / 100
    return total / parcelas

print(parcelar(1200))
print(parcelar(1200, parcelas=10))
print(parcelar(1200, parcelas=10, juros=5))

1200.0
120.0
126.0

5. Por que cadastrar(idade=13, "Leo") dá erro, se a função é def cadastrar(nome, idade)? Corrija a chamada de duas formas.

Ver resposta 
def cadastrar(nome, idade):
    print(nome, idade)

cadastrar("Leo", idade=13)
cadastrar(idade=13, nome="Leo")

Leo 13
Leo 13

Um argumento posicional não pode vir depois de um nomeado. Ou o "Leo" vem primeiro, ou ele também recebe nome.
