O básico: comparar com valores

O match olha um valor e testa os case de cima para baixo. O primeiro que combinar é executado, e os outros são ignorados. O case _ é o curinga: combina com qualquer coisa, como o else de um if.

def dia_util(dia):
    match dia:
        case "sábado" | "domingo":
            return "fim de semana"
        case "segunda" | "terça" | "quarta" | "quinta" | "sexta":
            return "dia de aula"
        case _:
            return "dia desconhecido"


print(dia_util("sábado"))
print(dia_util("quarta"))
print(dia_util("feriado"))

fim de semana
dia de aula
dia desconhecido

A barra | junta várias opções num mesmo case.

Atenção: match e case só existem a partir do Python 3.10. Num Python mais antigo, o código dá SyntaxError. Confira sua versão com python --version (aula 02).

Capturando partes de uma sequência

O match brilha quando o valor tem forma: uma lista ou tupla com certo número de itens. Um nome dentro do padrão vira uma variável que recebe aquela parte:

def executar(comando):
    match comando.split():
        case ["sair"]:
            return "Tchau!"
        case ["ir", direcao]:
            return f"Andando para o {direcao}."
        case ["pegar", item, "e", outro]:
            return f"Pegou {item} e {outro}."
        case ["falar", *palavras]:
            return "Disse: " + " ".join(palavras)
        case _:
            return "Não entendi."


print(executar("ir norte"))
print(executar("pegar chave e mapa"))
print(executar("falar bom dia pessoal"))
print(executar("sair"))
print(executar("dançar"))

Andando para o norte.
Pegou chave e mapa.
Disse: bom dia pessoal
Tchau!
Não entendi.

*palavras captura "o resto" da lista, do mesmo jeito que no desempacotamento (aula 43).

Padrões com dicionários

Um padrão de dicionário confere se as chaves existem e captura os valores. Chaves a mais no dicionário não atrapalham:

def descrever(evento):
    match evento:
        case {"tipo": "gol", "time": time, "minuto": minuto}:
            return f"Gol do {time} aos {minuto} minutos!"
        case {"tipo": "cartao", "cor": "vermelho", "jogador": jogador}:
            return f"{jogador} foi expulso."
        case {"tipo": "cartao", "jogador": jogador}:
            return f"{jogador} levou cartão amarelo."
        case _:
            return "Lance comum."


print(descrever({"tipo": "gol", "time": "Bahia", "minuto": 37, "placar": "1x0"}))
print(descrever({"tipo": "cartao", "cor": "vermelho", "jogador": "Zé"}))
print(descrever({"tipo": "cartao", "cor": "amarelo", "jogador": "Bruno"}))
print(descrever({"tipo": "escanteio"}))

Gol do Bahia aos 37 minutos!
Zé foi expulso.
Bruno levou cartão amarelo.
Lance comum.

Dica: A ordem dos case importa: o caso mais específico (cartão vermelho) vem antes do mais geral (qualquer cartão).

Padrões com classes e guardas

Com objetos, o padrão parece uma chamada: Ponto(x=0, y=0) confere o tipo e os atributos. E um if depois do padrão, chamado guarda, acrescenta uma condição:

from dataclasses import dataclass


@dataclass
class Ponto:
    x: int
    y: int


def onde_esta(p):
    match p:
        case Ponto(x=0, y=0):
            return "na origem"
        case Ponto(x=0, y=y):
            return f"no eixo y, altura {y}"
        case Ponto(x=x, y=0):
            return f"no eixo x, posição {x}"
        case Ponto(x=x, y=y) if x == y:
            return "na diagonal"
        case Ponto():
            return "em algum lugar do plano"


for p in [Ponto(0, 0), Ponto(0, 5), Ponto(3, 0), Ponto(2, 2), Ponto(4, 1)]:
    print(p, "->", onde_esta(p))

Ponto(x=0, y=0) -> na origem
Ponto(x=0, y=5) -> no eixo y, altura 5
Ponto(x=3, y=0) -> no eixo x, posição 3
Ponto(x=2, y=2) -> na diagonal
Ponto(x=4, y=1) -> em algum lugar do plano

O @dataclass (aula 88) cria a classe com __init__ e __repr__ prontos, ótima para usar com match.

Cuidado: nome solto captura tudo

Um nome sozinho num case não compara com uma variável: ele captura o valor. Para comparar com constantes, use nomes com ponto, como os de um Enum (aula 87):

from enum import Enum


class Cor(Enum):
    VERMELHO = "vermelho"
    VERDE = "verde"


def semaforo(cor):
    match cor:
        case Cor.VERMELHO:
            return "Pare!"
        case Cor.VERDE:
            return "Siga."
        case outra:
            return f"Cor sem regra: {outra}"


print(semaforo(Cor.VERMELHO))
print(semaforo(Cor.VERDE))
print(semaforo("amarelo"))

Pare!
Siga.
Cor sem regra: amarelo

Se você escrevesse case VERMELHO: (sem Cor.), esse case combinaria com qualquer valor e o Python ainda reclamaria que os casos de baixo nunca seriam alcançados.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
match comando.split():

1. Escreva nota_conceito(nota) com match que devolva "A" para 10 e 9, "B" para 8 e 7, "C" para 6 e 5 e "D" para o resto (as notas são inteiras).

Ver resposta 
def nota_conceito(nota):
    match nota:
        case 10 | 9:
            return "A"
        case 8 | 7:
            return "B"
        case 6 | 5:
            return "C"
        case _:
            return "D"


for n in [10, 7, 5, 2]:
    print(n, nota_conceito(n))

2. Faça uma calculadora que recebe uma tupla como (3, "+", 4) e usa match para fazer a conta com +, -, * e /, avisando divisão por zero.

Ver resposta 
def calcular(expressao):
    match expressao:
        case (a, "+", b):
            return a + b
        case (a, "-", b):
            return a - b
        case (a, "*", b):
            return a * b
        case (a, "/", 0):
            return "não dá para dividir por zero"
        case (a, "/", b):
            return a / b
        case _:
            return "operação desconhecida"


print(calcular((3, "+", 4)))
print(calcular((10, "/", 4)))
print(calcular((5, "/", 0)))
print(calcular((2, "^", 3)))

7
2.5
não dá para dividir por zero
operação desconhecida

3. Use match com padrões de dicionário para responder pedidos de lanchonete: {"item": "suco", "sabor": s} vira "Suco de s", {"item": "pastel", "recheio": r} vira "Pastel de r", e qualquer outro pedido vira "Pedido inválido".

Ver resposta 
def preparar(pedido):
    match pedido:
        case {"item": "suco", "sabor": sabor}:
            return f"Suco de {sabor}"
        case {"item": "pastel", "recheio": recheio}:
            return f"Pastel de {recheio}"
        case _:
            return "Pedido inválido"


print(preparar({"item": "suco", "sabor": "cajá"}))
print(preparar({"item": "pastel", "recheio": "queijo"}))
print(preparar({"item": "bolo"}))

Suco de cajá
Pastel de queijo
Pedido inválido

4. Use um case com guarda para classificar a idade recebida numa lista ["idade", n]: menos de 12 é "criança", de 12 a 17 "adolescente" e 18 ou mais "adulto".

Ver resposta 
def classificar(dado):
    match dado:
        case ["idade", n] if n < 12:
            return "criança"
        case ["idade", n] if n < 18:
            return "adolescente"
        case ["idade", n]:
            return "adulto"
        case _:
            return "dado inválido"


print(classificar(["idade", 8]))
print(classificar(["idade", 15]))
print(classificar(["idade", 40]))
print(classificar(["altura", 1.6]))

criança
adolescente
adulto
dado inválido
