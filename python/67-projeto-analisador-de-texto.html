Nesta aula você vai aprender

  • Limpar um texto: minúsculas, sem pontuação e sem acentos
  • Remover acentos com o módulo unicodedata
  • Contar palavras e letras com collections.Counter
  • Mostrar o "top 5" e um gráfico de barras feito com caracteres

O que vamos construir

Que palavra aparece mais num texto? Qual letra você mais digita? Essas perguntas são importantes até para quem cria teclados e cursos de digitação: as letras mais usadas do português (como a, e e o) ficam em posições fáceis de alcançar.

Nosso analisador vai receber um texto e mostrar: total de palavras, palavras diferentes, as 5 palavras mais frequentes e as 5 letras mais frequentes.

Passo 1: separar as palavras

O método split() corta o texto nos espaços (e nas quebras de linha):

texto = "O rato roeu a roupa do rei de Roma."
palavras = texto.split()
print(palavras)
print("Total de palavras:", len(palavras))

['O', 'rato', 'roeu', 'a', 'roupa', 'do', 'rei', 'de', 'Roma.']
Total de palavras: 9

Repare no problema: a última palavra veio como 'Roma.', com o ponto grudado. E "O" e "o" seriam contadas como palavras diferentes. Precisamos limpar o texto antes.

Passo 2: minúsculas e sem pontuação

O módulo string tem uma lista pronta de sinais de pontuação. Com str.maketrans montamos uma "tabela" que apaga esses sinais, e translate aplica a tabela:

import string

print(string.punctuation)

texto = "Olá! Tudo bem? Tudo ótimo, e você?"
tabela = str.maketrans("", "", string.punctuation)
limpo = texto.lower().translate(tabela)
print(limpo)
print(limpo.split())

!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~
olá tudo bem tudo ótimo e você
['olá', 'tudo', 'bem', 'tudo', 'ótimo', 'e', 'você']

Atenção: string.punctuation só tem os sinais do teclado americano. Travessão (—), reticências (…) e aspas curvas (“ ”) não estão lá. Por isso, no programa final, vamos somar esses sinais à lista.

Passo 3: tirar os acentos

Para o computador, "você" e "voce" são palavras diferentes. Para contar letras, também queremos que "á", "ã" e "a" contem como a. O módulo unicodedata resolve: a forma "NFD" separa cada letra do seu acento, e depois jogamos fora os acentos (a categoria "Mn" é a das marcas que ficam "em cima" das letras):

import unicodedata


def sem_acentos(texto):
    decomposto = unicodedata.normalize("NFD", texto)
    return "".join(c for c in decomposto if unicodedata.category(c) != "Mn")


print(sem_acentos("Ação, coração, pão e café"))
print(len("ã"), len(unicodedata.normalize("NFD", "ã")))

Acao, coracao, pao e cafe
1 2

O "ã" tem 1 caractere, mas na forma NFD vira 2: a letra "a" e o til. O "ç" também vira "c" + cedilha.

Passo 4: contar com Counter

Contar coisas é tão comum que o Python tem uma ferramenta pronta: Counter, do módulo collections. Ele funciona como um dicionário em que cada item aponta para quantas vezes apareceu:

from collections import Counter

palavras = "o rato roeu a roupa do rei de roma o rato".split()
contagem = Counter(palavras)
print(contagem["rato"])
print(contagem["gato"])
print(contagem.most_common(3))

2
0
[('o', 2), ('rato', 2), ('roeu', 1)]

  • contagem["gato"] dá 0 em vez de erro, porque o Counter sabe que algo que nunca apareceu tem contagem zero.
  • most_common(3) devolve os 3 mais frequentes, do maior para o menor. Em caso de empate, vem primeiro quem apareceu primeiro.

Passo 5: contar letras

Um texto também é uma sequência de caracteres. Basta ficar só com as letras usando isalpha():

from collections import Counter

texto = "Abacaxi, banana e maracujá"
letras = Counter(c for c in texto.lower() if c.isalpha())
print(letras.most_common(3))

[('a', 8), ('b', 2), ('c', 2)]

Repare que o "á" de maracujá ficou separado do "a". No programa final, tiramos os acentos antes de contar.

Passo 6: juntar tudo numa função

Vamos criar analisar(texto), que devolve um dicionário com os resultados, e relatorio(dados), que mostra tudo bonito, com barras de #:

import string
import unicodedata
from collections import Counter

PONTUACAO = string.punctuation + "—–“”‘’…«»"


def sem_acentos(texto):
    decomposto = unicodedata.normalize("NFD", texto)
    return "".join(c for c in decomposto if unicodedata.category(c) != "Mn")


def limpar(texto):
    texto = sem_acentos(texto.lower())
    return texto.translate(str.maketrans("", "", PONTUACAO))


def analisar(texto):
    palavras = limpar(texto).split()
    letras = [c for c in "".join(palavras) if c.isalpha()]
    return {
        "total_palavras": len(palavras),
        "palavras_diferentes": len(set(palavras)),
        "top_palavras": Counter(palavras).most_common(5),
        "top_letras": Counter(letras).most_common(5),
    }


def relatorio(dados):
    print("Total de palavras:", dados["total_palavras"])
    print("Palavras diferentes:", dados["palavras_diferentes"])
    print("Palavras mais frequentes:")
    for palavra, vezes in dados["top_palavras"]:
        print(f"  {palavra:<10} {'#' * vezes} {vezes}")
    print("Letras mais frequentes:")
    for letra, vezes in dados["top_letras"]:
        print(f"  {letra}  {'#' * vezes} {vezes}")


texto = """O Brasil tem praias lindas e florestas enormes.
No Brasil, o futebol é paixão — e a comida também:
feijoada, acarajé, pão de queijo e açaí!"""
relatorio(analisar(texto))

  o          ## 2

  tem        # 1
  praias     # 1

Repare que "é" virou "e" depois de tirar os acentos, e por isso o "e" apareceu 4 vezes. Para contar letras isso é ótimo; para palavras, às vezes junta coisas diferentes. Todo programa tem escolhas assim, e tudo bem.

O {palavra:<10} dentro da f-string alinha a palavra à esquerda num espaço de 10 caracteres, para as barras ficarem uma embaixo da outra no terminal.

Passo 7: o programa completo

A versão final pergunta o texto. Se o que você digitar terminar em .txt, o programa tenta abrir esse arquivo — assim dá para analisar uma redação inteira ou um livro baixado em texto puro.

import string
import unicodedata
from collections import Counter

PONTUACAO = string.punctuation + "—–“”‘’…«»"


def sem_acentos(texto):
    decomposto = unicodedata.normalize("NFD", texto)
    return "".join(c for c in decomposto if unicodedata.category(c) != "Mn")


def limpar(texto):
    texto = sem_acentos(texto.lower())
    return texto.translate(str.maketrans("", "", PONTUACAO))


def analisar(texto):
    palavras = limpar(texto).split()
    letras = [c for c in "".join(palavras) if c.isalpha()]
    return {
        "total_palavras": len(palavras),
        "palavras_diferentes": len(set(palavras)),
        "top_palavras": Counter(palavras).most_common(5),
        "top_letras": Counter(letras).most_common(5),
    }


def relatorio(dados):
    print()
    print("Total de palavras:", dados["total_palavras"])
    print("Palavras diferentes:", dados["palavras_diferentes"])
    print("Palavras mais frequentes:")
    for palavra, vezes in dados["top_palavras"]:
        print(f"  {palavra:<10} {'#' * vezes} {vezes}")
    print("Letras mais frequentes:")
    for letra, vezes in dados["top_letras"]:
        print(f"  {letra}  {'#' * vezes} {vezes}")


def ler_texto():
    entrada = input("Digite um texto ou o nome de um arquivo .txt: ").strip()
    if entrada.endswith(".txt"):
        try:
            with open(entrada, encoding="utf-8") as arquivo:
                return arquivo.read()
        except FileNotFoundError:
            print(f"Não achei o arquivo {entrada}. Vou analisar o próprio nome.")
    return entrada


def main():
    print("=== ANALISADOR DE TEXTO ===")
    texto = ler_texto()
    if not texto.strip():
        print("Texto vazio. Nada para analisar.")
        return
    relatorio(analisar(texto))


if __name__ == "__main__":
    main()

Exercícios

1. Escreva palavra_mais_longa(texto), que devolve a maior palavra do texto (sem pontuação). Dica: max aceita key=len.

Ver resposta 
import string


def palavra_mais_longa(texto):
    limpo = texto.translate(str.maketrans("", "", string.punctuation))
    return max(limpo.split(), key=len)


print(palavra_mais_longa("Paralelepípedo é uma palavra difícil de digitar!"))

Paralelepípedo

Em caso de empate, max devolve a primeira palavra mais longa que encontrar.

2. Faça o analisador ignorar palavras comuns. Crie um conjunto PALAVRAS_VAZIAS = {"o", "a", "os", "as", "de", "do", "da", "e", "um", "uma"} e mostre o top 3 sem elas.

Ver resposta 
from collections import Counter

PALAVRAS_VAZIAS = {"o", "a", "os", "as", "de", "do", "da", "e", "um", "uma"}

texto = "o gato e o cachorro brincam no quintal e o gato dorme no sofá do quintal"
palavras = [p for p in texto.split() if p not in PALAVRAS_VAZIAS]
print(Counter(palavras).most_common(3))

[('gato', 2), ('no', 2), ('quintal', 2)]

Usamos um conjunto (set) porque conferir se algo está dentro dele com in é muito rápido, mesmo com milhares de palavras.

4. Calcule a média de letras por palavra de um texto, com uma casa decimal.

Ver resposta 
import string

texto = "Quem digita bem programa mais rápido."
palavras = texto.translate(str.maketrans("", "", string.punctuation)).split()
media = sum(len(p) for p in palavras) / len(palavras)
print(f"{len(palavras)} palavras, média de {media:.1f} letras por palavra")

6 palavras, média de 5.2 letras por palavra

5. Conte quantas frases há num texto, considerando que uma frase termina em ., ! ou ?. Cuidado: reticências (...) não devem contar como três frases.

Ver resposta 
import re

texto = "Hoje tem jogo! Você vai assistir? Eu acho que sim... Vamos torcer."
frases = [f.strip() for f in re.split(r"[.!?]+", texto) if f.strip()]
print("Frases:", len(frases))
print(frases)

Frases: 4
['Hoje tem jogo', 'Você vai assistir', 'Eu acho que sim', 'Vamos torcer']

O módulo re (expressões regulares) aparece com calma na aula 140. Aqui, o re.split com [.!?]+ corta o texto em qualquer sequência de um ou mais desses sinais, então ... conta como um corte só.
