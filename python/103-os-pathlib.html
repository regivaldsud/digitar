Caminhos

Todo arquivo mora numa pasta, que mora em outra pasta... O caminho é o endereço do arquivo. No Windows ele usa barra invertida, como C:\Users\Ana\Documents\notas.txt. No Linux, no macOS e no Python do navegador, barra normal: /home/pyodide/notas.txt.

Um caminho absoluto começa da raiz do disco. Um caminho relativo, como fotos/praia.jpg, é procurado a partir da pasta atual do programa.

Dica: Os exemplos desta aula rodam num sistema de arquivos de mentira, dentro do navegador. Pode criar e apagar à vontade: nada acontece com os arquivos do seu computador, e tudo some ao recarregar a página.

pathlib.Path e o operador /

Path representa um caminho, e o operador / junta pedaços com a barra certa para cada sistema:

from pathlib import Path

arquivo = Path("escola") / "notas" / "matematica.txt"
print(arquivo)
print(arquivo.name)
print(arquivo.stem)
print(arquivo.suffix)
print(arquivo.parent)

escola/notas/matematica.txt
matematica.txt
matematica
.txt
escola/notas

No Windows, o mesmo código mostra escola\notas\matematica.txt. O programa é o mesmo; o Python cuida da diferença.

  • name: nome completo; stem: nome sem extensão;
  • suffix: a extensão com o ponto; parent: a pasta onde ele está.

Criando pastas e arquivos

from pathlib import Path

pasta = Path("diario")
print("Existe antes?", pasta.exists())
pasta.mkdir(exist_ok=True)
print("Existe depois?", pasta.exists())

pagina = pasta / "segunda.txt"
pagina.write_text("Hoje treinei digitação por 20 minutos.", encoding="utf-8")
print(pagina.read_text(encoding="utf-8"))
print("É arquivo?", pagina.is_file(), "| É pasta?", pasta.is_dir())

Existe antes? False
Existe depois? True
Hoje treinei digitação por 20 minutos.
É arquivo? True | É pasta? True

Atenção: Sem exist_ok=True, chamar mkdir numa pasta que já existe dá FileExistsError. Para criar várias pastas de uma vez (a/b/c), use também parents=True.

Listando e procurando

iterdir() percorre o que existe numa pasta e glob("*.jpg") filtra por um padrão. O * quer dizer "qualquer coisa":

from pathlib import Path

fotos = Path("fotos")
fotos.mkdir(exist_ok=True)
for nome in ["praia.jpg", "festa.png", "lista.txt", "bolo.jpg"]:
    (fotos / nome).write_text("conteúdo", encoding="utf-8")

print("Tudo:", sorted(p.name for p in fotos.iterdir()))
print("Só JPG:", sorted(p.name for p in fotos.glob("*.jpg")))

Tudo: ['bolo.jpg', 'festa.png', 'lista.txt', 'praia.jpg']
Só JPG: ['bolo.jpg', 'praia.jpg']

Usamos sorted porque a ordem em que o sistema devolve os arquivos não é garantida.

O jeito antigo: os e os.path

Antes do pathlib, tudo era feito com funções dos módulos os e os.path. Você vai encontrar muito código assim:

import os

os.makedirs("projetos/jogo", exist_ok=True)
caminho = os.path.join("projetos", "jogo", "placar.txt")
print(caminho)
print(os.path.exists(caminho))
print(os.path.basename(caminho))
print(os.path.splitext(caminho))
print(os.listdir("projetos"))

projetos/jogo/placar.txt
False
placar.txt
('projetos/jogo/placar', '.txt')
['jogo']

  • os.path.join equivale ao / do Path;
  • os.path.basename equivale a .name, e os.path.splitext separa a extensão;
  • os.listdir equivale a iterdir, e os.getcwd() mostra a pasta atual.
Dica: Em código novo, prefira pathlib: é mais legível. Mas vale reconhecer os dois, porque tutoriais antigos usam os.path o tempo todo.

Percorrendo tudo com os.walk

os.walk visita uma pasta e todas as subpastas. A cada passo ele entrega três coisas: a pasta atual, a lista de subpastas e a lista de arquivos.

import os
from pathlib import Path

for caminho in ["site/css/estilo.css", "site/index.html", "site/img/logo.png", "site/img/foto.jpg"]:
    Path(caminho).parent.mkdir(parents=True, exist_ok=True)
    Path(caminho).write_text("x", encoding="utf-8")

for pasta, subpastas, arquivos in os.walk("site"):
    subpastas.sort()
    print(pasta, "->", sorted(arquivos))

site -> ['index.html']
site/css -> ['estilo.css']
site/img -> ['foto.jpg', 'logo.png']

O subpastas.sort() deixa a visita em ordem alfabética. Com Path, o equivalente é Path("site").rglob("*"), que procura em todas as subpastas.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
caminho = Path("fotos") / "praia.jpg"

2. Crie a pasta materias com um arquivo .txt para cada matéria de ["portugues", "matematica", "historia"] e liste os arquivos em ordem alfabética.

Ver resposta 
from pathlib import Path

pasta = Path("materias")
pasta.mkdir(exist_ok=True)
for materia in ["portugues", "matematica", "historia"]:
    (pasta / f"{materia}.txt").write_text("", encoding="utf-8")

print(sorted(p.name for p in pasta.iterdir()))

['historia.txt', 'matematica.txt', 'portugues.txt']

4. Crie os arquivos escola/trabalho.pdf, escola/fotos/excursao.jpg e escola/provas/mat.pdf e use os.walk para contar quantos PDFs existem ao todo.

Ver resposta 
import os
from pathlib import Path

for caminho in ["escola/trabalho.pdf", "escola/fotos/excursao.jpg", "escola/provas/mat.pdf"]:
    Path(caminho).parent.mkdir(parents=True, exist_ok=True)
    Path(caminho).write_text("x", encoding="utf-8")

total = 0
for pasta, subpastas, arquivos in os.walk("escola"):
    total += sum(1 for nome in arquivos if nome.endswith(".pdf"))
print(total, "PDFs")

2 PDFs
