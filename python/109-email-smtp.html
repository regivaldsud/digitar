Nesta aula você vai aprender

Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Como um e-mail viaja

Quando você aperta "Enviar", o programa de e-mail entrega a mensagem a um servidor SMTP (SMTP é o protocolo, o "idioma", usado para mandar e-mails). Esse servidor passa a mensagem adiante até o servidor do destinatário, que a guarda na caixa de entrada.

O Python separa o trabalho em duas partes:

  • o módulo email monta a mensagem (assunto, remetente, texto, anexos);
  • o módulo smtplib envia, conversando com o servidor SMTP.

Montar não precisa de internet nem de conta, então os exemplos com o botão Executar montam e mostram mensagens. Só o envio de verdade fica para o seu computador.

Montando a primeira mensagem

Uma EmailMessage funciona parecido com um dicionário: os cabeçalhos (Subject, From, To) são colocados com colchetes, e o texto do corpo com set_content.

from email.message import EmailMessage

msg = EmailMessage()
msg["Subject"] = "Lembrete: entrega do trabalho"
msg["From"] = "turma7b@exemplo.com"
msg["To"] = "aluno@exemplo.com"
msg.set_content("Oi! O trabalho de ciências deve ser entregue na sexta.")

print("Assunto:", msg["Subject"])
print("Para:", msg["To"])
print("Texto:", msg.get_content())

Assunto: Lembrete: entrega do trabalho
Para: aluno@exemplo.com
Texto: Oi! O trabalho de ciências deve ser entregue na sexta.

get_content() devolve o texto do corpo. Repare que ele termina com uma quebra de linha: o padrão dos e-mails exige isso, e o Python acrescenta sozinho.

Atenção: Cada cabeçalho só pode ser colocado uma vez. Se você fizer msg["To"] = ... de novo, dá ValueError. Para trocar, apague antes com del msg["To"]; para vários destinatários, escreva todos no mesmo texto, separados por vírgula.

O que vai de verdade pela internet

Por dentro, um e-mail é só texto: uma lista de cabeçalhos, uma linha em branco e o corpo. Além dos cabeçalhos que você colocou, o set_content preenche alguns sozinho. Dá para ver todos com items():

from email.message import EmailMessage

msg = EmailMessage()
msg["Subject"] = "Reunião de pais"
msg["From"] = "escola@exemplo.com"
msg["To"] = "familia.silva@exemplo.com, familia.souza@exemplo.com"
msg["Cc"] = "coordenacao@exemplo.com"
msg.set_content("A reunião será no sábado, às 9h.")

for chave, valor in msg.items():
    print(f"{chave}: {valor}")

Subject: Reunião de pais
From: escola@exemplo.com
To: familia.silva@exemplo.com, familia.souza@exemplo.com
Cc: coordenacao@exemplo.com
Content-Type: text/plain; charset="utf-8"
Content-Transfer-Encoding: 8bit
MIME-Version: 1.0

  • Cc (cópia) manda para mais pessoas, e todos veem quem recebeu;
  • Content-Type: text/plain; charset="utf-8" avisa que o corpo é texto simples, com acentos em UTF-8;
  • Content-Transfer-Encoding diz como o corpo foi codificado para viajar. Os servidores de e-mail antigos só entendem letras sem acento, então o Python transforma o texto com acentos em códigos (e o programa de quem recebe desfaz isso). Se quiser ver o texto cru, use print(msg.as_string()).
Dica: Para mandar para muita gente sem que um veja o e-mail do outro, use o cabeçalho Bcc (cópia oculta). O send_message do smtplib entrega para quem está no Bcc e tira esse cabeçalho antes de enviar.

Versão em HTML e anexos

Um e-mail pode ter duas versões do mesmo texto: simples e em HTML (com negrito, cores e links). O programa de e-mail do destinatário mostra a melhor que conseguir. Com add_alternative você acrescenta a versão HTML; com add_attachment, um arquivo anexo.

from email.message import EmailMessage

msg = EmailMessage()
msg["Subject"] = "Boletim do 3º bimestre"
msg["From"] = "secretaria@exemplo.com"
msg["To"] = "familia@exemplo.com"
msg.set_content("Olá! Segue o boletim em anexo.")
msg.add_alternative("<p>Olá! Segue o <b>boletim</b> em anexo.</p>", subtype="html")

planilha = "materia;nota\nPortuguês;8.5\nMatemática;9.0\n".encode("utf-8")
msg.add_attachment(planilha, maintype="text", subtype="csv", filename="boletim.csv")

print("Tipo da mensagem:", msg.get_content_type())
for parte in msg.walk():
    print("-", parte.get_content_type(), parte.get_filename() or "")
for anexo in msg.iter_attachments():
    print("Anexo:", anexo.get_filename(), len(anexo.get_content()), "caracteres")

Tipo da mensagem: multipart/mixed
- multipart/mixed
- multipart/alternative
- text/plain
- text/html
- text/csv boletim.csv
Anexo: boletim.csv 44 caracteres

A mensagem virou multipart/mixed: um "envelope" com várias partes dentro. walk() percorre todas elas, e iter_attachments() só os anexos.

Para anexar um arquivo do computador, leia os bytes dele: Path("foto.jpg").read_bytes(), com maintype="image" e subtype="jpeg". Se não souber o tipo, o módulo mimetypes descobre pela extensão: mimetypes.guess_type("foto.jpg") devolve ('image/jpeg', None).

Enviando com smtplib

Para enviar, o programa abre uma conexão com o servidor SMTP do seu provedor, faz login e entrega a mensagem. No Gmail, o servidor é smtp.gmail.com, na porta 465, com conexão segura (SSL). Outros provedores usam a porta 587 com starttls(); a página de ajuda do provedor informa os dados.

Este código só funciona no seu computador, com internet e uma conta configurada. Salve como enviar.py:

import os
import smtplib
from email.message import EmailMessage

remetente = os.environ["EMAIL_USUARIO"]
senha = os.environ["EMAIL_SENHA_APP"]

msg = EmailMessage()
msg["Subject"] = "Teste do Python"
msg["From"] = remetente
msg["To"] = remetente          # mande para você mesmo
msg.set_content("Funcionou! Este e-mail foi enviado por um programa.")

with smtplib.SMTP_SSL("smtp.gmail.com", 465) as servidor:
    servidor.login(remetente, senha)
    servidor.send_message(msg)
print("Enviado!")

Enviado!

Antes de rodar, crie as variáveis de ambiente no mesmo terminal (no Windows, PowerShell; no Linux ou macOS, troque a primeira forma por export EMAIL_USUARIO="voce@gmail.com"):

$env:EMAIL_USUARIO = "voce@gmail.com"
$env:EMAIL_SENHA_APP = "abcd efgh ijkl mnop"
py enviar.py

Se der certo, aparece Enviado! e o e-mail chega na sua caixa de entrada em alguns segundos. O with fecha a conexão sozinho no fim, mesmo se acontecer um erro.

Atenção: Nunca escreva sua senha dentro do código e nunca use a senha principal da conta. Provedores como o Gmail exigem uma senha de app (criada nas configurações de segurança da conta, com a verificação em duas etapas ligada). Guarde-a numa variável de ambiente ou num .env (aula 108). Se você tem menos de 18 anos, peça ajuda a um responsável para configurar a conta.
Atenção: Erros comuns: SMTPAuthenticationError quer dizer usuário ou senha de app errados; KeyError: 'EMAIL_SENHA_APP' quer dizer que a variável de ambiente não foi criada nesse terminal; TimeoutError ou ConnectionRefusedError costumam ser servidor ou porta errados, ou uma rede que bloqueia e-mail.

Separando montar de enviar

Um truque de programador: escreva uma função que monta a mensagem e outra que envia. Assim você testa a montagem sem internet e só troca o "carteiro" na hora de enviar de verdade. Aqui o carteiro é de mentira — ele só mostra o que enviaria:

from email.message import EmailMessage

def montar_aviso(nome, email, nota):
    msg = EmailMessage()
    msg["Subject"] = f"Sua nota, {nome}"
    msg["From"] = "professora@exemplo.com"
    msg["To"] = email
    situacao = "aprovado(a)" if nota >= 6 else "em recuperação"
    msg.set_content(f"Olá, {nome}! Sua nota foi {nota}. Você está {situacao}.")
    return msg

class CarteiroDeTeste:
    def send_message(self, msg):
        print(f"[para {msg['To']}] {msg.get_content().strip()}")

turma = [("Ana", "ana@exemplo.com", 8.5), ("Caio", "caio@exemplo.com", 5.0)]
carteiro = CarteiroDeTeste()
for nome, email, nota in turma:
    carteiro.send_message(montar_aviso(nome, email, nota))

[para ana@exemplo.com] Olá, Ana! Sua nota foi 8.5. Você está aprovado(a).
[para caio@exemplo.com] Olá, Caio! Sua nota foi 5.0. Você está em recuperação.

No computador, o carteiro de verdade é o objeto servidor do with smtplib.SMTP_SSL(...): ele também tem o método send_message. Você monta a lista de mensagens, confere com o carteiro de teste e só então envia:

# continuação: montar_aviso e turma são os mesmos do exemplo acima
import os
import smtplib
import time

with smtplib.SMTP_SSL("smtp.gmail.com", 465) as servidor:
    servidor.login(os.environ["EMAIL_USUARIO"], os.environ["EMAIL_SENHA_APP"])
    for nome, email, nota in turma:
        servidor.send_message(montar_aviso(nome, email, nota))
        print("Enviado para", email)
        time.sleep(2)   # uma pausa entre e-mails

Enviado para ana@exemplo.com
Enviado para caio@exemplo.com

Dica: Para treinar, mande as mensagens só para você mesmo. Um programa com erro num laço pode disparar dezenas de e-mails sem querer, e os provedores bloqueiam contas que mandam muitos e-mails de uma vez. A pausa com time.sleep ajuda a não parecer spam.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
msg["Subject"] = "Lembrete da aula"

5. Escreva a função montar_boas_vindas(nome, email) que devolve uma EmailMessage com o assunto Bem-vindo(a), NOME! e use-a com o carteiro de teste para "enviar" para três pessoas.

Ver resposta 
from email.message import EmailMessage

def montar_boas_vindas(nome, email):
    msg = EmailMessage()
    msg["Subject"] = f"Bem-vindo(a), {nome}!"
    msg["From"] = "clube@exemplo.com"
    msg["To"] = email
    msg.set_content(f"Oi, {nome}! Que bom ter você no clube de leitura.")
    return msg

class CarteiroDeTeste:
    def send_message(self, msg):
        print(msg["To"], "->", msg["Subject"])

carteiro = CarteiroDeTeste()
for nome, email in [("Ana", "ana@exemplo.com"), ("Rui", "rui@exemplo.com"), ("Lia", "lia@exemplo.com")]:
    carteiro.send_message(montar_boas_vindas(nome, email))

ana@exemplo.com -> Bem-vindo(a), Ana!
rui@exemplo.com -> Bem-vindo(a), Rui!
lia@exemplo.com -> Bem-vindo(a), Lia!
