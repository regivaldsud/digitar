Aula 109 · Enviando e-mail com smtplib

Nesta aula você vai aprender

  • Montar uma mensagem com email.message.EmailMessage
  • Enviar com smtplib usando SSL
  • Usar senha de app e variáveis de ambiente em vez da senha real
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Montando a mensagem

O Python separa duas tarefas: o módulo email monta a mensagem e o smtplib envia. Montar não precisa de internet, então dá para testar primeiro:

from email.message import EmailMessage

msg = EmailMessage()
msg["Subject"] = "Lembrete: entrega do trabalho"
msg["From"] = "turma7b@exemplo.com"
msg["To"] = "aluno@exemplo.com"
msg.set_content("Oi! O trabalho de ciências deve ser entregue na sexta.")

print(msg["Subject"])
print(msg.get_content())

Lembrete: entrega do trabalho
Oi! O trabalho de ciências deve ser entregue na sexta.

Enviando com smtplib

Para enviar, o programa conversa com um servidor SMTP do seu provedor de e-mail. No Gmail, o servidor é smtp.gmail.com, porta 465. Este código só funciona no seu computador, com internet e uma conta configurada:

import os
import smtplib
from email.message import EmailMessage

remetente = os.environ["EMAIL_USUARIO"]
senha = os.environ["EMAIL_SENHA_APP"]

msg = EmailMessage()
msg["Subject"] = "Teste do Python"
msg["From"] = remetente
msg["To"] = remetente          # mande para você mesmo
msg.set_content("Funcionou! Este e-mail foi enviado por um programa.")

with smtplib.SMTP_SSL("smtp.gmail.com", 465) as servidor:
    servidor.login(remetente, senha)
    servidor.send_message(msg)
print("Enviado!")
Atenção: Nunca escreva sua senha dentro do código e nunca use a senha principal da conta. Provedores como o Gmail exigem uma senha de app (criada nas configurações de segurança da conta, com verificação em duas etapas ligada). Guarde-a numa variável de ambiente ou num .env (aula 108). Se você tem menos de 18 anos, peça ajuda a um responsável para configurar a conta.
Dica: Para treinar sem e-mail de verdade, mande as mensagens só para você mesmo. Um programa com erro num laço pode disparar dezenas de e-mails sem querer.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
msg["Subject"] = "Lembrete da aula"

Exercícios

1. Monte (sem enviar) um e-mail com assunto Notas do bimestre cujo texto liste três matérias e notas, uma por linha.

Ver resposta 
from email.message import EmailMessage

notas = {"Português": 8.5, "Matemática": 7.0, "Ciências": 9.0}
texto = "\n".join(f"{materia}: {nota}" for materia, nota in notas.items())

msg = EmailMessage()
msg["Subject"] = "Notas do bimestre"
msg["To"] = "familia@exemplo.com"
msg.set_content(texto)
print(msg.get_content())

Ciências: 9.0

2. Por que usamos os.environ["EMAIL_SENHA_APP"] em vez de escrever a senha no código?

Ver resposta

Para a senha não ficar no arquivo .py. Assim você pode mostrar ou publicar
