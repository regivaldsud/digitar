Sua primeira classe de testes

O Python já vem com o módulo unittest. Um teste é um método, dentro de uma classe que herda de unittest.TestCase (você viu herança na aula 76), com nome começando por test:

import unittest


def dobro(n):
    return n * 2


class TestDobro(unittest.TestCase):
    def test_numero_positivo(self):
        self.assertEqual(dobro(4), 8)

    def test_zero(self):
        self.assertEqual(dobro(0), 0)


unittest.main(argv=[""], exit=False)

Cada ponto . é um teste que passou. OK no fim quer dizer que deu tudo certo.

Dica: Aqui no site usamos unittest.main(argv=[""], exit=False) para os testes rodarem no navegador. No seu computador, basta unittest.main().

Os principais asserts

Um assert é uma afirmação: "eu garanto que isto é verdade". Se não for, o teste falha.

  • assertEqual(a, b): confere se a == b.
  • assertTrue(x) e assertFalse(x): confere se x é verdadeiro ou falso.
  • assertIn(item, colecao): confere se o item está na coleção.
  • assertAlmostEqual(a, b): para números com vírgula, que podem ter pequenos erros de arredondamento.
import unittest


def e_par(n):
    return n % 2 == 0


def vogais(texto):
    return [letra for letra in texto.lower() if letra in "aeiou"]


class TestFuncoes(unittest.TestCase):
    def test_par(self):
        self.assertTrue(e_par(10))

    def test_impar(self):
        self.assertFalse(e_par(7))

    def test_vogais(self):
        self.assertIn("a", vogais("Bahia"))
        self.assertEqual(len(vogais("Bahia")), 3)

    def test_decimal(self):
        self.assertAlmostEqual(0.1 + 0.2, 0.3)


unittest.main(argv=[""], exit=False)

....

Atenção: Nunca compare números decimais com assertEqual(0.1 + 0.2, 0.3): isso falha, porque 0.1 + 0.2 dá 0.30000000000000004 (veja a aula 29). Use assertAlmostEqual.

Testando erros com assertRaises

Às vezes o comportamento certo é dar erro. Por exemplo, sacar mais do que tem na conta. O assertRaises confere se o erro esperado acontece:

import unittest


def sacar(saldo, valor):
    if valor > saldo:
        raise ValueError("Saldo insuficiente")
    return saldo - valor


class TestSaque(unittest.TestCase):
    def test_saque_normal(self):
        self.assertEqual(sacar(100, 30), 70)

    def test_saque_maior_que_saldo(self):
        with self.assertRaises(ValueError):
            sacar(50, 80)


unittest.main(argv=[""], exit=False)

Preparando dados com setUp

Quando vários testes usam os mesmos dados, escreva-os uma vez no método setUp. Ele roda antes de cada teste, então cada teste começa com uma cópia nova, sem a bagunça do teste anterior:

import unittest


class TestCarrinho(unittest.TestCase):
    def setUp(self):
        self.carrinho = ["arroz", "feijão"]

    def test_adicionar(self):
        self.carrinho.append("farofa")
        self.assertEqual(len(self.carrinho), 3)

    def test_carrinho_comeca_com_dois(self):
        self.assertEqual(len(self.carrinho), 2)


unittest.main(argv=[""], exit=False)

..
----------------------------------------------------------------------
Ran 2 tests in 0.000s
 
OK

Mesmo que test_adicionar rode primeiro e coloque a farofa, o outro teste recebe um carrinho novo com dois itens.

Quando um teste falha

Um teste que falha é uma boa notícia: ele achou um erro antes do usuário. Imagine uma função de desconto com um engano (ela soma em vez de subtrair):

import unittest


def com_desconto(preco, porcentagem):
    return preco + preco * porcentagem / 100   # erro: deveria ser -


class TestDesconto(unittest.TestCase):
    def test_dez_por_cento(self):
        self.assertEqual(com_desconto(200, 10), 180)


unittest.main(argv=[""], exit=False)

F

O F marca a falha. A linha File mostra o arquivo e a linha do teste que falhou (no navegador, o nome do arquivo aparece diferente; o que importa é o número da linha). A linha do AssertionError mostra o que a função devolveu (220.0) e o que era esperado (180). Troque o + por - e rode de novo.

Rodando no seu computador

No projeto, deixe as funções num arquivo (por exemplo banco.py) e os testes em outro, com nome começando por test_ (por exemplo test_banco.py), que faz from banco import sacar. No terminal, na pasta do projeto:

python -m unittest
python -m unittest -v

O primeiro comando procura e roda todos os arquivos test_*.py. Com -v (verbose), ele mostra o nome de cada teste.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
self.assertEqual(dobro(4), 8)

2. Escreva a função e_palindromo(texto) (lê igual de trás para frente, ignorando espaços e maiúsculas) e teste com "Ame a ema" (verdadeiro) e "Python" (falso).

Ver resposta 
import unittest


def e_palindromo(texto):
    limpo = texto.replace(" ", "").lower()
    return limpo == limpo[::-1]


class TestPalindromo(unittest.TestCase):
    def test_e_palindromo(self):
        self.assertTrue(e_palindromo("Ame a ema"))

    def test_nao_e_palindromo(self):

4. Use setUp para criar uma lista de notas [8, 6, 10] e escreva dois testes: um confere a soma (24) e outro confere a maior nota (10).

Ver resposta 
import unittest


class TestNotas(unittest.TestCase):
    def setUp(self):
        self.notas = [8, 6, 10]

    def test_soma(self):
        self.assertEqual(sum(self.notas), 24)

    def test_maior(self):
        self.assertEqual(max(self.notas), 10)


unittest.main(argv=[""], exit=False)
