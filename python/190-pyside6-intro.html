O que é o PySide6

Até agora, seus programas conversavam com você pelo terminal: escreviam com print e liam com input. Os aplicativos que você usa no dia a dia têm janelas, botões e caixas de texto. O PySide6 é a biblioteca que deixa o Python criar esse tipo de programa.

Ele é a versão oficial para Python do Qt 6, um conjunto de ferramentas usado em programas famosos (o VLC, partes do KDE no Linux e muitos programas de engenharia). O mesmo código roda no Windows, no Linux e no macOS.

Janelas de verdade não abrem dentro do navegador, por isso todo este módulo é feito no seu computador. Mesmo assim, a aula tem exemplos com o botão Executar que mostram, só com Python puro, as ideias que o Qt usa por baixo.

Instalando

Crie uma pasta para o projeto, crie e ative um ambiente virtual (aula 60) e instale o pacote. No Windows:

mkdir janelas
cd janelas
py -m venv .venv
.venv\Scripts\activate
py -m pip install pyside6

No Linux e no macOS:

mkdir janelas
cd janelas
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install pyside6

O download tem algumas centenas de megabytes, porque traz o Qt inteiro junto. Para conferir se deu certo:

python -c "import PySide6; print(PySide6.__version__)"
Dica: No VS Code, escolha o Python do .venv (canto inferior direito, ou Ctrl+Shift+P → Python: Select Interpreter). Se o editor sublinhar PySide6 em vermelho, quase sempre é porque ele está usando outro Python.

Programa de terminal x programa de eventos

Um programa de terminal segue uma receita de cima para baixo e termina. Um programa com janela é diferente: ele mostra a tela e fica esperando você fazer alguma coisa — clicar, digitar, arrastar, fechar. Cada uma dessas ações é um evento.

Quem fica esperando e distribuindo os eventos é o laço de eventos (*event loop*). Veja uma simulação, em Python puro, de como ele funciona por dentro:

from collections import deque

# os eventos que o usuário "fez", na ordem
fila = deque(["clique no botão", "tecla A", "clique no botão", "fechar janela"])

cliques = 0
while fila:
    evento = fila.popleft()
    print("Evento recebido:", evento)
    if evento == "clique no botão":
        cliques += 1
        print("  -> respondendo ao clique número", cliques)
    elif evento == "fechar janela":
        print("  -> fim do laço, o programa termina")
        break

No Qt, você não escreve esse while: ele já vem pronto dentro de app.exec(). A sua parte é dizer o que fazer quando cada evento acontecer.

Sua primeira janela

Todo programa Qt precisa de exatamente um objeto QApplication. Ele cuida do teclado, do mouse, do laço de eventos e da conversa com o sistema operacional. Um QWidget é qualquer pedaço de tela; quando ele não está dentro de nada, vira uma janela.

Salve como janela.py e rode com python janela.py (com o .venv ativado):

import sys
from PySide6.QtWidgets import QApplication, QWidget

app = QApplication(sys.argv)          # 1. cria o aplicativo
janela = QWidget()                    # 2. cria um widget (sem pai = janela)
janela.setWindowTitle("Minha primeira janela")
janela.resize(400, 200)               # largura, altura em pixels
janela.show()                         # 3. mostra na tela
sys.exit(app.exec())                  # 4. começa o laço de eventos

Abre uma janela vazia de 400×200 pixels com o título "Minha primeira janela".
O terminal fica parado (esperando) até você fechar a janela; aí o programa termina.

  • QApplication(sys.argv) recebe os argumentos da linha de comando (aula 110); o Qt usa alguns deles.
  • show() só pede para mostrar; a janela aparece de verdade quando o laço de eventos começa.
  • app.exec() só termina quando a última janela é fechada. sys.exit(...) devolve ao sistema o código de saída.
Atenção: Se você esquecer o app.exec(), a janela pisca e some na hora: o programa chega ao fim do arquivo e termina antes de você conseguir ver qualquer coisa.

Widgets dentro de widgets

Um widget pode ficar dentro de outro. Quem fica por fora é o pai (*parent*). Quando você passa a janela como pai do botão, o botão é desenhado dentro dela:

import sys
from PySide6.QtWidgets import QApplication, QWidget, QPushButton

app = QApplication(sys.argv)
janela = QWidget()
janela.setWindowTitle("Botão dentro da janela")
janela.resize(300, 150)

botao = QPushButton("Eu moro na janela", janela)   # janela é o pai
botao.move(70, 50)                                 # posição x, y dentro do pai

janela.show()
sys.exit(app.exec())

Abre uma janela de 300×150 com um botão "Eu moro na janela" perto do centro.

Na próxima aula você vai trocar o move por layouts, que arrumam tudo sozinhos. Por enquanto, guarde a ideia: os widgets formam uma árvore, com a janela na raiz.

Um botão que faz alguma coisa

Quando você clica num QPushButton, ele emite o sinal clicked. Com connect, você diz qual função deve rodar quando isso acontecer:

import sys
from PySide6.QtWidgets import QApplication, QPushButton


def dizer_oi():
    print("Oi! Você clicou no botão.")


app = QApplication(sys.argv)
botao = QPushButton("Clique aqui")
botao.clicked.connect(dizer_oi)   # sem parênteses!
botao.resize(250, 80)
botao.show()
sys.exit(app.exec())

Abre uma janela que é só o botão "Clique aqui". A cada clique, aparece no terminal:
Oi! Você clicou no botão.

Por que sem parênteses? Porque você não quer rodar a função agora: quer entregar a função para o Qt guardar e chamar depois. Veja a diferença em Python puro:

def dizer_oi():
    print("Oi!")
    return "pronto"

guardada = dizer_oi        # guarda a função (nada é impresso)
print(guardada)            # é um objeto função

resultado = dizer_oi()     # com parênteses: roda agora
print(resultado)           # o que fica guardado é o retorno, não a função

<function dizer_oi at 0x0000022902DCA3E0>
Oi!
pronto

Atenção: botao.clicked.connect(dizer_oi()) é um erro clássico: a função roda uma vez, na hora em que o programa abre, e o connect recebe o retorno dela (None). O PySide6 reclama na hora: TypeError: Expected signal or callable, got "NoneType".
Atenção: Crie um único QApplication por programa. Criar um segundo dá o erro RuntimeError: libshiboken: Please destroy the QApplication singleton before creating a new QApplication instance.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
botao.clicked.connect(dizer_oi)

Ao rodar, aparece uma janela vazia de 500×300 com esse título.

2. Crie um botão "Sair" que fecha o programa quando clicado. Dica: app.quit é uma função pronta.

Ver resposta 
import sys
from PySide6.QtWidgets import QApplication, QPushButton

app = QApplication(sys.argv)
botao = QPushButton("Sair")
botao.clicked.connect(app.quit)
botao.show()
sys.exit(app.exec())

Repare: app.quit vai sem parênteses, igual a qualquer função passada para connect.

import sys
from PySide6.QtWidgets import QApplication, QWidget, QPushButton


def oi():

4. Na simulação do laço de eventos, acrescente o evento "tecla B" e faça o programa contar quantas teclas foram apertadas (eventos que começam com "tecla").

Ver resposta 
from collections import deque

fila = deque(["tecla A", "clique no botão", "tecla B", "fechar janela"])
teclas = 0
while fila:
    evento = fila.popleft()
    if evento.startswith("tecla"):
        teclas += 1
    elif evento == "fechar janela":
        break
print("Teclas apertadas:", teclas)

Teclas apertadas: 2

5. Um colega escreveu um programa que cria o QApplication, cria um QWidget, chama janela.show() e termina ali. Ele diz que "a janela não aparece". Qual é o problema?
