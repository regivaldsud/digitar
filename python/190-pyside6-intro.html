O que é o PySide6

Até agora, seus programas conversavam com você pelo terminal. O PySide6 é uma biblioteca que permite criar programas com janelas, botões e caixas de texto, como os aplicativos que você usa no dia a dia. Ele é a versão oficial para Python do Qt 6, um conjunto de ferramentas usado em programas famosos.

Janelas não funcionam no navegador, por isso esta aula (e todo este módulo) é feita no seu computador.

Instalando

Crie uma pasta para o projeto, ative um ambiente virtual (aula 60) e instale o pacote:

mkdir janelas
cd janelas
python -m venv .venv
.venv\Scripts\activate
pip install pyside6
Dica: No Linux e no macOS, o comando de ativação é source .venv/bin/activate.

Sua primeira janela

Todo programa Qt precisa de exatamente um objeto QApplication. Ele cuida do teclado, do mouse e da conversa com o sistema operacional. Um QWidget é qualquer pedaço de tela; sozinho, ele já é uma janela vazia.

import sys
from PySide6.QtWidgets import QApplication, QWidget

app = QApplication(sys.argv)
janela = QWidget()
janela.setWindowTitle("Minha primeira janela")
janela.resize(400, 200)
janela.show()
sys.exit(app.exec())

Salve como janela.py e rode com python janela.py. A linha app.exec() inicia o laço de eventos: o programa fica esperando você clicar, digitar ou fechar a janela. Quando você fecha, exec() termina e o programa acaba.

Um botão que faz alguma coisa

O QPushButton é um botão. Quando ele é clicado, emite o sinal clicked, que podemos ligar a uma função com connect:

import sys
from PySide6.QtWidgets import QApplication, QPushButton


def dizer_oi():
    print("Oi! Você clicou no botão.")


app = QApplication(sys.argv)
botao = QPushButton("Clique aqui")
botao.clicked.connect(dizer_oi)
botao.resize(250, 80)
botao.show()
sys.exit(app.exec())

Oi! Você clicou no botão.
Oi! Você clicou no botão.

A mensagem aparece no terminal a cada clique.

Atenção: Passe a função sem parênteses para o connect: connect(dizer_oi). Com parênteses, dizer_oi() seria chamada na hora, uma vez só, e o botão ficaria sem ação.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
botao.clicked.connect(dizer_oi)

Exercícios

1. Faça uma janela (QWidget) com o título "Lanchonete do Zé" e tamanho 500 por 300.

Ver resposta 
import sys
from PySide6.QtWidgets import QApplication, QWidget

app = QApplication(sys.argv)
janela = QWidget()
janela.setWindowTitle("Lanchonete do Zé")
janela.resize(500, 300)
janela.show()
sys.exit(app.exec())

2. Crie um botão "Sair" que fecha o programa quando clicado. Dica: app.quit é uma função pronta.

Ver resposta 
import sys
from PySide6.QtWidgets import QApplication, QPushButton

app = QApplication(sys.argv)
botao = QPushButton("Sair")
botao.clicked.connect(app.quit)
botao.show()
sys.exit(app.exec())

Repare: app.quit vai sem parênteses, igual a qualquer função passada para connect.
