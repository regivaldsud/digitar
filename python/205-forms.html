ModelForm

Um ModelForm cria o formulário a partir do model: os campos, os tipos e as validações básicas vêm prontos.

# contatos/forms.py
from django import forms
from .models import Contato


class ContatoForm(forms.ModelForm):
    class Meta:
        model = Contato
        fields = ["nome", "telefone", "email", "favorito"]

    def clean_telefone(self):
        telefone = self.cleaned_data["telefone"]
        digitos = "".join(c for c in telefone if c.isdigit())
        if len(digitos) < 10:
            raise forms.ValidationError("Informe o DDD e o número.")
        return telefone

Um método clean_<campo> valida um campo: se algo estiver errado, lance ValidationError com a mensagem que o usuário vai ver.

A view: mostrar e receber

from django.shortcuts import redirect, render
from .forms import ContatoForm


def novo(request):
    if request.method == "POST":
        form = ContatoForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect("lista")
    else:
        form = ContatoForm()
    return render(request, "contatos/form.html", {"form": form})
<form method="post">
  {% csrf_token %}
  {{ form.as_p }}
  <button type="submit">Salvar</button>
</form>

Na primeira visita (GET) o formulário aparece vazio. Ao enviar (POST), se for inválido, ele volta com os dados digitados e as mensagens de erro.

Atenção: Sem {% csrf_token %} dentro do <form method="post">, o Django recusa o envio com 403 Forbidden (CSRF verification failed). Esse código protege contra sites que tentam enviar formulários em seu nome.
Dica: Depois de salvar, sempre faça redirect. Assim, se a pessoa apertar F5, o navegador não reenvia o formulário e não cria um contato repetido.

from django import forms


def clean_nome(self):
    nome = self.cleaned_data["nome"].strip()
    if len(nome) < 2:
        raise forms.ValidationError("O nome precisa de pelo menos 2 letras.")
    return nome.title()

Esse método vai dentro da classe ContatoForm.
