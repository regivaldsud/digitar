Aula 78 · Classes abstratas (abc, abstractmethod)

Nesta aula você vai aprender

  • O que é uma classe abstrata e para que serve
  • Criar classes abstratas com ABC e @abstractmethod
  • Entender o erro ao instanciar uma classe abstrata ou uma filha incompleta
  • Misturar métodos abstratos com métodos prontos

Um molde incompleto de propósito

Às vezes uma classe mãe existe só para dizer o que as filhas precisam ter, sem saber como. Por exemplo, toda forma geométrica tem área, mas não existe a área de uma "forma" genérica — só de um quadrado, de um círculo... Uma classe assim se chama abstrata: ela não vira objeto, só serve de modelo.

Na aula 76 a classe Forma devolvia 0 na área, o que é meio estranho. Com o módulo abc (*abstract base classes*) dá para fazer melhor.

ABC e @abstractmethod

Herde de ABC e marque os métodos obrigatórios com @abstractmethod. Eles não precisam de corpo: um pass (ou só a docstring) basta.

from abc import ABC, abstractmethod

class Forma(ABC):
    @abstractmethod
    def area(self):
        pass

class Quadrado(Forma):
    def __init__(self, lado):
        self.lado = lado

    def area(self):
        return self.lado ** 2

class Circulo(Forma):
    def __init__(self, raio):
        self.raio = raio

    def area(self):
        return 3.14159 * self.raio ** 2

for f in [Quadrado(3), Circulo(1)]:
    print(type(f).__name__, round(f.area(), 2))

Quadrado 9
Circulo 3.14

Abstrata não vira objeto

Tentar criar um objeto da classe abstrata dá erro, porque ela está incompleta:

from abc import ABC, abstractmethod

class Forma(ABC):
    @abstractmethod
    def area(self):
        pass

f = Forma()

TypeError: Can't instantiate abstract class Forma without an implementation for abstract method 'area'

O mesmo erro acontece com uma filha que esqueceu de implementar algum método abstrato. Essa é a grande vantagem: o erro aparece logo ao criar o objeto, e não lá na frente, quando alguém chamar o método que falta.

from abc import ABC, abstractmethod

class Pagamento(ABC):
    @abstractmethod
    def pagar(self, valor):
        pass

class Pix(Pagamento):
    def pagr(self, valor):  # nome digitado errado!
        print(f"Pix de R$ {valor:.2f}")

p = Pix()

TypeError: Can't instantiate abstract class Pix without an implementation for abstract method 'pagar'

Atenção: A mensagem Can't instantiate abstract class ... quer dizer: "esta classe ainda tem métodos abstratos sem implementação". Confira se a filha implementou todos os métodos com @abstractmethod, com o nome escrito igualzinho.

Métodos prontos junto com os abstratos

Uma classe abstrata também pode ter métodos normais, que usam os abstratos. As filhas só preenchem o que falta.

from abc import ABC, abstractmethod

class Relatorio(ABC):
    def gerar(self):
        print("=" * 20)
        print(self.titulo())
        print("=" * 20)
        for linha in self.linhas():
            print("-", linha)

    @abstractmethod
    def titulo(self):
        pass

    @abstractmethod
    def linhas(self):
        pass

class RelatorioNotas(Relatorio):
    def __init__(self, notas):
        self.notas = notas

    def titulo(self):
        return "Boletim do 7º ano"

    def linhas(self):
        return [f"{nome}: {nota}" for nome, nota in self.notas.items()]

RelatorioNotas({"Ana": 9.0, "Davi": 7.5}).gerar()

====================
Boletim do 7º ano
====================
- Ana: 9.0
- Davi: 7.5

O método gerar define o "roteiro" e as filhas preenchem os detalhes. Esse jeito de organizar tem até nome: *Template Method*, um padrão de projeto que aparece no Módulo 8.

Dica: Também dá para ter property abstrata: coloque @property em cima de @abstractmethod. As filhas então precisam ter esse property.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
from abc import ABC, abstractmethod

Exercícios

1. Crie a classe abstrata Animal com o método abstrato som() e as filhas Cachorro e Galo. Mostre o som de cada um num laço.

Ver resposta 
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def som(self):
        pass

class Cachorro(Animal):
    def som(self):
        return "au au"

class Galo(Animal):
    def som(self):
        return "cocoricó"

for a in [Cachorro(), Galo()]:
    print(type(a).__name__, "->", a.som())

Cachorro -> au au
Galo -> cocoricó

2. Crie a classe abstrata Pagamento com o método abstrato pagar(valor) e as filhas Pix e Boleto. O boleto cobra R$ 3,50 de taxa. Mostre o que cada um faz ao pagar R$ 100.

Ver resposta 
from abc import ABC, abstractmethod

class Pagamento(ABC):
    @abstractmethod
    def pagar(self, valor):
        pass

class Pix(Pagamento):
    def pagar(self, valor):
        print(f"Pix de R$ {valor:.2f} enviado na hora.")

class Boleto(Pagamento):
    def pagar(self, valor):
        print(f"Boleto de R$ {valor + 3.5:.2f} gerado (com taxa).")

for forma in [Pix(), Boleto()]:
    forma.pagar(100)

Pix de R$ 100.00 enviado na hora.
Boleto de R$ 103.50 gerado (com taxa).

3. O que acontece ao rodar este código? Explique e corrija: a classe abstrata Veiculo tem os métodos abstratos acelerar e frear, e a classe Bike(Veiculo) implementa só acelerar.

Ver resposta 
from abc import ABC, abstractmethod

class Veiculo(ABC):
    @abstractmethod
    def acelerar(self):
        pass

    @abstractmethod
    def frear(self):
        pass

class Bike(Veiculo):
    def acelerar(self):
        print("pedalando mais rápido")

    def frear(self):
        print("apertando o freio")

b = Bike()
b.acelerar()
b.frear()

pedalando mais rápido
apertando o freio

Sem o método frear, Bike() dá TypeError: Can't instantiate abstract class Bike.... A correção é implementar todos os métodos abstratos.

4. Crie a classe abstrata Jogo com um método pronto jogar() que mostra Começando <nome>..., chama o método abstrato rodada() três vezes e mostra Fim!. Faça a filha JogoDaVelha.

Ver resposta 
from abc import ABC, abstractmethod

class Jogo(ABC):
    def jogar(self):
        print(f"Começando {self.nome}...")
        for n in range(1, 4):
            self.rodada(n)
        print("Fim!")

    @abstractmethod
    def rodada(self, n):
        pass

class JogoDaVelha(Jogo):
    nome = "jogo da velha"

    def rodada(self, n):
        print(f"Rodada {n}: marque X ou O")

JogoDaVelha().jogar()

Começando jogo da velha...
Rodada 1: marque X ou O
Rodada 2: marque X ou O
Rodada 3: marque X ou O
Fim!
