Aula 88 · dataclasses: campos, __post_init__, asdict, field

Nesta aula você vai aprender

  • Criar classes de dados com @dataclass, sem escrever __init__

Menos código repetido

Lembra das classes com __init__ que só copiam os parâmetros para self (aula 70)? É muito código repetido. O decorador @dataclass escreve o __init__, o __repr__ (o jeito de mostrar o objeto) e o __eq__ (a comparação) por você. Basta listar os campos com seus tipos:

from dataclasses import dataclass

@dataclass
class Aluno:
    nome: str
    turma: str
    nota: float

aluno = Aluno("Ana", "7º B", 8.5)
print(aluno)
print(aluno.nome, aluno.nota)
print(aluno == Aluno("Ana", "7º B", 8.5))

Aluno(nome='Ana', turma='7º B', nota=8.5)
Ana 8.5
True

Atenção: Os type hints são obrigatórios na dataclass. Uma linha como nome = "x", sem o tipo, não vira campo.

Valores padrão e field

Campos podem ter valor padrão. Eles precisam vir depois dos campos sem padrão. Para listas e dicionários, não use = []: use field(default_factory=list), que cria uma lista nova para cada objeto.

from dataclasses import dataclass, field

@dataclass
class Mochila:
    dono: str
    cor: str = "azul"
    itens: list[str] = field(default_factory=list)

a = Mochila("Caio")
b = Mochila("Bia", "rosa")
a.itens.append("caderno")
print(a)
print(b)

Mochila(dono='Caio', cor='azul', itens=['caderno'])
Mochila(dono='Bia', cor='rosa', itens=[])

Dica: Escrever itens: list[str] = [] numa dataclass dá erro de propósito (ValueError: mutable default). O Python protege você de todos os objetos dividirem a mesma lista.

O field tem outras opções úteis. Com repr=False, o campo não aparece quando o objeto é mostrado — bom para senhas:

from dataclasses import dataclass, field

@dataclass
class Usuario:
    login: str
    senha: str = field(repr=False)

print(Usuario("joana", "segredo123"))

Usuario(login='joana')

__post_init__: validar e calcular

Como a dataclass escreve o __init__ por você, onde colocar validações? No método __post_init__, que roda logo depois do __init__ automático:

from dataclasses import dataclass, field

@dataclass
class Produto:
    nome: str
    preco: float
    quantidade: int = 1
    total: float = field(init=False)

    def __post_init__(self):
        if self.preco < 0:
            raise ValueError("o preço não pode ser negativo")
        self.total = self.preco * self.quantidade

p = Produto("pão de queijo", 1.5, 6)
print(p)
try:
    Produto("erro", -2)
except ValueError as erro:
    print("Erro:", erro)

Produto(nome='pão de queijo', preco=1.5, quantidade=6, total=9.0)
Erro: o preço não pode ser negativo

Com field(init=False), o campo total não é pedido na criação: ele é calculado no __post_init__.

asdict: de objeto para dicionário

A função asdict transforma a dataclass num dicionário. Isso combina muito com JSON (aula 62):

import json
from dataclasses import dataclass, asdict

@dataclass
class Contato:
    nome: str
    telefone: str

c = Contato("Marcos", "(11) 98888-7777")
dados = asdict(c)
print(dados)
print(json.dumps(dados, ensure_ascii=False))

{'nome': 'Marcos', 'telefone': '(11) 98888-7777'}
{"nome": "Marcos", "telefone": "(11) 98888-7777"}

Ordenar e congelar

Com order=True, os objetos podem ser comparados com < e >, campo por campo, na ordem em que foram declarados. Com frozen=True, o objeto não pode mais ser alterado depois de criado:

from dataclasses import dataclass

@dataclass(order=True)
class Placar:
    pontos: int
    jogador: str

ranking = [Placar(120, "Rafa"), Placar(300, "Duda"), Placar(210, "Leo")]
for p in sorted(ranking, reverse=True):
    print(p.jogador, p.pontos)

Duda 300
Leo 210
Rafa 120

from dataclasses import dataclass

@dataclass(frozen=True)
class Cidade:
    nome: str
    estado: str

capital = Cidade("Salvador", "BA")
print(capital)
capital.estado = "SP"

Cidade(nome='Salvador', estado='BA')
dataclasses.FrozenInstanceError: cannot assign to field 'estado'

itens: list[str] = field(default_factory=list)

Exercícios

1. Crie a dataclass Livro com titulo, autor e paginas. Crie um livro e mostre-o.

Ver resposta 
from dataclasses import dataclass

@dataclass
class Livro:
    titulo: str
    autor: str
    paginas: int

livro = Livro("O Menino Maluquinho", "Ziraldo", 112)
print(livro)

Livro(titulo='O Menino Maluquinho', autor='Ziraldo', paginas=112)

2. Crie a dataclass Turma com nome e uma lista alunos (padrão vazio). Adicione um método matricular(nome) e matricule dois alunos.

Ver resposta 
from dataclasses import dataclass, field

@dataclass
class Turma:
    nome: str
    alunos: list[str] = field(default_factory=list)

    def matricular(self, nome: str) -> None:
        self.alunos.append(nome)

turma = Turma("8º A")
turma.matricular("Iara")
turma.matricular("Davi")
print(turma)

Turma(nome='8º A', alunos=['Iara', 'Davi'])

Dataclasses aceitam métodos normalmente, como qualquer classe.

3. Crie a dataclass Retangulo com largura e altura e um campo area calculado no __post_init__ (use field(init=False)).

Ver resposta 
from dataclasses import dataclass, field

@dataclass
class Retangulo:
    largura: float
    altura: float
    area: float = field(init=False)

    def __post_init__(self):
        self.area = self.largura * self.altura

print(Retangulo(3, 4))

Retangulo(largura=3, altura=4, area=12)

4. Crie a dataclass Nota com aluno e valor, e faça o __post_init__ dar ValueError se o valor estiver fora de 0 a 10. Teste com 11.

Ver resposta 
from dataclasses import dataclass

@dataclass
class Nota:
    aluno: str
    valor: float

    def __post_init__(self):
        if not 0 <= self.valor <= 10:
            raise ValueError("a nota deve estar entre 0 e 10")

print(Nota("Lia", 9.5))
try:
    Nota("Téo", 11)
except ValueError as erro:
    print("Erro:", erro)

Nota(aluno='Lia', valor=9.5)
Erro: a nota deve estar entre 0 e 10

5. Crie a dataclass Produto (nome, preco), monte uma lista de três produtos e converta todos para dicionários com asdict, numa list comprehension.

Ver resposta 
from dataclasses import dataclass, asdict

@dataclass
class Produto:
    nome: str
    preco: float

produtos = [Produto("arroz", 25.9), Produto("feijão", 8.5), Produto("café", 17.0)]
print([asdict(p) for p in produtos])

[{'nome': 'arroz', 'preco': 25.9}, {'nome': 'feijão', 'preco': 8.5}, {'nome': 'café', 'preco': 17.0}]
