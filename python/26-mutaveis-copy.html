Nesta aula você vai aprender

  • Diferenciar tipos mutáveis (como listas) de imutáveis (como textos e números)

Mutável e imutável

Alguns tipos do Python podem ser alterados depois de criados: são os mutáveis, como as listas. Outros não podem: são os imutáveis, como int, float, str, bool e as tuplas (aula 27).

lista = [1, 2, 3]
lista[0] = 99
print(lista)
texto = "gato"
maiusculo = texto.upper()
print(texto, maiusculo)

[99, 2, 3]
gato GATO

A lista mudou de verdade. Já o texto continua "gato": o upper() criou um texto novo. Tentar mudar uma letra de um texto, como em texto[0] = "p", dá TypeError.

O nome é só uma etiqueta

Uma variável funciona como uma etiqueta colada num valor. Quando você escreve b = a, não cria uma lista nova: cola uma segunda etiqueta na mesma lista.

original = ["lápis", "borracha"]
apelido = original
apelido.append("caderno")
print(original)
print(apelido is original)

['lápis', 'borracha', 'caderno']
True

Mexemos no apelido, mas o original também mudou — porque é a mesma lista! O operador is, que você viu na aula 21, confirma: os dois nomes apontam para o mesmo objeto.

Atenção: Essa é uma das maiores pegadinhas do Python. Se você quer uma lista independente, não use b = a; faça uma cópia.

Fazendo cópias de verdade

Há três jeitos comuns de copiar uma lista. Todos criam uma lista nova, com os mesmos itens:

original = ["lápis", "borracha"]
copia1 = original.copy()
copia2 = list(original)
copia3 = original[:]
copia1.append("régua")
print(original)
print(copia1)
print(copia1 is original, copia1 == original)
print(copia2 == original, copia3 == original)

['lápis', 'borracha']
['lápis', 'borracha', 'régua']
False False
True True

== pergunta "têm os mesmos itens?"; is pergunta "é o mesmo objeto?". Depois do append, a cópia ficou diferente e o original não mudou. O módulo copy também tem copy.copy(lista), que faz o mesmo.

import copy

turma = ["Ana", "Bia"]
reserva = copy.copy(turma)
reserva.append("Caio")
print(turma, reserva)

['Ana', 'Bia'] ['Ana', 'Bia', 'Caio']

E com imutáveis?

Com números e textos, essa preocupação não existe: como eles não mudam, "alterar" sempre cria um valor novo e guarda na variável.

a = 10
b = a
b += 5
print(a, b)
nome = "Ana"
outro = nome
outro += " Clara"
print(nome, "|", outro)

10 15
Ana | Ana Clara

b += 5 criou o número 15 e colou a etiqueta b nele; o a continuou no 10.

O limite da cópia simples

copy() faz uma cópia rasa: copia a lista de fora, mas as listas que estão dentro dela continuam compartilhadas.

grade = [["seg", "ter"], ["qua", "qui"]]
copia = grade.copy()
copia.append(["sex"])
copia[0].append("EXTRA")
print(grade)
print(copia)

[['seg', 'ter', 'EXTRA'], ['qua', 'qui']]
[['seg', 'ter', 'EXTRA'], ['qua', 'qui'], ['sex']]

O append(["sex"]) mexeu só na cópia, mas copia[0].append("EXTRA") mudou a lista interna, que é a mesma nas duas. Para copiar tudo, inclusive as listas de dentro, existe a cópia profunda com copy.deepcopy, que você verá na aula 47.

Dica: Quando estiver confuso, use print(id(x)) ou x is y para descobrir se dois nomes apontam para o mesmo objeto.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
copia = original.copy()

Exercícios

1. Explique o que o programa mostra: a = [1, 2], b = a, b.append(3), print(a). Depois corrija para que a não mude.

Ver resposta 
a = [1, 2]
b = a.copy()
b.append(3)
print(a)
print(b)

[1, 2]
[1, 2, 3]

No original, b = a não copia: as duas variáveis apontam para a mesma lista, então print(a) mostraria [1, 2, 3]. Com a.copy(), b é uma lista nova.

2. Você tem cardapio = ["arroz", "feijão", "salada"]. Crie cardapio_domingo como uma cópia com a fatia [:], troque o último item da cópia por "lasanha" e mostre as duas listas.

Ver resposta 
cardapio = ["arroz", "feijão", "salada"]
cardapio_domingo = cardapio[:]
cardapio_domingo[-1] = "lasanha"
print(cardapio)
print(cardapio_domingo)

['arroz', 'feijão', 'salada']
['arroz', 'feijão', 'lasanha']

3. Para cada par abaixo, diga se o resultado é True ou False e confira: x = [1] e y = [1], compare x == y e x is y; depois z = x, compare z is x.

Ver resposta 
x = [1]
y = [1]
print(x == y)
print(x is y)
z = x
print(z is x)

True
False
True

x e y têm os mesmos itens, mas são duas listas diferentes. z = x só cria outro nome para a mesma lista.

4. Por que, no programa abaixo, a lista pontos termina com 4 itens se só mexemos em backup? pontos = [10, 20], backup = pontos, backup += [30, 40]. Rode e corrija.

Ver resposta 
pontos = [10, 20]
backup = list(pontos)
backup += [30, 40]
print(pontos)
print(backup)

[10, 20]
[10, 20, 30, 40]

Com listas, += altera a lista no lugar (como o extend). Como backup = pontos era só um apelido, a mudança aparecia em pontos. Com list(pontos), o backup é independente.
