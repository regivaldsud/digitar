Métodos com dois sublinhados

Você já conhece um método especial: o __init__. Existem muitos outros, todos com dois sublinhados antes e depois do nome — por isso são chamados de dunder (de *double underscore*). Você quase nunca os chama diretamente: o Python chama sozinho quando você usa print, +, ==, len()...

print(len("Brasil"), "Brasil".__len__())
print(2 + 3, (2).__add__(3))

6 6
5 5

Quando você escreve len(x), o Python chama x.__len__(). Ao criar esses métodos na sua classe, ela passa a funcionar com essas operações.

__str__ e __repr__: como o objeto aparece

Sem eles, o print mostra algo como <__main__.Produto object at 0x...>, que não ajuda ninguém.

  • __str__ devolve o texto para o usuário, usado no print e no str();
  • __repr__ devolve a versão para programadores, usada dentro de listas e no modo interativo. O costume é parecer o código que cria o objeto.
class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

    def __str__(self):
        return f"{self.nome} - R$ {self.preco:.2f}"

    def __repr__(self):
        return f"Produto({self.nome!r}, {self.preco})"

coxinha = Produto("Coxinha", 6.5)
print(coxinha)
print([coxinha, Produto("Suco", 7)])
print(f"No cardápio: {coxinha}")

Coxinha - R$ 6.50
[Produto('Coxinha', 6.5), Produto('Suco', 7)]
No cardápio: Coxinha - R$ 6.50

Atenção: __str__ e __repr__ precisam devolver um texto com return, não dar print. Sem return, aparece TypeError: __str__ returned non-string (type NoneType).
Dica: Se a classe tiver só __repr__, o print usa ele também. Por isso, se for escrever um só, escreva o __repr__.

__add__: somando objetos

O __add__(self, outro) define o que a + b faz. Ele deve devolver um objeto novo, sem mudar os dois originais.

class Dinheiro:
    def __init__(self, centavos):
        self.centavos = centavos

    def __add__(self, outro):
        return Dinheiro(self.centavos + outro.centavos)

    def __repr__(self):
        reais = self.centavos / 100
        return "R$ " + f"{reais:.2f}".replace(".", ",")

lanche = Dinheiro(1250)
suco = Dinheiro(600)
total = lanche + suco
print(lanche, "+", suco, "=", total)
print(sum([lanche, suco, Dinheiro(150)], Dinheiro(0)))

R$ 12,50 + R$ 6,00 = R$ 18,50
R$ 20,00

Existem também __sub__ (-), __mul__ (*) e __truediv__ (/).

__eq__ e __lt__: comparando

Sem __eq__, dois objetos só são iguais se forem o mesmo objeto. Com ele, você decide o que é "igual". O __lt__ (*less than*, menor que) define o < — e com ele o sorted já consegue ordenar.

class Ponto:
    def __init__(self, x, y):
        self.x = x
        self.y = y

print(Ponto(1, 2) == Ponto(1, 2))

class Ponto2:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, outro):
        return (self.x, self.y) == (outro.x, outro.y)

print(Ponto2(1, 2) == Ponto2(1, 2))

False
True

class Atleta:
    def __init__(self, nome, tempo):
        self.nome = nome
        self.tempo = tempo

    def __lt__(self, outro):
        return self.tempo < outro.tempo

    def __repr__(self):
        return f"{self.nome} ({self.tempo}s)"

corrida = [Atleta("Vitor", 10.4), Atleta("Rosa", 9.9), Atleta("Leo", 10.1)]
print(sorted(corrida))
print("Vencedora:", min(corrida))

[Rosa (9.9s), Leo (10.1s), Vitor (10.4s)]
Vencedora: Rosa (9.9s)

__len__, __getitem__ e __contains__: objetos que parecem listas

Com __len__ o objeto funciona com len(). Com __getitem__, ele aceita colchetes (playlist[0]) e ainda pode ser percorrido com for. Com __contains__, funciona com in.

class Playlist:
    def __init__(self, nome, musicas):
        self.nome = nome
        self._musicas = list(musicas)

    def __len__(self):
        return len(self._musicas)

    def __getitem__(self, i):
        return self._musicas[i]

    def __contains__(self, musica):
        return musica in self._musicas

p = Playlist("Estudar", ["Garota de Ipanema", "Aquarela", "Trem das Onze"])
print(len(p), "músicas")
print(p[0], "|", p[-1])
print("Aquarela" in p)
for musica in p:
    print("-", musica)

3 músicas
Garota de Ipanema | Trem das Onze
True
- Garota de Ipanema
- Aquarela
- Trem das Onze

2. Crie a classe Vetor(x, y) com __add__, __mul__ (multiplica por um número) e __repr__. Mostre Vetor(1, 2) + Vetor(3, 4) e Vetor(1, 2) * 3.

Ver resposta 
class Vetor:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, outro):
        return Vetor(self.x + outro.x, self.y + outro.y)

    def __mul__(self, numero):
        return Vetor(self.x * numero, self.y * numero)

    def __repr__(self):
        return f"Vetor({self.x}, {self.y})"

print(Vetor(1, 2) * 3)

3. Crie a classe Carta(valor, naipe) com __eq__ (iguais se valor e naipe forem iguais) e __lt__ (compara só o valor). Ordene a mão [Carta(7, "copas"), Carta(2, "ouros"), Carta(11, "espadas")].

Ver resposta 
class Carta:
    def __init__(self, valor, naipe):
        self.valor = valor
        self.naipe = naipe

    def __eq__(self, outra):
        return (self.valor, self.naipe) == (outra.valor, outra.naipe)

    def __lt__(self, outra):
        return self.valor < outra.valor

    def __repr__(self):
        return f"{self.valor} de {self.naipe}"

mao = [Carta(7, "copas"), Carta(2, "ouros"), Carta(11, "espadas")]
print(sorted(mao))
print(Carta(7, "copas") == Carta(7, "copas"))

True

4. Crie a classe Fila com os métodos entrar(nome) e atender() (tira o primeiro), e com __len__ e __contains__. Mostre o tamanho da fila e se alguém está nela.

Ver resposta 
class Fila:
    def __init__(self):
        self._pessoas = []

    def entrar(self, nome):
        self._pessoas.append(nome)

    def atender(self):
        return self._pessoas.pop(0)

    def __len__(self):
        return len(self._pessoas)

    def __contains__(self, nome):
        return nome in self._pessoas

f = Fila()
for nome in ["Dona Rosa", "Seu Jorge", "Bia"]:
    f.entrar(nome)
print("Atendido:", f.atender())
print("Na fila:", len(f))
print("Dona Rosa está na fila?", "Dona Rosa" in f)
print("Bia está na fila?", "Bia" in f)

Atendido: Dona Rosa
Na fila: 2
Dona Rosa está na fila? False
Bia está na fila? True
