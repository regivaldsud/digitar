Módulo 6 · Testes automatizados

Aula 134 · Introdução ao pytest

Nesta aula você vai aprender

  • Instalar o pytest com pip e rodar testes no terminal
  • Escrever testes como funções simples com assert
  • Testar erros com pytest.raises
  • Testar vários casos de uma vez com @pytest.mark.parametrize

Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Por que pytest

O pytest faz o mesmo trabalho do unittest (aula 131), só que com menos código: os testes são funções comuns e você usa o assert do próprio Python (aula 130). Ele não vem com o Python; instale com o pip, de preferência dentro do ambiente virtual do projeto (aula 60):

pip install pytest
pytest --version
Atenção: O pytest roda no seu computador, pelo terminal — por isso os exemplos desta aula não têm o botão Executar. As saídas mostradas são as reais.

O código que vamos testar

Imagine o arquivo notas.py, de um programa da escola:

def media(notas):
    if not notas:
        raise ValueError("lista de notas vazia")
    return sum(notas) / len(notas)


def situacao(media_final):
    if media_final >= 7:
        return "aprovado"
    if media_final >= 5:
        return "recuperação"
    return "reprovado"

Seu primeiro teste

Na mesma pasta, crie test_notas.py. Cada função com nome começando por test_ é um teste. Dentro dela, assert seguido de algo que deve ser verdadeiro:

from notas import media, situacao


def test_media_simples():
    assert media([6, 8, 10]) == 8


def test_aprovado():
    assert situacao(7.5) == "aprovado"


def test_reprovado():
    assert situacao(3) == "reprovado"

Para rodar, abra o terminal na pasta e digite só pytest (ou pytest -q, para uma saída mais curta). Ele encontra sozinho os arquivos test_*.py:

pytest -q

...                                [100%]
3 passed in 0.01s

Dica: Os três pontinhos são os três testes que passaram. Use pytest -v para ver o nome de cada um.

Testando erros com pytest.raises

Para garantir que um erro acontece, use with pytest.raises(TipoDoErro):. Se o erro não acontecer, o teste falha.

import pytest

from notas import media


def test_media_de_lista_vazia_da_erro():
    with pytest.raises(ValueError):
        media([])

Vários casos de uma vez: parametrize

Em vez de copiar o mesmo teste várias vezes, o decorador @pytest.mark.parametrize roda a função uma vez para cada caso da lista:

import pytest

from notas import situacao


@pytest.mark.parametrize("nota, esperado", [
    (10, "aprovado"),
    (7, "aprovado"),
    (6.9, "recuperação"),
    (5, "recuperação"),
    (4.9, "reprovado"),
])
def test_situacao(nota, esperado):
    assert situacao(nota) == esperado

.....                              [100%]
5 passed in 0.01s

Repare nos casos escolhidos: 7 e 6.9, 5 e 4.9. Os valores logo antes e logo depois de cada limite são onde os erros costumam se esconder.

Quando um teste falha

Vamos ver uma falha de verdade. Este teste espera a média errada de propósito:

from notas import media


def test_media_errada():
    assert media([5, 6]) == 6

F                                  [100%]
============ FAILURES ============
________ test_media_errada ________
 
    def test_media_errada():
>       assert media([5, 6]) == 6
E       assert 5.5 == 6
E        +  where 5.5 = media([5, 6])
 
test_falha.py:5: AssertionError
===== short test summary info =====
FAILED test_falha.py::test_media_errada - assert 5.5 == 6
1 failed in 0.01s

O pytest mostra a linha que falhou (marcada com >) e, nas linhas com E, o valor de verdade: media([5, 6]) deu 5.5, não 6. Aqui o erro estava no teste, não na função — também acontece!

Atenção: Se o pytest disser no tests ran (nenhum teste rodou), confira os nomes: o arquivo precisa começar com test_ e as funções também.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
assert media([6, 8, 10]) == 8

3. Use parametrize para testar a função e_bissexto(ano) com 2024 (sim), 2023 (não), 1900 (não) e 2000 (sim). Escreva a função no próprio arquivo de teste.

Ver resposta 
import pytest


def e_bissexto(ano):
    return ano % 4 == 0 and (ano % 100 != 0 or ano % 400 == 0)


@pytest.mark.parametrize("ano, esperado", [
    (2024, True),
    (2023, False),
    (1900, False),
    (2000, True),
])
def test_bissexto(ano, esperado):
    assert e_bissexto(ano) == esperado
