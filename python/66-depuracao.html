O que é um bug

Um bug é um erro no programa. Às vezes ele causa uma exceção e o programa para; outras vezes, pior, o programa roda mas dá o resultado errado. Depurar (em inglês, *debug*) é o trabalho de detetive de achar e corrigir esse erro.

O segredo é não chutar: observe o que o programa realmente faz, compare com o que você esperava e descubra em que linha os dois se separam.

Lendo um traceback de várias chamadas

Na aula 06 você aprendeu a ler uma mensagem de erro simples. Quando uma função chama outra, e o erro acontece lá no fundo, o Python mostra o caminho todo. Isso se chama traceback ("rastro de volta").

def preco_com_desconto(preco, desconto):
    return preco - preco * desconto / 100

def total_carrinho(itens):
    total = 0
    for preco, desconto in itens:
        total += preco_com_desconto(preco, desconto)
    return total

carrinho = [(50, 10), (30, "5")]
print(total_carrinho(carrinho))

TypeError: unsupported operand type(s) for /: 'str' and 'int'

No seu computador, a mensagem completa fica parecida com esta:

Traceback (most recent call last):
  File "loja.py", line 11, in <module>
    print(total_carrinho(carrinho))
  File "loja.py", line 7, in total_carrinho
    total += preco_com_desconto(preco, desconto)
  File "loja.py", line 2, in preco_com_desconto
    return preco - preco * desconto / 100
TypeError: unsupported operand type(s) for /: 'str' and 'int'

Como ler:

  • comece pela última linha: ela diz o tipo do erro e o motivo — aqui, tentaram dividir um texto (str) por um número;
  • suba uma linha: ela mostra onde o erro aconteceu (arquivo, número da linha e o código);
  • continue subindo para ver quem chamou quem, até chegar ao começo do programa (<module>).

O erro estourou na linha 2, mas a causa está na linha 10: o desconto "5" foi escrito entre aspas.

print de depuração

A ferramenta mais simples é colocar print no meio do código para ver os valores das variáveis. Veja este programa que deveria calcular a média, mas dá um resultado estranho:

notas = [8, 6, 10]
soma = 0
for nota in notas:
    soma = nota
    print(f"[depuração] nota={nota} soma={soma}")
media = soma / len(notas)
print("Média:", media)

[depuração] nota=8 soma=8
[depuração] nota=6 soma=6
[depuração] nota=10 soma=10
Média: 3.3333333333333335

Os prints mostram que soma não acumula: ela só guarda a última nota. O certo é soma += nota. Depois de corrigir, apague os prints de depuração.

Dica: Coloque uma marca como [depuração] nos seus prints. Fica fácil achar e apagar todos depois.

Mostrando o tipo e o valor exato

Muitos bugs vêm de um valor que parece um número mas é um texto. O print comum esconde isso; type() e repr() mostram a verdade. Na f-string, {variavel=} mostra o nome e o valor de uma vez:

idade = "13"
anos_ate_maioridade = "5"
print(idade + anos_ate_maioridade)
print(f"{idade=} {type(idade)=}")
print(repr(" Ana "), repr("13"), repr(13))

135
idade='13' type(idade)=<class 'str'>
' Ana ' '13' 13

O resultado 135 parecia mágica, mas o type revela: são dois textos, e + com textos junta, não soma. O repr também mostra os espaços escondidos em " Ana ", outro bug muito comum ao ler dados digitados.

assert: conferindo suposições

O assert verifica se algo é verdade. Se for, nada acontece; se não for, o programa para com AssertionError e a mensagem que você escolheu. É um jeito de pegar o bug cedo, perto de onde ele nasce.

def porcentagem(acertos, total):
    resultado = acertos / total * 100
    assert 0 <= resultado <= 100, f"porcentagem impossível: {resultado}"
    return resultado

print(porcentagem(45, 50))
print(porcentagem(50, 45))

90.0
AssertionError: porcentagem impossível: 111.11111111111111

Atenção: Use assert para conferir erros de programação, não para validar o que o usuário digita. Para isso, use if e raise (ou try), como na aula 53.

breakpoint(): pausando o programa

O breakpoint() pausa o programa naquela linha e abre o pdb, o depurador que vem com o Python. Ele funciona no terminal do seu computador (aqui no navegador, não).

def contar_vogais(palavra):
    total = 0
    for letra in palavra:
        breakpoint()
        if letra in "aeiou":
            total += 1
    return total

print(contar_vogais("Amapá"))

Rode no terminal com python vogais.py. O programa para e mostra o prompt (Pdb), onde você digita comandos:

> vogais.py(5)contar_vogais()
-> if letra in "aeiou":
(Pdb) p letra
'A'
(Pdb) p total
0
(Pdb) n
> vogais.py(3)contar_vogais()
-> for letra in palavra:
(Pdb) c

Os comandos principais:

  • p variavel: mostra o valor (de *print*);
  • n: executa a próxima linha (de *next*);
  • s: entra dentro da função chamada nessa linha (de *step*);
  • c: continua até o próximo breakpoint (de *continue*);
  • q: sai do depurador e encerra o programa (de *quit*).

O depurador do VS Code

O VS Code faz o mesmo com cliques:

  • clique à esquerda do número da linha: aparece uma bolinha vermelha, o ponto de parada;
  • aperte F5 e escolha "Python File" (ou o ícone de inseto ao lado do ▶);
  • o programa para na bolinha, e o painel Variáveis mostra todos os valores;
  • F10 executa a próxima linha, F11 entra na função e F5 continua.
Dica: Depurar é uma habilidade que se treina. Toda vez que algo der errado, antes de mudar o código, pergunte: "o que eu esperava ver?" e "o que apareceu de verdade?".
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
assert total >= 0, "o total não pode ser negativo"

Exercícios

1. Um programa deveria mostrar o maior número de numeros = [-8, -3, -15]. Ele começa com maior = 0 e, num for, troca maior sempre que n > maior. Mas mostra Maior: 0. Use um print de depuração para entender e corrija.

Ver resposta 
numeros = [-8, -3, -15]
maior = numeros[0]
for n in numeros:
    if n > maior:
        maior = n
print("Maior:", maior)

Maior: -3

O bug era começar com maior = 0: nenhum número negativo é maior que zero. Começar com o primeiro elemento da lista resolve.

2. Leia o traceback abaixo e responda: qual é o tipo do erro, em que linha ele aconteceu e em que linha está a chamada que levou até ele?

Ver resposta

Traceback (most recent call last):
  File "boletim.py", line 8, in <module>
    mostrar("Rafa", notas)
  File "boletim.py", line 4, in mostrar
    print(nome, notas[nome])
KeyError: 'Rafa'

O tipo é KeyError: a chave 'Rafa' não existe no dicionário notas. O erro aconteceu na linha 4, dentro da função mostrar, que foi chamada na linha 8.

5. Um colega quer contar quantas palavras de ["sol", "cachoeira", "mar", "montanha", "praia"] têm mais de 4 letras. Dentro do for p in palavras: ele escreveu contador = 0 e depois if len(p) > 4: contador += 1. O programa sempre mostra 1. Descubra o bug e corrija.

Ver resposta 
palavras = ["sol", "cachoeira", "mar", "montanha", "praia"]
contador = 0
for p in palavras:
    if len(p) > 4:
        contador += 1
print(contador)

3

Na versão com bug, a linha contador = 0 estava dentro do for, zerando o contador a cada palavra. Um print de contador dentro do laço mostra isso na hora.
