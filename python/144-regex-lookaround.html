Aula 144 · Lookahead e lookbehind

Nesta aula você vai aprender

  • Entender o que é um lookaround (olhar em volta)
  • Usar o lookahead positivo (?=...) e o negativo (?!...)
  • Usar o lookbehind positivo (?<=...) e o negativo (?<!...)
  • Validar senhas e formatar números com lookarounds

Olhar sem pegar

Às vezes você quer achar algo só se vier antes ou depois de outra coisa, mas sem colocar essa outra coisa no resultado. Exemplo: pegar só o número dos preços, sem o R$.

Os lookarounds conferem o que está em volta e não "gastam" nenhum caractere:

  • (?=...): o que vem depois tem que ser isso (lookahead positivo).
  • (?!...): o que vem depois não pode ser isso (lookahead negativo).
  • (?<=...): o que vem antes tem que ser isso (lookbehind positivo).
  • (?<!...): o que vem antes não pode ser isso (lookbehind negativo).

Lookbehind: o que vem antes

Pegue os valores em reais, sem o símbolo:

import re

extrato = "Lanche R$ 18, Uber R$ 25, 3 pastéis e R$ 9 de caldo de cana"
valores = re.findall(r"(?<=R\$ )\d+", extrato)
print(valores)
print("Total:", sum(map(int, valores)))

['18', '25', '9']
Total: 52

Os 3 pastéis não entraram, porque não vinham depois de R$ . E o R$ não aparece no resultado.

Com o lookbehind negativo, você pega números que não vêm depois de um sinal de menos:

import re

print(re.findall(r"(?<![-\d])\d+", "Temperaturas: 12, -3, 25, -7"))

['12', '25']

Atenção: No Python, o lookbehind precisa ter tamanho fixo: (?<=R\$ ) funciona, mas (?<=R\$ *) dá erro look-behind requires fixed-width pattern.

Lookahead: o que vem depois

Pegue as palavras que vêm antes de um ponto de exclamação, e as quantidades que não são em gramas:

import re

print(re.findall(r"\w+(?=!)", "Gol! Que jogo! Incrível"))
print(re.findall(r"\b\d+(?!\d|g)\b", "200g de queijo, 3 ovos, 500g de farinha, 2 xícaras"))

['Gol', 'jogo']
['3', '2']

Validando senhas

Lookaheads no começo do padrão funcionam como uma lista de exigências: cada um confere uma regra no texto todo, sem sair do lugar.

import re

SENHA_FORTE = re.compile(r"""
    (?=.*[a-z])      # pelo menos uma minúscula
    (?=.*[A-Z])      # pelo menos uma maiúscula
    (?=.*\d)         # pelo menos um dígito
    .{8,}            # oito caracteres ou mais
""", re.VERBOSE)

for senha in ["abc123", "abcdefgh1", "Abcdefgh1", "SENHA2025x"]:
    status = "forte" if SENHA_FORTE.fullmatch(senha) else "fraca"
    print(f"{senha}: {status}")

abc123: fraca
abcdefgh1: fraca
Abcdefgh1: forte
SENHA2025x: forte

Dica: Regras de senha também podem ser escritas com any() e laços, sem regex. Escolha a forma que você e sua equipe leem com mais facilidade.

Separando milhares

Um truque famoso: colocar pontos de milhar com re.sub e lookarounds. O padrão acha posições (não caracteres) em que, à direita, há grupos de três dígitos até o fim do número:

import re


def milhares(numero):
    return re.sub(r"(?<=\d)(?=(\d{3})+(?!\d))", ".", str(numero))


print(milhares(1234567))
print(milhares(950))
print(milhares(2026000))

1.234.567
950
2.026.000

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
re.findall(r"(?<=R\$ )\d+", extrato)

Exercícios

1. Pegue só os nomes de usuário (sem o @) em "Valeu @ana_b e @joaoP pelo jogo!".

Ver resposta 
import re

print(re.findall(r"(?<=@)\w+", "Valeu @ana_b e @joaoP pelo jogo!"))

['ana_b', 'joaoP']

2. Ache os números seguidos de "km" em "Corri 5km, andei 3 km e pedalei 20km" (só quando o km vem colado), sem incluir o km.

Ver resposta 
import re

print(re.findall(r"\d+(?=km)", "Corri 5km, andei 3 km e pedalei 20km"))

['5', '20']

3. Escreva uma regex com lookahead que aceite só senhas com pelo menos um dígito e 6 caracteres ou mais. Teste com "abcdef", "abc123" e "a1".

Ver resposta 
import re

for senha in ["abcdef", "abc123", "a1"]:
    print(senha, bool(re.fullmatch(r"(?=.*\d).{6,}", senha)))

abcdef False
abc123 True
a1 False

4. Ache as palavras que começam com "pre" mas não com "prev" em "prever presente prego previsão preço".

Ver resposta 
import re

print(re.findall(r"\bpre(?!v)\w*", "prever presente prego previsão preço"))

['presente', 'prego', 'preço']
