Por que a janela "congela"

A janela só redesenha e responde a cliques quando o laço de eventos (app.exec()) está livre. Se um slot fica 10 segundos baixando um arquivo ou fazendo contas, o laço para e o Windows mostra "Não respondendo". A solução é rodar o trabalho em outra thread — uma linha de execução paralela.

O padrão trabalhador + QThread

import sys
import time
from PySide6.QtCore import QObject, QThread, Signal
from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout,
                               QPushButton, QProgressBar)


class Trabalhador(QObject):
    progresso = Signal(int)
    terminou = Signal()

    def rodar(self):
        for i in range(1, 101):
            time.sleep(0.05)  # finge um trabalho demorado
            self.progresso.emit(i)
        self.terminou.emit()


class Janela(QWidget):
    def __init__(self):
        super().__init__()
        self.barra = QProgressBar()
        self.botao = QPushButton("Começar")
        self.botao.clicked.connect(self.comecar)
        layout = QVBoxLayout(self)
        layout.addWidget(self.barra)
        layout.addWidget(self.botao)

    def comecar(self):
        self.botao.setEnabled(False)
        self.thread = QThread()
        self.trabalhador = Trabalhador()
        self.trabalhador.moveToThread(self.thread)
        self.thread.started.connect(self.trabalhador.rodar)
        self.trabalhador.progresso.connect(self.barra.setValue)
        self.trabalhador.terminou.connect(self.thread.quit)
        self.thread.finished.connect(lambda: self.botao.setEnabled(True))
        self.thread.start()


app = QApplication(sys.argv)
janela = Janela()
janela.show()
sys.exit(app.exec())

O Trabalhador nunca mexe nos widgets diretamente: ele só emite sinais (progresso, terminou). O Qt entrega esses sinais na thread da janela, que atualiza a barra com segurança.

Atenção: Nunca altere um widget de dentro da outra thread (por exemplo, self.barra.setValue(i) dentro de rodar). Isso pode travar ou fechar o programa sem aviso. Use sinais.
Dica: Guarde a thread e o trabalhador em self. — se forem variáveis locais, o Python os apaga no fim do método enquanto ainda estão rodando.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
progresso = Signal(int)

Exercícios

1. Crie um sinal mensagem que envia um texto (str) e emita "Metade feita!" quando i chegar a 50. Mostre só a classe Trabalhador.

Ver resposta 
import time
from PySide6.QtCore import QObject, Signal


class Trabalhador(QObject):
    progresso = Signal(int)
    mensagem = Signal(str)
    terminou = Signal()

    def rodar(self):
        for i in range(1, 101):
            time.sleep(0.05)
            self.progresso.emit(i)
            if i == 50:
                self.mensagem.emit("Metade feita!")
        self.terminou.emit()

2. Por que o botão "Começar" é desativado em comecar e só reativado no finished da thread?

Para o usuário não clicar de novo e iniciar uma segunda thread enquanto a primeira
ainda está rodando. Quando a thread termina, o botão volta a funcionar.
