Aula 110 · sys.argv e argparse

Nesta aula você vai aprender

  • Ler os argumentos do terminal com sys.argv
  • Criar opções e ajuda automática com argparse
  • Converter e validar argumentos com type e choices
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

sys.argv

Quando você roda python saudar.py Ana Bia, as palavras depois do nome do arquivo chegam ao programa na lista sys.argv. A posição 0 é o nome do próprio arquivo:

# saudar.py
import sys

print("Argumentos:", sys.argv)
for nome in sys.argv[1:]:
    print(f"Olá, {nome}!")
python saudar.py Ana Bia

Argumentos: ['saudar.py', 'Ana', 'Bia']
Olá, Ana!
Olá, Bia!

Atenção: Tudo em sys.argv é texto. Para somar números recebidos assim, converta com int() ou float(). E se o usuário não passar nada, sys.argv[1] dá IndexError.

argparse: um programa de verdade

O argparse faz o trabalho chato: lê os argumentos, converte tipos, mostra erros claros e cria a ajuda --help sozinho. Para testar sem terminal, dá para passar a lista de argumentos direto para parse_args:

import argparse

parser = argparse.ArgumentParser(description="Mostra a tabuada de um número.")
parser.add_argument("numero", type=int, help="o número da tabuada")
parser.add_argument("--ate", type=int, default=10, help="até onde ir (padrão: 10)")

args = parser.parse_args(["7", "--ate", "3"])   # no terminal: parser.parse_args()

for i in range(1, args.ate + 1):
    print(f"{args.numero} x {i} = {args.numero * i}")

7 x 1 = 7
7 x 2 = 14
7 x 3 = 21

No programa de verdade, use parser.parse_args() sem lista e rode:

python tabuada.py 7 --ate 3
python tabuada.py --help
  • argumentos posicionais (numero) são obrigatórios;
  • argumentos com -- (--ate) são opcionais e podem ter default;
  • type=int converte o texto para número e dá uma mensagem de erro se não der.

Escolhas e chaves liga/desliga

import argparse

parser = argparse.ArgumentParser(description="Pedido de pizza")
parser.add_argument("sabor", choices=["calabresa", "mussarela", "portuguesa"])
parser.add_argument("--borda", action="store_true", help="com borda recheada")

args = parser.parse_args(["calabresa", "--borda"])
print("Sabor:", args.sabor)
print("Borda recheada:", args.borda)

Sabor: calabresa
Borda recheada: True

choices só aceita os valores da lista, e action="store_true" cria uma opção que vale True quando aparece e False quando não aparece.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
parser.add_argument("--ate", type=int, default=10)

Exercícios

1. Escreva um programa com sys.argv que soma todos os números passados no terminal (python somar.py 4 5 10 mostra 19).

Ver resposta 
import sys

numeros = [float(x) for x in sys.argv[1:]]
print(sum(numeros))

2. Com argparse, crie um programa conversor.py que recebe uma temperatura em Celsius e a opção --kelvin. Sem a opção, mostra em Fahrenheit; com ela, em Kelvin. Teste com a lista ["30", "--kelvin"].

Ver resposta 
import argparse

parser = argparse.ArgumentParser(description="Converte temperaturas")
parser.add_argument("celsius", type=float)
parser.add_argument("--kelvin", action="store_true")
args = parser.parse_args(["30", "--kelvin"])

if args.kelvin:
    print(args.celsius + 273.15, "K")
else:
    print(args.celsius * 9 / 5 + 32, "°F")

303.15 K
