Aula 110 · sys.argv e argparse

Nesta aula você vai aprender

  • Entender o que são argumentos de linha de comando e para que servem
  • Ler os argumentos do terminal com sys.argv
  • Criar argumentos posicionais e opcionais com argparse
  • Converter e validar com type, choices, nargs e action="store_true"
  • Usar a ajuda automática --help e entender as mensagens de erro
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Para que servem argumentos

Até agora seus programas perguntavam as coisas com input(). Programas de terminal costumam receber as informações já na hora de rodar, escritas depois do nome do arquivo:

py tabuada.py 7
py renomear.py fotos --prefixo ferias

Isso tem vantagens: dá para repetir o comando sem digitar tudo de novo (seta para cima no terminal), dá para usar o programa dentro de outros programas e dá para agendar o programa para rodar sozinho. Cada palavra depois do nome do arquivo é um argumento.

Esta aula é para o computador porque os argumentos vêm do terminal. Mas os exemplos com o botão Executar simulam o terminal, passando a lista de argumentos direto para o programa.

sys.argv: a lista crua

Quando você roda py saudar.py Ana Bia, as palavras chegam ao programa na lista sys.argv. A posição 0 é o nome do próprio arquivo; os argumentos começam na posição 1. Aqui simulamos o terminal colocando a lista à mão:

import sys

sys.argv = ["saudar.py", "Ana", "Bia"]   # simula: py saudar.py Ana Bia

print("Argumentos:", sys.argv)
print("Nome do programa:", sys.argv[0])
for nome in sys.argv[1:]:
    print(f"Olá, {nome}!")

Argumentos: ['saudar.py', 'Ana', 'Bia']
Nome do programa: saudar.py
Olá, Ana!
Olá, Bia!

No seu computador, apague a linha que simula e rode de verdade:

# saudar.py
import sys

for nome in sys.argv[1:]:
    print(f"Olá, {nome}!")
py saudar.py Ana Bia

Olá, Ana!
Olá, Bia!

Atenção: Tudo em sys.argv é texto. Para somar números recebidos assim, converta com int() ou float(). E se o usuário não passar nada, sys.argv[1] dá IndexError: confira antes com len(sys.argv).
Dica: Um argumento com espaço vai entre aspas: py saudar.py "Ana Clara" Bia entrega dois argumentos, "Ana Clara" e "Bia".

sys.argv com verificação

Com sys.argv você mesmo precisa conferir tudo: se veio a quantidade certa de argumentos e se eles são números. O programa abaixo calcula a média e avisa como usar quando algo está errado:

import sys

def principal(argv):
    if len(argv) < 2:
        print("Uso: py media.py NOTA1 NOTA2 ...")
        return
    try:
        notas = [float(x) for x in argv[1:]]
    except ValueError:
        print("Erro: todas as notas precisam ser números.")
        return
    print(f"Média de {len(notas)} notas: {sum(notas) / len(notas):.1f}")

principal(["media.py", "7", "8.5", "10"])
principal(["media.py"])
principal(["media.py", "7", "dez"])

Média de 3 notas: 8.5
Uso: py media.py NOTA1 NOTA2 ...
Erro: todas as notas precisam ser números.

No programa de verdade, a última linha seria só principal(sys.argv). Funciona, mas dá trabalho: imagine conferir opções, valores padrão e escrever a ajuda à mão. É para isso que existe o argparse.

argparse: um programa de verdade

O argparse lê os argumentos, converte os tipos, mostra erros claros e cria a ajuda --help sozinho. Você descreve o que o programa aceita e ele faz o resto. Para testar sem terminal, passe a lista de argumentos (sem o nome do arquivo) para parse_args:

import argparse

parser = argparse.ArgumentParser(prog="tabuada.py", description="Mostra a tabuada de um número.")
parser.add_argument("numero", type=int, help="o número da tabuada")
parser.add_argument("--ate", type=int, default=10, help="até onde ir (padrão: 10)")

args = parser.parse_args(["7", "--ate", "3"])   # no terminal: parser.parse_args()
print(args)

for i in range(1, args.ate + 1):
    print(f"{args.numero} x {i} = {args.numero * i}")

Namespace(numero=7, ate=3)
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21

  • argumentos posicionais (numero) são obrigatórios e a ordem importa;
  • argumentos com -- (--ate) são opcionais, podem vir em qualquer ordem e têm um default;
  • type=int converte o texto para número — dentro do programa, args.numero já é um int;
  • o resultado é um objeto Namespace, e cada argumento vira um atributo: args.numero, args.ate.

No seu computador, troque a lista por parser.parse_args() e rode:

py tabuada.py 7 --ate 3
py tabuada.py --help

Ajuda automática e mensagens de erro

O --help (ou -h) aparece sem você escrever nada, usando os textos de description e help. Aqui mostramos a ajuda com print_help():

import argparse

parser = argparse.ArgumentParser(prog="tabuada.py", description="Mostra a tabuada de um número.")
parser.add_argument("numero", type=int, help="o número da tabuada")
parser.add_argument("-a", "--ate", type=int, default=10, help="até onde ir (padrão: 10)")
parser.print_help()

usage: tabuada.py [-h] [-a ATE] numero
 
Mostra a tabuada de um número.
 
positional arguments:
  numero             o número da tabuada
 
options:
  -h, --help         show this help message and exit
  -a ATE, --ate ATE  até onde ir (padrão: 10)

Repare que -a virou um atalho para --ate. Quando o usuário erra, o argparse mostra o uso certo e encerra o programa. No terminal, py tabuada.py sete mostra:

usage: tabuada.py [-h] [-a ATE] numero
tabuada.py: error: argument numero: invalid int value: 'sete'

Para ver esse erro aqui no navegador sem encerrar o bloco, crie o parser com exit_on_error=False: em vez de encerrar, ele lança uma exceção que você pode tratar com try:

import argparse

parser = argparse.ArgumentParser(prog="tabuada.py", exit_on_error=False)
parser.add_argument("numero", type=int)

try:
    parser.parse_args(["sete"])
except argparse.ArgumentError as erro:
    print("Erro:", erro)

Erro: argument numero: invalid int value: 'sete'

Atenção: O argparse encerra o programa (com SystemExit) quando mostra a ajuda ou um erro. Isso é o certo num programa de terminal, mas pode assustar quando você testa num editor ou aqui no site. Não confunda: não é o seu programa que quebrou, é o argparse avisando que os argumentos estavam errados.

Escolhas, chaves liga/desliga e listas

import argparse

parser = argparse.ArgumentParser(prog="pizza.py", description="Pedido de pizza")
parser.add_argument("sabor", choices=["calabresa", "mussarela", "portuguesa"])
parser.add_argument("--borda", action="store_true", help="com borda recheada")
parser.add_argument("--extras", nargs="*", default=[], help="ingredientes extras")
parser.add_argument("-q", "--quantidade", type=int, default=1)

args = parser.parse_args(["calabresa", "--borda", "--extras", "milho", "azeitona", "-q", "2"])
print("Sabor:", args.sabor)
print("Borda recheada:", args.borda)
print("Extras:", args.extras)
print("Quantidade:", args.quantidade)

sem_nada = parser.parse_args(["mussarela"])
print(sem_nada.borda, sem_nada.extras, sem_nada.quantidade)

Sabor: calabresa
Borda recheada: True
Extras: ['milho', 'azeitona']
Quantidade: 2
False [] 1

  • choices só aceita os valores da lista;
  • action="store_true" cria uma opção que vale True quando aparece e False quando não aparece;
  • nargs="*" junta zero ou mais valores numa lista; nargs="+" exige pelo menos um.
Dica: Ao escrever o nome de uma opção com hífen, como --sem-som, o atributo troca o hífen por sublinhado: args.sem_som.

No seu computador: um programa completo

Junte tudo num programa que conta palavras de um texto. Salve como contar.py e rode no terminal:

import argparse

def principal():
    parser = argparse.ArgumentParser(description="Conta as palavras de um texto.")
    parser.add_argument("palavras", nargs="+", help="o texto a contar")
    parser.add_argument("--maiusculas", action="store_true", help="mostra o texto em maiúsculas")
    args = parser.parse_args()

    texto = " ".join(args.palavras)
    if args.maiusculas:
        texto = texto.upper()
    print(texto)
    print("Palavras:", len(args.palavras))

if __name__ == "__main__":
    principal()
py contar.py o sol nasceu no mar --maiusculas

O SOL NASCEU NO MAR
Palavras: 5

O if __name__ == "__main__": (aula 100) faz o programa rodar quando é chamado pelo terminal, mas deixa você importar a função principal em outro arquivo sem rodar nada.

parser.add_argument("--ate", type=int, default=10)

Exercícios

1. Escreva um programa com sys.argv que soma todos os números passados no terminal (py somar.py 4 5 10 mostra 19.0). Simule o terminal com a lista ["somar.py", "4", "5", "10"].

Ver resposta

print(sum(numeros))

2. Com argparse, crie um programa conversor.py que recebe uma temperatura em Celsius e a opção --kelvin. Sem a opção, mostra em Fahrenheit; com ela, em Kelvin. Teste com a lista ["30", "--kelvin"] e depois com ["30"].

Ver resposta 
import argparse

parser = argparse.ArgumentParser(prog="conversor.py", description="Converte temperaturas")
parser.add_argument("celsius", type=float)
parser.add_argument("--kelvin", action="store_true")

for lista in (["30", "--kelvin"], ["30"]):
    args = parser.parse_args(lista)
    if args.kelvin:
        print(args.celsius + 273.15, "K")
    else:
        print(args.celsius * 9 / 5 + 32, "°F")

303.15 K
86.0 °F

3. Crie um programa dado.py com a opção --faces (só aceita 4, 6, 12 ou 20; padrão 6) e --vezes (padrão 1). Sorteie com random usando random.seed(1) para o resultado ser sempre igual. Teste com ["--faces", "20", "--vezes", "3"].

Ver resposta 
import argparse
import random

parser = argparse.ArgumentParser(prog="dado.py", description="Joga dados")
parser.add_argument("--faces", type=int, choices=[4, 6, 12, 20], default=6)
parser.add_argument("--vezes", type=int, default=1)
args = parser.parse_args(["--faces", "20", "--vezes", "3"])

random.seed(1)
for _ in range(args.vezes):
    print(random.randint(1, args.faces))

5
19
3

Repare que type=int vem antes de choices: primeiro o texto "20" vira o número 20, depois o argparse confere se ele está na lista.

5. Faça um programa lista.py que recebe um ou mais nomes (nargs="+") e a opção --ordenar. Mostre os nomes numerados, em ordem alfabética quando a opção for usada. Teste com ["Rui", "Ana", "Lia", "--ordenar"].

Ver resposta 
import argparse

parser = argparse.ArgumentParser(prog="lista.py")
parser.add_argument("nomes", nargs="+")
parser.add_argument("--ordenar", action="store_true")
args = parser.parse_args(["Rui", "Ana", "Lia", "--ordenar"])

nomes = sorted(args.nomes) if args.ordenar else args.nomes
for numero, nome in enumerate(nomes, start=1):
    print(f"{numero}. {nome}")

2. Lia
