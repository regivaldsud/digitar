Módulo 10 · Interface gráfica com PySide6

Aula 193 · Projeto: calculadora (display, grade de botões, teclado, QMessageBox)

Nesta aula você vai aprender

  • Separar a lógica da calculadora (sem Qt) da parte visual
  • Testar a lógica no navegador antes de abrir qualquer janela
  • Criar a grade de botões a partir de uma lista, com QGridLayout
  • Ligar todos os botões a um único método com lambda
  • Usar a calculadora pelo teclado com keyPressEvent e mostrar erros com QMessageBox
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

O plano do projeto

Neste projeto você vai juntar tudo do módulo: layouts (aula 191), sinais e slots (aula 192) e uma classe para a janela. A calculadora vai ter:

  • um display no alto, onde aparece a conta;
  • uma grade de botões com números, operações, C (limpar), ⌫ (apagar o último) e =;
  • uso pelo teclado (ótimo para quem treina digitação!): números, operações, Enter, Backspace e Esc;
  • uma caixa de aviso quando a conta for impossível, como dividir por zero.

O segredo de um bom programa com janela é separar duas partes: a lógica (que faz as contas e sabe o que mostrar) e a tela (que só desenha e repassa os cliques). A lógica, escrita em Python puro, pode ser testada aqui no navegador, sem janela nenhuma. A tela fica fininha e fácil de entender.

Passo 1: o desenho dos botões

Os botões ficam numa lista de listas: cada lista de dentro é uma linha da grade. Assim, mudar a calculadora é só mudar a lista. Confira o desenho:

BOTOES = [
    ["C", "⌫", "(", ")"],
    ["7", "8", "9", "/"],
    ["4", "5", "6", "*"],
    ["1", "2", "3", "-"],
    ["0", ".", "=", "+"],
]

for numero_linha, linha in enumerate(BOTOES, start=1):
    for coluna, texto in enumerate(linha):
        print(f"[{texto:^3}]", end="")
    print(f"   <- linha {numero_linha} da grade")

[ C ][ ⌫ ][ ( ][ ) ]   <- linha 1 da grade
[ 7 ][ 8 ][ 9 ][ / ]   <- linha 2 da grade
[ 4 ][ 5 ][ 6 ][ * ]   <- linha 3 da grade
[ 1 ][ 2 ][ 3 ][ - ]   <- linha 4 da grade
[ 0 ][ . ][ = ][ + ]   <- linha 5 da grade

A contagem começa em 1 porque a linha 0 da grade vai ser ocupada pelo display.

Passo 2: a função que calcula

A função calcular recebe a conta como texto, por exemplo "12+30", e devolve o resultado. Ela usa o eval, que calcula uma expressão do Python, mas antes confere cada caractere: só passam dígitos, ponto, parênteses e as quatro operações.

PERMITIDOS = set("0123456789+-*/.() ")


def calcular(expressao):
    if not expressao or not set(expressao) <= PERMITIDOS or "**" in expressao or "//" in expressao:
        raise ValueError("Conta inválida.")
    try:
        resultado = eval(expressao, {"__builtins__": {}})
    except ZeroDivisionError:
        raise ValueError("Não dá para dividir por zero.")
    except SyntaxError:
        raise ValueError("Conta incompleta.")
    resultado = round(resultado, 10)
    if resultado == int(resultado):
        resultado = int(resultado)
    return resultado


print(calcular("12+30"))
print(calcular("7/2"))
print(calcular("(2+3)*4"))
print(calcular("0.1+0.2"))
for conta in ["5/0", "8+", "2**100", "abc"]:
    try:
        calcular(conta)
    except ValueError as erro:
        print(conta, "->", erro)

42
3.5
20
0.3
5/0 -> Não dá para dividir por zero.
8+ -> Conta incompleta.
2**100 -> Conta inválida.
abc -> Conta inválida.

  • set(expressao) <= PERMITIDOS confere se todos os caracteres estão na lista de permitidos (aula 48).
  • Os erros diferentes viram sempre ValueError com uma mensagem amigável. Assim, a tela só precisa tratar um tipo de erro.
  • round(resultado, 10) resolve a imprecisão do float (aula 29): sem ele, 0.1+0.2 mostraria 0.30000000000000004.
  • int(resultado) tira o .0 de contas exatas: 4/2 mostra 2, não 2.0.
Atenção: O eval roda qualquer código Python, por isso é perigoso com texto vindo do usuário. Aqui ele só é seguro porque conferimos os caracteres antes e tiramos as funções embutidas ("__builtins__": {}). Nunca use eval com um texto que você não conferiu.

Passo 3: o motor da calculadora

O "motor" é uma classe sem nada de Qt que guarda o texto do display e sabe o que fazer com cada tecla. A janela só vai chamar motor.apertar(tecla) e mostrar motor.texto.

PERMITIDOS = set("0123456789+-*/.() ")


def calcular(expressao):
    if not expressao or not set(expressao) <= PERMITIDOS or "**" in expressao or "//" in expressao:
        raise ValueError("Conta inválida.")
    try:
        resultado = eval(expressao, {"__builtins__": {}})
    except ZeroDivisionError:
        raise ValueError("Não dá para dividir por zero.")
    except SyntaxError:
        raise ValueError("Conta incompleta.")
    resultado = round(resultado, 10)
    if resultado == int(resultado):
        resultado = int(resultado)
    return resultado


class Motor:
    def __init__(self):
        self.texto = ""

    def apertar(self, tecla):
        if tecla == "C":
            self.texto = ""
        elif tecla == "⌫":
            self.texto = self.texto[:-1]
        elif tecla == "=":
            try:
                self.texto = str(calcular(self.texto))
            except ValueError:
                self.texto = ""
                raise              # avisa quem chamou (a janela)
        else:
            self.texto += tecla
        return self.texto


motor = Motor()
for tecla in "12+30":
    motor.apertar(tecla)
print("Display:", motor.texto)
print("Depois do =:", motor.apertar("="))
print("Mais uma conta:", motor.apertar("*"), "->", motor.apertar("2"), "->", motor.apertar("="))
print("Apagando:", motor.apertar("⌫"))

Display: 12+30
Depois do =: 42
Mais uma conta: 42* -> 42*2 -> 84
Apagando: 8

Dica: Repare que o motor não sabe nada de botões nem de janelas. Se um dia você quiser fazer a calculadora no terminal, num site ou com outra biblioteca de janelas, o motor continua igual.

Passo 5: a janela completa

Agora sim, a parte visual. Crie uma pasta calculadora, ative o ambiente virtual com o PySide6 instalado (aula 190), salve o código abaixo como calculadora.py e rode:

python calculadora.py
import sys

from PySide6.QtCore import Qt
from PySide6.QtWidgets import (QApplication, QGridLayout, QLineEdit,
                               QMessageBox, QPushButton, QWidget)

# ------------------------------------------------ lógica (sem Qt)
PERMITIDOS = set("0123456789+-*/.() ")


def calcular(expressao):
    if not expressao or not set(expressao) <= PERMITIDOS or "**" in expressao or "//" in expressao:
        raise ValueError("Conta inválida.")
    try:
        resultado = eval(expressao, {"__builtins__": {}})
    except ZeroDivisionError:
        raise ValueError("Não dá para dividir por zero.")
    except SyntaxError:
        raise ValueError("Conta incompleta.")
    resultado = round(resultado, 10)
    if resultado == int(resultado):
        resultado = int(resultado)
    return resultado


class Motor:
    def __init__(self):
        self.texto = ""

    def apertar(self, tecla):
        if tecla == "C":
            self.texto = ""
        elif tecla == "⌫":
            self.texto = self.texto[:-1]
        elif tecla == "=":
            try:
                self.texto = str(calcular(self.texto))
            except ValueError:
                self.texto = ""
                raise
        else:
            self.texto += tecla
        return self.texto


# ------------------------------------------------ tela (Qt)
BOTOES = [
    ["C", "⌫", "(", ")"],
    ["7", "8", "9", "/"],
    ["4", "5", "6", "*"],
    ["1", "2", "3", "-"],
    ["0", ".", "=", "+"],
]

TECLAS_DIGITAVEIS = "0123456789+-*/.()"


class Calculadora(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Calculadora")
        self.motor = Motor()

        self.display = QLineEdit()
        self.display.setReadOnly(True)
        self.display.setAlignment(Qt.AlignmentFlag.AlignRight)
        self.display.setStyleSheet("font-size: 28px; padding: 6px")
        self.display.setFocusPolicy(Qt.FocusPolicy.NoFocus)

        grade = QGridLayout(self)
        grade.addWidget(self.display, 0, 0, 1, 4)   # linha 0, coluna 0, 1 linha, 4 colunas

        for linha, textos in enumerate(BOTOES, start=1):
            for coluna, texto in enumerate(textos):
                botao = QPushButton(texto)
                botao.setMinimumSize(60, 50)
                botao.setFocusPolicy(Qt.FocusPolicy.NoFocus)
                botao.clicked.connect(lambda _=False, t=texto: self.apertar(t))
                grade.addWidget(botao, linha, coluna)

    def apertar(self, tecla):
        try:
            self.motor.apertar(tecla)
        except ValueError as erro:
            QMessageBox.warning(self, "Ops", str(erro))
        self.display.setText(self.motor.texto)

    def keyPressEvent(self, evento):
        tecla = evento.text()
        if evento.key() in (Qt.Key.Key_Return, Qt.Key.Key_Enter) or tecla == "=":
            self.apertar("=")
        elif evento.key() == Qt.Key.Key_Backspace:
            self.apertar("⌫")
        elif evento.key() == Qt.Key.Key_Escape:
            self.apertar("C")
        elif tecla and tecla in TECLAS_DIGITAVEIS:
            self.apertar(tecla)
        else:
            super().keyPressEvent(evento)


if __name__ == "__main__":
    app = QApplication(sys.argv)
    janela = Calculadora()
    janela.show()
    sys.exit(app.exec())

Abre a janela "Calculadora": o display grande no alto e, embaixo, a grade 5×4 de botões.
Clicando 1, 2, +, 3, 0 e =, o display mostra 42.
Digitando 5/0 e apertando Enter, aparece a caixa "Ops" com "Não dá para dividir por zero." e o display fica vazio.
Backspace apaga o último caractere e Esc limpa tudo.

O que cada parte faz:

  • grade.addWidget(self.display, 0, 0, 1, 4) faz o display ocupar a linha 0 inteira (1 linha e 4 colunas).
  • Os dois for com enumerate montam a grade a partir da lista BOTOES, como no Passo 1.
  • lambda _=False, t=texto: self.apertar(t) liga todos os botões ao mesmo método, cada um mandando o seu texto (aula 192).
  • O método apertar da janela só repassa a tecla ao motor, mostra o resultado e, se o motor reclamar, abre a caixa de aviso com QMessageBox.warning.
  • keyPressEvent é chamado pelo Qt a cada tecla apertada com a janela em foco. evento.text() é o caractere digitado e evento.key() identifica teclas especiais como Enter e Esc.
  • setFocusPolicy(NoFocus) nos botões e no display faz as teclas chegarem sempre à janela. Sem isso, depois de clicar num botão, o Enter "apertaria" de novo o botão que ficou em foco.
Atenção: Em keyPressEvent, teste tecla and tecla in TECLAS_DIGITAVEIS. Teclas como Shift e Ctrl têm evento.text() vazio, e "" in "0123" dá True no Python — sem o tecla and, elas entrariam como se fossem dígitos.
Dica: O if __name__ == "__main__": (aula 100) deixa você importar Motor e calcular deste arquivo num teste sem abrir a janela.

Passo 6: testando a janela sem abrir a tela

Para quem quiser ir além: o Qt tem o módulo QtTest, que clica e digita sozinho. Salve como testar_calculadora.py na mesma pasta e rode com python testar_calculadora.py:

import os
import sys

os.environ["QT_QPA_PLATFORM"] = "offscreen"   # não mostra nada na tela

from PySide6.QtCore import Qt
from PySide6.QtTest import QTest
from PySide6.QtWidgets import QApplication, QMessageBox

import calculadora

app = QApplication(sys.argv)
avisos = []
QMessageBox.warning = lambda pai, titulo, texto: avisos.append(texto)   # troca a caixa modal

janela = calculadora.Calculadora()
QTest.keyClicks(janela, "12+30")
QTest.keyClick(janela, Qt.Key.Key_Return)
print("Display:", janela.display.text())

QTest.keyClicks(janela, "5/0")
QTest.keyClick(janela, Qt.Key.Key_Return)
print("Avisos:", avisos)

Display: 42
Avisos: ['Não dá para dividir por zero.']

A caixa do QMessageBox espera alguém clicar em OK, o que travaria um teste automático. Por isso o teste troca QMessageBox.warning por uma função que só guarda a mensagem — é a mesma ideia dos mocks da aula 133.
