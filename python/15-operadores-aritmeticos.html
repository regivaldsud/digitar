Aula 15 · Operadores aritméticos, precedência, + e * com textos

Nesta aula você vai aprender

  • Usar os operadores +, -, *, /, //, % e **
  • Entender a ordem em que as contas são feitas (precedência)
  • Usar parênteses para mudar a ordem
  • Juntar textos com + e repeti-los com *

As quatro operações

print(7 + 3)
print(7 - 3)
print(7 * 3)
print(7 / 2)
print(6 / 2)

10
4
21
3.5
3.0

A multiplicação usa * (asterisco), não x. E repare: a divisão / sempre dá um float, mesmo quando a conta é exata — 6 / 2 dá 3.0.

Divisão inteira, resto e potência

  • // faz a divisão inteira: descarta o que sobra depois da vírgula.
  • % dá o resto da divisão (o nome é "módulo").
  • ** é a potência: 2 ** 3 é 2 elevado a 3.
print(17 // 5)
print(17 % 5)
print(2 ** 3)
print(9 ** 0.5)

3
2
8
3.0

Exemplo da vida real: 17 brigadeiros para dividir entre 5 amigos. Cada um ganha 17 // 5, que dá 3, e sobram 17 % 5, que dá 2. E 9 ** 0.5 é a raiz quadrada de 9.

minutos = 135
horas = minutos // 60
resto = minutos % 60
print(minutos, "minutos são", horas, "horas e", resto, "minutos")

135 minutos são 2 horas e 15 minutos

Dica: O % é ótimo para saber se um número é par: se numero % 2 dá 0, o número é par.
Atenção: Dividir por zero não pode, nem na matemática: 10 / 0, 10 // 0 e 10 % 0 dão ZeroDivisionError.

Quem vem primeiro: precedência

O Python segue a mesma ordem da matemática da escola: primeiro **, depois *, /, // e %, e por último + e -. Em empate, a conta é feita da esquerda para a direita. Use parênteses para mudar a ordem:

print(2 + 3 * 4)
print((2 + 3) * 4)
print(10 - 4 - 3)
print(2 * 3 ** 2)
nota1 = 7
nota2 = 9
print("Errado:", nota1 + nota2 / 2)
print("Certo:", (nota1 + nota2) / 2)

14
20
3
18
Errado: 11.5
Certo: 8.0

Atenção: O erro clássico da média: nota1 + nota2 / 2 divide só a nota2. Para a média, coloque a soma entre parênteses: (nota1 + nota2) / 2.

+ e * com textos

Os operadores + e * também funcionam com textos, mas com outro sentido:

  • + entre dois textos junta (concatena);
  • * entre um texto e um inteiro repete o texto.
nome = "Ana"
sobrenome = "Lima"
print(nome + " " + sobrenome)
print("ha" * 3)
print("=" * 20)
print("-" * 5 + " MENU " + "-" * 5)

Ana Lima
hahaha
====================
----- MENU -----

Atenção: Somar texto com número dá TypeError: "Idade: " + 13 não funciona. Converta o número com str(13) (aula 13) ou use vírgulas no print.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
media = (nota1 + nota2 + nota3) / 3

Exercícios

1. Calcule a média das notas 6.5, 8.0 e 9.5.

Ver resposta 
media = (6.5 + 8.0 + 9.5) / 3
print(media)

8.0

2. Uma turma de 34 alunos vai fazer grupos de 4. Quantos grupos completos são formados e quantos alunos sobram?

Ver resposta 
alunos = 34
print("Grupos:", alunos // 4)
print("Sobram:", alunos % 4)

Grupos: 8
Sobram: 2

3. Converta 200 segundos em minutos e segundos (por exemplo, 3 minutos e 20 segundos).

Ver resposta 
total = 200
print(total // 60, "minutos e", total % 60, "segundos")

3 minutos e 20 segundos

4. Calcule a área de um terreno quadrado de 12 metros de lado usando **.

Ver resposta 
lado = 12
print("Área:", lado ** 2, "metros quadrados")

Área: 144 metros quadrados

5. Use * e + com textos para mostrar uma linha de 10 asteriscos, a palavra PROMOÇÃO e outra linha de 10 asteriscos, tudo numa linha só.

Ver resposta 
print("*" * 10 + " PROMOÇÃO " + "*" * 10)

********** PROMOÇÃO **********
