Models: tabelas escritas em Python

Um model é uma classe que vira uma tabela no banco de dados. Cada atributo é uma coluna. Você não precisa escrever SQL: o Django faz isso.

# contatos/models.py
from django.db import models


class Contato(models.Model):
    nome = models.CharField(max_length=100)
    telefone = models.CharField(max_length=20)
    email = models.EmailField(blank=True)
    nascimento = models.DateField(null=True, blank=True)
    favorito = models.BooleanField(default=False)
    criado_em = models.DateTimeField(auto_now_add=True)

    class Meta:
        ordering = ["nome"]

    def __str__(self):
        return self.nome
  • blank=True deixa o campo opcional nos formulários; null=True permite vazio no banco.
  • auto_now_add=True grava a data e hora da criação sozinho.
  • __str__ (aula 81) define como o contato aparece nas listas do admin.

Migrações

Uma migração é um arquivo com as mudanças a fazer no banco. Sempre que mudar um model, rode os dois comandos:

python manage.py makemigrations
python manage.py migrate

Migrations for 'contatos':
  contatos\migrations\0001_initial.py
    + Create model Contato
Operations to perform:
  Apply all migrations: admin, auth, contatos, contenttypes, sessions
Running migrations:
  Applying contatos.0001_initial... OK

Por padrão o banco é um arquivo SQLite, db.sqlite3, na pasta do projeto (aula 174).

A área administrativa

O Django já vem com um painel para cadastrar e editar dados. Registre o model e crie um usuário administrador:

# contatos/admin.py
from django.contrib import admin
from .models import Contato


@admin.register(Contato)
class ContatoAdmin(admin.ModelAdmin):
    list_display = ["nome", "telefone", "favorito"]
    search_fields = ["nome", "email"]
    list_filter = ["favorito"]
python manage.py createsuperuser
python manage.py runserver

Entre em http://127.0.0.1:8000/admin/ com o usuário criado.

Atenção: Mudou o model e apareceu no such column ou no such table? Você esqueceu do makemigrations e do migrate.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
nome = models.CharField(max_length=100)

Exercícios

1. Crie um model Receita com titulo (texto até 120), minutos (número inteiro) e vegetariana (verdadeiro/falso, padrão falso), com __str__ devolvendo o título.

Ver resposta 
from django.db import models


class Receita(models.Model):
    titulo = models.CharField(max_length=120)
    minutos = models.PositiveIntegerField()
    vegetariana = models.BooleanField(default=False)

    def __str__(self):
        return self.titulo

Depois rode makemigrations e migrate.

2. Você acrescentou o campo apelido = models.CharField(max_length=50) num model que já tem dados. O makemigrations pergunta o que fazer com as linhas antigas. Qual é a saída mais simples?

Ver resposta 
from django.db import models

apelido = models.CharField(max_length=50, blank=True, default="")

Dê um valor padrão (default="") ou permita vazio; assim os contatos antigos recebem um apelido vazio.
