Aula 48 · Conjuntos (set) e suas operações

Nesta aula você vai aprender

  • Criar conjuntos com set e com chaves

Um saco sem repetições

Um conjunto (set) é uma coleção que não aceita itens repetidos e não tem ordem. É como as figurinhas que você já colou no álbum: tirar a mesma figurinha duas vezes não muda nada.

figurinhas = {"Neymar", "Marta", "Vini Jr.", "Marta"}
print(len(figurinhas))
print("Marta" in figurinhas)
print(sorted(figurinhas))

3
True
['Marta', 'Neymar', 'Vini Jr.']

O "Marta" repetido foi descartado. Como o conjunto não tem ordem, usamos sorted para mostrá-lo sempre na mesma ordem (alfabética).

Atenção: Conjuntos não têm índice: figurinhas[0] dá TypeError. E a ordem em que um conjunto aparece no print pode mudar — não conte com ela.

Tirando repetidos de uma lista

Um truque muito útil: transformar uma lista em conjunto remove as repetições.

presencas = ["Ana", "Beto", "Ana", "Caio", "Beto", "Ana"]
unicos = set(presencas)
print(len(presencas), "registros")
print(len(unicos), "pessoas diferentes")
print(sorted(unicos))

6 registros
3 pessoas diferentes
['Ana', 'Beto', 'Caio']

add, remove e discard

cidades = set()
cidades.add("Natal")
cidades.add("Natal")
cidades.add("Maceió")
cidades.discard("Recife")
cidades.remove("Natal")
print(cidades)

{'Maceió'}

remove dá erro se o item não existe; discard não reclama.

Atenção: Para criar um conjunto vazio, use set(). Escrever {} cria um dicionário vazio, não um conjunto.

União, interseção e diferença

O ponto forte dos conjuntos é comparar grupos, como na matemática:

  • a | b (união): tudo que está em a ou em b;
  • a & b (interseção): o que está nos dois;
  • a - b (diferença): o que está em a mas não em b;
  • a ^ b (diferença simétrica): o que está em só um dos dois.
futebol = {"Ana", "Bruno", "Caio", "Duda"}
volei = {"Caio", "Duda", "Elisa"}
print(sorted(futebol | volei))
print(sorted(futebol & volei))
print(sorted(futebol - volei))
print(sorted(futebol ^ volei))
print({"Caio"} <= futebol)

['Ana', 'Bruno', 'Caio', 'Duda', 'Elisa']
['Caio', 'Duda']
['Ana', 'Bruno']
['Ana', 'Bruno', 'Elisa']
True

O <= pergunta se um conjunto está contido no outro. Os mesmos cálculos existem como métodos: a.union(b), a.intersection(b), a.difference(b).

Dica: Testar item in conjunto é muito mais rápido do que item in lista quando há milhares de itens. Se você só precisa saber "está ou não está", um conjunto é ótimo.

Qual estrutura usar?

Agora que você conhece as quatro coleções principais, compare:

  • Lista [1, 2, 3]: ordenada, pode mudar, aceita repetidos. Lista de compras, histórico de pontos.
  • Tupla (1, 2, 3): ordenada, não muda. Coordenadas, data de nascimento.
  • Dicionário {"a": 1}: busca pelo nome (chave). Ficha de aluno, preço de cada produto.
  • Conjunto {1, 2, 3}: sem ordem e sem repetidos. "Está ou não está?" e comparar grupos.
compras = ["arroz", "feijão", "arroz"]
nascimento = (15, 3, 2011)
ficha = {"nome": "Iara", "turma": "8B"}
tags = {"python", "jogos", "python"}
for colecao in [compras, nascimento, ficha, tags]:
    print(type(colecao).__name__, len(colecao))

list 3
tuple 3
dict 2
set 2

Repare que o conjunto ficou com 2 itens, enquanto a lista manteve os dois "arroz". Na dúvida, comece com uma lista; se você perceber que vive procurando itens pelo nome, troque por um dicionário.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
comuns = sorted(futebol & volei)

Exercícios

1. Remova as repetições da lista [3, 1, 3, 2, 1, 5, 2] e mostre os números únicos em ordem crescente.

Ver resposta 
numeros = [3, 1, 3, 2, 1, 5, 2]
print(sorted(set(numeros)))

[1, 2, 3, 5]

2. Lia tem as figurinhas {1, 4, 7, 9, 12} e Téo tem {4, 5, 9, 10}. Mostre as que os dois têm, as que só a Lia tem e as que só um deles tem (para trocar).

Ver resposta 
lia = {1, 4, 7, 9, 12}
teo = {4, 5, 9, 10}
print("Os dois têm:", sorted(lia & teo))
print("Só a Lia tem:", sorted(lia - teo))
print("Para trocar:", sorted(lia ^ teo))

Os dois têm: [4, 9]
Só a Lia tem: [1, 7, 12]
Para trocar: [1, 5, 7, 10, 12]

3. Conte quantas palavras diferentes há na frase "o rato roeu a roupa do rei de roma e o rei riu".

Ver resposta 
frase = "o rato roeu a roupa do rei de roma e o rei riu"
palavras = frase.split()
print(len(palavras), "palavras no total")
print(len(set(palavras)), "palavras diferentes")

13 palavras no total
11 palavras diferentes

4. Verifique se "amor" e "roma" usam exatamente as mesmas letras, comparando conjuntos.

Ver resposta 
print(set("amor") == set("roma"))
print(sorted(set("amor")))

True
['a', 'm', 'o', 'r']

5. Qual estrutura você usaria para: (a) os 26 estados e o DF, que nunca mudam; (b) os produtos no carrinho de uma loja; (c) o preço de cada produto; (d) os usuários que já curtiram uma foto?

Ver resposta

(a) Tupla: são valores fixos, em ordem, que não mudam.
(b) Lista: o carrinho cresce e diminui, e pode ter itens repetidos.
(c) Dicionário: procuramos o preço pelo nome do produto (chave).
(d) Conjunto: cada usuário só conta uma vez e só queremos saber se curtiu ou não.
