Iterável e iterador

Um iterável é qualquer coisa que dá para percorrer com for: listas, tuplas, textos, dicionários, range...

Por dentro, o for pede ao iterável um iterador, com a função iter(). O iterador é como um marcador de página: ele lembra onde parou e entrega o próximo item cada vez que você chama next():

frutas = ["caju", "açaí", "goiaba"]
marcador = iter(frutas)
print(next(marcador))
print(next(marcador))
print(next(marcador))

caju
açaí
goiaba

O fim da fila: StopIteration

Quando os itens acabam, next() lança a exceção StopIteration. É assim que o for sabe a hora de parar — ele trata esse erro sozinho, sem você ver:

letras = iter("ok")
print(next(letras))
print(next(letras))
print(next(letras))

o
k
StopIteration

Você pode passar um segundo valor para next(), que é devolvido quando os itens acabam, em vez do erro:

numeros = iter([10, 20])
print(next(numeros, "acabou"))
print(next(numeros, "acabou"))
print(next(numeros, "acabou"))

10
20
acabou

Atenção: Um iterador só anda para a frente e não volta. Depois de percorrido até o fim, ele fica vazio. Se precisar percorrer de novo, crie outro com iter().

Funções geradoras com yield

Um gerador é uma função que entrega valores um de cada vez. No lugar de return, ela usa yield: entrega um valor, pausa e, no próximo pedido, continua de onde parou:

def contagem_regressiva(n):
    while n > 0:
        yield n
        n -= 1
    yield "Feliz Ano Novo!"

for valor in contagem_regressiva(5):
    print(valor)

5
4
3
2
1
Feliz Ano Novo!

Veja a pausa acontecendo. O texto "preparando" só aparece quando o primeiro valor é pedido:

def senhas_da_fila():
    print("(preparando a fila do banco...)")
    yield "A001"
    print("(chamando o próximo...)")
    yield "A002"

fila = senhas_da_fila()
print("Gerador criado, nada rodou ainda.")
print(next(fila))
print(next(fila))

Gerador criado, nada rodou ainda.
(preparando a fila do banco...)
A001
(chamando o próximo...)
A002

yield from: repassando outro iterável

yield from iteravel entrega, um por um, todos os itens de outro iterável (ou de outro gerador). É um atalho para for item in iteravel: yield item:

def cardapio():
    yield from ["arroz", "feijão"]
    yield from ("bife", "salada")
    yield "pudim"

print(list(cardapio()))

def achatar(listas):
    for lista in listas:
        yield from lista

print(list(achatar([[1, 2], [3], [4, 5, 6]])))

['arroz', 'feijão', 'bife', 'salada', 'pudim']
[1, 2, 3, 4, 5, 6]

Na aula 90 você vai usar yield para fazer suas próprias classes funcionarem dentro de um for.

Gerador ou lista?

Uma lista guarda todos os itens na memória ao mesmo tempo. Um gerador cria cada item só na hora em que ele é pedido. Para poucos itens tanto faz; para milhões, o gerador economiza muita memória.

Uma expressão geradora é igual a uma compreensão de lista, mas com parênteses no lugar de colchetes:

import sys

quadrados_lista = [n * n for n in range(100_000)]
quadrados_gerador = (n * n for n in range(100_000))

print(sum(n * n for n in range(1, 4)))
print("lista grande:", sys.getsizeof(quadrados_lista) > 100_000)
print("gerador pequeno:", sys.getsizeof(quadrados_gerador) < 1_000)

14
lista grande: True
gerador pequeno: True

sys.getsizeof diz quantos bytes um objeto ocupa: a lista ocupa centenas de milhares; o gerador, só algumas centenas.

Dica: Quando a expressão geradora é o único argumento de uma função, como em sum(n * n for n in numeros), não precisa de parênteses extras.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
quadrados = (n * n for n in range(10))

Exercícios

1. Crie um iterador para a lista ["vermelho", "amarelo", "verde"] e use next() três vezes para mostrar as cores do semáforo.

Ver resposta 
semaforo = iter(["vermelho", "amarelo", "verde"])
print(next(semaforo))
print(next(semaforo))
print(next(semaforo))

vermelho
amarelo
verde

2. Escreva um gerador pares(limite) que entregue os números pares de 0 até limite (incluindo o limite, se for par). Mostre list(pares(10)).

Ver resposta 
def pares(limite):
    n = 0
    while n <= limite:
        yield n
        n += 2

print(list(pares(10)))

[0, 2, 4, 6, 8, 10]

3. Use uma expressão geradora com sum para calcular o total da compra precos = [4.5, 12.0, 3.25] com 10% de desconto em cada item.

Ver resposta 
precos = [4.5, 12.0, 3.25]
total = sum(p * 0.9 for p in precos)
print(f"Total: R$ {total:.2f}")

Total: R$ 17.78

4. Escreva um gerador tabuada(n) que entregue as linhas da tabuada de n de 1 a 10, como "7 x 1 = 7". Mostre as três primeiras linhas usando next().

Ver resposta 
def tabuada(n):
    for i in range(1, 11):
        yield f"{n} x {i} = {n * i}"

linhas = tabuada(7)
print(next(linhas))
print(next(linhas))
print(next(linhas))

7 x 1 = 7
7 x 2 = 14
7 x 3 = 21

5. Escreva o gerador semana() que use yield from para entregar os dias úteis de uma lista e depois os dias do fim de semana de outra. Mostre todos com um for.

Ver resposta 
def semana():

    yield from ["sábado", "domingo"]

for dia in semana():
    print(dia)
