Aula 20 · Índices, fatiamento de textos e len

Nesta aula você vai aprender

  • Medir o tamanho de um texto com len()
  • Pegar um caractere pelo índice, inclusive com índices negativos
  • Recortar pedaços com fatias [início:fim:passo]
  • Entender que strings são imutáveis

Uma string é uma fila de caracteres

Uma string é uma sequência de caracteres (letras, números, espaços, símbolos). Cada caractere tem uma posição, chamada índice, que começa em 0:

 P   y   t   h   o   n
 0   1   2   3   4   5
-6  -5  -4  -3  -2  -1

palavra = "Python"
print(len(palavra))
print(palavra[0])
print(palavra[1])
print(palavra[5])

6
P
y
n

len() dá o tamanho: quantos caracteres há. Como o índice começa em 0, o último caractere fica em len - 1.

Atenção: Pedir um índice que não existe dá IndexError: string index out of range. Em "Python", os índices vão de 0 a 5; palavra[6] dá erro.

Índices negativos

Índices negativos contam a partir do fim: -1 é o último, -2 o penúltimo, e assim por diante.

cidade = "Florianópolis"
print(cidade[-1])
print(cidade[-2])
print(cidade[0], cidade[-1])
print(cidade[len(cidade) - 1])

s
i
F s
s

cidade[-1] e cidade[len(cidade) - 1] dão o mesmo resultado, mas o primeiro é bem mais curto.

Fatiamento: pegando pedaços

Uma fatia pega um pedaço do texto: texto[início:fim]. Ela começa no índice início e vai até antes do fim.

frase = "Bom dia, Brasil"
print(frase[0:3])
print(frase[4:7])
print(frase[:3])
print(frase[9:])
print(frase[-6:])

Bom
dia
Bom
Brasil
Brasil

Se você omite o início, começa do 0. Se omite o fim, vai até o final.

Dica: Um jeito de lembrar: em texto[2:5], o tamanho da fatia é 5 - 2 = 3 caracteres. E fatias não dão IndexError: "oi"[0:100] simplesmente devolve "oi".

O passo

Um terceiro número na fatia é o passo: de quantos em quantos caracteres andar.

numeros = "0123456789"
print(numeros[::2])
print(numeros[1::2])
print(numeros[::-1])
print("arara"[::-1])

02468
13579
9876543210
arara

Passo -1 anda de trás para frente: é o jeito clássico de inverter um texto. "arara" ao contrário continua "arara": é um palíndromo!

Strings não mudam (imutáveis)

Você não pode trocar uma letra de uma string diretamente. Strings são imutáveis:

nome = "Rafael"
nome[0] = "G"

TypeError: 'str' object does not support item assignment

Para "mudar", crie um texto novo juntando pedaços:

nome = "Rafael"
novo = "G" + nome[1:]
print(novo)
print(nome)

Gafael
Rafael

A variável nome continua "Rafael"; novo é outro texto.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
print(frase[0:3], frase[-6:], frase[::-1])
