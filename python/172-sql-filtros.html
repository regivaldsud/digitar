A tabela de exemplo

Como cada bloco desta aula roda sozinho, todos começam criando a mesma tabela notas com as notas de uma turma. A parte nova de cada exemplo está depois do executemany:

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE notas (aluno TEXT, materia TEXT, nota REAL)")
con.executemany("INSERT INTO notas VALUES (?, ?, ?)", [
    ("Ana", "Matemática", 9.0), ("Ana", "História", 7.5),
    ("Bruno", "Matemática", 6.0), ("Bruno", "História", 7.0),
    ("Carla", "Matemática", 10.0), ("Carla", "História", 9.5),
    ("Davi", "Matemática", 4.5), ("Davi", "História", None),
])

for aluno, materia, nota in con.execute("SELECT * FROM notas"):
    print(f"{aluno:<6} {materia:<11} {nota}")
con.close()

Ana    Matemática  9.0
Ana    História    7.5
Bruno  Matemática  6.0
Bruno  História    7.0
Carla  Matemática  10.0
Carla  História    9.5
Davi   Matemática  4.5
Davi   História    None

O Davi ainda não fez a prova de História: a nota dele está NULL (no Python, None).

Dica: Filtrar no banco é muito mais rápido do que trazer tudo para o Python e filtrar com if. Com milhões de linhas, a diferença é enorme: só as linhas que interessam viajam até o seu programa.

WHERE: escolhendo as linhas

O WHERE funciona como um if para cada linha: só entram no resultado as que tornam a condição verdadeira. Os operadores são parecidos com os do Python:

  • = igual (um só =, não ==) e <> diferente (também vale !=);
  • >, <, >=, <=;
  • BETWEEN a AND b — entre a e b, incluindo os dois;
  • IN (x, y, z) — igual a algum da lista;
  • AND, OR e NOT para combinar condições.
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE notas (aluno TEXT, materia TEXT, nota REAL)")
con.executemany("INSERT INTO notas VALUES (?, ?, ?)", [
    ("Ana", "Matemática", 9.0), ("Ana", "História", 7.5),
    ("Bruno", "Matemática", 6.0), ("Bruno", "História", 7.0),
    ("Carla", "Matemática", 10.0), ("Carla", "História", 9.5),
    ("Davi", "Matemática", 4.5), ("Davi", "História", None),
])

def mostrar(titulo, sql):
    print(titulo, con.execute(sql).fetchall())

mostrar("Mat. >= 7:  ", "SELECT aluno FROM notas WHERE materia = 'Matemática' AND nota >= 7")
mostrar("Entre 6 e 8:", "SELECT aluno, nota FROM notas WHERE nota BETWEEN 6 AND 8")
mostrar("Ana ou Davi:", "SELECT materia, nota FROM notas WHERE aluno IN ('Ana', 'Davi')")
mostrar("Não é Mat.: ", "SELECT aluno FROM notas WHERE materia <> 'Matemática' AND nota > 9")
mostrar("Sem nota:   ", "SELECT aluno, materia FROM notas WHERE nota IS NULL")
con.close()

Mat. >= 7:   [('Ana',), ('Carla',)]
Entre 6 e 8: [('Ana', 7.5), ('Bruno', 6.0), ('Bruno', 7.0)]
Ana ou Davi: [('Matemática', 9.0), ('História', 7.5), ('Matemática', 4.5), ('História', None)]
Não é Mat.:  [('Carla',)]
Sem nota:    [('Davi', 'História')]

Para achar valores vazios, use IS NULL (e IS NOT NULL). Repare também que, na busca "entre 6 e 8", a nota NULL do Davi não apareceu: comparações com NULL nunca são verdadeiras.

Atenção: WHERE nota = NULL não funciona: não dá erro, mas nunca encontra nada, porque NULL quer dizer "valor desconhecido" e não é igual a nada — nem a outro NULL. O certo é WHERE nota IS NULL.
Atenção: Quando misturar AND e OR, use parênteses. WHERE materia = 'História' AND nota < 7 OR nota IS NULL é lido como (... AND ...) OR ..., o que talvez não seja o que você queria.

LIKE: procurando pedaços de texto

Para buscar "nomes que começam com C" ou "e-mails do gmail", use LIKE com dois coringas:

  • % — qualquer quantidade de caracteres (inclusive nenhum);
  • _ — exatamente um caractere.
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE alunos (nome TEXT, email TEXT)")
con.executemany("INSERT INTO alunos VALUES (?, ?)", [
    ("Carla", "carla@gmail.com"), ("Caio", "caio@escola.edu.br"),
    ("Ana", "ana@gmail.com"), ("Luana", "lu@yahoo.com"), ("Rui", "rui@escola.edu.br"),
])

def mostrar(titulo, sql):
    print(titulo, [linha[0] for linha in con.execute(sql)])

mostrar("Começa com C:  ", "SELECT nome FROM alunos WHERE nome LIKE 'C%'")
mostrar("Termina com a: ", "SELECT nome FROM alunos WHERE nome LIKE '%a'")
mostrar("Tem 'ua':      ", "SELECT nome FROM alunos WHERE nome LIKE '%ua%'")
mostrar("Três letras:   ", "SELECT nome FROM alunos WHERE nome LIKE '___'")
mostrar("Usa gmail:     ", "SELECT nome FROM alunos WHERE email LIKE '%@gmail.com'")
con.close()

Começa com C:   ['Carla', 'Caio']
Termina com a:  ['Carla', 'Ana', 'Luana']
Tem 'ua':       ['Luana']
Três letras:    ['Ana', 'Rui']
Usa gmail:      ['Carla', 'Ana']

No SQLite, o LIKE não diferencia maiúsculas de minúsculas para letras sem acento: 'c%' também encontra "Carla".

ORDER BY, LIMIT e OFFSET

Sem ORDER BY, o banco devolve as linhas na ordem que for mais cômoda para ele. Para ordenar, diga a coluna e o sentido: ASC (crescente, o padrão) ou DESC (decrescente). LIMIT n pega só as n primeiras linhas e OFFSET k pula as k primeiras — juntos, eles fazem a paginação ("página 2 de resultados").

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE notas (aluno TEXT, materia TEXT, nota REAL)")
con.executemany("INSERT INTO notas VALUES (?, ?, ?)", [
    ("Ana", "Matemática", 9.0), ("Ana", "História", 7.5),
    ("Bruno", "Matemática", 6.0), ("Bruno", "História", 7.0),
    ("Carla", "Matemática", 10.0), ("Carla", "História", 9.5),
    ("Davi", "Matemática", 4.5), ("Davi", "História", None),
])

print("Pódio:")
sql = "SELECT aluno, materia, nota FROM notas WHERE nota IS NOT NULL ORDER BY nota DESC LIMIT 3"
for posicao, (aluno, materia, nota) in enumerate(con.execute(sql), start=1):
    print(f"  {posicao}º {aluno} ({materia}): {nota}")

print("Por matéria e depois por nome:")
for linha in con.execute("SELECT materia, aluno FROM notas ORDER BY materia, aluno"):
    print(" ", linha)

print("Página 2 (2 por página):")
sql = "SELECT aluno, nota FROM notas ORDER BY aluno, materia LIMIT 2 OFFSET 2"
print(" ", con.execute(sql).fetchall())
con.close()

Pódio:
  1º Carla (Matemática): 10.0
  2º Carla (História): 9.5
  3º Ana (Matemática): 9.0
Por matéria e depois por nome:
  ('História', 'Ana')
  ('História', 'Bruno')
  ('História', 'Carla')
  ('História', 'Davi')
  ('Matemática', 'Ana')
  ('Matemática', 'Bruno')
  ('Matemática', 'Carla')
  ('Matemática', 'Davi')
Página 2 (2 por página):
  [('Bruno', 7.0), ('Bruno', 6.0)]

ORDER BY materia, aluno ordena primeiro pela matéria e, em caso de empate, pelo nome. A página p (começando em 1), com n itens por página, é LIMIT n OFFSET (p - 1) * n.

Atenção: A ordem das partes do comando é fixa: SELECT ... FROM ... WHERE ... GROUP BY ... HAVING ... ORDER BY ... LIMIT .... Escrever o ORDER BY antes do WHERE, por exemplo, dá syntax error.

Resumindo: funções de agregação

As funções de agregação transformam muitas linhas em um único valor:

  • COUNT(*) conta linhas; COUNT(coluna) conta só os valores que não são NULL;
  • SUM soma, AVG tira a média, MIN e MAX acham o menor e o maior.

AS dá um apelido para a coluna do resultado, e DISTINCT tira as repetições.

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE notas (aluno TEXT, materia TEXT, nota REAL)")
con.executemany("INSERT INTO notas VALUES (?, ?, ?)", [
    ("Ana", "Matemática", 9.0), ("Ana", "História", 7.5),
    ("Bruno", "Matemática", 6.0), ("Bruno", "História", 7.0),
    ("Carla", "Matemática", 10.0), ("Carla", "História", 9.5),
    ("Davi", "Matemática", 4.5), ("Davi", "História", None),
])

linhas, notas, media, menor, maior = con.execute(
    "SELECT COUNT(*), COUNT(nota), AVG(nota), MIN(nota), MAX(nota) FROM notas").fetchone()
print(f"{linhas} linhas, {notas} notas lançadas")
print(f"média {media:.2f}, menor {menor}, maior {maior}")

print(con.execute("SELECT DISTINCT aluno FROM notas ORDER BY aluno").fetchall())
print(con.execute("SELECT COUNT(DISTINCT materia) AS total_materias FROM notas").fetchone())
con.close()

8 linhas, 7 notas lançadas
média 7.64, menor 4.5, maior 10.0
[('Ana',), ('Bruno',), ('Carla',), ('Davi',)]
(2,)

O AVG ignora o NULL do Davi: a média é das 7 notas lançadas, não das 8 linhas.

GROUP BY e HAVING

Com GROUP BY, a agregação é feita por grupo: uma média para cada aluno, uma contagem para cada matéria. Para filtrar os grupos depois de calculados, use HAVING (o WHERE filtra as linhas antes de agrupar).

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE notas (aluno TEXT, materia TEXT, nota REAL)")
con.executemany("INSERT INTO notas VALUES (?, ?, ?)", [
    ("Ana", "Matemática", 9.0), ("Ana", "História", 7.5),
    ("Bruno", "Matemática", 6.0), ("Bruno", "História", 7.0),
    ("Carla", "Matemática", 10.0), ("Carla", "História", 9.5),
    ("Davi", "Matemática", 4.5), ("Davi", "História", None),
])

print("Média por aluno:")
sql = "SELECT aluno, AVG(nota) AS media FROM notas GROUP BY aluno ORDER BY media DESC"
for aluno, media in con.execute(sql):
    print(f"  {aluno:<6} {media:.2f}")

print("Só quem tem média 8 ou mais:")
sql = """
    SELECT aluno, ROUND(AVG(nota), 1) AS media
    FROM notas
    GROUP BY aluno
    HAVING media >= 8
    ORDER BY aluno
"""
print(" ", con.execute(sql).fetchall())
con.close()

Média por aluno:
  Carla  9.75
  Ana    8.25
  Bruno  6.50
  Davi   4.50
Só quem tem média 8 ou mais:
  [('Ana', 8.3), ('Carla', 9.8)]

ROUND(valor, 1) arredonda para uma casa decimal, como o round do Python. Pense no GROUP BY como separar as linhas em pilhas (uma pilha por aluno) e calcular a função em cada pilha.

Dica: Toda coluna do SELECT que não está dentro de uma função de agregação deveria estar no GROUP BY. O SQLite deixa passar, mas outros bancos dão erro, e o resultado pode não ser o que você imagina.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
SELECT aluno, AVG(nota) FROM notas GROUP BY aluno

4. Numa tabela vendas (produto, quantidade, preco), mostre o total vendido em reais de cada produto (quantidade vezes preço, somado), do maior para o menor.

Ver resposta 
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE vendas (produto TEXT, quantidade INTEGER, preco REAL)")
con.executemany("INSERT INTO vendas VALUES (?, ?, ?)", [
    ("Pastel", 3, 8.0), ("Caldo de cana", 2, 6.5), ("Pastel", 5, 8.0),
    ("Coxinha", 4, 7.0), ("Caldo de cana", 6, 6.5),
])

    SELECT produto, SUM(quantidade * preco) AS total

5. Uma loja mostra 3 produtos por página, em ordem alfabética. Escreva uma função pagina(con, numero) que devolva os nomes da página pedida e mostre as páginas 1, 2 e 3.

Ver resposta 
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE produtos (nome TEXT)")
nomes = ["Lápis", "Caneta", "Borracha", "Régua", "Cola", "Tesoura", "Estojo"]
con.executemany("INSERT INTO produtos VALUES (?)", [(n,) for n in nomes])

def pagina(con, numero, por_pagina=3):
    pulo = (numero - 1) * por_pagina
    sql = "SELECT nome FROM produtos ORDER BY nome LIMIT ? OFFSET ?"
    return [nome for (nome,) in con.execute(sql, (por_pagina, pulo))]

for n in [1, 2, 3]:
    print("Página", n, pagina(con, n))
con.close()

Página 1 ['Borracha', 'Caneta', 'Cola']
Página 2 ['Estojo', 'Lápis', 'Régua']
Página 3 ['Tesoura']

O ? também funciona no LIMIT e no OFFSET. A última página veio com um item só, porque são 7 produtos.
