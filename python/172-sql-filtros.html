Os dados da turma

Todos os exemplos usam esta tabela de notas. Copie a parte de criação quando quiser testar suas consultas:

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE notas (aluno TEXT, materia TEXT, nota REAL)")
con.executemany("INSERT INTO notas VALUES (?, ?, ?)", [
    ("Ana", "Matemática", 9.0), ("Ana", "História", 7.5),
    ("Bruno", "Matemática", 6.0), ("Bruno", "História", 7.0),
    ("Carla", "Matemática", 10.0), ("Carla", "História", 9.5),
])

print(con.execute("SELECT aluno, nota FROM notas WHERE materia = 'Matemática' AND nota >= 7").fetchall())
print(con.execute("SELECT DISTINCT aluno FROM notas WHERE aluno LIKE 'C%'").fetchall())
con.close()

[('Ana', 9.0), ('Carla', 10.0)]
[('Carla',)]

executemany insere várias linhas de uma vez (os ? são explicados na aula 175). No LIKE, % significa "qualquer coisa" e _ significa "exatamente um caractere". DISTINCT tira repetições.

Ordenar e limitar

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE notas (aluno TEXT, materia TEXT, nota REAL)")
con.executemany("INSERT INTO notas VALUES (?, ?, ?)", [
    ("Ana", "Matemática", 9.0), ("Ana", "História", 7.5),
    ("Bruno", "Matemática", 6.0), ("Bruno", "História", 7.0),
    ("Carla", "Matemática", 10.0), ("Carla", "História", 9.5),
])
for linha in con.execute("SELECT aluno, materia, nota FROM notas ORDER BY nota DESC LIMIT 3"):
    print(linha)
con.close()

('Carla', 'Matemática', 10.0)
('Carla', 'História', 9.5)
('Ana', 'Matemática', 9.0)

ORDER BY nota DESC ordena da maior para a menor (ASC, o padrão, é da menor para a maior). LIMIT 3 pega só as três primeiras: o "pódio".

Resumindo com agregação

As funções de agregação transformam muitas linhas em um número. Com GROUP BY, o resumo é feito por grupo:

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE notas (aluno TEXT, materia TEXT, nota REAL)")
con.executemany("INSERT INTO notas VALUES (?, ?, ?)", [
    ("Ana", "Matemática", 9.0), ("Ana", "História", 7.5),
    ("Bruno", "Matemática", 6.0), ("Bruno", "História", 7.0),
    ("Carla", "Matemática", 10.0), ("Carla", "História", 9.5),
])
print(con.execute("SELECT COUNT(*), MIN(nota), MAX(nota) FROM notas").fetchone())
for aluno, media in con.execute(
        "SELECT aluno, AVG(nota) FROM notas GROUP BY aluno ORDER BY aluno"):
    print(f"{aluno}: {media:.2f}")
con.close()

(6, 6.0, 10.0)
Ana: 8.25
Bruno: 6.50
Carla: 9.75

Dica: Para filtrar depois de agrupar, use HAVING em vez de WHERE: GROUP BY aluno HAVING AVG(nota) >= 8.
Atenção: Sem ORDER BY, o banco pode devolver as linhas em qualquer ordem. Se a ordem importa, peça explicitamente.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
SELECT aluno, AVG(nota) FROM notas GROUP BY aluno

Exercícios

1. Usando a tabela notas, mostre a média de cada matéria, da maior para a menor.

Ver resposta 
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE notas (aluno TEXT, materia TEXT, nota REAL)")
con.executemany("INSERT INTO notas VALUES (?, ?, ?)", [
    ("Ana", "Matemática", 9.0), ("Ana", "História", 7.5),
    ("Bruno", "Matemática", 6.0), ("Bruno", "História", 7.0),
    ("Carla", "Matemática", 10.0), ("Carla", "História", 9.5),
])
sql = "SELECT materia, AVG(nota) AS media FROM notas GROUP BY materia ORDER BY media DESC"
for materia, media in con.execute(sql):
    print(f"{materia}: {media:.2f}")
con.close()

Matemática: 8.33
História: 8.00

2. Mostre só os alunos com média maior ou igual a 8, usando HAVING.
