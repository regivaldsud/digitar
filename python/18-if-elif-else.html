O programa que decide

Até agora, todo programa rodava todas as linhas, sempre. Mas a vida real é cheia de escolhas: se estiver chovendo, levo guarda-chuva; senão, vou de boné. Em Python, essas escolhas são feitas com if (se), elif (senão, se) e else (senão).

temperatura = 32
if temperatura > 30:
    print("Está calor! Bora tomar um açaí.")
print("Fim do programa.")

Está calor! Bora tomar um açaí.
Fim do programa.

A linha com print recuada só roda se a condição temperatura > 30 for True. A última linha, sem recuo, roda sempre. Mude a temperatura para 25 e rode de novo.

Para escrever condições, use as comparações: > (maior), < (menor), >= (maior ou igual), <= (menor ou igual), == (igual) e != (diferente). Você vai estudá-las a fundo na aula 19.

Indentação: o recuo que manda

Depois do if vem sempre um dois-pontos :. As linhas de baixo que pertencem ao if são recuadas com 4 espaços (o VS Code coloca sozinho quando você aperta Tab). Esse conjunto de linhas recuadas é um bloco.

nota = 8.5
if nota >= 7:
    print("Aprovado!")
    print("Parabéns, pode comemorar.")
print("Boletim conferido.")

Aprovado!
Parabéns, pode comemorar.
Boletim conferido.

Atenção: Esquecer os dois-pontos dá SyntaxError: expected ':'. Misturar recuos diferentes (2 espaços numa linha, 4 na outra) dá IndentationError. Use sempre 4 espaços.

if e else: dois caminhos

Com else, você diz o que fazer quando a condição é falsa. O else não tem condição — ele pega "todo o resto".

idade = 15
if idade >= 18:
    print("Você já pode tirar a carteira de motorista.")
else:
    faltam = 18 - idade
    print(f"Faltam {faltam} anos para tirar a carteira.")

Faltam 3 anos para tirar a carteira.

resposta = input("Qual país ganhou 5 Copas do Mundo? ")
if resposta.strip().lower() == "brasil":
    print("Acertou!")
else:
    print("Errou! Foi o Brasil.")

(exemplo digitando Brasil)
Qual país ganhou 5 Copas do Mundo? Brasil
Acertou!

Atenção: Não confunda = (guardar um valor) com == (comparar). if idade = 18: dá erro; o certo é if idade == 18:.

elif: vários caminhos

Quando há mais de duas possibilidades, use elif. O Python testa as condições de cima para baixo e executa só o primeiro bloco cuja condição for verdadeira.

nota = 6.5
if nota >= 9:
    print("Conceito A")
elif nota >= 7:
    print("Conceito B")
elif nota >= 5:
    print("Conceito C")
else:
    print("Conceito D")

Conceito C

A nota 6.5 não é maior ou igual a 9, nem a 7, mas é maior ou igual a 5 — então aparece "Conceito C" e o resto é ignorado.

Dica: A ordem dos elif importa. Se você testar nota >= 5 antes de nota >= 9, uma nota 10 cairia no "Conceito C". Comece sempre pela condição mais exigente.

Um if dentro do outro

Um bloco pode ter outro if dentro. Cada nível ganha mais 4 espaços de recuo:

saldo = 20
preco = 15
if saldo >= preco:
    print("Compra aprovada!")
    troco = saldo - preco
    if troco > 0:
        print(f"Seu troco: R$ {troco:.2f}")
else:
    print("Saldo insuficiente.")

Compra aprovada!
Seu troco: R$ 5.00

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
if nota >= 7: print("Aprovado")

Exercícios

1. Crie uma variável saldo e mostre "Pode comprar o lanche" se ela for maior ou igual a 15, ou "Saldo insuficiente" caso contrário. Teste com saldo = 12.

Ver resposta 
saldo = 12
if saldo >= 15:
    print("Pode comprar o lanche")
else:
    print("Saldo insuficiente")

Saldo insuficiente

2. Faça um programa que diga se um número guardado na variável n é positivo, negativo ou zero. Teste com n = -4.

Ver resposta 
n = -4
if n > 0:
    print("Positivo")
elif n < 0:
    print("Negativo")
else:
    print("Zero")

Negativo

3. Peça um número inteiro e diga se ele é par ou ímpar (dica: use %).

Ver resposta 
numero = int(input("Digite um número: "))
if numero % 2 == 0:
    print(numero, "é par")
else:
    print(numero, "é ímpar")

(exemplo digitando 7)
Digite um número: 7
7 é ímpar

4. Classifique o IMC de uma pessoa: abaixo de 18.5 é "abaixo do peso", até 24.9 é "peso normal", até 29.9 é "sobrepeso" e acima disso "obesidade". Calcule com peso = 70 e altura = 1.75 (IMC = peso / altura²).

Ver resposta 
peso = 70
altura = 1.75
imc = peso / altura ** 2
if imc < 18.5:
    faixa = "abaixo do peso"
elif imc <= 24.9:
    faixa = "peso normal"
elif imc <= 29.9:
    faixa = "sobrepeso"
else:
    faixa = "obesidade"
print(f"IMC {imc:.1f}: {faixa}")

IMC 22.9: peso normal

5. Uma loja dá frete grátis para compras a partir de R$ 100. Abaixo disso, o frete custa R$ 15. Mostre o total a pagar para uma compra de R$ 85.

Ver resposta 
compra = 85
if compra >= 100:
    frete = 0
else:
    frete = 15
print(f"Total: R$ {compra + frete:.2f}")

Total: R$ 100.00
