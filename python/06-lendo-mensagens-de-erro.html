Aula 06 · Lendo mensagens de erro

Nesta aula você vai aprender

  • Entender as três partes de uma mensagem de erro: onde, qual tipo e por quê
  • Reconhecer SyntaxError, NameError, TypeError, IndentationError e ZeroDivisionError
  • Corrigir erros com calma, começando pela última linha da mensagem
  • Perceber que erro não é fracasso: é o Python tentando ajudar

O erro é um recado, não uma bronca

Quando algo dá errado, o Python para o programa e mostra uma mensagem chamada traceback ("rastro"). Parece assustadora no começo, mas ela diz exatamente o que aconteceu. Veja um exemplo de traceback completo:

Traceback (most recent call last):
  File "C:\Users\Ana\curso-python\teste.py", line 2, in <module>
    print(nome)
          ^^^^
NameError: name 'nome' is not defined

Leia assim:

  • Onde: arquivo teste.py, linha 2. A linha com problema aparece logo abaixo, e os ^^^^ apontam o pedaço exato.
  • Tipo: NameError — o nome do erro.
  • Por quê: name 'nome' is not defined — "o nome 'nome' não foi definido".
Dica: Comece sempre pela última linha. Ela tem o tipo e a explicação do erro. Depois suba para ver em que linha aconteceu.

Aqui no site, ao executar um exemplo com erro, a saída mostra essa última linha.

NameError: nome desconhecido

Acontece quando você usa um nome que o Python não conhece: uma variável que não existe, ou uma palavra escrita errada.

cidade = "Salvador"
print(cidad)

NameError: name 'cidad' is not defined. Did you mean: 'cidade'?

Aqui faltou a letra "e". O Python até sugere: Did you mean: 'cidade'? ("Você quis dizer 'cidade'?").

Print("Olá")

NameError: name 'Print' is not defined. Did you mean: 'print'?

Print com P maiúsculo não existe. O certo é print.

SyntaxError: escrita errada

Sintaxe é a "gramática" da linguagem. Um SyntaxError aparece quando o código não segue as regras: faltou fechar parênteses, aspas, ou sobrou algum símbolo. Com esse erro, nada do programa roda, nem as linhas que estavam certas.

print("Bom dia"

  File "teste.py", line 1
    print("Bom dia"
         ^
SyntaxError: '(' was never closed

A mensagem diz que o parêntese ( foi aberto e nunca fechado. Outro clássico é esquecer de fechar as aspas:

print("Bom dia)

  File "teste.py", line 1
    print("Bom dia)
          ^
SyntaxError: unterminated string literal (detected at line 1)

"Unterminated string literal" quer dizer "texto que não terminou": faltou a aspa do final.

Atenção: Às vezes o Python aponta a linha seguinte à do erro real, porque só percebe o problema depois. Se a linha indicada parece certa, olhe a linha de cima.

TypeError e ZeroDivisionError

O TypeError acontece quando você mistura coisas que não combinam, como juntar um texto com um número:

idade = 12
print("Tenho " + idade + " anos")

TypeError: can only concatenate str (not "int") to str

A mensagem diz que só dá para juntar (concatenar) texto com texto, não com número (int). Uma solução é usar vírgulas no print:

idade = 12
print("Tenho", idade, "anos")

Tenho 12 anos

Já o ZeroDivisionError aparece quando o programa tenta dividir por zero, que é impossível também na matemática:

pizzas = 3
pessoas = 0
print(pizzas / pessoas)

ZeroDivisionError: division by zero

IndentationError: espaços no começo da linha

No Python, os espaços no começo da linha (a indentação) têm significado. Um espaço sobrando já causa erro:

print("linha 1")
    print("linha 2")

  File "teste.py", line 2
    print("linha 2")
IndentationError: unexpected indent

"Unexpected indent" é "recuo inesperado". Por enquanto, todas as suas linhas devem começar encostadas na margem. Nas aulas 18 (if) e 22 (while) você vai ver quando o recuo é necessário.

Um roteiro para corrigir erros

  • Leia a última linha: qual é o tipo e a explicação?
  • Veja o número da linha e o pedaço marcado com ^.
  • Confira letras maiúsculas, aspas, parênteses e espaços.
  • Corrija um erro por vez e rode de novo.
  • Se não entender, copie a última linha e pesquise na internet: alguém já teve o mesmo erro.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
print("Corrija um erro de cada vez!")

Exercícios

1. Rode o código abaixo, leia o erro e corrija: print("Feliz aniversário!".

Ver resposta 
print("Feliz aniversário!")

Feliz aniversário!

O erro era SyntaxError: '(' was never closed: faltava fechar o parêntese.

2. Qual é o tipo de erro e como corrigir? numero = 7 e depois print(Numero).

Ver resposta 
numero = 7
print(numero)

7

É um NameError: Numero com N maiúsculo é outro nome, diferente de numero. O Python diferencia maiúsculas de minúsculas.

3. Este código dá TypeError. Corrija para mostrar Pontos: 50: pontos = 50 e print("Pontos: " + pontos).

Ver resposta 
pontos = 50
print("Pontos:", pontos)

Pontos: 50

Também funcionaria print("Pontos: " + str(pontos)), convertendo o número em texto. Você vai ver o str() na aula 13.

4. Numa mensagem de erro, em qual linha você deve começar a ler e o que ela informa?

Ver resposta

Na última linha. Ela informa o tipo do erro (por exemplo, NameError)
e uma explicação curta do que aconteceu.

5. O programa abaixo tem dois erros. Encontre e corrija os dois: print("Olá) e, na linha seguinte, print("Tchau") com um espaço no começo.

Ver resposta 
print("Olá")
print("Tchau")

Olá
Tchau

Faltava fechar as aspas na primeira linha (SyntaxError) e havia um espaço sobrando no começo da segunda (IndentationError).
