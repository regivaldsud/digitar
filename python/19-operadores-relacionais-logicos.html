Perguntas de sim ou não

Um operador de comparação (ou relacional) faz uma pergunta e a resposta é sempre um bool: True ou False.

  • == igual a
  • != diferente de
  • < menor que, > maior que
  • <= menor ou igual, >= maior ou igual
print(5 > 3)
print(5 < 3)
print(10 == 10)
print(10 != 10)
print(7 >= 7)
idade = 13
pode_ver = idade >= 12
print("Pode ver o filme de 12 anos?", pode_ver)

True
False
True
False
True
Pode ver o filme de 12 anos? True

Atenção: = e == são coisas diferentes. Um = guarda um valor (idade = 13). Dois == comparam (idade == 13). Trocar um pelo outro é um dos erros mais comuns.

Comparando textos

Textos também podem ser comparados. A comparação diferencia maiúsculas de minúsculas:

print("banana" == "banana")
print("Banana" == "banana")
print("abacate" < "banana")
print("10" == 10)
print("Sim".lower() == "sim")

O < entre textos compara em ordem alfabética (como no dicionário). E o texto "10" não é igual ao número 10: são tipos diferentes.

and, or e not

Para juntar condições, use os operadores lógicos:

  • and (e): só é True se as duas forem verdadeiras.
  • or (ou): é True se pelo menos uma for verdadeira.
  • not (não): inverte, True vira False e vice-versa.
idade = 15
tem_autorizacao = True
print(idade >= 12 and tem_autorizacao)
print(idade < 12 or tem_autorizacao)
print(not tem_autorizacao)
if idade >= 12 and tem_autorizacao:
    print("Pode ir à excursão do museu.")

True
True
False
Pode ir à excursão do museu.

A tabela-verdade mostra o resultado de cada combinação:

A      B      | A and B | A or B
True   True   | True    | True
True   False  | False   | True
False  True   | False   | True
False  False  | False   | False

Um jeito de lembrar: no and, basta um False para tudo dar False. No or, basta um True para tudo dar True.

Dica: A ordem de prioridade é: primeiro not, depois and, depois or. Quando misturar and e or, use parênteses para deixar claro o que você quer: (a or b) and c.

Intervalos

Para saber se um valor está entre dois limites, use and ou a forma encadeada do Python, que lê igual à matemática:

nota = 7.5
print(nota >= 7 and nota <= 10)
print(7 <= nota <= 10)
chovendo = False
fim_de_semana = True
vai_a_praia = fim_de_semana and not chovendo
print("Vai à praia?", vai_a_praia)

Vai à praia? True

Procurando com in e not in

O operador in verifica se um trecho aparece dentro de um texto. not in faz a pergunta contrária:

email = "ana.souza@exemplo.com.br"
print("@" in email)
print(".br" in email)
print("gmail" in email)
print(" " not in email)
if "@" not in email:
    print("E-mail inválido")
else:
    print("E-mail parece válido")

Exercícios

1. Um número é par quando o resto da divisão por 2 é zero. Mostre se 84 é par usando % e ==.

Ver resposta 
numero = 84
print(numero % 2 == 0)

True

2. Para entrar no brinquedo, é preciso ter pelo menos 1,40 m e no máximo 1,95 m. Mostre se a altura 1.38 pode entrar.

Ver resposta 
altura = 1.38
print(1.40 <= altura <= 1.95)

False

3. Sem rodar, diga o resultado de True and False or True. Depois confira.

Ver resposta 
print(True and False or True)

True

O and é feito primeiro: True and False dá False. Depois False or True dá True.

4. A loja dá desconto para quem é estudante ou tem mais de 60 anos. Com estudante = False e idade = 65, mostre se a pessoa ganha desconto.

Ver resposta 
estudante = False
idade = 65
print("Ganha desconto?", estudante or idade > 60)

Ganha desconto? True

frase = input("Digite uma frase: ")
