Aula 243 · Projeto: uma landing page com HTML e CSS

Nesta aula você vai aprender

  • Planejar as partes de uma landing page antes de programar
  • Guardar o conteúdo da página em listas e dicionários do Python
  • Escrever funções que geram cada parte do HTML, com html.escape
  • Gerar o CSS com flexbox, grid e uma media query para o celular
  • Gravar index.html e estilo.css, conferir com html.parser e abrir no navegador
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

O que vamos construir

Uma landing page ("página de chegada") é uma página única que apresenta algo e convida a pessoa a fazer uma ação, como se inscrever. A nossa vai divulgar uma (imaginária) Feira de Ciências da Escola. Ela terá:

  • um cabeçalho com o nome do evento, uma frase e um botão;
  • três ou mais cartões de destaque, lado a lado no computador e um embaixo do outro no celular;
  • uma seção de depoimentos de quem foi no ano passado;
  • um rodapé com a data e o local.

Por que gerar a página com Python, em vez de escrever o HTML à mão? Porque o conteúdo fica separado da aparência: para trocar um cartão ou adicionar um depoimento, você mexe só nos dados e roda o script de novo. É o mesmo princípio dos templates do Django (aula 202).

Crie uma pasta feira no computador. No fim, ela terá dados.py, gerar_pagina.py, index.html e estilo.css.

Passo 2: uma função para cada parte

Cada parte da página vira uma função pequena que recebe dados e devolve um texto HTML. Funções pequenas são fáceis de testar uma de cada vez. Veja duas delas funcionando:

import html


def cartao(item):
    return (f'    <article class="cartao">\n'
            f'      <h2>{html.escape(item["titulo"])}</h2>\n'
            f'      <p>{html.escape(item["texto"])}</p>\n'
            f'    </article>')


def depoimento(item):
    return (f'    <blockquote>\n'
            f'      <p>“{html.escape(item["texto"])}”</p>\n'
            f'      <cite>{html.escape(item["nome"])}</cite>\n'
            f'    </blockquote>')


print(cartao({"titulo": "Química", "texto": "Vulcão de bicarbonato & outras reações."}))
print(depoimento({"nome": "Prof. Carla", "texto": "A melhor feira!"}))

    <article class="cartao">
      <h2>Química</h2>
      <p>Vulcão de bicarbonato &amp; outras reações.</p>
    </article>
    <blockquote>
      <p>“A melhor feira!”</p>
      <cite>Prof. Carla</cite>
    </blockquote>

O & virou &amp;, que o navegador mostra como & normal.

Passo 3: o CSS

O CSS também é gerado pelo script, com as cores num dicionário (aula 242). Os pontos importantes:

  • * { box-sizing: border-box; } para as larguras não surpreenderem;
  • .destaques usa flexbox com flex-wrap: wrap: os cartões descem para a linha de baixo quando não cabem;
  • .depoimentos usa grid com duas colunas;
  • a media query deixa os depoimentos em uma coluna e diminui o título em telas de até 600px.

Veja o trecho das cores sendo montado:

cores = {"principal": "#0b6e4f", "botao": "#ffd23f", "fundo_rodape": "#eeeeee"}

trecho = f""".topo {{ background: {cores["principal"]}; color: white; }}
.botao {{ background: {cores["botao"]}; }}
.rodape {{ background: {cores["fundo_rodape"]}; }}"""
print(trecho)

.topo { background: #0b6e4f; color: white; }
.botao { background: #ffd23f; }
.rodape { background: #eeeeee; }

Passo 4: o gerador completo

Este é o programa inteiro. Salve como gerar_pagina.py na pasta feira, ao lado de dados.py, abra o terminal nessa pasta e rode com python gerar_pagina.py (python3 no Linux e no Mac):

import html
from pathlib import Path

from dados import depoimentos, destaques, evento

CORES = {"principal": "#0b6e4f", "botao": "#ffd23f", "texto": "#222222",
         "fundo_rodape": "#eeeeee"}


def esc(texto):
    return html.escape(texto)


def cartao(item):
    return (f'    <article class="cartao">\n'
            f'      <h2>{esc(item["titulo"])}</h2>\n'
            f'      <p>{esc(item["texto"])}</p>\n'
            f'    </article>')


def depoimento(item):
    return (f'    <blockquote>\n'
            f'      <p>“{esc(item["texto"])}”</p>\n'
            f'      <cite>{esc(item["nome"])}</cite>\n'
            f'    </blockquote>')


def gerar_html():
    cartoes = "\n".join(cartao(d) for d in destaques)
    falas = "\n".join(depoimento(d) for d in depoimentos)
    return f"""<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>{esc(evento["nome"])}</title>
  <link rel="stylesheet" href="estilo.css">
</head>
<body>
  <header class="topo">
    <h1>{esc(evento["nome"])}</h1>
    <p>{esc(evento["frase"])}</p>
    <a class="botao" href="#local">Quero participar</a>
  </header>
  <main>
  <section class="destaques">
{cartoes}
  </section>
  <section class="depoimentos">
{falas}
  </section>
  </main>
  <footer class="rodape" id="local">
    <p>{esc(evento["data"])} · {esc(evento["local"])}</p>
  </footer>
</body>
</html>
"""


def gerar_css():
    c = CORES
    return f"""* {{ box-sizing: border-box; }}
body {{ margin: 0; font-family: Arial, sans-serif; color: {c["texto"]}; }}
.topo {{ background: {c["principal"]}; color: white; text-align: center; padding: 48px 16px; }}
.topo h1 {{ font-size: 2.5rem; margin: 0 0 8px; }}
.botao {{ display: inline-block; background: {c["botao"]}; color: {c["texto"]};
         padding: 12px 24px; border-radius: 8px; text-decoration: none; font-weight: bold; }}
.botao:hover {{ filter: brightness(0.9); }}
.destaques {{ display: flex; flex-wrap: wrap; gap: 16px; padding: 32px 16px;
             justify-content: center; }}
.cartao {{ flex: 1 1 220px; max-width: 300px; padding: 16px;
          border: 2px solid {c["principal"]}; border-radius: 8px; }}
.depoimentos {{ display: grid; grid-template-columns: repeat(2, 1fr); gap: 16px;
               max-width: 800px; margin: 0 auto; padding: 0 16px 32px; }}
blockquote {{ margin: 0; padding: 16px; border-left: 4px solid {c["principal"]};
             background: #f7f7f7; }}
cite {{ display: block; margin-top: 8px; font-weight: bold; }}
.rodape {{ background: {c["fundo_rodape"]}; text-align: center; padding: 16px; }}

@media (max-width: 600px) {{
  .topo h1 {{ font-size: 1.8rem; }}
  .depoimentos {{ grid-template-columns: 1fr; }}
}}
"""


Path("index.html").write_text(gerar_html(), encoding="utf-8")
Path("estilo.css").write_text(gerar_css(), encoding="utf-8")
print(f"index.html: {len(destaques)} destaques e {len(depoimentos)} depoimentos")
print("estilo.css:", gerar_css().count("{"), "blocos de regras")

index.html: 3 destaques e 2 depoimentos
estilo.css: 15 blocos de regras

Agora abra o index.html com dois cliques (ou, no terminal, start index.html no Windows, open index.html no Mac, xdg-open index.html no Linux). O botão leva até o rodapé porque o link href="#local" aponta para o elemento com id="local".

Atenção: Se aparecer ModuleNotFoundError: No module named 'dados', o terminal não está na pasta feira ou o arquivo tem outro nome. Use cd feira e confira com ls (ou dir) que dados.py está ali.
Atenção: O <meta name="viewport" ...> é o que faz a página ficar boa no celular. Sem ele, o celular mostra a página minúscula, como se fosse uma tela de computador, e a media query não funciona.

Passo 5: conferir o resultado

Antes de mostrar para alguém, confira se a página está bem formada. Este script lê o index.html gerado e conta as tags importantes com o html.parser (aula 241). Salve como conferir.py na mesma pasta e rode:

from collections import Counter
from html.parser import HTMLParser
from pathlib import Path


class Contador(HTMLParser):
    def __init__(self):
        super().__init__()
        self.tags = Counter()

    def handle_starttag(self, tag, attrs):
        self.tags[tag] += 1


c = Contador()
c.feed(Path("index.html").read_text(encoding="utf-8"))
for tag in ["header", "section", "article", "blockquote", "footer", "a"]:
    print(f"{tag:10} {c.tags[tag]}")
print("Tem viewport?", "viewport" in Path("index.html").read_text(encoding="utf-8"))

header     1
section    2
article    3
blockquote 2
footer     1
a          1
Tem viewport? True

Para ver como fica no celular, aperte F12 no navegador e clique no ícone de celular (modo dispositivo): os cartões ficam um embaixo do outro e os depoimentos viram uma coluna.

def menu(itens):
    links = "".join(f'<a href="{html.escape(end)}">{html.escape(txt)}</a>' for txt, end in itens)

3. Por que usamos html.escape nas funções do gerador, se fomos nós mesmos que escrevemos os dados?

Ver resposta

Porque os dados podem mudar: um dia o depoimento pode vir de um formulário ou de uma
planilha. Um texto com < ou & quebraria a página (ou abriria espaço para um ataque XSS).
Escapar sempre é um hábito barato que evita esses problemas.

5. Faça uma função secao_faq(perguntas) que receba uma lista de pares (pergunta, resposta) e devolva uma <section> com um <details> para cada par (a pergunta vai no <summary>).

Ver resposta 
import html


def secao_faq(perguntas):
    partes = ['<section class="faq">', "  <h2>Perguntas frequentes</h2>"]
    for pergunta, resposta in perguntas:
        partes.append(f"  <details><summary>{html.escape(pergunta)}</summary>"
                      f"<p>{html.escape(resposta)}</p></details>")
    partes.append("</section>")
    return "\n".join(partes)


print(secao_faq([("Precisa pagar?", "Não, a entrada é grátis."),
                 ("Pode levar a família?", "Pode e deve!")]))

<section class="faq">
  <h2>Perguntas frequentes</h2>
  <details><summary>Precisa pagar?</summary><p>Não, a entrada é grátis.</p></details>
  <details><summary>Pode levar a família?</summary><p>Pode e deve!</p></details>
</section>
