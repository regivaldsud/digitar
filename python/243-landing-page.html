Aula 243 · Projeto: uma landing page com HTML e CSS

Nesta aula você vai aprender

  • Planejar as partes de uma landing page
  • Escrever o HTML e o CSS de cada parte
  • Gerar a página a partir de dados guardados em Python
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

O que vamos construir

Uma landing page é uma página única que apresenta um produto e convida a pessoa a fazer algo, como se inscrever. A nossa vai divulgar uma (imaginária) Feira de Ciências da Escola. Ela terá:

  • um cabeçalho com o nome do evento e um botão;
  • três cartões com os destaques, lado a lado (flexbox);
  • um rodapé com a data e o local.

Use o que você viu nas aulas 241 (HTML) e 242 (CSS).

Passo 1: o CSS

Salve como estilo.css:

body { margin: 0; font-family: Arial, sans-serif; color: #222; }
.topo { background: #0b6e4f; color: white; text-align: center; padding: 48px 16px; }
.botao { background: #ffd23f; color: #222; padding: 12px 24px;
         border-radius: 8px; text-decoration: none; font-weight: bold; }
.destaques { display: flex; flex-wrap: wrap; gap: 16px; padding: 32px 16px;
             justify-content: center; }
.cartao { flex: 1 1 220px; max-width: 300px; padding: 16px;
          border: 2px solid #0b6e4f; border-radius: 8px; }
.rodape { background: #eee; text-align: center; padding: 16px; }

O flex-wrap: wrap com flex: 1 1 220px faz os cartões descerem um embaixo do outro no celular, quando não cabem lado a lado.

Passo 2: os dados em Python

Em vez de escrever cada cartão à mão, guardamos o conteúdo numa lista de dicionários. Para mudar a página, basta mudar os dados:

evento = {
    "nome": "Feira de Ciências 2026",
    "frase": "Venha ver os projetos dos alunos!",
    "data": "12 de setembro, das 9h às 16h",
    "local": "Quadra da escola",
}

destaques = [
    {"titulo": "Robótica", "texto": "Robôs feitos com sucata e Arduino."},
    {"titulo": "Química", "texto": "Vulcão de bicarbonato e outras reações."},
    {"titulo": "Programação", "texto": "Jogos criados em Python pelos alunos."},
]

Passo 3: o gerador da página

Este script lê os dados e escreve index.html. Salve como gerar_pagina.py, na mesma pasta de dados.py e estilo.css, e rode com python gerar_pagina.py:

from pathlib import Path
from dados import evento, destaques


def cartao(item):
    return (f'    <div class="cartao">\n'
            f'      <h2>{item["titulo"]}</h2>\n'
            f'      <p>{item["texto"]}</p>\n'
            f'    </div>')


cartoes = "\n".join(cartao(item) for item in destaques)

pagina = f"""<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>{evento["nome"]}</title>
  <link rel="stylesheet" href="estilo.css">
</head>
<body>
  <header class="topo">
    <h1>{evento["nome"]}</h1>
    <p>{evento["frase"]}</p>
    <a class="botao" href="#local">Quero participar</a>
  </header>
  <main class="destaques">
{cartoes}
  </main>
  <footer class="rodape" id="local">
    <p>{evento["data"]} · {evento["local"]}</p>
  </footer>
</body>
</html>
"""

Path("index.html").write_text(pagina, encoding="utf-8")
print(f"Página gerada com {len(destaques)} cartões em index.html")

Página gerada com 3 cartões em index.html

Abra index.html no navegador. O botão leva até o rodapé porque o link href="#local" aponta para o elemento com id="local".

Atenção: O <meta name="viewport" ...> é o que faz a página ficar boa no celular. Sem ele, o celular mostra a página minúscula, como se fosse uma tela de computador.
Dica: Desafios extras: adicione uma seção de depoimentos, troque as cores do tema, ou publique a página de graça com o GitHub Pages (veja a aula 244).
Pratique no DIGITAR: digite este trecho no modo Programar do app.
