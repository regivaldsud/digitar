CRUD

Quase todo sistema faz quatro coisas com os dados: Create (criar), Read (ler), Update (atualizar) e Delete (apagar). Em SQL: INSERT, SELECT, UPDATE e DELETE.

Criando e inserindo

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("""
    CREATE TABLE produtos (
        id INTEGER PRIMARY KEY,
        nome TEXT NOT NULL,
        preco REAL,
        estoque INTEGER DEFAULT 0
    )
""")
con.execute("INSERT INTO produtos (nome, preco, estoque) VALUES ('Caderno', 18.5, 30)")
con.execute("INSERT INTO produtos (nome, preco, estoque) VALUES ('Lápis', 1.2, 200)")
con.execute("INSERT INTO produtos (nome, preco) VALUES ('Mochila', 120.0)")
for p in con.execute("SELECT * FROM produtos"):
    print(p)
con.close()

(1, 'Caderno', 18.5, 30)
(2, 'Lápis', 1.2, 200)
(3, 'Mochila', 120.0, 0)

NOT NULL obriga a coluna a ter valor; DEFAULT 0 define o valor quando nada é informado (a mochila ficou com estoque 0).

Atualizando e apagando

import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE produtos (id INTEGER PRIMARY KEY, nome TEXT, preco REAL)")
con.execute("INSERT INTO produtos (nome, preco) VALUES ('Caderno', 18.5)")
con.execute("INSERT INTO produtos (nome, preco) VALUES ('Lápis', 1.2)")
con.execute("INSERT INTO produtos (nome, preco) VALUES ('Borracha', 2.0)")

con.execute("UPDATE produtos SET preco = 20.0 WHERE nome = 'Caderno'")
con.execute("DELETE FROM produtos WHERE id = 3")

print(con.execute("SELECT * FROM produtos").fetchall())
con.close()

[(1, 'Caderno', 20.0), (2, 'Lápis', 1.2)]

fetchall() devolve todas as linhas numa lista; fetchone() devolve só a próxima.

Atenção: UPDATE ou DELETE sem WHERE mudam ou apagam a tabela inteira! Antes de rodar, leia o comando e confira o WHERE.

Salvando as mudanças

Num banco em arquivo, as alterações só ficam gravadas depois de con.commit(). Usar a conexão num with faz o commit sozinho quando tudo dá certo:

import sqlite3

con = sqlite3.connect("loja.db")
with con:
    con.execute("DROP TABLE IF EXISTS clientes")
    con.execute("CREATE TABLE clientes (id INTEGER PRIMARY KEY, nome TEXT)")
    con.execute("INSERT INTO clientes (nome) VALUES ('Joana')")
print(con.execute("SELECT COUNT(*) FROM clientes").fetchone()[0], "cliente(s)")
con.close()

1 cliente(s)

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
UPDATE produtos SET preco = 20.0 WHERE id = 1

Exercícios

1. Crie uma tabela filmes (id, titulo, ano), insira três filmes, mude o ano de um deles e apague outro. Mostre o resultado.

Ver resposta 
import sqlite3

con = sqlite3.connect(":memory:")
con.execute("CREATE TABLE filmes (id INTEGER PRIMARY KEY, titulo TEXT, ano INTEGER)")
con.execute("INSERT INTO filmes (titulo, ano) VALUES ('Central do Brasil', 1998)")
con.execute("INSERT INTO filmes (titulo, ano) VALUES ('O Auto da Compadecida', 2001)")
con.execute("INSERT INTO filmes (titulo, ano) VALUES ('Cidade de Deus', 2000)")
con.execute("UPDATE filmes SET ano = 2002 WHERE titulo = 'Cidade de Deus'")
con.execute("DELETE FROM filmes WHERE id = 1")
for f in con.execute("SELECT * FROM filmes"):
    print(f)
con.close()

(2, 'O Auto da Compadecida', 2001)
(3, 'Cidade de Deus', 2002)
