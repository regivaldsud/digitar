Aula 111 · HTTP com requests e http.server

Nesta aula você vai aprender

Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Como a web conversa

Quando você abre um site, o navegador manda uma requisição HTTP para um servidor, e o servidor devolve uma resposta. Toda resposta tem um código de status: 200 quer dizer "deu certo", 404 "não encontrado" e 500 "erro no servidor".

Uma API é um endereço feito para programas, e não para pessoas: em vez de uma página bonita, ela devolve dados, quase sempre em JSON (aula 105).

Instalando e usando requests

A biblioteca requests não vem com o Python. Instale dentro do seu ambiente virtual (aula 60):

pip install requests

Este exemplo consulta um CEP no ViaCEP, um serviço público brasileiro:

import requests

resposta = requests.get("https://viacep.com.br/ws/01001000/json/", timeout=10)
print("Status:", resposta.status_code)

if resposta.status_code == 200:
    dados = resposta.json()          # transforma o JSON em dicionário
    print(dados["logradouro"], "-", dados["localidade"], "/", dados["uf"])
else:
    print("Algo deu errado.")
Atenção: Sempre passe timeout. Sem ele, se o servidor não responder, seu programa pode ficar esperando para sempre. E trate erros de conexão com try/except requests.RequestException (aula 53).

O resposta.json() faz o mesmo que json.loads(resposta.text). Dá para treinar essa parte sem internet, com uma resposta de exemplo guardada num texto:

import json

texto = '{"cep": "01001-000", "logradouro": "Praça da Sé", "localidade": "São Paulo", "uf": "SP"}'
dados = json.loads(texto)
print(f"{dados['logradouro']}, {dados['localidade']} - {dados['uf']}")

Praça da Sé, São Paulo - SP

Um servidor em um comando

O Python traz um servidor web simples. Entre numa pasta com um arquivo index.html e rode:

python -m http.server 8000

Agora abra http://localhost:8000 no navegador: a página é servida pelo seu computador. Aperte Ctrl+C no terminal para parar. É ótimo para testar sites estáticos, como os das aulas 241 a 243.

Dica: localhost quer dizer "este computador". Só você consegue abrir esse endereço; não é um site público.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
resposta = requests.get(url, timeout=10)

Exercícios

1. Escreva uma função descrever_status(codigo) que devolve "sucesso" para 200, "não encontrado" para 404 e "erro" para os outros. Teste com 200, 404 e 500.

Ver resposta 
def descrever_status(codigo):
    if codigo == 200:
        return "sucesso"
    if codigo == 404:
        return "não encontrado"
    return "erro"

for c in [200, 404, 500]:
    print(c, descrever_status(c))

200 sucesso
404 não encontrado
500 erro

2. Modifique o exemplo do ViaCEP para pedir um CEP ao usuário com input e tratar falta de internet.

Ver resposta 
import requests

cep = input("CEP (só números): ").strip()
try:
    resposta = requests.get(f"https://viacep.com.br/ws/{cep}/json/", timeout=10)
    dados = resposta.json()
    if "erro" in dados:
        print("CEP não encontrado.")
    else:
        print(dados["logradouro"], "-", dados["localidade"])
except requests.RequestException:
    print("Não consegui conectar. Confira sua internet.")
