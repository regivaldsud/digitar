O problema dos índices

Uma tupla guarda vários valores juntos, como ("Fortaleza", "CE", 2428678). Mas, para pegar a população, você precisa lembrar que ela está na posição 2. Daqui a uma semana, o que significa cidade[2]?

cidade = ("Fortaleza", "CE", 2428678)
print(cidade[0], "tem", cidade[2], "habitantes")

Fortaleza tem 2428678 habitantes

A namedtuple resolve isso: é uma tupla em que cada posição também tem um nome.

Criando uma namedtuple

A função namedtuple, do módulo collections, cria um novo tipo. Você passa o nome do tipo e a lista dos campos:

from collections import namedtuple

Cidade = namedtuple("Cidade", ["nome", "estado", "populacao"])

fortaleza = Cidade("Fortaleza", "CE", 2428678)
print(fortaleza)
print(fortaleza.nome, "tem", fortaleza.populacao, "habitantes")
print(fortaleza[1])

Cidade(nome='Fortaleza', estado='CE', populacao=2428678)
Fortaleza tem 2428678 habitantes
CE

Ela continua sendo uma tupla: funciona com índices, desempacotamento e len. E, como toda tupla, é imutável:

from collections import namedtuple

Ponto = namedtuple("Ponto", ["x", "y"])
p = Ponto(3, 4)
x, y = p
print(x + y, len(p))
p.x = 10

7 2
AttributeError: can't set attribute

Atenção: Para "mudar" uma namedtuple, crie outra com _replace, como mostrado a seguir. Tentar alterar um campo dá AttributeError.

Métodos úteis

As namedtuples trazem alguns métodos que começam com sublinhado (para não confundir com os nomes dos campos):

from collections import namedtuple

Aluno = namedtuple("Aluno", ["nome", "turma", "nota"])
a = Aluno("Bruna", "9º A", 7.5)

print(Aluno._fields)
print(a._asdict())
b = a._replace(nota=9.0)
print(b)
print(a)

('nome', 'turma', 'nota')
{'nome': 'Bruna', 'turma': '9º A', 'nota': 7.5}
Aluno(nome='Bruna', turma='9º A', nota=9.0)
Aluno(nome='Bruna', turma='9º A', nota=7.5)

  • _fields: os nomes dos campos.
  • _asdict(): transforma em dicionário.
  • _replace(...): devolve uma cópia com alguns campos trocados; a original não muda.

Também dá para definir valores padrão com defaults. Eles valem para os últimos campos:

from collections import namedtuple

Pedido = namedtuple("Pedido", ["lanche", "quantidade", "bebida"], defaults=[1, "água"])
print(Pedido("tapioca"))
print(Pedido("cuscuz", 2, "suco de caju"))

Pedido(lanche='tapioca', quantidade=1, bebida='água')
Pedido(lanche='cuscuz', quantidade=2, bebida='suco de caju')

A versão com tipos: typing.NamedTuple

Com typing.NamedTuple, você escreve a namedtuple no formato de classe, com type hints. O resultado é o mesmo tipo de tupla, mas mais fácil de ler — e dá até para colocar métodos:

from typing import NamedTuple

class Produto(NamedTuple):
    nome: str
    preco: float
    quantidade: int = 1

    def total(self):
        return self.preco * self.quantidade

itens = [Produto("arroz", 25.90), Produto("ovos", 0.80, 12)]
for item in itens:
    print(f"{item.nome:<6} R$ {item.total():6.2f}")

arroz  R$  25.90
ovos   R$   9.60

namedtuple ou dataclass?

  • Use namedtuple para registros pequenos que não mudam: coordenadas, cores RGB, uma linha de planilha. É leve e funciona em qualquer lugar onde uma tupla funciona.
  • Use dataclass (aula 88) quando o objeto precisa mudar, ter validação no __post_init__ ou muitos métodos.
Dica: Funções que devolvem vários valores ficam muito mais claras devolvendo uma namedtuple: quem chamar pode usar resultado.media em vez de resultado[1].
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
Ponto = namedtuple("Ponto", ["x", "y"])

Exercícios

1. Crie a namedtuple Cor com os campos r, g e b e mostre a cor Cor(0, 156, 59) (o verde da bandeira) e o valor do campo g.

Ver resposta 
from collections import namedtuple

Cor = namedtuple("Cor", ["r", "g", "b"])
verde = Cor(0, 156, 59)
print(verde)
print(verde.g)

Cor(r=0, g=156, b=59)
156

2. Crie a função estatisticas(notas) que devolve uma namedtuple Resumo com menor, maior e media. Teste com [7, 9.5, 6, 8].

Ver resposta 
from collections import namedtuple

Resumo = namedtuple("Resumo", ["menor", "maior", "media"])

def estatisticas(notas):
    return Resumo(min(notas), max(notas), sum(notas) / len(notas))

r = estatisticas([7, 9.5, 6, 8])
print(r)
print(f"Média: {r.media:.2f}")

Resumo(menor=6, maior=9.5, media=7.625)
Média: 7.62

3. Uma namedtuple Jogador tem nome e pontos. Use _replace para criar uma versão com 10 pontos a mais e mostre a antiga e a nova.

Ver resposta 
from collections import namedtuple

Jogador = namedtuple("Jogador", ["nome", "pontos"])
antes = Jogador("Duda", 40)
depois = antes._replace(pontos=antes.pontos + 10)
print(antes)
print(depois)

Jogador(nome='Duda', pontos=40)
Jogador(nome='Duda', pontos=50)

4. Com typing.NamedTuple, crie Viagem com origem, destino e km, e um método horas(velocidade) que calcula o tempo de viagem. Ordene uma lista de viagens pela distância.

Ver resposta 
from typing import NamedTuple

class Viagem(NamedTuple):
    origem: str
    destino: str
    km: float

    def horas(self, velocidade):
        return self.km / velocidade

viagens = [Viagem("São Paulo", "Rio", 430), Viagem("Recife", "João Pessoa", 120),
           Viagem("Curitiba", "Florianópolis", 300)]
for v in sorted(viagens, key=lambda v: v.km):
    print(f"{v.origem} -> {v.destino}: {v.horas(80):.1f} h")

Recife -> João Pessoa: 1.5 h
Curitiba -> Florianópolis: 3.8 h
São Paulo -> Rio: 5.4 h

5. Transforme cada linha da lista abaixo numa namedtuple Linha (produto, preco) e mostre a soma dos preços.

Ver resposta 
from collections import namedtuple

Linha = namedtuple("Linha", ["produto", "preco"])
dados = [("leite", 5.49), ("pão", 0.75), ("manteiga", 12.90)]
linhas = [Linha(*d) for d in dados]
print(f"Total: R$ {sum(l.preco for l in linhas):.2f}")

Total: R$ 19.14
