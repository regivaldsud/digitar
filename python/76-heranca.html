Herdar é reaproveitar

Imagine um jogo com vários tipos de personagens: guerreiro, mago, arqueiro. Todos têm nome e vida e todos andam, mas cada um ataca de um jeito. Em vez de copiar o mesmo código três vezes, você escreve o que é comum numa classe mãe (ou superclasse) e cria classes filhas (subclasses) que herdam tudo dela.

Para herdar, coloque o nome da classe mãe entre parênteses:

class Animal:
    def __init__(self, nome):
        self.nome = nome

    def comer(self):
        print(f"{self.nome} está comendo.")

class Cachorro(Animal):
    def latir(self):
        print(f"{self.nome}: Au au!")

caramelo = Cachorro("Caramelo")
caramelo.comer()
caramelo.latir()

Caramelo está comendo.
Caramelo: Au au!

O Cachorro não tem __init__ nem comer, mas herdou os dois de Animal. Dizemos que um cachorro é um animal.

Sobrescrevendo métodos

Se a filha define um método com o mesmo nome de um da mãe, o da filha vence. Isso se chama sobrescrever.

class Animal:
    def __init__(self, nome):
        self.nome = nome

    def som(self):
        return "..."

    def falar(self):
        print(f"{self.nome} faz {self.som()}")

class Gato(Animal):
    def som(self):
        return "miau"

class Vaca(Animal):
    def som(self):
        return "muuu"

for bicho in [Gato("Mimi"), Vaca("Mimosa"), Animal("Peixe")]:
    bicho.falar()

Mimi faz miau
Mimosa faz muuu
Peixe faz ...

O falar está só na mãe, mas cada objeto usa o seu próprio som. Na aula 79 você vai ver que isso tem nome: polimorfismo.

super(): aproveitando o método da mãe

Quando a filha precisa de atributos a mais, ela escreve o próprio __init__ e chama o da mãe com super().__init__(...) para não repetir código. O super() funciona em qualquer método, não só no __init__.

class Funcionario:
    def __init__(self, nome, salario):
        self.nome = nome
        self.salario = salario

    def __str__(self):
        return f"{self.nome} ganha R$ {self.salario:.2f}"

class Gerente(Funcionario):
    def __init__(self, nome, salario, equipe):
        super().__init__(nome, salario)
        self.equipe = equipe

    def __str__(self):
        return super().__str__() + f" e lidera {len(self.equipe)} pessoas"

print(Funcionario("Paulo", 3200))
print(Gerente("Renata", 7500, ["Paulo", "Sueli", "Tiago"]))

Paulo ganha R$ 3200.00
Renata ganha R$ 7500.00 e lidera 3 pessoas

Atenção: Se a filha tem __init__ próprio e você esquece o super().__init__(...), os atributos da mãe não são criados. Depois aparece AttributeError: 'Gerente' object has no attribute 'nome'.

isinstance e issubclass

isinstance(objeto, Classe) responde True se o objeto é daquela classe ou de uma filha dela. issubclass(Filha, Mae) compara duas classes.

class Veiculo:
    pass

class Carro(Veiculo):
    pass

class Bicicleta(Veiculo):
    pass

fusca = Carro()
caloi = Bicicleta()

print(isinstance(fusca, Carro))
print(isinstance(fusca, Veiculo))
print(isinstance(fusca, Bicicleta))
print(isinstance(caloi, Veiculo))
print(issubclass(Carro, Veiculo))
print(issubclass(Veiculo, Carro))

True

False
True
True
False

Dica: Use herança quando a frase "X é um Y" faz sentido: um gato é um animal, um gerente é um funcionário. Se a frase for "X tem um Y", use composição (aula 75).

Um exemplo de jogo

class Personagem:
    def __init__(self, nome, vida=100):
        self.nome = nome
        self.vida = vida

    def atacar(self):
        return 10

    def __str__(self):
        return f"{self.nome} ({type(self).__name__}) causa {self.atacar()} de dano"

class Guerreiro(Personagem):
    def atacar(self):
        return 25

class Mago(Personagem):
    def __init__(self, nome, mana=50):
        super().__init__(nome, vida=70)
        self.mana = mana

    def atacar(self):
        return 15 + self.mana // 10

for p in [Personagem("Aldeão"), Guerreiro("Lampião"), Mago("Iara")]:
    print(p, "| vida:", p.vida)

Aldeão (Personagem) causa 10 de dano | vida: 100
Lampião (Guerreiro) causa 25 de dano | vida: 100
Iara (Mago) causa 20 de dano | vida: 70

type(self).__name__ devolve o nome da classe do objeto, então o mesmo __str__ mostra Guerreiro ou Mago conforme o caso.

Exercícios

1. Crie a classe Forma com o método area() que devolve 0, e as filhas Quadrado(lado) e Circulo(raio) que sobrescrevem area(). Mostre a área de um quadrado de lado 4 e de um círculo de raio 2 (use 3.14 para pi).

Ver resposta 
class Forma:
    def area(self):
        return 0

class Quadrado(Forma):
    def __init__(self, lado):
        self.lado = lado

    def area(self):
        return self.lado ** 2

class Circulo(Forma):
    def __init__(self, raio):
        self.raio = raio

    def area(self):
        return 3.14 * self.raio ** 2

for f in [Quadrado(4), Circulo(2)]:
    print(type(f).__name__, f.area())

Quadrado 16
Circulo 12.56

2. Crie a classe Aluno(nome) e a filha Monitor(nome, materia), usando super().__init__. O Monitor deve ter um método ajudar() que mostra <nome> ajuda em <materia>.

Ver resposta 
class Aluno:
    def __init__(self, nome):
        self.nome = nome

class Monitor(Aluno):
    def __init__(self, nome, materia):
        super().__init__(nome)
        self.materia = materia

    def ajudar(self):
        print(f"{self.nome} ajuda em {self.materia}")

Monitor("Clara", "matemática").ajudar()

Clara ajuda em matemática

3. Com as classes Animal, Gato(Animal) e Vaca(Animal), conte quantos objetos de uma lista são gatos e quantos são animais usando isinstance.

Ver resposta 
class Animal:
    pass

class Gato(Animal):
    pass

class Vaca(Animal):
    pass

bichos = [Gato(), Vaca(), Gato(), Animal(), Gato()]
print("Gatos:", sum(1 for b in bichos if isinstance(b, Gato)))
print("Animais:", sum(1 for b in bichos if isinstance(b, Animal)))

Gatos: 3
Animais: 5

4. Crie a classe Conta(titular, saldo) com sacar(valor) que não deixa o saldo ficar negativo, e a filha ContaEspecial com um limite extra de R$ 500.

Ver resposta 
class Conta:
    def __init__(self, titular, saldo=0):
        self.titular = titular
        self.saldo = saldo

    def limite(self):
        return 0

    def sacar(self, valor):
        if valor > self.saldo + self.limite():
            print(f"{self.titular}: saque de {valor} negado")
        else:
            self.saldo -= valor
            print(f"{self.titular}: novo saldo {self.saldo}")

class ContaEspecial(Conta):
    def limite(self):
        return 500

Conta("Rui", 100).sacar(300)
ContaEspecial("Sara", 100).sacar(300)

Rui: saque de 300 negado
Sara: novo saldo -200

A filha sobrescreve só o método limite, e o sacar da mãe já funciona para as duas. Sobrescrever o próprio sacar também é uma resposta certa.

5. Crie a classe Notificacao com o método enviar(texto) que mostra Enviando: texto, e a filha NotificacaoUrgente, que sobrescreve enviar para colocar URGENTE! antes do texto, chamando o enviar da mãe com super().

Ver resposta 
class Notificacao:
    def enviar(self, texto):
        print("Enviando:", texto)

class NotificacaoUrgente(Notificacao):
    def enviar(self, texto):
        super().enviar("URGENTE! " + texto)

Notificacao().enviar("Prova amanhã")
NotificacaoUrgente().enviar("A aula começou")

Enviando: Prova amanhã
Enviando: URGENTE! A aula começou
