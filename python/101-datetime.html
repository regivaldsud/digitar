Aula 101 · Datas e horas: datetime, fuso horário, timestamp

Nesta aula você vai aprender

  • Criar datas com date e momentos com datetime
  • Pegar a data e a hora atuais
  • Entender o que é fuso horário e usar timezone
  • Converter um momento em timestamp e de volta
  • Ler e escrever datas no formato ISO

date e datetime

O módulo datetime tem dois tipos principais: date guarda só a data e datetime guarda data e hora.

from datetime import date, datetime

independencia = date(1822, 9, 7)
print(independencia)
print(independencia.day, independencia.month, independencia.year)

final_copa = datetime(2026, 7, 19, 16, 0)
print(final_copa)
print(final_copa.hour, "horas")

1822-09-07
7 9 1822
2026-07-19 16:00:00
16 horas

A ordem dos números é ano, mês, dia — o contrário do jeito brasileiro. Na aula 102 você aprende a mostrar no formato dd/mm/aaaa.

Atenção: Uma data impossível dá erro na hora: date(2025, 2, 30) gera ValueError: day is out of range for month. Isso é bom — o Python não deixa você guardar o dia 30 de fevereiro por engano.

Hoje e agora

from datetime import date, datetime

print("Hoje é", date.today())
agora = datetime.now()
print("Agora são", agora.hour, "horas e", agora.minute, "minutos")

(exemplo — a sua saída pode ser diferente)
Hoje é 2026-11-21
Agora são 14 horas e 30 minutos

date.today() e datetime.now() leem o relógio do computador. No navegador, a hora vem do relógio do seu aparelho.

Fuso horário

O Brasil tem quatro fusos. Quando são 12h em Brasília, são 11h em Manaus. Para o computador, um horário sem fuso é ambíguo: "16h" de onde?

Os horários do mundo inteiro são medidos a partir do UTC, o horário de referência. Brasília fica 3 horas atrás: UTC−3. No Python, um fuso fixo é criado com timezone e timedelta:

from datetime import datetime, timezone, timedelta

brasilia = timezone(timedelta(hours=-3))
manaus = timezone(timedelta(hours=-4))

aula = datetime(2026, 3, 10, 14, 0, tzinfo=brasilia)
print("Em Brasília:", aula)
print("Em Manaus:  ", aula.astimezone(manaus))
print("Em UTC:     ", aula.astimezone(timezone.utc))

Em Brasília: 2026-03-10 14:00:00-03:00
Em Manaus:   2026-03-10 13:00:00-04:00
Em UTC:      2026-03-10 17:00:00+00:00

Um datetime com tzinfo é chamado de consciente (sabe o seu fuso); sem tzinfo, é ingênuo. astimezone mostra o mesmo instante no relógio de outro lugar.

No computador você pode usar fusos com nome, que já sabem até as regras de horário de verão:

from datetime import datetime
from zoneinfo import ZoneInfo

agora_sp = datetime.now(ZoneInfo("America/Sao_Paulo"))
print(agora_sp)
Dica: No Windows, o zoneinfo precisa do pacote tzdata: rode pip install tzdata (veja a aula 60). Sem ele aparece ZoneInfoNotFoundError.

Timestamp: o momento como número

Um timestamp é a quantidade de segundos desde 1º de janeiro de 1970, à meia-noite em UTC. Computadores adoram esse número: é fácil de guardar e comparar.

from datetime import datetime, timezone, timedelta

brasilia = timezone(timedelta(hours=-3))
momento = datetime(2026, 1, 1, 0, 0, tzinfo=brasilia)

ts = momento.timestamp()
print("Timestamp:", ts)

de_volta = datetime.fromtimestamp(ts, tz=brasilia)
print("De volta:", de_volta)
print("Início da contagem:", datetime.fromtimestamp(0, tz=timezone.utc))

Timestamp: 1767236400.0
De volta: 2026-01-01 00:00:00-03:00
Início da contagem: 1970-01-01 00:00:00+00:00

Atenção: Use timestamp() só com datas que têm fuso. Num datetime ingênuo, o Python supõe o fuso do computador, e o mesmo código dá números diferentes em máquinas diferentes.

Formato ISO

O formato AAAA-MM-DD HH:MM:SS se chama ISO 8601. É o jeito padrão de guardar datas em texto (em arquivos JSON, por exemplo), porque não tem confusão entre dia e mês.

from datetime import datetime, date

texto = "2026-06-12T20:30:00"
jogo = datetime.fromisoformat(texto)
print(f"Jogo em {jogo.day}/{jogo.month} às {jogo.hour}h{jogo.minute}")

print(date(2026, 12, 25).isoformat())

Jogo em 12/6 às 20h30
2026-12-25

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
agora = datetime.now(tz=timezone.utc)

Exercícios

1. Crie a data do seu aniversário de 2026 com date e mostre o dia, o mês e o ano separados.

Ver resposta 
from datetime import date

aniversario = date(2026, 4, 23)
print(aniversario.day, aniversario.month, aniversario.year)

23 4 2026

2. Um show começa às 21h de 20/12/2026 em Brasília (UTC−3). Mostre que horas serão em Fernando de Noronha (UTC−2) e no Acre (UTC−5).

Ver resposta 
from datetime import datetime, timezone, timedelta

brasilia = timezone(timedelta(hours=-3))
noronha = timezone(timedelta(hours=-2))
acre = timezone(timedelta(hours=-5))

show = datetime(2026, 12, 20, 21, 0, tzinfo=brasilia)
print("Noronha:", show.astimezone(noronha).strftime("%H:%M"))
print("Acre:", show.astimezone(acre).strftime("%H:%M"))

Noronha: 22:00
Acre: 19:00

3. Converta o timestamp 1767225600 em data e hora UTC.

Ver resposta 
from datetime import datetime, timezone

print(datetime.fromtimestamp(1767225600, tz=timezone.utc))

2026-01-01 00:00:00+00:00

4. Transforme o texto "2026-07-19" numa date e mostre em que dia da semana cai. Dica: weekday() devolve 0 para segunda e 6 para domingo.

Ver resposta 
from datetime import date

dias = ["segunda", "terça", "quarta", "quinta", "sexta", "sábado", "domingo"]
final = date.fromisoformat("2026-07-19")
print(dias[final.weekday()])

domingo
