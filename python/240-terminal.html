Aula 240 · Comandos de terminal mais usados (Linux, Mac, WSL2)

Nesta aula você vai aprender

  • Navegar e mexer em pastas e arquivos com pwd, ls, cd, mkdir, cp, mv e rm
  • Comparar os comandos do Linux/Mac com os do Prompt de Comando do Windows

Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Por que aprender o terminal do Linux

Na aula 03 você usou o Prompt de Comando do Windows. Só que a maioria dos servidores da internet roda Linux, e o macOS usa praticamente os mesmos comandos. Por isso vale aprender os dois "sotaques" do terminal.

No Windows 10 e 11 dá para ter um Linux de verdade, sem apagar nada, com o WSL2 (Subsistema do Windows para Linux). Abra o PowerShell como administrador e digite:

wsl --install

Depois de reiniciar o computador, procure Ubuntu no menu Iniciar, crie um usuário e uma senha, e pronto: você tem um terminal Linux.

Os comandos do dia a dia

pwd                     # mostra em que pasta você está
ls                      # lista os arquivos (ls -la mostra os ocultos e detalhes)
cd projetos             # entra na pasta projetos
cd ..                   # volta uma pasta
cd ~                    # vai para a sua pasta pessoal
mkdir jogos             # cria a pasta jogos
touch anotacoes.txt     # cria um arquivo vazio
cat anotacoes.txt       # mostra o conteúdo do arquivo
cp ola.py copia.py      # copia um arquivo
mv copia.py velho.py    # move ou renomeia
rm velho.py             # apaga o arquivo (não vai para a lixeira!)
clear                   # limpa a tela

No terminal do Linux, o texto depois de # é um comentário, igual no Python.

Comparando com o Windows: dir vira ls, cls vira clear, copy vira cp, move vira mv, del vira rm e type vira cat. No Linux, as pastas são separadas por / (como em /home/ana/projetos); no Windows, por \.

Atenção: O rm apaga para sempre, sem lixeira. E rm -r pasta apaga a pasta inteira com tudo dentro. Confira duas vezes o nome antes de apertar Enter.
Dica: No Linux e no Mac, o Python costuma se chamar python3 no terminal: use python3 ola.py e python3 -m venv .venv.

O mesmo trabalho feito pelo Python

Tudo o que você faz no terminal também dá para fazer em Python, com o pathlib (visto na aula 103). Este script cria uma pasta, coloca um arquivo nela e lista o que tem dentro — o equivalente a mkdir, touch e ls:

from pathlib import Path

pasta = Path("exercicios")
pasta.mkdir(exist_ok=True)
(pasta / "ola.py").write_text('print("oi")\n', encoding="utf-8")
(pasta / "notas.txt").write_text("Estudar terminal\n", encoding="utf-8")

for arquivo in sorted(pasta.iterdir()):
    print(arquivo.name)

notas.txt
ola.py

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
mkdir -p projetos/jogos && cd projetos/jogos

Exercícios

1. Escreva os comandos do Linux para criar a pasta escola, entrar nela, criar o arquivo tarefas.txt e listar o conteúdo da pasta.

Ver resposta 
mkdir escola
cd escola
touch tarefas.txt
ls

2. Qual é o comando do Linux equivalente a cada comando do Windows: dir, cls, del nota.txt?

Ver resposta 
ls
clear
rm nota.txt

3. Faça um script Python que crie a pasta backup e, dentro dela, os arquivos dia1.txt, dia2.txt e dia3.txt, mostrando os nomes no fim.

Ver resposta 
from pathlib import Path

backup = Path("backup")
backup.mkdir(exist_ok=True)
for numero in range(1, 4):
    (backup / f"dia{numero}.txt").write_text("", encoding="utf-8")

for arquivo in sorted(backup.iterdir()):
    print(arquivo.name)

dia1.txt
dia2.txt
dia3.txt
