Por que aprender o terminal do Linux

Na aula 03 você usou o terminal do Windows. Só que quase todos os servidores da internet rodam Linux, e o macOS usa praticamente os mesmos comandos. Quando você for publicar um site (aula 220) ou usar o Docker (aula 210), vai digitar esses comandos. Por isso vale aprender os dois "sotaques" do terminal.

No Windows 10 e 11 dá para ter um Linux de verdade, sem apagar nada, com o WSL2 (Subsistema do Windows para Linux). Abra o PowerShell como administrador e digite:

wsl --install

Depois de reiniciar o computador, procure Ubuntu no menu Iniciar, crie um usuário e uma senha, e pronto: você tem um terminal Linux. No macOS, abra o aplicativo Terminal (procure com Cmd + Espaço).

Dica: Ao digitar a senha no Linux, nada aparece na tela — nem bolinhas. É de propósito, para ninguém contar as letras. Digite e aperte Enter.

Onde estou? pwd, ls e cd

O terminal sempre está "dentro" de uma pasta, chamada pasta atual. Os três comandos mais usados servem para se localizar:

pwd                 # mostra a pasta atual, por exemplo /home/ana
ls                  # lista o que tem na pasta atual
ls -la              # lista tudo, com detalhes e arquivos ocultos
cd projetos         # entra na pasta projetos
cd ..               # sobe uma pasta
cd ~                # vai para a sua pasta pessoal
cd -                # volta para a pasta onde você estava antes

No terminal do Linux, o texto depois de # é um comentário, igual no Python. A tecla Tab completa nomes de pastas e arquivos: digite cd proj e aperte Tab.

Em Python, Path.cwd() faz o papel do pwd, iterdir() o do ls e os.chdir() o do cd. Rode e veja (o programa cria uma pasta temporária só para o teste, que some no fim):

import os
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as raiz:
    os.chdir(raiz)                       # cd raiz
    Path("projetos/jogos").mkdir(parents=True)
    Path("notas.txt").write_text("oi", encoding="utf-8")

    print("ls:", sorted(p.name for p in Path.cwd().iterdir()))
    os.chdir("projetos")                 # cd projetos
    print("pwd termina em:", Path.cwd().name)
    os.chdir("..")                       # cd ..
    print("de volta em:", Path.cwd() == Path(raiz).resolve())
    os.chdir(Path.home())                # cd ~  (sai antes de apagar a pasta)

ls: ['notas.txt', 'projetos']
pwd termina em: projetos
de volta em: True

Caminhos absolutos e relativos

Um caminho absoluto começa na raiz do disco e funciona de qualquer lugar: /home/ana/projetos/jogo.py no Linux, C:\Users\Ana\projetos\jogo.py no Windows. Um caminho relativo parte da pasta atual: projetos/jogo.py.

Dois nomes especiais aparecem em todo lugar: . é a pasta atual e .. é a pasta de cima. E ~ é a sua pasta pessoal.

from pathlib import PurePosixPath, PureWindowsPath

linux = PurePosixPath("/home/ana/projetos/jogo.py")
windows = PureWindowsPath(r"C:\Users\Ana\projetos\jogo.py")

print("Absoluto?", linux.is_absolute(), windows.is_absolute())
print("Relativo?", PurePosixPath("projetos/jogo.py").is_absolute())
print("Pasta:", linux.parent)
print("Nome:", windows.name)
print("Subindo duas pastas:", linux.parent.parent)

Absoluto? True True
Relativo? False
Pasta: /home/ana/projetos
Nome: jogo.py
Subindo duas pastas: /home/ana

Atenção: No Linux e no Mac, maiúsculas e minúsculas fazem diferença: Fotos e fotos são pastas diferentes. No Windows, não. Um programa que funciona no seu Windows pode quebrar no servidor Linux por causa de uma letra maiúscula.

Criar, copiar, mover e apagar

mkdir jogos                 # cria a pasta jogos
mkdir -p escola/2026/notas  # cria a pasta e as de cima, se faltarem
touch anotacoes.txt         # cria um arquivo vazio
cp ola.py copia.py          # copia um arquivo
cp -r jogos jogos_backup    # copia uma pasta inteira (-r = recursivo)
mv copia.py velho.py        # renomeia
mv velho.py jogos/          # move para dentro de jogos
rm velho.py                 # apaga o arquivo (não vai para a lixeira!)
rm -r jogos_backup          # apaga a pasta com tudo dentro
clear                       # limpa a tela

O mesmo trabalho em Python usa pathlib (aula 103) e shutil (aula 104):

import os
import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as raiz:
    os.chdir(raiz)
    Path("escola/2026/notas").mkdir(parents=True)   # mkdir -p
    Path("ola.py").touch()                          # touch
    shutil.copy("ola.py", "copia.py")               # cp
    shutil.copytree("escola", "escola_backup")      # cp -r
    shutil.move("copia.py", "velho.py")             # mv (renomear)
    Path("velho.py").unlink()                       # rm
    shutil.rmtree("escola_backup")                  # rm -r

    print(sorted(p.name for p in Path(".").iterdir()))
    os.chdir(Path.home())

['escola', 'ola.py']

Atenção: O rm e o rm -r apagam para sempre, sem lixeira e sem perguntar. Nunca rode um comando com rm que você copiou da internet sem entender. Confira duas vezes o nome antes de apertar Enter.

Ver e procurar dentro dos arquivos

cat notas.txt            # mostra o arquivo inteiro
head -n 3 notas.txt      # mostra só as 3 primeiras linhas
tail -n 3 notas.txt      # mostra só as 3 últimas
grep Python notas.txt    # mostra as linhas que têm a palavra Python
wc -l notas.txt          # conta as linhas
ls | grep .py            # o | (pipe) manda a saída de um comando para o outro

O | (chamado pipe) é um superpoder: ele liga comandos pequenos para fazer algo maior. Em Python, cada um vira poucas linhas:

import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as raiz:
    arquivo = Path(raiz) / "notas.txt"
    arquivo.write_text("Estudar Python\nTreinar digitação\nRevisar Python\nDormir cedo\n",
                       encoding="utf-8")
    linhas = arquivo.read_text(encoding="utf-8").splitlines()

    print("head -n 2:", linhas[:2])
    print("tail -n 1:", linhas[-1:])
    print("grep Python:", [l for l in linhas if "Python" in l])
    print("wc -l:", len(linhas))

head -n 2: ['Estudar Python', 'Treinar digitação']
tail -n 1: ['Dormir cedo']
grep Python: ['Estudar Python', 'Revisar Python']
wc -l: 4

Linux, Windows e Python lado a lado

  • pwd — Windows: cd (sozinho) ou Get-Location — Python: Path.cwd()
  • ls — Windows: dir — Python: Path(".").iterdir()
  • cd pasta — Windows: cd pasta — Python: os.chdir("pasta")
  • mkdir -p a/b — Windows: mkdir a\b — Python: Path("a/b").mkdir(parents=True)
  • touch x.txt — Windows (PowerShell): New-Item x.txt — Python: Path("x.txt").touch()
  • cp / cp -r — Windows: copy / xcopy — Python: shutil.copy / shutil.copytree
  • mv — Windows: move ou ren — Python: shutil.move
  • rm / rm -r — Windows: del / rmdir /s — Python: Path.unlink() / shutil.rmtree
  • cat — Windows: type — Python: Path.read_text()
  • grep — Windows: findstr — Python: [l for l in linhas if "x" in l]
  • clear — Windows: cls

No PowerShell do Windows, ls, cat, cp, mv e rm também funcionam, como apelidos. No Linux, as pastas são separadas por /; no Windows, por \.

Dica: No Linux e no Mac, o Python costuma se chamar python3 no terminal: use python3 ola.py e python3 -m venv .venv. No Windows, é py ou python.

A variável PATH

Quando você digita python ou git, como o terminal sabe onde está o programa? Ele procura numa lista de pastas guardada na variável de ambiente PATH. Se a pasta do programa não estiver lá, aparece command not found (Linux) ou "não é reconhecido como um comando" (Windows).

echo $PATH          # Linux e Mac: mostra as pastas, separadas por :
echo $env:Path      # PowerShell: separadas por ;
which python3       # Linux e Mac: em que pasta está o programa
where python        # Windows: o mesmo

O Python lê o PATH com os.environ e procura programas com shutil.which. Aqui usamos um PATH de exemplo, escrito no próprio código, para ver como ele é dividido:

from pathlib import PurePosixPath

path_exemplo = "/usr/local/bin:/usr/bin:/bin:/home/ana/.local/bin"

for numero, pasta in enumerate(path_exemplo.split(":"), start=1):
    print(numero, pasta)

print("Onde o terminal procuraria 'python3':",
      [str(PurePosixPath(p) / "python3") for p in path_exemplo.split(":")][:2], "...")

1 /usr/local/bin
2 /usr/bin
3 /bin
4 /home/ana/.local/bin
Onde o terminal procuraria 'python3': ['/usr/local/bin/python3', '/usr/bin/python3'] ...

No seu computador, troque o texto de exemplo por os.environ["PATH"] e o ":" por os.pathsep (que vale ; no Windows e : no Linux).

5. Faça um script Python que, numa pasta temporária, crie a pasta backup com os arquivos dia1.txt, dia2.txt e dia3.txt, copie a pasta inteira para backup_velho (como cp -r) e mostre os nomes dentro da cópia.

Ver resposta 
import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as raiz:
    backup = Path(raiz) / "backup"
    backup.mkdir()
    for numero in range(1, 4):
        (backup / f"dia{numero}.txt").touch()

    copia = shutil.copytree(backup, Path(raiz) / "backup_velho")
    print(sorted(p.name for p in Path(copia).iterdir()))
