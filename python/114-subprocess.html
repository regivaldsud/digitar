Aula 114 · Rodando programas externos com subprocess

Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Chamando outros programas

O Python pode rodar qualquer programa do computador, como se você digitasse no terminal. O jeito recomendado é subprocess.run, com o comando em forma de lista: primeiro o programa, depois os argumentos.

import subprocess
import sys

resultado = subprocess.run(
    [sys.executable, "-c", "print('Oi, eu sou outro programa!')"],
    capture_output=True,
    text=True,
)
print("Código de retorno:", resultado.returncode)
print("Saída:", resultado.stdout.strip())

Código de retorno: 0
Saída: Oi, eu sou outro programa!

  • sys.executable é o caminho do próprio Python, então o exemplo funciona em qualquer computador;
  • capture_output=True guarda a saída em vez de mostrar na tela; text=True entrega como texto;
  • returncode 0 quer dizer "deu certo"; outro número quer dizer erro.

Quando o programa falha

import subprocess
import sys

resultado = subprocess.run([sys.executable, "-c", "1 / 0"], capture_output=True, text=True)
print("Código de retorno:", resultado.returncode)
print("Última linha do erro:", resultado.stderr.strip().splitlines()[-1])

Código de retorno: 1
Última linha do erro: ZeroDivisionError: division by zero

Com check=True, o run gera a exceção subprocess.CalledProcessError sozinho quando o programa falha — prático dentro de um try (aula 53).

Um uso comum é chamar o Git (aula 244) de dentro de um script:

import subprocess

saida = subprocess.run(["git", "status", "--short"], capture_output=True, text=True, check=True)
print(saida.stdout or "Nada mudou.")
Atenção: Evite shell=True com textos digitados pelo usuário: alguém pode digitar ; del *.* e o comando extra roda junto. Passe o comando como lista, sem shell.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
subprocess.run(["git", "status"], check=True)

Exercícios

1. Rode, com subprocess.run, o Python mostrando a própria versão (-V) e imprima o resultado.

Ver resposta 
import subprocess
import sys

r = subprocess.run([sys.executable, "-V"], capture_output=True, text=True)
print((r.stdout or r.stderr).split()[0])

Python

O comando python -V mostra algo como Python 3.12.7; aqui imprimimos só a primeira palavra para a saída ser a mesma em qualquer versão.

Que o programa terminou com erro. Por convenção, 0 é sucesso e qualquer
outro número indica algum tipo de falha.
