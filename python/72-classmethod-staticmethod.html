Três tipos de método

Até agora todo método recebia self, o objeto. Mas às vezes o método não precisa de um objeto específico:

  • método de instância (o normal): recebe self e trabalha com um objeto;
  • método de classe (@classmethod): recebe cls, a própria classe;
  • método estático (@staticmethod): não recebe nem self nem cls; é uma função comum que mora dentro da classe.

O @ antes do nome é um decorador (você aprofunda na aula 56). Por enquanto, pense nele como uma etiqueta que muda o jeito de o método funcionar.

@classmethod: métodos fábrica

O uso mais comum do @classmethod é criar objetos de outro jeito, além do __init__. Esses métodos são chamados de fábricas.

class Aluno:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

    @classmethod
    def de_texto(cls, texto):
        nome, idade = texto.split(";")
        return cls(nome, int(idade))

a = Aluno("Ana", 13)
b = Aluno.de_texto("Bruno;12")
print(a.nome, a.idade)
print(b.nome, b.idade)

Ana 13
Bruno 12

O cls é a classe Aluno, então cls(nome, int(idade)) é o mesmo que Aluno(nome, int(idade)). Repare que chamamos o método pela classe: Aluno.de_texto(...).

Dica: Por que usar cls(...) e não Aluno(...)? Porque, se outra classe herdar de Aluno (aula 76), a fábrica vai criar objetos da classe filha automaticamente.

Mais de uma fábrica

Uma classe pode ter várias fábricas, cada uma para um formato de entrada diferente.

class Pessoa:
    ANO_ATUAL = 2026

    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

    @classmethod
    def pelo_ano(cls, nome, ano_nascimento):
        return cls(nome, cls.ANO_ATUAL - ano_nascimento)

    @classmethod
    def bebe(cls, nome):
        return cls(nome, 0)

for p in [Pessoa("Vó Cida", 71), Pessoa.pelo_ano("Kauã", 2013), Pessoa.bebe("Helena")]:
    print(f"{p.nome}: {p.idade} anos")

Vó Cida: 71 anos
Kauã: 13 anos
Helena: 0 anos

O cls também dá acesso aos atributos de classe, como cls.ANO_ATUAL.

@staticmethod: uma função que mora na classe

Um método estático não usa o objeto nem a classe. Ele fica dentro da classe só porque o assunto tem a ver com ela — como uma função de validação ou de conversão.

class Termometro:
    def __init__(self, celsius):
        self.celsius = celsius

    @staticmethod
    def para_fahrenheit(c):
        return c * 9 / 5 + 32

    def mostrar(self):
        f = Termometro.para_fahrenheit(self.celsius)
        print(f"{self.celsius} °C = {f} °F")

print(Termometro.para_fahrenheit(100))
Termometro(25).mostrar()

212.0
25 °C = 77.0 °F

class Placa:
    @staticmethod
    def valida(texto):
        # padrão Mercosul: 3 letras, 1 número, 1 letra, 2 números (ex.: BRA2E19)
        if len(texto) != 7:
            return False
        return (texto[:3].isalpha() and texto[3].isdigit()
                and texto[4].isalpha() and texto[5:].isdigit())

for p in ["BRA2E19", "ABC1234", "XY12"]:
    print(p, Placa.valida(p))

BRA2E19 True
ABC1234 False
XY12 False

Atenção: Num @staticmethod não existe self. Se você tentar usar self.algo lá dentro, aparece NameError: name 'self' is not defined. Se o método precisa do objeto, ele não é estático.

Qual usar?

  • Precisa dos dados de um objeto (self.nome, self.saldo)? Método de instância.
  • Quer criar objetos de outro jeito ou mexer em atributos de classe? @classmethod.
  • É uma função auxiliar que não usa nem objeto nem classe? @staticmethod (ou até uma função comum fora da classe).

Exercícios

1. Crie a classe Produto(nome, preco) com a fábrica de_csv(linha) que recebe "Pão de queijo,4.50" e cria o produto com o preço como float.

Ver resposta 
class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

    @classmethod
    def de_csv(cls, linha):
        nome, preco = linha.split(",")
        return cls(nome, float(preco))

p = Produto.de_csv("Pão de queijo,4.50")
print(p.nome, p.preco)

Pão de queijo 4.5

2. Crie a classe Data(dia, mes, ano) com a fábrica de_texto("25/12/2026") e um método mostrar que imprime 25 do mês 12 de 2026.

Ver resposta 
class Data:
    def __init__(self, dia, mes, ano):
        self.dia = dia
        self.mes = mes
        self.ano = ano

    @classmethod
    def de_texto(cls, texto):
        dia, mes, ano = texto.split("/")
        return cls(int(dia), int(mes), int(ano))

    def mostrar(self):
        print(f"{self.dia} do mês {self.mes} de {self.ano}")

Data.de_texto("25/12/2026").mostrar()

25 do mês 12 de 2026

3. Crie a classe Calculadora com os métodos estáticos somar(a, b) e media(lista). Use sem criar nenhum objeto.

Ver resposta 
class Calculadora:
    @staticmethod
    def somar(a, b):
        return a + b

    @staticmethod
    def media(lista):
        return sum(lista) / len(lista)

print(Calculadora.somar(7, 5))
print(Calculadora.media([6, 8, 10]))

12
8.0

4. Crie a classe Usuario com um contador de classe criados e a fábrica visitante(), que cria um usuário chamado visitante1, visitante2... usando o contador.

Ver resposta 
class Usuario:
    criados = 0

    def __init__(self, nome):
        self.nome = nome
        Usuario.criados += 1

    @classmethod
    def visitante(cls):
        return cls(f"visitante{cls.criados + 1}")

print(Usuario.visitante().nome)
print(Usuario("Rafa").nome)
print(Usuario.visitante().nome)

visitante1
Rafa
visitante3

5. Para cada caso, diga se usaria método de instância, @classmethod ou @staticmethod: (a) calcular o saldo de uma conta; (b) criar uma conta a partir de um dicionário; (c) conferir se um CPF tem 11 dígitos.

Ver resposta

(a) método de instância: precisa do saldo daquela conta (self).
(b) @classmethod: é uma fábrica, cria um objeto com cls(...).
(c) @staticmethod: só confere um texto, não precisa de objeto nem de classe.
