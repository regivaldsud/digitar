Aula 104 · Copiar, mover e apagar com shutil

Nesta aula você vai aprender

  • Entender a diferença entre o que o pathlib faz e o que o shutil faz
  • Copiar arquivos com shutil.copy e shutil.copy2, e pastas inteiras com shutil.copytree
  • Mover e renomear com shutil.move
  • Apagar pastas inteiras com shutil.rmtree sem susto
  • Compactar uma pasta em .zip com shutil.make_archive e ver o espaço livre do disco
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Por que shutil

O pathlib (aula 103) cria pastas, lê, escreve e lista arquivos. Mas ele não sabe copiar um arquivo nem copiar uma pasta com tudo dentro. Para isso o Python tem o shutil ("shell utilities", utilidades do terminal): são as mesmas tarefas que você faz arrastando pastas no explorador de arquivos, só que automáticas.

Ele é ótimo para tarefas chatas e repetidas: fazer backup da pasta de trabalhos da escola, separar fotos por ano, limpar arquivos temporários.

Esta aula é para o computador porque, no fim, você vai mexer em arquivos de verdade. Mas os exemplos com o botão Executar funcionam aqui no site: eles criam uma pasta temporária com tempfile.TemporaryDirectory(), que some sozinha quando o bloco with termina. É o jeito mais seguro de treinar.

import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    treino = Path(pasta)
    (treino / "lista.txt").write_text("arroz\nfeijão\n", encoding="utf-8")
    print("Dentro da pasta:", [p.name for p in treino.iterdir()])
    print("Existe?", treino.exists())

print("Depois do with, existe?", treino.exists())

Dentro da pasta: ['lista.txt']
Existe? True
Depois do with, existe? False

Dica: Use pastas temporárias (ou uma pasta chamada treino) sempre que estiver testando um programa que copia, move ou apaga. Só aponte para as suas pastas de verdade quando tiver certeza de que o programa faz o que você quer.

Copiar um arquivo: copy e copy2

shutil.copy(origem, destino) copia o conteúdo de um arquivo. O original continua onde estava. O destino pode ser um nome de arquivo novo ou uma pasta (aí a cópia fica com o mesmo nome dentro dela).

shutil.copy2 faz a mesma coisa e ainda copia as informações do arquivo, como a data da última modificação. Use copy2 em backups, para a cópia "lembrar" quando o original foi alterado.

import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    base = Path(pasta)
    redacao = base / "redacao.txt"
    redacao.write_text("Minhas férias em Salvador", encoding="utf-8")

    # cópia com outro nome, na mesma pasta
    shutil.copy(redacao, base / "redacao_copia.txt")

    # cópia para dentro de outra pasta (mantém o nome)
    entregas = base / "entregas"
    entregas.mkdir()
    destino = shutil.copy2(redacao, entregas)

    print("Cópia criada:", Path(destino).relative_to(base))
    print("Conteúdo:", (entregas / "redacao.txt").read_text(encoding="utf-8"))
    print("Na pasta base:", sorted(p.name for p in base.iterdir()))

Cópia criada: entregas\redacao.txt
Conteúdo: Minhas férias em Salvador
Na pasta base: ['entregas', 'redacao.txt', 'redacao_copia.txt']

As funções de cópia devolvem o caminho do arquivo criado. Isso ajuda a mostrar na tela o que o programa fez.

Atenção: Se o destino já existe, copy escreve por cima sem perguntar. E se a pasta de destino não existe, dá FileNotFoundError: crie a pasta antes com mkdir(parents=True, exist_ok=True).

Copiar uma pasta inteira: copytree

shutil.copytree(origem, destino) copia a pasta com todas as subpastas e arquivos. Por padrão, a pasta de destino não pode existir; com dirs_exist_ok=True, ele copia por cima de uma pasta que já existe (bom para backups repetidos).

Também dá para pular arquivos que você não quer no backup com ignore=shutil.ignore_patterns(...):

import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    base = Path(pasta)
    escola = base / "escola"
    (escola / "matematica").mkdir(parents=True)
    (escola / "historia").mkdir()
    (escola / "matematica" / "lista1.txt").write_text("2 + 2", encoding="utf-8")
    (escola / "historia" / "resumo.txt").write_text("Brasil Colônia", encoding="utf-8")
    (escola / "historia" / "rascunho.tmp").write_text("lixo", encoding="utf-8")

    shutil.copytree(escola, base / "backup", ignore=shutil.ignore_patterns("*.tmp"))

    for arquivo in sorted((base / "backup").rglob("*")):
        print(arquivo.relative_to(base))

backup\historia
backup\historia\resumo.txt
backup\matematica
backup\matematica\lista1.txt

O arquivo rascunho.tmp ficou de fora do backup, como pedimos.

Atenção: Rodar copytree duas vezes para o mesmo destino dá FileExistsError na segunda vez. Se a ideia é atualizar o backup, use dirs_exist_ok=True.

Mover e renomear: move

shutil.move(origem, destino) tira o arquivo (ou a pasta) de um lugar e coloca em outro. Se o destino estiver na mesma pasta, mas com outro nome, mover é o mesmo que renomear.

Um uso clássico: organizar a pasta de downloads separando os arquivos pela extensão.

import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    downloads = Path(pasta)
    for nome in ["foto1.jpg", "trabalho.pdf", "foto2.jpg", "musica.mp3", "prova.pdf"]:
        (downloads / nome).write_text("x", encoding="utf-8")

    for arquivo in list(downloads.iterdir()):
        if arquivo.is_file():
            tipo = arquivo.suffix[1:]            # ".jpg" vira "jpg"
            destino = downloads / tipo
            destino.mkdir(exist_ok=True)
            shutil.move(arquivo, destino / arquivo.name)

    for item in sorted(downloads.rglob("*")):
        if item.is_file():
            print(item.relative_to(downloads))

jpg\foto1.jpg
jpg\foto2.jpg
mp3\musica.mp3
pdf\prova.pdf
pdf\trabalho.pdf

Dica: Repare no list(downloads.iterdir()): primeiro fazemos a lista completa dos arquivos e só depois mexemos neles. Mover arquivos enquanto ainda estamos percorrendo a mesma pasta pode confundir o laço.

Apagar pastas: rmtree

Para apagar, você já conhece duas ferramentas do pathlib: Path.unlink() apaga um arquivo e Path.rmdir() apaga uma pasta vazia. Para apagar uma pasta com tudo dentro, use shutil.rmtree:

import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    base = Path(pasta)
    cache = base / "temporario" / "cache"
    cache.mkdir(parents=True)
    (cache / "a.tmp").write_text("x", encoding="utf-8")

    try:
        (base / "temporario").rmdir()
    except OSError:
        print("rmdir não apaga pasta com coisas dentro")

    alvo = base / "temporario"
    print("Vou apagar:", alvo.relative_to(base))
    shutil.rmtree(alvo)
    print("Ainda existe?", alvo.exists())

rmdir não apaga pasta com coisas dentro
Vou apagar: temporario
Ainda existe? False

Atenção: rmtree apaga para sempre: os arquivos não vão para a Lixeira. Antes de rodar, mostre na tela o caminho que será apagado e confira. Um erro de digitação no caminho pode apagar a pasta errada. Nunca rode rmtree num caminho montado com o que o usuário digitou sem conferir antes.

Compactar em .zip e ver o espaço do disco

shutil.make_archive(nome, "zip", pasta) cria um arquivo nome.zip com tudo o que está na pasta. Para abrir de volta, use shutil.unpack_archive. E shutil.disk_usage diz quanto espaço o disco tem — útil antes de copiar muita coisa.

import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    base = Path(pasta)
    fotos = base / "fotos"
    fotos.mkdir()
    for i in range(1, 4):
        (fotos / f"praia{i}.txt").write_text("imagem " * 100, encoding="utf-8")

    zip_criado = shutil.make_archive(base / "fotos_backup", "zip", fotos)
    print("Criado:", Path(zip_criado).name)

    shutil.unpack_archive(zip_criado, base / "restaurado")
    print("Restaurado:", sorted(p.name for p in (base / "restaurado").iterdir()))

Criado: fotos_backup.zip
Restaurado: ['praia1.txt', 'praia2.txt', 'praia3.txt']

Atenção ao primeiro argumento de make_archive: é o nome sem a extensão. O Python acrescenta .zip sozinho.

import shutil

uso = shutil.disk_usage(".")
gb = 1024 ** 3
print(f"Total: {uso.total / gb:.1f} GB")
print(f"Livre: {uso.free / gb:.1f} GB")

(exemplo — a sua saída pode ser diferente)
Total: 476.3 GB
Livre: 182.9 GB

No seu computador: um backup de verdade

Agora junte tudo num programa que roda no seu computador. Crie uma pasta vazia de treino, salve o código como backup.py dentro dela e rode com py backup.py (no Linux ou macOS, python3 backup.py):

import shutil
from datetime import date
from pathlib import Path

origem = Path("trabalhos")
# cria alguns arquivos só para o exemplo funcionar na primeira vez
(origem / "ciencias").mkdir(parents=True, exist_ok=True)
(origem / "ciencias" / "relatorio.txt").write_text("Fotossíntese", encoding="utf-8")
(origem / "poema.txt").write_text("Batatinha quando nasce", encoding="utf-8")

destino = Path("backups") / f"trabalhos_{date(2026, 11, 21):%Y-%m-%d}"
print("Copiando", origem, "para", destino)
shutil.copytree(origem, destino, dirs_exist_ok=True)

arquivos = [p for p in destino.rglob("*") if p.is_file()]
print("Arquivos no backup:", len(arquivos))

Copiando trabalhos para backups\trabalhos_2026-11-21
Arquivos no backup: 2

py backup.py

Cada dia gera uma pasta nova em backups, com a data no nome. No programa de verdade, troque date(2026, 11, 21) por date.today().

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
shutil.copytree("fotos", "backup_fotos", dirs_exist_ok=True)

Exercícios

1. Escreva um programa que copie todos os arquivos .txt de uma pasta textos para uma pasta copias, deixando de fora os outros tipos. Use uma pasta temporária.

Ver resposta 
import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    base = Path(pasta)
    textos = base / "textos"
    textos.mkdir()
    for nome in ["a.txt", "b.txt", "foto.jpg"]:
        (textos / nome).write_text("x", encoding="utf-8")

    copias = base / "copias"
    copias.mkdir()
    for arquivo in textos.glob("*.txt"):
        shutil.copy(arquivo, copias / arquivo.name)

    print(sorted(p.name for p in copias.iterdir()))

['a.txt', 'b.txt']

2. Qual é a diferença entre Path("pasta").rmdir() e shutil.rmtree("pasta")?

Ver resposta

rmdir() só apaga a pasta se ela estiver vazia (senão dá OSError).
shutil.rmtree() apaga a pasta e tudo o que está dentro dela, sem passar pela Lixeira.

3. Renomeie todos os arquivos .jpeg de uma pasta para a extensão .jpg usando shutil.move. Mostre os nomes no fim.

Ver resposta 
import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    fotos = Path(pasta)
    for nome in ["gato.jpeg", "cachorro.jpeg", "nota.txt"]:
        (fotos / nome).write_text("x", encoding="utf-8")

    for arquivo in list(fotos.glob("*.jpeg")):
        shutil.move(arquivo, arquivo.with_suffix(".jpg"))

    print(sorted(p.name for p in fotos.iterdir()))

['cachorro.jpg', 'gato.jpg', 'nota.txt']

with_suffix(".jpg") monta o mesmo caminho trocando só a extensão. Mover para outro nome na mesma pasta é renomear.

4. Faça um backup da pasta projeto para projeto_backup, ignorando os arquivos .pyc e a pasta __pycache__. Mostre o que foi copiado.

Ver resposta 
import shutil
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    base = Path(pasta)
    projeto = base / "projeto"
    (projeto / "__pycache__").mkdir(parents=True)
    (projeto / "main.py").write_text("print('oi')", encoding="utf-8")
    (projeto / "util.pyc").write_text("x", encoding="utf-8")
    (projeto / "__pycache__" / "main.cpython-312.pyc").write_text("x", encoding="utf-8")

    shutil.copytree(projeto, base / "projeto_backup",
                    ignore=shutil.ignore_patterns("*.pyc", "__pycache__"))

    for item in sorted((base / "projeto_backup").rglob("*")):
        print(item.relative_to(base))

projeto_backup\main.py

5. Compacte uma pasta notas num arquivo notas.zip e depois confira, com o módulo zipfile, quais arquivos estão dentro do zip.

Ver resposta 
import shutil
import tempfile
import zipfile
from pathlib import Path

with tempfile.TemporaryDirectory() as pasta:
    base = Path(pasta)
    notas = base / "notas"
    notas.mkdir()
    (notas / "bimestre1.txt").write_text("8.5", encoding="utf-8")
    (notas / "bimestre2.txt").write_text("9.0", encoding="utf-8")

    caminho_zip = shutil.make_archive(base / "notas", "zip", notas)

    with zipfile.ZipFile(caminho_zip) as z:
        print(sorted(z.namelist()))

['bimestre1.txt', 'bimestre2.txt']
