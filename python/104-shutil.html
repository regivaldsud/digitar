Aula 104 · Copiar, mover e apagar com shutil

Nesta aula você vai aprender

  • Copiar arquivos com shutil.copy e pastas com shutil.copytree
  • Mover e renomear com shutil.move
  • Apagar pastas inteiras com shutil.rmtree sem susto
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Por que shutil

O pathlib (aula 103) cria, lê e lista arquivos. Para copiar e mover em grande quantidade, o Python tem o shutil ("shell utilities", utilidades do terminal). Ele é ótimo para automatizar tarefas chatas, como fazer backup da pasta de trabalhos da escola.

Esta aula é para o computador porque você vai mexer em arquivos de verdade. Teste sempre numa pasta de treino, nunca nos seus documentos importantes.

Copiar e mover

Salve como organizar.py numa pasta vazia de treino e rode com python organizar.py:

import shutil
from pathlib import Path

# prepara uma pasta de treino
treino = Path("treino")
treino.mkdir(exist_ok=True)
(treino / "redacao.txt").write_text("Minhas férias em Salvador", encoding="utf-8")

# copia um arquivo (o original continua lá)
shutil.copy(treino / "redacao.txt", treino / "redacao_copia.txt")

# copia a pasta inteira, com tudo dentro
shutil.copytree(treino, "backup", dirs_exist_ok=True)

# move (ou renomeia) um arquivo
shutil.move(str(treino / "redacao_copia.txt"), str(treino / "redacao_v2.txt"))

print("treino:", sorted(p.name for p in treino.iterdir()))
print("backup:", sorted(p.name for p in Path("backup").iterdir()))

treino: ['redacao.txt', 'redacao_v2.txt']
backup: ['redacao.txt', 'redacao_copia.txt']

  • copy(origem, destino) copia um arquivo;
  • copytree(origem, destino) copia uma pasta inteira; dirs_exist_ok=True deixa copiar por cima de uma pasta que já existe;
  • move(origem, destino) move; se o destino estiver na mesma pasta com outro nome, é o mesmo que renomear.

Apagar pastas

Path.unlink() apaga um arquivo e Path.rmdir() só apaga pastas vazias. Para apagar uma pasta com tudo dentro, use shutil.rmtree:

import shutil
from pathlib import Path

lixo = Path("temporario/cache")
lixo.mkdir(parents=True, exist_ok=True)
(lixo / "a.tmp").write_text("x", encoding="utf-8")

shutil.rmtree("temporario")
print("Ainda existe?", Path("temporario").exists())

Ainda existe? False

Atenção: rmtree apaga para sempre: os arquivos não vão para a Lixeira. Antes de rodar, mostre na tela o caminho que será apagado e confira. Um erro de digitação no caminho pode apagar a pasta errada.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
shutil.copytree("fotos", "backup_fotos", dirs_exist_ok=True)

Exercícios

1. Escreva um programa que copie todos os arquivos .txt da pasta textos para a pasta copias.

Ver resposta 
import shutil
from pathlib import Path

textos = Path("textos")
textos.mkdir(exist_ok=True)
for nome in ["a.txt", "b.txt", "foto.jpg"]:
    (textos / nome).write_text("x", encoding="utf-8")

copias = Path("copias")
copias.mkdir(exist_ok=True)
for arquivo in textos.glob("*.txt"):
    shutil.copy(arquivo, copias / arquivo.name)

print(sorted(p.name for p in copias.iterdir()))

['a.txt', 'b.txt']

2. Qual é a diferença entre Path("pasta").rmdir() e shutil.rmtree("pasta")?

Ver resposta

rmdir() só apaga a pasta se ela estiver vazia (senão dá OSError).
shutil.rmtree() apaga a pasta e tudo o que está dentro dela, sem passar pela Lixeira.
