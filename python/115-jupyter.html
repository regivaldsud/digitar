Código em pedacinhos

Um notebook (arquivo .ipynb) é um documento dividido em células. Uma célula pode ter código, que você roda e vê o resultado logo embaixo, ou texto formatado em Markdown (títulos, listas, negrito). Fica parecido com um caderno de laboratório: você explica o que vai fazer, faz, vê o resultado e anota a conclusão.

Cientistas de dados e professores usam notebooks o tempo todo para explorar dados passo a passo — do mesmo jeito que você roda os exemplos deste site um por vez.

Os exemplos com botão Executar desta aula são o tipo de código que se escreve numa célula; os outros mostram o que só existe dentro do Jupyter.

Instalando e abrindo no VS Code

Dentro do seu ambiente virtual (aula 60), instale o pacote que roda as células:

python -m pip install ipykernel
  • no VS Code, instale a extensão Jupyter (da Microsoft);
  • aperte Ctrl+Shift+P, digite Create: New Jupyter Notebook e salve o arquivo como estudo.ipynb;
  • no canto superior direito, clique em Select Kernel e escolha o Python do seu .venv;
  • escreva o código numa célula e aperte Shift+Enter para rodar e ir para a próxima (Ctrl+Enter roda e fica na mesma).
Dica: Prefere usar no navegador? Instale com python -m pip install notebook e abra com jupyter notebook no terminal. O Google Colab também roda notebooks direto na internet, sem instalar nada.

Células de Markdown

Uma célula de Markdown não roda código: ela vira texto formatado. Você escreve com símbolos simples:

# Análise das notas da turma
Aqui eu calculo a **média** e a maior nota.
- notas do 1º bimestre
- notas do 2º bimestre

O # vira título, **...** vira negrito e o - vira item de lista. No VS Code, troque o tipo da célula clicando em Markdown ou apertando M (com a célula selecionada, fora do modo de edição).

A última linha aparece sozinha

Na última linha de uma célula, você não precisa de print: o notebook mostra o valor da expressão. Imagine estas duas células:

# célula 1
notas = [7.5, 8.0, 9.5, 6.0]
# célula 2
media = sum(notas) / len(notas)
media

7.75

Aqui no site (e num arquivo .py) não existe essa mágica, então usamos print. Este bloco junta as duas células num só:

notas = [7.5, 8.0, 9.5, 6.0]
media = sum(notas) / len(notas)
print(media)
print("Maior nota:", max(notas))

7.75
Maior nota: 9.5

Atenção: Só a última linha aparece. Se uma célula tem media e depois max(notas), o notebook mostra apenas o maior valor. Para ver vários resultados numa célula, use print em cada um.

O kernel e a ordem de execução

Quem roda as células é o kernel: um Python que fica ligado enquanto o notebook está aberto. Ele guarda todas as variáveis criadas, e por isso uma célula enxerga o que a outra criou.

A ordem em que você roda as células vale mais que a ordem em que elas aparecem na tela. O número entre colchetes ao lado de cada célula, como [3], mostra em que ordem ela rodou. Veja o que acontece quando a mesma "célula" roda duas vezes:

# célula 1
pontos = 0

# célula 2: rodada três vezes seguidas
pontos = pontos + 10
pontos = pontos + 10
pontos = pontos + 10
print(pontos)

30

Num notebook, cada Shift+Enter na célula 2 soma mais 10 — o resultado depende de quantas vezes você rodou, e não do que está escrito. Isso confunde muita gente.

Atenção: Se rodar uma célula que usa uma variável antes da célula que a cria, aparece NameError. Quando tudo ficar confuso, use Restart (reinicia o kernel e apaga as variáveis) e depois Run All (roda tudo de cima para baixo). Se funcionar assim, o notebook está correto.

Comandos mágicos

Linhas que começam com % são comandos mágicos: só funcionam no Jupyter, não num arquivo .py.

%timeit sum(range(1000))
%pip install matplotlib
%who

4.85 µs ± 61.2 ns per loop (mean ± std. dev. of 7 runs, 100,000 loops each)
Successfully installed matplotlib-3.9.2
media notas pontos

  • %timeit mede quanto tempo um código demora, repetindo muitas vezes;
  • %pip install instala um pacote no mesmo Python do kernel (evita instalar no Python errado);
  • %who lista as variáveis que o kernel está guardando.

Fora do Jupyter, dá para medir tempo com o módulo timeit da biblioteca padrão:

import timeit

tempo = timeit.timeit("sum(range(1000))", number=1000)
print(f"1000 repetições levaram {tempo:.4f} segundos")

(exemplo — a sua saída pode ser diferente)
1000 repetições levaram 0.0150 segundos

Notebook ou arquivo .py?

  • Notebook: explorar dados, testar ideias, fazer gráficos, explicar um raciocínio com texto e resultados juntos;
  • arquivo .py: programas que outras pessoas vão rodar, que você vai importar (aula 54), testar (módulo 6) ou guardar no Git (o .ipynb é um JSON grande e difícil de comparar).

Um bom costume é explorar no notebook e, quando o código ficar bom, passar as funções para um arquivo .py.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
media = sum(notas) / len(notas)

Exercícios

1. Num notebook, você criou preco = 10 na célula 1 e preco * 3 na célula 2. Depois mudou a célula 1 para preco = 20, mas rodou só a célula 2. O que aparece?

Ver resposta

30. A célula 1 nova não foi rodada, então preco continua valendo 10 no kernel.
Rode a célula 1 de novo (ou Run All) para ver 60.

2. Qual atalho roda a célula atual e passa para a próxima? E qual roda e fica na mesma célula?

Ver resposta

Shift+Enter roda e vai para a próxima; Ctrl+Enter roda e fica na mesma.

3. Uma célula tem duas linhas: len(notas) e depois sum(notas), com notas = [5, 7, 9]. O que o notebook mostra? Reescreva para mostrar os dois valores (aqui com print).

Ver resposta 
notas = [5, 7, 9]
print(len(notas))
print(sum(notas))

3
21

O notebook mostraria só 21, o valor da última linha. Com print em cada uma, aparecem os dois.

4. Escreva uma célula de Markdown com um título "Minha análise" e uma lista com dois itens.

Ver resposta

# Minha análise
- média da turma
- maior nota

5. Um colega diz que o notebook dele "funciona", mas dá NameError depois de Restart e Run All. O que provavelmente aconteceu?

Ver resposta

Ele rodou as células fora de ordem: alguma célula usa uma variável criada
numa célula que está mais abaixo (ou que ele apagou). Antes, o kernel ainda
guardava a variável; depois do Restart ela sumiu. A correção é colocar as
células na ordem certa, de cima para baixo.
