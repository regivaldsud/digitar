Código em pedacinhos

Um notebook (arquivo .ipynb) é um documento dividido em células. Uma célula pode ter código, que você roda e vê o resultado logo embaixo, ou texto formatado em Markdown. Cientistas de dados usam notebooks o tempo todo para explorar dados passo a passo — do mesmo jeito que você roda os exemplos deste site um por vez.

Instalando e abrindo no VS Code

Dentro do seu ambiente virtual (aula 60), instale o pacote que roda as células:

pip install ipykernel
  • No VS Code, instale a extensão Jupyter (da Microsoft);
  • aperte Ctrl+Shift+P, digite Create: New Jupyter Notebook e escolha o Python do seu .venv no canto superior direito ("Select Kernel");
  • escreva o código numa célula e aperte Shift+Enter para rodar e ir para a próxima.

Como as células funcionam

As variáveis criadas numa célula continuam existindo nas outras. Imagine estas duas células:

# célula 1
notas = [7.5, 8.0, 9.5, 6.0]
# célula 2
media = sum(notas) / len(notas)
media

7.75

Na última linha de uma célula, não precisa de print: o notebook mostra o valor sozinho.

Atenção: A ordem em que você roda as células vale mais que a ordem em que elas aparecem. Se rodar a célula 2 antes da 1, dá NameError. Quando tudo ficar confuso, use Restart e depois Run All.
Dica: Notebooks são ótimos para experimentar e explicar. Para programas que outras pessoas vão rodar, como os projetos deste curso, prefira arquivos .py.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
media = sum(notas) / len(notas)
