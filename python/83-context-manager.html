Preparar, usar, arrumar

Na aula 61 você usou with open(...) para abrir arquivos. A grande vantagem do with é que o arquivo é fechado sempre no final do bloco — mesmo se acontecer um erro no meio.

Esse "prepara, usa e arruma" aparece em muitas situações: abrir e fechar arquivos, ligar e desligar algo, mudar uma configuração e voltar ao normal. O objeto que cuida disso se chama gerenciador de contexto.

Seu gerenciador com uma classe

Uma classe vira gerenciador de contexto quando tem dois métodos especiais:

  • __enter__: roda no começo do with. O que ele devolver vai para a variável depois do as.
  • __exit__: roda no final do bloco, aconteça o que acontecer.
class Aula:
    def __init__(self, materia):
        self.materia = materia

    def __enter__(self):
        print(f"Abrindo o caderno de {self.materia}")
        return self

    def __exit__(self, tipo, valor, rastro):
        print(f"Fechando o caderno de {self.materia}")

with Aula("Matemática") as aula:
    print("Estudando", aula.materia)
print("Fim do bloco with")

Abrindo o caderno de Matemática
Estudando Matemática
Fechando o caderno de Matemática
Fim do bloco with

O __exit__ recebe três informações sobre um possível erro: o tipo da exceção, a exceção em si e o traceback. Quando não houve erro, as três chegam como None.

Mesmo com erro, o __exit__ roda

Veja que a mensagem de fechar aparece mesmo quando o bloco quebra no meio:

class Luz:
    def __enter__(self):
        print("Luz acesa")
        return self

    def __exit__(self, tipo, valor, rastro):
        print("Luz apagada")
        if tipo is not None:
            print("Aconteceu um erro:", tipo.__name__)

try:
    with Luz():
        print("Lendo um livro...")
        resultado = 10 / 0
        print("Esta linha não roda")
except ZeroDivisionError:
    print("O erro chegou até o try de fora")

Luz acesa
Lendo um livro...
Luz apagada
Aconteceu um erro: ZeroDivisionError
O erro chegou até o try de fora

Se o __exit__ devolver True, o Python considera o erro resolvido e não o repassa adiante. Use com cuidado:

class IgnorarDivisaoPorZero:
    def __enter__(self):
        return self

    def __exit__(self, tipo, valor, rastro):
        if tipo is ZeroDivisionError:
            print("Divisão por zero ignorada")
            return True
        return False

with IgnorarDivisaoPorZero():
    print(8 / 0)
print("O programa continuou")

Divisão por zero ignorada
O programa continuou

Atenção: Engolir erros esconde problemas. Devolva True no __exit__ só para um tipo de erro específico que você sabe tratar, nunca para todos.

O jeito curto: @contextmanager

O módulo contextlib tem o decorator @contextmanager, que transforma uma função geradora (aula 52) em gerenciador de contexto. Tudo antes do yield é o "preparar"; tudo depois é o "arrumar":

from contextlib import contextmanager

@contextmanager
def etiqueta(nome):
    print(f"<{nome}>")
    try:
        yield
    finally:
        print(f"</{nome}>")

with etiqueta("p"):
    print("Olá do Brasil!")

<p>
Olá do Brasil!
</p>

O try/finally garante que a parte de arrumar rode mesmo se houver erro dentro do with. Um uso prático: mudar uma configuração só durante um trecho e depois voltar ao valor antigo.

from contextlib import contextmanager

config = {"volume": 50}

@contextmanager
def volume_temporario(valor):
    antigo = config["volume"]
    config["volume"] = valor
    try:
        yield config
    finally:
        config["volume"] = antigo

with volume_temporario(10) as c:
    print("Durante o filme:", c["volume"])
print("Depois do filme:", config["volume"])

Durante o filme: 10
Depois do filme: 50

Dica: Esqueceu o try/finally em volta do yield? Então, se der erro dentro do with, a parte de arrumar não roda. Coloque sempre.

Pronto para usar: suppress

Para o caso simples de "ignore este erro", o contextlib já tem o suppress:

from contextlib import suppress

estoque = {"arroz": 10, "feijão": 4}
with suppress(KeyError):
    del estoque["macarrão"]
print(estoque)

{'arroz': 10, 'feijão': 4}

3. Crie um gerenciador Contador que guarda numa lista tudo o que for anotado com o método anotar(texto) e, no final do with, mostra quantas anotações foram feitas.

Ver resposta 
class Contador:
    def __enter__(self):
        self.anotacoes = []
        return self

    def anotar(self, texto):
        self.anotacoes.append(texto)

    def __exit__(self, tipo, valor, rastro):
        print(f"{len(self.anotacoes)} anotações feitas")

with Contador() as c:
    c.anotar("comprar pão")
    c.anotar("estudar Python")
    c.anotar("treinar digitação")

3 anotações feitas

from contextlib import suppress

total = 0
