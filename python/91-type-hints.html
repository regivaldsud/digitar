Para que servem

Type hints (dicas de tipo) são anotações que dizem qual tipo de valor uma variável ou função espera. Elas não mudam o que o programa faz: servem para quem lê o código e para o editor, que passa a sugerir métodos e avisar erros enquanto você digita.

def calcular_imc(peso: float, altura: float) -> float:
    return peso / altura ** 2


imc = calcular_imc(60.0, 1.65)
print(f"IMC: {imc:.1f}")

IMC: 22.0

Depois de cada parâmetro vem : tipo. Depois dos parênteses, -> tipo diz o que a função devolve. Uma função que não devolve nada é anotada com -> None.

Listas, dicionários e tuplas

Para coleções, o tipo dos itens vai entre colchetes: list[int] é uma lista de inteiros; dict[str, float] é um dicionário com chaves str e valores float; tuple[int, int] é uma tupla com dois inteiros.

def media(notas: list[float]) -> float:
    return sum(notas) / len(notas)


precos: dict[str, float] = {"pão": 0.75, "leite": 5.49}
ponto: tuple[int, int] = (3, 4)

print(media([7.5, 8.0, 9.5]))
print(precos["leite"])
print(ponto)

8.333333333333334
5.49
(3, 4)

Valores opcionais e "isto ou aquilo"

A barra | significa "ou". str | None quer dizer "um texto ou nada"; int | float aceita inteiro ou decimal. Essa forma funciona a partir do Python 3.10 — em códigos antigos você vai ver Optional[str] e Union[int, float], do módulo typing, que significam a mesma coisa.

def buscar_telefone(agenda: dict[str, str], nome: str) -> str | None:
    return agenda.get(nome)


def dobrar(valor: int | float) -> int | float:
    return valor * 2


agenda = {"Vó Lúcia": "(81) 99999-0000"}
print(buscar_telefone(agenda, "Vó Lúcia"))
print(buscar_telefone(agenda, "Tio Zé"))
print(dobrar(4), dobrar(2.5))

(81) 99999-0000
None
8 5.0

Classes, funções e apelidos de tipo

Suas classes também são tipos: um parâmetro pode ser Aluno ou list[Aluno]. Para uma função recebida como parâmetro, use Callable[[tipos dos parâmetros], tipo do retorno], de collections.abc. E, quando um tipo fica comprido, dê um apelido a ele:

from collections.abc import Callable

Boletim = dict[str, list[float]]


class Aluno:
    def __init__(self, nome: str, notas: list[float]) -> None:
        self.nome = nome
        self.notas = notas

    def media(self) -> float:
        return sum(self.notas) / len(self.notas)


def melhor_aluno(alunos: list[Aluno]) -> Aluno:
    return max(alunos, key=lambda a: a.media())


def aplicar(funcao: Callable[[float], float], valores: list[float]) -> list[float]:
    return [funcao(v) for v in valores]


turma = [Aluno("Rafa", [7.0, 8.0]), Aluno("Lia", [9.5, 9.0])]
print(melhor_aluno(turma).nome)
print(aplicar(lambda n: n + 1, [6.0, 8.5]))
boletim: Boletim = {a.nome: a.notas for a in turma}
print(boletim)

Lia
[7.0, 9.5]
{'Rafa': [7.0, 8.0], 'Lia': [9.5, 9.0]}

Dica: No Python 3.12 existe também a palavra type para criar apelidos: type Boletim = dict[str, list[float]]. A forma com = mostrada acima funciona em qualquer versão moderna.

O Python não confere os tipos

As anotações são só dicas. O Python não impede que você passe o tipo errado:

def somar(a: int, b: int) -> int:
    return a + b


print(somar(2, 3))
print(somar("2", "3"))

5
23

somar("2", "3") juntou os textos e deu 23, sem erro nenhum. Para pegar esse tipo de engano existe o mypy, um verificador que lê o código sem rodar. Instale no seu computador e use no terminal:

pip install mypy
mypy meu_programa.py

meu_programa.py:5: error: Argument 1 to "somar" has incompatible type "str"; expected "int"  [arg-type]
Found 1 error in 1 file (checked 1 source file)

Atenção: Type hints não convertem valores. Anotar idade: int = input() não transforma o texto em número — você ainda precisa do int().

Exercícios

1. Adicione type hints à função def area(base, altura): return base * altura / 2, que calcula a área de um triângulo.

Ver resposta 
def area(base: float, altura: float) -> float:
    return base * altura / 2


print(area(6.0, 4.0))

12.0

2. Escreva contar_letras(palavra: str) -> dict[str, int], que devolve quantas vezes cada letra aparece.

Ver resposta 
def contar_letras(palavra: str) -> dict[str, int]:
    contagem: dict[str, int] = {}
    for letra in palavra:
        contagem[letra] = contagem.get(letra, 0) + 1
    return contagem


print(contar_letras("arara"))

{'a': 3, 'r': 2}

3. Escreva primeiro_negativo(numeros: list[int]) -> int | None que devolve o primeiro número negativo da lista, ou None se não houver.

Ver resposta 
def primeiro_negativo(numeros: list[int]) -> int | None:
    for n in numeros:
        if n < 0:
            return n
    return None


print(primeiro_negativo([3, 8, -2, -7]))
print(primeiro_negativo([1, 2, 3]))

-2
None

4. Anote a função def repetir(funcao, vezes): ..., que chama funcao() várias vezes e devolve a lista de resultados. funcao não recebe parâmetros e devolve str.

Ver resposta 
from collections.abc import Callable


def repetir(funcao: Callable[[], str], vezes: int) -> list[str]:
    return [funcao() for _ in range(vezes)]


print(repetir(lambda: "olé", 3))

['olé', 'olé', 'olé']

5. O código def dobro(n: int) -> int: return n * 2 seguido de print(dobro("oi")) roda sem erro? Por quê?

Ver resposta 
def dobro(n: int) -> int:
    return n * 2


print(dobro("oi"))

oioi

Roda, sim. Os type hints não são verificados durante a execução, e "oi" * 2 repete o texto. Um verificador como o mypy apontaria o erro antes de rodar.
