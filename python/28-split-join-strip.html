Aula 28 · Métodos úteis de texto: split, join, strip

Nesta aula você vai aprender

  • Limpar espaços com strip, lstrip e rstrip
  • Quebrar textos em listas com split
  • Juntar listas de textos com join
  • Combinar esses métodos com replace, lower, find e isdigit

Métodos devolvem textos novos

Um método é uma função que pertence a um valor e é chamada com ponto: texto.strip(). Como textos são imutáveis (aula 26), os métodos de texto não mudam o original: eles devolvem um texto novo. Para guardar o resultado, use uma variável.

nome = "  Ana Clara  "
limpo = nome.strip()
print("[" + nome + "]")
print("[" + limpo + "]")

[  Ana Clara  ]
[Ana Clara]

strip: limpando as pontas

strip() tira espaços (e quebras de linha) do começo e do fim. lstrip() limpa só a esquerda e rstrip(), só a direita. Também dá para dizer quais caracteres tirar:

frase = "   eu adoro pão de queijo   "
print("[" + frase.strip() + "]")
print("[" + frase.lstrip() + "]")
print("[" + frase.rstrip() + "]")
print("...Gol!!!".strip(".!"))

[eu adoro pão de queijo]
[eu adoro pão de queijo   ]
[   eu adoro pão de queijo]
Gol

Dica: Ao comparar respostas digitadas, use .strip().lower(). Assim " SIM ", "Sim" e "sim" viram todos "sim". Repare que dá para encadear métodos, um depois do outro.
resposta = input("Quer continuar? ")
if resposta.strip().lower() == "sim":
    print("Continuando!")
else:
    print("Parando.")

(exemplo digitando SIM )
Quer continuar?   SIM
Continuando!

split: quebrando em pedaços

split() quebra um texto e devolve uma lista de pedaços (aula 25). Sem argumento, quebra em qualquer espaço — e ignora espaços repetidos. Com um argumento, quebra naquele separador:

frase = "o rato   roeu a roupa do rei"
palavras = frase.split()
print(palavras)
print(len(palavras), "palavras")
dia, mes, ano = "21/04/2025".split("/")
print(dia, mes, ano)
print("arroz;feijão;;ovo".split(";"))

['o', 'rato', 'roeu', 'a', 'roupa', 'do', 'rei']
7 palavras
21 04 2025
['arroz', 'feijão', '', 'ovo']

Repare no último exemplo: com separador explícito, dois ; seguidos geram um texto vazio '' no meio. E como split devolve uma lista, dá para desempacotar direto em variáveis (aula 27).

join: juntando pedaços

join() faz o contrário do split: junta uma lista de textos usando um separador.

ingredientes = ["farinha", "ovos", "leite"]
print(", ".join(ingredientes))
print("-".join(["21", "04", "2025"]))
print("".join(["D", "I", "G", "I", "T", "A", "R"]))
titulo = " ".join("bom dia turma".split()).title()
print(titulo)

farinha, ovos, leite
21-04-2025
DIGITAR
Bom Dia Turma

Atenção: O join se escreve "ao contrário" do que muita gente espera: o separador vem antes do ponto. Escreva "-".join(lista), e não lista.join("-"). E todos os itens precisam ser textos: ", ".join([1, 2]) dá TypeError.

Outros métodos úteis

Alguns métodos que combinam muito bem com os três de hoje:

  • lower() e upper(): tudo minúsculo ou maiúsculo; title(): cada palavra com inicial maiúscula;
  • replace(velho, novo): troca trechos; count(trecho): conta ocorrências;
  • find(trecho): posição onde o trecho começa (ou -1); startswith e endswith: testam começo e fim;
  • isdigit(): o texto tem só dígitos?
telefone = "(81) 99999-1234"
so_numeros = telefone.replace("(", "").replace(")", "").replace(" ", "").replace("-", "")
print(so_numeros, so_numeros.isdigit())
email = "joao.silva@escola.edu.br"
arroba = email.find("@")
print(email[:arroba], email.endswith(".br"))
print("banana".count("a"), "banana".upper())

81999991234 True
joao.silva True
3 BANANA

dia, mes, ano = data.strip().split("/")

Exercícios

1. Peça o nome de uma pessoa (que pode vir com espaços sobrando e letras bagunçadas, como " mARIA dA sILVA ") e mostre-o arrumado: sem espaços nas pontas e com cada palavra começando com maiúscula.

Ver resposta 
nome = input("Nome: ")
print(nome.strip().title())

(exemplo digitando mARIA dA sILVA )
Nome:   mARIA dA sILVA
Maria Da Silva

2. Transforme "arroz feijão farofa salada" em "arroz, feijão, farofa, salada" usando split e join.

Ver resposta 
pratos = "arroz feijão farofa salada"
print(", ".join(pratos.split()))

arroz, feijão, farofa, salada

3. A data "2025-12-25" está no formato ano-mês-dia. Use split e join para mostrá-la como 25/12/2025.

Ver resposta 
ano, mes, dia = "2025-12-25".split("-")
print("/".join([dia, mes, ano]))

25/12/2025

4. Conte quantas palavras tem a frase " Python é muito legal " e mostre a frase com só um espaço entre as palavras.

Ver resposta 
frase = "  Python   é   muito   legal  "
palavras = frase.split()
print(len(palavras))
print(" ".join(palavras))

4
Python é muito legal

5. A lista [" ana ", "BRUNO", " cArLa"] veio de uma planilha bagunçada. Monte com um for uma nova lista com os nomes limpos (sem espaços e com inicial maiúscula) e mostre-os separados por " | ".

Ver resposta 
nomes = ["  ana ", "BRUNO", " cArLa"]
limpos = []
for nome in nomes:
    limpos.append(nome.strip().title())
print(" | ".join(limpos))

Ana | Bruno | Carla
