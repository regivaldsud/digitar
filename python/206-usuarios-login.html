Login e logout prontos

O Django já tem tudo de usuários: senha guardada com segurança (nunca em texto puro), login e logout. Basta incluir as URLs:

# config/urls.py
from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path("admin/", admin.site.urls),
    path("contas/", include("django.contrib.auth.urls")),
    path("", include("contatos.urls")),
]
# config/settings.py (trecho)
LOGIN_URL = "login"
LOGIN_REDIRECT_URL = "lista"
LOGOUT_REDIRECT_URL = "login"

O template do login fica em templates/registration/login.html:

<form method="post">
  {% csrf_token %}
  {{ form.as_p }}
  <button type="submit">Entrar</button>
</form>
Atenção: No Django 5, o logout precisa ser um POST: um link <a href="/contas/logout/"> não funciona mais. Use um formulário com {% csrf_token %} e um botão "Sair".

Páginas só para quem entrou

from django.contrib.auth.decorators import login_required
from django.shortcuts import render
from .models import Contato


@login_required
def lista(request):
    contatos = Contato.objects.filter(dono=request.user)
    return render(request, "contatos/lista.html", {"contatos": contatos})

Para cada usuário ver só os próprios contatos, o model ganha um dono:

from django.conf import settings
from django.db import models


class Contato(models.Model):
    dono = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.CASCADE)
    nome = models.CharField(max_length=100)

No template, {% if user.is_authenticated %}Olá, {{ user.username }}!{% endif %} mostra quem está logado.

Cadastro de usuários

from django.contrib.auth import login
from django.contrib.auth.forms import UserCreationForm
from django.shortcuts import redirect, render


def cadastro(request):
    form = UserCreationForm(request.POST or None)
    if form.is_valid():
        usuario = form.save()
        login(request, usuario)
        return redirect("lista")
    return render(request, "registration/cadastro.html", {"form": form})
Dica: @login_required é um decorador, como os da aula 56: ele "embrulha" a view e manda para o login quem não entrou.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
@login_required

Exercícios

1. Escreva o formulário de logout (Django 5) para colocar no menu.

Ver resposta 
<form method="post" action="{% url 'logout' %}">
  {% csrf_token %}
  <button type="submit">Sair</button>
</form>

2. Na view novo (aula 205), como gravar o usuário logado como dono antes de salvar o contato?

Ver resposta 
contato = form.save(commit=False)
contato.dono = request.user
contato.save()

commit=False cria o objeto sem salvar, para você completar o campo dono antes.
