O que é JSON

JSON (*JavaScript Object Notation*, lê-se "djêison") é um formato de texto para guardar dados organizados. Aplicativos e sites usam JSON o tempo todo para trocar informações — a previsão do tempo no seu celular, por exemplo, provavelmente chega em JSON.

A boa notícia: JSON é quase igual aos dicionários e listas que você já conhece.

{
  "nome": "Bia",
  "idade": 13,
  "esportes": ["vôlei", "natação"],
  "tem_bicicleta": true
}

Ele guarda dados aninhados: listas dentro de dicionários, dicionários dentro de listas, e assim por diante.

De Python para texto: json.dumps

O json.dumps (o "s" é de *string*) transforma dados do Python em um texto JSON.

import json

aluno = {"nome": "Bia", "idade": 13, "esportes": ["vôlei", "natação"], "tem_bicicleta": True}

texto = json.dumps(aluno)
print(texto)
print(type(texto))

bonito = json.dumps(aluno, indent=2, ensure_ascii=False)
print(bonito)

{"nome": "Bia", "idade": 13, "esportes": ["v\u00f4lei", "nata\u00e7\u00e3o"], "tem_bicicleta": true}
<class 'str'>
{
  "nome": "Bia",
  "idade": 13,
  "esportes": [
    "vôlei",
    "natação"
  ],
  "tem_bicicleta": true
}

Por padrão, o JSON troca letras acentuadas por códigos como \u00f4 (o "ô"). O ensure_ascii=False mantém os acentos, e o indent=2 coloca cada item numa linha com 2 espaços de recuo.

De texto para Python: json.loads

O caminho de volta é o json.loads: ele lê um texto JSON e devolve dicionários, listas, números etc.

import json

resposta = '{"cidade": "Fortaleza", "temperatura": 31.5, "chuva": false, "dias": [30, 31, 29]}'

dados = json.loads(resposta)
print(dados["cidade"])
print(dados["temperatura"] + 1)
print(dados["chuva"])
print(max(dados["dias"]))

Fortaleza
32.5
False
31

Repare: no texto JSON estava false (minúsculo); no Python virou False.

Tipos do Python e do JSON

  • dict vira objeto { } e list (ou tuple) vira array [ ];
  • str vira texto, sempre entre aspas duplas;
  • int e float viram números;
  • True e False viram true e false;
  • None vira null.
import json

print(json.dumps([1, 2.5, "oi", True, False, None]))
print(json.dumps((10, 20)))
print(json.loads("[null, true, 3]"))

[1, 2.5, "oi", true, false, null]
[10, 20]
[None, True, 3]

Atenção: Em JSON as chaves dos objetos são sempre textos. Se você salvar {1: "um"}, ao carregar de volta a chave vira "1" (string), e dados[1] dá KeyError.
Atenção: JSON não aceita aspas simples. json.loads("{'a': 1}") dá erro; o certo é json.loads('{"a": 1}'). Também não dá para salvar direto um set nem uma data: transforme antes em lista ou texto.

Salvando e carregando arquivos: dump e load

Para arquivos, use json.dump (grava) e json.load (lê), sem o "s". É o jeito mais fácil de fazer um programa "lembrar" das coisas entre uma execução e outra.

import json

jogador = {"nome": "Caio", "fase": 7, "vidas": 3, "itens": ["espada", "escudo"]}

with open("save.json", "w", encoding="utf-8") as f:
    json.dump(jogador, f, indent=2, ensure_ascii=False)

with open("save.json", encoding="utf-8") as f:
    carregado = json.load(f)

carregado["fase"] += 1
print("Continuando da fase", carregado["fase"])
print("Itens:", ", ".join(carregado["itens"]))

Continuando da fase 8
Itens: espada, escudo

Na primeira vez que o programa roda, o arquivo ainda não existe. O padrão é tentar carregar e, se não der, começar com dados novos:

import json

def carregar(nome, padrao):
    try:
        with open(nome, encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return padrao

recordes = carregar("recordes.json", {"ppm": 0})
print("Recorde atual:", recordes["ppm"])

recordes["ppm"] = 42
with open("recordes.json", "w", encoding="utf-8") as f:
    json.dump(recordes, f)

print("Depois de salvar:", carregar("recordes.json", {"ppm": 0}))

Recorde atual: 0
Depois de salvar: {'ppm': 42}

Dica: Lembre-se: dumps/loads trabalham com string; dump/load trabalham com arquivo. O "s" no fim é de *string*. Você vai usar tudo isso no projeto da aula 69.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
dados = json.loads('{"nome": "Bia", "idade": 13}')

Exercícios

1. Transforme o dicionário {"time": "Corinthians", "titulos": 7} em texto JSON e mostre o resultado e o tipo dele.

Ver resposta 
import json

texto = json.dumps({"time": "Corinthians", "titulos": 7})
print(texto)
print(type(texto))

{"time": "Corinthians", "titulos": 7}
<class 'str'>

2. Dado o texto JSON '{"produto": "pastel", "preco": 8.0, "sabores": ["carne", "queijo", "palmito"]}', mostre o preço e quantos sabores existem.

Ver resposta 
import json

texto = '{"produto": "pastel", "preco": 8.0, "sabores": ["carne", "queijo", "palmito"]}'
dados = json.loads(texto)
print("Preço:", dados["preco"])
print("Sabores:", len(dados["sabores"]))

Preço: 8.0
Sabores: 3

3. Salve uma lista de três contatos (cada um um dicionário com nome e telefone) em contatos.json, com indent=2. Depois carregue o arquivo e mostre só os nomes.

Ver resposta 
import json

contatos = [
    {"nome": "Vó Lurdes", "telefone": "(81) 99999-0001"},
    {"nome": "Tio Zé", "telefone": "(81) 99999-0002"},
    {"nome": "Júlia", "telefone": "(81) 99999-0003"},
]

with open("contatos.json", "w", encoding="utf-8") as f:
    json.dump(contatos, f, indent=2, ensure_ascii=False)

with open("contatos.json", encoding="utf-8") as f:
    lidos = json.load(f)

for contato in lidos:
    print(contato["nome"])

Vó Lurdes
Tio Zé
Júlia

4. Mostre a diferença entre json.dumps({"fruta": "maçã"}) e json.dumps({"fruta": "maçã"}, ensure_ascii=False).

Ver resposta 
import json

print(json.dumps({"fruta": "maçã"}))
print(json.dumps({"fruta": "maçã"}, ensure_ascii=False))

{"fruta": "ma\u00e7\u00e3"}
{"fruta": "maçã"}

Os dois textos são JSON válidos e carregam a mesma palavra; o segundo só é mais fácil para uma pessoa ler.

5. Faça um contador de visitas: o programa grava {"visitas": 0} em contador.json, depois, três vezes seguidas, carrega o arquivo, soma 1 e grava de novo. No fim, mostre o total.

Ver resposta 
import json

with open("contador.json", "w", encoding="utf-8") as f:
    json.dump({"visitas": 0}, f)

for _ in range(3):
    with open("contador.json", encoding="utf-8") as f:
        dados = json.load(f)
    dados["visitas"] += 1
    with open("contador.json", "w", encoding="utf-8") as f:
        json.dump(dados, f)

with open("contador.json", encoding="utf-8") as f:
    print("Total de visitas:", json.load(f)["visitas"])

Total de visitas: 3
