Aula 24 · for e range; como o for usa iteráveis

Nesta aula você vai aprender

  • Repetir um bloco um número exato de vezes com for e range
  • Usar range(início, fim, passo) para contar do jeito que quiser
  • Percorrer as letras de uma string com for
  • Entender o que é um iterável e como o for usa iter e next
  • Colocar um laço dentro de outro (laços aninhados)

for: repetir para cada item

O for (para) repete um bloco para cada item de uma sequência. Junto com range, ele conta para você — sem precisar criar e aumentar um contador na mão, como no while.

for i in range(5):
    print("Volta número", i)

Volta número 0
Volta número 1
Volta número 2
Volta número 3
Volta número 4

range(5) gera os números 0, 1, 2, 3 e 4. São 5 números, mas começando do zero e parando antes do 5.

Atenção: O fim do range nunca entra. range(1, 10) vai de 1 a 9. Para incluir o 10, escreva range(1, 11).

range com início, fim e passo

range aceita até três valores: range(início, fim, passo).

print(list(range(1, 6)))
print(list(range(0, 21, 5)))
print(list(range(10, 0, -2)))

[1, 2, 3, 4, 5]
[0, 5, 10, 15, 20]
[10, 8, 6, 4, 2]

Aqui usamos list(...) só para ver todos os números de uma vez (listas são o assunto da aula 25). Com passo negativo, o range conta para trás. O acumulador da aula 22 fica mais curto com for:

total = 0
for dia in range(1, 31):
    total += 2
print(f"Guardando R$ 2 por dia, em 30 dias você junta R$ {total}")

Guardando R$ 2 por dia, em 30 dias você junta R$ 60

Percorrendo uma string

O for também percorre textos, uma letra de cada vez:

frase = "Programar em Python é divertido"
vogais = 0
for letra in frase.lower():
    if letra in "aeiouáéíóúâêôãõ":
        vogais += 1
print(f"A frase tem {vogais} vogais")

A frase tem 10 vogais

Dica: Use for quando você sabe quantas vezes vai repetir (ou tem uma sequência para percorrer). Use while quando a repetição depende de algo que você não sabe de antemão, como o que o usuário vai digitar.

Por dentro do for: iteráveis

Tudo o que o for consegue percorrer se chama iterável: textos, range, listas, tuplas e muitos outros. Por trás dos panos, o for pede ao iterável um iterador com iter() e vai pegando um item de cada vez com next(). Você pode fazer isso na mão:

iterador = iter("sol")
print(next(iterador))
print(next(iterador))
print(next(iterador))

s
o
l

Quando os itens acabam, next avisa com o erro StopIteration — e é exatamente esse aviso que faz o for parar sozinho. Você vai aprofundar isso na aula 52.

iterador = iter("ok")
next(iterador)
next(iterador)
next(iterador)

StopIteration

Assim como o while, o for pode ter else (que roda se não houve break), break e continue:

for numero in range(1, 11):
    if numero % 3 == 0:
        continue
    print(numero, end=" ")
print()

1 2 4 5 7 8 10

Um laço dentro do outro

Um laço pode ficar dentro de outro. Para cada volta do laço de fora, o laço de dentro roda inteiro. Pense num relógio: para cada hora, o ponteiro dos minutos dá uma volta completa.

for tabuada in range(2, 4):
    print(f"--- Tabuada do {tabuada} ---")
    for i in range(1, 6):
        print(f"{tabuada} x {i} = {tabuada * i}")

--- Tabuada do 2 ---
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
--- Tabuada do 3 ---
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15

Laços aninhados também desenham. Multiplicar um texto repete: "*" * 3 vira "***":

for linha in range(1, 6):
    print("*" * linha)
for fila in "ABC":
    for numero in range(1, 5):
        print(f"{fila}{numero}", end=" ")
    print()

*
**
***
****
*****
A1 A2 A3 A4
B1 B2 B3 B4
C1 C2 C3 C4

Atenção: Preste atenção na indentação: o que está com 4 espaços pertence ao laço de fora; o que está com 8, ao de dentro. Um recuo errado muda tudo.
Dica: Um break dentro do laço de dentro só interrompe o laço de dentro. O de fora continua normalmente.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
for i in range(1, 11): print(i * 2)
