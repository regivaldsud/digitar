Vários valores, uma variável

Imagine guardar as notas de 30 alunos em 30 variáveis: nota1, nota2, nota3... Cansativo! Uma lista guarda vários valores em ordem, numa só variável. Ela é escrita entre colchetes, com os itens separados por vírgulas.

frutas = ["manga", "caju", "goiaba", "açaí"]
notas = [7.5, 9.0, 6.0]
vazia = []
print(frutas)
print(notas)
print(vazia)
print(len(frutas))

['manga', 'caju', 'goiaba', 'açaí']
[7.5, 9.0, 6.0]
[]
4

Assim como nos textos (aula 20), cada item tem um índice que começa em zero, índices negativos contam do fim e fatias pegam pedaços. A diferença é que a lista pode mudar: dá para trocar um item pelo índice.

times = ["Flamengo", "Palmeiras", "Grêmio", "Bahia", "Fortaleza"]
print(times[0], times[-1])
print(times[1:3])
times[2] = "Sport"
print(times)
print("Bahia" in times)

Flamengo Fortaleza
['Palmeiras', 'Grêmio']
['Flamengo', 'Palmeiras', 'Sport', 'Bahia', 'Fortaleza']
True

Atenção: Pedir um índice que não existe dá erro. Numa lista de 5 itens, o último é o índice 4. times[5] gera IndexError: list index out of range.

Adicionando itens

  • append(item) coloca um item no fim;
  • insert(posição, item) coloca um item numa posição;
  • extend(outra_lista) junta todos os itens de outra lista no fim.
fila = ["Ana", "Bruno"]
fila.append("Carla")
fila.insert(0, "Vovó Zélia")
print(fila)
fila.extend(["Diego", "Elisa"])
print(fila)

['Vovó Zélia', 'Ana', 'Bruno', 'Carla']
['Vovó Zélia', 'Ana', 'Bruno', 'Carla', 'Diego', 'Elisa']

Dica: append e os outros são métodos: funções que pertencem à lista e são chamadas com ponto. Eles mudam a própria lista; não escreva fila = fila.append(...), porque append devolve None e você perderia sua lista.

Removendo itens

  • pop() tira e devolve o último item; pop(posição) tira o item daquela posição;
  • del lista[posição] apaga o item daquela posição (sem devolver nada);
  • remove(valor) tira a primeira ocorrência daquele valor.
fila = ["Vovó Zélia", "Ana", "Bruno", "Carla", "Diego"]
atendido = fila.pop(0)
print("Atendido:", atendido)
ultimo = fila.pop()
print("Desistiu:", ultimo)
del fila[1]
print(fila)
fila.remove("Carla")
print(fila)

Atendido: Vovó Zélia
Desistiu: Diego
['Ana', 'Carla']
['Ana']

Atenção: remove dá ValueError se o valor não estiver na lista, e pop numa lista vazia dá IndexError. Antes, confira com if item in lista: ou if len(lista) > 0:.

Ordenar, contar e resumir

sort() ordena a própria lista; sorted(lista) devolve uma nova lista ordenada e deixa a original como estava. Com reverse=True, a ordem fica do maior para o menor.

pontos = [72, 95, 58, 88, 95]
print(sorted(pontos))
print(pontos)
pontos.sort(reverse=True)
print(pontos)
print(pontos.count(95), pontos.index(58))
print(sum(pontos), min(pontos), max(pontos))

[58, 72, 88, 95, 95]
[72, 95, 58, 88, 95]
[95, 95, 88, 72, 58]
2 4
408 58 95

count conta quantas vezes um valor aparece e index diz a posição da primeira ocorrência. sum, min e max resumem a lista inteira.

Atenção: pontos = pontos.sort() apaga sua lista, pois sort() devolve None. Use pontos.sort() sozinho, ou pontos = sorted(pontos).

Percorrendo e montando listas

O for percorre a lista item por item — é o jeito mais comum de trabalhar com listas. Também dá para montar uma lista aos poucos, começando vazia:

precos = [4.50, 12.00, 3.25, 8.75]
total = 0
for preco in precos:
    total += preco
print(f"Total: R$ {total:.2f}")
pares = []
for n in range(1, 11):
    if n % 2 == 0:
        pares.append(n)
print(pares)

Total: R$ 28.50
[2, 4, 6, 8, 10]

Uma lista pode até conter outras listas, como uma tabela. boletim[1][0] quer dizer: pegue a linha 1 e, dentro dela, o item 0.

boletim = [["Ana", 8, 9], ["Bruno", 6, 7], ["Carla", 10, 9]]
print(boletim[1][0])
for aluno in boletim:
    print(aluno[0], (aluno[1] + aluno[2]) / 2)

Bruno
Ana 8.5
Bruno 6.5
Carla 9.5

cores = ["azul", "verde", "amarelo"]

Exercícios

1. Comece com uma lista vazia de compras e adicione "pão", "leite" e "café". Depois coloque "manteiga" na posição 1 e mostre a lista e quantos itens ela tem.

Ver resposta 
compras = []
compras.append("pão")
compras.append("leite")
compras.append("café")
compras.insert(1, "manteiga")
print(compras)
print(len(compras))

['pão', 'manteiga', 'leite', 'café']
4

2. Na lista numeros = [5, 3, 8, 1], insira o número 10 na posição 2, remova o 3 e mostre a lista final ordenada do menor para o maior.

Ver resposta 
numeros = [5, 3, 8, 1]
numeros.insert(2, 10)
numeros.remove(3)
numeros.sort()
print(numeros)

[1, 5, 8, 10]

3. Dada a lista gols = [2, 0, 3, 1, 3, 0, 3] (gols por jogo), mostre o total de gols, a maior goleada e quantos jogos tiveram 3 gols.

Ver resposta 
gols = [2, 0, 3, 1, 3, 0, 3]
print("Total:", sum(gols))
print("Maior:", max(gols))
print("Jogos com 3 gols:", gols.count(3))

Total: 12
Maior: 3
Jogos com 3 gols: 3

4. Junte as listas manha = ["Matemática", "Português"] e tarde = ["Ciências", "Inglês"] numa só, com extend. Depois tire a última matéria com pop e mostre qual foi tirada e a lista final.

Ver resposta 
manha = ["Matemática", "Português"]
tarde = ["Ciências", "Inglês"]
manha.extend(tarde)
tirada = manha.pop()
print("Tirada:", tirada)
print(manha)

Tirada: Inglês
['Matemática', 'Português', 'Ciências']

5. Dada a lista idades = [12, 17, 25, 9, 33, 15], crie uma nova lista só com as idades menores de 18 e mostre-a em ordem crescente.

Ver resposta 
idades = [12, 17, 25, 9, 33, 15]
menores = []
for idade in idades:
    if idade < 18:
        menores.append(idade)
print(sorted(menores))

[9, 12, 15, 17]
