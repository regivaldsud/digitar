Módulo 2 · Lógica de programação

Aula 32 · Projeto: jogo de adivinhação

Nesta aula você vai aprender

  • Sortear números com o módulo random
  • Repetir perguntas com while e for até o jogador acertar ou as tentativas acabarem
  • Validar o que o jogador digita antes de converter para número
  • Montar o jogo completo com placar e "jogar de novo"

O que vamos construir

Neste projeto você junta quase tudo o que aprendeu no módulo: variáveis, input, conversão, if, laços, break e um módulo da biblioteca padrão. O jogo funciona assim:

  • o computador pensa em um número de 1 a 100;
  • você chuta um número e ele responde "É maior!" ou "É menor!";
  • você tem 7 tentativas;
  • no fim, ele mostra o placar e pergunta se você quer jogar de novo.

Vamos construir uma peça de cada vez e testar cada peça antes de juntar tudo. É assim que programadores de verdade trabalham: pedaços pequenos que funcionam são mais fáceis de juntar do que um programão cheio de erros.

Passo 1: sortear o número secreto

O módulo random tem a função randint(a, b), que sorteia um número inteiro entre a e b, incluindo os dois extremos. Para usá-lo, escrevemos import random no começo do programa (a aula 54 explica o import em detalhes). Rode várias vezes e veja o número mudar:

import random

secreto = random.randint(1, 100)
print("Número sorteado:", secreto)

(exemplo — a sua saída pode ser diferente)
Número sorteado: 4

Dica: Enquanto você está testando, pode usar random.seed(10) antes do sorteio. Com a mesma "semente", o sorteio dá sempre o mesmo número, o que facilita encontrar erros. Lembre-se de tirar a linha quando o jogo estiver pronto!

Passo 2: a dica de maior ou menor

A parte mais importante do jogo é comparar o palpite com o número secreto. Vamos testar os três casos possíveis — abaixo, acima e igual — com palpites já prontos, sem precisar do teclado:

secreto = 42
for palpite in [30, 50, 42]:
    if palpite < secreto:
        print(palpite, "-> É maior!")
    elif palpite > secreto:
        print(palpite, "-> É menor!")
    else:
        print(palpite, "-> Acertou!")

30 -> É maior!
50 -> É menor!
42 -> Acertou!

Sempre teste todos os caminhos de um if: um erro escondido num elif só aparece quando aquele caminho é usado.

Passo 3: o laço de tentativas

Agora simulamos uma partida inteira, contando as tentativas e parando com break quando o palpite acerta:

secreto = 42
palpites = [50, 25, 37, 43, 40, 42, 99]
tentativas = 0
for palpite in palpites:
    tentativas += 1
    if palpite == secreto:
        print(f"Tentativa {tentativas}: {palpite} -> Acertou!")
        break
    dica = "É maior!" if palpite < secreto else "É menor!"
    print(f"Tentativa {tentativas}: {palpite} -> {dica}")
print("Precisou de", tentativas, "tentativas")

Tentativa 1: 50 -> É menor!
Tentativa 2: 25 -> É maior!
Tentativa 3: 37 -> É maior!
Tentativa 4: 43 -> É menor!
Tentativa 5: 40 -> É maior!
Tentativa 6: 42 -> Acertou!
Precisou de 6 tentativas

O break para o laço assim que o palpite acerta — por isso o 99 nem chega a ser usado.

Passo 4: ler o palpite sem quebrar o programa

Se o jogador digitar "dez" em vez de "10", int("dez") dá erro e o jogo fecha. Vamos perguntar de novo, com while True, até receber um número válido:

while True:
    texto = input("Seu palpite (1 a 100): ").strip()
    if texto.isdigit() and 1 <= int(texto) <= 100:
        break
    print("Digite um número inteiro de 1 a 100.")
palpite = int(texto)
print("Você chutou", palpite)

(exemplo digitando dez, 150, 42)
Seu palpite (1 a 100): dez
Digite um número inteiro de 1 a 100.
Seu palpite (1 a 100): 150
Digite um número inteiro de 1 a 100.
Seu palpite (1 a 100): 42
Você chutou 42

O and só testa int(texto) se texto.isdigit() for verdadeiro. Assim, o int nunca recebe um texto que não é número.

Atenção: "-5".isdigit() dá False, porque o sinal de menos não é um dígito. Para este jogo isso é ótimo, já que só aceitamos de 1 a 100.

Passo 5: por que 7 tentativas?

Existe uma estratégia que sempre acerta em até 7 chutes: chutar o meio do intervalo que sobrou. Comece em 50; se for maior, chute 75; se for menor, 25; e assim por diante. Cada chute corta as possibilidades pela metade: 100, 50, 25, 13, 7, 4, 2, 1. Esse truque se chama busca binária e é usado em computação o tempo todo.

Passo 6: o programa completo

Agora juntamos as peças. O laço de fora (while True) controla as partidas e o placar; o de dentro (for) controla as tentativas de uma partida; e o while True mais interno valida cada palpite.

import random

MAX_TENTATIVAS = 7
partidas = 0
vitorias = 0
print("=== JOGO DE ADIVINHAÇÃO ===")
while True:
    partidas += 1
    secreto = random.randint(1, 100)
    print()
    print("Pensei em um número de 1 a 100.")
    print(f"Você tem {MAX_TENTATIVAS} tentativas. Boa sorte!")
    acertou = False
    for tentativa in range(1, MAX_TENTATIVAS + 1):
        while True:
            texto = input("Seu palpite (1 a 100): ").strip()
            if texto.isdigit() and 1 <= int(texto) <= 100:
                break
            print("Digite um número inteiro de 1 a 100.")
        palpite = int(texto)
        if palpite == secreto:
            print(f"Acertou em {tentativa} tentativa(s)!")
            acertou = True
            break
        restam = MAX_TENTATIVAS - tentativa
        dica = "É maior!" if palpite < secreto else "É menor!"
        print(f"{dica} Restam {restam}.")
    if acertou:
        vitorias += 1
    else:
        print(f"Suas tentativas acabaram. O número era {secreto}.")
    print(f"Placar: {vitorias} vitória(s) em {partidas} partida(s).")
    resposta = input("Jogar de novo? (s/n) ").strip().lower()
    if resposta != "s":
        break
print("Valeu por jogar! Até a próxima.")

(exemplo digitando 50, 25, 37, 43, 40, 42, 41, n)

A variável acertou começa False e vira True só quando o jogador acerta. Depois do for, ela diz se a partida foi vitória ou derrota. (O else do for, que você viu nas aulas 22 e 24, também resolveria isso.)

Dica: O nome MAX_TENTATIVAS está em maiúsculas para avisar que é uma constante: um valor que não muda durante o programa. Se quiser um jogo mais difícil, basta mudar esse número em um lugar só.

Como rodar no seu computador

Este jogo conversa com você várias vezes pelo teclado, então ele fica mais divertido no terminal:

  • no VS Code, crie o arquivo jogo.py dentro da sua pasta curso-python e cole o código completo;
  • salve com Ctrl+S;
  • no terminal do VS Code, digite o comando abaixo e jogue!
python jogo.py

Exercícios

1. Crie a escolha de nível: para cada texto da lista ["facil", "medio", "dificil", "outro"], defina maximo e tentativas assim: "facil" dá 10 e 4, "medio" dá 100 e 7, "dificil" dá 1000 e 10. Qualquer outro texto cai no nível médio.

Ver resposta 
for nivel in ["facil", "medio", "dificil", "outro"]:
    if nivel == "facil":
        maximo, tentativas = 10, 4
    elif nivel == "dificil":
        maximo, tentativas = 1000, 10
    else:
        maximo, tentativas = 100, 7
    print(f"{nivel}: 1 a {maximo}, {tentativas} tentativas")

facil: 1 a 10, 4 tentativas
medio: 1 a 100, 7 tentativas
dificil: 1 a 1000, 10 tentativas
outro: 1 a 100, 7 tentativas

O else pega tanto "medio" quanto qualquer texto desconhecido, então não é preciso um elif só para o médio.

2. Faça o computador jogar sozinho com a busca binária: para secreto = 42, chute sempre o meio do intervalo que sobrou e mostre cada chute e quantas tentativas foram necessárias.

Ver resposta 
secreto = 42
minimo = 1
maximo = 100
tentativas = 0
while True:
    tentativas += 1
    chute = (minimo + maximo) // 2
    print("Chute:", chute)
    if chute == secreto:
        break
    if chute < secreto:
        minimo = chute + 1
    else:
        maximo = chute - 1
print("Acertou em", tentativas, "tentativas")

Chute: 50
Chute: 25
Chute: 37
Chute: 43
Chute: 40
Chute: 41
Chute: 42
Acertou em 7 tentativas

3. Crie a dica de temperatura: se a diferença entre o palpite e o secreto for de até 5, mostre "Está quente!"; até 15, "Está morno."; acima disso, "Está frio...". Teste com o secreto 42 e os palpites 40, 30 e 90. Dica: abs() dá a diferença sem sinal.

Ver resposta 
secreto = 42
for palpite in [40, 30, 90]:
    diferenca = abs(palpite - secreto)
    if diferenca <= 5:
        dica = "Está quente!"
    elif diferenca <= 15:
        dica = "Está morno."
    else:
        dica = "Está frio..."
    print(palpite, dica)

40 Está quente!
30 Está morno.
90 Está frio...

4. Guarde o recorde (o menor número de tentativas) de várias partidas. Comece com recorde = None, percorra os resultados [6, 4, 5, 3] e avise sempre que houver um novo recorde.

Ver resposta 
recorde = None
for tentativas in [6, 4, 5, 3]:
    if recorde is None or tentativas < recorde:
        recorde = tentativas
        print(f"Novo recorde: {tentativas} tentativa(s)!")
print("Recorde final:", recorde)

Novo recorde: 6 tentativa(s)!
Novo recorde: 4 tentativa(s)!
Novo recorde: 3 tentativa(s)!
Recorde final: 3

O None, que você viu na aula 21, indica que ainda não existe recorde. Por isso o primeiro resultado sempre vira recorde.
