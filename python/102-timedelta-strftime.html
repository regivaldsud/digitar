Aula 102 · Calculando e formatando datas (timedelta, strftime), calendar, locale

Nesta aula você vai aprender

  • Somar e subtrair datas com timedelta
  • Formatar datas no padrão brasileiro com strftime
  • Transformar texto em data com strptime
  • Usar o módulo calendar para anos bissextos e dias do mês
  • Saber para que serve o locale e por que ele é delicado

Contas com timedelta

Subtrair duas datas dá um timedelta: uma duração. E somar um timedelta a uma data dá outra data.

from datetime import date, timedelta

inicio_ferias = date(2026, 12, 18)
volta_aulas = date(2027, 2, 1)
duracao = volta_aulas - inicio_ferias
print("Férias de", duracao.days, "dias")

prova = date(2026, 11, 10)
print("Revisão em:", prova - timedelta(days=7))
print("Resultado em:", prova + timedelta(weeks=2))

Férias de 45 dias
Revisão em: 2026-11-03
Resultado em: 2026-11-24

Um timedelta aceita days, weeks, hours, minutes e seconds. Com total_seconds() você converte tudo em segundos:

from datetime import timedelta

treino = timedelta(hours=1, minutes=15)
print(treino)
print(treino.total_seconds() / 60, "minutos")

1:15:00
75.0 minutos

strftime: data do jeito brasileiro

O método strftime ("string format time") transforma uma data em texto. Cada código com % é trocado por uma parte da data:

from datetime import datetime

momento = datetime(2026, 3, 8, 9, 5)
print(momento.strftime("%d/%m/%Y"))
print(momento.strftime("%d/%m/%y às %H:%M"))
print(momento.strftime("%H:%M:%S"))

08/03/2026
08/03/26 às 09:05
09:05:00

  • %d dia, %m mês, %Y ano com 4 dígitos, %y com 2;
  • %H hora de 00 a 23, %M minuto, %S segundo.
Atenção: %m (minúsculo) é mês e %M (maiúsculo) é minuto. Trocar um pelo outro é um dos erros mais comuns com datas.

strptime: de texto para data

strptime ("string parse time") faz o caminho contrário: lê um texto num formato que você descreve. Ótimo para datas digitadas pelo usuário.

from datetime import datetime, date

def idade(nascimento, hoje):
    anos = hoje.year - nascimento.year
    if (hoje.month, hoje.day) < (nascimento.month, nascimento.day):
        anos -= 1
    return anos

nasc = datetime.strptime("15/08/2012", "%d/%m/%Y").date()
print(nasc)
print("Idade em 14/08/2026:", idade(nasc, date(2026, 8, 14)))
print("Idade em 15/08/2026:", idade(nasc, date(2026, 8, 15)))

2012-08-15
Idade em 14/08/2026: 13
Idade em 15/08/2026: 14

Se o texto não bater com o formato, como "31-12-2026" com "%d/%m/%Y", o Python dá ValueError. Na aula 53 você aprendeu a tratar esse erro com try.

O módulo calendar

O calendar responde perguntas sobre o calendário:

import calendar

print(calendar.isleap(2028))
print(calendar.isleap(2026))
primeiro_dia, total_dias = calendar.monthrange(2026, 2)
print("Fevereiro de 2026 tem", total_dias, "dias")
print(calendar.month(2026, 9))

monthrange devolve o dia da semana em que o mês começa (0 = segunda) e quantos dias ele tem. O calendário impresso sai em inglês, porque o Python começa usando o idioma "neutro".

locale: nomes em português

O módulo locale muda o idioma de coisas como o nome dos meses no strftime("%B"). Só que ele depende de o sistema ter o idioma instalado, e o nome muda de um sistema para outro:

import locale
from datetime import date

locale.setlocale(locale.LC_TIME, "pt_BR.UTF-8")   # Linux e macOS
# locale.setlocale(locale.LC_TIME, "Portuguese_Brazil")   # Windows
print(date(2026, 9, 7).strftime("%d de %B de %Y"))

Por isso, em programas simples, muita gente prefere uma lista própria com os nomes, que funciona em qualquer lugar:

from datetime import date

MESES = ["janeiro", "fevereiro", "março", "abril", "maio", "junho", "julho",
         "agosto", "setembro", "outubro", "novembro", "dezembro"]

d = date(2026, 9, 7)
print(f"{d.day} de {MESES[d.month - 1]} de {d.year}")

7 de setembro de 2026

Dica: Se setlocale der locale.Error: unsupported locale setting, o idioma não está instalado no sistema. Use a solução da lista própria.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
print(hoje.strftime("%d/%m/%Y %H:%M"))

Exercícios

1. Um empréstimo de livro dura 14 dias. Se você pegou o livro em 28/10/2026, qual é a data de devolução, no formato dd/mm/aaaa?

Ver resposta 
from datetime import date, timedelta

retirada = date(2026, 10, 28)
print((retirada + timedelta(days=14)).strftime("%d/%m/%Y"))

11/11/2026

2. Quantos dias se passaram entre o descobrimento (22/04/1500) e a Independência (07/09/1822)? Leia as duas datas de textos com strptime.

Ver resposta 
from datetime import datetime

inicio = datetime.strptime("22/04/1500", "%d/%m/%Y")
fim = datetime.strptime("07/09/1822", "%d/%m/%Y")
print((fim - inicio).days, "dias")

117746 dias

3. Transforme "31/12/2026 23:59" em datetime e mostre quantos minutos faltam para 00:00 de 01/01/2027.

Ver resposta 
from datetime import datetime

momento = datetime.strptime("31/12/2026 23:59", "%d/%m/%Y %H:%M")
virada = datetime(2027, 1, 1, 0, 0)
print(int((virada - momento).total_seconds() // 60), "minuto(s)")

1 minuto(s)

4. Mostre quais anos de 2024 a 2036 são bissextos.

Ver resposta 
import calendar

print([ano for ano in range(2024, 2037) if calendar.isleap(ano)])

[2024, 2028, 2032, 2036]

5. Escreva a data 25/12/2026 por extenso, como 25 de dezembro de 2026, sem usar locale.

Ver resposta 
from datetime import date

MESES = ["janeiro", "fevereiro", "março", "abril", "maio", "junho", "julho",
         "agosto", "setembro", "outubro", "novembro", "dezembro"]
natal = date(2026, 12, 25)
print(f"{natal.day} de {MESES[natal.month - 1]} de {natal.year}")

25 de dezembro de 2026
