O que é uma tupla

Uma tupla é parecida com uma lista: guarda vários valores em ordem. A diferença é que ela é escrita com parênteses e, depois de criada, não pode ser alterada.

coordenada = (-23.55, -46.63)
cores_bandeira = ("verde", "amarelo", "azul", "branco")
print(coordenada)
print(cores_bandeira[1])
print(len(cores_bandeira))
print("azul" in cores_bandeira)

(-23.55, -46.63)
amarelo
4
True

Índices, fatias, len, in, count, index e for funcionam igualzinho às listas. O que não existe são os métodos que mudam a sequência, como append e pop.

Imutável: não muda

Tentar alterar um item de uma tupla dá erro:

dias = ("sáb", "dom")
dias[0] = "seg"

TypeError: 'tuple' object does not support item assignment

Isso é uma vantagem quando os dados não devem mudar: as coordenadas de uma cidade, os meses do ano, a data de nascimento. A tupla protege contra alterações por engano.

Atenção: Uma tupla com um item só precisa de uma vírgula: (5,). Sem a vírgula, (5) é apenas o número 5 entre parênteses.
print(type((5,)))
print(type((5)))
ponto = 3, 4
print(ponto, type(ponto))

<class 'tuple'>
<class 'int'>
(3, 4) <class 'tuple'>

Na verdade, quem cria a tupla é a vírgula: os parênteses são opcionais, como mostra ponto = 3, 4.

Desempacotamento

Você pode "abrir" uma tupla (ou lista) direto em variáveis. O número de variáveis tem que ser igual ao número de itens. Com isso, trocar o valor de duas variáveis fica fácil, sem variável auxiliar:

aluno = ("Júlia", 13, "8º ano")
nome, idade, serie = aluno
print(nome, idade, serie)
goleiro = "Cássio"
atacante = "Hulk"
goleiro, atacante = atacante, goleiro
print("Goleiro:", goleiro)
print("Atacante:", atacante)

Júlia 13 8º ano
Goleiro: Hulk
Atacante: Cássio

Se o número de itens não bater, o Python reclama. Para pegar só alguns itens e juntar o resto numa lista, use o *:

primeiro, *resto = ("ouro", "prata", "bronze", "quarto")
print(primeiro)
print(resto)
*inicio, ultimo = [1, 2, 3, 4]
print(inicio, ultimo)

ouro
['prata', 'bronze', 'quarto']
[1, 2, 3] 4

Atenção: a, b = (1, 2, 3) dá ValueError: too many values to unpack (expected 2). Confira se o número de variáveis bate com o número de itens.

Pares no for

Tuplas aparecem muito em listas de pares. O for pode desempacotar cada par direto:

capitais = [("BA", "Salvador"), ("CE", "Fortaleza"), ("PA", "Belém")]
for sigla, cidade in capitais:
    print(f"{sigla}: {cidade}")
horas, minutos = divmod(135, 60)
print(f"135 minutos = {horas}h{minutos}min")

BA: Salvador
CE: Fortaleza
PA: Belém
135 minutos = 2h15min

A função divmod devolve uma tupla com o quociente e o resto da divisão. É com tuplas que o Python devolve vários valores de uma vez — você vai criar funções assim na aula 40.

Numerando com enumerate

Quando você precisa do item e da posição dele, use enumerate. Ele entrega, a cada volta, uma tupla (posição, item), que o for desempacota. O start=1 faz a contagem começar em 1:

podio = ["Rayssa", "Ítalo", "Rebeca"]
for posicao, nome in enumerate(podio, start=1):
    print(f"{posicao}º lugar: {nome}")
print(list(enumerate("abc")))

1º lugar: Rayssa
2º lugar: Ítalo
3º lugar: Rebeca
[(0, 'a'), (1, 'b'), (2, 'c')]

Dica: Regra prática: use lista quando a coleção vai crescer ou mudar (lista de compras) e tupla quando o conjunto de valores é fixo (latitude e longitude).
Pratique no DIGITAR: digite este trecho no modo Programar do app.

Exercícios

1. Desempacote a tupla ("Pão de Açúcar", "Rio de Janeiro", 396) nas variáveis ponto, cidade e altura e mostre a frase "O Pão de Açúcar fica no Rio de Janeiro e tem 396 m".

Ver resposta 
ponto, cidade, altura = ("Pão de Açúcar", "Rio de Janeiro", 396)
print(f"O {ponto} fica no {cidade} e tem {altura} m")

O Pão de Açúcar fica no Rio de Janeiro e tem 396 m

2. Troque os valores de x = 10 e y = 20 em uma linha e mostre os dois.

Ver resposta 
x = 10
y = 20
x, y = y, x
print(x, y)

20 10

3. Dada a lista de pares [("Ana", 9.5), ("Beto", 7.0), ("Caio", 8.0)], mostre cada nome com a nota e, no fim, a média da turma.

Ver resposta 
turma = [("Ana", 9.5), ("Beto", 7.0), ("Caio", 8.0)]
soma = 0
for nome, nota in turma:
    print(f"{nome}: {nota}")
    soma += nota
print(f"Média: {soma / len(turma):.2f}")

Ana: 9.5
Beto: 7.0
Caio: 8.0
Média: 8.17

4. Mostre cada letra da palavra "teclado" com sua posição, começando em 1, no formato 1: t.

Ver resposta 
for pos, letra in enumerate("teclado", start=1):
    print(f"{pos}: {letra}")

1: t
2: e
3: c
4: l
5: a
6: d
7: o

5. A lista fila = ["Ana", "Bia", "Caio", "Davi", "Edu"] representa uma fila. Use desempacotamento com * para separar o primeiro da fila, o último e quem está no meio.

Ver resposta 
fila = ["Ana", "Bia", "Caio", "Davi", "Edu"]
primeiro, *meio, ultimo = fila
print("Primeiro:", primeiro)
print("Meio:", meio)
print("Último:", ultimo)

Primeiro: Ana
Meio: ['Bia', 'Caio', 'Davi']
Último: Edu
