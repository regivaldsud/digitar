render e o contexto

Escrever HTML dentro de strings fica bagunçado. O Django usa templates: arquivos HTML com espaços para dados. A função render junta o template com um dicionário chamado contexto.

# contatos/views.py
from django.shortcuts import render


def lista(request):
    contexto = {
        "titulo": "Meus contatos",
        "contatos": ["Ana", "Bruno", "Carla"],
    }
    return render(request, "contatos/lista.html", contexto)

O template fica em contatos/templates/contatos/lista.html. A pasta repetida (contatos/templates/contatos/) evita confusão quando dois apps têm templates com o mesmo nome.

Herança: um layout para todas as páginas

O arquivo base define o esqueleto e os blocos que cada página preenche:

<!-- contatos/templates/base.html -->
{% load static %}
<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>{% block titulo %}Meu site{% endblock %}</title>
  <link rel="stylesheet" href="{% static 'css/estilo.css' %}">
</head>
<body>
  {% include "menu.html" %}
  {% block conteudo %}{% endblock %}
</body>
</html>
<!-- contatos/templates/contatos/lista.html -->
{% extends "base.html" %}
{% block titulo %}{{ titulo }}{% endblock %}
{% block conteudo %}
  <h1>{{ titulo }}</h1>
  <ul>
    {% for nome in contatos %}
      <li>{{ nome|upper }}</li>
    {% empty %}
      <li>Nenhum contato ainda.</li>
    {% endfor %}
  </ul>
  {% if contatos|length > 2 %}<p>Que turma grande!</p>{% endif %}
{% endblock %}
  • {{ variavel }} mostra um valor; |upper e |length são filtros.
  • {% for %}, {% if %} e {% block %} são tags; toda tag de bloco tem um {% end... %}.
  • {% include "menu.html" %} coloca outro template ali dentro.
Dica: O Django escapa o HTML das variáveis automaticamente: se um nome for <b>Ana</b>, aparece o texto, não o negrito. Isso protege o site contra código malicioso.

Arquivos estáticos

CSS, JavaScript e imagens são arquivos estáticos. Coloque-os em contatos/static/css/estilo.css, use {% load static %} no template e {% static 'css/estilo.css' %} no endereço. Com DEBUG = True, o runserver já serve esses arquivos.

Atenção: Se aparecer Invalid block tag ... 'static', faltou o {% load static %} no topo daquele template — ele vale só para o arquivo onde foi escrito.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
{% for nome in contatos %}<li>{{ nome }}</li>{% endfor %}

Exercícios

1. Escreva um template sobre.html que herda de base.html, troca o título para "Sobre" e mostra um parágrafo.

Ver resposta 
{% extends "base.html" %}
{% block titulo %}Sobre{% endblock %}
{% block conteudo %}
  <p>Este site foi feito por mim, com Django!</p>
{% endblock %}

2. Uma view manda {"notas": [7, 9.5, 6]}. Escreva o trecho de template que lista as notas e mostra quantas são.

Ver resposta 
<ul>
  {% for nota in notas %}
    <li>{{ nota }}</li>
  {% endfor %}
</ul>
<p>Total de notas: {{ notas|length }}</p>
