Moldes e coisas feitas com o molde

Pense numa forma de bolo. A forma não é um bolo, mas com ela você faz quantos bolos quiser — um de chocolate, outro de cenoura. Em programação é igual:

  • a classe é o molde: descreve como as coisas daquele tipo são e o que elas fazem;
  • o objeto (ou instância) é cada coisa concreta feita com o molde.

Você já usa objetos desde a primeira aula! "banana" é um objeto da classe str e [1, 2] é um objeto da classe list. É por isso que eles têm métodos, como "banana".upper().

print(type("banana"))
print(type([1, 2]))
print(type(3.5))
print("banana".upper())

<class 'str'>
<class 'list'>
<class 'float'>
BANANA

Até agora você usou classes que já vêm com o Python. Neste módulo você vai criar as suas.

Criando a sua classe

Use a palavra class e um nome com a primeira letra maiúscula. Para criar um objeto, chame a classe como se fosse uma função, com parênteses.

class Cachorro:
    pass

rex = Cachorro()
pipoca = Cachorro()

rex.nome = "Rex"
pipoca.nome = "Pipoca"

print(rex.nome)
print(pipoca.nome)
print(type(rex))

Rex
Pipoca
<class '__main__.Cachorro'>

O pass deixa a classe vazia por enquanto. Cada objeto guarda seus próprios atributos — variáveis que pertencem ao objeto e que você acessa com ponto: rex.nome.

Dica: Por convenção, nomes de classe usam CamelCase: cada palavra começa com maiúscula, sem _, como ContaBancaria ou JogoDaVelha. Variáveis e funções continuam em snake_case: minha_conta.

O método __init__

Criar os atributos "na mão" depois de criar o objeto é trabalhoso e fácil de esquecer. O __init__ (dois sublinhados antes e dois depois; lê-se "dunder init") é um método especial que o Python chama automaticamente toda vez que um objeto é criado. É o lugar de preparar os atributos.

class Pokemon:
    def __init__(self, nome, tipo, nivel):
        self.nome = nome
        self.tipo = tipo
        self.nivel = nivel

pika = Pokemon("Pikachu", "elétrico", 12)
bulba = Pokemon("Bulbasaur", "planta", 9)

print(pika.nome, pika.tipo, pika.nivel)
print(bulba.nome, bulba.tipo, bulba.nivel)

Pikachu elétrico 12
Bulbasaur planta 9

Os valores em Pokemon("Pikachu", "elétrico", 12) vão para os parâmetros do __init__. A linha self.nome = nome guarda o parâmetro como atributo do objeto: o nome da esquerda pertence ao objeto, o da direita é só o parâmetro.

Atenção: São dois sublinhados de cada lado: __init__. Se você escrever _init_ ou __int__, o método nunca é chamado, e ao criar o objeto aparece TypeError: Pokemon() takes no arguments.

Métodos e o self

Um método é uma função escrita dentro da classe. Todo método recebe primeiro o parâmetro self, que é o próprio objeto que chamou o método.

class ContaBancaria:
    def __init__(self, titular, saldo=0):
        self.titular = titular
        self.saldo = saldo

    def depositar(self, valor):
        self.saldo += valor

    def sacar(self, valor):
        if valor > self.saldo:
            print("Saldo insuficiente!")
        else:
            self.saldo -= valor

conta = ContaBancaria("Marina")
conta.depositar(150)
conta.sacar(40)
conta.sacar(500)
print(conta.titular, "tem R$", conta.saldo)

Saldo insuficiente!
Marina tem R$ 110

Quando você escreve conta.depositar(150), o Python faz ContaBancaria.depositar(conta, 150): a conta vai para o self e o 150 vai para valor. Por isso, dentro do método, self.saldo é o saldo desta conta.

Atenção: Esquecer o self na definição é um erro muito comum. Com def depositar(valor):, chamar conta.depositar(150) dá TypeError: ContaBancaria.depositar() takes 1 positional argument but 2 were given — o Python passou o objeto e mais o 150.

Cada objeto é independente

Mudar um objeto não muda os outros feitos com a mesma classe. Cada um tem os próprios atributos.

class Cofrinho:
    def __init__(self, dono):
        self.dono = dono
        self.total = 0

    def guardar(self, valor):
        self.total += valor

    def mostrar(self):
        print(f"{self.dono}: R$ {self.total:.2f}")

meu = Cofrinho("Lia")
do_irmao = Cofrinho("Theo")

meu.guardar(5)
meu.guardar(2.5)
do_irmao.guardar(10)

meu.mostrar()
do_irmao.mostrar()

Lia: R$ 7.50
Theo: R$ 10.00

Repare que total não veio como parâmetro: o __init__ pode criar atributos com um valor inicial fixo.

3. Crie a classe Retangulo com largura e altura e os métodos area() e perimetro(), que devolvem os valores. Teste com 5 por 3.

Ver resposta 
class Retangulo:
    def __init__(self, largura, altura):
        self.largura = largura
        self.altura = altura

    def area(self):
        return self.largura * self.altura

    def perimetro(self):
        return 2 * (self.largura + self.altura)

r = Retangulo(5, 3)
print("Área:", r.area())
print("Perímetro:", r.perimetro())

Área: 15
Perímetro: 16

4. Crie a classe Personagem com nome e vida (padrão 100) e o método levar_dano(dano), que não deixa a vida ficar abaixo de 0. Mostre a vida depois de 30 e depois de 90 de dano.

Ver resposta 
class Personagem:
    def __init__(self, nome, vida=100):
        self.nome = nome
        self.vida = vida

    def levar_dano(self, dano):
        self.vida = max(0, self.vida - dano)

heroi = Personagem("Saci")
heroi.levar_dano(30)
print(heroi.nome, heroi.vida)
heroi.levar_dano(90)
print(heroi.nome, heroi.vida)

Saci 70
Saci 0

5. Qual é a diferença entre classe e objeto? Dê um exemplo do dia a dia.

Ver resposta

A classe é o molde (a descrição do tipo); o objeto é uma coisa concreta feita com o molde.
Exemplo: "Celular" é a classe; o seu celular e o da sua mãe são dois objetos,
cada um com sua própria cor, bateria e contatos.
