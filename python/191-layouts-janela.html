Layouts: quem arruma a tela

Colocar cada botão numa posição fixa em pixels dá trabalho e quebra quando a janela muda de tamanho. Os layouts fazem isso por você:

  • QVBoxLayout empilha os widgets de cima para baixo;
  • QHBoxLayout coloca um ao lado do outro;
  • QGridLayout organiza em linhas e colunas, como uma tabela.
import sys
from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout,
                               QLabel, QLineEdit, QPushButton)

app = QApplication(sys.argv)
janela = QWidget()
layout = QVBoxLayout(janela)
layout.addWidget(QLabel("Qual é o seu nome?"))
layout.addWidget(QLineEdit())
layout.addWidget(QPushButton("Enviar"))
janela.show()
sys.exit(app.exec())

O QLabel mostra um texto e o QLineEdit é uma caixa onde o usuário digita.

QMainWindow e o widget central

A QMainWindow é uma janela "completa": pode ter barra de menus, barra de ferramentas e barra de status. No meio dela fica o widget central. A forma organizada de fazer isso é criar uma classe:

import sys
from PySide6.QtWidgets import (QApplication, QMainWindow, QWidget,
                               QGridLayout, QPushButton)


class JanelaPrincipal(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Teclado numérico")
        central = QWidget()
        grade = QGridLayout(central)
        for numero in range(9):
            botao = QPushButton(str(numero + 1))
            grade.addWidget(botao, numero // 3, numero % 3)
        self.setCentralWidget(central)
        self.statusBar().showMessage("Pronto!")


app = QApplication(sys.argv)
janela = JanelaPrincipal()
janela.show()
sys.exit(app.exec())

grade.addWidget(botao, linha, coluna) coloca o botão na posição certa. Com numero // 3 e numero % 3 você transforma 0 a 8 em linhas e colunas (aula 15).

Atenção: Guarde a janela numa variável (janela = ...). Se você criar o objeto sem guardar, o Python pode apagá-lo e a janela some na hora.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
grade.addWidget(botao, numero // 3, numero % 3)
