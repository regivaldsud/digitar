Layouts: quem arruma a tela

Na aula 190 você posicionou um botão com move(70, 50). Isso funciona, mas tem problemas: se a janela muda de tamanho, os botões ficam no mesmo lugar; se o texto cresce, um widget cobre o outro; em telas com letras maiores, tudo fica cortado.

Os layouts resolvem isso. Você só diz a ordem e a organização (em coluna, em linha, em grade) e o layout calcula posições e tamanhos sozinho — e recalcula toda vez que a janela muda de tamanho.

  • QVBoxLayout empilha os widgets de cima para baixo (V de vertical);
  • QHBoxLayout coloca um ao lado do outro (H de horizontal);
  • QGridLayout organiza em linhas e colunas, como uma tabela.

Instale o PySide6 como na aula 190 e rode cada exemplo com python nome_do_arquivo.py.

Empilhando: QVBoxLayout

import sys
from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout,
                               QLabel, QLineEdit, QPushButton)

app = QApplication(sys.argv)
janela = QWidget()
janela.setWindowTitle("Cadastro")

layout = QVBoxLayout(janela)        # o layout já fica ligado à janela
layout.addWidget(QLabel("Qual é o seu nome?"))
layout.addWidget(QLineEdit())
layout.addWidget(QPushButton("Enviar"))

janela.show()
sys.exit(app.exec())

Abre a janela "Cadastro" com, de cima para baixo: o texto "Qual é o seu nome?", uma caixa para digitar e o botão "Enviar".
Ao aumentar a janela, a caixa e o botão esticam junto.

O QLabel mostra um texto fixo e o QLineEdit é uma caixa de uma linha onde o usuário digita. Passar janela para QVBoxLayout(janela) é o mesmo que chamar janela.setLayout(layout) depois.

Dica: Não precisa passar um pai para cada widget quando usa layout: ao fazer addWidget, o layout já coloca o widget dentro da janela dele.

Layout dentro de layout

Formulários de verdade misturam linhas e colunas. O truque é colocar um layout dentro de outro com addLayout:

import sys
from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout, QHBoxLayout,
                               QLabel, QLineEdit, QPushButton)

app = QApplication(sys.argv)
janela = QWidget()
janela.setWindowTitle("Login")

coluna = QVBoxLayout(janela)

linha_nome = QHBoxLayout()
linha_nome.addWidget(QLabel("Usuário:"))
linha_nome.addWidget(QLineEdit())
coluna.addLayout(linha_nome)

linha_botoes = QHBoxLayout()
linha_botoes.addStretch()                 # "mola" que empurra os botões para a direita
linha_botoes.addWidget(QPushButton("Cancelar"))
linha_botoes.addWidget(QPushButton("Entrar"))
coluna.addLayout(linha_botoes)

janela.show()
sys.exit(app.exec())

Abre a janela "Login": na primeira linha, "Usuário:" e a caixa de texto lado a lado;
na segunda, os botões "Cancelar" e "Entrar" encostados no canto direito.

addStretch() coloca uma "mola" invisível que ocupa o espaço que sobra. É assim que se alinham botões à direita, como nas caixas de diálogo do Windows.

A grade: QGridLayout e a conta da posição

No QGridLayout, cada widget vai para uma célula: grade.addWidget(widget, linha, coluna). As linhas e colunas começam do zero, como os índices de lista.

Quando os botões vêm de uma lista, dá para descobrir a linha e a coluna de cada um com uma conta: com 3 colunas, o item de posição i fica na linha i // 3 e na coluna i % 3. A função divmod faz as duas contas de uma vez. Experimente:

botoes = ["1", "2", "3", "4", "5", "6", "7", "8", "9"]
colunas = 3

for i, texto in enumerate(botoes):
    linha, coluna = divmod(i, colunas)
    print(f"botão {texto} -> linha {linha}, coluna {coluna}")

botão 1 -> linha 0, coluna 0
botão 2 -> linha 0, coluna 1
botão 3 -> linha 0, coluna 2
botão 4 -> linha 1, coluna 0
botão 5 -> linha 1, coluna 1
botão 6 -> linha 1, coluna 2
botão 7 -> linha 2, coluna 0
botão 8 -> linha 2, coluna 1
botão 9 -> linha 2, coluna 2

Você pode até "desenhar" a grade no terminal para conferir se a conta está certa:

botoes = ["7", "8", "9", "4", "5", "6", "1", "2", "3", "0"]
colunas = 3

grade = {}
for i, texto in enumerate(botoes):
    grade[divmod(i, colunas)] = texto

linhas = (len(botoes) + colunas - 1) // colunas
for linha in range(linhas):
    print(" ".join(f"[{grade.get((linha, c), ' ')}]" for c in range(colunas)))

[7] [8] [9]
[4] [5] [6]
[1] [2] [3]
[0] [ ] [ ]

Um widget também pode ocupar várias células: grade.addWidget(widget, linha, coluna, quantas_linhas, quantas_colunas). Na calculadora da aula 193, o display usa addWidget(display, 0, 0, 1, 4): começa na linha 0, coluna 0, e ocupa 1 linha e 4 colunas.

QMainWindow e o widget central

A QMainWindow é uma janela "completa": pode ter barra de menus em cima, barras de ferramentas, uma barra de status embaixo e, no meio, o widget central. Ela não aceita um layout direto: você cria um QWidget, põe o layout nele e entrega esse widget com setCentralWidget.

Também é aqui que vale escrever a janela como uma classe que herda de QMainWindow (aula 76). Assim tudo o que é da janela fica junto, e os widgets viram atributos (self.algo) que os outros métodos conseguem usar.

import sys
from PySide6.QtWidgets import (QApplication, QMainWindow, QWidget,
                               QGridLayout, QPushButton)


class JanelaPrincipal(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Teclado numérico")

        central = QWidget()
        grade = QGridLayout(central)
        for i in range(9):
            linha, coluna = divmod(i, 3)
            grade.addWidget(QPushButton(str(i + 1)), linha, coluna)
        self.setCentralWidget(central)

        menu_arquivo = self.menuBar().addMenu("&Arquivo")
        menu_arquivo.addAction("Sair", self.close)

        self.statusBar().showMessage("Pronto!")


app = QApplication(sys.argv)
janela = JanelaPrincipal()
janela.show()
sys.exit(app.exec())

Abre a janela "Teclado numérico" com o menu "Arquivo" (que tem a opção "Sair"),
uma grade 3×3 de botões de 1 a 9 e, embaixo, a barra de status com "Pronto!".

O & em "&Arquivo" faz a letra A virar atalho: Alt+A abre o menu.

Atenção: Guarde a janela numa variável (janela = JanelaPrincipal()). Se você fizer só JanelaPrincipal().show() dentro de uma função, o objeto pode ser apagado pelo Python quando a função termina, e a janela some na hora.
Atenção: Num QMainWindow, não use QVBoxLayout(self). O Qt avisa QLayout: Attempting to add QLayout "" to JanelaPrincipal "", which already has a layout no terminal e os widgets não aparecem. O layout vai no widget central.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
linha, coluna = divmod(i, 3)

Exercícios

1. Monte uma janela com dois botões lado a lado, "Sim" e "Não", usando QHBoxLayout.

Ver resposta 
import sys
from PySide6.QtWidgets import QApplication, QWidget, QHBoxLayout, QPushButton

app = QApplication(sys.argv)
janela = QWidget()
linha = QHBoxLayout(janela)
linha.addWidget(QPushButton("Sim"))
linha.addWidget(QPushButton("Não"))
janela.show()
sys.exit(app.exec())

2. Na grade do teclado numérico (3 colunas), em que linha e coluna fica o botão "8"? Faça a conta com divmod.

Ver resposta 
i = 7  # o botão "8" é criado quando i vale 7
linha, coluna = divmod(i, 3)
print("linha", linha, "coluna", coluna)

linha 2 coluna 1

As linhas e colunas começam do zero: linha 2 é a terceira linha.

3. Você quer 10 botões (de 0 a 9) numa grade de 4 colunas. Mostre a linha e a coluna de cada um e diga quantas linhas a grade vai ter.

Ver resposta 
colunas = 4
for i in range(10):
    print(i, "->", divmod(i, colunas))
print("linhas:", (10 + colunas - 1) // colunas)

0 -> (0, 0)
1 -> (0, 1)
2 -> (0, 2)
3 -> (0, 3)
4 -> (1, 0)
5 -> (1, 1)
6 -> (1, 2)
7 -> (1, 3)
8 -> (2, 0)
9 -> (2, 1)
linhas: 3

A conta (10 + 4 - 1) // 4 arredonda a divisão para cima: 10 botões em 4 colunas precisam de 3 linhas.

4. Monte um formulário com duas linhas ("Nome:" + caixa e "Idade:" + caixa) e um botão "Salvar" embaixo, usando um QVBoxLayout com dois QHBoxLayout dentro.

Ver resposta 
import sys
from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout, QHBoxLayout,
                               QLabel, QLineEdit, QPushButton)

app = QApplication(sys.argv)
janela = QWidget()
coluna = QVBoxLayout(janela)

for rotulo in ["Nome:", "Idade:"]:
    linha = QHBoxLayout()
    linha.addWidget(QLabel(rotulo))
    linha.addWidget(QLineEdit())
    coluna.addLayout(linha)

coluna.addWidget(QPushButton("Salvar"))
janela.show()
sys.exit(app.exec())

Usar um for para as linhas repetidas evita copiar e colar o mesmo código.

5. Escreva uma classe Bloco que herda de QMainWindow, com o título "Bloco de notas", um QTextEdit como widget central e a mensagem "0 caracteres" na barra de status.

Ver resposta 
import sys
from PySide6.QtWidgets import QApplication, QMainWindow, QTextEdit


class Bloco(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Bloco de notas")
        self.texto = QTextEdit()
        self.setCentralWidget(self.texto)
        self.statusBar().showMessage("0 caracteres")


app = QApplication(sys.argv)
janela = Bloco()
janela.show()
sys.exit(app.exec())

Quando o widget central é um só (como o QTextEdit), não precisa de layout: ele vai direto para setCentralWidget.
