O que é CSV

CSV quer dizer *Comma-Separated Values*, "valores separados por vírgula". É uma planilha guardada como texto puro: cada linha do arquivo é uma linha da planilha, e as colunas são separadas por um caractere.

nome,nota
Ana,8.5
Bruno,7.0
Carla,9.5

Excel, LibreOffice e Google Planilhas abrem e salvam .csv. Por isso CSV é um jeito muito comum de trocar dados entre programas. Os exemplos gravam e leem o arquivo no mesmo bloco, como na aula 61.

Escrevendo com csv.writer

O writerow escreve uma linha a partir de uma lista. O módulo csv cuida dos detalhes, como colocar aspas quando um valor tem vírgula dentro:

import csv

with open("notas.csv", "w", newline="", encoding="utf-8") as f:
    escritor = csv.writer(f)
    escritor.writerow(["nome", "nota", "comentario"])
    escritor.writerow(["Ana", 8.5, "ótima, caprichou"])
    escritor.writerow(["Bruno", 7.0, "bom"])

with open("notas.csv", encoding="utf-8") as f:
    print(f.read(), end="")

nome,nota,comentario
Ana,8.5,"ótima, caprichou"
Bruno,7.0,bom

Repare nas aspas em "ótima, caprichou": sem elas, a vírgula do comentário seria confundida com uma nova coluna.

Atenção: Ao abrir um arquivo para o csv, use sempre newline="". Sem isso, no Windows aparece uma linha em branco entre cada linha da planilha.

Lendo com csv.reader

O csv.reader entrega cada linha como uma lista de strings. Use next para pular o cabeçalho:

import csv

with open("notas.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows([["nome", "nota"], ["Ana", 8.5], ["Bruno", 7.0], ["Carla", 9.5]])

with open("notas.csv", newline="", encoding="utf-8") as f:
    leitor = csv.reader(f)
    cabecalho = next(leitor)
    print("Colunas:", cabecalho)
    soma = 0
    quantidade = 0
    for nome, nota in leitor:
        print(nome, "tirou", nota)
        soma += float(nota)
        quantidade += 1

print("Média da turma:", round(soma / quantidade, 2))

Colunas: ['nome', 'nota']
Ana tirou 8.5
Bruno tirou 7.0
Carla tirou 9.5
Média da turma: 8.33

Atenção: Tudo o que o csv lê é texto, mesmo que pareça número. Converta com int() ou float() antes de fazer contas, senão "8.5" + "7.0" vira "8.57.0".

DictReader e DictWriter

Com DictReader, cada linha vira um dicionário cujas chaves são os nomes do cabeçalho: linha["nota"] em vez de linha[1]. O código fica muito mais fácil de ler.

import csv

alunos = [
    {"nome": "Diego", "cidade": "Manaus", "nota": 6.5},
    {"nome": "Elisa", "cidade": "Curitiba", "nota": 9.0},
    {"nome": "Fábio", "cidade": "Salvador", "nota": 8.0},
]

with open("turma.csv", "w", newline="", encoding="utf-8") as f:
    escritor = csv.DictWriter(f, fieldnames=["nome", "cidade", "nota"])
    escritor.writeheader()
    escritor.writerows(alunos)

with open("turma.csv", newline="", encoding="utf-8") as f:
    for linha in csv.DictReader(f):
        situacao = "aprovado" if float(linha["nota"]) >= 7 else "recuperação"
        print(f"{linha['nome']} ({linha['cidade']}): {situacao}")

Diego (Manaus): recuperação
Elisa (Curitiba): aprovado
Fábio (Salvador): aprovado

O Excel em português usa ponto e vírgula

No Brasil, a vírgula é o separador decimal (8,5). Por isso o Excel em português costuma usar ponto e vírgula entre as colunas. Use delimiter=";" para combinar:

import csv

with open("gastos.csv", "w", newline="", encoding="utf-8") as f:
    f.write("item;valor\nlanche;12,50\nônibus;4,40\ncaderno;18,90\n")

total = 0
with open("gastos.csv", newline="", encoding="utf-8") as f:
    for linha in csv.DictReader(f, delimiter=";"):
        total += float(linha["valor"].replace(",", "."))

print(f"Total gasto: R$ {total:.2f}".replace(".", ","))

Total gasto: R$ 35,80

Dica: Se os acentos aparecerem estranhos ao abrir no Excel um CSV gravado pelo Python, grave com encoding="utf-8-sig". Essa marca invisível no começo do arquivo avisa o Excel de que o texto é UTF-8.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
escritor.writerow(["nome", "nota"])

Exercícios

1. Crie filmes.csv com as colunas titulo e ano e três filmes brasileiros. Depois leia com csv.reader e mostre cada um no formato Titulo (ano).

Ver resposta 
import csv

with open("filmes.csv", "w", newline="", encoding="utf-8") as f:
    escritor = csv.writer(f)
    escritor.writerow(["titulo", "ano"])
    escritor.writerow(["Central do Brasil", 1998])
    escritor.writerow(["Cidade de Deus", 2002])
    escritor.writerow(["O Auto da Compadecida", 2000])

with open("filmes.csv", newline="", encoding="utf-8") as f:
    leitor = csv.reader(f)
    next(leitor)
    for titulo, ano in leitor:
        print(f"{titulo} ({ano})")

Central do Brasil (1998)
Cidade de Deus (2002)
O Auto da Compadecida (2000)

2. Grave uma planilha com produto e preco (três produtos) usando DictWriter e calcule o total usando DictReader.

Ver resposta 
import csv

with open("loja.csv", "w", newline="", encoding="utf-8") as f:
    escritor = csv.DictWriter(f, fieldnames=["produto", "preco"])
    escritor.writeheader()
    escritor.writerow({"produto": "pão francês", "preco": 0.75})
    escritor.writerow({"produto": "leite", "preco": 5.49})
    escritor.writerow({"produto": "café", "preco": 18.90})

total = 0
with open("loja.csv", newline="", encoding="utf-8") as f:
    for linha in csv.DictReader(f):
        total += float(linha["preco"])

print(f"Total: R$ {total:.2f}")

Total: R$ 25.14

3. Leia o CSV nome;nota, Gabi;7,5, Heitor;9,0, Iara;8,5 (grave-o no próprio programa) e mostre quem tirou a maior nota.

Ver resposta 
import csv

with open("notas.csv", "w", newline="", encoding="utf-8") as f:
    f.write("nome;nota\nGabi;7,5\nHeitor;9,0\nIara;8,5\n")

with open("notas.csv", newline="", encoding="utf-8") as f:
    linhas = list(csv.DictReader(f, delimiter=";"))

melhor = max(linhas, key=lambda l: float(l["nota"].replace(",", ".")))
print("Maior nota:", melhor["nome"], melhor["nota"])

Maior nota: Heitor 9,0

O key com lambda (aula 49) diz ao max como comparar as linhas.
