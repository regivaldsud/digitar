Aula 69 · Projeto: lista de tarefas que salva em arquivo

Nesta aula você vai aprender

  • Representar tarefas como uma lista de dicionários
  • Criar funções para adicionar, listar, concluir e remover tarefas
  • Salvar e carregar os dados em um arquivo JSON
  • Tratar o caso do arquivo que ainda não existe (ou que está estragado)
  • Montar um menu que repete até o usuário escolher sair

O que vamos construir

Um programa de terminal para organizar o seu dia: lição de casa, treino de digitação, levar o lixo para fora. O mais importante: quando você fecha o programa e abre de novo, as tarefas continuam lá, porque ficam guardadas num arquivo tarefas.json.

O menu vai ficar assim:

1 - Listar tarefas
2 - Adicionar tarefa
3 - Concluir tarefa
4 - Remover tarefa
0 - Sair

Passo 1: como guardar uma tarefa

Cada tarefa tem um título e uma informação de "feita ou não". Um dicionário guarda isso muito bem, e uma lista guarda várias tarefas:

tarefas = [
    {"titulo": "Fazer a lição de matemática", "feita": False},
    {"titulo": "Levar o cachorro para passear", "feita": True},
]

for tarefa in tarefas:
    print(tarefa["titulo"], "->", tarefa["feita"])

Fazer a lição de matemática -> False
Levar o cachorro para passear -> True

Essa estrutura (lista de dicionários com textos, números e True/False) tem uma vantagem enorme: ela pode ser salva em JSON sem nenhuma adaptação.

Passo 2: adicionar e listar

def adicionar(tarefas, titulo):
    titulo = titulo.strip()
    if not titulo:
        print("O título não pode ficar vazio.")
        return
    tarefas.append({"titulo": titulo, "feita": False})
    print(f"Tarefa adicionada: {titulo}")


def listar(tarefas):
    if not tarefas:
        print("Nenhuma tarefa. Aproveite o dia!")
        return
    for numero, tarefa in enumerate(tarefas, start=1):
        marca = "x" if tarefa["feita"] else " "
        print(f"{numero}. [{marca}] {tarefa['titulo']}")


minhas = []
listar(minhas)
adicionar(minhas, "Estudar Python")
adicionar(minhas, "   ")
adicionar(minhas, "Treinar digitação no DIGITAR")
minhas[0]["feita"] = True
listar(minhas)

Nenhuma tarefa. Aproveite o dia!
Tarefa adicionada: Estudar Python
O título não pode ficar vazio.
Tarefa adicionada: Treinar digitação no DIGITAR
1. [x] Estudar Python
2. [ ] Treinar digitação no DIGITAR

O enumerate(tarefas, start=1) numera as tarefas a partir de 1, que é como as pessoas contam. Já a lista do Python começa no índice 0 — vamos lidar com isso no próximo passo.

Atenção: Dentro de uma f-string com aspas duplas, use aspas simples para a chave do dicionário: f"{tarefa['titulo']}". Se usar aspas duplas nos dois lugares, versões mais antigas do Python dão erro de sintaxe.

Passo 3: concluir e remover pelo número

O usuário digita um número (um texto, na verdade). Precisamos conferir se é um número e se existe uma tarefa com ele. Essa conferência vai para uma função própria, usada por concluir e por remover:

def pegar_indice(tarefas, texto):
    """Converte o número digitado no índice da lista, ou devolve None."""
    texto = texto.strip()
    if not texto.isdigit():
        return None
    indice = int(texto) - 1
    if 0 <= indice < len(tarefas):
        return indice
    return None


def concluir(tarefas, texto):
    indice = pegar_indice(tarefas, texto)
    if indice is None:
        print("Número inválido.")
        return
    tarefas[indice]["feita"] = True
    print(f"Concluída: {tarefas[indice]['titulo']}")


def remover(tarefas, texto):
    indice = pegar_indice(tarefas, texto)
    if indice is None:
        print("Número inválido.")
        return
    removida = tarefas.pop(indice)
    print(f"Removida: {removida['titulo']}")


tarefas = [
    {"titulo": "Arrumar o quarto", "feita": False},
    {"titulo": "Comprar pão", "feita": False},
]
concluir(tarefas, "1")
concluir(tarefas, "7")
remover(tarefas, "dois")
remover(tarefas, "2")
print(tarefas)

Concluída: Arrumar o quarto
Número inválido.
Número inválido.
Removida: Comprar pão
[{'titulo': 'Arrumar o quarto', 'feita': True}]

O usuário vê "1", mas no Python é o índice 0. Por isso fazemos int(texto) - 1.

Passo 4: salvar e carregar em JSON

Como você viu nas aulas 61 e 62, o módulo json transforma a lista em texto (json.dump) e o texto de volta em lista (json.load). Na primeira vez que o programa roda, o arquivo ainda não existe — e isso não é um erro do usuário, então tratamos com try/except (aula 53):

import json


def salvar(tarefas, caminho):
    with open(caminho, "w", encoding="utf-8") as arquivo:
        json.dump(tarefas, arquivo, ensure_ascii=False, indent=2)


def carregar(caminho):
    try:
        with open(caminho, encoding="utf-8") as arquivo:
            return json.load(arquivo)
    except FileNotFoundError:
        return []
    except json.JSONDecodeError:
        print("Aviso: o arquivo de tarefas estava estragado. Começando do zero.")
        return []


print(carregar("nao_existe.json"))
salvar([{"titulo": "Estudar para a prova", "feita": False}], "teste.json")
print(carregar("teste.json"))

with open("teste.json", encoding="utf-8") as arquivo:
    print(arquivo.read())

[]
[{'titulo': 'Estudar para a prova', 'feita': False}]
[
  {
    "titulo": "Estudar para a prova",
    "feita": false
  }
]

  • ensure_ascii=False guarda palavras como "pão" e "lição" com acento de verdade, em vez de códigos como ã.
  • indent=2 deixa o arquivo organizado, fácil de ler num editor.
Dica: Sempre use encoding="utf-8" ao abrir arquivos de texto. No Windows, sem isso, palavras com acento podem virar símbolos estranhos.

Passo 5: o programa completo

Agora o menu: um while True que mostra as opções, lê a escolha e chama a função certa. Depois de cada mudança, o programa salva o arquivo — assim nada se perde se a luz acabar.

import json

ARQUIVO = "tarefas.json"


def carregar(caminho=ARQUIVO):
    try:
        with open(caminho, encoding="utf-8") as arquivo:
            return json.load(arquivo)
    except FileNotFoundError:
        return []
    except json.JSONDecodeError:
        print("Aviso: o arquivo de tarefas estava estragado. Começando do zero.")
        return []


def salvar(tarefas, caminho=ARQUIVO):
    with open(caminho, "w", encoding="utf-8") as arquivo:
        json.dump(tarefas, arquivo, ensure_ascii=False, indent=2)


def pegar_indice(tarefas, texto):
    texto = texto.strip()
    if not texto.isdigit():
        return None
    indice = int(texto) - 1
    if 0 <= indice < len(tarefas):
        return indice
    return None


def listar(tarefas):
    if not tarefas:
        print("Nenhuma tarefa. Aproveite o dia!")
        return
    for numero, tarefa in enumerate(tarefas, start=1):
        marca = "x" if tarefa["feita"] else " "
        print(f"{numero}. [{marca}] {tarefa['titulo']}")


def adicionar(tarefas):
    titulo = input("Título da tarefa: ").strip()
    if not titulo:
        print("O título não pode ficar vazio.")
        return
    tarefas.append({"titulo": titulo, "feita": False})
    salvar(tarefas)
    print(f"Tarefa adicionada: {titulo}")


def concluir(tarefas):
    listar(tarefas)
    indice = pegar_indice(tarefas, input("Número da tarefa concluída: "))
    if indice is None:
        print("Número inválido.")
        return
    tarefas[indice]["feita"] = True
    salvar(tarefas)
    print(f"Muito bem! Concluída: {tarefas[indice]['titulo']}")


def remover(tarefas):
    listar(tarefas)
    indice = pegar_indice(tarefas, input("Número da tarefa a remover: "))
    if indice is None:
        print("Número inválido.")
        return
    removida = tarefas.pop(indice)
    salvar(tarefas)
    print(f"Removida: {removida['titulo']}")


def main():
    tarefas = carregar()
    print(f"=== MINHAS TAREFAS === ({len(tarefas)} carregada(s))")
    while True:
        print()
        print("1 - Listar tarefas")
        print("2 - Adicionar tarefa")
        print("3 - Concluir tarefa")
        print("4 - Remover tarefa")
        print("0 - Sair")
        opcao = input("Escolha: ").strip()
        if opcao == "1":
            listar(tarefas)
        elif opcao == "2":
            adicionar(tarefas)
        elif opcao == "3":
            concluir(tarefas)
        elif opcao == "4":
            remover(tarefas)
        elif opcao == "0":
            print(f"Até logo! Suas tarefas estão salvas em {ARQUIVO}.")
            break
        else:
            print("Opção inválida. Digite um número do menu.")


if __name__ == "__main__":
    main()

def resumo(tarefas):
    feitas = sum(1 for t in tarefas if t["feita"])
    pendentes = len(tarefas) - feitas
    return f"{feitas} feita(s), {pendentes} pendente(s)"

2. Crie editar(tarefas, texto_numero, novo_titulo), que troca o título de uma tarefa, conferindo se o número existe e se o novo título não está vazio.

Ver resposta 
def editar(tarefas, texto_numero, novo_titulo):
    texto_numero = texto_numero.strip()
    novo_titulo = novo_titulo.strip()
    if not texto_numero.isdigit() or not 1 <= int(texto_numero) <= len(tarefas):
        print("Número inválido.")
        return
    if not novo_titulo:
        print("O título não pode ficar vazio.")
        return
    tarefas[int(texto_numero) - 1]["titulo"] = novo_titulo
    print("Título atualizado!")


tarefas = [{"titulo": "Estudar", "feita": False}]

def limpar_concluidas(tarefas):
    return [t for t in tarefas if not t["feita"]]

4. Mostre as tarefas com as pendentes primeiro e as feitas no fim, sem mudar a lista original. Dica: False vem antes de True quando o Python ordena.

Ver resposta 
tarefas = [
    {"titulo": "Arrumar a cama", "feita": True},
    {"titulo": "Estudar história", "feita": False},
    {"titulo": "Regar as plantas", "feita": True},

for t in sorted(tarefas, key=lambda t: t["feita"]):

sorted cria uma lista nova e é estável: tarefas com o mesmo valor de feita mantêm a ordem original.
