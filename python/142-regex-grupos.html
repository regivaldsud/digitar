Aula 142 · Grupos, grupos nomeados e retrovisores

Nesta aula você vai aprender

  • Capturar partes do texto com grupos ( )
  • Dar nomes aos grupos com (?P<nome>...) e usar groupdict
  • Entender o findall com grupos e os grupos sem captura (?:...)
  • Usar retrovisores (\1) para achar repetições e reorganizar textos com re.sub

Grupos: partes do que foi achado

Parênteses numa regex criam um grupo. Depois, group(1) devolve o que o primeiro grupo pegou, group(2) o segundo, e assim por diante. group(0) (ou só group()) é o trecho inteiro.

import re

data = re.search(r"(\d{2})/(\d{2})/(\d{4})", "Nasci em 07/09/2012, num feriado.")
print(data.group())
print(data.group(1), data.group(2), data.group(3))
print(data.groups())
dia, mes, ano = data.groups()
print(f"Ano {ano}, mês {mes}, dia {dia}")

07/09/2012
07 09 2012
('07', '09', '2012')
Ano 2012, mês 09, dia 07

O groups() devolve uma tupla, que você pode desempacotar como na aula 27.

Grupos com nome

Contar grupos fica confuso. Dê nomes a eles com (?P<nome>...) e pegue por nome. O groupdict() devolve tudo num dicionário:

import re

placa = re.search(r"(?P<letras>[A-Z]{3})-?(?P<numeros>\d[A-Z0-9]\d{2})", "Carro placa BRA2E19 estacionado")
print(placa.group("letras"))
print(placa.group("numeros"))
print(placa.groupdict())

BRA
2E19
{'letras': 'BRA', 'numeros': '2E19'}

findall com grupos

Atenção: quando o padrão tem grupos, o findall devolve só os grupos, não o trecho inteiro. Com dois ou mais grupos, cada item vira uma tupla:

import re

notas = "Ana: 9, Beto: 7, Carla: 10"
print(re.findall(r"(\w+): (\d+)", notas))
for nome, nota in re.findall(r"(\w+): (\d+)", notas):
    print(nome, "tirou", nota)

[('Ana', '9'), ('Beto', '7'), ('Carla', '10')]
Ana tirou 9
Beto tirou 7
Carla tirou 10

Se você precisa de parênteses só para agrupar (por exemplo, para repetir um pedaço) mas não quer capturar, use (?:...):

import re

risadas = "kkk hahaha hehe haha"
print(re.findall(r"(ha)+", risadas))
print(re.findall(r"(?:ha)+", risadas))

['ha', 'ha']
['hahaha', 'haha']

Atenção: O primeiro findall devolveu só 'ha' e não 'hahaha': com um grupo de captura, ele mostra o conteúdo do grupo (a última repetição). Use (?:...) quando o grupo é só para organizar.

Retrovisores: reaproveitando o grupo

Dentro do próprio padrão, \1 quer dizer "o mesmo texto que o grupo 1 pegou". Isso acha palavras repetidas sem querer, um erro comum de digitação:

import re

texto = "Eu fui fui na padaria e comprei pão pão de queijo."
print(re.findall(r"\b(\w+) \1\b", texto))
print(re.sub(r"\b(\w+) \1\b", r"\1", texto))

['fui', 'pão']
Eu fui na padaria e comprei pão de queijo.

O \b marca a borda de uma palavra (você vai ver na aula 143).

Na troca do re.sub, \1 (ou \g<nome> para grupos com nome) coloca o grupo de volta no texto. Assim dá para reorganizar uma data do formato americano para o brasileiro:

import re

log = "Backup em 2025-03-15 e em 2025-04-01"
print(re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3/\2/\1", log))
print(re.sub(r"(?P<a>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})", r"\g<d>/\g<m>/\g<a>", log))

Backup em 15/03/2025 e em 01/04/2025
Backup em 15/03/2025 e em 01/04/2025

Dica: Na troca, use sempre string crua (r"\1"). Sem o r, "\1" vira um caractere invisível e a troca sai estranha.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3/\2/\1", data)

Exercícios

1. Separe o DDD e o número de "Fone: (81) 99876-5432" usando dois grupos.

Ver resposta 
import re

achado = re.search(r"\((\d{2})\) (\d{4,5}-\d{4})", "Fone: (81) 99876-5432")
ddd, numero = achado.groups()
print("DDD:", ddd)
print("Número:", numero)

DDD: 81
Número: 99876-5432

2. Use grupos com nome para pegar usuário e domínio do e-mail "bia.souza@escola.com.br" e mostre o groupdict().

Ver resposta 
import re

achado = re.search(r"(?P<usuario>[\w.]+)@(?P<dominio>[\w.]+)", "bia.souza@escola.com.br")
print(achado.groupdict())

{'usuario': 'bia.souza', 'dominio': 'escola.com.br'}

3. Transforme a lista "Silva, João; Souza, Maria" em "João Silva; Maria Souza" com re.sub e grupos.

Ver resposta 
import re

nomes = "Silva, João; Souza, Maria"
print(re.sub(r"(\w+), (\w+)", r"\2 \1", nomes))

João Silva; Maria Souza

4. Monte um dicionário {produto: preço} a partir de "arroz=25, feijão=9, café=18" usando findall com dois grupos.

Ver resposta 
import re

texto = "arroz=25, feijão=9, café=18"
precos = {produto: int(valor) for produto, valor in re.findall(r"(\w+)=(\d+)", texto)}
print(precos)

{'arroz': 25, 'feijão': 9, 'café': 18}
