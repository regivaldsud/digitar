A ORM no shell

A ORM traduz código Python para SQL. Teste no shell do Django:

python manage.py shell
from contatos.models import Contato

Contato.objects.create(nome="Ana", telefone="81 99999-0000", favorito=True)
Contato.objects.create(nome="Bruno", telefone="11 98888-1111")

todos = Contato.objects.all()
favoritos = Contato.objects.filter(favorito=True)
ana = Contato.objects.get(nome="Ana")
ana.telefone = "81 97777-2222"
ana.save()
print(Contato.objects.count())

Um QuerySet é preguiçoso: a consulta ao banco só acontece quando você usa os resultados (num for, num print, com count()...).

Atenção: get devolve um registro. Se não achar nenhum, dá Contato.DoesNotExist; se achar mais de um, MultipleObjectsReturned. Para "zero ou mais", use filter.

Filtros, Q e ordenação

from django.db.models import Q
from contatos.models import Contato

com_a = Contato.objects.filter(nome__icontains="a")       # contém "a", sem ligar p/ maiúscula
de_sp = Contato.objects.filter(telefone__startswith="11")
sem_email = Contato.objects.exclude(email__contains="@")
recife_ou_fav = Contato.objects.filter(Q(telefone__startswith="81") | Q(favorito=True))
por_nome = Contato.objects.order_by("nome")              # A a Z
recentes = Contato.objects.order_by("-criado_em")[:5]    # 5 mais novos

Q permite combinar condições com | (ou), & (e) e ~ (não).

Paginação

Com mil contatos, ninguém quer ver todos de uma vez. O Paginator divide a lista:

from django.core.paginator import Paginator
from django.shortcuts import render
from contatos.models import Contato


def lista(request):
    paginador = Paginator(Contato.objects.order_by("nome"), 10)
    pagina = paginador.get_page(request.GET.get("page"))
    return render(request, "contatos/lista.html", {"pagina": pagina})
{% for contato in pagina %}<p>{{ contato.nome }}</p>{% endfor %}
{% if pagina.has_next %}<a href="?page={{ pagina.next_page_number }}">Próxima</a>{% endif %}
Dica: get_page é tolerante: se o número da página for inválido ou grande demais, ele devolve a primeira ou a última página em vez de dar erro.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
Contato.objects.filter(nome__icontains="a").order_by("nome")

from django.core.paginator import Paginator

nomes = [f"Aluno {i}" for i in range(1, 24)]
paginador = Paginator(nomes, 10)
print(paginador.num_pages)
