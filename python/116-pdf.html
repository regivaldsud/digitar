Aula 116 · Ler, juntar e dividir PDF (pypdf)

Nesta aula você vai aprender

  • Instalar e abrir PDFs com pypdf
  • Extrair o texto das páginas
  • Juntar e dividir arquivos PDF
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Instalando

pip install pypdf

Para treinar, coloque dois PDFs quaisquer na pasta do projeto, por exemplo boletim.pdf e atestado.pdf.

Lendo páginas e texto

from pypdf import PdfReader

leitor = PdfReader("boletim.pdf")
print("Páginas:", len(leitor.pages))

primeira = leitor.pages[0]
print(primeira.extract_text()[:200])   # os 200 primeiros caracteres
Atenção: extract_text só funciona em PDFs que têm texto de verdade. Um documento escaneado é uma foto: o texto vem vazio. Para isso seria preciso OCR, que é outro assunto.

Juntando e dividindo

from pypdf import PdfReader, PdfWriter

# juntar: todas as páginas dos dois arquivos em um só
juntos = PdfWriter()
for nome in ["boletim.pdf", "atestado.pdf"]:
    for pagina in PdfReader(nome).pages:
        juntos.add_page(pagina)
with open("documentos.pdf", "wb") as f:
    juntos.write(f)

# dividir: cada página vira um arquivo
leitor = PdfReader("documentos.pdf")
for i, pagina in enumerate(leitor.pages, start=1):
    sozinha = PdfWriter()
    sozinha.add_page(pagina)
    with open(f"pagina_{i}.pdf", "wb") as f:
        sozinha.write(f)
print("Pronto!")

Repare no modo "wb": PDF não é texto, é um arquivo binário, então abrimos com b.

Dica: Junte com pathlib (aula 103): sorted(Path("notas").glob("*.pdf")) pega todos os PDFs de uma pasta em ordem de nome.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
leitor = PdfReader("boletim.pdf")

Exercícios

1. Escreva um programa que mostre quantas páginas tem cada PDF da pasta apostilas.

Ver resposta 
from pathlib import Path
from pypdf import PdfReader

for arquivo in sorted(Path("apostilas").glob("*.pdf")):
    print(arquivo.name, len(PdfReader(arquivo).pages), "páginas")

2. Por que abrimos o arquivo de saída com "wb" e não com "w"?

Ver resposta

Porque PDF é um arquivo binário, não um texto. O modo "wb" grava bytes;
o modo "w" espera textos e daria erro (ou estragaria o arquivo).
