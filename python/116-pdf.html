Para que mexer em PDF pelo Python

Boletins, apostilas, contas e documentos quase sempre chegam em PDF. Fazer à mão tarefas como "juntar 30 PDFs num só" ou "tirar a página 3 de todos os arquivos da pasta" é demorado e cansativo. Com a biblioteca pypdf, um programa de poucas linhas faz isso em segundos.

A pypdf não vem com o Python: é um pacote de terceiros, então esta aula é para o computador.

Instalando e preparando a pasta

Com o ambiente virtual ativado (aula 60):

python -m pip install pypdf

Para treinar, crie uma pasta treino_pdf e coloque nela dois PDFs quaisquer — por exemplo, salve duas páginas da internet com Imprimir → Salvar como PDF e chame de boletim.pdf e atestado.pdf. Rode os programas de dentro dessa pasta.

PDF é um arquivo binário

Um arquivo de texto guarda letras. Um PDF guarda bytes: fontes, imagens e instruções de desenho, misturados. Todo PDF começa com os bytes %PDF-, e é assim que um programa pode desconfiar se um arquivo é PDF de verdade:

def parece_pdf(conteudo):
    return conteudo[:5] == b"%PDF-"

arquivo_pdf = b"%PDF-1.7\n%...bytes do documento..."
arquivo_txt = "Minhas anotações".encode("utf-8")

print(parece_pdf(arquivo_pdf))
print(parece_pdf(arquivo_txt))
print(type(arquivo_pdf).__name__, arquivo_pdf[:8])

True
False
bytes b'%PDF-1.7'

No computador, você leria esses bytes com open("boletim.pdf", "rb").read(5). É por isso que, ao gravar um PDF, usamos o modo "wb" (write binary) e não "w".

Lendo páginas e texto

from pypdf import PdfReader

leitor = PdfReader("boletim.pdf")
print("Páginas:", len(leitor.pages))

primeira = leitor.pages[0]
texto = primeira.extract_text()
print(texto[:60])        # os 60 primeiros caracteres
print("Tem a palavra Matemática?", "Matemática" in texto)

Páginas: 2
Boletim escolar - 1º bimestre
Aluna: Ana Souza
Matemática: 8
Tem a palavra Matemática? True

  • PdfReader(nome) abre o arquivo;
  • leitor.pages funciona como uma lista: tem len, índice [0] e dá para usar no for;
  • extract_text() devolve o texto da página como uma str comum.
Atenção: extract_text só funciona em PDFs que têm texto de verdade. Um documento escaneado é uma foto: o texto vem vazio (""). Para isso seria preciso OCR (reconhecimento de letras em imagens), que é outro assunto.

Juntando PDFs

O PdfWriter é um PDF "em branco" onde você vai colocando páginas. No fim, ele é gravado num arquivo:

from pathlib import Path
from pypdf import PdfReader, PdfWriter

juntos = PdfWriter()
for arquivo in sorted(Path(".").glob("*.pdf")):
    if arquivo.name == "documentos.pdf":
        continue                      # não junta o resultado dentro dele mesmo
    leitor = PdfReader(arquivo)
    for pagina in leitor.pages:
        juntos.add_page(pagina)
    print(arquivo.name, "->", len(leitor.pages), "página(s)")

with open("documentos.pdf", "wb") as f:
    juntos.write(f)
print("Total:", len(juntos.pages), "páginas em documentos.pdf")

atestado.pdf -> 1 página(s)
boletim.pdf -> 2 página(s)
Total: 3 páginas em documentos.pdf

Dica: sorted(...glob("*.pdf")) junta em ordem alfabética. Se a ordem importa, comece os nomes com números: 01_capa.pdf, 02_boletim.pdf…

Dividindo e escolhendo páginas

Para dividir, cada página vai para um PdfWriter próprio. Para tirar só algumas, use fatiamento em leitor.pages, igual a uma lista:

from pypdf import PdfReader, PdfWriter

leitor = PdfReader("documentos.pdf")

# cada página vira um arquivo
for i, pagina in enumerate(leitor.pages, start=1):
    sozinha = PdfWriter()
    sozinha.add_page(pagina)
    with open(f"pagina_{i}.pdf", "wb") as f:
        sozinha.write(f)
    print("gravei", f"pagina_{i}.pdf")

# só as páginas 2 e 3, e a 3 girada
parte = PdfWriter()
for pagina in leitor.pages[1:3]:
    parte.add_page(pagina)
parte.pages[1].rotate(90)
with open("parte.pdf", "wb") as f:
    parte.write(f)
print("parte.pdf com", len(parte.pages), "páginas")

gravei pagina_1.pdf
gravei pagina_2.pdf
gravei pagina_3.pdf
parte.pdf com 2 páginas

Atenção: O Python conta as páginas a partir de 0, mas as pessoas contam a partir de 1. A "página 2" do leitor de PDF é leitor.pages[1]. Esquecer disso tira a página errada.

Programas de PDF costumam pedir as páginas como texto, por exemplo "1-3,5". Transformar esse texto em índices do Python é pura lógica — e roda aqui no site:

def paginas_escolhidas(texto):
    indices = []
    for parte in texto.split(","):
        if "-" in parte:
            inicio, fim = parte.split("-")
            indices.extend(range(int(inicio) - 1, int(fim)))
        else:
            indices.append(int(parte) - 1)
    return indices

print(paginas_escolhidas("1-3,5"))
print(paginas_escolhidas("2"))

[0, 1, 2, 4]
[1]

Com esses índices, bastaria fazer for i in indices: novo.add_page(leitor.pages[i]).

leitor = PdfReader("boletim.pdf")

leitor = PdfReader("boletim.pdf")

4. Complete a função nomes_das_partes(nome, quantidade) para devolver os nomes dos arquivos que um programa de dividir PDF criaria. Exemplo: nomes_das_partes("prova.pdf", 3) deve dar ['prova_1.pdf', 'prova_2.pdf', 'prova_3.pdf'].

Ver resposta 
def nomes_das_partes(nome, quantidade):
    base = nome.removesuffix(".pdf")
    return [f"{base}_{i}.pdf" for i in range(1, quantidade + 1)]

print(nomes_das_partes("prova.pdf", 3))

['prova_1.pdf', 'prova_2.pdf', 'prova_3.pdf']

5. Por que abrimos o arquivo de saída com "wb" e não com "w"? E por que um PDF escaneado devolve texto vazio?

Ver resposta

PDF é um arquivo binário (bytes), não um texto. O modo "wb" grava bytes;
o modo "w" espera str e daria erro.
O PDF escaneado é só uma imagem das páginas: não existem letras guardadas
nele para extrair. Seria preciso OCR para reconhecer o texto da imagem.
