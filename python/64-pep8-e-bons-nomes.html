Código é lido mais vezes do que é escrito

Você escreve um programa uma vez, mas lê (e outras pessoas leem) dezenas de vezes. A PEP 8 é o guia de estilo oficial do Python: um combinado de como formatar o código para que todo programador Python se sinta em casa lendo o código de qualquer outro.

Compare. Os dois programas abaixo fazem exatamente a mesma coisa:

def F(a,b):
  X=a*b/2
  return X
print(F(10,5))

25.0

def area_do_triangulo(base, altura):
    area = base * altura / 2
    return area


print(area_do_triangulo(10, 5))

25.0

O segundo explica a si mesmo. Esse é o objetivo.

Como escrever cada tipo de nome

  • Variáveis e funções: snake_case, tudo minúsculo com _ entre as palavras: nota_final, calcular_media().
  • Classes: PascalCase, cada palavra começando com maiúscula: ContaBancaria, JogoDaVelha.
  • Constantes (valores que não mudam): MAIUSCULAS_COM_UNDERLINE: VELOCIDADE_MAXIMA, PI.
  • Módulos (arquivos): curtos e minúsculos: utilidades.py, jogo.py.
LIMITE_DE_FALTAS = 25


class Estudante:
    def __init__(self, nome, faltas):
        self.nome = nome
        self.faltas = faltas

    def esta_reprovado_por_falta(self):
        return self.faltas > LIMITE_DE_FALTAS


aluno = Estudante("Vitória", 30)
print(aluno.esta_reprovado_por_falta())

True

Bons nomes contam a história

Um bom nome diz o que a coisa é. Fuja de nomes de uma letra (exceto contadores curtos como i) e de abreviações que só você entende.

# Ruim: o que são x, y e z?
x = 3.5
y = 4
z = x * y
print(z)

# Bom: dá para entender sem explicação
preco_do_picole = 3.5
quantidade = 4
total_a_pagar = preco_do_picole * quantidade
print(total_a_pagar)

14.0
14.0

Dica: Funções fazem algo, então comece o nome com um verbo: calcular_frete, enviar_mensagem, mostrar_menu. Para funções que respondem sim ou não, use e_, esta_ ou tem_: esta_vazio, tem_desconto.
Atenção: Nunca use como nome de variável algo que já existe no Python, como list, str, input, sum ou max. Você "apaga" a função original e ganha erros estranhos depois.

Números mágicos viram constantes

Um "número mágico" é um valor solto no meio do código, sem explicação. Quem lê if idade >= 16 não sabe se 16 é a idade para votar, para trabalhar ou outra coisa. Dê um nome a ele:

IDADE_MINIMA_PARA_VOTAR = 16
ANO_ATUAL = 2026


def pode_votar(ano_de_nascimento):
    idade = ANO_ATUAL - ano_de_nascimento
    return idade >= IDADE_MINIMA_PARA_VOTAR


print(pode_votar(2008))
print(pode_votar(2013))

True
False

Se a regra mudar, você troca o valor num lugar só, no topo do arquivo.

Espaços, linhas e indentação

  • Indente com 4 espaços (o VS Code faz isso quando você aperta Tab).
  • Um espaço de cada lado de =, +, -, ==, < e outros operadores: total = preco * 2.
  • Depois da vírgula vai espaço; antes, não: print(a, b).
  • Sem espaço dentro dos parênteses: print(x), não print( x ).
  • Em argumentos nomeados, sem espaço no =: print("a", end="").
  • Linhas com até 79 caracteres; duas linhas em branco antes de cada def ou class do topo do arquivo.
def frete(peso_kg, distancia_km, expresso=False):
    valor = 5 + peso_kg * 0.5 + distancia_km * 0.1
    if expresso:
        valor = valor * 1.5
    return round(valor, 2)


print(frete(2, 100))
print(frete(2, 100, expresso=True))

16.0
24.0

Ferramentas que arrumam por você

Ninguém decora todas as regras. Ferramentas fazem o trabalho (elas são instaladas com o pip, que você conheceu na aula 60): o black reformata o código automaticamente e o ruff aponta problemas de estilo e erros comuns. Instale e rode no terminal, na pasta do projeto:

pip install black ruff
black meu_programa.py
ruff check meu_programa.py

reformatted meu_programa.py
All done! ✨ 🍰 ✨
1 file reformatted.

Dica: No VS Code, instale a extensão Ruff ou Black Formatter e ative "Format on Save" nas configurações: o código fica arrumado sempre que você salva.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
VELOCIDADE_MAXIMA = 110  # km/h na rodovia

porcentagem_aluguel = 0.3

3. Classifique cada nome como bom para variável, função, classe ou constante: ContaPoupanca, TAXA_DE_JUROS, saldo_atual, calcular_rendimento.

Ver resposta

ContaPoupanca       -> classe (PascalCase)
TAXA_DE_JUROS       -> constante (MAIÚSCULAS)
saldo_atual         -> variável (snake_case)
calcular_rendimento -> função (snake_case, começa com verbo)

4. Este código dá erro na última linha. Por quê? list = [3, 1, 2] e depois numeros = list("abc"). Corrija.

Ver resposta 
numeros = [3, 1, 2]
letras = list("abc")
print(numeros, letras)

[3, 1, 2] ['a', 'b', 'c']

Ao usar list como nome de variável, o nome passa a apontar para a lista [3, 1, 2] e a função list() some. Escolha outro nome.

velocidade = 72
