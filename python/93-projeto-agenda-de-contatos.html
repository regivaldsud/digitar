Módulo 4 · Programação orientada a objetos

Aula 93 · Projeto: agenda de contatos com classes

Nesta aula você vai aprender

  • Validar e formatar telefones brasileiros com DDD
  • Criar a classe Contato com __init__ e __str__
  • Criar a classe Agenda, que guarda e organiza os contatos
  • Buscar, remover e listar contatos em ordem alfabética
  • Salvar e carregar a agenda num arquivo JSON

O que vamos construir

Toda pessoa tem uma agenda no celular. Agora você vai construir a sua, em Python, usando orientação a objetos:

  • a classe Contato representa uma pessoa (nome, telefone e e-mail);
  • a classe Agenda representa a coleção de contatos e sabe adicionar, buscar, remover, listar e salvar.

Separar assim deixa cada classe responsável por uma coisa só, e o programa fica fácil de entender e de aumentar.

Passo 1: validar e formatar o telefone

Telefones brasileiros têm DDD com 2 dígitos e número com 8 dígitos (fixo) ou 9 dígitos (celular). Cada pessoa digita de um jeito: 11987654321, (11) 98765-4321, 11 98765 4321. Por isso, primeiro ficamos só com os dígitos:

def so_digitos(texto):
    return "".join(c for c in texto if c.isdigit())


def telefone_valido(texto):
    return len(so_digitos(texto)) in (10, 11)


def formatar_telefone(texto):
    n = so_digitos(texto)
    if len(n) == 11:
        return f"({n[:2]}) {n[2:7]}-{n[7:]}"
    if len(n) == 10:
        return f"({n[:2]}) {n[2:6]}-{n[6:]}"
    return texto


for tel in ["11987654321", "(81) 3222-1234", "21 99876 5432", "12345"]:
    print(tel, "->", telefone_valido(tel), formatar_telefone(tel))

11987654321 -> True (11) 98765-4321
(81) 3222-1234 -> True (81) 3222-1234
21 99876 5432 -> True (21) 99876-5432
12345 -> False 12345

O fatiamento faz todo o trabalho: n[:2] é o DDD, e o resto é dividido em duas partes com o hífen no meio.

Passo 2: a classe Contato

O __init__ confere os dados antes de criar o contato. Se algo estiver errado, ele levanta um ValueError com uma mensagem clara. O __str__ define como o contato aparece no print:

def so_digitos(texto):
    return "".join(c for c in texto if c.isdigit())


def formatar_telefone(texto):
    n = so_digitos(texto)
    if len(n) == 11:
        return f"({n[:2]}) {n[2:7]}-{n[7:]}"
    return f"({n[:2]}) {n[2:6]}-{n[6:]}"


class Contato:
    def __init__(self, nome, telefone, email=""):
        nome = nome.strip()
        if not nome:
            raise ValueError("O nome não pode ficar vazio.")
        if len(so_digitos(telefone)) not in (10, 11):
            raise ValueError(f"Telefone inválido: {telefone}")
        self.nome = nome
        self.telefone = formatar_telefone(telefone)
        self.email = email.strip()

    def __str__(self):
        texto = f"{self.nome} - {self.telefone}"
        if self.email:
            texto += f" - {self.email}"
        return texto

    def para_dict(self):
        return {"nome": self.nome, "telefone": self.telefone, "email": self.email}


maria = Contato("Maria Souza", "11987654321", "maria@email.com")
print(maria)
print(maria.para_dict())

try:
    Contato("Pedro", "123")
except ValueError as erro:
    print("Erro:", erro)

Maria Souza - (11) 98765-4321 - maria@email.com
{'nome': 'Maria Souza', 'telefone': '(11) 98765-4321', 'email': 'maria@email.com'}
Erro: Telefone inválido: 123

O método para_dict transforma o contato num dicionário — é ele que vai permitir salvar a agenda em JSON, porque o json não sabe guardar objetos das nossas classes diretamente.

Passo 3: a classe Agenda

A agenda guarda os contatos num dicionário, usando o nome em minúsculas como chave. Assim, "Maria" e "maria" são reconhecidas como a mesma pessoa e não há contatos repetidos:

class Contato:
    def __init__(self, nome, telefone, email=""):
        self.nome = nome
        self.telefone = telefone
        self.email = email

    def __str__(self):
        return f"{self.nome} - {self.telefone}"


class Agenda:
    def __init__(self):
        self.contatos = {}

    def adicionar(self, contato):
        chave = contato.nome.lower()
        if chave in self.contatos:
            raise ValueError(f"Já existe um contato chamado {contato.nome}.")
        self.contatos[chave] = contato

    def buscar(self, trecho):
        trecho = trecho.lower()
        return [c for c in self.listar() if trecho in c.nome.lower()]

    def remover(self, nome):
        return self.contatos.pop(nome.lower(), None) is not None

    def listar(self):
        return sorted(self.contatos.values(), key=lambda c: c.nome.lower())

    def __len__(self):
        return len(self.contatos)


agenda = Agenda()
agenda.adicionar(Contato("Pedro Alves", "(21) 99876-5432"))
agenda.adicionar(Contato("Ana Lima", "(81) 3222-1234"))
agenda.adicionar(Contato("Carla Dias", "(11) 98765-4321"))

for contato in agenda.listar():
    print(contato)
print("Busca por 'li':", [c.nome for c in agenda.buscar("li")])
print("Removeu Ana?", agenda.remover("ana lima"))
print("Removeu Zeca?", agenda.remover("Zeca"))
print("Contatos:", len(agenda))

Ana Lima - (81) 3222-1234
Carla Dias - (11) 98765-4321
Pedro Alves - (21) 99876-5432
Busca por 'li': ['Ana Lima']
Removeu Ana? True
Removeu Zeca? False
Contatos: 2

  • sorted(..., key=lambda c: c.nome.lower()) ordena pelo nome, sem se importar com maiúsculas.
  • pop(chave, None) remove e devolve o contato, ou devolve None se ele não existir — sem dar erro.
  • O método especial __len__ faz len(agenda) funcionar, como numa lista.
Atenção: A ordenação comum do Python coloca letras acentuadas depois do "z": "Álvaro" apareceria depois de "Zeca". Se isso incomodar, ordene pelo nome sem acentos, usando a função sem_acentos da aula 67 (analisador de texto) — o exercício 2 desta aula mostra como.

Passo 4: salvar e carregar

Para salvar, transformamos cada contato em dicionário. Para carregar, fazemos o caminho de volta, criando um Contato para cada dicionário:

import json


class Contato:
    def __init__(self, nome, telefone, email=""):
        self.nome = nome
        self.telefone = telefone
        self.email = email

    def __str__(self):
        return f"{self.nome} - {self.telefone}"

    def para_dict(self):
        return {"nome": self.nome, "telefone": self.telefone, "email": self.email}


def salvar(contatos, caminho):
    with open(caminho, "w", encoding="utf-8") as arquivo:
        json.dump([c.para_dict() for c in contatos], arquivo, ensure_ascii=False, indent=2)


def carregar(caminho):
    try:
        with open(caminho, encoding="utf-8") as arquivo:
            dados = json.load(arquivo)
    except FileNotFoundError:
        return []
    return [Contato(d["nome"], d["telefone"], d.get("email", "")) for d in dados]


salvar([Contato("João Lima", "(81) 3222-1234", "joao@email.com")], "agenda.json")
for contato in carregar("agenda.json"):
    print(contato)
print(carregar("nao_existe.json"))

João Lima - (81) 3222-1234
[]

O d.get("email", "") garante que o programa não quebra se um contato antigo foi salvo sem e-mail.

Passo 5: o programa completo

Juntamos tudo e colocamos um menu. Repare como o try/except ValueError mostra a mensagem de erro do Contato ou da Agenda sem fechar o programa:

import json

ARQUIVO = "agenda.json"


def so_digitos(texto):
    return "".join(c for c in texto if c.isdigit())


def formatar_telefone(texto):
    n = so_digitos(texto)
    if len(n) == 11:
        return f"({n[:2]}) {n[2:7]}-{n[7:]}"
    return f"({n[:2]}) {n[2:6]}-{n[6:]}"


class Contato:
    def __init__(self, nome, telefone, email=""):
        nome = nome.strip()
        if not nome:
            raise ValueError("O nome não pode ficar vazio.")
        if len(so_digitos(telefone)) not in (10, 11):
            raise ValueError(f"Telefone inválido: {telefone}. Use DDD + número.")
        self.nome = nome
        self.telefone = formatar_telefone(telefone)
        self.email = email.strip()

    def __str__(self):
        texto = f"{self.nome} - {self.telefone}"
        if self.email:
            texto += f" - {self.email}"
        return texto

    def para_dict(self):
        return {"nome": self.nome, "telefone": self.telefone, "email": self.email}


class Agenda:
    def __init__(self, caminho=ARQUIVO):
        self.caminho = caminho
        self.contatos = {}

    def adicionar(self, contato):
        chave = contato.nome.lower()
        if chave in self.contatos:
            raise ValueError(f"Já existe um contato chamado {contato.nome}.")
        self.contatos[chave] = contato
        self.salvar()

    def buscar(self, trecho):
        trecho = trecho.lower()
        return [c for c in self.listar() if trecho in c.nome.lower()]

    def remover(self, nome):
        removido = self.contatos.pop(nome.strip().lower(), None)
        if removido is not None:
            self.salvar()
        return removido is not None

    def listar(self):
        return sorted(self.contatos.values(), key=lambda c: c.nome.lower())

    def __len__(self):
        return len(self.contatos)

    def salvar(self):
        dados = [c.para_dict() for c in self.listar()]
        with open(self.caminho, "w", encoding="utf-8") as arquivo:
            json.dump(dados, arquivo, ensure_ascii=False, indent=2)

    def carregar(self):
        try:
            with open(self.caminho, encoding="utf-8") as arquivo:
                dados = json.load(arquivo)
        except FileNotFoundError:
            return
        for d in dados:
            contato = Contato(d["nome"], d["telefone"], d.get("email", ""))
            self.contatos[contato.nome.lower()] = contato


def mostrar(contatos):
    if not contatos:
        print("Nenhum contato encontrado.")
    for contato in contatos:
        print(" ", contato)


def main():
    agenda = Agenda()
    agenda.carregar()
    print(f"=== AGENDA === ({len(agenda)} contato(s))")
    while True:
        print()
        print("1 - Adicionar  2 - Listar  3 - Buscar  4 - Remover  0 - Sair")
        opcao = input("Escolha: ").strip()
        if opcao == "1":
            nome = input("Nome: ")
            telefone = input("Telefone com DDD: ")
            email = input("E-mail (opcional): ")
            try:
                agenda.adicionar(Contato(nome, telefone, email))
                print("Contato salvo!")
            except ValueError as erro:
                print("Erro:", erro)
        elif opcao == "2":
            mostrar(agenda.listar())
        elif opcao == "3":
            mostrar(agenda.buscar(input("Buscar por: ")))
        elif opcao == "4":
            if agenda.remover(input("Nome completo para remover: ")):
                print("Contato removido.")
            else:
                print("Não achei esse contato.")
        elif opcao == "0":
            print("Agenda salva. Até mais!")
            break
        else:
            print("Opção inválida.")


if __name__ == "__main__":
    main()

1. Crie a função contar_por_ddd(contatos), que recebe uma lista de telefones formatados como "(11) 98765-4321" e devolve um dicionário com quantos contatos há em cada DDD.

Ver resposta 
def contar_por_ddd(telefones):
    contagem = {}
    for tel in telefones:
        ddd = tel[1:3]
        contagem[ddd] = contagem.get(ddd, 0) + 1
    return contagem

2. Faça a busca ignorar acentos e maiúsculas: buscar "joao" deve encontrar "João Lima".

Ver resposta 
import unicodedata


def sem_acentos(texto):
    decomposto = unicodedata.normalize("NFD", texto)
    return "".join(c for c in decomposto if unicodedata.category(c) != "Mn")


def buscar(nomes, trecho):
    trecho = sem_acentos(trecho).lower()
    return [n for n in nomes if trecho in sem_acentos(n).lower()]


nomes = ["João Lima", "Márcia Araújo", "Joana Dias"]
print(buscar(nomes, "joao"))
print(buscar(nomes, "ARAUJO"))
print(buscar(nomes, "jo"))

['João Lima']
['Márcia Araújo']
['João Lima', 'Márcia Araújo', 'Joana Dias']

3. Acrescente à classe Agenda o método atualizar_telefone(nome, novo), que devolve True se conseguiu trocar e False se o contato não existe.

class Contato:
    def __init__(self, nome, telefone):
        self.nome = nome
        self.telefone = telefone

    def __str__(self):
        return f"{self.nome} - {self.telefone}"


class Agenda:
    def __init__(self):
        self.contatos = {}

    def adicionar(self, contato):
        self.contatos[contato.nome.lower()] = contato

    def atualizar_telefone(self, nome, novo):
        contato = self.contatos.get(nome.lower())
        if contato is None:
            return False
        contato.telefone = novo
        return True

import csv

contatos = [
    {"nome": "Maria Souza", "telefone": "(11) 98765-4321", "email": "maria@email.com"},
    {"nome": "João Lima", "telefone": "(81) 3222-1234", "email": ""},

with open("contatos.csv", "w", encoding="utf-8", newline="") as arquivo:
    escritor = csv.DictWriter(arquivo, fieldnames=["nome", "telefone", "email"])
    escritor.writeheader()
    escritor.writerows(contatos)

with open("contatos.csv", encoding="utf-8") as arquivo:
