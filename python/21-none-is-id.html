None: o valor do "nada"

Às vezes uma variável precisa existir, mas ainda não tem valor. Para isso o Python tem o None (nenhum). Ele é o único valor do tipo NoneType:

vencedor = None
print(vencedor)
print(type(vencedor))
print(bool(None))

None
<class 'NoneType'>
False

Pense num campeonato que ainda não acabou: o vencedor existe como informação, mas ainda é "ninguém". None também conta como falso em bool().

Atenção: None é diferente de 0, de "" (texto vazio) e de False. Zero é um número, texto vazio é um texto. None significa "não tem valor nenhum".

Funções que não devolvem nada

Algumas funções fazem uma tarefa mas não devolvem resultado. Quando isso acontece, o resultado é None. O print é um exemplo:

resultado = print("Olá!")
print(resultado)

Olá!
None

O primeiro print mostra Olá!, mas o valor que ele devolve é None. Você vai entender melhor isso na aula 40, quando criar suas próprias funções.

Testando None com is

Para saber se algo é None, o jeito recomendado é usar is (é) e is not (não é):

apelido = None
if apelido is None:
    print("Você ainda não escolheu um apelido.")
apelido = "Juju"
if apelido is not None:
    print(f"Seu apelido é {apelido}.")

Você ainda não escolheu um apelido.
Seu apelido é Juju.

Dica: Leia x is None como "x é o None". Funciona com == também, mas os guias de estilo do Python pedem is None e is not None.

Identidade: a função id

Cada valor guardado na memória do computador tem uma identidade, um número único enquanto o programa roda. A função id() mostra esse número:

cidade = "Recife"
print(id(cidade))
outra = cidade
print(id(outra))
print(id(cidade) == id(outra))

(exemplo — a sua saída pode ser diferente)
2470096279408
2470096279408
True

O número muda a cada execução, mas repare que cidade e outra têm o mesmo id: as duas variáveis são etiquetas coladas na mesma caixinha.

== compara valor, is compara identidade

  • a == b pergunta: os valores são iguais?
  • a is b pergunta: é o mesmo objeto na memória (mesmo id)?
a = [1, 2, 3]
b = [1, 2, 3]
c = a
print(a == b)
print(a is b)
print(a is c)

True
False
True

[1, 2, 3] é uma lista (você vai estudar listas na aula 25). a e b têm o mesmo conteúdo, então a == b é True. Mas são duas listas diferentes, criadas separadamente, então a is b é False. Já c é outro nome para a mesma lista de a.

Atenção: Não use is para comparar números ou textos. x is 1000 pode dar resultados inesperados (e o Python até avisa com SyntaxWarning). Para valores, use ==. Guarde o is para None, True e False.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
if apelido is None: print("Sem apelido")
