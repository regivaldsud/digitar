Aula 108 · string.Template e variáveis de ambiente (.env)

string.Template

Você já conhece as f-strings (aula 16). Elas são ótimas quando o texto está no código. Mas às vezes o modelo do texto vem de fora — de um arquivo, ou escrito por outra pessoa. Para isso existe o string.Template, que troca $nome pelo valor:

from string import Template

modelo = Template("Olá, $nome! Seu pedido de $item chega em $dias dias.")
print(modelo.substitute(nome="Rafa", item="tênis", dias=3))

dados = {"nome": "Lu", "item": "mochila", "dias": 5}
print(modelo.substitute(dados))

Olá, Rafa! Seu pedido de tênis chega em 3 dias.
Olá, Lu! Seu pedido de mochila chega em 5 dias.

Use ${nome} quando a variável estiver grudada em outras letras, e $$ para escrever um cifrão de verdade:

from string import Template

preco = Template("${produto}s em promoção: $$ ${valor}")
print(preco.substitute(produto="Caderno", valor="9,90"))

incompleto = Template("Oi, $nome. Você tem $pontos pontos.")
print(incompleto.safe_substitute(nome="Gui"))

Cadernos em promoção: $ 9,90
Oi, Gui. Você tem $pontos pontos.

Atenção: substitute dá KeyError se faltar algum valor. safe_substitute não dá erro: ele deixa o $pontos no texto como estava.
Dica: Por que não usar f-string num modelo vindo de fora? Porque uma f-string executa expressões Python. Um Template só troca nomes — é mais seguro para textos que o usuário pode editar.

Variáveis de ambiente

Todo programa roda dentro de um ambiente com variáveis próprias, fora do código: o nome do usuário, a pasta de trabalho, configurações. O Python lê essas variáveis pelo dicionário os.environ:

import os

modo = os.environ.get("MODO_DO_APP", "teste")
print("Rodando no modo:", modo)

Rodando no modo: teste

Como MODO_DO_APP não foi definida, get devolveu o valor padrão "teste". No terminal do Windows (PowerShell), você define a variável antes de rodar o programa:

$env:MODO_DO_APP = "producao"
python app.py

No Linux e no macOS: MODO_DO_APP=producao python app.py.

O arquivo .env

Senhas e chaves de API nunca devem ficar escritas no código: se você publicar o código no GitHub, todo mundo vê. O costume é guardá-las num arquivo .env na pasta do projeto e colocar .env no .gitignore (aula 244).

Um .env é só um texto com linhas NOME=valor. Este exemplo mostra a ideia lendo um .env à mão:

from pathlib import Path

Path(".env").write_text("CHAVE_API=abc123\nCIDADE=Natal\n# comentário\n", encoding="utf-8")

config = {}
for linha in Path(".env").read_text(encoding="utf-8").splitlines():
    linha = linha.strip()
    if linha and not linha.startswith("#"):
        nome, valor = linha.split("=", 1)
        config[nome] = valor

print(config["CIDADE"])
print("Chave carregada?", "CHAVE_API" in config)

Natal
Chave carregada? True

No dia a dia, use a biblioteca python-dotenv, que faz isso e coloca os valores em os.environ:

pip install python-dotenv
import os
from dotenv import load_dotenv

load_dotenv()                       # lê o .env da pasta atual
chave = os.environ["CHAVE_API"]     # KeyError se a variável não existir

Na aula 177 você usa essa ideia para guardar a senha de um banco de dados.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
msg = Template("Olá, $nome!").substitute(nome="Ana")

Exercícios

1. Crie um modelo de convite de aniversário com $nome, $data e $local e preencha para duas pessoas diferentes usando um for.

Ver resposta 
from string import Template

convite = Template("$nome, venha à minha festa em $data, no $local!")
for nome in ["Duda", "Enzo"]:
    print(convite.substitute(nome=nome, data="12/12", local="salão do prédio"))

Duda, venha à minha festa em 12/12, no salão do prédio!
Enzo, venha à minha festa em 12/12, no salão do prédio!

2. Leia a variável de ambiente IDIOMA e, se ela não existir, use "pt-BR". Mostre o resultado.

Ver resposta 
import os

print(os.environ.get("IDIOMA", "pt-BR"))

pt-BR

3. Por que o arquivo .env deve estar no .gitignore?

Ver resposta

Porque ele guarda senhas e chaves. Se ele for para o Git e o projeto
for publicado no GitHub, qualquer pessoa pode copiar essas senhas.
