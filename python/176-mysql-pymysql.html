Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Por que um servidor de banco

O SQLite guarda tudo num arquivo usado por um programa de cada vez. Para um sistema escolar com dezenas de pessoas usando ao mesmo tempo, ou um site com milhares de visitas, usamos um servidor de banco de dados: um programa que fica ligado o tempo todo e atende vários programas ao mesmo tempo, inclusive pela rede.

O MySQL e o PostgreSQL são os servidores gratuitos mais usados. Seu programa Python é o cliente: ele se conecta ao servidor informando o endereço (host), a porta, o usuário, a senha e o nome do banco.

A boa notícia: pelo jeito DB-API que você viu na aula 174, o código Python muda muito pouco.

Subindo o MySQL com Docker

Instalar um servidor de banco à mão dá trabalho. O Docker roda programas prontos dentro de contêineres, caixinhas isoladas que você liga e desliga com um comando (a aula 210 aprofunda o Docker).

Instale o Docker Desktop pelo site docker.com, abra o programa e espere ele dizer que está rodando. Depois, no terminal:

docker run --name mysql-curso -e MYSQL_ROOT_PASSWORD=troque_esta_senha -e MYSQL_DATABASE=escola -p 3306:3306 -v dados-mysql:/var/lib/mysql -d mysql:8
docker ps

O que cada parte faz:

  • --name mysql-curso dá um nome ao contêiner, para você ligar e desligar depois;
  • -e MYSQL_ROOT_PASSWORD=... define a senha do usuário root, e -e MYSQL_DATABASE=escola já cria o banco escola;
  • -p 3306:3306 liga a porta 3306 do contêiner (a porta padrão do MySQL) à porta 3306 do seu computador;
  • -v dados-mysql:/var/lib/mysql cria um volume: os dados ficam guardados mesmo se o contêiner for apagado;
  • -d deixa o servidor rodando em segundo plano, e mysql:8 é a imagem (MySQL versão 8).

Os outros comandos do dia a dia:

docker stop mysql-curso
docker start mysql-curso
docker logs mysql-curso
Atenção: Na primeira vez, o MySQL leva uns 20 a 30 segundos para ficar pronto. Se o Python mostrar Can't connect to MySQL server ou Lost connection, espere um pouco e tente de novo. Se aparecer erro de porta já em uso, outro MySQL está ligado no seu computador: troque para -p 3307:3306 e use port=3307 no Python.

Conectando com pymysql

O pymysql é uma biblioteca escrita só em Python que conversa com o MySQL. Dentro do seu ambiente virtual (aula 60), instale:

py -m pip install pymysql
python3 -m pip install pymysql

(A primeira linha é para Windows; a segunda, para Linux e macOS.) Salve como mysql_teste.py e rode com python mysql_teste.py:

import pymysql

con = pymysql.connect(
    host="localhost",
    port=3306,
    user="root",
    password="troque_esta_senha",
    database="escola",
)
with con:
    with con.cursor() as cur:
        cur.execute("""CREATE TABLE IF NOT EXISTS alunos (
            id INT AUTO_INCREMENT PRIMARY KEY,
            nome VARCHAR(80) NOT NULL,
            idade INT
        )""")
        cur.execute("INSERT INTO alunos (nome, idade) VALUES (%s, %s)", ("Ana", 12))
        print("id gerado:", cur.lastrowid)
    con.commit()

    with con.cursor() as cur:
        cur.execute("SELECT id, nome, idade FROM alunos")
        for linha in cur.fetchall():
            print(linha)

id gerado: 1
(1, 'Ana', 12)

Cada vez que você roda, entra mais uma Ana, com id 2, 3... porque o banco agora é um servidor que guarda tudo.

  • with con: fecha a conexão no fim; with con.cursor() as cur: fecha o cursor.
  • No pymysql é obrigatório o con.commit() para gravar. Sem ele, o INSERT é desfeito quando a conexão fecha.
Atenção: No pymysql o placeholder é %s (para qualquer tipo, até número), não ?. Mesmo parecendo formatação de texto, ele é seguro porque você passa os valores separados, como na aula 175. Nunca use o % do Python para montar o comando: "... VALUES ('%s')" % nome volta a abrir a porta para o SQL Injection.

Quando a conexão falha

Com um servidor, a conexão pode falhar: o Docker está desligado, a senha está errada ou o MySQL ainda está ligando. Em vez de deixar o programa quebrar com uma mensagem enorme, trate o erro e explique o que fazer:

import pymysql

try:
    con = pymysql.connect(host="localhost", user="root",
                          password="senha_errada", database="escola",
                          connect_timeout=5)
except pymysql.err.OperationalError as erro:
    codigo = erro.args[0]
    if codigo == 1045:
        print("Usuário ou senha incorretos.")
    elif codigo == 2003:
        print("Servidor desligado. Rode: docker start mysql-curso")
    else:
        print("Não consegui conectar:", erro)
else:
    print("Conectado!")
    con.close()

Usuário ou senha incorretos.

O código 1045 é o erro de acesso negado do MySQL e o 2003 significa que ninguém atendeu na porta 3306 (servidor desligado ou porta errada).

Linhas como dicionários: DictCursor

O sqlite3.Row da aula 174 tem um primo no pymysql: o DictCursor, que devolve cada linha como dicionário:

import pymysql
import pymysql.cursors

con = pymysql.connect(host="localhost", user="root", password="troque_esta_senha",
                      database="escola", cursorclass=pymysql.cursors.DictCursor)
with con:
    with con.cursor() as cur:
        cur.execute("SELECT nome, idade FROM alunos WHERE idade >= %s ORDER BY nome", (12,))
        for aluno in cur.fetchall():
            print(aluno["nome"], "tem", aluno["idade"], "anos")

Ana tem 12 anos

O mesmo código com sqlite3

Para ver como a ideia é a mesma, aqui está o programa anterior com sqlite3, que você pode rodar agora no navegador. Compare linha por linha:

import sqlite3

con = sqlite3.connect(":memory:")
con.row_factory = sqlite3.Row
cur = con.cursor()
cur.execute("""CREATE TABLE IF NOT EXISTS alunos (
    id INTEGER PRIMARY KEY,
    nome VARCHAR(80) NOT NULL,
    idade INT
)""")
cur.execute("INSERT INTO alunos (nome, idade) VALUES (?, ?)", ("Ana", 12))
print("id gerado:", cur.lastrowid)
con.commit()

cur.execute("SELECT nome, idade FROM alunos WHERE idade >= ? ORDER BY nome", (12,))
for aluno in cur.fetchall():
    print(aluno["nome"], "tem", aluno["idade"], "anos")
cur.close()
con.close()

id gerado: 1
Ana tem 12 anos

As diferenças principais:

  • sqlite3.connect("arquivo.db") vira pymysql.connect(host=..., user=..., password=..., database=...);
  • o placeholder ? vira %s;
  • INTEGER PRIMARY KEY vira INT AUTO_INCREMENT PRIMARY KEY, e textos costumam ter tamanho máximo: VARCHAR(80);
  • sqlite3.Row vira DictCursor.

O resto do SQL (SELECT, WHERE, JOIN, GROUP BY) e o roteiro conectar, executar, buscar, commit e fechar continuam iguais.

Dica: Uma boa ideia é escrever e testar a lógica do seu programa com sqlite3 e só depois trocar para o MySQL. Se você usar funções como as da aula 174, só a função que abre a conexão e os placeholders mudam.

Docker Compose: o comando guardado num arquivo

Aquele docker run comprido é fácil de errar. O Docker Compose guarda a configuração num arquivo compose.yaml na pasta do projeto:

services:
  banco:
    image: mysql:8
    environment:
      MYSQL_ROOT_PASSWORD: troque_esta_senha
      MYSQL_DATABASE: escola
    ports:
      - "3306:3306"
    volumes:
      - dados-mysql:/var/lib/mysql
volumes:
  dados-mysql:

Na pasta desse arquivo, docker compose up -d liga o banco e docker compose down desliga (os dados continuam no volume).

Dica: A senha não deveria ficar escrita nem no código Python nem no compose.yaml que vai para o GitHub. A aula 177 mostra como guardar tudo num arquivo .env.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
cur.execute("INSERT INTO alunos (nome) VALUES (%s)", (nome,))

3. Converta este trecho de sqlite3 para pymysql (só os comandos): cur.execute("UPDATE alunos SET idade = ? WHERE id = ?", (13, 1)) seguido de con.commit().

Ver resposta 
cur.execute("UPDATE alunos SET idade = %s WHERE id = %s", (13, 1))
con.commit()

4. Para que serve o -v dados-mysql:/var/lib/mysql no docker run? O que aconteceria sem ele se você apagasse o contêiner com docker rm mysql-curso?

Ver resposta

Ele cria um volume chamado dados-mysql, um lugar fora do contêiner onde o MySQL
guarda os arquivos do banco. Sem o volume, os dados ficam dentro do contêiner e
somem junto com ele quando ele é apagado com docker rm.

5. Escreva a função inserir_aluno(con, nome, idade) para pymysql que insere o aluno, grava com commit e devolve o id gerado.

Ver resposta 
def inserir_aluno(con, nome, idade):
    with con.cursor() as cur:
        cur.execute("INSERT INTO alunos (nome, idade) VALUES (%s, %s)", (nome, idade))
        novo_id = cur.lastrowid
    con.commit()
    return novo_id
