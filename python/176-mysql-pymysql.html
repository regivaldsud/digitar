Aula 176 · MySQL com pymysql e Docker

Nesta aula você vai aprender

  • Subir um servidor MySQL com Docker
  • Instalar e usar a biblioteca pymysql
  • Ver o que muda do SQLite para o MySQL
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Por que MySQL

O SQLite é um arquivo usado por um programa. O MySQL é um servidor: um programa que fica rodando e atende muitos programas ao mesmo tempo, até pela rede. Sites e sistemas grandes usam servidores assim (MySQL, PostgreSQL).

Subindo o MySQL com Docker

O Docker roda programas prontos dentro de "contêineres", sem instalação complicada. Instale o Docker Desktop (docker.com), abra-o e, no terminal, rode:

docker run --name mysql-curso -e MYSQL_ROOT_PASSWORD=troque_esta_senha -e MYSQL_DATABASE=escola -p 3306:3306 -d mysql:8
docker ps

O -p 3306:3306 libera a porta do MySQL no seu computador e -d deixa rodando em segundo plano. Para parar: docker stop mysql-curso; para ligar de novo: docker start mysql-curso.

Conectando com pymysql

Dentro do seu ambiente virtual (aula 60), instale a biblioteca:

pip install pymysql
import pymysql

con = pymysql.connect(
    host="localhost",
    user="root",
    password="troque_esta_senha",
    database="escola",
)
with con:
    with con.cursor() as cur:
        cur.execute("CREATE TABLE IF NOT EXISTS alunos (id INT AUTO_INCREMENT PRIMARY KEY, nome VARCHAR(80))")
        cur.execute("INSERT INTO alunos (nome) VALUES (%s)", ("Ana",))
    con.commit()
    with con.cursor() as cur:
        cur.execute("SELECT id, nome FROM alunos")
        for linha in cur.fetchall():
            print(linha)
Atenção: No pymysql o placeholder é %s, não ?. Mesmo parecendo formatação de texto, ele é seguro: passe os valores separados, como na aula 175. Nunca use % do Python para montar o comando.
Dica: Não deixe a senha escrita no código que vai para o GitHub. A aula 177 mostra como guardá-la num arquivo .env.

O que muda do SQLite

  • INTEGER PRIMARY KEY vira INT AUTO_INCREMENT PRIMARY KEY.
  • Textos costumam ter tamanho: VARCHAR(80).
  • É preciso commit() para gravar, como no SQLite em arquivo.
  • O resto do SQL (SELECT, WHERE, JOIN, GROUP BY) é praticamente igual.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
cur.execute("INSERT INTO alunos (nome) VALUES (%s)", (nome,))
