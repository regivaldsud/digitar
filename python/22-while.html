Aula 22 · Repetição com while, break, continue, while/else

Nesta aula você vai aprender

  • Repetir um bloco de código com while
  • Controlar as voltas com um contador e somar valores com um acumulador

  • Usar while True com segurança e entender o else do laço

Repetir sem copiar e colar

Imagine mostrar os números de 1 a 100. Escrever 100 vezes print seria cansativo — até para quem digita rápido! O while (enquanto) repete um bloco enquanto a condição for verdadeira.

contador = 1
while contador <= 5:
    print(contador)
    contador = contador + 1
print("Acabou!")

1
2
3
4
5
Acabou!

A cada volta (chamada de iteração), o Python testa contador <= 5. Se for verdade, roda o bloco recuado e volta para testar de novo. Quando o contador chega a 6, a condição fica falsa e o programa segue para a linha de baixo.

Dica: Escrever contador = contador + 1 é tão comum que existe um atalho: contador += 1. Você vai conhecer todos esses atalhos na aula 23; a partir dela, vamos usá-los o tempo todo.

Acumulando valores

Uma variável acumuladora começa em zero e vai somando algo a cada volta. Veja quanto você guarda juntando R$ 5 por semana durante 10 semanas:

semana = 1
total = 0
while semana <= 10:
    total = total + 5
    semana = semana + 1
print(f"Em 10 semanas você juntou R$ {total}")

Em 10 semanas você juntou R$ 50

Às vezes você não sabe quantas vezes vai repetir. Um jeito comum é repetir até a pessoa digitar um valor especial, chamado sentinela. Aqui, o laço soma preços até a pessoa digitar 0:

total = 0
preco = float(input("Preço do item (0 para terminar): "))
while preco != 0:
    total = total + preco
    preco = float(input("Preço do item (0 para terminar): "))
print(f"Total da compra: R$ {total:.2f}")

(exemplo digitando 12.5, 8, 4.5, 0)
Preço do item (0 para terminar): 12.5
Preço do item (0 para terminar): 8
Preço do item (0 para terminar): 4.5
Preço do item (0 para terminar): 0
Total da compra: R$ 25.00

break: parar agora

O break interrompe o laço imediatamente, mesmo que a condição ainda seja verdadeira. O programa continua na primeira linha depois do laço.

numero = 1
while numero < 100:
    if numero * numero > 50:
        print(f"{numero} é o primeiro número cujo quadrado passa de 50")
        break
    numero = numero + 1
print("Busca encerrada.")

8 é o primeiro número cujo quadrado passa de 50
Busca encerrada.

Um padrão muito usado é o laço "para sempre", while True, que só termina com break. Fica fácil de ler: "repita até a pessoa digitar sair".

itens = 0
while True:
    item = input("Item da lista (ou 'sair'): ")
    if item == "sair":
        break
    itens = itens + 1
    print(f"Anotado: {item}")
print(f"Você anotou {itens} itens.")

(exemplo digitando arroz, feijão, farofa, sair)
Item da lista (ou 'sair'): arroz
Anotado: arroz
Item da lista (ou 'sair'): feijão
Anotado: feijão
Item da lista (ou 'sair'): farofa
Anotado: farofa
Item da lista (ou 'sair'): sair
Você anotou 3 itens.

Atenção: Todo while True precisa de um break que realmente aconteça. Se a condição do break nunca for verdadeira, você criou um laço infinito.

continue: pular esta volta

O continue não sai do laço: ele pula o resto do bloco nesta volta e volta direto para o teste da condição. Aqui somamos números digitados: negativos são ignorados com continue, e o 0 encerra com break.

soma = 0
while True:
    n = int(input("Número (0 para parar): "))
    if n == 0:
        break
    if n < 0:
        print("Negativo ignorado.")
        continue
    soma = soma + n
print("Soma:", soma)

(exemplo digitando 10, -3, 5, 0)
Número (0 para parar): 10
Número (0 para parar): -3
Negativo ignorado.
Número (0 para parar): 5
Número (0 para parar): 0
Soma: 15

Atenção: Com continue num while, cuidado para não pular a linha que atualiza o contador. Se o continue vier antes de contador = contador + 1, o contador nunca muda e o laço não termina.

O else do while

Um while pode ter um else, que roda só se o laço terminar normalmente, ou seja, quando a condição ficar falsa — e não roda se o laço foi interrompido por break. É útil em buscas e tentativas: "tentei tudo e não consegui".

tentativas = 3
while tentativas > 0:
    senha = input("Senha do cofre: ")
    if senha == "4321":
        print("Cofre aberto!")
        break
    tentativas = tentativas - 1
    print(f"Senha errada. Restam {tentativas} tentativas.")
else:
    print("Cofre bloqueado!")

(exemplo digitando 1234, 0000, 9999)
Senha do cofre: 1234
Senha errada. Restam 2 tentativas.
Senha do cofre: 0000
Senha errada. Restam 1 tentativas.
Senha do cofre: 9999
Senha errada. Restam 0 tentativas.
Cofre bloqueado!

O for, que você verá na aula 24, também aceita else, com a mesma regra.

Cuidado com o laço infinito

Se a condição nunca ficar falsa, o laço nunca termina. Isso é um laço infinito, e o programa fica "travado". Veja o erro clássico: esquecemos de aumentar o contador.

contador = 1
while contador <= 5:
    print(contador)
# contador nunca muda: mostra 1 para sempre!
Atenção: Se um programa travar num laço infinito no terminal, aperte Ctrl+C para interrompê-lo. No navegador, recarregue a página.
Dica: Antes de rodar um while, pergunte-se: "o que, dentro do bloco, faz a condição ficar falsa um dia (ou faz o break acontecer)?". Se a resposta for "nada", você tem um laço infinito.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
while contador <= 10: contador = contador + 1

5. Peça notas até a pessoa digitar -1. Ignore com continue as notas maiores que 10 (avisando "Nota inválida") e, no fim, mostre a média das notas válidas.

Ver resposta 
soma = 0
quantidade = 0
while True:
    nota = float(input("Nota (-1 para sair): "))
    if nota == -1:
        break
    if nota > 10:
        print("Nota inválida")
        continue
    soma = soma + nota
    quantidade = quantidade + 1
if quantidade > 0:
    print(f"Média: {soma / quantidade:.2f}")
else:
    print("Nenhuma nota digitada")

(exemplo digitando 8, 12, 6.5, 9, -1)

Nota (-1 para sair): 12
Nota inválida
Nota (-1 para sair): 6.5
Nota (-1 para sair): 9
Nota (-1 para sair): -1
Média: 7.83
