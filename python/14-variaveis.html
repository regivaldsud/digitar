Aula 14 · Variáveis e nomes em snake_case

Nesta aula você vai aprender

  • Criar variáveis com = e usá-las depois
  • Mudar o valor de uma variável
  • Seguir as regras para nomes e o estilo snake_case
  • Criar e trocar várias variáveis numa linha só

Variável é uma caixinha com nome

Uma variável guarda um valor para usar depois. Pense numa caixinha com uma etiqueta: a etiqueta é o nome, e dentro está o valor. Para criar, use o sinal =:

nome = "Júlia"
idade = 13
print(nome)
print(idade)
print(nome, "tem", idade, "anos")

Júlia
13
Júlia tem 13 anos

O = em Python não é o "igual" da matemática: ele quer dizer "guarde o valor da direita na variável da esquerda". Leia idade = 13 como "idade recebe 13".

Atenção: Usar uma variável antes de criá-la dá NameError: name '...' is not defined. O Python lê de cima para baixo, então a linha com = precisa vir antes do uso. Confira também se não há erro de digitação no nome.

Mudando o valor

Uma variável pode mudar de valor (por isso o nome "variável"). O valor antigo é substituído:

placar = 0
print("Começo do jogo:", placar)
placar = 1
print("Depois do gol:", placar)
placar = placar + 1
print("Depois do segundo gol:", placar)

Começo do jogo: 0
Depois do gol: 1
Depois do segundo gol: 2

A linha placar = placar + 1 parece estranha, mas é muito comum: o Python calcula primeiro o lado direito (1 + 1) e depois guarda o resultado em placar.

A variável não tem tipo fixo

O tipo pertence ao valor, não à variável. A mesma variável pode guardar um número e, depois, um texto:

coisa = 10
print(coisa, type(coisa))
coisa = "dez"
print(coisa, type(coisa))

10 <class 'int'>
dez <class 'str'>

Isso é permitido, mas evite: fica confuso para quem lê o código.

Regras para nomes

Os nomes de variáveis seguem regras:

  • podem ter letras, números e o sublinhado _;
  • não podem começar com número (1lugar é inválido; lugar1 é válido);
  • não podem ter espaços nem hífen (nota-final é inválido);
  • não podem ser palavras reservadas do Python, como if, for, True;
  • maiúsculas e minúsculas são diferentes: nome e Nome são duas variáveis.

Em Python, a convenção é usar letras minúsculas e separar as palavras com _. Esse estilo se chama snake_case (de *snake*, cobra, porque o nome fica comprido e "rastejando" no chão):

nota_final = 8.5
nome_do_aluno = "Pedro"
total_de_pontos = 120
print(nome_do_aluno, nota_final, total_de_pontos)

Pedro 8.5 120

Dica: Escolha nomes que digam o que a variável guarda. preco_do_lanche é muito melhor que p ou x. Evite acentos nos nomes: o Python aceita, mas em muitos projetos isso causa confusão.

Várias variáveis de uma vez

Dá para criar várias variáveis numa linha só, separando nomes e valores por vírgula:

x, y = 10, 20
print(x, y)
x, y = y, x
print(x, y)
a = b = 0
print(a, b)

10 20
20 10
0 0

A linha x, y = y, x troca os valores das duas variáveis. E a = b = 0 dá o mesmo valor para as duas.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
nome_do_aluno = "Pedro"

Exercícios

1. Crie variáveis para guardar o nome de um filme, o ano de lançamento e a nota que você dá (com casa decimal). Mostre as três.

Ver resposta 
filme = "Central do Brasil"
ano = 1998
nota = 9.5
print(filme, ano, nota)

Central do Brasil 1998 9.5

2. Quais destes nomes são inválidos e por quê: idade, 2ano, nome completo, _contador, preco-total, cidade2?

Ver resposta

Inválidos: 2ano (começa com número), nome completo (tem espaço)
e preco-total (tem hífen). Os outros são válidos.

3. Uma variável moedas começa com 5. O jogador ganha 3 moedas e depois gasta 2. Use moedas = moedas + ... e moedas = moedas - ... e mostre o valor final.

Ver resposta 
moedas = 5
moedas = moedas + 3
moedas = moedas - 2
print("Moedas:", moedas)

Moedas: 6

4. Troque os valores de a = "café" e b = "leite" usando uma linha só, e mostre o resultado.

Ver resposta 
a = "café"
b = "leite"
a, b = b, a
print(a, b)

leite café

5. Reescreva em snake_case os nomes NomeDoCliente, VALORTOTAL e diaDoPagamento, criando as variáveis com valores de exemplo.

Ver resposta 
nome_do_cliente = "Carla"
valor_total = 89.9
dia_do_pagamento = 10
print(nome_do_cliente, valor_total, dia_do_pagamento)

Carla 89.9 10
