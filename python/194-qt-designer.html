Módulo 10 · Interface gráfica com PySide6

Aula 194 · Telas no Qt Designer (.ui)

Nesta aula você vai aprender

  • Abrir o Qt Designer que vem com o PySide6
  • Salvar uma tela como arquivo .ui e dar nomes aos widgets
  • Carregar o .ui com QUiLoader ou convertê-lo com pyside6-uic
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Desenhar em vez de programar a tela

O Qt Designer é um programa onde você monta a tela arrastando botões, caixas e rótulos com o mouse. Ele já vem junto com o PySide6. Com o ambiente virtual ativado, abra assim:

pyside6-designer

Escolha Main Window ou Widget, arraste um Push Button e um Line Edit, e no painel Property Editor mude o objectName deles para botao_enviar e campo_nome. Salve como tela.ui.

Atenção: O objectName é o nome que você vai usar no código. Nomes como pushButton_3 ficam confusos; troque por nomes claros em snake_case.

Jeito 1: carregar o .ui na hora

import sys
from PySide6.QtCore import QFile
from PySide6.QtUiTools import QUiLoader
from PySide6.QtWidgets import QApplication

app = QApplication(sys.argv)
arquivo = QFile("tela.ui")
arquivo.open(QFile.OpenModeFlag.ReadOnly)
janela = QUiLoader().load(arquivo)
arquivo.close()

janela.botao_enviar.clicked.connect(
    lambda: print("Olá,", janela.campo_nome.text())
)
janela.show()
sys.exit(app.exec())

Jeito 2: converter para Python

O comando pyside6-uic transforma o .ui num arquivo .py com uma classe pronta:

pyside6-uic tela.ui -o ui_tela.py
import sys
from PySide6.QtWidgets import QApplication, QMainWindow
from ui_tela import Ui_MainWindow


class Janela(QMainWindow, Ui_MainWindow):
    def __init__(self):
        super().__init__()
        self.setupUi(self)
        self.botao_enviar.clicked.connect(self.enviar)

    def enviar(self):
        print("Olá,", self.campo_nome.text())


app = QApplication(sys.argv)
janela = Janela()
janela.show()
sys.exit(app.exec())
Dica: Nunca edite o ui_tela.py gerado: na próxima conversão ele é sobrescrito. Mude a tela no Designer e converta de novo.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
pyside6-uic tela.ui -o ui_tela.py

Exercícios

1. Você mudou a tela no Designer e salvou o tela.ui. Usando o jeito 2, o que precisa fazer para a mudança aparecer no programa?

Ver resposta 
pyside6-uic tela.ui -o ui_tela.py
python main.py

Converta de novo o .ui e rode o programa. No jeito 1 isso não é preciso, porque o .ui é lido toda vez que o programa abre.

2. Escreva o slot limpar para um botão botao_limpar que apaga o texto de campo_nome (classe do jeito 2).

Ver resposta 
# no __init__: self.botao_limpar.clicked.connect(self.limpar)

def limpar(self):
    self.campo_nome.clear()
