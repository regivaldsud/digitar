Desenhar em vez de programar a tela

Nas aulas 190 a 193 você criou cada botão e cada layout escrevendo código. Isso funciona, mas numa tela com 30 campos o código fica enorme, e para mudar um botão de lugar você precisa rodar o programa várias vezes até acertar.

O Qt Designer é um programa onde você monta a tela arrastando botões, caixas de texto e rótulos com o mouse, e vê o resultado na hora. Ele salva a tela num arquivo com a extensão .ui. O seu código Python continua fazendo a parte importante: o que acontece quando o usuário clica.

Essa separação é boa: o "desenho" fica num arquivo e o "comportamento" fica em outro. Dá até para uma pessoa cuidar da tela e outra do código.

Abrindo o Qt Designer

O Designer já vem junto com o PySide6. Com o ambiente virtual do projeto ativado (aula 60), instale o PySide6 (se ainda não tiver) e abra o Designer:

pip install pyside6
pyside6-designer

Na janela New Form, escolha Widget e clique em Create. Depois:

  • arraste da caixa Widget Box (à esquerda) um Label, um Line Edit e um Push Button para dentro do formulário;
  • dê dois cliques no Label e escreva Digite seu nome:; faça o mesmo no botão e escreva Enviar;
  • clique com o botão direito num espaço vazio do formulário e escolha Lay out → Lay Out Vertically: os widgets se alinham e passam a acompanhar o tamanho da janela;
  • salve com Ctrl+S como tela.ui, na pasta do seu projeto.
Dica: Use Ctrl+R no Designer para ver uma prévia da tela funcionando, sem escrever nenhuma linha de código.

Nomes que fazem sentido: objectName

Cada widget tem uma propriedade chamada objectName. É por esse nome que o seu código vai encontrar o widget. O Designer inventa nomes como pushButton, lineEdit_2 e label_3, que não dizem nada.

Clique em cada widget e, no painel Property Editor (à direita), troque o objectName: titulo para o Label, campo_nome para o Line Edit e botao_enviar para o botão. Use o mesmo estilo snake_case dos nomes de variáveis (aula 14).

Atenção: Se você esquecer de pôr o widget num layout, ele fica "solto" numa posição fixa: ao aumentar a janela, tudo continua espremido num canto. O ícone de um círculo vermelho ao lado do formulário, no Object Inspector, avisa que falta layout.

Por dentro de um .ui: é só XML

Abra o tela.ui no VS Code e você vai ver que ele é um texto no formato XML: etiquetas como <widget> dentro de outras etiquetas, parecido com HTML. Cada widget aparece com a sua classe e o seu objectName.

Como é texto, o Python consegue ler o arquivo com o módulo xml.etree.ElementTree da biblioteca padrão. Este exemplo roda aqui no navegador e lista os widgets da tela:

import xml.etree.ElementTree as ET

tela_ui = """<?xml version="1.0" encoding="UTF-8"?>
<ui version="4.0">
 <class>Form</class>
 <widget class="QWidget" name="Form">
  <property name="windowTitle"><string>Cadastro</string></property>
  <layout class="QVBoxLayout" name="layout_principal">
   <item><widget class="QLabel" name="titulo">
    <property name="text"><string>Digite seu nome:</string></property>
   </widget></item>
   <item><widget class="QLineEdit" name="campo_nome"/></item>
   <item><widget class="QPushButton" name="botao_enviar">
    <property name="text"><string>Enviar</string></property>
   </widget></item>
  </layout>
 </widget>
</ui>"""

raiz = ET.fromstring(tela_ui)
for widget in raiz.iter("widget"):
    print(f"{widget.get('class'):<12} objectName = {widget.get('name')}")

QWidget      objectName = Form
QLabel       objectName = titulo
QLineEdit    objectName = campo_nome
QPushButton  objectName = botao_enviar

O iter("widget") passa por todas as etiquetas <widget>, mesmo as que estão dentro de layouts. O get("name") lê o atributo name, que é justamente o objectName que você escolheu no Designer.

Também dá para ler as propriedades, como o texto de cada widget e o título da janela:

import xml.etree.ElementTree as ET

tela_ui = """<ui version="4.0">
 <widget class="QWidget" name="Form">
  <property name="windowTitle"><string>Cadastro</string></property>
  <layout class="QVBoxLayout" name="layout_principal">
   <item><widget class="QLabel" name="titulo">
    <property name="text"><string>Digite seu nome:</string></property>
   </widget></item>
   <item><widget class="QPushButton" name="botao_enviar">
    <property name="text"><string>Enviar</string></property>
   </widget></item>
  </layout>
 </widget>
</ui>"""

raiz = ET.fromstring(tela_ui)
janela = raiz.find("widget")
print("Título da janela:", janela.find("property/string").text)
print("Layout:", raiz.find(".//layout").get("class"))
for widget in raiz.iter("widget"):
    texto = widget.find("property[@name='text']/string")
    if texto is not None:
        print(widget.get("name"), "->", texto.text)

Título da janela: Cadastro
Layout: QVBoxLayout
titulo -> Digite seu nome:
botao_enviar -> Enviar

Você não precisa escrever XML à mão: quem escreve é o Designer. Mas saber que é texto ajuda a entender os erros e a ver as mudanças no Git (aula 244).

Jeito 1: carregar o .ui quando o programa abre

O QUiLoader lê o .ui e monta a tela na hora em que o programa roda. Salve este código como main.py, na mesma pasta do tela.ui:

import sys
from PySide6.QtWidgets import QApplication
from PySide6.QtUiTools import QUiLoader

app = QApplication(sys.argv)
janela = QUiLoader().load("tela.ui")


def enviar():
    nome = janela.campo_nome.text()
    janela.titulo.setText(f"Olá, {nome}!")
    print("Botão clicado por", nome)


janela.botao_enviar.clicked.connect(enviar)
janela.show()
sys.exit(app.exec())
python main.py

(abre a janela "Cadastro" com o rótulo, a caixa de texto e o botão Enviar)

Depois de escrever Ana e clicar em Enviar, o rótulo muda para "Olá, Ana!" e o terminal mostra a linha acima. Repare que janela.campo_nome e janela.botao_enviar existem porque esses são os objectName que você deu no Designer.

Atenção: Se aparecer AttributeError: 'QWidget' object has no attribute 'botao_enviar', o nome no código não é igual ao objectName do Designer. Confira letra por letra, inclusive maiúsculas.

Jeito 2: converter o .ui em Python

O comando pyside6-uic transforma o .ui num arquivo .py com uma classe pronta, chamada Ui_ mais o nome do formulário:

pyside6-uic tela.ui -o ui_tela.py

Agora a sua janela herda dessa classe (aula 76) e chama setupUi, que cria todos os widgets:

import sys
from PySide6.QtWidgets import QApplication, QWidget
from ui_tela import Ui_Form


class Janela(QWidget, Ui_Form):
    def __init__(self):
        super().__init__()
        self.setupUi(self)
        self.botao_enviar.clicked.connect(self.enviar)

    def enviar(self):
        nome = self.campo_nome.text()
        self.titulo.setText(f"Olá, {nome}!")
        print("Botão clicado por", nome)


app = QApplication(sys.argv)
janela = Janela()
janela.show()
sys.exit(app.exec())

(abre a mesma janela "Cadastro"; ao clicar em Enviar com "Ana" na caixa:)
Botão clicado por Ana

Se no Designer você escolheu Main Window em vez de Widget, a classe gerada se chama Ui_MainWindow e a sua janela deve herdar de QMainWindow.

Dica: Nunca edite o ui_tela.py gerado: na próxima conversão ele é apagado e escrito de novo. Mude a tela no Designer, converta outra vez e deixe o seu código em outro arquivo.

Qual jeito escolher

  • QUiLoader (jeito 1): mais simples para começar; salvou no Designer, é só rodar de novo. Mas o editor não sabe quais widgets existem, então não completa os nomes enquanto você digita.
  • pyside6-uic (jeito 2): dá um pouquinho mais de trabalho (converter a cada mudança), mas o VS Code passa a completar self.campo_nome e avisa erros de digitação. É o jeito mais usado em projetos maiores.

Os dois usam o mesmo .ui, então você pode começar com um e trocar depois.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
pyside6-uic tela.ui -o ui_tela.py

2. Escreva uma função nomes_ruins(tela_ui) que devolve os objectName que ainda têm o nome automático do Designer (começam com pushButton, lineEdit ou label).

Ver resposta 
import xml.etree.ElementTree as ET

tela_ui = """<ui version="4.0">
 <widget class="QWidget" name="Form">
  <layout class="QVBoxLayout" name="verticalLayout">
   <item><widget class="QLabel" name="label_3"/></item>
   <item><widget class="QLineEdit" name="campo_nome"/></item>
   <item><widget class="QPushButton" name="pushButton"/></item>
  </layout>
 </widget>
</ui>"""


def nomes_ruins(texto):
    automaticos = ("pushButton", "lineEdit", "label")
    raiz = ET.fromstring(texto)
    return [w.get("name") for w in raiz.iter("widget")
            if w.get("name").startswith(automaticos)]


print(nomes_ruins(tela_ui))

['label_3', 'pushButton']

startswith aceita uma tupla e responde True se o texto começar com qualquer um dos itens.
