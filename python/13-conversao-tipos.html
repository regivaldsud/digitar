Aula 13 · Convertendo tipos (int(), float(), str(), bool())

Nesta aula você vai aprender

  • Converter textos em números com int() e float()
  • Converter números em texto com str()
  • Descobrir o que vira True ou False com bool()
  • Entender o ValueError quando a conversão não é possível

Por que converter?

Às vezes um número chega como texto: um valor lido do teclado, uma linha de arquivo, um dado de planilha. Texto não serve para conta: o + entre textos junta em vez de somar.

print("12" + "7")
print(12 + 7)
print(int("12") + int("7"))

127
19
19

Converter é transformar um valor de um tipo em outro. Cada tipo tem uma função com o próprio nome: int(), float(), str() e bool().

Texto para número: int e float

  • int("12") vira o inteiro 12;
  • float("1.75") vira o número real 1.75;
  • int() também transforma um float em inteiro, cortando a parte decimal (não arredonda).
print(int("2025"))
print(float("1.75"))
print(float("3"))
print(int(3.9))
print(int(-3.9))
print(int(" 42 "))

2025
1.75
3.0
3
-3
42

int(3.9) dá 3 e int(-3.9) dá -3: o corte sempre joga fora o que vem depois do ponto. Espaços nas pontas, como em " 42 ", são ignorados.

Número para texto: str

O caminho contrário também existe: str() transforma um número em texto. É útil para juntar números com outros textos usando +:

pontos = 250
print("Você fez " + str(pontos) + " pontos!")
print(str(3.5) + " km")
print(len(str(2025)))

Você fez 250 pontos!
3.5 km
4

len(str(2025)) conta os dígitos do número: primeiro vira o texto "2025", depois len conta 4 caracteres.

Quando a conversão falha: ValueError

Se o texto não parece um número, a conversão falha com ValueError:

print(int("doze"))

ValueError: invalid literal for int() with base 10: 'doze'

O mesmo acontece com int("12.5") (tem ponto, então não é inteiro), float("1,5") (vírgula não vale) e int("") (texto vazio). Um jeito de aceitar vírgula é trocá-la por ponto antes de converter:

valor = "1,5"
print(float(valor.replace(",", ".")))
print(int(float("12.5")))

1.5
12

int(float("12.5")) converte em duas etapas: primeiro para float, depois para int.

Atenção: int("12.5") dá erro, mas int(12.5) funciona. A diferença: o primeiro é um texto com ponto, o segundo já é um número float.

bool(): o que é verdadeiro?

bool() converte qualquer valor em True ou False. A regra: o que é "vazio" ou "zero" vira False; o resto vira True.

print(bool(0))
print(bool(15))
print(bool(""))
print(bool("oi"))
print(bool(" "))
print(bool("False"))

False
True
False
True
True
True

Cuidado com as duas últimas: " " tem um espaço, então não é vazio. E "False" é um texto com 5 letras, então vira True!

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
total = int("12") + float("7.5")

Exercícios

1. Converta os textos "15" e "27" em números e mostre a soma.

Ver resposta 
print(int("15") + int("27"))

42

2. Mostre a frase Faltam 30 dias para as férias juntando textos com + e o número 30 convertido com str().

Ver resposta 
dias = 30
print("Faltam " + str(dias) + " dias para as férias")

Faltam 30 dias para as férias

3. O preço "4,99" veio de uma planilha brasileira. Converta para float e mostre o dobro do preço.

Ver resposta 
preco = float("4,99".replace(",", "."))
print(preco * 2)

9.98

4. Sem rodar, diga o resultado de int(7.99), bool(0.0) e bool("0"). Depois confira.

Ver resposta 
print(int(7.99))
print(bool(0.0))
print(bool("0"))

7
False
True

int corta as casas e dá 7. 0.0 é zero, então dá False. Já "0" é um texto com um caractere, não vazio, então dá True.

5. Quantos dígitos tem o número 9876543210? Use str() e len().

Ver resposta 
print(len(str(9876543210)))

10
