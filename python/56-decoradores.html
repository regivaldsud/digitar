A ideia: embrulhar uma função

Na aula 45 você viu que funções são valores e que uma função pode criar e devolver outra. Um decorador usa exatamente isso: é uma função que recebe uma função e devolve uma versão "embrulhada" dela, com algo a mais antes ou depois.

def anunciar(funcao):
    def embrulho():
        print("--- começando ---")
        funcao()
        print("--- terminou ---")
    return embrulho


def boas_vindas():
    print("Bem-vindo ao DIGITAR!")


boas_vindas = anunciar(boas_vindas)
boas_vindas()

--- começando ---
Bem-vindo ao DIGITAR!
--- terminou ---

O atalho @

Escrever boas_vindas = anunciar(boas_vindas) funciona, mas o Python tem um atalho: o @ em cima do def. As duas formas fazem a mesma coisa.

def anunciar(funcao):
    def embrulho():
        print("--- começando ---")
        funcao()
        print("--- terminou ---")
    return embrulho


@anunciar
def lembrete():
    print("Hoje tem treino de digitação!")


lembrete()

--- começando ---
Hoje tem treino de digitação!
--- terminou ---

Para qualquer função: *args, **kwargs e wraps

Para o decorador servir em funções com quaisquer parâmetros, o embrulho recebe *args e **kwargs (aula 43) e repassa tudo. E não esqueça de devolver o resultado da função original!

Use também functools.wraps: sem ele, a função decorada perde o próprio nome e a docstring.

from functools import wraps


def registrar(funcao):
    @wraps(funcao)
    def embrulho(*args, **kwargs):
        print(f"Chamando {funcao.__name__} com {args} {kwargs}")
        resultado = funcao(*args, **kwargs)
        print(f"{funcao.__name__} devolveu {resultado}")
        return resultado
    return embrulho


@registrar
def preco_final(preco, desconto=0):
    """Calcula o preço com desconto."""
    return preco - desconto


preco_final(50, desconto=5)
print(preco_final.__name__)
print(preco_final.__doc__)

Chamando preco_final com (50,) {'desconto': 5}
preco_final devolveu 45
preco_final
Calcula o preço com desconto.

Atenção: Esquecer o return resultado dentro do embrulho é o erro mais comum: a função decorada passa a devolver None, sem nenhuma mensagem de erro.

Um uso clássico é medir o tempo que uma função demora com time.perf_counter(), o relógio mais preciso do Python. O tempo muda a cada execução:

import time
from functools import wraps


def cronometrar(funcao):
    @wraps(funcao)
    def embrulho(*args, **kwargs):
        inicio = time.perf_counter()
        resultado = funcao(*args, **kwargs)
        print(f"{funcao.__name__} levou {time.perf_counter() - inicio:.4f} s")
        return resultado
    return embrulho


@cronometrar
def somar_ate(n):
    return sum(range(n))


print(somar_ate(1_000_000))

(exemplo — a sua saída pode ser diferente)
somar_ate levou 0.0261 s
499999500000

Decoradores com parâmetros

E se o decorador precisar de uma configuração, como @repetir(3)? Aí são três funções, uma dentro da outra: a de fora recebe o parâmetro e devolve o decorador de verdade.

from functools import wraps


def repetir(vezes):
    def decorador(funcao):
        @wraps(funcao)
        def embrulho(*args, **kwargs):
            for _ in range(vezes):
                resultado = funcao(*args, **kwargs)
            return resultado
        return embrulho
    return decorador


@repetir(3)
def torcer(time):
    print(f"Vai, {time}!")


torcer("Fortaleza")

Vai, Fortaleza!
Vai, Fortaleza!
Vai, Fortaleza!

Leia @repetir(3) em duas etapas: primeiro repetir(3) roda e devolve decorador; depois decorador embrulha torcer.

Dica: Um decorador com parâmetro muito útil é o que confere permissões ou valores. Por exemplo, @limite(0, 10) poderia recusar notas fora da faixa antes mesmo de a função rodar.

Vários decoradores: a ordem importa

Você pode empilhar decoradores. Eles são aplicados de baixo para cima (o mais perto do def embrulha primeiro), mas, na hora de rodar, o de cima começa primeiro — como caixas uma dentro da outra.

def negrito(funcao):
    def embrulho():
        return "<b>" + funcao() + "</b>"
    return embrulho


def italico(funcao):
    def embrulho():
        return "<i>" + funcao() + "</i>"
    return embrulho


@negrito
@italico
def titulo():
    return "Python"


print(titulo())

<b><i>Python</i></b>

É o mesmo que titulo = negrito(italico(titulo)): o italico embrulha primeiro, e o negrito embrulha o resultado. Troque a ordem e veja as etiquetas mudarem de lugar.

def embrulho(*args, **kwargs):

Exercícios

1. Escreva um decorador em_maiusculas que transforma em maiúsculas o texto devolvido pela função decorada. Teste com uma função que devolve "Vai, Bahia!".

Ver resposta 
from functools import wraps


def em_maiusculas(funcao):
    @wraps(funcao)
    def embrulho(*args, **kwargs):
        return funcao(*args, **kwargs).upper()
    return embrulho


@em_maiusculas
def grito(time):
    return f"Vai, {time}!"


print(grito("Bahia"))

VAI, BAHIA!

2. O que está errado neste decorador? def dobrar(f): def e(x): f(x) * 2; return e. Corrija e teste com uma função que devolve x + 1.

Ver resposta 
def dobrar(f):
    def e(x):
        return f(x) * 2
    return e


@dobrar
def mais_um(x):
    return x + 1

Faltava o return dentro de e: sem ele, a função decorada devolvia None.

3. Escreva um decorador contar_chamadas que mostre quantas vezes a função já foi chamada. Dica: guarde o contador como atributo do embrulho.

Ver resposta 
from functools import wraps


def contar_chamadas(funcao):
    @wraps(funcao)
    def embrulho(*args, **kwargs):
        embrulho.chamadas += 1
        print(f"Chamada número {embrulho.chamadas}")
        return funcao(*args, **kwargs)
    embrulho.chamadas = 0
    return embrulho


@contar_chamadas
def tocar_campainha():
    print("Dim-dom!")


tocar_campainha()
tocar_campainha()

Dim-dom!
Chamada número 2
Dim-dom!

4. Crie o decorador com parâmetro prefixo(texto), que coloca texto antes do resultado da função. Teste com @prefixo("Aviso: ") numa função que devolve "amanhã não tem aula".

Ver resposta 
from functools import wraps


def prefixo(texto):
    def decorador(funcao):
        @wraps(funcao)
        def embrulho(*args, **kwargs):
            return texto + funcao(*args, **kwargs)
        return embrulho
    return decorador


@prefixo("Aviso: ")
def recado():
    return "amanhã não tem aula"


print(recado())

Aviso: amanhã não tem aula

5. Sem rodar, diga o que aparece ao chamar saudacao(), sabendo que @exclamar (acrescenta "!" no fim) está em cima de @maiusculas (deixa em maiúsculas) e a função devolve "oi". Depois rode para conferir.

Ver resposta 
def exclamar(funcao):
    def embrulho():
        return funcao() + "!"
    return embrulho


def maiusculas(funcao):
    def embrulho():
        return funcao().upper()
    return embrulho


@exclamar
@maiusculas
def saudacao():
    return "oi"


print(saudacao())

OI!

O maiusculas embrulha primeiro ("OI"), depois o exclamar acrescenta o "!". Resultado: OI!.
