Aula 02 · Instalando Python e VS Code (Windows, Linux, macOS)

Nesta aula você vai aprender

  • Baixar e instalar o Python 3 no Windows sem esquecer a opção do PATH
  • Instalar o Python no Linux e no macOS
  • Instalar o VS Code e a extensão de Python
  • Conferir a instalação pelo terminal e usar o modo interativo
  • Saber o que fazer se o comando python não for encontrado
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Por que instalar, se o site já roda Python?

Os exemplos deste curso rodam no navegador, o que é ótimo para aprender. Mas, para criar seus próprios programas, salvar arquivos, instalar bibliotecas e fazer os projetos, você vai querer o Python no seu computador. Leva uns 10 minutos.

Windows: instalando o Python

  • Entre em python.org/downloads e clique no botão amarelo Download Python 3.x (qualquer versão 3.12 ou mais nova serve).
  • Abra o arquivo baixado.
  • Antes de clicar em Install Now, marque a caixinha Add python.exe to PATH, lá embaixo na janela.
  • Clique em Install Now e espere terminar. Se aparecer "Disable path length limit", pode clicar — não faz mal.
Atenção: Esquecer de marcar Add python.exe to PATH é o erro de instalação mais comum. Sem ela, o Windows não acha o comando python. Se isso aconteceu, rode o instalador de novo, escolha Modify (ou desinstale e instale de novo) e marque a opção.

Para conferir, aperte a tecla Windows, digite cmd, abra o Prompt de Comando e digite:

python --version

Se aparecer algo assim, deu certo:

Python 3.12.7

No Windows também existe o inicializador py, que funciona mesmo quando o PATH deu problema:

py --version
Dica: Se python abrir a Microsoft Store em vez de mostrar a versão, é um atalho do Windows. Desligue em Configurações › Aplicativos › Configurações avançadas de aplicativos › Aliases de execução de aplicativo, desativando os itens "python.exe" e "python3.exe".

Linux e macOS

No Linux (Ubuntu, Mint, Debian), o Python 3 quase sempre já vem instalado. Abra o Terminal e confira. Se faltar algo, instale com o gerenciador de pacotes:

python3 --version
sudo apt update
sudo apt install python3 python3-pip python3-venv

No macOS, baixe o instalador em python.org/downloads e siga as telas (Continuar, Concordar, Instalar). Quem usa o Homebrew pode instalar com brew install python. Depois, no Terminal:

python3 --version
Atenção: No Linux e no macOS o comando costuma ser python3 (e pip3), e não python. Sempre que este curso disser python, use python3 nesses sistemas.

Instalando o VS Code

Dá para escrever Python até no Bloco de Notas, mas um editor de código ajuda muito: ele colore o código, avisa erros e roda o programa com um clique.

  • Entre em code.visualstudio.com e baixe a versão do seu sistema (Windows, Linux ou macOS).
  • Instale aceitando as opções padrão. No Windows, se aparecer "Adicionar ao PATH" e "Abrir com Code", marque.
  • Abra o VS Code, clique no ícone de Extensões na barra lateral (quatro quadradinhos) ou aperte Ctrl+Shift+X.
  • Procure por Python e instale a extensão da Microsoft.

O modo interativo

No terminal, digite só python (ou python3) e aperte Enter. Vai aparecer o sinal >>>: é o modo interativo, onde cada linha roda na hora.

python

Python 3.12.7 (tags/v3.12.7, ...) on win32
Type "help", "copyright", "credits" or "license" for more information.
>>> print("Funcionou!")
Funcionou!
>>> 2 + 2
4
>>> exit()

Para sair, digite exit() e aperte Enter. Para conferir de dentro do Python qual versão está rodando, salve este código num arquivo e rode (você aprende como na aula 03):

import sys

print("Versão do Python:", sys.version_info.major, sys.version_info.minor)

Versão do Python: 3 12

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
python --version

Exercícios

1. No modo interativo do Python (>>>), qual comando mostra o resultado de 365 vezes 24? Escreva também a versão para um arquivo .py.

Ver resposta 
print(365 * 24)

8760

No modo interativo você pode digitar só 365 * 24, e o resultado aparece. Em um arquivo .py, precisa do print.

2. Você digitou python --version e o Windows respondeu que "python" não é reconhecido como um comando. Quais são duas formas de resolver?

Ver resposta

1. Rodar o instalador de novo, escolher Modify/Repair e marcar "Add python.exe to PATH"
   (depois feche e abra o terminal de novo).
2. Usar o inicializador do Windows no lugar: py --version

3. Abra o modo interativo e use print para mostrar a frase Estou programando em Python!. Depois saia do modo interativo. Quais foram os comandos?

Ver resposta

python
>>> print("Estou programando em Python!")
Estou programando em Python!
>>> exit()

4. Sua prima usa Ubuntu e digitou python --version, mas apareceu "comando não encontrado". O que ela deve tentar?

Ver resposta 
python3 --version

No Linux o comando costuma se chamar python3. Se nem ele existir, ela instala com sudo apt install python3.
