Aula 40 · Funções: def, parâmetros e return

Nesta aula você vai aprender

  • O que é uma função e por que ela evita repetir código
  • Como criar uma função com def e chamá-la pelo nome
  • Como enviar valores para a função usando parâmetros
  • Como devolver um resultado com return — e por que return não é print

Você já usa funções

Desde as primeiras aulas você usa funções que vêm prontas no Python: print, input, len, int. Cada uma tem um nome e faz uma tarefa. Agora você vai criar as suas.

Uma função é um bloco de código com nome. Você escreve as instruções uma vez e depois "chama" a função sempre que precisar, usando o nome dela seguido de parênteses.

Criando a primeira função

Use a palavra def (de "definir"), o nome da função, parênteses e dois-pontos. As linhas de dentro ficam indentadas com 4 espaços, como no if e no for:

def linha():
    print("-" * 24)

linha()
print("Flamengo 2 x 1 Palmeiras")
linha()
print("Grêmio 0 x 0 Inter")
linha()

------------------------
Flamengo 2 x 1 Palmeiras
------------------------
Grêmio 0 x 0 Inter
------------------------

A linha def só ensina ao Python o que a função faz — nada aparece na tela nesse momento. São as linhas linha(), sem indentação, que chamam a função e executam o que está dentro dela. Se um dia você quiser trocar o - por =, basta mudar em um lugar.

Atenção: Não esqueça os parênteses ao chamar. Escrever só linha (sem parênteses) não executa nada: o Python apenas "olha" para a função sem rodá-la.

Primeiro definir, depois chamar

O Python lê o arquivo de cima para baixo. Se você chamar uma função antes da linha def dela, ele ainda não a conhece:

cantar()

def cantar():
    print("Parabéns pra você!")

NameError: name 'cantar' is not defined

A correção é simples: coloque as definições (def) no começo do arquivo e as chamadas depois.

Parâmetros: a função recebe dados

Com parâmetros, a função deixa de fazer sempre a mesma coisa. O parâmetro é uma variável que fica entre os parênteses do def; os valores usados na chamada são os argumentos:

def saudar(nome):
    print(f"Olá, {nome}! Bem-vindo ao DIGITAR.")

saudar("Pedro")
saudar("Maria")

Olá, Pedro! Bem-vindo ao DIGITAR.
Olá, Maria! Bem-vindo ao DIGITAR.

Para vários parâmetros, separe com vírgula. Os argumentos são entregues na mesma ordem:

def mostrar_preco(produto, preco):
    print(f"{produto}: R$ {preco:.2f}")

mostrar_preco("Pastel", 7.5)
mostrar_preco("Caldo de cana", 6)

Pastel: R$ 7.50
Caldo de cana: R$ 6.00

Atenção: Chamar com argumentos de menos dá erro: mostrar_preco("Pastel") gera TypeError: mostrar_preco() missing 1 required positional argument: 'preco'. Leia a mensagem: ela diz exatamente qual argumento faltou.

return: a função devolve um resultado

Muitas vezes a função deve calcular algo e entregar o resultado para o programa usar depois. Para isso serve o return. Quando o Python encontra return, a função termina na hora e o valor "volta" para o lugar da chamada:

def dobro(numero):
    return numero * 2

resultado = dobro(21)
print(resultado)
print(dobro(5) + dobro(10))

42
30

return não é print

Essa é a confusão mais comum de quem está começando. print só mostra na tela; return entrega o valor. Veja:

def soma_com_print(a, b):
    print(a + b)

def soma_com_return(a, b):
    return a + b

x = soma_com_print(2, 3)
y = soma_com_return(2, 3)
print("x vale", x)
print("y vale", y)

5
x vale None
y vale 5

A primeira função mostrou 5, mas não devolveu nada. Uma função sem return devolve o valor especial None, que significa "nada".

Dica: Regra prática: se você vai usar o resultado depois (numa conta, num if, numa variável), use return. Deixe o print para a parte do programa que conversa com o usuário.

Devolvendo mais de um valor

Uma função pode devolver vários valores separados por vírgula. Eles chegam juntos numa tupla (aula 27) e podem ser separados em variáveis. O return também pode aparecer mais de uma vez: o primeiro que rodar encerra a função.

def min_e_max(notas):
    return min(notas), max(notas)

def situacao(media):
    if media >= 7:
        return "Aprovado"
    return "Recuperação"

menor, maior = min_e_max([7.5, 9.0, 6.0, 8.5])
print("Menor nota:", menor, "| Maior nota:", maior)
print(situacao(8.2))
print(situacao(5.9))

Menor nota: 6.0 | Maior nota: 9.0
Aprovado
Recuperação

Exercícios

1. Crie uma função moldura() que mostre uma linha de 15 asteriscos e use-a para emoldurar a frase Feliz aniversário! (uma moldura em cima e outra embaixo).

Ver resposta 
def moldura():
    print("*" * 15)

moldura()
print("Feliz aniversário!")
moldura()

***************
Feliz aniversário!
***************

2. Crie a função area_retangulo(base, altura) que devolve a área. Use-a para calcular a área de um quarto de 3 por 4 metros.

Ver resposta 
def area_retangulo(base, altura):
    return base * altura

print(area_retangulo(3, 4), "metros quadrados")

12 metros quadrados

3. Crie a função eh_par(n) que devolve True se o número for par e False se for ímpar. Teste com 10 e 7.

Ver resposta 
def eh_par(n):
    return n % 2 == 0

print(eh_par(10))
print(eh_par(7))

True
False

O resultado de n % 2 == 0 já é True ou False, então dá para devolvê-lo direto, sem if.

4. O que este programa mostra? Uma função f() que faz print("oi") e depois print(f()). Rode e explique.

Ver resposta 
def f():
    print("oi")

print(f())

oi
None

Primeiro a função roda e mostra oi. Como ela não tem return, devolve None, e o print de fora mostra None.

5. Crie a função troco(valor_pago, preco) que devolva duas coisas: o troco e uma mensagem ("Troco ok" ou "Falta dinheiro"). Teste com um lanche de R$ 18 pago com R$ 20 e com R$ 15.

Ver resposta 
def troco(valor_pago, preco):
    diferenca = valor_pago - preco
    if diferenca >= 0:
        return diferenca, "Troco ok"
    return 0, "Falta dinheiro"

valor, mensagem = troco(20, 18)
print(valor, mensagem)
valor, mensagem = troco(15, 18)
print(valor, mensagem)

2 Troco ok
0 Falta dinheiro
