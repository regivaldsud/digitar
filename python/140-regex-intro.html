Procurar padrões, não palavras

Com in e find (aula 28) você procura um texto exato, como "Recife". Mas e se quiser achar qualquer CEP numa mensagem? Ou todos os números de telefone de um texto? Você não sabe o texto exato, só o formato: cinco dígitos, um tracinho, três dígitos.

Uma expressão regular (em inglês *regular expression*, ou regex) é um mini-idioma para descrever formatos de texto. Em Python ela mora no módulo re. Por exemplo, \d quer dizer "um dígito qualquer", e \d{5} quer dizer "cinco dígitos seguidos".

re.search: achar a primeira ocorrência

re.search(padrao, texto) procura o padrão em qualquer lugar do texto. Se achar, devolve um objeto match; o método group() mostra o trecho encontrado. Se não achar, devolve None.

import re

mensagem = "Pode mandar a encomenda para o CEP 01310-100, em São Paulo."
achado = re.search(r"\d{5}-\d{3}", mensagem)
print(achado.group())
print(achado.start(), achado.end())

nada = re.search(r"\d{5}-\d{3}", "Esqueci o CEP.")
print(nada)

01310-100
35 44
None

start() e end() mostram onde o trecho começa e termina, como nos índices de texto da aula 20.

Atenção: Antes de chamar group(), confira se achou algo: if achado:. Chamar .group() em None dá AttributeError: 'NoneType' object has no attribute 'group'.

Strings cruas: o r antes das aspas

Repare no r em r"\d{5}". Ele cria uma string crua: a barra invertida fica do jeito que você digitou. Sem o r, o Python tenta interpretar combinações como \n (nova linha) ou \b antes de a regex ver o texto.

print(len("\b"), len(r"\b"))
print(r"\d+ e \n ficam como estão")

1 2
\d+ e \n ficam como estão

Dica: Crie o hábito: toda regex começa com r". Assim você nunca cai na pegadinha das barras.

re.findall: todas as ocorrências

re.findall devolve uma lista com todos os trechos que combinam com o padrão. \d+ quer dizer "um ou mais dígitos seguidos":

import re

lista = "Comprei 3 pães, 12 ovos e 2 litros de leite por 25 reais."
numeros = re.findall(r"\d+", lista)
print(numeros)
print(sum(int(n) for n in numeros))

['3', '12', '2', '25']
42

Os itens vêm como texto; use int() para fazer contas.

re.sub: procurar e trocar

re.sub(padrao, troca, texto) troca todos os trechos encontrados. Que tal esconder números de telefone de uma mensagem antes de publicar?

import re

texto = "Me liga no 98765-4321 ou no 91234-5678!"
seguro = re.sub(r"\d{5}-\d{4}", "*****-****", texto)
print(seguro)

espacos = "Muito     espaço    entre   as palavras"
print(re.sub(r" +", " ", espacos))

Me liga no *****-**** ou no *****-****!
Muito espaço entre as palavras

O segundo exemplo usa " +" (um ou mais espaços) para deixar só um espaço entre as palavras.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
cep = re.search(r"\d{5}-\d{3}", texto)

Exercícios

1. Use re.findall para pegar todos os números do texto "Tenho 2 gatos, 1 cachorro e 15 peixes" e mostre a lista.

Ver resposta 
import re

texto = "Tenho 2 gatos, 1 cachorro e 15 peixes"
print(re.findall(r"\d+", texto))

['2', '1', '15']

2. Procure um horário no formato HH:MM (dois dígitos, dois-pontos, dois dígitos) na frase "O ônibus sai às 07:45 da rodoviária" e mostre só o horário.

Ver resposta 
import re

frase = "O ônibus sai às 07:45 da rodoviária"
achado = re.search(r"\d{2}:\d{2}", frase)
if achado:
    print(achado.group())

07:45

3. Troque todas as sequências de dígitos do texto "Senha 1234 e PIN 987" por "###".

Ver resposta 
import re

print(re.sub(r"\d+", "###", "Senha 1234 e PIN 987"))

Senha ### e PIN ###

4. O que re.search(r"\d{3}", "abc") devolve? Por que é perigoso chamar .group() direto nesse caso?

Ver resposta 
import re

resultado = re.search(r"\d{3}", "abc")
print(resultado)
if resultado is None:
    print("Nada encontrado: chamar .group() aqui daria AttributeError")

None
Nada encontrado: chamar .group() aqui daria AttributeError
