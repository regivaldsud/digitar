Opções com nome

Imagine um sistema de lanchonete em que o pedido pode estar "recebido", "preparando", "saiu" ou "entregue". Se você usar textos soltos, basta um erro de digitação ("prepanrando") para o programa se perder, sem nenhum aviso.

Uma enumeração (Enum) é uma lista fechada de opções com nome. Cada opção é um membro, com um nome e um valor:

from enum import Enum

class Status(Enum):
    RECEBIDO = 1
    PREPARANDO = 2
    SAIU = 3
    ENTREGUE = 4

pedido = Status.PREPARANDO
print(pedido)
print(pedido.name, pedido.value)
print(pedido == Status.PREPARANDO)

Status.PREPARANDO
PREPARANDO 2
True

Errou o nome? O Python avisa na hora:

from enum import Enum

class Status(Enum):
    RECEBIDO = 1
    PREPARANDO = 2

print(Status.PREPARANDDO)

AttributeError: type object 'Status' has no attribute 'PREPARANDDO'. Did you mean: 'PREPARANDO'?

Dica: Os nomes dos membros ficam em MAIÚSCULAS, como as constantes, porque eles não mudam.

Buscando e percorrendo

Dá para pegar um membro pelo valor (com parênteses) ou pelo nome (com colchetes). E um for percorre todos os membros, na ordem em que foram escritos:

from enum import Enum

class Semaforo(Enum):
    VERDE = "siga"
    AMARELO = "atenção"
    VERMELHO = "pare"

print(Semaforo("pare"))
print(Semaforo["VERDE"].value)

for cor in Semaforo:
    print(f"{cor.name:<9} -> {cor.value}")
print(len(Semaforo))

Semaforo.VERMELHO
siga
VERDE     -> siga
AMARELO   -> atenção
VERMELHO  -> pare
3

Atenção: Um membro de enum não é igual ao seu valor: Semaforo.VERDE == "siga" dá False. Compare membro com membro, ou use .value quando precisar do valor.

auto() e métodos no enum

Quando o valor não importa, use auto() e o Python numera sozinho a partir de 1. E um enum é uma classe: pode ter métodos!

from enum import Enum, auto

class Dia(Enum):
    SEGUNDA = auto()
    TERCA = auto()
    QUARTA = auto()
    QUINTA = auto()
    SEXTA = auto()
    SABADO = auto()
    DOMINGO = auto()

    def fim_de_semana(self):
        return self in (Dia.SABADO, Dia.DOMINGO)

print(Dia.QUARTA.value)
print(Dia.SABADO.fim_de_semana(), Dia.TERCA.fim_de_semana())

3
True False

Enum em decisões

Enums deixam os if mais claros e seguros. Veja uma função que diz o que fazer em cada cor do semáforo:

from enum import Enum

class Semaforo(Enum):
    VERDE = 1
    AMARELO = 2
    VERMELHO = 3

def acao(cor):
    if cor is Semaforo.VERDE:
        return "Pode atravessar"
    elif cor is Semaforo.AMARELO:
        return "Atenção, vai fechar"
    return "Espere"

for cor in Semaforo:
    print(cor.name, "->", acao(cor))

VERDE -> Pode atravessar
AMARELO -> Atenção, vai fechar
VERMELHO -> Espere

Como cada membro existe uma única vez, dá para comparar com is. Na aula 92 você verá como o match/case combina muito bem com enums.

StrEnum: membros que são textos

A partir do Python 3.11, o StrEnum cria membros que também são textos. Eles se comparam com strings e funcionam direto em f-strings:

from enum import StrEnum

class Tamanho(StrEnum):
    P = "pequeno"
    M = "médio"
    G = "grande"

print(Tamanho.M == "médio")
print(f"Açaí {Tamanho.G}")

True
Açaí grande

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
class Cor(Enum): VERDE = 1

3. Acrescente ao enum Status (RECEBIDO, PREPARANDO, SAIU, ENTREGUE, valores 1 a 4) um método proximo() que devolve o próximo status, e o próprio ENTREGUE quando já for o último.

Ver resposta 
from enum import Enum

class Status(Enum):
    RECEBIDO = 1
    PREPARANDO = 2
    SAIU = 3
    ENTREGUE = 4

    def proximo(self):
        if self is Status.ENTREGUE:
            return self
        return Status(self.value + 1)

s = Status.RECEBIDO
for _ in range(4):
    print(s.name)
    s = s.proximo()

RECEBIDO
PREPARANDO
SAIU
ENTREGUE

4. O que acontece em Semaforo("azul"), se não existe membro com esse valor? Trate o erro com try e mostre uma mensagem amigável.

class Semaforo(Enum):

try:
    cor = Semaforo("azul")

Cor inválida: 'azul' is not a valid Semaforo
