Nesta aula você vai aprender

Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Seu primeiro módulo

Programas grandes ficam melhores divididos em arquivos. Na pasta do projeto (veja a aula 03), crie um arquivo cantina.py:

"""Funções da cantina da escola."""

PRECOS = {"coxinha": 6.0, "suco": 5.0, "pão de queijo": 4.0}


def preco(item):
    return PRECOS[item]


def total(itens):
    return sum(preco(i) for i in itens)

Na mesma pasta, crie pedido.py e importe pelo nome do arquivo, sem o .py:

import cantina

pedido = ["coxinha", "suco"]
print("Total: R$", cantina.total(pedido))
print("Suco custa", cantina.preco("suco"))

Total: R$ 11.0
Suco custa 5.0

Rode com python pedido.py. O Python procura cantina.py primeiro na pasta do programa que você mandou rodar.

Atenção: Se aparecer ModuleNotFoundError: No module named 'cantina', confira se os dois arquivos estão na mesma pasta e se o terminal está nela.

Pacotes: módulos numa pasta

Quando os módulos se multiplicam, agrupe-os numa pasta. Uma pasta de módulos é um pacote. Vamos montar um pacote loja:

projeto/
├── app.py
└── loja/
    ├── __init__.py
    ├── precos.py
    └── carrinho.py

Crie a pasta loja pelo Explorador de Arquivos, pelo terminal com mkdir loja ou com Python:

from pathlib import Path

Path("loja").mkdir(exist_ok=True)
print("Pasta loja pronta")

Pasta loja pronta

O arquivo loja/__init__.py marca a pasta como pacote e roda na primeira vez que o pacote é importado. Ele pode até ficar vazio; aqui ele guarda a versão do pacote:

"""Pacote da lojinha da escola."""

VERSAO = "1.0"
TABELA = {"caderno": 18.90, "lápis": 1.50, "borracha": 2.00}


def preco(produto):
    return TABELA[produto]

Dentro de um pacote, um módulo importa o vizinho com um import relativo: o ponto quer dizer "deste mesmo pacote".

from .precos import preco


def total(itens):
    """Soma o preço de uma lista de (produto, quantidade)."""
    return sum(preco(p) * q for p, q in itens)

Importando do pacote

No app.py, fora da pasta loja, use o nome do pacote, um ponto e o nome do módulo:

import loja
from loja import carrinho
from loja.precos import TABELA

compra = [("caderno", 2), ("lápis", 3)]
print("Versão da loja:", loja.VERSAO)
print("Produtos:", ", ".join(TABELA))
print(f"Total: R$ {carrinho.total(compra):.2f}")

Versão da loja: 1.0
Produtos: caderno, lápis, borracha
Total: R$ 42.30

Dica: Na primeira importação, o Python cria a pasta __pycache__ com versões "pré-compiladas" dos módulos, para ficar mais rápido da próxima vez. Pode ignorá-la (e colocá-la no .gitignore, como você vê na aula 244).
Atenção: O import relativo (from .precos import preco) só funciona dentro de um pacote. Se você rodar python loja/carrinho.py direto, aparece ImportError: attempted relative import with no known parent package. Rode sempre o programa de fora, como o app.py, ou use python -m.

__main__.py e python -m

Um pacote pode ter um arquivo __main__.py: é o que roda quando você executa o pacote inteiro com python -m nome.

from . import VERSAO
from .carrinho import total

print(f"Lojinha {VERSAO}")
print(f"Kit escolar: R$ {total([('caderno', 1), ('borracha', 2)]):.2f}")

No terminal, na pasta projeto (a que contém loja):

python -m loja

Lojinha 1.0
Kit escolar: R$ 22.90

O -m quer dizer "rode este módulo ou pacote". Você já usou isso sem perceber em python -m venv e python -m pip (aula 60). A variável __name__, que diz se um arquivo foi rodado ou importado, é o assunto da aula 100.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
from loja.precos import preco

Exercícios

1. Crie um módulo geometria.py com as funções area_quadrado(lado) e area_triangulo(base, altura), e um programa principal.py que importe e use as duas.

Ver resposta 
def area_quadrado(lado):
    return lado * lado


def area_triangulo(base, altura):
    return base * altura / 2
import geometria

print(geometria.area_quadrado(5))
print(geometria.area_triangulo(6, 4))

25
12.0

2. Dentro de um pacote jogo, o módulo jogo/placar.py precisa da função somar que está em jogo/contas.py. Escreva a linha de import relativo.

Ver resposta 
from .contas import somar

O ponto significa "do mesmo pacote". Fora do pacote, o import seria from jogo.contas import somar.

3. Para que serve o arquivo __init__.py? E o __main__.py?

Ver resposta

__init__.py: marca a pasta como pacote e roda quando o pacote é importado
(pode ficar vazio ou guardar coisas como a versão).
__main__.py: é o que roda quando você executa o pacote com python -m nome_do_pacote.

4. Você rodou python loja/carrinho.py e apareceu ImportError: attempted relative import with no known parent package. Por quê, e como resolver?

Ver resposta

O carrinho.py usa import relativo (from .precos ...), que só funciona quando o arquivo
é carregado como parte do pacote. Rode um programa de fora que importe o pacote
(python app.py) ou rode como módulo: python -m loja.carrinho
