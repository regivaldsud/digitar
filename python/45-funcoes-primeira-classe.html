Funções também são valores

Em Python, uma função é um valor como um número ou um texto: dá para guardá-la numa variável, colocá-la numa lista e passá-la para outra função. O segredo é não colocar os parênteses — sem eles você não chama a função, só fala dela:

def gritar(texto):
    return texto.upper() + "!"

falar_alto = gritar
print(falar_alto("gol do Brasil"))
print(gritar)
print(type(gritar))

GOL DO BRASIL!
<function gritar at 0x000002144AE4A480>
<class 'function'>

Funções de ordem superior

Uma função que recebe outra função como argumento (ou devolve uma) é chamada de função de ordem superior. Assim, o "jeito de fazer" vira um parâmetro:

def gritar(texto):
    return texto.upper() + "!"

def sussurrar(texto):
    return texto.lower() + "..."

def falar(frase, jeito):
    return jeito(frase)

print(falar("Gol do Brasil", gritar))
print(falar("Gol do Brasil", sussurrar))

GOL DO BRASIL!
gol do brasil...

Você já usou isso: sorted(nomes, key=len) recebe a função len para decidir a ordem. A aula 49 mostra mais disso com lambda.

Dicionário de funções

Como funções são valores, um dicionário pode ligar um nome a uma ação. É um jeito elegante de trocar uma fila de if/elif:

def somar(a, b):
    return a + b

def subtrair(a, b):
    return a - b

def multiplicar(a, b):
    return a * b

operacoes = {"+": somar, "-": subtrair, "*": multiplicar}

for simbolo in ["+", "-", "*"]:
    conta = operacoes[simbolo]
    print(f"8 {simbolo} 2 =", conta(8, 2))

8 + 2 = 10
8 - 2 = 6
8 * 2 = 16

Função dentro de função

Uma função pode criar outra lá dentro e devolvê-la. Cada função criada assim é uma "fábrica" personalizada:

def criar_multiplicador(fator):
    def multiplicar(numero):
        return numero * fator
    return multiplicar

dobro = criar_multiplicador(2)
triplo = criar_multiplicador(3)
print(dobro(5))
print(triplo(5))

10
15

Closures: funções que lembram

Repare que criar_multiplicador já terminou quando chamamos dobro(5), e mesmo assim dobro ainda sabe que fator vale 2. A função de dentro "carrega" as variáveis de fora de que precisa. Isso se chama closure (fechamento):

def criar_desconto(porcentagem):
    def aplicar(preco):
        return round(preco * (1 - porcentagem / 100), 2)
    return aplicar

black_friday = criar_desconto(30)
aniversario = criar_desconto(10)
print(black_friday(200))
print(aniversario(200))
print(black_friday.__closure__[0].cell_contents)

140.0
180.0
30

O atributo __closure__ mostra o valor guardado (30). Você não precisa usá-lo no dia a dia, mas ajuda a ver que a closure existe de verdade.

Atenção: Cuidado para não chamar a função na hora errada: falar("oi", gritar()) dá erro, porque gritar() tenta rodar gritar sem argumento. Para passar a função, escreva o nome sem parênteses.
Dica: Closures são a base dos decoradores, que você vai aprender na aula 56.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
dobro = criar_multiplicador(2)

Exercícios

1. Crie a função aplicar(funcao, lista) que devolve uma nova lista com a função aplicada a cada item. Teste com len e com str.upper na lista ["sol", "praia", "mar"].

Ver resposta 
def aplicar(funcao, lista):
    return [funcao(item) for item in lista]

print(aplicar(len, ["sol", "praia", "mar"]))
print(aplicar(str.upper, ["sol", "praia", "mar"]))

[3, 5, 3]
['SOL', 'PRAIA', 'MAR']

2. Escreva criar_saudacao(saudacao) que devolva uma função que recebe um nome e devolve a frase completa. Crie bom_dia e boa_noite com ela.

Ver resposta 
def criar_saudacao(saudacao):
    def saudar(nome):
        return f"{saudacao}, {nome}!"
    return saudar

bom_dia = criar_saudacao("Bom dia")
boa_noite = criar_saudacao("Boa noite")
print(bom_dia("Joana"))
print(boa_noite("Pedro"))

Bom dia, Joana!
Boa noite, Pedro!

3. Monte um dicionário que ligue os comandos "maiúsculas", "minúsculas" e "título" aos métodos str.upper, str.lower e str.title. Aplique cada comando ao texto "são luís do maranhão".

Ver resposta 
comandos = {"maiúsculas": str.upper, "minúsculas": str.lower, "título": str.title}
texto = "são luís do maranhão"
for nome, funcao in comandos.items():
    print(nome, "->", funcao(texto))

maiúsculas -> SÃO LUÍS DO MARANHÃO
minúsculas -> são luís do maranhão
título -> São Luís Do Maranhão

4. Escreva repetir(funcao, vezes) que chama a função recebida (sem argumentos) a quantidade de vezes pedida. Teste com uma função que mostra Bip! três vezes.

Ver resposta 
def repetir(funcao, vezes):
    for _ in range(vezes):
        funcao()

def bip():
    print("Bip!")

repetir(bip, 3)

Bip!
Bip!
Bip!

5. Escreva criar_conversor(taxa), que devolve uma função que converte reais para outra moeda dividindo pela taxa. Crie para_dolar com taxa 5.0 e para_euro com taxa 6.25 e converta R$ 100.

Ver resposta 
def criar_conversor(taxa):
    def converter(reais):
        return reais / taxa
    return converter

para_dolar = criar_conversor(5.0)
para_euro = criar_conversor(6.25)
print(f"US$ {para_dolar(100):.2f}")
print(f"€ {para_euro(100):.2f}")

US$ 20.00
€ 16.00
