Aula 10 · A função print: separador e fim de linha

Nesta aula você vai aprender

  • Mostrar vários valores num único print
  • Trocar o separador entre os valores com sep
  • Controlar o final da linha com end
  • Quebrar linhas com \n e mostrar linhas em branco

Vários valores de uma vez

Você já usou o print para mostrar um texto. Ele aceita vários valores, separados por vírgula, e mostra todos na mesma linha, com um espaço entre eles:

print("Arroz", "feijão", "farofa")
print("Eu tenho", 13, "anos")
print("Placar:", 2, "x", 1)

Arroz feijão farofa
Eu tenho 13 anos
Placar: 2 x 1

Repare que dá para misturar textos e números. O Python coloca os espaços para você.

Atenção: Cada valor precisa ser separado por vírgula. print("Eu tenho" 13 "anos") (sem vírgulas) dá SyntaxError.

Trocando o separador com sep

O espaço entre os valores é o separador padrão. Para usar outro, escreva sep= no fim, dentro dos parênteses:

print("21", "04", "2025", sep="/")
print("Rio", "São Paulo", "Belo Horizonte", sep=" - ")
print("a", "b", "c", sep="")
print("www", "digitar", "com", sep=".")

21/04/2025
Rio - São Paulo - Belo Horizonte
abc
www.digitar.com

sep="" (aspas vazias) junta tudo sem nada no meio.

Mudando o final com end

Normalmente cada print termina pulando para a próxima linha. Com end= você escolhe o que vai no final, no lugar do pulo de linha:

print("Carregando", end="")
print("...", end="")
print(" pronto!")
print("Um", end=" | ")
print("Dois", end=" | ")
print("Três")

Carregando... pronto!
Um | Dois | Três

Os três primeiros print ficaram na mesma linha porque os dois primeiros terminaram com end="".

Dica: Dá para usar sep e end juntos, em qualquer ordem: print("a", "b", sep="-", end="!\n").

Quebra de linha com \n

Dentro de um texto, \n significa "pule uma linha aqui". Assim um único print mostra várias linhas:

print("Lista de compras:\n- pão\n- leite\n- banana")
print()
print("O print vazio acima mostrou uma linha em branco.")

Lista de compras:
- pão
- leite
- banana
 
O print vazio acima mostrou uma linha em branco.

print() sem nada dentro mostra uma linha em branco. Ótimo para separar partes da saída.

Desenhando com print

Com o que você já sabe, dá para fazer pequenos desenhos e cartazes na tela:

print("+---------------+")
print("|  BOM DIA, BR! |")
print("+---------------+")
print("*", "*", "*", sep="   ")

+---------------+
|  BOM DIA, BR! |
+---------------+
*   *   *

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
print("Dia", "mês", "ano", sep="/")

Exercícios

1. Use um único print com sep para mostrar o horário 14:30:00 a partir dos valores "14", "30" e "00".

Ver resposta 
print("14", "30", "00", sep=":")

14:30:00

2. Com um único print e \n, mostre os três primeiros dias da semana, um por linha.

Ver resposta 
print("Segunda\nTerça\nQuarta")

Segunda
Terça
Quarta

3. Use dois print e o parâmetro end para que a saída fique Gol do Brasil! numa linha só.

Ver resposta 
print("Gol do ", end="")
print("Brasil!")

Gol do Brasil!

4. Mostre o CEP 01310-100 usando um só print com os valores "01310" e "100".

Ver resposta 
print("01310", "100", sep="-")

01310-100

5. Faça uma contagem regressiva 3... 2... 1... Já! numa linha só, usando quatro print e end.

Ver resposta 
print("3", end="... ")
print("2", end="... ")
print("1", end="... ")
print("Já!")

3... 2... 1... Já!
