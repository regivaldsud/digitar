Aula 117 · Filas e pilhas com collections.deque

Nesta aula você vai aprender

  • A diferença entre fila (primeiro a chegar, primeiro a sair) e pilha (último a chegar, primeiro a sair)
  • Usar deque com append, appendleft, pop e popleft
  • Guardar só os últimos itens com maxlen
  • Girar os itens com rotate

Filas e pilhas

Pense na fila da cantina: quem chega primeiro é atendido primeiro. Isso é uma fila (em inglês, FIFO: *first in, first out*). Agora pense numa pilha de pratos: o último prato colocado é o primeiro a sair. Isso é uma pilha (LIFO: *last in, first out*).

Uma lista comum serve bem como pilha. Mas como fila ela é lenta: tirar o primeiro item com lista.pop(0) obriga o Python a empurrar todos os outros uma posição. O deque (fala-se "deque", de *double-ended queue*, fila de duas pontas) foi feito para mexer nas duas pontas rapidamente.

A fila da cantina

from collections import deque

fila = deque()
fila.append("Ana")
fila.append("Bruno")
fila.append("Carla")
print("Fila:", list(fila))

atendido = fila.popleft()
print("Atendido:", atendido)
print("Próximo:", fila[0])
print("Ainda esperando:", len(fila))

Fila: ['Ana', 'Bruno', 'Carla']
Atendido: Ana
Próximo: Bruno
Ainda esperando: 2

  • append coloca no fim (a direita);
  • popleft tira do começo (a esquerda) — é o atendimento;
  • fila[0] espia o primeiro sem tirar.
Atenção: Chamar popleft() ou pop() num deque vazio dá IndexError: pop from an empty deque. Antes, confira com if fila:.

Pilha: desfazer

O botão desfazer de um editor é uma pilha: a última ação feita é a primeira a ser desfeita.

from collections import deque

acoes = deque()
for acao in ["digitou 'Olá'", "apagou uma letra", "colou um texto"]:
    acoes.append(acao)

while acoes:
    print("Desfazendo:", acoes.pop())

Desfazendo: colou um texto
Desfazendo: apagou uma letra
Desfazendo: digitou 'Olá'

pop() tira do fim, então sai na ordem contrária à que entrou.

As duas pontas e o maxlen

O deque também tem appendleft e pop. E com maxlen ele guarda só os últimos itens: quando enche, o mais antigo sai sozinho do outro lado. Perfeito para um histórico das últimas tentativas:

from collections import deque

ultimas_ppm = deque(maxlen=3)
for ppm in [18, 22, 25, 27, 31]:
    ultimas_ppm.append(ppm)
    print(list(ultimas_ppm))

print("Média das últimas 3:", round(sum(ultimas_ppm) / len(ultimas_ppm), 1))

prioridade = deque(["Caio", "Duda"])
prioridade.appendleft("Vó Lurdes")
print(list(prioridade))

[18]
[18, 22]
[18, 22, 25]
[22, 25, 27]
[25, 27, 31]
Média das últimas 3: 27.7
['Vó Lurdes', 'Caio', 'Duda']

Girando com rotate

rotate(n) gira os itens n posições para a direita (com n negativo, para a esquerda). Ótimo para rodízios:

from collections import deque

goleiro = deque(["Léo", "Mia", "Nina", "Otto"])
for rodada in range(1, 4):
    print(f"Rodada {rodada}: {goleiro[0]} no gol")
    goleiro.rotate(-1)

Rodada 1: Léo no gol
Rodada 2: Mia no gol
Rodada 3: Nina no gol

proximo = fila.popleft()

Exercícios

1. Simule a fila de um banco: entram Rui, Sol e Téo; depois são atendidas duas pessoas e entra Uri. Mostre quem foi atendido e a fila final.

Ver resposta 
from collections import deque

fila = deque(["Rui", "Sol", "Téo"])
for _ in range(2):
    print("Atendido:", fila.popleft())
fila.append("Uri")
print("Fila final:", list(fila))

Atendido: Rui
Atendido: Sol
Fila final: ['Téo', 'Uri']

2. Use uma pilha para inverter a palavra "arara" e a palavra "python". Elas são palíndromos?

Ver resposta 
from collections import deque

for palavra in ["arara", "python"]:
    pilha = deque(palavra)
    invertida = ""
    while pilha:
        invertida += pilha.pop()
    print(palavra, invertida, palavra == invertida)

arara arara True
python nohtyp False

3. Guarde as 4 últimas buscas de um site: "praia", "bolo", "tênis", "livro", "praia", "jogo". Mostre o histórico no fim, da mais recente para a mais antiga.

Ver resposta 
from collections import deque

buscas = deque(maxlen=4)
for termo in ["praia", "bolo", "tênis", "livro", "praia", "jogo"]:
    buscas.append(termo)
print(list(reversed(buscas)))

['jogo', 'praia', 'livro', 'tênis']

4. Faça um rodízio de quem lava a louça entre ["Pai", "Mãe", "Lia"] para os 5 dias úteis da semana.

Ver resposta 
from collections import deque

dias = ["segunda", "terça", "quarta", "quinta", "sexta"]
vez = deque(["Pai", "Mãe", "Lia"])
for dia in dias:
    print(dia, "->", vez[0])
    vez.rotate(-1)

segunda -> Pai
terça -> Mãe
quarta -> Lia
quinta -> Pai
sexta -> Mãe
