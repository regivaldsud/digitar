Aula 196 · Empacotando o programa com PyInstaller

Nesta aula você vai aprender

  • Instalar e usar o PyInstaller
  • Gerar um executável com janela, sem terminal, e com ícone
  • Achar o resultado na pasta dist e resolver problemas comuns
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Para que serve

Para usar seu programa, um amigo precisaria instalar Python e PySide6. O PyInstaller junta seu código, o Python e as bibliotecas num pacote que roda sozinho. No Windows, o resultado é um .exe.

Gerando o executável

No ambiente virtual do projeto:

pip install pyinstaller
pyinstaller --onefile --windowed --name Calculadora --icon icone.ico calculadora.py
  • --onefile gera um único arquivo .exe (sem ela, sai uma pasta com vários arquivos, que abre mais rápido);
  • --windowed não abre a janela preta do terminal junto;
  • --name dá o nome do executável e --icon usa um ícone .ico.

...
INFO: Building EXE from EXE-00.toc completed successfully.

O executável fica em dist\Calculadora.exe. As pastas build e o arquivo Calculadora.spec são de trabalho do PyInstaller.

Arquivos extras, como o .ui

Se o programa lê arquivos (um .ui, imagens), eles precisam ir junto. Use --add-data "origem;destino" e encontre o caminho certo no código:

pyinstaller --onefile --windowed --add-data "tela.ui;." main.py
import sys
from pathlib import Path


def caminho_recurso(nome):
    base = Path(getattr(sys, "_MEIPASS", Path(__file__).parent))
    return base / nome


print(caminho_recurso("tela.ui"))

Dentro do executável --onefile, os arquivos são descompactados numa pasta temporária guardada em sys._MEIPASS.

Atenção: O executável só roda no sistema em que foi gerado: um .exe feito no Windows não roda no Linux nem no macOS. E alguns antivírus desconfiam de executáveis novos; isso é comum e não quer dizer que seu programa tem vírus.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
pyinstaller --onefile --windowed calculadora.py

Exercícios

1. Qual comando gera um executável chamado Contador.exe, sem janela de terminal, a partir de contador.py?

Ver resposta 
pyinstaller --onefile --windowed --name Contador contador.py

2. Rodei o .exe e ele abre e fecha na hora, sem mostrar nada. Como descobrir o erro?

Ver resposta

Gere de novo SEM a opção --windowed e rode o .exe pelo terminal (cmd).
Assim a mensagem de erro (o traceback) aparece no terminal. Um erro comum
é um arquivo extra (como tela.ui) que não foi incluído com --add-data.
