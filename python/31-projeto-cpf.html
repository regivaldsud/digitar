Aula 31 · Projeto: gerador e validador de CPF

Nesta aula você vai aprender

  • Entender como funcionam os dígitos verificadores do CPF
  • Limpar um texto digitado, deixando só os números
  • Calcular os dois dígitos com laços, listas e o operador %
  • Gerar CPFs fictícios com o módulo random
  • Juntar tudo num programa com menu

O que vamos construir

O CPF tem 11 dígitos: os 9 primeiros identificam a pessoa e os 2 últimos são dígitos verificadores, calculados a partir dos 9 primeiros. Eles servem para pegar erros de digitação: se você trocar um número, a conta não fecha. Vamos fazer um programa que:

  • valida um CPF digitado (com ou sem pontos e traço);
  • gera CPFs fictícios, que passam na validação.
Atenção: Os CPFs deste projeto são fictícios, só para estudar. Nunca use, publique ou peça o CPF verdadeiro de outra pessoa — é um dado pessoal protegido por lei (LGPD).

Passo 1: deixar só os números

A pessoa pode digitar 111.444.777-35 ou 11144477735. Primeiro, vamos guardar só os dígitos, percorrendo o texto com for e usando isdigit() (aula 28):

digitado = "111.444.777-35"
cpf = ""
for caractere in digitado:
    if caractere.isdigit():
        cpf += caractere
print(cpf)
print(len(cpf))

11144477735
11

Um CPF válido precisa ter exatamente 11 dígitos. Também é regra que CPFs com todos os dígitos iguais, como 11111111111, são inválidos — mesmo que a conta feche para eles.

cpf = "11111111111"
print(cpf == cpf[0] * 11)

True

Aqui usamos a repetição de textos: cpf[0] * 11 monta um texto com o primeiro dígito repetido 11 vezes.

Passo 2: o primeiro dígito verificador

A conta do primeiro dígito funciona assim:

  • multiplique os 9 primeiros dígitos pelos pesos 10, 9, 8, 7, 6, 5, 4, 3 e 2 e some tudo;
  • calcule o resto da divisão da soma por 11;
  • se o resto for menor que 2, o dígito é 0; senão, é 11 menos o resto.
cpf = "11144477735"
soma = 0
peso = 10
for digito in cpf[:9]:
    soma += int(digito) * peso
    peso -= 1
resto = soma % 11
d1 = 0 if resto < 2 else 11 - resto
print("Soma:", soma)
print("Resto:", resto)
print("Primeiro dígito:", d1)

Soma: 162
Resto: 8
Primeiro dígito: 3

O resultado bate com o décimo dígito do CPF (3). Repare no ternário da aula 30 escolhendo o valor do dígito.

Passo 3: o segundo dígito verificador

O segundo dígito usa os 9 primeiros mais o primeiro dígito verificador (10 dígitos), com pesos de 11 até 2. O resto da regra é igual.

cpf = "11144477735"
soma = 0
peso = 11
for digito in cpf[:10]:
    soma += int(digito) * peso
    peso -= 1
resto = soma % 11
d2 = 0 if resto < 2 else 11 - resto
print("Segundo dígito:", d2)
print("Confere?", d2 == int(cpf[10]))

Segundo dígito: 5
Confere? True

Dica: Os dois passos são quase iguais: só mudam quantos dígitos entram e o peso inicial. Na aula 40 você vai aprender a transformar isso numa função e escrever a conta uma vez só.

Passo 4: validar vários CPFs

Juntando os passos, dá para validar uma lista inteira. Para cada CPF, limpamos, conferimos o tamanho, recalculamos os dois dígitos e comparamos com os dois últimos:

lista = ["111.444.777-35", "111.444.777-36", "123.456.789-09", "000.000.000-00", "1234"]
for digitado in lista:
    cpf = ""
    for caractere in digitado:
        if caractere.isdigit():
            cpf += caractere
    if len(cpf) != 11 or cpf == cpf[0] * 11:
        print(f"{digitado}: inválido")
        continue
    numeros = cpf[:9]
    for peso_inicial in (10, 11):
        soma = 0
        peso = peso_inicial
        for digito in numeros:
            soma += int(digito) * peso
            peso -= 1
        resto = soma % 11
        numeros += str(0 if resto < 2 else 11 - resto)
    situacao = "válido" if numeros == cpf else "inválido"
    print(f"{digitado}: {situacao}")

111.444.777-35: válido
111.444.777-36: inválido
123.456.789-09: válido
000.000.000-00: inválido
1234: inválido

O truque está no laço for peso_inicial in (10, 11): na primeira volta ele calcula o primeiro dígito e o cola no fim de numeros; na segunda, calcula o segundo dígito usando esses 10 números. No fim, numeros é o CPF "correto" — se for igual ao digitado, ele é válido.

Passo 5: gerar CPFs fictícios

Para gerar, sorteamos 9 dígitos com random.randint(0, 9) e calculamos os dois verificadores com o mesmo laço. Com random.seed(2025), o sorteio sai sempre igual, o que ajuda nos testes:

import random

random.seed(2025)
for vez in range(3):
    numeros = ""
    for i in range(9):
        numeros += str(random.randint(0, 9))
    for peso_inicial in (10, 11):
        soma = 0
        peso = peso_inicial
        for digito in numeros:
            soma += int(digito) * peso
            peso -= 1
        resto = soma % 11
        numeros += str(0 if resto < 2 else 11 - resto)
    print(f"{numeros[:3]}.{numeros[3:6]}.{numeros[6:9]}-{numeros[9:]}")

817.280.569-18
316.610.136-51
160.908.813-17

O fatiamento da aula 20 coloca os pontos e o traço no lugar certo.

Passo 6: o programa completo

Agora um menu com while True (aula 22): a pessoa escolhe validar, gerar ou sair.

import random

print("=== CPF: VALIDADOR E GERADOR ===")
while True:
    print()
    print("1 - Validar um CPF")
    print("2 - Gerar um CPF fictício")
    print("0 - Sair")
    opcao = input("Escolha: ").strip()
    if opcao == "0":
        break
    if opcao == "1":
        digitado = input("Digite o CPF: ")
        cpf = ""
        for caractere in digitado:
            if caractere.isdigit():
                cpf += caractere
        if len(cpf) != 11 or cpf == cpf[0] * 11:
            print("CPF inválido.")
            continue
        numeros = cpf[:9]
    elif opcao == "2":
        numeros = ""
        for i in range(9):
            numeros += str(random.randint(0, 9))
    else:
        print("Opção inválida.")
        continue
    for peso_inicial in (10, 11):
        soma = 0
        peso = peso_inicial
        for digito in numeros:
            soma += int(digito) * peso
            peso -= 1
        resto = soma % 11
        numeros += str(0 if resto < 2 else 11 - resto)
    formatado = f"{numeros[:3]}.{numeros[3:6]}.{numeros[6:9]}-{numeros[9:]}"
    if opcao == "1":
        print("CPF válido!" if numeros == cpf else "CPF inválido.")
    else:
        print("CPF gerado:", formatado)
print("Até logo!")
