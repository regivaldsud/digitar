Todo valor tem um "lado" verdadeiro ou falso

No if e no while, o Python aceita qualquer valor, não só True e False. Ele converte o valor com bool(). Os valores que contam como falso são chamados de falsy; todo o resto é truthy. A lista dos falsy é curta:

  • False e None;
  • o zero: 0, 0.0;
  • coleções e textos vazios: "", [], (), {}, set().
for valor in [0, 7, -1, 0.0, "", " ", "oi", [], [0], {}, None]:
    print(repr(valor), "->", bool(valor))

0 -> False
7 -> True
-1 -> True
0.0 -> False
'' -> False
' ' -> True
'oi' -> True
[] -> False
[0] -> True
{} -> False
None -> False

Repare: " " (um espaço) e [0] (uma lista com um item) são truthy, porque não estão vazios.

Testes mais curtos

Graças a isso, em vez de if len(lista) > 0: você pode escrever só if lista:. E if not nome: pergunta "o nome está vazio?":

tarefas = []
if not tarefas:
    print("Nenhuma tarefa por hoje!")

tarefas.append("estudar Python")
if tarefas:
    print("Você tem", len(tarefas), "tarefa(s)")

Nenhuma tarefa por hoje!
Você tem 1 tarefa(s)

O or devolve o primeiro valor truthy que encontrar. Isso dá um jeito curto de usar um valor padrão quando algo está vazio:

digitado = "   "
nome = digitado.strip() or "Visitante"
print(f"Olá, {nome}!")

digitado = "Marina"
nome = digitado.strip() or "Visitante"
print(f"Olá, {nome}!")

Olá, Visitante!
Olá, Marina!

Atenção: Cuidado quando o zero é um valor válido: pontos = pontos_digitados or 10 troca um 0 legítimo por 10! Nesses casos, compare de forma explícita: if pontos is None:.

isinstance: de que tipo é?

isinstance(valor, tipo) responde se o valor é daquele tipo. Ele aceita uma tupla de tipos, para testar vários de uma vez:

def descrever(valor):
    if isinstance(valor, bool):
        return "verdadeiro/falso"
    if isinstance(valor, (int, float)):
        return "número"
    if isinstance(valor, str):
        return "texto"
    return "outra coisa"

for v in [42, 3.5, "pão", True, [1, 2]]:
    print(repr(v), "é", descrever(v))
print(isinstance(True, int))

42 é número
3.5 é número
'pão' é texto
True é verdadeiro/falso
[1, 2] é outra coisa
True

O bool foi testado primeiro porque, em Python, True e False também são int (valem 1 e 0) — veja a última linha.

Dica: Prefira isinstance(x, int) a type(x) == int: o isinstance também aceita os "filhos" de um tipo, o que vai fazer sentido quando você estudar herança na aula 76.

dir, getattr e hasattr

dir(objeto) lista tudo o que o objeto tem: atributos e métodos. Os nomes com __ são especiais; filtrando, sobram os métodos do dia a dia:

metodos = [m for m in dir("texto") if not m.startswith("_")]
print("upper" in metodos, "split" in metodos)
print(metodos[:8])

True True
['capitalize', 'casefold', 'center', 'count', 'encode', 'endswith', 'expandtabs', 'find']

hasattr(objeto, "nome") pergunta se o objeto tem aquele atributo, e getattr(objeto, "nome") pega o atributo a partir de um texto — útil quando o nome só é conhecido enquanto o programa roda:

frase = "bom dia, brasil"
for nome in ["upper", "title", "voar"]:
    if hasattr(frase, nome):
        metodo = getattr(frase, nome)
        print(nome, "->", metodo())
    else:
        print(nome, "-> str não tem esse método")

print(getattr(frase, "cor", "sem cor"))

upper -> BOM DIA, BRASIL
title -> Bom Dia, Brasil
voar -> str não tem esse método
sem cor

O terceiro argumento de getattr é o valor padrão, usado quando o atributo não existe (sem ele, daria AttributeError).

Exercícios

1. Sem rodar, diga quais destes valores são truthy: 0, "0", [], [[]], None, -0.5. Depois confira com bool.

Ver resposta 
for v in [0, "0", [], [[]], None, -0.5]:
    print(repr(v), bool(v))

0 False
'0' True
[] False
[[]] True
None False
-0.5 True

"0" é um texto não vazio, [[]] é uma lista com um item (mesmo que o item seja uma lista vazia) e -0.5 não é zero: os três são truthy.

2. Escreva a função primeiro_ou_aviso(lista) que devolve o primeiro item da lista ou o texto "lista vazia", usando if not lista:.

Ver resposta 
def primeiro_ou_aviso(lista):
    if not lista:
        return "lista vazia"
    return lista[0]

print(primeiro_ou_aviso(["arroz", "feijão"]))
print(primeiro_ou_aviso([]))

arroz
lista vazia

3. Escreva somar_numeros(itens) que soma só os itens que são int ou float (ignorando textos e o resto). Teste com [10, "dez", 2.5, None, 7].

Ver resposta 
def somar_numeros(itens):
    total = 0
    for item in itens:
        if isinstance(item, (int, float)) and not isinstance(item, bool):
            total += item
    return total

print(somar_numeros([10, "dez", 2.5, None, 7]))

4. Use hasattr para descobrir quais destes objetos têm o método append: uma lista, uma tupla, um texto e um conjunto.

Ver resposta 
for objeto in [[1], (1,), "1", {1}]:
    print(type(objeto).__name__, hasattr(objeto, "append"))

list True
tuple False
str False
set False

Só a lista tem append. O conjunto usa add, e a tupla e o texto não podem ser alterados.
