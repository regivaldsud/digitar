Aula 177 · Senhas fora do código com .env

Nesta aula você vai aprender

  • Por que senha no código é um problema
  • O que são variáveis de ambiente e como lê-las com os.environ

Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

O problema

Se a senha do banco está escrita no código e você envia o projeto para o GitHub, qualquer pessoa pode lê-la. Robôs procuram senhas em repositórios públicos o tempo todo. A regra é: segredos ficam fora do código.

Variáveis de ambiente

O sistema operacional guarda variáveis de ambiente: pares nome=valor que os programas podem ler. No Python, elas ficam em os.environ:

import os

os.environ["MODO"] = "teste"
print(os.environ.get("MODO"))
print(os.environ.get("SENHA_DO_BANCO", "não definida"))

teste
não definida

get com um segundo argumento devolve um valor padrão quando a variável não existe, em vez de dar erro.

O arquivo .env

Escrever variáveis no terminal toda vez é chato. Por isso se usa um arquivo .env na pasta do projeto:

DB_HOST=localhost
DB_USUARIO=root
DB_SENHA=troque_esta_senha

Instale a biblioteca e carregue o arquivo no começo do programa:

pip install python-dotenv
import os
from dotenv import load_dotenv

load_dotenv()
senha = os.environ["DB_SENHA"]
print("Senha carregada com", len(senha), "caracteres")

Se quiser entender o que a biblioteca faz, aqui está uma versão simplificada só com a biblioteca padrão:

import os
from pathlib import Path

Path(".env").write_text("DB_HOST=localhost\nDB_SENHA=troque_esta_senha\n", encoding="utf-8")


def carregar_env(caminho=".env"):
    for linha in Path(caminho).read_text(encoding="utf-8").splitlines():
        linha = linha.strip()
        if linha and not linha.startswith("#") and "=" in linha:
            nome, valor = linha.split("=", 1)
            os.environ.setdefault(nome.strip(), valor.strip())


carregar_env()
print(os.environ["DB_HOST"])

localhost

Não envie o .env

Coloque o .env no .gitignore (aula 244) e crie um .env.exemplo com os nomes das variáveis, mas sem os valores verdadeiros, para quem baixar o projeto saber o que preencher:

# .gitignore
.env
.venv/
__pycache__/
Atenção: Se uma senha já foi enviada para o GitHub, apagar o arquivo depois não resolve: ela continua no histórico. Troque a senha imediatamente.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
senha = os.environ.get("DB_SENHA", "")
