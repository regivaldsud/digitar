Aula 113 · Automatizando o navegador com Selenium

Nesta aula você vai aprender

  • Para que serve o Selenium e quando ele é melhor que requests
  • Abrir uma página e encontrar elementos
  • Digitar, clicar e esperar a página carregar
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Um robô que usa o navegador

O requests (aula 111) só baixa o HTML. Muitos sites montam a página com JavaScript, e aí o conteúdo só aparece num navegador de verdade. O Selenium abre o Chrome ou o Firefox e controla tudo pelo Python: digita, clica, rola a página. Também é muito usado para testar sites automaticamente.

pip install selenium

As versões novas do Selenium baixam sozinhas o "driver" do navegador. Você só precisa ter o Chrome (ou Firefox) instalado.

Primeiro robô

Este exemplo abre o site de documentação do Python, pesquisa uma palavra e mostra o título da página de resultados:

from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.common.keys import Keys
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

navegador = webdriver.Chrome()
try:
    navegador.get("https://docs.python.org/pt-br/3/")
    busca = navegador.find_element(By.NAME, "q")
    busca.send_keys("pathlib")
    busca.send_keys(Keys.ENTER)

    WebDriverWait(navegador, 10).until(EC.title_contains("Buscar"))
    print("Título:", navegador.title)
finally:
    navegador.quit()
  • find_element(By.NAME, "q") acha o campo pelo atributo name; também existem By.ID, By.CSS_SELECTOR e outros;
  • send_keys digita (que nem você no DIGITAR!) e click() clica;
  • WebDriverWait espera até uma condição acontecer, em vez de chutar um tempo.
Atenção: Não use robôs para fazer login em contas, comprar, votar em enquetes ou burlar CAPTCHAs. Além de ir contra as regras da maioria dos sites, pode bloquear a sua conta. Use o Selenium para tarefas suas e para testar os seus próprios sites.
Dica: O try/finally garante que o navegador fecha mesmo se der erro no meio (aula 53). Sem ele, janelas de Chrome vão se acumulando.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
navegador.find_element(By.ID, "busca").click()

Exercícios

1. Escreva um robô que abre https://www.python.org, mostra o título da página e fecha o navegador.

Ver resposta 
from selenium import webdriver

navegador = webdriver.Chrome()
try:
    navegador.get("https://www.python.org")
    print(navegador.title)
finally:
    navegador.quit()

2. Por que WebDriverWait é melhor do que time.sleep(5) para esperar a página?

Ver resposta

time.sleep(5) espera sempre 5 segundos: às vezes é pouco (a página ainda não
carregou) e às vezes é demais (perde tempo). O WebDriverWait espera só até a
condição acontecer, com um limite máximo.
