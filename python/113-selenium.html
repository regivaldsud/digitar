Aula 113 · Automatizando o navegador com Selenium

Nesta aula você vai aprender

  • Para que serve o Selenium e quando ele é melhor que requests
  • Instalar o Selenium e abrir o navegador pelo Python
  • Encontrar elementos com find_element, find_elements e By
  • Digitar com send_keys, clicar com click e ler textos e atributos
  • Esperar a página com WebDriverWait em vez de time.sleep
  • Rodar sem janela (modo headless) e tirar print da tela
Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

Um robô que usa o navegador

O requests (aula 111) só baixa o HTML que o servidor mandou. Muitos sites montam a página depois, com JavaScript, e aí o conteúdo só aparece num navegador de verdade. O Selenium abre o Chrome, o Edge ou o Firefox e controla tudo pelo Python: digita, clica, rola a página, lê o que apareceu.

Ele é muito usado para testar sites automaticamente: em vez de uma pessoa clicar em tudo antes de cada versão nova, um robô faz isso em segundos. Também serve para automatizar tarefas repetitivas suas.

Como abre um navegador inteiro, o Selenium é bem mais lento que o requests. Regra prática: se o dado aparece no HTML baixado com requests, use requests; se só aparece depois que o JavaScript roda, use Selenium.

Instalando

Instale no seu ambiente virtual e tenha o Chrome (ou Edge, ou Firefox) instalado no computador:

# Windows
py -m pip install selenium

# Linux e macOS
python3 -m pip install selenium

O navegador é controlado por um programa auxiliar chamado driver. As versões novas do Selenium (4.6 em diante) baixam o driver certo sozinhas na primeira vez que você roda, por isso a primeira execução demora um pouco mais e precisa de internet.

Abrindo uma página

Salve como primeiro_robo.py e rode no computador. Uma janela do Chrome vai abrir sozinha, carregar o site e fechar:

from selenium import webdriver

navegador = webdriver.Chrome()      # ou webdriver.Edge(), webdriver.Firefox()
try:
    navegador.get("https://www.python.org")
    print("Título:", navegador.title)
    print("Endereço:", navegador.current_url)
finally:
    navegador.quit()

Título: Welcome to Python.org
Endereço: https://www.python.org/

Dica: O try/finally garante que o navegador fecha mesmo se der erro no meio (aula 53). Sem ele, janelas e processos do Chrome vão se acumulando no seu computador.

Encontrando elementos

Para mexer num campo ou botão, primeiro você precisa achá-lo. O find_element recebe como procurar (By) e o quê:

  • By.ID pelo atributo id (o jeito mais confiável, porque é único);
  • By.NAME pelo atributo name dos campos de formulário;
  • By.CLASS_NAME por uma classe;
  • By.CSS_SELECTOR por um seletor CSS, como "li.prato span" (aula 242);
  • By.TAG_NAME pelo nome da tag, como "h1".

find_element devolve o primeiro que achar (e dá erro NoSuchElementException se não achar nenhum); find_elements, no plural, devolve uma lista, que pode vir vazia.

A ideia por trás é a mesma da raspagem (aula 112): percorrer a árvore do HTML e parar no elemento com o id ou a classe pedida. Este exemplo, que roda aqui no navegador, imita um find_element simples com o html.parser:

from html.parser import HTMLParser

pagina = """
<form>
  <input id="nome" name="nome" class="campo">
  <input id="email" name="email" class="campo">
  <button id="enviar" class="botao principal">Enviar</button>
</form>
"""


class Procurador(HTMLParser):
    def __init__(self):
        super().__init__()
        self.elementos = []

    def handle_starttag(self, tag, attrs):
        self.elementos.append((tag, dict(attrs)))


def procurar(por, valor):
    p = Procurador()
    p.feed(pagina)
    achados = []
    for tag, atributos in p.elementos:
        if por == "id" and atributos.get("id") == valor:
            achados.append(tag)
        elif por == "classe" and valor in atributos.get("class", "").split():
            achados.append(atributos.get("id"))
    return achados


print("id 'email':", procurar("id", "email"))
print("classe 'campo':", procurar("classe", "campo"))
print("classe 'principal':", procurar("classe", "principal"))
print("id 'senha':", procurar("id", "senha"))

id 'email': ['input']
classe 'campo': ['nome', 'email']
classe 'principal': ['enviar']
id 'senha': []

Repare que um elemento pode ter várias classes separadas por espaço ("botao principal"), e que procurar algo que não existe devolve uma lista vazia — igualzinho ao find_elements.

Digitando e clicando

Para treinar sem depender de nenhum site, o robô abaixo cria uma página de cadastro no seu computador e abre o arquivo no navegador. A página tem um campo, um botão e um parágrafo que o JavaScript preenche quando você clica:

from pathlib import Path
from selenium import webdriver
from selenium.webdriver.common.by import By

Path("cadastro.html").write_text("""<!doctype html>
<html><body>
  <h1>Cadastro</h1>
  <input id="nome">
  <button id="enviar"
    onclick="document.getElementById('msg').textContent =
             'Olá, ' + document.getElementById('nome').value + '!'">Enviar</button>
  <p id="msg"></p>
</body></html>""", encoding="utf-8")

navegador = webdriver.Chrome()
try:
    navegador.get(Path("cadastro.html").resolve().as_uri())
    campo = navegador.find_element(By.ID, "nome")
    campo.send_keys("Joana")
    navegador.find_element(By.ID, "enviar").click()

    print(navegador.find_element(By.TAG_NAME, "h1").text)
    print(navegador.find_element(By.ID, "msg").text)
    print("Valor do campo:", campo.get_attribute("value"))
finally:
    navegador.quit()

Cadastro
Olá, Joana!
Valor do campo: Joana

  • send_keys("texto") digita no campo, tecla por tecla (que nem você no DIGITAR!); clear() apaga o que já estava escrito;
  • click() clica no elemento;
  • .text é o texto visível do elemento e get_attribute("value") lê um atributo;
  • Path(...).resolve().as_uri() transforma o caminho do arquivo num endereço file:///..., que o navegador sabe abrir.

Esperando a página carregar

O robô é muito mais rápido que a página. Se ele procurar um elemento antes de a página terminar de carregar, recebe NoSuchElementException. A solução é esperar — mas do jeito certo. O WebDriverWait fica conferindo uma condição até ela acontecer, com um tempo máximo:

from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.common.keys import Keys
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

navegador = webdriver.Chrome()
try:
    navegador.get("https://docs.python.org/pt-br/3/")
    busca = navegador.find_element(By.NAME, "q")
    busca.send_keys("pathlib")
    busca.send_keys(Keys.ENTER)

    espera = WebDriverWait(navegador, 10)
    espera.until(EC.title_contains("Busca"))
    resultados = espera.until(
        EC.presence_of_all_elements_located((By.CSS_SELECTOR, "ul.search li a"))
    )
    print("Título:", navegador.title)
    print("Primeiro resultado:", resultados[0].text)
finally:
    navegador.quit()

Título: Busca — documentação Python 3 (o número da versão aparece no título)
Primeiro resultado: pathlib — Caminhos de sistema de arquivos orientados a objetos

  • Keys.ENTER aperta a tecla Enter; há também Keys.TAB, Keys.ESCAPE e outras;
  • EC.title_contains, EC.presence_of_element_located e EC.element_to_be_clickable são condições prontas; repare que o localizador vai como uma tupla (By..., "..."), com parênteses extras;
  • se a condição não acontecer em 10 segundos, aparece TimeoutException, que você pode tratar com try/except.
Atenção: Não use time.sleep(5) para esperar a página. Às vezes 5 segundos é pouco (a internet está lenta e o programa quebra) e às vezes é demais (o robô fica parado à toa). O WebDriverWait espera só o necessário. Os textos de sites reais também mudam: se a documentação mudar o título, ajuste a condição.

Sem janela: o modo headless

Para tarefas que rodam sozinhas (num servidor, num agendamento), não é preciso ver a janela. O modo headless ("sem cabeça") roda o navegador escondido. Dá até para tirar um print da página:

from selenium import webdriver
from selenium.webdriver.common.by import By

opcoes = webdriver.ChromeOptions()
opcoes.add_argument("--headless=new")
opcoes.add_argument("--window-size=1280,800")

navegador = webdriver.Chrome(options=opcoes)
try:
    navegador.get("https://www.python.org")
    links = navegador.find_elements(By.CSS_SELECTOR, "#top ul.menu li a")
    print(len(links), "links no menu do topo")
    navegador.save_screenshot("python_org.png")
    print("Print salvo em python_org.png")
finally:
    navegador.quit()

6 links no menu do topo (o número muda se o site mudar o menu)
Print salvo em python_org.png

Atenção: Não use robôs para fazer login em contas, comprar, votar em enquetes, mandar mensagens em massa ou burlar CAPTCHAs. Além de ir contra as regras da maioria dos sites, pode bloquear a sua conta. Use o Selenium para tarefas suas e para testar os seus próprios sites.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
navegador.find_element(By.ID, "busca").click()

3. Por que WebDriverWait é melhor do que time.sleep(5) para esperar a página?

Ver resposta

time.sleep(5) espera sempre 5 segundos: às vezes é pouco (a página ainda não
carregou e o programa quebra) e às vezes é demais (perde tempo). O WebDriverWait
espera só até a condição acontecer, com um limite máximo, e avisa com
TimeoutException se passar do limite.

4. Usando a ideia do exemplo com html.parser, escreva uma função texto_do_id(pagina, id_procurado) que devolve o texto de dentro do elemento com aquele id. Teste com <p id="msg">Olá, Joana!</p><p id="rodape">Fim</p>.

Ver resposta 
from html.parser import HTMLParser


class LeitorDeTexto(HTMLParser):
    def __init__(self, id_procurado):
        super().__init__()
        self.id_procurado = id_procurado
        self.dentro = False
        self.texto = ""

    def handle_starttag(self, tag, attrs):
        if dict(attrs).get("id") == self.id_procurado:
            self.dentro = True

    def handle_data(self, dado):
        if self.dentro:
            self.texto += dado

    def handle_endtag(self, tag):
        self.dentro = False


def texto_do_id(pagina, id_procurado):
    leitor = LeitorDeTexto(id_procurado)
    leitor.feed(pagina)
    return leitor.texto


pagina = '<p id="msg">Olá, Joana!</p><p id="rodape">Fim</p>'
print(texto_do_id(pagina, "msg"))
print(texto_do_id(pagina, "rodape"))

Olá, Joana!
Fim

É o que o Selenium faz por você com navegador.find_element(By.ID, "msg").text.
