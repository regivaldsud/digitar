Aula 12 · Números (int, float) e verdadeiro/falso (bool)

Nesta aula você vai aprender

  • Diferenciar números inteiros (int) de números reais (float)
  • Escrever números grandes com _ e decimais com ponto

  • Saber qual tipo resulta de uma conta

Inteiros: o tipo int

Números sem casas decimais são do tipo int (de *integer*, inteiro): 13, 0, -5, 2025. Eles podem ser enormes, sem limite de tamanho.

print(13)
print(-5)
print(type(2025))
print(2 ** 100)

13
-5
<class 'int'>
1267650600228229401496703205376

2 ** 100 é 2 elevado a 100, um número com 31 dígitos. O Python faz essa conta sem reclamar.

Dica: Para números grandes, você pode separar os milhares com _ para ficar fácil de ler: 1_000_000 é um milhão. O Python ignora o sublinhado.

Reais: o tipo float

Números com casas decimais são do tipo float: 1.75, 3.5, -0.25. Em Python, a parte decimal é separada por ponto, como na calculadora, e não por vírgula.

print(1.75)
print(type(1.75))
print(type(10.0))
print(1_000_000)
print(.5)

1.75
<class 'float'>
<class 'float'>
1000000
0.5

Repare que 10.0 é float, mesmo valendo dez: o ponto já basta para ser real. E .5 é o mesmo que 0.5.

Atenção: Escrever 1,75 não dá o número 1,75! Para o Python, a vírgula separa valores: print(1,75) mostra 1 75, dois números inteiros.

Que tipo sai de uma conta?

Quando você faz uma conta, o tipo do resultado segue regras simples:

  • int com int dá int (na soma, subtração e multiplicação);
  • se aparecer um float na conta, o resultado é float;
  • a divisão / sempre dá float, mesmo quando é exata.
print(7 + 3)
print(7 + 3.0)
print(6 / 2)
print(type(6 / 2))
print(2 * 2.5)

10
10.0
3.0
<class 'float'>
5.0

Verdadeiro ou falso: o tipo bool

O tipo bool tem só dois valores: True (verdadeiro) e False (falso). Ele é a base das decisões que o programa vai tomar.

print(True)
print(False)
print(type(True))
print(10 > 3)
print(10 < 3)

True
False
<class 'bool'>
True
False

Toda comparação, como 10 > 3, dá um bool. Você vai estudar as comparações a fundo na aula 19.

Atenção: Escreva True e False com a primeira letra maiúscula e sem aspas. true dá NameError, e "True" (com aspas) é um texto, não um bool.

Curiosidade: bool também é número

Por dentro, True vale 1 e False vale 0. Por isso dá até para somar:

print(True + True)
print(True + 10)
print(False * 100)

2
11
0

Isso parece estranho, mas é útil para contar quantas coisas são verdadeiras — você vai ver isso no futuro.

2. Sem rodar, diga se o resultado de cada conta é int ou float: 5 + 5, 5 + 5.0, 10 / 5, 3 * 4. Depois confira.

Ver resposta 
print(type(5 + 5))
print(type(5 + 5.0))
print(type(10 / 5))
print(type(3 * 4))

<class 'int'>
<class 'float'>
<class 'float'>
<class 'int'>

3. Mostre o número de habitantes do Brasil, 215 milhões, escrito no código com _ para separar os milhares.

Ver resposta 
print(215_000_000)

215000000

4. Explique por que print(3,14) não mostra o número pi. Como escrever certo?

Ver resposta 
print(3,14)
print(3.14)

3 14
3.14

Com vírgula, o print recebe dois números, 3 e 14, e mostra os dois separados por espaço. O número real se escreve com ponto: 3.14.

5. Mostre o resultado de True + True + False + True. Por que dá esse número?

Ver resposta 
print(True + True + False + True)

3

Cada True vale 1 e cada False vale 0, então a conta é 1 + 1 + 0 + 1.
