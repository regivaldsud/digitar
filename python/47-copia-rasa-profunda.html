Aula 47 · Cópia rasa e cópia profunda

Nesta aula você vai aprender

  • Lembrar a diferença entre apelido (b = a) e cópia

  • Fazer uma cópia profunda com copy.deepcopy

Relembrando: apelido não é cópia

Na aula 26 você viu que b = a não cria uma lista nova: b vira outro nome para a mesma lista. Para copiar, usamos a.copy(), list(a) ou a[:]. O operador is confirma se dois nomes são o mesmo objeto:

original = ["lápis", "borracha"]
apelido = original
copia = original.copy()
print(apelido is original)
print(copia is original)
copia.append("régua")
print(original)
print(copia)

True
False
['lápis', 'borracha']
['lápis', 'borracha', 'régua']

Quando a cópia não basta

O copy() faz uma cópia rasa: cria uma lista nova, mas os itens de dentro continuam sendo os mesmos objetos. Se os itens forem números ou textos, tudo bem. Mas se forem listas (ou dicionários), as duas "cópias" compartilham as listas de dentro:

turma_a = [["Ana", 8], ["Bruno", 6]]
turma_b = turma_a.copy()
turma_b.append(["Caio", 9])
turma_b[0][1] = 10
print(turma_a)
print(turma_b)
print(turma_a[0] is turma_b[0])

[['Ana', 10], ['Bruno', 6]]
[['Ana', 10], ['Bruno', 6], ['Caio', 9]]
True

O append só mudou turma_b (a lista de fora é nova), mas a nota da Ana mudou nas duas, porque ["Ana", 8] é o mesmo objeto nas duas listas.

Atenção: A fatia [:], o list(), o dict.copy() e o copy.copy() fazem todos cópia rasa. Para listas de listas e dicionários com listas dentro, eles não bastam.

Cópia profunda com deepcopy

O módulo copy tem a função deepcopy, que copia tudo, inclusive o que está dentro do que está dentro:

import copy

turma_a = [["Ana", 8], ["Bruno", 6]]
turma_b = copy.deepcopy(turma_a)
turma_b[0][1] = 10
print(turma_a)
print(turma_b)
print(turma_a[0] is turma_b[0])

[['Ana', 8], ['Bruno', 6]]
[['Ana', 10], ['Bruno', 6]]
False

O mesmo vale para dicionários

Um dicionário com listas dentro tem o mesmo problema:

import copy

cardapio = {"segunda": ["arroz", "feijão"], "terça": ["macarrão"]}
raso = cardapio.copy()
profundo = copy.deepcopy(cardapio)

raso["segunda"].append("farofa")
print(cardapio["segunda"])
profundo["terça"].append("salada")
print(cardapio["terça"])
print(profundo["terça"])

['arroz', 'feijão', 'farofa']
['macarrão']
['macarrão', 'salada']

Dica: Na dúvida, pergunte: "minha estrutura tem listas ou dicionários dentro dela?" Se tiver e você vai alterar a cópia, use copy.deepcopy. Se não tiver, um copy() simples resolve e é mais rápido.

Um caso comum: o tabuleiro

Criar uma grade com * também cria listas compartilhadas, porque repete o mesmo objeto:

errado = [["."] * 3] * 3
errado[0][0] = "X"
print(errado)

certo = [["."] * 3 for _ in range(3)]
certo[0][0] = "X"
print(certo)

[['X', '.', '.'], ['X', '.', '.'], ['X', '.', '.']]
[['X', '.', '.'], ['.', '.', '.'], ['.', '.', '.']]

Com a compreensão de lista (aula 50), cada linha é uma lista nova.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
copia = copy.deepcopy(original)

Exercícios

1. Explique o que este código mostra e corrija para que a não mude: a = [[1, 2], [3, 4]], b = a.copy(), b[1][0] = 99, print(a).

Ver resposta 
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
b[1][0] = 99
print(a)
print(b)

[[1, 2], [3, 4]]
[[1, 2], [99, 4]]

Com a.copy() a lista de dentro [3, 4] seria a mesma nas duas, e print(a) mostraria [[1, 2], [99, 4]]. Com deepcopy, a fica intacta.

2. Crie uma ficha {"nome": "Theo", "jogos": ["xadrez", "damas"]}, faça uma cópia profunda, adicione "dominó" aos jogos da cópia e mostre as duas fichas.

Ver resposta 
import copy

ficha = {"nome": "Theo", "jogos": ["xadrez", "damas"]}
copia = copy.deepcopy(ficha)
copia["jogos"].append("dominó")
print(ficha)
print(copia)

{'nome': 'Theo', 'jogos': ['xadrez', 'damas']}
{'nome': 'Theo', 'jogos': ['xadrez', 'damas', 'dominó']}

3. Por que lista = [1, 2, 3] e copia = lista[:] funciona bem como cópia, mesmo sendo rasa? Mostre com um teste.

Ver resposta 
lista = [1, 2, 3]
copia = lista[:]
copia[0] = 100
print(lista)
print(copia)

[1, 2, 3]
[100, 2, 3]

Os itens são números, que não podem ser alterados por dentro. Trocar copia[0] só troca o item da lista nova; a original não é afetada.

4. Crie um tabuleiro de jogo da velha 3x3 cheio de " " sem o problema das linhas compartilhadas, coloque um "O" no centro e mostre as linhas.

Ver resposta 
tabuleiro = [[" "] * 3 for _ in range(3)]
tabuleiro[1][1] = "O"
for linha in tabuleiro:
    print(linha)

[' ', ' ', ' ']
[' ', 'O', ' ']
[' ', ' ', ' ']
