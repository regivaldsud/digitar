O que é o Django

Um site tem muitas partes repetitivas: receber o pedido do navegador, falar com o banco de dados, montar o HTML, cuidar de login e segurança. O Django é um framework: um conjunto de peças prontas, em Python, que resolve tudo isso. Sites grandes como o Instagram começaram com Django.

Um site precisa de um servidor rodando, então todo este módulo é feito no seu computador.

Criando o projeto

mkdir meusite
cd meusite
python -m venv .venv
.venv\Scripts\activate
pip install django
django-admin startproject config .
python manage.py runserver

Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.

Abra http://127.0.0.1:8000/ no navegador: aparece a página com um foguete dizendo que deu certo. Para parar o servidor, aperte Ctrl+C no terminal.

Dica: O ponto no fim de startproject config . cria o projeto na pasta atual, sem uma pasta extra dentro da outra. Chamar o projeto de config deixa claro que ali ficam as configurações.

O que foi criado

meusite/
├── manage.py          <- seu "controle remoto" do projeto
└── config/
    ├── settings.py    <- configurações (apps, banco, idioma...)
    ├── urls.py        <- quais endereços o site tem
    ├── asgi.py
    └── wsgi.py        <- usados para publicar o site

O manage.py roda os comandos do projeto: runserver, startapp, migrate, createsuperuser e outros.

Apps: as partes do site

Um projeto Django é dividido em apps, cada um cuidando de uma parte (blog, loja, contatos). Crie um e registre no settings.py:

python manage.py startapp contatos
# config/settings.py (trecho)
INSTALLED_APPS = [
    "django.contrib.admin",
    "django.contrib.auth",
    "django.contrib.contenttypes",
    "django.contrib.sessions",
    "django.contrib.messages",
    "django.contrib.staticfiles",
    "contatos",
]

LANGUAGE_CODE = "pt-br"
TIME_ZONE = "America/Sao_Paulo"
Atenção: Esquecer de pôr o app em INSTALLED_APPS é um erro clássico: os models e templates dele não são encontrados.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
python manage.py startapp contatos

Exercícios

1. Quais comandos criam um projeto config na pasta atual e um app chamado receitas?

Ver resposta 
django-admin startproject config .
python manage.py startapp receitas

Depois, acrescente "receitas" em INSTALLED_APPS.

2. O servidor mostrou Error: That port is already in use. O que fazer?

Ver resposta 
python manage.py runserver 8001

Outro programa (talvez outro servidor seu) já usa a porta 8000. Feche-o com Ctrl+C ou rode em outra porta, como 8001.
