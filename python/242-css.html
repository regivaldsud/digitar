Aula para fazer no computador: o assunto desta aula precisa do seu computador. Os códigos sem o botão Executar devem ser copiados para um arquivo .py no VS Code e rodados no seu computador, como mostrado na aula 03.

O que é CSS

Se o HTML diz o que é cada parte da página, o CSS diz como ela aparece: cores, fontes, tamanhos, espaços e posição. O CSS fica num arquivo separado, estilo.css, ligado à página por uma linha dentro do <head>:

<link rel="stylesheet" href="estilo.css">

Seletores e propriedades

Uma regra de CSS tem um seletor (quem vai mudar) e, entre chaves, propriedades com valores:

body {
  font-family: Arial, sans-serif;
  background: #f4f7fb;
  color: #222;
}

h1 { color: #0b6e4f; }            /* todas as tags h1 */
.destaque { font-weight: bold; }   /* elementos com class="destaque" */
#topo { padding: 16px; }           /* o elemento com id="topo" */

No HTML, a classe vai assim: <p class="destaque">Promoção!</p>. Uma classe pode ser usada em vários elementos; um id deve ser único na página.

Atenção: Cada propriedade termina com ponto e vírgula. Esquecer o ; faz o navegador ignorar a propriedade seguinte, sem mostrar erro nenhum. Os comentários do CSS são /* assim */, não #.

O modelo de caixa

Todo elemento é uma caixa. De dentro para fora: o conteúdo, o padding (espaço interno), a border (borda) e a margin (espaço externo, que afasta das outras caixas).

.cartao {
  padding: 16px;
  border: 2px solid #0b6e4f;
  border-radius: 8px;
  margin: 12px;
}

Flexbox e grid

O flexbox coloca itens em linha (ou coluna) e distribui o espaço. O grid monta uma grade com linhas e colunas:

.menu {
  display: flex;
  gap: 12px;
  justify-content: space-between;
}

.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 8px;
}

1fr quer dizer "uma fração do espaço livre": com repeat(3, 1fr), a galeria fica com três colunas iguais.

Dica: Aperte F12 no navegador para abrir as Ferramentas do desenvolvedor. Lá você clica num elemento, vê o CSS dele e testa mudanças na hora, sem salvar nada.

Gerando o CSS com Python

Um programa Python pode escrever o CSS também. Este cria um tema com as cores guardadas num dicionário:

from pathlib import Path

cores = {"fundo": "#f4f7fb", "texto": "#222222", "destaque": "#0b6e4f"}

css = f"""body {{
  background: {cores["fundo"]};
  color: {cores["texto"]};
}}
h1 {{ color: {cores["destaque"]}; }}
"""
Path("estilo.css").write_text(css, encoding="utf-8")
print(css)

body {
  background: #f4f7fb;
  color: #222222;
}
h1 { color: #0b6e4f; }

Repare que, dentro de uma f-string, as chaves do CSS precisam ser dobradas ({{ e }}); as chaves simples são do Python.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
.menu { display: flex; gap: 12px; }

Exercícios

1. Escreva uma regra CSS que deixe todos os parágrafos com letra tamanho 18px e cor cinza-escuro (#333).

Ver resposta 
p {
  font-size: 18px;
  color: #333;
}

2. Escreva o CSS de uma classe .grade que mostre os itens em 4 colunas iguais, com 10px de espaço entre eles.

Ver resposta 
.grade {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 10px;
}

3. Faça um programa Python que gere uma regra CSS .botao-N com uma cor diferente para cada cor da lista ["red", "green", "blue"], numerando de 1 a 3.

Ver resposta 
cores = ["red", "green", "blue"]

for numero, cor in enumerate(cores, start=1):
    print(f".botao-{numero} {{ background: {cor}; }}")

.botao-1 { background: red; }
.botao-2 { background: green; }
.botao-3 { background: blue; }
