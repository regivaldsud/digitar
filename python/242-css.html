O que é CSS

Se o HTML diz o que é cada parte da página, o CSS diz como ela aparece: cores, fontes, tamanhos, espaços e posição. Separar os dois é uma ótima ideia: para mudar a cor do site inteiro, você mexe num arquivo só.

O CSS fica num arquivo separado, estilo.css, ligado à página por uma linha dentro do <head>:

<link rel="stylesheet" href="estilo.css">
Atenção: Se o CSS "não pega", quase sempre o caminho no href está errado ou o arquivo tem outro nome. O estilo.css precisa estar na mesma pasta do HTML (ou o href tem de apontar para a pasta certa). Aperte Ctrl + F5 para o navegador recarregar sem usar a cópia antiga.

Seletores e propriedades

Uma regra de CSS tem um seletor (quem vai mudar) e, entre chaves, propriedades com valores:

body {
  font-family: Arial, sans-serif;
  background: #f4f7fb;
  color: #222;
}

h1 { color: #0b6e4f; }            /* todas as tags h1 */
.destaque { font-weight: bold; }   /* elementos com class="destaque" */
#topo { padding: 16px; }           /* o elemento com id="topo" */
nav a { text-decoration: none; }   /* links que estão dentro de nav */
a:hover { color: tomato; }         /* link com o mouse em cima */

No HTML, a classe vai assim: <p class="destaque">Promoção!</p>. Uma classe pode ser usada em vários elementos; um id deve ser único na página.

As cores podem ser nomes (tomato), códigos #rrggbb (vermelho, verde e azul em hexadecimal, de 00 a ff) ou rgb(255, 99, 71). O Python converte uma na outra facilmente:

def hex_para_rgb(cor):
    cor = cor.lstrip("#")
    return tuple(int(cor[i:i + 2], 16) for i in (0, 2, 4))


def rgb_para_hex(r, g, b):
    return f"#{r:02x}{g:02x}{b:02x}"


print(hex_para_rgb("#0b6e4f"))
print(rgb_para_hex(255, 99, 71))

(11, 110, 79)
#ff6347

Atenção: Cada propriedade termina com ponto e vírgula. Esquecer o ; faz o navegador ignorar a propriedade seguinte, sem mostrar erro nenhum. Os comentários do CSS são /* assim */, não #.

Quem ganha? A especificidade

Quando duas regras mudam a mesma propriedade do mesmo elemento, vence a mais específica. Uma conta simples ajuda: cada id vale 100 pontos, cada classe (ou :hover) vale 10 e cada tag vale 1. Empatou? Vence a regra que aparece por último no arquivo.

import re


def pontos(seletor):
    ids = len(re.findall(r"#[\w-]+", seletor))
    classes = len(re.findall(r"[.:][\w-]+", seletor))
    sem_ids_classes = re.sub(r"[#.:][\w-]+", " ", seletor)
    tags = len(re.findall(r"[a-zA-Z][\w-]*", sem_ids_classes))
    return ids * 100 + classes * 10 + tags


regras = {"p": "preto", ".aviso": "laranja", "p.aviso": "vermelho", "#topo p": "azul"}
for seletor, cor in regras.items():
    print(f"{seletor:10} {pontos(seletor):3} pontos -> {cor}")

vencedora = max(regras, key=pontos)
print("Um <p class='aviso'> dentro de #topo fica", regras[vencedora])

p            1 pontos -> preto
.aviso      10 pontos -> laranja
p.aviso     11 pontos -> vermelho
#topo p    101 pontos -> azul
Um <p class='aviso'> dentro de #topo fica azul

(É uma conta simplificada, mas vale para a grande maioria dos casos.)

O modelo de caixa

Todo elemento é uma caixa. De dentro para fora: o conteúdo, o padding (espaço interno), a border (borda) e a margin (espaço externo, que afasta das outras caixas).

.cartao {
  width: 300px;
  padding: 16px;
  border: 2px solid #0b6e4f;
  border-radius: 8px;
  margin: 12px;
}

Uma surpresa comum: o width vale só para o conteúdo. O padding e a borda são somados dos dois lados. Com box-sizing: border-box, o width passa a incluir padding e borda — bem mais fácil de planejar:

def largura_na_tela(width, padding, border, box_sizing="content-box"):
    if box_sizing == "border-box":
        return width
    return width + 2 * padding + 2 * border


print("content-box:", largura_na_tela(300, 16, 2), "px")
print("border-box: ", largura_na_tela(300, 16, 2, "border-box"), "px")
print("Espaço ocupado com margin de 12px:", largura_na_tela(300, 16, 2) + 2 * 12, "px")

content-box: 336 px
border-box:  300 px
Espaço ocupado com margin de 12px: 360 px

Dica: Muitos sites começam o CSS com * { box-sizing: border-box; }, que vale para todos os elementos. Assim um cartão de width: 300px ocupa 300px mesmo, sem contas.

Flexbox e grid

O flexbox coloca itens em linha (ou coluna) e distribui o espaço entre eles — ótimo para menus e fileiras de cartões. O grid monta uma grade com linhas e colunas — ótimo para galerias e para o esqueleto da página:

.menu {
  display: flex;
  gap: 12px;                       /* espaço entre os itens */
  justify-content: space-between;  /* espalha na horizontal */
  align-items: center;             /* centraliza na vertical */
}

.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 8px;
}

1fr quer dizer "uma fração do espaço livre". A conta que o navegador faz é esta:

def colunas_grid(largura, fracoes, gap):
    livre = largura - gap * (len(fracoes) - 1)
    total = sum(fracoes)
    return [round(livre * f / total, 1) for f in fracoes]


print("repeat(3, 1fr) em 600px:", colunas_grid(600, [1, 1, 1], 8))
print("2fr 1fr em 600px:       ", colunas_grid(600, [2, 1], 8))

repeat(3, 1fr) em 600px: [194.7, 194.7, 194.7]
2fr 1fr em 600px:        [394.7, 197.3]

Dica: Aperte F12 no navegador para abrir as Ferramentas do desenvolvedor. Lá você clica num elemento, vê o CSS dele, a caixa com margin e padding desenhados, e testa mudanças na hora, sem salvar nada.

Página que se adapta ao celular

Uma media query aplica regras só quando a tela tem certo tamanho. Assim a galeria tem 3 colunas no computador e 1 no celular:

.galeria { display: grid; grid-template-columns: repeat(3, 1fr); }

@media (max-width: 600px) {
  .galeria { grid-template-columns: 1fr; }
}

Não esqueça a linha <meta name="viewport" content="width=device-width, initial-scale=1"> no HTML (aula 241); sem ela, o celular finge ser uma tela larga e a media query não funciona.

Gerando o CSS com Python

Um programa Python pode escrever o CSS também. Guardando as cores num dicionário, dá para criar um tema claro e um escuro com o mesmo código:

temas = {
    "claro": {"fundo": "#f4f7fb", "texto": "#222222", "destaque": "#0b6e4f"},
    "escuro": {"fundo": "#121212", "texto": "#eeeeee", "destaque": "#4cd3a5"},
}


def gerar_css(cores):
    return f"""body {{
  background: {cores["fundo"]};
  color: {cores["texto"]};
}}
h1 {{ color: {cores["destaque"]}; }}"""


print("/* tema escuro */")
print(gerar_css(temas["escuro"]))

/* tema escuro */
body {
  background: #121212;
  color: #eeeeee;
}
h1 { color: #4cd3a5; }

Repare que, dentro de uma f-string, as chaves do CSS precisam ser dobradas ({{ e }}); as chaves simples são do Python. No seu computador, grave com Path("estilo.css").write_text(css, encoding="utf-8").

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
.menu { display: flex; gap: 12px; }

Exercícios

1. Escreva uma regra CSS que deixe todos os parágrafos com letra tamanho 18px e cor cinza-escuro (#333).

Ver resposta 
p {
  font-size: 18px;
  color: #333;
}

2. Escreva o CSS de uma classe .grade que mostre os itens em 4 colunas iguais, com 10px de espaço entre eles, e que vire 2 colunas em telas de até 700px.

Ver resposta 
.grade {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 10px;
}

@media (max-width: 700px) {
  .grade { grid-template-columns: repeat(2, 1fr); }
}

3. Uma caixa tem width: 200px, padding: 10px e border: 5px. Quanto ela ocupa na tela com content-box e com border-box? Calcule com Python.

Ver resposta 
width, padding, border = 200, 10, 5

print("content-box:", width + 2 * padding + 2 * border, "px")
print("border-box:", width, "px (o conteúdo fica com", width - 2 * padding - 2 * border, "px)")

content-box: 230 px
border-box: 200 px (o conteúdo fica com 170 px)

4. Faça um programa Python que gere uma regra CSS .botao-N com uma cor diferente para cada cor da lista ["red", "green", "blue"], numerando de 1 a 3.

Ver resposta 
cores = ["red", "green", "blue"]

for numero, cor in enumerate(cores, start=1):
    print(f".botao-{numero} {{ background: {cor}; }}")

.botao-1 { background: red; }
.botao-2 { background: green; }
.botao-3 { background: blue; }

5. Um <p id="aviso" class="alerta"> recebe p { color: black }, .alerta { color: orange } e #aviso { color: red }. De que cor ele fica, e por quê?

Ver resposta

Vermelho. O seletor de id (#aviso) vale 100 pontos, mais que a classe (.alerta, 10)
e que a tag (p, 1). A ordem das regras no arquivo só desempata quando os pontos são iguais.
