Iterável e iterador: dois papéis

Na aula 52 você viu que o for funciona com qualquer iterável: listas, textos, dicionários, geradores. Por dentro, o for faz duas coisas: pede um iterador ao objeto com iter() e depois chama next() nele até acabar.

  • Iterável é quem sabe criar um iterador: tem o método __iter__.
  • Iterador é quem entrega os itens um por um: tem __next__ (e também __iter__, que devolve ele mesmo). Quando acabam os itens, ele levanta StopIteration.
frutas = ["caju", "manga", "acerola"]
it = iter(frutas)
print(next(it))
print(next(it))
print(next(it))
try:
    next(it)
except StopIteration:
    print("Acabaram as frutas!")

caju
manga
acerola
Acabaram as frutas!

Uma classe iteradora

Vamos criar uma contagem regressiva de lançamento de foguete. A classe guarda onde está e entrega o próximo número a cada next:

class ContagemRegressiva:
    def __init__(self, inicio):
        self.atual = inicio

    def __iter__(self):
        return self

    def __next__(self):
        if self.atual < 0:
            raise StopIteration
        numero = self.atual
        self.atual -= 1
        return numero


for n in ContagemRegressiva(5):
    print(n, end=" ")
print("Decolar!")

5 4 3 2 1 0 Decolar!

Atenção: Um iterador só pode ser percorrido uma vez. Depois que ele chega ao fim, um segundo for no mesmo objeto não mostra nada. Se você precisa percorrer várias vezes, faça uma classe iterável que cria um iterador novo a cada for, como na próxima seção.

O jeito curto: __iter__ com yield

Escrever __next__ à mão dá trabalho. Quase sempre é mais simples fazer __iter__ ser um gerador: cada for chama __iter__ de novo e ganha um gerador novinho.

class Turma:
    def __init__(self, nome):
        self.nome = nome
        self.alunos = []

    def matricular(self, aluno):
        self.alunos.append(aluno)

    def __iter__(self):
        for numero, aluno in enumerate(self.alunos, start=1):
            yield f"{numero}. {aluno}"


turma = Turma("7º ano B")
turma.matricular("Davi")
turma.matricular("Helena")
turma.matricular("Yasmin")
for linha in turma:
    print(linha)
print(list(turma))

1. Davi
2. Helena
3. Yasmin
['1. Davi', '2. Helena', '3. Yasmin']

Repare que list(turma) funcionou mesmo depois do for: cada uso começa do zero.

Uma sequência: __len__ e __getitem__

Listas e textos são sequências: têm tamanho e aceitam índices. Para sua classe se comportar assim, escreva __len__ (usado por len()) e __getitem__ (usado por obj[i]). Se você herdar de collections.abc.Sequence, o Python ainda dá de presente in, index, count e reversed:

from collections.abc import Sequence


class Estante(Sequence):
    def __init__(self, *livros):
        self._livros = list(livros)

    def __len__(self):
        return len(self._livros)

    def __getitem__(self, indice):
        return self._livros[indice]


estante = Estante("O Pequeno Príncipe", "Capitães da Areia", "A Bolsa Amarela")
print(len(estante))
print(estante[0])
print(estante[-1])
print(estante[0:2])
print("Capitães da Areia" in estante)
print(estante.index("A Bolsa Amarela"))
print(list(reversed(estante)))

3
O Pequeno Príncipe
A Bolsa Amarela
['O Pequeno Príncipe', 'Capitães da Areia']
True
2
['A Bolsa Amarela', 'Capitães da Areia', 'O Pequeno Príncipe']

Como __getitem__ repassa o índice para a lista interna, até as fatias (estante[0:2]) funcionam.

Dica: Herdar de Sequence obriga você a escrever __len__ e __getitem__. Se esquecer um deles, o Python avisa com TypeError: Can't instantiate abstract class — é a ideia das classes abstratas da aula 78.

Conferindo com isinstance

O módulo collections.abc também serve para perguntar "esse objeto é iterável?" sem testar na marra:

from collections.abc import Iterable, Iterator

numeros = [1, 2, 3]
print(isinstance(numeros, Iterable))
print(isinstance(numeros, Iterator))
print(isinstance(iter(numeros), Iterator))
print(isinstance(42, Iterable))

True
False
True
False

Uma lista é iterável, mas não é iteradora; iter(lista) é. E um número não é iterável — por isso for x in 42 dá erro.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
def __getitem__(self, indice): return self._itens[indice]

1. Crie uma classe iteradora Dado que entregue as faces de 1 a 6, uma por vez, e use-a num for.

Ver resposta 
class Dado:
    def __init__(self):
        self.face = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.face == 6:
            raise StopIteration
        self.face += 1
        return self.face


for face in Dado():
    print(face, end=" ")
print()

1 2 3 4 5 6

2. Crie uma classe Cardapio com uma lista de pratos e um __iter__ com yield que entregue só os pratos que custam até R$ 20.

Ver resposta 
class Cardapio:
    def __init__(self):
        self.pratos = [("Pastel", 8.0), ("Feijoada", 32.0), ("Coxinha", 6.5), ("Moqueca", 45.0)]

    def __iter__(self):
        for nome, preco in self.pratos:
            if preco <= 20:
                yield nome


print(list(Cardapio()))

['Pastel', 'Coxinha']

class Semana(Sequence):
    dias = ["domingo", "segunda", "terça", "quarta", "quinta", "sexta", "sábado"]

    def __len__(self):
        return len(self.dias)

    def __getitem__(self, indice):
