Aula 16 · Formatando textos: f-strings, format e %

Nesta aula você vai aprender

  • Colocar variáveis e contas dentro de textos com f-strings
  • Controlar casas decimais com :.2f e mostrar preços em reais
  • Alinhar textos e números para montar tabelas
  • Reconhecer o método format() e o operador %, usados em códigos mais antigos

O que é uma f-string

Uma f-string é um texto com a letra f antes das aspas. Dentro dela, tudo que estiver entre chaves {} é trocado pelo valor:

nome = "Caio"
idade = 14
print(f"Meu nome é {nome} e tenho {idade} anos.")
print(f"Ano que vem terei {idade + 1} anos.")
print(f"Meu nome em maiúsculas: {nome.upper()}")

Meu nome é Caio e tenho 14 anos.
Ano que vem terei 15 anos.
Meu nome em maiúsculas: CAIO

Dentro das chaves vale qualquer expressão: contas, métodos, chamadas de função. Bem mais prático que juntar pedaços com + e str().

Atenção: Esquecer o f é muito comum. Sem ele, as chaves aparecem do jeito que estão: print("Olá, {nome}") mostra literalmente Olá, {nome}.

Casas decimais e preços em reais

Depois do valor, um : abre a formatação. :.2f mostra o número com 2 casas decimais (o f é de "float"):

preco = 7.5
media = 8.3333333
print(f"Preço: {preco:.2f}")
print(f"Média: {media:.1f}")
print(f"Sem casas: {media:.0f}")

Preço: 7.50
Média: 8.3
Sem casas: 8

O :.2f arredonda na hora de mostrar, mas não muda o valor da variável. No Brasil, usamos vírgula nos centavos e ponto nos milhares: R$ 1.234,50. O Python usa o padrão americano (1,234.50). Um truque: formate com :,.2f e depois troque os símbolos com replace:

valor = 1234.5
texto = f"{valor:,.2f}"
print(texto)
brasil = texto.replace(",", "X").replace(".", ",").replace("X", ".")
print(f"R$ {brasil}")
print(f"R$ {19.9:.2f}".replace(".", ","))

1,234.50
R$ 1.234,50
R$ 19,90

O X serve de "lugar temporário" para não misturar as vírgulas com os pontos durante as trocas.

Alinhamento e largura

Um número depois do : define a largura do campo. Os sinais escolhem o alinhamento: < esquerda, > direita, ^ centro. Um 0 antes da largura completa com zeros:

print(f"[{'pão':<10}]")
print(f"[{'pão':>10}]")
print(f"[{'pão':^10}]")
print(f"[{7:03}]")
print(f"{'Produto':<15}{'Preço':>8}")
print(f"{'Coxinha':<15}{6.5:>8.2f}")
print(f"{'Caldo de cana':<15}{5.25:>8.2f}")

[pão       ]
[       pão]
[   pão    ]
[007]
Produto           Preço
Coxinha            6.50
Caldo de cana      5.25

Dica: Repare nas aspas simples dentro da f-string: f"{'pão':<10}". Se a f-string usa aspas duplas por fora, use simples dentro das chaves, para não confundir o Python.

Porcentagem e conferência com {x=}

:.1% mostra um número como porcentagem. E {variavel=} mostra o nome e o valor juntos, ótimo para conferir o que está acontecendo no programa:

acertos = 17
total = 20
taxa = acertos / total
print(f"Aproveitamento: {taxa:.1%}")
print(f"{acertos=}")
print(f"{acertos * 5=}")

Aproveitamento: 85.0%
acertos=17
acertos * 5=85

format() e %: os jeitos antigos

Antes das f-strings existirem (elas chegaram no Python 3.6), formatava-se texto de outras duas formas. Você vai encontrá-las em códigos e tutoriais mais antigos, então vale reconhecer:

nome = "Bia"
nota = 9.25
print("Aluna: {}, nota: {:.1f}".format(nome, nota))
print("Aluna: {0}, de novo {0}!".format(nome))
print("Aluna: %s, nota: %.1f" % (nome, nota))
print("Tenho %d anos" % 13)

Aluna: Bia, nota: 9.2
Aluna: Bia, de novo Bia!
Aluna: Bia, nota: 9.2
Tenho 13 anos

  • No format(), cada {} é trocado pelos valores, na ordem; {0} repete o primeiro valor.
  • No %, %s marca um texto, %d um inteiro e %.1f um real com uma casa.

Para programas novos, prefira as f-strings: são mais fáceis de ler e de digitar.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
print(f"Total: R$ {total:.2f}".replace(".", ","))

Exercícios

1. Com produto = "Açaí" e preco = 12.9, mostre Açaí custa R$ 12.90 usando f-string.

Ver resposta 
produto = "Açaí"
preco = 12.9
print(f"{produto} custa R$ {preco:.2f}")

Açaí custa R$ 12.90

2. Calcule a média de 7, 8.5 e 6 e mostre Sua média é 7.17 com duas casas decimais.

Ver resposta 
media = (7 + 8.5 + 6) / 3
print(f"Sua média é {media:.2f}")

Sua média é 7.17

3. Mostre o valor 2599.9 no formato brasileiro: R$ 2.599,90.

Ver resposta 
valor = 2599.9
texto = f"{valor:,.2f}".replace(",", "X").replace(".", ",").replace("X", ".")
print(f"R$ {texto}")

R$ 2.599,90

4. Monte uma tabelinha alinhada com o nome de 3 colegas (largura 10, à esquerda) e a nota (largura 5, à direita, uma casa decimal).

Ver resposta 
print(f"{'Bia':<10}{9.5:>5.1f}")
print(f"{'Gustavo':<10}{7:>5.1f}")
print(f"{'Lia':<10}{8.5:>5.1f}")

Bia         9.5
Gustavo     7.0
Lia         8.5

5. Reescreva print("Olá, %s! Você tem %d pontos." % ("Leo", 80)) usando f-string.

Ver resposta 
nome = "Leo"
pontos = 80
print(f"Olá, {nome}! Você tem {pontos} pontos.")

Olá, Leo! Você tem 80 pontos.
