Aula 63 · Código limpo: guard clause e menos if aninhado

Nesta aula você vai aprender

  • Reconhecer o código "em escadinha", com muitos if um dentro do outro
  • Usar guard clauses: tratar os casos de erro primeiro e sair cedo com return
  • Usar continue para pular itens num laço sem aumentar o recuo
  • Trocar cadeias de elif por um dicionário quando fizer sentido

O problema da escadinha

Veja esta função que decide se uma pessoa pode alugar uma bicicleta. Ela funciona, mas cada condição empurra o código mais para a direita:

def pode_alugar(idade, tem_cadastro, saldo):
    if idade >= 12:
        if tem_cadastro:
            if saldo >= 5:
                return "Pode alugar!"
            else:
                return "Saldo insuficiente"
        else:
            return "Faça o cadastro primeiro"
    else:
        return "Idade mínima: 12 anos"

print(pode_alugar(13, True, 10))
print(pode_alugar(13, False, 10))
print(pode_alugar(10, True, 10))

Pode alugar!
Faça o cadastro primeiro
Idade mínima: 12 anos

Para entender o else lá de baixo, você precisa voltar os olhos várias linhas e descobrir a qual if ele pertence. Com mais regras, fica impossível de ler.

Guard clause: saia cedo

Uma guard clause ("cláusula de guarda") é um if no começo da função que trata um caso problemático e sai na hora com return. Depois de todas as guardas, sobra só o caminho feliz, sem recuo nenhum:

def pode_alugar(idade, tem_cadastro, saldo):
    if idade < 12:
        return "Idade mínima: 12 anos"
    if not tem_cadastro:
        return "Faça o cadastro primeiro"
    if saldo < 5:
        return "Saldo insuficiente"
    return "Pode alugar!"

print(pode_alugar(13, True, 10))
print(pode_alugar(13, False, 10))
print(pode_alugar(10, True, 10))

Pode alugar!
Faça o cadastro primeiro
Idade mínima: 12 anos

O resultado é o mesmo, mas agora cada regra é uma linha que se lê de cima para baixo, como uma lista de conferência.

Dica: Repare que as condições ficaram invertidas: em vez de "se a idade é suficiente, continue", escrevemos "se a idade não é suficiente, saia". Esse é o truque da guard clause.

Guardas com raise

As guardas também combinam com raise (aula 53): primeiro você recusa os dados ruins, depois faz a conta tranquilo.

def media(notas):
    if not notas:
        raise ValueError("a lista de notas está vazia")
    if any(n < 0 or n > 10 for n in notas):
        raise ValueError("toda nota deve estar entre 0 e 10")
    return sum(notas) / len(notas)

print(media([7, 8, 9]))
for ruim in ([], [5, 11]):
    try:
        media(ruim)
    except ValueError as e:
        print("Erro:", e)

8.0
Erro: a lista de notas está vazia
Erro: toda nota deve estar entre 0 e 10

continue: guardas dentro de laços

Dentro de um for, o continue faz o papel do return: pula para o próximo item. Compare as duas versões de um programa que soma só os pedidos válidos:

pedidos = [("pastel", 2), ("", 1), ("caldo de cana", 0), ("coxinha", 3)]

total_aninhado = 0
for nome, qtd in pedidos:
    if nome:
        if qtd > 0:
            total_aninhado += qtd

total_guarda = 0
for nome, qtd in pedidos:
    if not nome:
        continue
    if qtd <= 0:
        continue
    total_guarda += qtd

print(total_aninhado, total_guarda)

5 5

Atenção: Guard clause não é desculpa para funções enormes. Se uma função tem guardas demais, talvez ela esteja fazendo coisas demais e deva ser dividida em funções menores.

Um dicionário no lugar de muitos elif

Quando uma cadeia de if/elif só escolhe um valor de acordo com outro, um dicionário faz o mesmo trabalho em menos linhas:

def frete_com_elif(regiao):
    if regiao == "Nordeste":
        return 15.0
    elif regiao == "Sudeste":
        return 10.0
    elif regiao == "Sul":
        return 12.0
    else:
        return 20.0

FRETES = {"Nordeste": 15.0, "Sudeste": 10.0, "Sul": 12.0}

def frete_com_dicionario(regiao):
    return FRETES.get(regiao, 20.0)

for r in ["Sul", "Norte"]:
    print(r, frete_com_elif(r), frete_com_dicionario(r))

Sul 12.0 12.0
Norte 20.0 20.0

O get com um valor padrão (aula 46) faz o papel do else. E, para mudar um preço, basta mexer no dicionário.

Pratique no DIGITAR: digite este trecho no modo Programar do app. 
if not tem_cadastro: return "Faça o cadastro"

Exercícios

1. Reescreva com guard clauses: def entrar(ingresso, idade): se tem ingresso, então se a idade é maior ou igual a 14 devolve "Entrada liberada", senão "Show para maiores de 14"; se não tem ingresso, devolve "Compre o ingresso".

Ver resposta 
def entrar(ingresso, idade):
    if not ingresso:
        return "Compre o ingresso"
    if idade < 14:
        return "Show para maiores de 14"
    return "Entrada liberada"

print(entrar(True, 15))
print(entrar(True, 12))
print(entrar(False, 20))

Entrada liberada
Show para maiores de 14
Compre o ingresso

2. Escreva dividir(a, b) com uma guarda que gera ZeroDivisionError com a mensagem não dá para dividir por zero quando b é 0, e devolve a / b no caminho feliz.

Ver resposta 
def dividir(a, b):
    if b == 0:
        raise ZeroDivisionError("não dá para dividir por zero")
    return a / b

print(dividir(10, 4))
try:
    dividir(1, 0)
except ZeroDivisionError as e:
    print("Erro:", e)

2.5
Erro: não dá para dividir por zero

3. Na lista ["Ana", "", " ", "Bruno", "carla"], mostre os nomes com a primeira letra maiúscula, pulando com continue os vazios ou só com espaços.

Ver resposta 
nomes = ["Ana", "", "  ", "Bruno", "carla"]
for nome in nomes:
    if not nome.strip():
        continue
    print(nome.strip().capitalize())

5. Escreva validar_senha(senha) com guard clauses: devolve "curta demais" se tiver menos de 8 caracteres, "falta um número" se não tiver nenhum dígito, e "senha forte" caso contrário.

Ver resposta 
def validar_senha(senha):
    if len(senha) < 8:
        return "curta demais"
    if not any(c.isdigit() for c in senha):
        return "falta um número"
    return "senha forte"

for s in ["abc", "digitando", "digitar2026"]:
    print(s, "->", validar_senha(s))

abc -> curta demais
digitando -> falta um número
digitar2026 -> senha forte
