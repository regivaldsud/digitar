O que é raspagem

Quando um site não tem API (aula 111), dá para ler a própria página HTML e extrair o que interessa: preços, manchetes, horários. Isso se chama raspagem (*scraping*).

Instale as bibliotecas no seu ambiente virtual:

pip install requests beautifulsoup4

Encontrando elementos

O BeautifulSoup transforma o HTML numa árvore que você consulta. Para treinar sem internet, use um HTML guardado num texto:

from bs4 import BeautifulSoup

html = """
<ul id="cardapio">
  <li class="prato">Baião de dois <span class="preco">32,00</span></li>
  <li class="prato">Moqueca <span class="preco">58,00</span></li>
  <li class="prato">Tapioca <span class="preco">12,00</span></li>
</ul>
"""

sopa = BeautifulSoup(html, "html.parser")
for item in sopa.select("li.prato"):
    nome = item.contents[0].strip()
    preco = item.select_one(".preco").get_text()
    print(f"{nome}: R$ {preco}")

Baião de dois: R$ 32,00
Moqueca: R$ 58,00
Tapioca: R$ 12,00

  • select("li.prato") acha todos os <li> com a classe prato (o mesmo seletor do CSS, aula 242);
  • select_one acha só o primeiro; get_text() pega o texto sem as tags.

Numa página real, você baixa o HTML com requests.get(url, timeout=10).text e passa para o BeautifulSoup.

Raspar com responsabilidade

Atenção: Antes de raspar um site, leia os termos de uso e o arquivo /robots.txt dele, que diz o que robôs podem acessar. Não colete dados pessoais de ninguém, faça poucas requisições (use time.sleep entre elas) e prefira uma API oficial quando existir.
Dica: Sites mudam o HTML sem avisar, e o seu programa quebra. Raspagem é ótima para projetos pessoais, mas frágil para coisas importantes.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
precos = sopa.select("span.preco")

Exercícios

1. Usando o mesmo HTML do cardápio, some os preços de todos os pratos.

Ver resposta 
from bs4 import BeautifulSoup

html = '<span class="preco">32,00</span><span class="preco">58,00</span><span class="preco">12,00</span>'
sopa = BeautifulSoup(html, "html.parser")
total = sum(float(s.get_text().replace(",", ".")) for s in sopa.select(".preco"))
print(f"Total: R$ {total:.2f}")

2. Cite três cuidados antes de raspar um site.

Ver resposta

1. Ler os termos de uso e o robots.txt do site.
2. Não coletar dados pessoais e fazer poucas requisições, com pausas.
3. Usar a API oficial, se o site tiver uma.
