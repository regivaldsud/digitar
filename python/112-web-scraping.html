O que é raspagem

Quando um site não tem API (aula 111), dá para ler a própria página HTML e extrair o que interessa: preços, manchetes, horários de ônibus. Isso se chama raspagem (*scraping*): o programa "raspa" os dados de dentro da página.

A ordem certa é sempre: primeiro procure uma API oficial; só se não houver, raspe. A API foi feita para programas e não muda de formato sem aviso. A página foi feita para pessoas, e o site pode mudar o visual amanhã.

O HTML é uma árvore

Para raspar, você precisa enxergar a página como o computador enxerga. O HTML é feito de tags que ficam umas dentro das outras, como galhos de uma árvore:

<ul id="cardapio">                         ← tag ul, com o atributo id
  <li class="prato">                       ← tag li, com o atributo class
    Moqueca <span class="preco">58,00</span>
  </li>
</ul>

  • a tag diz o tipo do elemento: ul (lista), li (item), a (link), span (trecho de texto);
  • os atributos ficam dentro da tag de abertura: href (endereço de um link), src (de uma imagem);
  • id é um nome único na página; class é um "grupo", e vários elementos podem ter a mesma classe.
Dica: No navegador, clique com o botão direito em qualquer parte de uma página e escolha Inspecionar. Você vê o HTML daquele pedaço, com as classes e os ids — é assim que se descobre o que procurar.

Raspando com a biblioteca padrão

O Python já vem com o html.parser, um leitor de HTML simples. Você cria uma classe filha de HTMLParser e escreve o que fazer quando ele encontra a abertura de uma tag, um texto ou o fechamento de uma tag. Este exemplo coleta todos os links de uma página:

from html.parser import HTMLParser

pagina = """
<nav>
  <a href="/inicio">Início</a>
  <a href="/cursos/python">Curso de Python</a>
  <a href="https://www.python.org">Site oficial</a>
</nav>
"""


class ColetorDeLinks(HTMLParser):
    def __init__(self):
        super().__init__()
        self.links = []

    def handle_starttag(self, tag, attrs):
        if tag == "a":
            atributos = dict(attrs)          # attrs vem como lista de pares
            self.links.append(atributos["href"])


coletor = ColetorDeLinks()
coletor.feed(pagina)
for link in coletor.links:
    print(link)

/inicio
/cursos/python
https://www.python.org

Para pegar o texto de um elemento, o leitor precisa lembrar onde está. Aqui uma variável marca quando estamos dentro de um <span class="preco">:

from html.parser import HTMLParser

pagina = """
<ul id="cardapio">
  <li class="prato">Baião de dois <span class="preco">32,00</span></li>
  <li class="prato">Moqueca <span class="preco">58,00</span></li>
  <li class="prato">Tapioca <span class="preco">12,00</span></li>
</ul>
"""


class LeitorDePrecos(HTMLParser):
    def __init__(self):
        super().__init__()
        self.dentro_do_preco = False
        self.precos = []

    def handle_starttag(self, tag, attrs):
        if tag == "span" and ("class", "preco") in attrs:
            self.dentro_do_preco = True

    def handle_data(self, texto):
        if self.dentro_do_preco:
            self.precos.append(float(texto.replace(",", ".")))

    def handle_endtag(self, tag):
        if tag == "span":
            self.dentro_do_preco = False


leitor = LeitorDePrecos()
leitor.feed(pagina)
print("Preços:", leitor.precos)
print(f"Total: R$ {sum(leitor.precos):.2f}")

Preços: [32.0, 58.0, 12.0]
Total: R$ 102.00

Funciona, mas dá trabalho: para cada coisa que você quer achar, precisa de uma classe nova. É por isso que existe o BeautifulSoup.

BeautifulSoup: a mesma coisa, mais fácil

O BeautifulSoup transforma o HTML numa árvore que você consulta com uma linha. Instale no seu ambiente virtual (o requests vai ser usado logo adiante):

# Windows
py -m pip install requests beautifulsoup4

# Linux e macOS
python3 -m pip install requests beautifulsoup4

O mesmo cardápio, agora com BeautifulSoup. Salve como cardapio.py e rode no computador:

from bs4 import BeautifulSoup

html = """
<ul id="cardapio">
  <li class="prato">Baião de dois <span class="preco">32,00</span></li>
  <li class="prato">Moqueca <span class="preco">58,00</span></li>
  <li class="prato">Tapioca <span class="preco">12,00</span></li>
</ul>
"""

sopa = BeautifulSoup(html, "html.parser")
for item in sopa.select("li.prato"):
    nome = item.contents[0].strip()
    preco = item.select_one(".preco").get_text()
    print(f"{nome}: R$ {preco}")

Baião de dois: R$ 32,00
Moqueca: R$ 58,00
Tapioca: R$ 12,00

  • select("li.prato") acha todos os <li> com a classe prato (o mesmo seletor do CSS, aula 242); select_one acha só o primeiro;
  • get_text() pega o texto sem as tags;
  • item.contents é a lista do que está dentro do elemento; o primeiro item aqui é o texto com o nome do prato.

Além dos seletores CSS, há find (o primeiro) e find_all (todos), que procuram pelo nome da tag e pelos atributos. E um elemento funciona como dicionário para ler atributos:

from bs4 import BeautifulSoup

html = """
<div id="noticias">
  <h2>Notícias da escola</h2>
  <a class="noticia" href="/feira">Feira de ciências na sexta</a>
  <a class="noticia" href="/jogos">Jogos internos começam dia 10</a>
  <img src="/logo.png" alt="Logo da escola">
</div>
"""

sopa = BeautifulSoup(html, "html.parser")
print(sopa.find("h2").get_text())
for link in sopa.find_all("a", class_="noticia"):
    print("-", link.get_text(), "->", link["href"])
print("Imagem:", sopa.find("img")["src"], "/", sopa.find("img").get("alt"))
print("Tem vídeo?", sopa.find("video"))

Notícias da escola
- Feira de ciências na sexta -> /feira
- Jogos internos começam dia 10 -> /jogos
Imagem: /logo.png / Logo da escola
Tem vídeo? None

Atenção: O argumento é class_, com sublinhado, porque class é palavra reservada do Python (aula 70). E quando find não acha nada, devolve None: se você fizer sopa.find("video").get_text(), recebe AttributeError: 'NoneType' object has no attribute 'get_text'. Confira com if elemento is not None: antes de usar.

Uma página de verdade

O site books.toscrape.com é uma livraria de mentira feita justamente para treinar raspagem. Este programa baixa a primeira página, pega o título e o preço de cada livro e salva tudo numa planilha CSV (aula 106):

import csv
import requests
from bs4 import BeautifulSoup

resposta = requests.get("https://books.toscrape.com/", timeout=10)
resposta.raise_for_status()
resposta.encoding = "utf-8"          # garante que o símbolo £ venha certo

sopa = BeautifulSoup(resposta.text, "html.parser")
livros = []
for artigo in sopa.select("article.product_pod"):
    titulo = artigo.select_one("h3 a")["title"]
    preco = artigo.select_one(".price_color").get_text()
    livros.append({"titulo": titulo, "preco": preco})

for livro in livros[:3]:
    print(livro["titulo"], "-", livro["preco"])

with open("livros.csv", "w", newline="", encoding="utf-8") as arquivo:
    escritor = csv.DictWriter(arquivo, fieldnames=["titulo", "preco"])
    escritor.writeheader()
    escritor.writerows(livros)
print(len(livros), "livros salvos em livros.csv")

A Light in the Attic - £51.77
Tipping the Velvet - £53.74
Soumission - £50.10
20 livros salvos em livros.csv

Repare que o título vem do atributo title do link, porque o texto visível na página é cortado com "..." quando o nome é comprido. Achar esse tipo de detalhe é o trabalho de quem raspa: inspecione a página antes de escrever o código.

Raspar com responsabilidade

Um robô consegue abrir centenas de páginas por minuto, e isso pode atrapalhar o site de outras pessoas. Antes de raspar:

  • leia os termos de uso do site; alguns proíbem raspagem;
  • leia o arquivo /robots.txt (por exemplo, https://books.toscrape.com/robots.txt), que diz o que robôs podem acessar;
  • não colete dados pessoais de ninguém (nomes, telefones, fotos de pessoas);
  • faça poucas requisições e espere entre elas com time.sleep(1);
  • prefira sempre uma API oficial quando existir.

O Python sabe ler o robots.txt com o módulo urllib.robotparser. Aqui o texto do arquivo foi colocado direto no código para você testar:

from urllib.robotparser import RobotFileParser

robots = """
User-agent: *
Disallow: /admin/
Disallow: /carrinho/
Crawl-delay: 2
"""

leitor = RobotFileParser()
leitor.parse(robots.splitlines())

for caminho in ["/produtos/chinelo", "/admin/usuarios", "/carrinho/"]:
    pode = leitor.can_fetch("MeuRobo", caminho)
    print(caminho, "->", "pode" if pode else "proibido")
print("Esperar entre pedidos:", leitor.crawl_delay("MeuRobo"), "segundos")

/produtos/chinelo -> pode
/admin/usuarios -> proibido
/carrinho/ -> proibido
Esperar entre pedidos: 2 segundos

No computador, leitor.set_url("https://site/robots.txt") seguido de leitor.read() baixa o arquivo de verdade.

Dica: Sites mudam o HTML sem avisar, e o seu programa quebra. Raspagem é ótima para projetos pessoais e estudos, mas frágil para coisas importantes. Quando quebrar, abra o Inspecionar de novo e veja o que mudou.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
precos = sopa.select("span.preco")

Exercícios

1. Use o html.parser para contar quantos itens <li> existem nesta lista e mostrar o texto de cada um: <ul><li>Arroz</li><li>Feijão</li><li>Farofa</li></ul>.

Ver resposta 
from html.parser import HTMLParser


class LeitorDeItens(HTMLParser):
    def __init__(self):
        super().__init__()
        self.dentro = False
        self.itens = []

    def handle_starttag(self, tag, attrs):
        if tag == "li":
            self.dentro = True

    def handle_data(self, texto):
        if self.dentro:
            self.itens.append(texto)

    def handle_endtag(self, tag):
        if tag == "li":
            self.dentro = False


leitor = LeitorDeItens()
leitor.feed("<ul><li>Arroz</li><li>Feijão</li><li>Farofa</li></ul>")
print(len(leitor.itens), "itens:", ", ".join(leitor.itens))

3 itens: Arroz, Feijão, Farofa

3. Com BeautifulSoup, mostre o endereço (href) de todos os links que abrem um site externo (que começam com https://) neste HTML: <a href="/sobre">Sobre</a><a href="https://www.python.org">Python</a><a href="https://pypi.org">PyPI</a>.

Ver resposta 
from bs4 import BeautifulSoup

html = '<a href="/sobre">Sobre</a><a href="https://www.python.org">Python</a><a href="https://pypi.org">PyPI</a>'
sopa = BeautifulSoup(html, "html.parser")
for link in sopa.find_all("a"):
    if link["href"].startswith("https://"):
        print(link["href"])

A saída é https://www.python.org e, na linha de baixo, https://pypi.org.

4. Um site tem este robots.txt: User-agent: *, Disallow: /privado/, Allow: /privado/publico.html. Use o RobotFileParser para descobrir se um robô pode abrir /privado/notas.html e /privado/publico.html.

Ver resposta 
from urllib.robotparser import RobotFileParser

leitor = RobotFileParser()
leitor.parse([
    "User-agent: *",
    "Allow: /privado/publico.html",
    "Disallow: /privado/",
])
print(leitor.can_fetch("MeuRobo", "/privado/notas.html"))
print(leitor.can_fetch("MeuRobo", "/privado/publico.html"))

False
True

O leitor do Python obedece a primeira regra que combina com o caminho, por isso a linha Allow, mais específica, vem antes do Disallow.
