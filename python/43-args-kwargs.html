Aula 43 · *args, **kwargs, empacotar e desempacotar

Nesta aula você vai aprender

  • Como receber qualquer número de argumentos com *args
  • Como receber argumentos nomeados variáveis com **kwargs
  • Como desempacotar listas e dicionários ao chamar uma função
  • Como empacotar "o resto" numa atribuição com *

Quantos argumentos? Não sei!

O print aceita um, dois ou cinquenta valores. Para criar uma função assim, coloque um asterisco antes do nome do parâmetro:

def somar_tudo(*numeros):
    print("Recebi:", numeros)
    return sum(numeros)

print(somar_tudo(1, 2))
print(somar_tudo(10, 20, 30, 40))
print(somar_tudo())

Recebi: (1, 2)
3
Recebi: (10, 20, 30, 40)
100
Recebi: ()
0

O *numeros empacota todos os argumentos posicionais numa tupla. Por costume, esse parâmetro se chama args (de "arguments"), mas o que importa é o asterisco. Os parâmetros normais vêm antes e o *args pega "o resto":

def lista_de_chamada(turma, *alunos):
    print(f"Turma {turma}: {len(alunos)} alunos")
    for aluno in alunos:
        print(" -", aluno)

lista_de_chamada("7º A", "Ana", "Caio", "Duda")

Turma 7º A: 3 alunos
 - Ana
 - Caio
 - Duda

**kwargs: argumentos nomeados à vontade

Com dois asteriscos, a função recebe qualquer argumento nomeado. Eles chegam num dicionário. Por costume, esse parâmetro se chama kwargs ("keyword arguments"):

def ficha(**dados):
    for chave, valor in dados.items():
        print(f"{chave}: {valor}")

ficha(nome="Luana", idade=13, time="Bahia")

nome: Luana
idade: 13
time: Bahia

Desempacotando na chamada

O asterisco também funciona ao contrário, na chamada: * espalha os itens de uma lista como argumentos separados, e ** espalha um dicionário como argumentos nomeados:

def apresentar(nome, idade, cidade):
    print(f"{nome} tem {idade} anos e mora em {cidade}.")

pessoa = ["Igor", 15, "Natal"]
apresentar(*pessoa)

outra = {"nome": "Sofia", "idade": 12, "cidade": "Belém"}
apresentar(**outra)

numeros = [3, 1, 2]
print(*numeros)

Igor tem 15 anos e mora em Natal.
Sofia tem 12 anos e mora em Belém.
3 1 2

Atenção: Ao desempacotar um dicionário com **, as chaves precisam ter exatamente os nomes dos parâmetros. Uma chave a mais ou com nome diferente dá TypeError: ... got an unexpected keyword argument.

Empacotando numa atribuição

O * também aparece no desempacotamento de variáveis: a variável com asterisco recebe uma lista com tudo o que sobrou:

primeiro, *resto = ["ouro", "prata", "bronze", "4º", "5º"]
print(primeiro)
print(resto)

*comeco, ultimo = [7, 8, 9, 10]
print(comeco, ultimo)

lista_a = [1, 2]
lista_b = [3, 4]
print([*lista_a, *lista_b])
print({**{"a": 1}, **{"b": 2}})

ouro
['prata', 'bronze', '4º', '5º']
[7, 8, 9] 10
[1, 2, 3, 4]
{'a': 1, 'b': 2}

A ordem de tudo

Quando a função usa todos os tipos, a ordem é: parâmetros normais, *args, parâmetros que só aceitam nome e **kwargs:

def pedido(mesa, *itens, garcom="Zé", **extras):
    print("Mesa", mesa, "| garçom:", garcom)
    print("Itens:", itens)
    print("Extras:", extras)

pedido(5, "feijoada", "guaraná", garcom="Rita", gelo=True)

Mesa 5 | garçom: Rita
Itens: ('feijoada', 'guaraná')
Extras: {'gelo': True}

Dica: Não saia usando *args e **kwargs em tudo. Eles são ótimos quando o número de valores realmente varia; quando você sabe quais parâmetros a função precisa, nomeá-los deixa o código mais claro.
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
def somar(*args): return sum(args)

Exercícios

1. Crie a função maior(*numeros) que devolve o maior número recebido (use max). Teste com 4, 19, 7 e 12.

Ver resposta 
def maior(*numeros):
    return max(numeros)

print(maior(4, 19, 7, 12))

19

2. Crie a função media(*notas) que devolve a média das notas. Se nenhuma nota for passada, devolva 0.

Ver resposta 
def media(*notas):
    if len(notas) == 0:
        return 0
    return sum(notas) / len(notas)

print(media(7, 8, 9))
print(media())

8.0
0

3. Crie a função perfil(**info) que mostre cada informação no formato chave -> valor. Chame com nome, jogo_favorito e ppm (palavras por minuto).

Ver resposta 
def perfil(**info):
    for chave, valor in info.items():
        print(chave, "->", valor)

perfil(nome="Theo", jogo_favorito="Minecraft", ppm=42)

nome -> Theo
jogo_favorito -> Minecraft
ppm -> 42

4. Você tem a lista data = [7, 9, 2022] e a função mostrar_data(dia, mes, ano). Chame a função usando a lista desempacotada para mostrar 7/9/2022.

Ver resposta 
def mostrar_data(dia, mes, ano):
    print(f"{dia}/{mes}/{ano}")

data = [7, 9, 2022]
mostrar_data(*data)

7/9/2022

5. Na lista de chegada ["Bia", "Davi", "Gui", "Lara", "Rui"], separe numa linha só o campeão, o vice e o resto dos corredores.

Ver resposta 
campeao, vice, *outros = ["Bia", "Davi", "Gui", "Lara", "Rui"]
print("Campeão:", campeao)
print("Vice:", vice)
print("Outros:", outros)

Campeão: Bia
Vice: Davi
Outros: ['Gui', 'Lara', 'Rui']
