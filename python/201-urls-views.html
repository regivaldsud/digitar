Do endereço até a função

Quando você abre http://127.0.0.1:8000/ola/, o Django procura em urls.py qual view cuida do caminho ola/. A view é uma função Python que recebe o pedido (request) e devolve uma resposta (HttpResponse).

# contatos/views.py
from django.http import HttpResponse


def ola(request):
    return HttpResponse("<h1>Olá do Django!</h1>")


def dobro(request, numero):
    return HttpResponse(f"O dobro de {numero} é {numero * 2}")

Ligando as URLs

# contatos/urls.py (crie este arquivo)
from django.urls import path
from . import views

urlpatterns = [
    path("ola/", views.ola, name="ola"),
    path("dobro/<int:numero>/", views.dobro, name="dobro"),
]
# config/urls.py
from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("contatos.urls")),
]

Abrindo http://127.0.0.1:8000/dobro/21/:

O dobro de 21 é 42

O conversor <int:numero> pega o pedaço da URL, transforma em int e entrega para a view com o nome numero.

O que vem no request

O objeto request traz tudo sobre o pedido: o método (GET ou POST), os dados enviados e o usuário logado. Os dados da URL depois do ? ficam em request.GET:

from django.http import HttpResponse


def busca(request):
    termo = request.GET.get("q", "")
    return HttpResponse(f"Você buscou: {termo}")

Para /busca/?q=pastel, a resposta é Você buscou: pastel (registre a rota path("busca/", views.busca)).

Atenção: Toda view precisa devolver uma resposta com return. Se esquecer, o Django mostra o erro "didn't return an HttpResponse object. It returned None instead."
Pratique no DIGITAR: digite este trecho no modo Programar do app. 
path("dobro/<int:numero>/", views.dobro, name="dobro")

Exercícios

from django.http import HttpResponse


def saudacao(request, nome):
    return HttpResponse(f"Oi, {nome}!")

2. A lógica de uma view pode ser testada como função comum. Escreva tabuada_texto(n) que devolve a tabuada de n (de 1 a 3) separada por vírgulas, para usar numa view /tabuada/<int:n>/.

Ver resposta 
def tabuada_texto(n):
    return ", ".join(f"{n}x{i}={n * i}" for i in range(1, 4))


print(tabuada_texto(7))

7x1=7, 7x2=14, 7x3=21
