O que vamos construir

Você aprendeu a digitar com o DIGITAR. Agora vai construir o seu próprio treino de digitação! O programa mostra uma frase, você digita, e ele responde quanto tempo levou, sua velocidade e sua precisão.

É o encontro perfeito das duas coisas que você aprendeu: digitar bem e programar.

  • random.choice sorteia um item da lista.

Passo 2: medir o tempo

O módulo time tem a função perf_counter(), um cronômetro de alta precisão. O valor dela sozinho não significa nada; o que importa é a diferença entre duas leituras:

import time

inicio = time.perf_counter()
total = sum(range(1_000_000))
fim = time.perf_counter()
print(f"Somar um milhão de números levou {fim - inicio:.4f} segundos")

(exemplo — a sua saída pode ser diferente)
Somar um milhão de números levou 0.0182 segundos

No treino, vamos ler o cronômetro logo antes do input e logo depois que a pessoa aperta Enter.

Dica: Prefira time.perf_counter() a time.time() para medir duração. O time.time() segue o relógio do computador, que pode ser ajustado no meio da medição; o perf_counter só anda para a frente.

Passo 3: calcular a velocidade (PPM)

Palavras têm tamanhos diferentes: "pé" é rapidinho, "paralelepípedo" não. Para comparar de forma justa, os cursos de digitação usam uma palavra padrão de 5 caracteres (contando espaços e pontuação). A fórmula fica:

PPM = (caracteres digitados ÷ 5) ÷ minutos

def calcular_ppm(caracteres, segundos):
    if segundos <= 0:
        return 0.0
    minutos = segundos / 60
    return (caracteres / 5) / minutos


print(round(calcular_ppm(250, 60)))
print(round(calcular_ppm(120, 30)))
print(round(calcular_ppm(21, 6.3)))

50
48
40

Digitar 250 caracteres em 1 minuto dá 50 PPM. Também dá para contar as palavras de verdade, com split():

def palavras_reais_por_minuto(texto, segundos):
    return len(texto.split()) / (segundos / 60)


print(round(palavras_reais_por_minuto("O sapo não lava o pé.", 6.3)))

57

As duas medidas são diferentes: "O sapo não lava o pé." tem 6 palavras curtinhas, então a contagem real dá mais que a palavra padrão.

Passo 4: calcular a precisão

Comparamos a frase certa com o que foi digitado, posição por posição. A função zip anda pelas duas ao mesmo tempo:

def calcular_precisao(alvo, digitado):
    total = max(len(alvo), len(digitado))
    if total == 0:
        return 100.0
    acertos = 0
    for certo, feito in zip(alvo, digitado):
        if certo == feito:
            acertos += 1
    return acertos / total * 100


print(calcular_precisao("o gato mia", "o gato mia"))
print(calcular_precisao("o gato mia", "o gatp mia"))
print(calcular_precisao("o gato mia", "o gato"))
print(calcular_precisao("o gato mia", "o gato miaaaaa"))

100.0
90.0
60.0
71.42857142857143

  • Usamos o maior tamanho como total: assim, digitar letras a menos ou a mais também diminui a precisão.
  • O zip para no fim da sequência mais curta, então os caracteres que sobram contam como erro.
Atenção: Esta comparação posição por posição é simples, mas tem um ponto fraco: se você pular uma letra no começo, todas as seguintes ficam "fora do lugar" e contam como erro. Um desafio extra no fim da aula mostra uma forma mais esperta de comparar.

Passo 5: mostrar onde estão os erros

Vamos desenhar um ^ embaixo de cada caractere errado:

def marcar_erros(alvo, digitado):
    marcas = ""
    for i in range(max(len(alvo), len(digitado))):
        certo = alvo[i] if i < len(alvo) else ""
        feito = digitado[i] if i < len(digitado) else ""
        marcas += " " if certo == feito else "^"
    return marcas.rstrip()


alvo = "A prática leva à perfeição."
digitado = "A pratica leva a perfeiçao."
print(alvo)
print(digitado)
print(marcar_erros(alvo, digitado))

A prática leva à perfeição.
A pratica leva a perfeiçao.
    ^          ^        ^

Num terminal, que usa letras de largura fixa, cada ^ fica bem embaixo do erro. Repare que esquecer os acentos também conta como erro — digitar bem em português inclui os acentos!

Passo 6: o programa completo

Agora juntamos tudo: 3 rodadas com frases sorteadas e, no fim, a média de velocidade e de precisão.

import random
import time

FRASES = [
    "O sapo não lava o pé.",
    "Quem digita bem programa mais rápido.",
    "A prática leva à perfeição.",
    "Python é uma linguagem fácil de ler.",
    "Hoje tem pão de queijo no café da manhã.",
    "O Brasil tem vinte e seis estados e o Distrito Federal.",
]
RODADAS = 3


def calcular_ppm(caracteres, segundos):
    if segundos <= 0:
        return 0.0
    return (caracteres / 5) / (segundos / 60)


def calcular_precisao(alvo, digitado):
    total = max(len(alvo), len(digitado))
    if total == 0:
        return 100.0
    acertos = sum(1 for certo, feito in zip(alvo, digitado) if certo == feito)
    return acertos / total * 100


def marcar_erros(alvo, digitado):
    marcas = ""
    for i in range(max(len(alvo), len(digitado))):
        certo = alvo[i] if i < len(alvo) else ""
        feito = digitado[i] if i < len(digitado) else ""
        marcas += " " if certo == feito else "^"
    return marcas.rstrip()


def rodada(numero, frase):
    print()
    print(f"--- Rodada {numero} de {RODADAS} ---")
    input("Aperte Enter quando estiver pronto...")
    print(frase)
    inicio = time.perf_counter()
    digitado = input()
    segundos = time.perf_counter() - inicio
    ppm = calcular_ppm(len(digitado), segundos)
    precisao = calcular_precisao(frase, digitado)
    print(f"Tempo: {segundos:.1f} s | Velocidade: {ppm:.0f} PPM | Precisão: {precisao:.0f}%")
    if digitado != frase:
        print(marcar_erros(frase, digitado))
    return ppm, precisao


def mensagem(precisao):
    if precisao == 100:
        return "Perfeito! Nenhum erro."
    if precisao >= 95:
        return "Excelente! Quase sem erros."
    if precisao >= 85:
        return "Bom trabalho! Capriche um pouco mais na precisão."
    return "Vá com calma: primeiro acerte, depois acelere."


def main():
    print("=== TREINO DE DIGITAÇÃO ===")
    print("Digite cada frase exatamente como aparece e aperte Enter.")
    resultados = []
    for numero, frase in enumerate(random.sample(FRASES, RODADAS), start=1):
        resultados.append(rodada(numero, frase))
    media_ppm = sum(r[0] for r in resultados) / len(resultados)
    media_precisao = sum(r[1] for r in resultados) / len(resultados)
    melhor = max(r[0] for r in resultados)
    print()
    print("=== RESULTADO FINAL ===")
    print(f"Velocidade média: {media_ppm:.0f} PPM (melhor rodada: {melhor:.0f} PPM)")
    print(f"Precisão média: {media_precisao:.0f}%")
    print(mensagem(media_precisao))


if __name__ == "__main__":
    main()

Como rodar no seu computador

Este programa precisa do terminal: o cronômetro mede o tempo entre a frase aparecer e você apertar Enter.

  • Salve o código como treino.py.
  • No terminal do VS Code, rode o comando abaixo.
  • Depois do "Aperte Enter quando estiver pronto...", a frase aparece e o cronômetro começa. Digite e aperte Enter.
python treino.py
Dica: Compare o resultado do seu treino com o do DIGITAR. Os números podem ser um pouco diferentes, porque cada programa mede de um jeito (aqui, o tempo de reação até começar a digitar também conta). O importante é ver a sua evolução de um dia para o outro.

2. Muitos cursos usam o PPM líquido: cada erro desconta uma palavra. A fórmula é (caracteres / 5 - erros) / minutos, e o resultado nunca fica negativo. Escreva ppm_liquido(caracteres, erros, segundos).

Ver resposta 
def ppm_liquido(caracteres, erros, segundos):
    minutos = segundos / 60
    resultado = (caracteres / 5 - erros) / minutos
    return max(resultado, 0)


print(round(ppm_liquido(250, 0, 60)))
print(round(ppm_liquido(250, 5, 60)))
print(round(ppm_liquido(30, 10, 60)))

45

from collections import Counter

pares = [

import json


def carregar_historico(caminho):
    try:
        with open(caminho, encoding="utf-8") as arquivo:
            return json.load(arquivo)
    except FileNotFoundError:
        return []


def salvar_historico(historico, caminho):
    with open(caminho, "w", encoding="utf-8") as arquivo:

5. Calcule a precisão com difflib.SequenceMatcher, que encontra as partes iguais mesmo quando uma letra foi pulada. Compare com a precisão posição por posição.

Ver resposta 
from difflib import SequenceMatcher


def precisao_simples(alvo, digitado):
    total = max(len(alvo), len(digitado))
    acertos = sum(1 for a, d in zip(alvo, digitado) if a == d)
    return acertos / total * 100


def precisao_esperta(alvo, digitado):
    return SequenceMatcher(None, alvo, digitado).ratio() * 100


alvo = "programar é divertido"
digitado = "rogramar é divertido"
print(f"Simples: {precisao_simples(alvo, digitado):.0f}%")
print(f"Esperta: {precisao_esperta(alvo, digitado):.0f}%")

Simples: 0%
Esperta: 98%

Só a primeira letra foi pulada, mas a comparação simples conta quase tudo como erro, porque cada letra ficou uma posição "fora do lugar". O SequenceMatcher encontra os trechos iguais e dá uma nota muito mais justa.
